Python Functions

Function cha use code reusable banvnyasathi hoto. Ekda function define karun tyala anek vela call karta yete.

📘 Level: Beginner ⏱️ Time: 40–50 Minutes

1. What are Functions?

Function ha code cha reusable block aahe. Specific task perform karnyasathi function create kartat.

Samja aaplyala Hello message anek vela print karaycha aahe. Pratyek veli print() lihinyapeksha ek function create karun tyala punha-punha call karu shakto.

Without Function

print("Hello Rohan")
print("Hello Rohan")
print("Hello Rohan")

With Function

def greet():
    print("Hello Rohan")

greet()
greet()
greet()
Output: 
Hello Rohan
Hello Rohan
Hello Rohan
Samjun ghe: Function ekda define kela aahe ani greet() call karun tyacha code teen vela execute kela aahe.

2. Advantages of Functions

  • Code Reusability: Ekach code anek vela use karta yeto.
  • Less Repetition: Same code punha-punha lihava lagat nahi.
  • Easy Maintenance: Code update karne sope hote.
  • Better Organization: Program small parts madhye divide hoto.
  • Easy Testing: Specific function separately test karta yeto.
Important: Large applications madhye functions mule code samjun ghene, debug karne ani maintain karne sope hote.

5. User-defined Functions

Programmer swatah specific task sathi function create karto. Tyala User-defined Function mhantat.

Python madhye function define karnyasathi def keyword vapartat.

Syntax

def function_name():
    # Code to execute

Example

def greet():
    print("Welcome to Python")

greet()
Output: 
Welcome to Python

Code Explanation

  • def – Function define karnyasathi keyword.
  • greet – Function che name.
  • () – Parameters lihinyasathi parentheses.
  • : – Function body suru hoto.
  • greet() – Function call karto.

7. Parameters in Functions

Function define kartana parentheses madhye je variables lihito tyanna Parameters mhantat.

Example

def greet(name):
    print("Hello", name)

greet("Rohan")
greet("Amit")
Output: 
Hello Rohan
Hello Amit

Ya example madhye name ha parameter aahe. Function call kartana dilelya values name madhye store hotat.

Important: Parameters ani Arguments ya donhi terms madhye difference aahe. Parameters function definition madhye astat, arguments function call kartana dile jatat.

9. return Statement

return statement cha use function madhun result value parat pathavnyasathi hoto.

return zalyanantar function madhil execution thambte ani result function call chya thikani milto.

Syntax

def function_name():
    return value

Example

def add(a, b):
    return a + b

result = add(10, 20)

print(result)
Output: 
30

Using Returned Value

def square(number):
    return number * number

answer = square(5)

print("Square:", answer)
Output: 
Square: 25
Important: return mule value caller la milte. Ti value variable madhye store karu shakto kiwa dusrya calculation madhye vapru shakto.

10. Difference Between print() and return

print() ani return ekach kam karat nahit. Ha difference samjun ghene khup important aahe.

Using print()

def add(a, b):
    print(a + b)

result = add(10, 20)

print("Result:", result)
Output: 
30
Result: None

Using return

def add(a, b):
    return a + b

result = add(10, 20)

print("Result:", result)
Output: 
Result: 30
print() return
Output display karto. Value caller la parat pathavto.
Swatah result return karat nahi. Result pudhe use karta yeto.
print() mule function automatically return hot nahi. return nantar function execution stop hote.

11. Function Without return

Function madhye return statement nasel tar Python automatically None return karto. 

def greet():
    print("Hello")

result = greet()

print(result)
Output: 
Hello
None

Function ne explicit value return keli nahi, mhanun result chi value None aahe.

12. Returning Multiple Values

Python madhye function madhun comma-separated multiple values return karta yetat. Python tyanna tuple madhye pack karto. 

def calculate(a, b):
    total = a + b
    difference = a - b

    return total, difference

result = calculate(20, 10)

print(result)
Output: 
(30, 10)

Unpacking Returned Values

def calculate(a, b):
    return a + b, a - b

total, difference = calculate(20, 10)

print("Total:", total)
print("Difference:", difference)
Output: 
Total: 30
Difference: 10

13. Local and Global Variables

Function chya aat create kelelya variable la Local Variable mhantat. Function chya baher create kelelya variable la Global Variable mhantat.

Local Variable

def greet():
    message = "Hello Python"
    print(message)

greet()
Output: 
Hello Python

message ha function chya aat create zala aahe. Mhanun to local variable aahe.

Global Variable

name = "Rohan"

def greet():
    print("Hello", name)

greet()
Output: 
Hello Rohan

name ha function chya baher define kela aahe. Mhanun to global variable aahe ani function madhun read karta yeto.

Note: Global variable la function madhun modify karaycha asel tar global keyword lagto. Pan unnecessary global variables vaprane talave.

15. Practical Example – Calculator

16. Common Beginner Mistakes

Mistake 1: Missing Parentheses

def greet:
    print("Hello")

Function name nantar parentheses dene avashyak aahe. 

def greet():
    print("Hello")

Mistake 2: Missing Colon

def greet()
    print("Hello")

Function definition nantar colon dene avashyak aahe. 

def greet():
    print("Hello")

Mistake 3: Wrong Indentation

def greet():
print("Hello")

Function body madhil code la indentation dene avashyak aahe. 

def greet():
    print("Hello")

Mistake 4: Calling Before Definition

greet()

def greet():
    print("Hello")

Function define honyapurvi call kelyas NameError yeu shakto. Function aadhi define kar. 

def greet():
    print("Hello")

greet()

Mistake 5: Forgetting return

def add(a, b):
    print(a + b)

result = add(10, 20)
print(result)

Function madhun result pudhe use karaycha asel tar print() aivaji return vapra. 

def add(a, b):
    return a + b

19. Practical Task – Student Result System

Student che name ani marks gheun result calculate kar. Function madhye marks check karun Pass kiwa Fail return kar. 

def check_result(name, marks):

    if marks >= 35:
        result = "Pass"
    else:
        result = "Fail"

    return result


student_name = "Rohan"
student_marks = 80

result = check_result(student_name, student_marks)

print("Student:", student_name)
print("Marks:", student_marks)
print("Result:", result)
Output: 
Student: Rohan
Marks: 80
Result: Pass
