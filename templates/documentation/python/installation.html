Python Installation

Ya lesson madhye apan Windows laptop var Python download ani install karayla shiknar aahot. Tasech Python properly install zale aahe ki nahi he suddha check karu.

📘 Beginner Level ⏱️ 15–20 Minutes

1. What is Python Installation?

Python installation mhanje aplya computer madhye Python language run karanyasathi avashyak software install karne.

Python install kelyanantar apan computer var Python code lihू shakto ani execute karu shakto.

Simple Example:

Jase mobile madhye app vaprayche asel tar te app install karave lagte, tasech computer madhye Python programs run karanyasathi Python install karave lagte.

2. Requirements Before Installation

Python install karanyapurvi khalil goshti aplyakade asne avashyak aahe.

  • Windows laptop kiwa computer.
  • Internet connection.
  • Python download karanyasathi web browser.
  • Installation sathi purashi disk space.
Tip:

Python shiknyasathi expensive laptop chi garaj nahi. Normal Windows computer var suddha Python shikta yete.

3. Download Python

Python download karanyasathi apan Python chi official website vaparnar aahot.

Step 1: Official Website Open Kara

Browser open kara ani khalil website la visit kara.

Download Python – Official Website ↗

Step 2: Python Download Kara

Website var tumchya Windows system sathi available Python release download kara. Installer download hoil.

Important:

Python fakt official python.org website varunach download kara. Unknown websites varun installer download karu naka.

4. Install Python on Windows

Python installer download zalyanantar khalil steps follow kara.

Step 1: Installer Open Kara

Downloads folder madhye ja. Download keleli Python installer file double-click karun open kara.

Step 2: Add Python to PATH

Installer chya suruvatichya screen var Add python.exe to PATH asa checkbox disel.

Ha checkbox select karne mahatvache aahe.

PATH mule Windows Command Prompt kiwa PowerShell madhun Python command access karu shakto.

Step 3: Install Now

Ata Install Now button var click kara. Installation process suru hoil.

Step 4: Installation Complete

Installation complete zalyavar successful installation cha message disel. Ata Close button var click kara.

Python Installed!

Tumchya Windows computer madhye Python install zale aahe. Ata tyachi installation verify karuya.

5. Verify Python Installation

Python properly install zale aahe ki nahi he check karanyasathi apan PowerShell vaparnar aahot.

Step 1: PowerShell Open Kara

Windows Start menu madhye PowerShell search kara ani open kara.

Step 2: Python Version Check Kara

Khalil command type karun Enter press kara. 

python --version

Output Example:

Python 3.14.5

Tumchya computer var install kelelya version nusar output vegla asu shakto.

Alternative Command:

Jar python command work hot nasel tar Windows Python Launcher vaprun check kara. 

py --version

Check pip Version:

pip he Python package installer aahe. Tyachya madatine apan Python libraries install karu shakto. 

python -m pip --version

7. Common Installation Problems

Problem 1: Python is not recognized

Command Prompt madhye Python command run kartana ha error yeu shakto. 

'python' is not recognized as an internal or external command
Solution:
  • Python installation madhye PATH checkbox select zala hota ka check kara.
  • PowerShell close karun punha open kara.
  • python --version punha run kara.
  • Garaj asel tar Python installer madhun Modify kiwa reinstall karun PATH setup kara.

Problem 2: Python command opens Microsoft Store

Kahi Windows systems madhye python command Microsoft Store open karu shakto.

Solution:

Adhi py --version command try kara. Python Launcher available asel tar version display hoil. Nantar Windows App Execution Aliases settings madhye python aliases check kara.
