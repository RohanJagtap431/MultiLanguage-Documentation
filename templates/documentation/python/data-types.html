06. Python Data Types

Python madhye data che vegvegale types kontya astat ani te kase use kartat he ya lesson madhye shikuya.

📘 Beginner Level ⏱️ 20-25 Minutes

1. What are Data Types?

Data Type mhanje variable madhye kontya prakarcha data store aahe he sangnara type.

Udaharanarth, aaplyala student che name, age, percentage ani pass/fail status store karaycha asel tar pratyek value cha data type vegala asu shakto.

Simple Definition: Data Type defines the type of value stored in a variable.
Example
name = "Rohan"
age = 20
marks = 85.5
is_passed = True

print(name)
print(age)
print(marks)
print(is_passed)
Output: 
Rohan
20
85.5
True

2. Types of Data Types in Python

Python madhye commonly use honare built-in data types khalil pramane aahet.

Data Type Use Example
int Whole numbers 10, 50, -5
float Decimal numbers 10.5, 25.75
complex Complex numbers 2 + 3j
str Text data "Python"
bool True or False True
list Collection of items [10, 20, 30]
tuple Ordered collection (10, 20, 30)
set Unique items {10, 20, 30}
dict Key-value data {"name": "Rohan"}
NoneType No value None

3. Integer (int)

Integer data type cha use whole numbers store karanyasathi hoto. Mhanje jyamadhye decimal point nasto ase numbers.

Examples: 10, 25, 100, -5, 0

Example
age = 20
marks = 85
temperature = -5

print(age)
print(marks)
print(temperature)
Output: 
20
85
-5

4. Float (float)

Float data type cha use decimal numbers store karanyasathi hoto.

Examples: 10.5, 25.75, 99.99

Example
price = 99.50
percentage = 85.75
height = 5.8

print(price)
print(percentage)
print(height)
Output: 
99.5
85.75
5.8
Tip: Decimal value lihitana Python kahi vela trailing zero display karat nahi. Udaharanarth 99.50 cha output 99.5 asa yeu shakto.

5. Complex (complex)

Complex data type cha use complex numbers store karanyasathi hoto. Complex number madhye real ani imaginary part astat.

Python madhye imaginary part sathi j vapartat.

Example
number = 2 + 3j

print(number)
print(type(number))
Output: 
(2+3j)
<class 'complex'>

6. String (str)

String data type cha use text store karanyasathi hoto. String madhye letters, words, numbers as text ani symbols store karta yetat.

String create karanyasathi single quotes (' ') kiwa double quotes (" ") vapartat.

Example
name = "Rohan"
city = 'Kolhapur'
language = "Python"

print(name)
print(city)
print(language)
Output: 
Rohan
Kolhapur
Python
Important: age = 20 ha integer aahe, pan age = "20" ha string aahe. Quotes mule data type change hoto.

7. Boolean (bool)

Boolean data type madhye fakt don values astat: True ani False.

Boolean cha use conditions, comparisons ani decision making madhye hoto.

Example
is_student = True
is_married = False

print(is_student)
print(is_married)
Output: 
True
False
Remember: Python madhye True ani False yanche pahile letter capital aste.

8. List (list)

List cha use ekach variable madhye anek values store karanyasathi hoto.

List square brackets [] madhye lihitat. List madhil values change karta yetat.

Example
fruits = ["Apple", "Banana", "Mango"]

print(fruits)
Output: 
['Apple', 'Banana', 'Mango']

Accessing List Items

List madhil item access karanyasathi index vapartat. Python madhye index 0 pasun suru hoto. 

fruits = ["Apple", "Banana", "Mango"]

print(fruits[0])
print(fruits[1])
Output: 
Apple
Banana

Changing List Items

fruits = ["Apple", "Banana", "Mango"]

fruits[1] = "Orange"

print(fruits)
Output: 
['Apple', 'Orange', 'Mango']

9. Tuple (tuple)

Tuple ha suddha anek values store karanyasathi use hoto. Tuple madhye values parentheses () madhye lihitat.

List peksha Tuple madhil ek important difference mhanje tuple create kelyanantar tyatil items change karta yet nahit.

Example
colors = ("Red", "Green", "Blue")

print(colors)
print(colors[0])
Output: 
('Red', 'Green', 'Blue')
Red
Important: Tuple madhil item change karanyacha prayatna kelyas TypeError yeu shakto.

10. Set (set)

Set cha use unique values store karanyasathi hoto. Set madhye duplicate values store hot nahit.

Set create karanyasathi curly brackets {} vapartat.

Example
numbers = {10, 20, 30, 20, 10}

print(numbers)
Output: 
{10, 20, 30}

Ithe 10 ani 20 ya values duplicate hotya. Set ne tyanchi duplicate entries remove kelya.

Remember: Set madhye order fixed nasto. Mhanun output madhil values veglya order madhye disu shaktat.

11. Dictionary (dict)

Dictionary madhye data key-value pairs madhye store hoto. Pratyek value la ek key aste.

Dictionary curly brackets {} madhye lihitat.

Example
student = {
    "name": "Rohan",
    "age": 20,
    "city": "Kolhapur"
}

print(student)
Output: 
{'name': 'Rohan', 'age': 20, 'city': 'Kolhapur'}

Accessing Dictionary Values

student = {
    "name": "Rohan",
    "age": 20
}

print(student["name"])
print(student["age"])
Output: 
Rohan
20

12. NoneType

Python madhye None cha use value available nasel kiwa sadhya kahi value dyaychi nasel tevha hoto.

Example
result = None

print(result)
print(type(result))
Output: 
None
<class 'NoneType'>
Tip: None mhanje zero kiwa empty string nahi. To value naslyache represent karto.

13. Checking Data Type Using type()

Variable cha data type check karanyasathi Python madhye type() function vapartat.

Example
name = "Rohan"
age = 20
marks = 85.5
is_passed = True

print(type(name))
print(type(age))
print(type(marks))
print(type(is_passed))
Output: 
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>

type() function variable cha data type return karto.

14. Mutable and Immutable Data Types

Python madhye kahi data types madhil values create kelyanantar change karta yetat, tar kahi data types madhil values change karta yet nahit.

Mutable Data Types

Mutable mhanje object create kelyanantar tyatil data change karta yeto.

Examples: list, dict, set

numbers = [10, 20, 30]

numbers[0] = 100

print(numbers)
Output: 
[100, 20, 30]

Immutable Data Types

Immutable mhanje object create kelyanantar tyatil value directly change karta yet nahi.

Examples: int, float, bool, str, tuple

name = "Python"

name[0] = "J"

print(name)
Error: TypeError: 'str' object does not support item assignment

String immutable aslyamule tyatil character directly change karta yet nahi.

15. Common Beginner Mistakes

Mistake 1: Number la String samajne

age = "20"
print(type(age))

Output: <class 'str'>

Quotes aslyamule 20 ha string aahe, integer nahi.

Mistake 2: List ani Tuple madhil difference visarne

numbers = (10, 20, 30)
numbers[0] = 100

Tuple immutable aslyamule item change karta yet nahi.

Mistake 3: Dictionary madhye wrong key use karne

student = {"name": "Rohan"}

print(student["age"])

Dictionary madhye age key naslyamule KeyError yeil.
