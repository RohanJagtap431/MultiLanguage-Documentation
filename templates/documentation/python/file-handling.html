Python File Handling

Python madhun files create, read, write ani update karnyasathi File Handling vapartat.

📘 Level: Beginner ⏱️ Time: 45–55 Minutes

1. What is File Handling?

File Handling mhanje Python program cha use karun computer madhil files sobat operations perform karne.

Aapan file madhil data read karu shakto, navin data write karu shakto ani existing data update karu shakto.

Example

Samaj tu Student Management System banavla aahe. Students chi information file madhye save karaychi asel, tar File Handling vaparta yeil.

Samjun ghe: Variable madhil data generally program chalu astana memory madhye asto. File madhye save kelela data program band zalyanantarsuddha available rahu shakto.

3. open() Function

Python madhye file open karnyasathi open() function vapartat.

Syntax

file = open("filename.txt", "mode")

Yethe:

  • filename.txt: File che name.
  • mode: File kontya purpose sathi open karaychi aahe.
  • file: File object store karnara variable.

Example

file = open("student.txt", "r")

print(file.read())

file.close()

Ya example madhye student.txt file read mode madhye open keli aahe. read() method ne data vachla ani close() ne file close keli.

Important: Read mode madhye file astitvat nasel tar FileNotFoundError yeu shakto.

4. File Opening Modes

File open kartana mode specify karava lagto. Mode varun file sobat konta operation karaycha te tharate.

Mode Meaning Purpose
r Read Existing file madhil data vachne.
w Write Data write karne; existing content overwrite hoto.
a Append Existing data chya shevti navin data add karne.
x Create Navin file create karne; file already asel tar error.
b Binary Binary mode madhye file open karne.
t Text Text mode; default mode.
r+ Read and Write Existing file read ani write karne.
w+ Write and Read File write ani read karne; existing content clear hoto.
a+ Append and Read File read karne ani shevti data add karne.
Important: w mode vaparlyas existing file madhil junya content la overwrite kele jate. Mahit nasatana w mode vapru nakos.

5. read() Method

read() method cha use file madhil content read karnyasathi hoto.

Example

Samaj student.txt madhye ha data aahe:

Rohan
Python
Django

Python code:

file = open("student.txt", "r")

data = file.read()

print(data)

file.close()
Output: 
Rohan
Python
Django

read(size)

read() madhye number dila tar tevdhe characters read karta yetat. 

file = open("student.txt", "r")

data = file.read(5)

print(data)

file.close()
Output: 
Rohan
Note: read() cha default argument -1 asto. Mhanje remaining complete content read hoto.

6. readline() Method

readline() method file madhun ek veli ek line read karte.

Example

file = open("student.txt", "r")

line1 = file.readline()
line2 = file.readline()

print(line1)
print(line2)

file.close()
Output: 
Rohan
Python

Pahilya readline() ne first line ani dusrya readline() ne second line read keli.

7. readlines() Method

readlines() method file madhil saglya lines read karun list return karte.

Example

file = open("student.txt", "r")

data = file.readlines()

print(data)

file.close()
Output: 
['Rohan\n', 'Python\n', 'Django']

readlines() ne file madhil pratyek line list madhil separate element mhanun milte.

8. write() Method

write() method cha use file madhye data write karnyasathi hoto.

Example

file = open("student.txt", "w")

file.write("Hello Python")

file.close()

print("Data written successfully")
Output: 
Data written successfully

Ya code mule student.txt file madhye Hello Python save hoil. File already asel tar ticha old content overwrite hoil.

Writing Multiple Lines

file = open("student.txt", "w")

file.write("Name: Rohan\n")
file.write("Course: Python\n")
file.write("Year: Second")

file.close()

File madhil content:

Name: Rohan
Course: Python
Year: Second

9. writelines() Method

writelines() method iterable madhil strings file madhye write karte.

Example

lines = [
    "Python\n",
    "Django\n",
    "SQL\n"
]

file = open("skills.txt", "w")

file.writelines(lines)

file.close()

File madhil content:

Python
Django
SQL
Important: writelines() automatic newline add karat nahi. Pratyek line sathi \n swatah dyava lagto.

10. Append Mode

Existing file madhil data delete na karta shevti navin data add karnyasathi a mode vapartat.

Example

file = open("student.txt", "a")

file.write("\nCourse: Django")

file.close()

print("New data added")
Output: 
New data added

File madhil updated content:

Name: Rohan
Course: Python
Year: Second
Course: Django
Tip: Existing data preserve karun navin data add karaycha asel tar append mode vapra.

11. close() Method

File open kelyanantar operation complete zalyavar close() method vaprun file close karavi.

Example

file = open("student.txt", "r")

print(file.read())

file.close()

File close kelyamule file resource release hoto. Closed file var read kiwa write operation karta yet nahi.

Warning: File close karayla visarlas tar resource unnecessarily open rahu shakto.

12. with open() Statement

Python madhye file handle karnyacha recommended way mhanje with open() statement.

with block complete zalyavar file automatically close hote.

Syntax

with open("filename.txt", "mode") as file:
    # File operations

Example

with open("student.txt", "r") as file:
    data = file.read()
    print(data)
Output: 
Name: Rohan
Course: Python
Best Practice: with open() vaparlyas manually close() call karanyachi garaj naste. Block samplyavar file automatically close hote.

13. File Paths

File open kartana file cha path dyava lagto. File current working directory madhye nasel tar path specify karava.

Relative Path

file = open("student.txt", "r")

Relative path current working directory chya reference ne file locate karto.

Absolute Path

file = open(
    r"C:\Users\Admin\Desktop\student.txt",
    "r"
)

Absolute path file cha complete location specify karto. Windows path madhye raw string r"..." vaparlyane backslash escape problems talta yetat.

Tip: Relative path vapartana Python cha current working directory konta aahe he lakshat thev.

14. File Handling Exceptions

File operations kartana suddha vegveglya exceptions yeu shaktat.

Exception Meaning
FileNotFoundError Requested file sapadli nahi.
PermissionError File access karnyachi permission nahi.
IsADirectoryError File aivaji directory open karnyacha prayatna kela.
UnicodeDecodeError Text decode kartana problem aali.

Handling FileNotFoundError

try:
    with open("unknown.txt", "r") as file:
        data = file.read()
        print(data)

except FileNotFoundError:
    print("File not found")
Output: 
File not found

16. Practical Example – Student Record System

Aapan student information text file madhye save karu ani nantar ti read karu.

Step 1 – Write Student Details

name = input("Enter student name: ")

print(data)

17. Common Beginner Mistakes

Mistake 1: Wrong File Mode

file = open("student.txt", "r")
file.write("Python")

Read mode madhye write operation karta yet nahi. Write karaycha asel tar w kiwa a mode vapra. 

file = open("student.txt", "a")
file.write("Python")
file.close()

Mistake 2: Forgetting close()

file = open("student.txt", "r")
print(file.read())

File manually close karaychi rahu shakte. with open() vaparlyas file automatically close hote.

Mistake 3: Using w Instead of a

file = open("student.txt", "w")
file.write("New Student")
file.close()

w mode existing content overwrite karto. Old content preserve karaycha asel tar a mode vapra.

Mistake 4: Wrong File Path

file = open("C:\new\test.txt", "r")

Windows path madhye backslash escape sequences cha problem yeu shakto. Raw string vapra. 

file = open(r"C:\new\test.txt", "r")

Mistake 5: Missing Newline

file.write("Python")
file.write("Django")

Donhi words ekach line var lihile jatil. Vegveglya lines sathi \n vapra. 

file.write("Python\n")
file.write("Django\n")
