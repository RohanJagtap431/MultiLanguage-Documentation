Python Comments

Python code madhye comments kase lihayche, comments cha upyog kay aahe ani code samjun ghenyasathi te kase madat kartat he ya lesson madhye shiku.

📘 Beginner Level ⏱️ 10–15 Minutes

1. What are Comments?

Comment mhanje code madhye lihileli ashi information ji programmer la code samjun ghenyasathi madat karte.

Python interpreter comment execute karat nahi. Mhanje comment lihilyamule program chya output madhye kahi badal hot nahi.

Simple Real-Life Example:

Samja tu vahimadhye ek maths example solve kelas. Tya example chya bajula "He addition che example aahe" ase lihiles. Hi note tula example samjun ghenyasathi madat karte.

Programming madhye asach kaam comments kartat.

2. Why Do We Use Comments?

Programming kartana code motha hot jato. Kahi divsanni swatacha code suddha samjun ghyayla kathin jau shakto.

Ashya veli comments mule code madhil logic samjun ghenyas madat hote.

Comments che uses:

  • Code kay kaam karto he explain karanyasathi.
  • Important information lihun thevanyasathi.
  • Complex logic samjun ghenyasathi.
  • Team madhil developers na code samjavnyasathi.
  • Testing kartana kahi code temporarily disable karanyasathi.

3. Single-Line Comments

Python madhye single-line comment lihinyasathi hash symbol (#) vapartat.

# nantar tyach line var lihilela text comment mhanun olakhla jato.

Syntax:

# This is a comment

Example:

# Display a welcome message
print("Welcome to Python")

Output:

Welcome to Python

Explanation:

  • # he comment symbol aahe.
  • Display a welcome message hi comment aahe.
  • print() function message display karte.

Python comment execute karat nahi. Mhanun output madhye fakt Welcome to Python disel.

4. Inline Comments

Code chya tyach line var code nantar comment lihili, tar tila inline comment mhantat.

Example:

age = 20  # Store the user's age
print(age)

Output:

20

Explanation:

  • age = 20 variable madhye 20 store karto.
  • # nantar cha text comment aahe.
  • print(age) variable madhil value display karto.
Tip:

Inline comments lahan ani relevant thev. Code madhye kay spashta aahe tyachi vinakaran punha explanation deu naye.

5. Multiple-Line Comments

Kahi vela aplyala ekapeksha jast lines madhye comment lihaychi aste.

Python madhye pratyek line chya suruvatila # vaprun multiple-line comment lihita yete.

Example:

# This program displays
# the student's name
# and the student's age

print("Rohan")
print(20)

Output:

Rohan
20

Ya example madhye pahilya three lines comments aahet. Tya execute hot nahit. Print statements execute hotat.

6. Triple Quotes and Comments

Python madhye triple quotes vaprun multi-line string lihita yete.

Triple quotes mhanje three single quotes (''') kiwa three double quotes (""").

Example:

message = """
Welcome to Python.
Learn programming step by step.
Keep practicing.
"""

print(message)

Output:

Welcome to Python.
Learn programming step by step.
Keep practicing.
Important Difference:

Triple quotes he comments nasun multi-line strings tayar karanyasathi vapartat.

Function, class kiwa module chya suruvatila lihilelya asha string la docstring mhantat.

Fakt code disable karanyasathi triple quotes vaprane hi standard comment technique nahi.

7. Temporarily Disable Code

Testing kartana kahi vela aplyala ekhadhi code line execute karaychi naste. Ashya veli tya line chya suruvatila # lavun tila comment karu shakto.

Example:

print("First Message")

# print("This line is disabled")

print("Third Message")

Output:

First Message
Third Message

Dusri line comment kelyamule ti execute hot nahi. Urlele don print statements normal execute hotat.

8. Good Practices for Writing Comments

  • Comments short ani clear lihava.
  • Code kay karto he avashyak asel tevha explain karava.
  • Comment ani actual code yanchyat sambandh asava.
  • Code change kelyanantar sambandhit comment suddha update karava.
  • Pratyek line sathi unnecessary comment lihू naye.
Professional Tip:

Changla code swatah barach kahi explain karto. Comments cha upyog code madhil important logic samjavnyasathi kara.

9. Common Beginner Mistakes

1. Hash Symbol Visarne

This is a comment

Solution: Comment chya suruvatila # vapra. 

# This is a comment

2. Comment Execute Hoil Asa Samajne

# print("Hello")

Ya line madhil print function execute honar nahi, karan sampurna line comment aahe.

3. Outdated Comment Thevane

Code madhil value badalali pan comment update keli nahi, tar dusrya programmer la chukichi information milu shakte.
