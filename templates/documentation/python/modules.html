Python Modules

Python modules cha use code vegveglya files madhye organize karnyasathi ani reusable banvnyasathi hoto.

📘 Level: Beginner ⏱️ Time: 40–50 Minutes

1. What are Modules?

Module mhanje ek Python file jyamadhye functions, variables ani classes lihilele astat.

Aapan dusrya Python file madhil code aaplya program madhye use karu shakto. Tyasathi import statement vapartat.

Example

Samja aaplyakade don Python files aahet: 

math_operations.py
main.py

math_operations.py madhye function lihun te main.py madhye import karun use karta yete.

Samjun ghe: Module mhanje code lihileli Python file. Tya file madhil code dusrya file madhye reuse karta yeto.

2. Advantages of Modules

  • Code Reusability: Ekach code vegveglya programs madhye use karta yeto.
  • Organization: Code vegveglya files madhye divide karta yeto.
  • Easy Maintenance: Code update ani manage karne sope hote.
  • Less Repetition: Same function punha lihava lagat nahi.
  • Easy Testing: Specific module separately test karta yeto.
Important: Large applications madhye modules mule project cha code organized ani manageable rahto.

3. Types of Python Modules

Python madhye modules che kahi important types aahet:

Type Meaning
Built-in Modules Python sobat already available aslele modules.
Third-party Modules External packages madhun install kele janare modules.
User-defined Modules Programmer swatah create karto te modules.

4. import Statement

Dusra module aaplya Python program madhye use karnyasathi import keyword vapartat.

Syntax

import module_name

Example – math Module

import math

print(math.sqrt(25))
print(math.pi)
Output: 
5.0
3.141592653589793

Yethe math module import kela aahe. sqrt() ani pi use karnyasathi math dot notation vaparla aahe.

5. Import Specific Functions

Purn module import karnyapeksha tyatil specific function kiwa variable import karta yeto.

Syntax

from module_name import function_name

Example

from math import sqrt

print(sqrt(36))
Output: 
6.0

Ya example madhye fakt sqrt function import kela aahe. Mhanun function call kartana math.sqrt() lihinyachi garaj nahi.

Import Multiple Functions

from math import sqrt, factorial

print(sqrt(49))
print(factorial(5))
Output: 
7.0
120

6. Import All Functions

Module madhil available public names import karnyasathi star symbol (*) vaparta yeto.

Example

from math import *

print(sqrt(64))
print(factorial(4))
Output: 
8.0
24
Note: from module import * he mothya projects madhye talave. Karan konti names kutheun aali he samajne kathin hou shakte. Specific functions import karne jast changle.

7. as Keyword (Alias)

Module kiwa imported function la short name denyasathi as keyword vapartat. Ya navala alias mhantat.

Module Alias Example

import math as m

print(m.sqrt(81))
print(m.pi)
Output: 
9.0
3.141592653589793

Function Alias Example

from math import factorial as fact

print(fact(5))
Output: 
120

9. Python random Module

random ha built-in module aahe. Random values generate karnyasathi tyacha use hoto.

Important Functions

Function Use
random.random()0.0 te 1.0 madhil random float deto.
random.randint()Inclusive range madhil random integer deto.
random.choice()Sequence madhun ek random item select karto.
random.shuffle()Mutable sequence madhil items shuffle karto.

Example – Random Number

import random

number = random.randint(1, 10)

print(number)
Possible Output: 
7
Output pratyek run madhye badlu shakto.

Example – Random Choice

import random

colors = ["Red", "Blue", "Green", "Yellow"]

result = random.choice(colors)

print(result)
Possible Output: 
Green

Example – Shuffle List

import random

numbers = [1, 2, 3, 4, 5]

random.shuffle(numbers)

print(numbers)
Possible Output: 
[3, 1, 5, 2, 4]
Important: randint(a, b) madhye donhi boundary values include hotat. shuffle() original list madhyech changes karto ani None return karto.

10. Python datetime Module

datetime module cha use date ani time handle karnyasathi hoto.

Example – Current Date and Time

import datetime

current = datetime.datetime.now()

print(current)
Possible Output: 
2026-11-15 10:30:25.123456
Actual output tumchya system chya date ani time nusar asel.

Example – Current Date

import datetime

today = datetime.date.today()

print(today)
Possible Output: 
2026-11-15

Example – Formatting Date

import datetime

today = datetime.date.today()

formatted = today.strftime("%d-%m-%Y")

print(formatted)
Possible Output: 
15-11-2026

Important Format Codes

Code Meaning

%mMonth

%HHour (24-hour format)
%MMinute
%SSecond

11. Creating Your Own Module

Aapan swatah Python module create karu shakto. Tyasathi ek Python file create karun tyat functions kiwa variables lihayche.

Step 1 – Create a Python File

Ek folder create kar ani tyat don files banav: 

my_project/
│
├── mymodule.py
└── main.py

Step 2 – Write Code in mymodule.py

def greet(name):
    print("Hello", name)


def add(a, b):
    return a + b


college = "Computer Science"

Step 3 – Import Module in main.py

import mymodule

mymodule.greet("Rohan")

result = mymodule.add(10, 20)

print(result)
print(mymodule.college)
Output: 
Hello Rohan
30
Computer Science
Samjun ghe: mymodule.py madhil function ani variable aapan main.py madhye import karun use kele. Ha User-defined Module aahe.
Important: Donhi files same folder madhye aslyamule ha simple import work karto. Dusrya folder madhil modules sathi package ani import path che rules samjun ghyave lagtat.

12. Difference Between Module and Package

Module Package
Ek Python file aste. Related modules organize karnara structure asto.
Example: math_operations.py Example: mypackage/
Functions, variables ani classes astat. Multiple modules contain karu shakto.

Example Package Structure

mypackage/
│
├── __init__.py
├── calculations.py
└── messages.py

Package mule related Python modules ekach folder madhye organize karta yetat.

14. Common Beginner Mistakes

Mistake 1: Forgetting to Import

print(math.sqrt(25))

math import kela nasel tar NameError yeu shakto. 

import math

print(math.sqrt(25))

Mistake 2: Wrong Function Name

import math

print(math.sqroot(25))

math module madhye sqroot() navacha function nahi. Correct function sqrt() aahe. 

print(math.sqrt(25))

Mistake 3: File Name Conflict

math.py
random.py

Swatahchya Python file la built-in module che same nav dilyas import conflict hou shakto.

Swatahchya files sathi meaningful vegli nave vapra. Udaharanarth, my_math_tools.py.

Mistake 4: Wrong Module Location

Import karaychi file Python la expected location madhye sapadli nahi tar ModuleNotFoundError yeu shakto.

File location, folder structure ani import path check kar.

Mistake 5: Using pip for Built-in Modules

pip install math

math ha Python cha built-in module aahe. Tyasathi pip install karaychi garaj nahi. 

import math

17. Practical Task – Random Number Guessing

Computer ek random number select karel. User ne to number guess karaycha aahe. 

import random

secret_number = random.randint(1, 10)

guess = int(input("Guess a number between 1 and 10: "))

if guess == secret_number:
    print("Correct Guess!")
else:
    print("Wrong Guess!")
    print("Correct Number:", secret_number)
Possible Output: 
Guess a number between 1 and 10: 5
Wrong Guess!
Correct Number: 8
Practice Challenge: Ya program madhye user la 3 attempts de. Number guess zala tar game stop kar ani success message display kar.
