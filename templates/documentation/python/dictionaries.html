Python Dictionaries

Dictionary cha use data Key-Value pairs madhye store karnyasathi hoto. User details ani structured data manage karnyasathi Dictionary useful aahe.

📘 Level: Beginner ⏱️ Time: 35–45 Minutes

1. What is a Dictionary?

Python madhye Dictionary ha collection data type aahe. Tyat data Key-Value pairs madhye store kela jato.

Pratyek Key la ek Value assign keli jate. Key cha use karun aapan tyachi Value access karu shakto. 

student = {
    "name": "Rohan",
    "age": 20,
    "course": "Computer Science"
}

print(student)
Output: 
{'name': 'Rohan', 'age': 20, 'course': 'Computer Science'}
Important: Dictionary create karnyasathi curly brackets {} vapartat. Pratyek Key ani Value madhye colon : vapartat.

2. Features of Dictionary

  • Key-Value Pairs: Data Key ani Value format madhye store hoto.
  • Ordered: Python 3.7 pasun insertion order maintain hoto.
  • Mutable: Values add, update ani delete karta yetat.
  • Unique Keys: Keys unique astat. Duplicate Key dilyas latest Value rahte.
  • Different Data Types: Values madhye vegvegale data types store karta yetat.
student = {
    "name": "Rohan",
    "age": 20,
    "marks": 85.5,
    "is_passed": True
}

print(student)
Example Output: 
{'name': 'Rohan', 'age': 20, 'marks': 85.5, 'is_passed': True}
Important: Dictionary keys immutable ani hashable values asne avashyak aahe. Strings, numbers ani tuples (tyatil values hashable aslyas) Keys mhanun vaparta yetat.

3. Creating a Dictionary

Example 1: Student Dictionary

student = {
    "name": "Rohan",
    "age": 20,
    "course": "BSc Computer Science"
}

print(student)
Output: 
{'name': 'Rohan', 'age': 20, 'course': 'BSc Computer Science'}

Example 2: Empty Dictionary

data = {}

print(data)
print(type(data))
Output: 
{}
<class 'dict'>

Example 3: Using dict()

Dictionary create karnyasathi dict() function suddha vaparta yete. 

student = dict(name="Rohan", age=20, course="Python")

print(student)
Output: 
{'name': 'Rohan', 'age': 20, 'course': 'Python'}

4. Accessing Dictionary Values

Dictionary madhil Value access karnyasathi Key vapartat. 

student = {
    "name": "Rohan",
    "age": 20,
    "course": "Python"
}

print(student["name"])
print(student["age"])
print(student["course"])
Output: 
Rohan
20
Python
Note: Dictionary madhye non-existing Key square brackets madhye access kelyas KeyError yeto.

5. get() Method

Dictionary madhil Value safely access karnyasathi get() method vapartat. 

student = {
    "name": "Rohan",
    "age": 20
}

print(student.get("name"))
print(student.get("course"))
Output: 
Rohan
None

Key available nasel tar get() default value mhanun None return karto.

Providing a Default Value

student = {
    "name": "Rohan",
    "age": 20
}

print(student.get("course", "Not Available"))
Output: 
Not Available
Difference: student["course"] Key nasel tar KeyError deto. student.get("course") Key nasel tar None return karto.

6. Adding New Items

Navin Key-Value pair add karnyasathi Dictionary madhye new Key assign karu shakto. 

student = {
    "name": "Rohan",
    "age": 20
}

student["course"] = "Python"

print(student)
Output: 
{'name': 'Rohan', 'age': 20, 'course': 'Python'}

Using update()

Ek kiwa anek Key-Value pairs add kiwa update karnyasathi update() vapartat. 

student = {
    "name": "Rohan",
    "age": 20
}

student.update({
    "course": "Python",
    "city": "Kolhapur"
})

print(student)
Output: 
{'name': 'Rohan', 'age': 20, 'course': 'Python', 'city': 'Kolhapur'}

7. Updating Dictionary Values

Existing Key la navin Value assign karun aapan Value update karu shakto. 

student = {
    "name": "Rohan",
    "age": 20,
    "course": "Python"
}

student["age"] = 21

print(student)
Output: 
{'name': 'Rohan', 'age': 21, 'course': 'Python'}

update() method vaprun suddha existing Value update karta yete. 

student = {
    "name": "Rohan",
    "age": 20
}

student.update({"age": 21})

print(student)
Output: 
{'name': 'Rohan', 'age': 21}

8. Removing Dictionary Items

pop()

Specific Key remove karnyasathi pop() vapartat. Ha removed Value return karto. 

student = {
    "name": "Rohan",
    "age": 20,
    "course": "Python"
}

removed = student.pop("age")

print(removed)
print(student)
Output: 
20
{'name': 'Rohan', 'course': 'Python'}

popitem()

Dictionary madhil shevatcha inserted Key-Value pair remove karnyasathi popitem() vapartat. 

student = {
    "name": "Rohan",
    "age": 20,
    "course": "Python"
}

removed = student.popitem()

print(removed)
print(student)
Output: 
('course', 'Python')
{'name': 'Rohan', 'age': 20}

del Keyword

Specific Key delete karnyasathi del vapartat. 

student = {
    "name": "Rohan",
    "age": 20
}

del student["age"]

print(student)
Output: 
{'name': 'Rohan'}

clear()

Dictionary madhil sarva Key-Value pairs remove karnyasathi clear() vapartat. 

student = {
    "name": "Rohan",
    "age": 20
}

student.clear()

print(student)
Output: 
{}

9. keys() Method

Dictionary madhil sarva Keys milavnyasathi keys() method vapartat. 

student = {
    "name": "Rohan",
    "age": 20,
    "course": "Python"
}

print(student.keys())
Output: 
dict_keys(['name', 'age', 'course'])

Keys var loop suddha chalvu shakto. 

for key in student.keys():
    print(key)
Output: 
name
age
course

10. values() Method

Dictionary madhil sarva Values milavnyasathi values() method vapartat. 

student = {
    "name": "Rohan",
    "age": 20,
    "course": "Python"
}

print(student.values())
Output: 
dict_values(['Rohan', 20, 'Python'])

Values var loop chalvnyasathi:

for value in student.values():
    print(value)
Output: 
Rohan
20
Python

11. items() Method

Dictionary madhil Key ani Value donhi ekatra milavnyasathi items() method vapartat. 

student = {
    "name": "Rohan",
    "age": 20,
    "course": "Python"
}

print(student.items())
Output: 
dict_items([('name', 'Rohan'), ('age', 20), ('course', 'Python')])

Using Loop

for key, value in student.items():
    print(key, ":", value)
Output: 
name : Rohan
age : 20
course : Python

12. Looping Through a Dictionary

Dictionary madhil data access karnyasathi for loop vapru shakto.

Loop Through Keys

student = {
    "name": "Rohan",
    "age": 20
}

for key in student:
    print(key)
Output: 
name
age

Loop Through Values

for value in student.values():
    print(value)
Output: 
Rohan
20

Loop Through Keys and Values

for key, value in student.items():
    print(key, value)
Output: 
name Rohan
age 20

13. Nested Dictionaries

Ek Dictionary chya aat dusri Dictionary store keli asel tar tila Nested Dictionary mhantat. 

students = {
    "student1": {
        "name": "Rohan",
        "age": 20
    },
    "student2": {
        "name": "Amit",
        "age": 21
    }
}

print(students)

Accessing Nested Values

print(students["student1"]["name"])
print(students["student2"]["age"])
Output: 
Rohan
21

14. copy() Method

Dictionary chi shallow copy tayar karnyasathi copy() method vapartat. 

student = {
    "name": "Rohan",
    "age": 20
}

new_student = student.copy()

new_student["age"] = 21

print(student)
print(new_student)
Output: 
{'name': 'Rohan', 'age': 20}
{'name': 'Rohan', 'age': 21}
Note: copy() shallow copy banavto. Nested mutable objects aslyas tyanchya changes cha effect donhi dictionaries madhye disu shakto.

15. fromkeys() Method

Dilelya Keys pasun navin Dictionary create karnyasathi fromkeys() vapartat. 

keys = ["name", "age", "course"]

student = dict.fromkeys(keys, "Not Available")

print(student)
Output: 
{'name': 'Not Available', 'age': 'Not Available', 'course': 'Not Available'}

16. Practical Example – Student Marks

Student chi nave ani tyanche marks Dictionary madhye store kar. Nantar specific student che marks access kar.

print("Rohan Marks:", marks["Rohan"])

17. Common Beginner Mistakes

Mistake 1: Missing Colon

student = {
    "name" "Rohan",
    "age": 20
}

Key ani Value madhye colon dene avashyak aahe. 

student = {
    "name": "Rohan",
    "age": 20
}

Mistake 2: Wrong Key Access

student = {"name": "Rohan"}

print(student["age"])

age Key available nahi, mhanun KeyError yeto. get() vaprun safely access karu shakto. 

print(student.get("age", "Not Available"))

Mistake 3: Duplicate Keys

student = {
    "name": "Rohan",
    "name": "Amit"
}

print(student)

Duplicate Keys allowed nahit. Latest Value rahte.

Mistake 4: Wrong Dictionary Syntax

student = {
    "name" = "Rohan"
}

Dictionary madhye assignment operator = nahi, tar colon : vapartat.

20. Practical Task – User Profile Manager

User che name, email ani city Dictionary madhye store kar. Nantar city update kar ani complete profile display kar. 

user = {
    "name": "Rohan",
    "email": "rohan@example.com",
    "city": "Kolhapur"
}

user["city"] = "Pune"

print("User Profile:")

for key, value in user.items():
    print(key, ":", value)
Example Output: 
User Profile:
name : Rohan
email : rohan@example.com
city : Pune

Ya practical madhye Dictionary creation, updating ani items() vaprun looping kele aahe.
