05. Python Variables

Python madhye data store karayla Variables kase use kartat he ya lesson madhye shikuya.

📘 Beginner Level ⏱️ 15-20 Minutes

1. What is a Variable?

Variable mhanje computer memory madhye data store karanyasathi dilele ek name.

Samja tujhya table var ek box aahe. Tya box madhye tu kahi vastu thevto ani box la ek label lavto. Nantar tula tya label varun box madhil vastu olakhata yete.

Python madhye suddha variable asech kam karto. Variable la ek name deto ani tyat value store karto.

Simple Definition: Variable is a name used to store a value in a program.
Example
name = "Rohan"
age = 20

print(name)
print(age)
Output: 
Rohan
20

Ya example madhye name ani age he don variables aahet.

2. Why Do We Use Variables?

Variables mule program madhil data store karne, access karne ani update karne sope hote.

Variables vaparnyache kahi fayde:

  • Data store karta yeto.
  • Stored data punha use karta yeto.
  • Program samjayla sopa hoto.
  • Data madhye badal karne sope hote.
Example
price = 500
quantity = 3

total = price * quantity

print(total)
Output: 
1500

Ithe price ani quantity variables madhye values store aahet. Tyanchya madatine total calculate kela aahe.

3. Creating a Variable

Python madhye variable create karanyasathi vegala declaration keyword lihinyachi garaj naste.

Variable name lihun tyala = operator ne value assign keli ki variable create hoto.

Syntax: 
variable_name = value
Example
name = "Rohan"
age = 20
city = "Kolhapur"
marks = 85.5

print(name)
print(age)
print(city)
print(marks)
Output: 
Rohan
20
Kolhapur
85.5

4. Understanding Variable Assignment

Variable assignment mhanje variable la value dene. Python madhye = ha assignment operator aahe.

Example
age = 20

Ya statement madhye:

  • age – Variable name
  • = – Assignment operator
  • 20 – Value
Important: = ha value assign karanyasathi vapartat. Don values equal aahet ka he check karanyasathi == vapartat.

5. Printing Variables

Variable madhil value screen var display karanyasathi print() function vapartat.

Example
name = "Rohan"
course = "BSc Computer Science"

print(name)
print(course)
Output: 
Rohan
BSc Computer Science
Tip: Variable print kartana tyache name quotes madhye lihayche nahi. Quotes madhye lihilyas variable name text mhanun print hoil.

6. Changing Variable Values

Python madhye ekda variable create kelyanantar tyachi value punha change karta yete.

Example
age = 19
print(age)

age = 20
print(age)
Output: 
19
20

Suruvatila age madhye 19 store hote. Nantar navin value 20 assign kelyamule age chi value change zali.

7. Assigning Multiple Variables

Python madhye ekach line madhye anek variables create karun tyanna vegveglya values assign karta yetat.

Example 1: Multiple Variables

a, b, c = 10, 20, 30

print(a)
print(b)
print(c)
Output: 
10
20
30

Example 2: Same Value to Multiple Variables

a = b = c = 100

print(a)
print(b)
print(c)
Output: 
100
100
100

8. Variable Naming Rules

Python madhye variable create kartana kahi rules follow karave lagtat.

  • Variable name letter kiwa underscore (_) ne suru zala pahije.
  • Variable name number ne suru hou shakat nahi.
  • Variable name madhye spaces allowed nahit.
  • Letters, numbers ani underscore vaparta yetat.
  • Python keywords variable name mhanun vaparta yet nahit.
  • Variable names case-sensitive astat.

Valid Variable Names

name = "Rohan"
age = 20
student_name = "Rahul"
_marks = 85
number1 = 100

Invalid Variable Names

1name = "Rohan"       # Number ne start
student name = "Raj" # Space allowed nahi
class = 10           # class is a keyword

9. Case-Sensitive Variables

Python madhye uppercase ani lowercase letters vegvegale samajle jatat.

Example
name = "Rohan"
Name = "Rahul"

print(name)
print(Name)
Output: 
Rohan
Rahul

Ithe name ani Name he don vegvegale variables aahet.

10. Variable Naming Convention

Variable names meaningful asavet. Name vachun variable madhye konta data store aahe he samajle pahije.

Python madhye variables sathi generally snake_case naming style vapartat.

Good Naming
student_name = "Rohan"
total_marks = 450
mobile_number = 9876543210
Avoid These Names
x = "Rohan"
a = 450
m = 9876543210
Tip: शक्यतो variable la meaningful name dya. Yamule code vachayla ani maintain karayla sopa hoto.

11. Dynamic Typing in Python

Python hi dynamically typed language aahe. Mhanje variable create kartana tyacha data type vegala declare karava lagat nahi.

Example
data = 100
print(data)

data = "Python"
print(data)
Output: 
100
Python

Suruvatila data madhye integer value hoti. Nantar tyach variable la string value assign keli.

Remember: Python madhye variable la vegveglya data types chya values assign karta yetat. Data type ha value cha asto.

12. Common Beginner Mistakes

Mistake 1: Variable name quotes madhye lihine

name = "Rohan"
print("name")

Output: name

Correct: print(name) lihilyas variable madhil value print hoil.

Mistake 2: Variable create karanyapurvi use karne

print(age)
age = 20

Correct: Pahile variable create kara ani nantar tyacha use kara.

Mistake 3: Invalid variable name

2name = "Rohan"

Correct: name2 = "Rohan"
