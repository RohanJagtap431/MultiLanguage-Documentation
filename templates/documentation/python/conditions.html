Python Conditions

Conditions cha use program madhye decision ghenyasathi hoto. Condition True kiwa False aahe yavarun code execute hoto.

📘 Level: Beginner ⏱️ Time: 35–45 Minutes

1. What are Conditions?

Python madhye Conditions cha use specific condition check karun decision ghenyasathi hoto.

Udaharanarth, student che marks 35 kiwa tyapeksha jast astil tar student Pass, nahitar Fail. 

marks = 60

if marks >= 35:
    print("Pass")
Output: 
Pass
Samjun ghe: marks >= 35 hi condition check hote. Condition True aslyamule print() execute hote.

2. Types of Conditional Statements

Python madhye mainly khalil conditional statements vapartat:

Statement Use
if Condition True asel tevha code execute karto.
if-else True ani False sathi vegvegla code execute karto.
if-elif-else Anek conditions check karto.
Nested if Ek if statement chya aat dusra if vaparto.

3. if Statement

if statement cha use ek condition check karnyasathi hoto.

Condition True asel tar if chya aatil code execute hoto. False asel tar to code skip hoto.

Syntax

if condition:
    # Code to execute

Example

age = 20

if age >= 18:
    print("You can vote")
Output: 
You can vote

Condition False Example

age = 15

if age >= 18:
    print("You can vote")

print("Program completed")
Output: 
Program completed
Important: if nantar colon : dene avashyak aahe. if chya aatil code la indentation (usually 4 spaces) dene suddha avashyak aahe.

4. if-else Statement

if-else cha use don possible conditions madhun ek result select karnyasathi hoto.

Condition True asel tar if block execute hoto. Condition False asel tar else block execute hoto.

Syntax

if condition:
    # True code
else:
    # False code

Example – Pass or Fail

marks = 30

if marks >= 35:
    print("Pass")
else:
    print("Fail")
Output: 
Fail

Example – Even or Odd

number = 8

if number % 2 == 0:
    print("Even Number")
else:
    print("Odd Number")
Output: 
Even Number
Samjun ghe: % ha modulus operator aahe. Number la 2 ne divide kelyavar remainder 0 asel tar number Even asto, nahitar Odd asto.

5. if-elif-else Statement

Aplyala ekapeksha jast conditions check karaychya astil tar elif vapartat.

Python conditions ek-ek karun check karto. Pahili True condition sapadlyavar ticha block execute hoto ani urlelya conditions skip hotat.

Syntax

if condition1:
    # Code 1
elif condition2:
    # Code 2
elif condition3:
    # Code 3
else:
    # Default code

Example – Grade System

marks = 85

if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
elif marks >= 35:
    print("Pass")
else:
    print("Fail")
Output: 
Grade B

Another Example – Positive, Negative or Zero

number = -5

if number > 0:
    print("Positive")
elif number < 0:
    print("Negative")
else:
    print("Zero")
Output: 
Negative
Tip: if-elif-else madhye else optional aahe. Sarva conditions False astil ani else available asel tar else execute hoto.

6. Nested if Statement

Ek if statement chya aat dusra if statement lihila tar tyala Nested if mhantat.

Pahili condition True zalyanantar dusri condition check karaychi asel tar Nested if useful aahe.

Syntax

if condition1:
    if condition2:
        # Code to execute

Example – Voting Eligibility

age = 20
has_voter_id = True

if age >= 18:
    if has_voter_id:
        print("You can vote")
    else:
        print("Voter ID required")
else:
    print("You are too young")
Output: 
You can vote
Important: Nested if madhye indentation khup important aahe. Inner if cha code outer if peksha adhik indent karava lagto.

7. Comparison Operators in Conditions

Conditions madhye don values compare karnyasathi Comparison Operators vapartat.

Operator Meaning Example Result
==Equal10 == 10True
!=Not Equal10 != 5True
>Greater Than10 > 5True
<Less Than5 < 10True
>=Greater or Equal10 >= 10True
<=Less or Equal5 <= 10True

Example

age = 20

if age == 20:
    print("Age is 20")

if age != 18:
    print("Age is not 18")
Output: 
Age is 20
Age is not 18

8. Logical Operators in Conditions

Ekach condition madhye anek conditions check karnyasathi Logical Operators vapartat.

and Operator

Donhi conditions True astil tarch result True milto. 

age = 20
has_id = True

if age >= 18 and has_id:
    print("Entry Allowed")
else:
    print("Entry Denied")
Output: 
Entry Allowed

or Operator

Don paiki kontihi ek condition True asel tar result True milto. 

day = "Sunday"

if day == "Saturday" or day == "Sunday":
    print("Holiday")
else:
    print("Working Day")
Output: 
Holiday

not Operator

not operator condition cha result ulta karto. True la False ani False la True karto. 

is_raining = False

if not is_raining:
    print("You can go outside")
Output: 
You can go outside
Operator Meaning
andAll conditions True pahijet.
orAt least one condition True pahije.
notCondition cha result reverse karto.

9. Multiple Conditions

Aapan ekach if statement madhye multiple conditions combine karu shakto.

Example – Age and Marks

age = 20
marks = 80

if age >= 18 and marks >= 35:
    print("Eligible")
else:
    print("Not Eligible")
Output: 
Eligible

Example – Number Range

number = 15

if number >= 10 and number <= 20:
    print("Number is between 10 and 20")
else:
    print("Number is outside the range")
Output: 
Number is between 10 and 20
Tip: Python madhye range check karnyasathi 10 <= number <= 20 ase suddha lihita yete.

10. Short-Hand if-else (Ternary Operator)

Simple if-else condition ekach line madhye lihaychi asel tar conditional expression vaparta yete.

Syntax

value_if_true if condition else value_if_false

Example

age = 20

result = "Adult" if age >= 18 else "Minor"

print(result)
Output: 
Adult
Note: Ternary expression simple conditions sathi useful aahe. Complex conditions sathi normal if-else vaprane changle.

11. Truthy and Falsy Values

Python madhye kahi values condition madhye directly vaparlya tar False samajlya jatat, tar bahutek non-empty values True samajlya jatat.

Falsy Values

  • False
  • None
  • 0 ani 0.0
  • Empty String ""
  • Empty List []
  • Empty Tuple ()
  • Empty Dictionary {}
  • Empty Set set()

Example – Empty List

students = []

if students:
    print("Students Available")
else:
    print("No Students Found")
Output: 
No Students Found

Example – Non-empty List

students = ["Rohan", "Amit"]

if students:
    print("Students Available")
else:
    print("No Students Found")
Output: 
Students Available
Important: Empty collection False aste. Non-empty collection True aste. He check kartana len() vaparnyachi garaj naste.

12. pass Statement

pass statement cha use empty code block temporary thevnyasathi hoto. 

age = 20

if age >= 18:
    pass

print("Program completed")
Output: 
Program completed

pass mule kontihi action hot nahi. To fakt empty block mule yenari syntax error talto.

13. Common Beginner Mistakes

Mistake 1: Colon Missing

age = 20

if age >= 18
    print("Adult")

if condition nantar colon dene avashyak aahe. 

if age >= 18:
    print("Adult")

Mistake 2: Wrong Indentation

age = 20

if age >= 18:
print("Adult")

if chya aatil code la indentation dene avashyak aahe. 

if age >= 18:
    print("Adult")

Mistake 3: Using = Instead of ==

number = 10

if number = 10:
    print("Equal")

Comparison sathi == vapartat. = ha assignment operator aahe. 

if number == 10:
    print("Equal")

Mistake 4: Wrong Condition Order

marks = 90

if marks >= 35:
    print("Pass")
elif marks >= 90:
    print("Grade A")

90 marks asun suddha pahili condition True hote, tyamule Grade A block execute hot nahi. More specific condition aadhi check kar. 

if marks >= 90:
    print("Grade A")
elif marks >= 35:
    print("Pass")
else:
    print("Fail")

16. Practical Task – Simple Login System

Username ani password check karun simple login system tayar kar. Donhi correct astil tar Login Successful print kar. 

username = "rohan"
password = "python123"

if username == "rohan":
    if password == "python123":
        print("Login Successful")
    else:
        print("Wrong Password")
else:
    print("User Not Found")
Output: 
Login Successful

Ya practical madhye if, nested if ani comparison operators vaprale aahet.
