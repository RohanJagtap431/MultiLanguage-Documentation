Python Polymorphism

Same method kiwa operation vegveglya objects sobat vegveglya prakare kase work karte te shikuya.

📘 Level: Beginner ⏱️ Time: 45–55 Minutes

1. What is Polymorphism?

Polymorphism ha Object-Oriented Programming madhil ek important concept aahe.

Polymorphism ya word cha meaning "Many Forms" asa hoto. Yacha arth ekach method kiwa operation vegveglya objects sobat vegveglya prakare work karu shakto.

Real-Life Example

Samaj ek vyakti aahe. To vegveglya paristhitimadhye vegvegli actions karu shakto:

  • Teacher classroom madhye teach karto.
  • Doctor hospital madhye treat karto.
  • Developer computer var code karto.

Vyakti vegveglya roles nusar vegvegli functionality perform karto. Programming madhye suddha Polymorphism mule asach behavior milto.

Simple Definition: One interface, different implementations. Mhanje same method call, pan object nusar different behavior.

2. Why Use Polymorphism?

  • Same interface vaprun vegveglya objects sobat work karta yete.
  • Code flexible ani reusable banto.
  • New classes add karne sope hote.
  • Large applications maintain karne sope hote.
  • Different objects sathi common code lihita yeto.

3. Basic Polymorphism Example

Khalil example madhye Dog ani Cat ya donhi classes madhye sound() method aahe. Pan donhi methods vegvegla output detat.

Example

class Dog:

    def sound(self):
        print("Dog barks")


class Cat:

    def sound(self):
        print("Cat meows")


dog = Dog()
cat = Cat()

dog.sound()
cat.sound()
Output: 
Dog barks
Cat meows

Donhi objects madhye same method name sound() aahe. Pan object nusar output vegvegla milto.

4. Types of Polymorphism

Python madhye Polymorphism samjun ghenyasathi he important concepts aahet:

Concept Meaning
Method Overriding Child class parent method chi navin implementation dete.
Method Overloading Same method name vegveglya parameters sobat use karne. Python madhye traditional signature-based overloading direct support nahi.
Operator Overloading Operators objects sobat vegveglya prakare work kartat.
Duck Typing Object cha type na baghta tyachyakade required method aahe ka te baghne.

5. Method Overriding

Parent class madhil method child class madhye same name ne punha define karun navin implementation dene mhanje Method Overriding.

Example

class Animal:

    def sound(self):
        print("Animal makes sound")


class Dog(Animal):

    def sound(self):
        print("Dog barks")


class Cat(Animal):

    def sound(self):
        print("Cat meows")


dog = Dog()
cat = Cat()

dog.sound()
cat.sound()
Output: 
Dog barks
Cat meows

Animal class madhye sound() method aahe. Dog ani Cat ya child classes ne ti method override keli.

Important: Method Overriding sathi inheritance lagte. Child class parent class chi method navin paddhatine implement karte.

6. Method Overriding with super()

Child class madhye parent method override kartana parent chi original functionality suddha use karaychi asel tar super() use karu shakto.

Example

class Animal:

    def sound(self):
        print("Animal makes sound")


class Dog(Animal):

    def sound(self):
        super().sound()
        print("Dog barks")


dog = Dog()
dog.sound()
Output: 
Animal makes sound
Dog barks

super().sound() mule parent class madhil sound() method call hote. Tyachyanantar child class cha code execute hoto.

7. Method Overloading

Method Overloading mhanje same method name vegveglya number kiwa type chya parameters sobat use karne.

Python Note: Python traditional Java/C++ style method overloading by function signature direct support karat nahi. Same class madhye same name chi dusri definition lihilyas ti pahili definition replace karte.

Incorrect Expectation

class Calculator:

    def add(self, a, b):
        return a + b

    def add(self, a, b, c):
        return a + b + c


obj = Calculator()

print(obj.add(10, 20))
Result:

Ha code TypeError deil. Karan dusrya add() definition ne pahili definition replace keli aahe ani ti 3 arguments expect karte.

Python Madhye Default Arguments Vaprun

class Calculator:

    def add(self, a, b, c=0):
        return a + b + c


obj = Calculator()

print(obj.add(10, 20))
print(obj.add(10, 20, 30))
Output: 
30
60

c la default value 0 dili aahe. Tyamule don kiwa tin values pass karu shakto.

*args Vaprun

class Calculator:

    def add(self, *numbers):
        return sum(numbers)


obj = Calculator()

print(obj.add(10, 20))
print(obj.add(10, 20, 30))
print(obj.add(10, 20, 30, 40))
Output: 
30
60
100

*args mule method la vegveglya sankhyene positional arguments pass karta yetat.

8. Operator Overloading

Python madhye operators vegveglya data types kiwa objects sobat vegveglya paddhatine work karu shaktat.

Simple Example

print(10 + 20)
print("Hello " + "Python")
print([10, 20] + [30, 40])
Output: 
30
Hello Python
[10, 20, 30, 40]

+ operator integer values add karto, strings join karto ani lists combine karto.

Magic Methods

Python madhye operators cha behavior special methods ne define kela jau shakto. Tyanna Magic Methods kiwa Dunder Methods mhantat.

Operator Special Method
+__add__()
-__sub__()
*__mul__()
/__truediv__()
==__eq__()
<__lt__()
>__gt__()

Custom Operator Overloading Example

class Number:

    def __init__(self, value):
        self.value = value

    def __add__(self, other):
        return self.value + other.value


num1 = Number(10)
num2 = Number(20)

result = num1 + num2

print(result)
Output: 
30

num1 + num2 lihilyavar Python __add__() method call karto. Ya method madhye donhi objects chya values add hotat.

9. Duck Typing

Duck Typing ha Python madhil important concept aahe. Yat object cha exact class type check karnyapeksha object required method support karto ka te pahile jate.

Simple idea: "If it behaves like a duck, it can be treated like a duck."

Example

class Dog:

    def sound(self):
        print("Dog barks")


class Cat:

    def sound(self):
        print("Cat meows")


def make_sound(animal):
    animal.sound()


dog = Dog()
cat = Cat()

make_sound(dog)
make_sound(cat)
Output: 
Dog barks
Cat meows

make_sound() function la Dog kiwa Cat class mahit asnyachi garaj nahi. Fakt object madhye sound() method asne garjeche aahe.

Remember: Duck Typing madhye object kay aahe yapeksha to kay karu shakto he important aste.

10. Polymorphism with Functions

Python madhil built-in functions vegveglya objects sobat work karu shaktat.

Example: len()

print(len("Python"))
print(len([10, 20, 30]))
print(len({"name": "Rohan", "age": 20}))
Output: 
6
3
2

len() function string chi length, list madhil elements ani dictionary madhil keys chi sankhya return karte.

Example: sum()

print(sum([10, 20, 30]))
print(sum((5, 10, 15)))
Output: 
60
30

11. Polymorphism with Inheritance

Parent class madhye common method define karun child classes madhye vegvegli implementation deta yete.

Example: Payment System

class Payment:

    def pay(self, amount):
        print("Processing payment:", amount)


class UpiPayment(Payment):

    def pay(self, amount):
        print("Paid using UPI:", amount)


class CardPayment(Payment):

    def pay(self, amount):
        print("Paid using Card:", amount)


class CashPayment(Payment):

    def pay(self, amount):
        print("Paid using Cash:", amount)


payments = [
    UpiPayment(),
    CardPayment(),
    CashPayment()
]


for payment in payments:
    payment.pay(500)
Output: 
Paid using UPI: 500
Paid using Card: 500
Paid using Cash: 500

Pratyek payment object kade pay() method aahe. Pan payment type nusar tyache behavior change hote.

Practical Use: E-commerce applications madhye UPI, Card ani Cash payments handle karnyasathi asha design cha use hou shakto.

12. Method Overriding vs Method Overloading

Method Overriding Method Overloading
Inheritance required aste. Inheritance required nahi.
Parent method child class madhye redefine hote. Same name vegveglya parameter combinations sobat use hote.
Python support karte. Traditional signature-based form direct support nahi.
Child implementation execute hote. Default arguments kiwa *args ne similar behavior banavta yete.

13. Common Beginner Mistakes

Mistake 1: Same Method Name in One Class

class Calculator:

    def add(self, a, b):
        return a + b

    def add(self, a, b, c):
        return a + b + c

Python madhye dusri definition pahili definition replace karte. Traditional method overloading automatic hot nahi.

Mistake 2: Wrong Method Name

class Dog:

    def sound(self):
        print("Bark")


dog = Dog()
dog.sounds()

Method che name sound aahe, sounds nahi. Wrong method name mule AttributeError yeil.

Mistake 3: Forgetting self

class Dog:

    def sound():
        print("Bark")

Instance method madhye pahila parameter normally self asto. 

class Dog:

    def sound(self):
        print("Bark")

Mistake 4: Assuming All Objects Have Same Method

Duck Typing vapartana function la dilelya pratyek object madhye required method asne garjeche aahe. Nahi tar AttributeError yeu shakto.
