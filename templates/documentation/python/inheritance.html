Python Inheritance

Ek class dusrya class madhil attributes ani methods reuse kashi karu shakto te Inheritance madhun shikuya.

📘 Level: Beginner ⏱️ Time: 50–60 Minutes

1. What is Inheritance?

Inheritance ha Object-Oriented Programming madhil ek important concept aahe. Yachya madatine ek class dusrya class madhil attributes ani methods use karu shakto.

Existing class madhun properties ani methods ghenyala Inheritance mhantat.

Real-Life Example

Samaj ek Animal class aahe. Tyamadhye eat() ani sleep() methods aahet.

Dog ani Cat he suddha animals aahet. Tyanna eat() ani sleep() ya common methods chi garaj aahe.

Pratyek class madhye same methods punha lihinyapeksha Dog ani Cat classes ne Animal class inherit karu shakto.

Samjun ghe: Inheritance mule code duplication kami hote ani existing functionality reuse karta yete.

2. Parent Class and Child Class

Inheritance madhye don main classes astat:

  • Parent Class: Jya class madhun properties ani methods inherit hotat.
  • Child Class: Ji class parent class inherit karte.

Syntax

class Parent:
    # Parent class code
    pass


class Child(Parent):
    # Child class code
    pass

Example

class Animal:

    def eat(self):
        print("Animal is eating")


class Dog(Animal):
    pass


dog = Dog()

dog.eat()
Output: 
Animal is eating

Yethe Animal hi Parent Class aahe ani Dog hi Child Class aahe. Dog class ne Animal madhil eat() method inherit keli.

3. Why Use Inheritance?

  • Code reuse karta yeto.
  • Same code punha lihava lagat nahi.
  • Application maintain karne sope hote.
  • Parent class madhye common functionality organize karta yete.
  • Child class madhye additional functionality add karta yete.

Without Inheritance

class Dog:

    def eat(self):
        print("Eating")


class Cat:

    def eat(self):
        print("Eating")

Donhi classes madhye same eat() method lihavi lagli.

With Inheritance

class Animal:

    def eat(self):
        print("Eating")


class Dog(Animal):
    pass


class Cat(Animal):
    pass

Aata Dog ani Cat donhi classes Animal madhil eat() method reuse karu shaktat.

4. Single Inheritance

Ek Child Class ekach Parent Class inherit karte, tyala Single Inheritance mhantat.

Structure

Animal (Parent)
↓
Dog (Child)

Example

class Animal:

    def eat(self):
        print("Animal is eating")


class Dog(Animal):

    def bark(self):
        print("Dog is barking")


dog = Dog()

dog.eat()
dog.bark()
Output: 
Animal is eating
Dog is barking

Dog class la Animal chi eat() method ani swatachi bark() method donhi access karta yetat.

5. Multiple Inheritance

Ek Child Class multiple Parent Classes inherit karte, tyala Multiple Inheritance mhantat.

Structure

Father
Mother
↓
Child

Example

class Father:

    def father_skill(self):
        print("Father: Driving")


class Mother:

    def mother_skill(self):
        print("Mother: Cooking")


class Child(Father, Mother):

    def child_skill(self):
        print("Child: Coding")


child = Child()

child.father_skill()
child.mother_skill()
child.child_skill()
Output: 
Father: Driving
Mother: Cooking
Child: Coding

Child class ne Father ani Mother ya donhi classes inherit kelya aahet.

Important: Multiple inheritance madhye parent classes madhil method names same aslyas konti method call honar he MRO tharavte.

6. Multilevel Inheritance

Ek class dusrya class la inherit karte ani tisri class dusrya class la inherit karte, tyala Multilevel Inheritance mhantat.

Structure

Animal
↓
Dog
↓
Puppy

Example

class Animal:

    def eat(self):
        print("Animal is eating")


class Dog(Animal):

    def bark(self):
        print("Dog is barking")


class Puppy(Dog):

    def play(self):
        print("Puppy is playing")


puppy = Puppy()

puppy.eat()
puppy.bark()
puppy.play()
Output: 
Animal is eating
Dog is barking
Puppy is playing

Puppy class la Dog madhil bark() ani Animal madhil eat() ya donhi methods access karta yetat.

7. Hierarchical Inheritance

Multiple Child Classes ekach Parent Class inherit kartat, tyala Hierarchical Inheritance mhantat.

Structure

Animal (Parent)
↓
Dog
Cat
Cow

Example

class Animal:

    def eat(self):
        print("Animal is eating")


class Dog(Animal):

    def bark(self):
        print("Dog is barking")


class Cat(Animal):

    def meow(self):
        print("Cat is meowing")


dog = Dog()
cat = Cat()

dog.eat()
dog.bark()

cat.eat()
cat.meow()
Output: 
Animal is eating
Dog is barking
Animal is eating
Cat is meowing

Dog ani Cat ya donhi classes Animal class inherit kartat.

8. Hybrid Inheritance

Don kiwa adhik inheritance patterns combine zalyas tyala Hybrid Inheritance mhantat.

Structure Example

Animal
↓
Dog
Cat
↓
Pet

Example

class Animal:

    def eat(self):
        print("Eating")


class Dog(Animal):

    def bark(self):
        print("Barking")


class Cat(Animal):

    def meow(self):
        print("Meowing")


class Pet(Dog, Cat):

    def play(self):
        print("Playing")


pet = Pet()

pet.eat()
pet.bark()
pet.meow()
pet.play()
Output: 
Eating
Barking
Meowing
Playing

Ya example madhye hierarchical ani multiple inheritance patterns combine kele aahet.

9. Inheritance with Constructor

Parent class madhye __init__() method asel tar child class object create kartana parent constructor automatically call hot nahi, jar child ne swatacha __init__() define kela asel.

Example

class Animal:

    def __init__(self, name):
        self.name = name


class Dog(Animal):

    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed


dog = Dog("Tommy", "Labrador")

print(dog.name)
print(dog.breed)
Output: 
Tommy
Labrador

super().__init__(name) mule parent class cha constructor call hoto ani name attribute initialize hoto.

10. super() Function

super() cha use current class chya Method Resolution Order madhil pudhil class chi functionality access karnyasathi hoto.

Example

class Animal:

    def sound(self):
        print("Animal makes sound")


class Dog(Animal):

    def sound(self):
        super().sound()
        print("Dog barks")


dog = Dog()
dog.sound()
Output: 
Animal makes sound
Dog barks

Dog madhil sound() method ne super() vaprun parent class madhil sound() method call keli.

Tip: super() fakt direct parent class la call karte asa samju nakos. Multiple inheritance madhye te MRO nusar pudhil class kade jate.

11. Method Overriding

Child class madhye parent class madhil method chya same name ne navin implementation define kelyas Method Overriding hote.

Example

class Animal:

    def sound(self):
        print("Animal makes sound")


class Dog(Animal):

    def sound(self):
        print("Dog barks")


animal = Animal()
dog = Dog()

animal.sound()
dog.sound()
Output: 
Animal makes sound
Dog barks

Animal ani Dog ya classes madhye sound() method aahe. Dog class madhil method parent method override karte.

12. MRO (Method Resolution Order)

MRO mhanje Python method kiwa attribute shodhtana classes kontya order ne check karto te tharavnari sequence.

Multiple Inheritance madhye same method name asel tar kontya class madhil method use honar he MRO tharavte.

Example

class A:

    def show(self):
        print("Class A")


class B(A):

    def show(self):
        print("Class B")


class C(A):

    def show(self):
        print("Class C")


class D(B, C):
    pass


obj = D()
obj.show()

print(D.mro())
Output: 
Class B

D class madhye B ani C donhi parent classes aahet. Python MRO nusar B madhil show() method first search karto.

MRO Check

print(D.mro())

Ya example madhil MRO order:

D → B → C → A → object
Remember: MRO check karnyasathi ClassName.mro() kiwa ClassName.__mro__ vaparta yeto.

13. isinstance() Function

isinstance() function object specific class cha kiwa tyachya parent class cha instance aahe ka he check karte.

Syntax

isinstance(object, class)

Example

class Animal:
    pass


class Dog(Animal):
    pass


dog = Dog()

print(isinstance(dog, Dog))
print(isinstance(dog, Animal))
Output: 
True
True

Dog ha Animal class cha child aslyamule dog object Dog ani Animal donhi classes cha instance aahe.

14. issubclass() Function

issubclass() function ek class dusrya class chi child kiwa subclass aahe ka he check karte.

Example

class Animal:
    pass


class Dog(Animal):
    pass


print(issubclass(Dog, Animal))
print(issubclass(Animal, Dog))
Output: 
True
False

Dog hi Animal chi subclass aahe. Pan Animal hi Dog chi subclass nahi.

15. Types of Inheritance – Revision

Type Structure Meaning
Single A → B One parent, one child.
Multiple A + B → C Multiple parents, one child.
Multilevel A → B → C Inheritance chain.
Hierarchical A → B, C One parent, multiple children.
Hybrid Combination Multiple inheritance patterns combine.

16. Practical Example – Employee Management System

Aata inheritance vaprun Employee Management System cha simple example baghuya.

Complete Program

class Employee:

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def display_details(self):
        print("Name:", self.name)
        print("Salary:", self.salary)


class Developer(Employee):

    def __init__(self, name, salary, language):
        super().__init__(name, salary)
        self.language = language

    def display_role(self):
        print("Role: Developer")
        print("Language:", self.language)


class Manager(Employee):

    def __init__(self, name, salary, team_size):
        super().__init__(name, salary)
        self.team_size = team_size

    def display_role(self):
        print("Role: Manager")
        print("Team Size:", self.team_size)


developer = Developer("Rohan", 30000, "Python")
manager = Manager("Amit", 50000, 5)

developer.display_details()
developer.display_role()

print()

manager.display_details()
manager.display_role()
Output: 
Name: Rohan
Salary: 30000
Role: Developer
Language: Python

Name: Amit
Salary: 50000
Role: Manager
Team Size: 5

Ya program madhye:

  • Employee hi Parent Class aahe.
  • Developer ani Manager ya Child Classes aahet.
  • Donhi child classes Employee cha constructor reuse kartat.
  • super() mule parent class chi initialization hote.
  • Pratyek child class madhye swatachi additional functionality aahe.
Backend Connection: Real Django projects madhye common functionality base classes madhye thevun child classes madhye specific behavior define karta yeto. Pan inheritance fakt code reuse sathi andhadhund vapru naye.

17. Common Beginner Mistakes

Mistake 1: Wrong Parent Class Name

class Animal:
    pass

class Dog(Animals):
    pass

Parent class che name Animal aahe, Animals nahi. 

class Dog(Animal):
    pass

Mistake 2: Forgetting super()

class Animal:

    def __init__(self, name):
        self.name = name


class Dog(Animal):

    def __init__(self, name, breed):
        self.breed = breed

Child class ne swatacha __init__() define kela aahe, pan parent constructor call kela nahi. Tyamule self.name initialize hot nahi. 

class Dog(Animal):

    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed

Mistake 3: Wrong Multiple Inheritance Syntax

class Child(Father, Mother):
    pass

Multiple inheritance madhye parent class names comma ne separate karave lagtat. Ha correct syntax aahe.

Mistake 4: Assuming Parent Methods Are Always First

class Animal:

    def sound(self):
        print("Animal")


class Dog(Animal):

    def sound(self):
        print("Dog")


dog = Dog()
dog.sound()

Child class madhye same method override asel tar object var call kelyavar child implementation use hote. 

Dog
