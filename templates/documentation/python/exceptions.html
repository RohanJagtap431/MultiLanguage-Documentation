Python Exception Handling

Program madhye runtime errors alyas te safely handle karnyasathi Exception Handling vapartat.

📘 Level: Beginner ⏱️ Time: 45–55 Minutes

1. What are Exceptions?

Program execute hot astana kahi unexpected problems yeu shaktat. Ya problems mule program cha normal execution stop hou shakto.

Python madhye runtime la yenarya errors na generally Exceptions mhantat.

Example

number = 10
result = number / 0

print(result)
Error: 
ZeroDivisionError: division by zero

Ya example madhye number la zero ne divide karnyacha prayatna kela aahe. Python madhye zero ne division allowed nahi.

Samjun ghe: Exception mhanje program execute hotana yenari unexpected problem. Exception Handling mule ashi problem handle karta yete.

2. Why Exception Handling?

Exception Handling vaparnyache fayde:

  • Program achanak terminate honyapasun vachavta yeto.
  • User la meaningful error message dakhavta yeto.
  • Program cha normal flow maintain karta yeto.
  • Unexpected situations handle karta yetat.
  • Application reliable banvnyas madat hote.

Without Exception Handling

print("Program Started")

number = 10 / 0

print("Program Completed")
Output: 
Program Started
ZeroDivisionError: division by zero

Last print statement execute hot nahi.

With Exception Handling

print("Program Started")

try:
    number = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")

print("Program Completed")
Output: 
Program Started
Cannot divide by zero
Program Completed

3. Errors vs Exceptions

Python madhye errors ha broad term aahe. Syntax errors ani runtime exceptions he vegvegale problems aahet.

Syntax Error Exception
Code cha syntax chukicha asto. Program execute hotana problem yete.
Program run honyapurvi detect hoto. Runtime madhye raise hoto.
Example: Missing colon. Example: ZeroDivisionError.

Syntax Error Example

if 10 > 5
    print("Yes")
Error: 
SyntaxError: expected ':'

Exception Example

number = int("hello")
Error: 
ValueError: invalid literal for int()

4. Common Python Exceptions

Python madhye vegveglya situations sathi vegveglya built-in exceptions available aahet.

Exception When it occurs
ZeroDivisionError Zero ne divide kelyas.
ValueError Value cha type barobar asla tari value invalid aslyas.
TypeError Incompatible data types vaparlyas.
NameError Undefined variable use kelyas.
IndexError List madhil invalid index access kelyas.
KeyError Dictionary madhil missing key access kelyas.
FileNotFoundError File sapadli nahi tar.
AttributeError Object madhye unavailable attribute access kelyas.
ImportError Required import karta ala nahi tar.

5. try Statement

try block madhye asa code lihitat jyamadhye exception yenayachi possibility aste.

Syntax

try:
    # Risky code

Example

try:
    number = 10 / 2
    print(number)
Output: 
5.0
Important: try block ekta vaparta yet nahi. Tyachyasobat except kiwa finally block asne avashyak aahe.

6. except Statement

except block cha use try block madhye yenari specific exception handle karnyasathi hoto.

Syntax

try:
    # Risky code

except ExceptionName:
    # Error handling code

Example

try:
    number = 10 / 0

except ZeroDivisionError:
    print("Zero ne divide karta yet nahi")
Output: 
Zero ne divide karta yet nahi

ZeroDivisionError alyamule tyach exception sathi aslela except block execute zala.

7. Multiple except Blocks

Ekach try block madhye vegveglya exceptions yeu shaktat. Tyanna handle karnyasathi multiple except blocks vapartat.

Example

try:
    number = int(input("Enter a number: "))
    result = 100 / number

    print("Result:", result)

except ValueError:
    print("Please enter a valid integer")

except ZeroDivisionError:
    print("Number cannot be zero")
Possible Output 1: 
Enter a number: abc
Please enter a valid integer
Possible Output 2: 
Enter a number: 0
Number cannot be zero
Samjun ghe: Input conversion madhye ValueError yeu shakto. Division madhye ZeroDivisionError yeu shakto. Donhi errors vegveglya except blocks madhye handle kele aahet.

8. Generic except Block

Specific exception mahit nasel tar generic except block vaparta yeto. Pan शक्य asel tithe specific exception handle karne changle.

Example

try:
    number = int("hello")

except Exception:
    print("Something went wrong")
Output: 
Something went wrong
Important: Generic except mule exact problem samajne kathin hou shakte. Mhanun specific exception classes vaprane prefer kar. KeyboardInterrupt ani SystemExit sarkhe BaseException exceptions unnecessarily catch karu naye.

9. else Block

else block fakt try block madhye exception raise zali nahi tar execute hoto.

Syntax

try:
    # Risky code

except ExceptionName:
    # Error handling

else:
    # No exception code

Example

try:
    number = int(input("Enter number: "))

except ValueError:
    print("Invalid input")

else:
    print("Your number is:", number)
Output: 
Enter number: 25
Your number is: 25

Input valid aslyamule exception aali nahi ani else block execute zala.

10. finally Block

finally block cha use cleanup code execute karnyasathi hoto.

Normal exception flow madhye exception aali kiwa nahi, tari finally block execute hoto.

Syntax

try:
    # Risky code

except ExceptionName:
    # Error handling

finally:
    # Cleanup code

Example

try:
    number = 10 / 2
    print(number)

except ZeroDivisionError:
    print("Cannot divide by zero")

finally:
    print("Program finished")
Output: 
5.0
Program finished

Example with Exception

try:
    number = 10 / 0

except ZeroDivisionError:
    print("Cannot divide by zero")

finally:
    print("Cleanup completed")
Output: 
Cannot divide by zero
Cleanup completed
Tip: File close karne, resources release karne kiwa cleanup tasks sathi finally useful aahe. File handling madhye with statement suddha resource management sathi commonly vapartat.

11. Complete try-except-else-finally

try, except, else ani finally he char blocks ekatra suddha use karta yetat.

Example

try:
    number = int(input("Enter a number: "))
    result = 100 / number

except ValueError:
    print("Please enter an integer")

except ZeroDivisionError:
    print("Cannot divide by zero")

else:
    print("Result:", result)

finally:
    print("Execution completed")
Possible Output: 
Enter a number: 20
Result: 5.0
Execution completed

Block Responsibilities

Block When it executes
tryRisky code execute karto.
exceptMatching exception raise zalyas execute hoto.
elsetry madhye exception raise zali nahi tar execute hoto.
finallyNormal exception flow madhye cleanup sathi execute hoto.

12. Exception Message using as

Exception object madhil error message access karnyasathi as keyword vaparta yeto.

Example

try:
    number = int("hello")

except ValueError as error:
    print("Error:", error)
Possible Output: 
Error: invalid literal for int() with base 10: 'hello'

Ya example madhye error ha exception object reference aahe. Tyatun error message display kela aahe.

13. raise Keyword

raise keyword cha use manually exception raise karnyasathi hoto.

Syntax

raise ExceptionName("Error message")

Example

age = 15

if age < 18:
    raise ValueError("You must be 18 or older")

print("Access granted")
Error: 
ValueError: You must be 18 or older

Age 18 peksha kami aslyamule manually ValueError raise zala. Tyamule pudhil print statement execute hot nahi.

Handling Raised Exception

age = 15

try:
    if age < 18:
        raise ValueError("Age must be 18 or above")

    print("Access granted")

except ValueError as error:
    print("Error:", error)
Output: 
Error: Age must be 18 or above

14. Custom Exceptions

Aaplyala application sathi swatachi exception class create karta yete. Ashya exception la Custom Exception mhantat.

Custom exception create karnyasathi generally Exception class inherit kartat.

Syntax

class CustomError(Exception):
    pass

Example – Invalid Age

class InvalidAgeError(Exception):
    pass


age = 15

try:
    if age < 18:
        raise InvalidAgeError("Age is not valid")

    print("Registration successful")

except InvalidAgeError as error:
    print("Error:", error)
Output: 
Error: Age is not valid

InvalidAgeError hi aapli custom exception class aahe. Age 18 peksha kami aslyas hi exception raise hote.

15. Practical Example – Safe Calculator

User kadun don numbers ghe. Addition, subtraction, multiplication ani division perform kar. Invalid input ani zero division handle kar. 

try:
    num1 = float(input("Enter first number: "))
    num2 = float(input("Enter second number: "))

    result = num1 / num2

except ValueError:
    print("Please enter valid numbers")

except ZeroDivisionError:
    print("Cannot divide by zero")

else:
    print("Division Result:", result)

finally:
    print("Calculator completed")
Possible Output: 
Enter first number: 20
Enter second number: 5
Division Result: 4.0
Calculator completed
Practice Challenge: Ya calculator madhye addition, subtraction ani multiplication suddha add kar. User ne invalid operator dila tar custom error message display kar.

16. Common Beginner Mistakes

Mistake 1: Wrong Exception Name

try:
    number = 10 / 0

except ValueError:
    print("Error handled")

Yethe ZeroDivisionError apekshit aahe. ValueError block tyala handle karat nahi. 

except ZeroDivisionError:
    print("Cannot divide by zero")

Mistake 2: Empty except Block

try:
    number = 10 / 0

except:
    pass

Ashya code mule error silently ignore hou shakto. Debugging kathin hote. Specific exception handle kar.

Mistake 3: Wrong Block Order

try:
    print(10 / 2)

else:
    print("Success")

except ZeroDivisionError:
    print("Error")

else block ha except block nantar lihaycha asto. 

try:
    print(10 / 2)

except ZeroDivisionError:
    print("Error")

else:
    print("Success")

Mistake 4: Not Handling Invalid Input

age = int(input("Enter age: "))

User ne letters enter kele tar ValueError yeu shakto. Input conversion try block madhye handle kar. 

try:
    age = int(input("Enter age: "))

except ValueError:
    print("Enter a valid age")
