08. Python Input and Output

Python madhye user kadun input kasa ghyaycha ani screen var output kasa display karaycha he ya lesson madhye shikuya.

📘 Beginner Level ⏱️ 20-25 Minutes

1. What is Input and Output?

Input mhanje user kadun program madhye data ghene. Output mhanje program madhun result screen var display karne.

Udaharanarth, calculator madhye user don numbers enter karto. Program tyanchi addition karto ani result display karto.

Simple Definition: Input means receiving data from the user. Output means displaying information to the user.
Example
name = input("Enter your name: ")

print("Hello", name)
Example Output: 
Enter your name: Rohan
Hello Rohan

2. print() Function

Python madhye output display karanyasathi print() function vapartat.

Aapan text, numbers, variables ani expressions print() function vaprun display karu shakto.

Example 1 – Printing Text
print("Hello World!")
print("Welcome to Python")
Output: 
Hello World!
Welcome to Python

Printing Numbers

print(100)
print(25.5)
print(10 + 20)
Output: 
100
25.5
30

Printing Variables

name = "Rohan"
age = 20

print(name)
print(age)
Output: 
Rohan
20

3. input() Function

Python madhye user kadun data ghenyasathi input() function vapartat.

Program input() function paryant alyavar user input enter kareparyant wait karto.

Example
name = input("Enter your name: ")

print("Your name is", name)
Example Output: 
Enter your name: Rohan
Your name is Rohan

Ithe user ne enter kelele name variable madhye store hote. Nantar print() tyachi value display karto.

4. input() Always Returns String

Python madhye input() function ne ghetleli value default ne string data type madhye aste.

Example
age = input("Enter your age: ")

print(age)
print(type(age))
Example Output: 
Enter your age: 20
20
<class 'str'>
Important: User ne 20 enter kele tari input() tyala string mhanun store karto. Number mhanun calculation karayche asel tar int() kiwa float() vapra.

5. Taking Integer Input

User kadun integer number ghenyasathi input() sobat int() function vapartat.

Example
age = int(input("Enter your age: "))

print(age)
print(type(age))
Example Output: 
Enter your age: 20
20
<class 'int'>

6. Taking Float Input

User kadun decimal number ghenyasathi float() function vapartat.

Example
marks = float(input("Enter your marks: "))

print(marks)
print(type(marks))
Example Output: 
Enter your marks: 85.5
85.5
<class 'float'>

7. Taking Multiple Inputs

Program madhye user kadun ekapeksha jast inputs gheta yetat. Pratyek input sathi vegala input() function vapru shakto.

Example
name = input("Enter your name: ")
age = int(input("Enter your age: "))
city = input("Enter your city: ")

print("Name:", name)
print("Age:", age)
print("City:", city)
Example Output: 
Enter your name: Rohan
Enter your age: 20
Enter your city: Kolhapur
Name: Rohan
Age: 20
City: Kolhapur

Taking Two Inputs in One Line

split() function vaprun ekach line madhye don kiwa adhik values gheta yetat. 

a, b = input("Enter two numbers: ").split()

print(a)
print(b)
Example Output: 
Enter two numbers: 10 20
10
20
Remember: split() ne milalelya values default ne strings astat. Calculation sathi tyanna convert kara.

Multiple Integer Inputs in One Line

a, b = map(int, input("Enter two numbers: ").split())

print(a + b)
Example Output: 
Enter two numbers: 10 20
30

8. sep Parameter in print()

sep parameter cha use print() madhil multiple values madhye separator denyasathi hoto.

Default separator space asto. Aapan to change karu shakto.

Example
print("Python", "Java", "C++")

print("Python", "Java", "C++", sep="-")
Output: 
Python Java C++
Python-Java-C++

Another Example

print(10, 20, 30, sep=" | ")
Output: 
10 | 20 | 30

9. end Parameter in print()

Default ne print() function output display kelyanantar new line madhye jato.

end parameter vaprun print() nantar kay display vhayla pahije te tharavta yete.

Example
print("Hello", end=" ")
print("Rohan")
Output: 
Hello Rohan

Using end with Symbol

print("Python", end=" - ")
print("Programming")
Output: 
Python - Programming

10. f-Strings in Python

f-string cha use string madhye variables ani expressions easily display karanyasathi hoto.

f-string lihitana string chya suruvatila f lihitat ani variable curly brackets madhye lihitat.

Example
name = "Rohan"
age = 20

print(f"My name is {name}")
print(f"My age is {age}")
Output: 
My name is Rohan
My age is 20

Using Expressions in f-Strings

a = 10
b = 20

print(f"Total is {a + b}")
Output: 
Total is 30
Tip: Variables ani values ekatra display karanyasathi f-string ha clean ani readable method aahe.

11. Formatting Output

f-string vaprun decimal numbers kiti digits paryant display karayche te tharavta yete.

Example
price = 99.5678

print(f"Price: {price:.2f}")
Output: 
Price: 99.57

:.2f mule number decimal point nantar don digits paryant display hoto.

12. Practical Example – Simple Calculator

Ata input, type casting ani output ya concepts cha use karun simple calculator banavuya.

Complete Code
num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

addition = num1 + num2
subtraction = num1 - num2
multiplication = num1 * num2
division = num1 / num2

print(f"Addition: {addition}")
print(f"Subtraction: {subtraction}")
print(f"Multiplication: {multiplication}")
print(f"Division: {division}")
Example Output: 
Enter first number: 20
Enter second number: 10
Addition: 30.0
Subtraction: 10.0
Multiplication: 200.0
Division: 2.0
Important: Division karanyapurvi second number zero nahi yachi khatri kara. Zero ne division kelyas ZeroDivisionError yeto.

13. Common Beginner Mistakes

Mistake 1: Input la Integer madhye Convert na karne

a = input("Enter first number: ")
b = input("Enter second number: ")

print(a + b)

Input values strings aslyamule 10 ani 20 cha result 1020 asa yeu shakto.

Correct: int() kiwa float() vapra.

Mistake 2: f-string madhye f visarne

name = "Rohan"

print("Hello {name}")

Output: Hello {name}

Correct: print(f"Hello {name}")

Mistake 3: Wrong Number of Values

a, b = input("Enter numbers: ").split()

Don variables sathi user ne don values enter karne aavashyak aahe. Kami kiwa jast values dilyas error yeu shakto.

Mistake 4: Invalid Integer Input

age = int(input("Enter age: "))

User ne "hello" sarkha text enter kela tar ValueError yeil. Integer madhye convert honari value enter karavi.
