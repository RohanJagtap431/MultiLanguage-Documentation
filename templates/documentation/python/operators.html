09. Python Operators

Python madhye calculations, comparisons ani logical operations karanyasathi operators kase use kartat he ya lesson madhye shikuya.

📘 Beginner Level ⏱️ 25-30 Minutes

1. What are Operators?

Operators mhanje special symbols kiwa keywords je values kiwa variables var specific operations perform kartat.

Udaharanarth, don numbers add karayche astil tar + operator vapartat.

Simple Definition: Operators are symbols or keywords used to perform operations on variables and values.
Example
a = 10
b = 20

result = a + b

print(result)
Output: 
30

Ithe + ha operator aahe. To a ani b ya don values chi addition karto.

2. Types of Python Operators

Modulus operator division nantar urleli remainder value return karto.

Floor Division result la nearest lower integer value paryant ghete. Negative numbers sathi suddha floor direction ne result milto.

Tip: Even ani Odd number check karanyasathi modulus operator khup useful aahe.

6. Logical Operators

Logical Operators cha use multiple conditions check karanyasathi hoto.

Python madhye three main logical operators aahet:

  • and – Donhi conditions True aslyas True.
  • or – Kamit kami ek condition True aslyas True.
  • not – Boolean result ulta karto.

AND Operator

age = 20
has_id = True

print(age >= 18 and has_id)
Output: 
True

OR Operator

has_email = False
has_mobile = True

print(has_email or has_mobile)
Output: 
True

NOT Operator

is_logged_in = True

print(not is_logged_in)
Output: 
False
Remember: AND sathi donhi conditions True pahijet. OR sathi kamit kami ek condition True asali tari chalate.

7. Identity Operators

Identity Operators cha use don variables ekach object la refer kartat ka he check karanyasathi hoto.

Python madhye don identity operators aahet:

  • is – Don references same object aslyas True.
  • is not – Don references same object naslyas True.
Example
a = [10, 20, 30]
b = a
c = [10, 20, 30]

print(a is b)
print(a is c)
print(a == c)
print(a is not c)
Output: 
True
False
True
True

Ithe b ha a ch tyach list object la refer karto. c madhye same values aahet, pan to vegala list object aahe.

Important: == values compare karto, tar is object identity check karto. Donhi ekach arthache nahit.

9. Bitwise Operators

Bitwise Operators numbers chya binary representation madhil bits var operations perform kartat.

Computer madhye numbers binary form madhye represent hotat. Binary madhye fakt 0 ani 1 astat.

Operator Name
& Bitwise AND
| Bitwise OR
^ Bitwise XOR
~ Bitwise NOT
<< Left Shift
>> Right Shift

Example – Bitwise AND

a = 5
b = 3

print(a & b)
Output: 
1

5 chi binary value 101 ani 3 chi binary value 011 aahe. Bitwise AND madhye donhi bits 1 aslyas result bit 1 hoto.

Example – Bitwise OR

a = 5
b = 3

print(a | b)
Output: 
7

Example – Left Shift

number = 5

print(number << 1)
Output: 
10
Tip: Bitwise Operators he thode advanced aahet. Sadhya operators chi nave ani basic examples samjun ghya.

10. Operator Precedence

Ekach expression madhye multiple operators astil tar Python ठराविक priority nusar operations perform karto. Yala Operator Precedence mhantat.

Example
result = 10 + 5 * 2

print(result)
Output: 
20

Multiplication la addition peksha jast priority aahe. Mhanun pahile 5 * 2 hote ani nantar 10 + 10.

Using Parentheses

result = (10 + 5) * 2

print(result)
Output: 
30
Tip: Expression samjayla kathin asel tar parentheses () vapra. Code readable hoto.

11. Common Beginner Mistakes

Mistake 1: Assignment ani Comparison madhye confusion

age = 20

print(age = 20)

print() madhye asa assignment lihilyas SyntaxError yeil.

Correct: print(age == 20)

Mistake 2: String ani Number direct add karne

age = 20

print("Age: " + age)

String ani integer direct concatenate karta yet nahit.

Correct: print("Age:", age)

Mistake 3: Division by Zero

print(10 / 0)

Division by zero mule ZeroDivisionError yeil.

Mistake 4: is ani == madhye confusion

a = [1, 2]
b = [1, 2]

print(a is b)
print(a == b)

Output: False ani True. is object identity check karto, tar == values compare karto.
