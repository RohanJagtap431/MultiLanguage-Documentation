Python Function Arguments

Function la values pass karnyachya vegveglya methods ya lesson madhye samjun gheu.

📘 Level: Beginner ⏱️ Time: 45–55 Minutes

1. What are Function Arguments?

Function call kartana function la dilelya actual values na Arguments mhantat.

Function definition madhye parameters astat ani function call kartana arguments pass kele jatat.

Example

def greet(name):
    print("Hello", name)

greet("Rohan")
Output: 
Hello Rohan
  • name – Parameter
  • "Rohan" – Argument
Lakshat thev: Parameter ha function define kartana lihitat. Argument hi actual value aste ji function call kartana detat.

2. Types of Function Arguments

Python madhye commonly he argument types vapartat:

Type Meaning
Positional Arguments Position nusar values pass hotat.
Keyword Arguments Parameter name vaprun values pass hotat.
Default Arguments Value dili nahi tar default value vaprali jate.
*args Multiple positional arguments accept karto.
**kwargs Multiple keyword arguments accept karto.

3. Positional Arguments

Function call kartana arguments jya order madhye pass karto, tyach order madhye te parameters la assign hotat. Tyanna Positional Arguments mhantat.

Example

def student(name, age):
    print("Name:", name)
    print("Age:", age)

student("Rohan", 20)
Output: 
Name: Rohan
Age: 20

Order Change Kelyas

def student(name, age):
    print("Name:", name)
    print("Age:", age)

student(20, "Rohan")
Output: 
Name: 20
Age: Rohan
Important: Positional arguments madhye order important asto. Chukicha order dilyas values wrong parameters madhye jau shaktat.

4. Keyword Arguments

Function call kartana parameter name sobat value pass keli, tar tyala Keyword Argument mhantat.

Example

def student(name, age):
    print("Name:", name)
    print("Age:", age)

student(age=20, name="Rohan")
Output: 
Name: Rohan
Age: 20

Yethe arguments cha order badlala tari output barobar milto. Karan values parameter names nusar assign hotat.

Another Example

def employee(name, salary, city):
    print(name)
    print(salary)
    print(city)

employee(
    city="Pune",
    name="Amit",
    salary=25000
)
Output: 
Amit
25000
Pune

5. Default Arguments

Function define kartana parameter la default value dili, tar tyala Default Argument mhantat.

Function call kartana tya parameter chi value dili nahi, tar default value use hote.

Example

def greet(name="Guest"):
    print("Hello", name)

greet()
greet("Rohan")
Output: 
Hello Guest
Hello Rohan

Default Value with Multiple Parameters

def student(name, course="Python"):
    print("Name:", name)
    print("Course:", course)

student("Rohan")
student("Amit", "Django")
Output: 
Name: Rohan
Course: Python
Name: Amit
Course: Django
Important Rule: Default value aslele parameters he default value naslelya parameters nantar define karave.

Incorrect Example

def student(course="Python", name):
    print(name, course)

Ha code SyntaxError deto, karan default parameter chya aadhi non-default parameter asla pahije.

Correct Example

def student(name, course="Python"):
    print(name, course)

6. Arbitrary Positional Arguments (*args)

Kahi vela function la kiti arguments milnar aahet he aadhi mahit naste.

Ashya veli *args vaprun multiple positional arguments accept karta yetat.

Example

def add_numbers(*args):
    print(args)

add_numbers(10, 20, 30)
add_numbers(5, 10, 15, 20, 25)
Output: 
(10, 20, 30)
(5, 10, 15, 20, 25)

*args madhye milalele positional arguments tuple madhye collect hotat.

Using *args in Calculation

def add_numbers(*args):
    total = sum(args)
    return total

print(add_numbers(10, 20))
print(add_numbers(10, 20, 30, 40))
Output: 
30
100

Loop with *args

def show_numbers(*args):
    for number in args:
        print(number)

show_numbers(10, 20, 30)
Output: 
10
20
30
Tip: args he fixed Python keyword nahi. * ha important syntax aahe. args ya navachya jagi dusre valid nav suddha vapru shakto.

7. Keyword Arbitrary Arguments (**kwargs)

Function la multiple keyword arguments accept karayche astil, tar **kwargs vapartat.

Ya madhye arguments key-value pairs chya form madhye dictionary madhye collect hotat.

Example

def student(**kwargs):
    print(kwargs)

student(name="Rohan", age=20, course="Python")
Output: 
{'name': 'Rohan', 'age': 20, 'course': 'Python'}

Accessing Values

def student(**kwargs):
    print("Name:", kwargs["name"])
    print("Age:", kwargs["age"])
    print("Course:", kwargs["course"])

student(
    name="Rohan",
    age=20,
    course="Computer Science"
)
Output: 
Name: Rohan
Age: 20
Course: Computer Science

Loop with **kwargs

def show_details(**kwargs):
    for key, value in kwargs.items():
        print(key, ":", value)

show_details(
    name="Amit",
    city="Pune",
    skill="Python"
)
Output: 
name : Amit
city : Pune
skill : Python
Lakshat thev: *args positional values tuple madhye store karto. **kwargs keyword values dictionary madhye store karto.

8. Combining Different Argument Types

Ekach function madhye positional, default, *args ani **kwargs vaparta yetat. Pan tyanchya order che rules follow karave lagtat.

Example

def student(name, course="Python", *subjects, **details):
    print("Name:", name)
    print("Course:", course)
    print("Subjects:", subjects)
    print("Details:", details)

student(
    "Rohan",
    "Django",
    "Python",
    "SQL",
    city="Pune",
    age=20
)
Output: 
Name: Rohan
Course: Django
Subjects: ('Python', 'SQL')
Details: {'city': 'Pune', 'age': 20}

Ya example madhye:

  • name – Positional parameter
  • course – Default parameter
  • *subjects – Extra positional arguments
  • **details – Extra keyword arguments
Note: Ha combined example samjun ghenyasathi aahe. Suruvatila pratyek argument type separately practice kar.

9. Argument Unpacking

List kiwa tuple madhil values function la separate arguments mhanun pass karaychya astil tar * vapartat.

List Unpacking

def add(a, b, c):
    return a + b + c

numbers = [10, 20, 30]

print(add(*numbers))
Output: 
60

Dictionary Unpacking

def student(name, age):
    print("Name:", name)
    print("Age:", age)

details = {
    "name": "Rohan",
    "age": 20
}

student(**details)
Output: 
Name: Rohan
Age: 20

Dictionary unpacking madhye dictionary keys function chya parameter names shi match zalyach pahijet.

11. Common Beginner Mistakes

Mistake 1: Missing Required Argument

def greet(name):
    print("Hello", name)

greet()

name ha required parameter aahe. Value dili nahi tar TypeError yeil. 

greet("Rohan")

Mistake 2: Too Many Positional Arguments

def add(a, b):
    print(a + b)

add(10, 20, 30)

Function fakt don arguments accept karto. Tisri value dilyas TypeError yeil. 

add(10, 20)

Mistake 3: Default Parameter Order

def student(course="Python", name):
    print(name, course)

Non-default parameter ha default parameter chya aadhi asla pahije. 

def student(name, course="Python"):
    print(name, course)

Mistake 4: Positional Argument After Keyword Argument

def student(name, age):
    print(name, age)

student(name="Rohan", 20)

Keyword argument nantar positional argument pass karta yet nahi. 

student("Rohan", 20)

Mistake 5: Wrong Dictionary Key

def student(name, age):
    print(name, age)

details = {"student_name": "Rohan", "age": 20}

student(**details)

student_name hi key name parameter shi match hot nahi. Mhanun function call fail hoil. 

details = {"name": "Rohan", "age": 20}
student(**details)

14. Practical Task – Student Profile System

Student profile system create kar. Ya system madhye name, age, course, multiple skills ani extra details accept kar. 

def student_profile(name, age, course="Python", *skills, **details):

    print("Student Name:", name)
    print("Age:", age)
    print("Course:", course)

    print("Skills:")
    for skill in skills:
        print("-", skill)

    print("Other Details:")
    for key, value in details.items():
        print(key, ":", value)


student_profile(
    "Rohan",
    20,
    "Django",
    "Python",
    "HTML",
    "CSS",
    city="Pune",
    college="Computer Science"
)
Output: 
Student Name: Rohan
Age: 20
Course: Django
Skills:
- Python
- HTML
- CSS
Other Details:
city : Pune
college : Computer Science
