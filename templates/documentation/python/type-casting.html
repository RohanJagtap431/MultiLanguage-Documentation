07. Python Type Casting

Python madhye eka data type madhil value dusrya data type madhye convert kashi karaychi he ya lesson madhye shikuya.

📘 Beginner Level ⏱️ 15-20 Minutes

1. What is Type Casting?

Type Casting mhanje eka data type madhil value dusrya data type madhye convert karne.

Udaharanarth, aaplyakade integer value aahe ani ti string madhye convert karaychi aahe. Ashya veli Type Casting vapartat.

Simple Definition: Type Casting is the process of converting one data type into another data type.
Example
number = 100

text = str(number)

print(text)
print(type(text))
Output: 
100
<class 'str'>

Ithe suruvatila number ha integer hota. str() vaprun tyala string madhye convert kele.

2. Types of Type Casting

Python madhye Type Casting che don main types aahet.

1. Implicit Type Casting

Python swatah ek data type dusrya compatible data type madhye convert karto. Ya process la Implicit Type Casting mhantat.

2. Explicit Type Casting

Programmer swatah conversion function vaprun data type convert karto. Ya process la Explicit Type Casting mhantat.

Remember: Implicit conversion Python swatah karto, tar Explicit conversion programmer karto.

3. Implicit Type Casting

Implicit Type Casting madhye Python compatible data types automatically convert karto.

Udaharanarth, integer ani float ekatra add kele tar Python integer la float madhye convert karu shakto.

Example
a = 10
b = 5.5

result = a + b

print(result)
print(type(result))
Output: 
15.5
<class 'float'>

Ithe a integer aahe ani b float aahe. Addition kartana Python ne result float madhye dila.

Tip: Implicit conversion madhye Python swatah compatible conversion karto. Pratyek data type madhye automatic conversion hot nahi.

4. Explicit Type Casting

Explicit Type Casting madhye aapan conversion functions vaprun data type manually convert karto.

Python madhye commonly use honare functions:

  • int() – Integer madhye convert karte.
  • float() – Float madhye convert karte.
  • str() – String madhye convert karte.
  • bool() – Boolean madhye convert karte.
  • list() – List madhye convert karte.
  • tuple() – Tuple madhye convert karte.
  • set() – Set madhye convert karte.

5. int() Function

int() function cha use value integer madhye convert karanyasathi hoto.

Example
number = "100"

result = int(number)

print(result)
print(type(result))
Output: 
100
<class 'int'>

Float to Integer

number = 25.8

result = int(number)

print(result)
Output: 
25
Important: Float la int madhye convert kartana decimal part remove hoto. Python nearest number round karat nahi.

6. float() Function

float() function cha use value decimal number madhye convert karanyasathi hoto.

Example
number = "50"

result = float(number)

print(result)
print(type(result))
Output: 
50.0
<class 'float'>

Integer to Float

number = 25

result = float(number)

print(result)
Output: 
25.0

7. str() Function

str() function cha use value string madhye convert karanyasathi hoto.

Example
age = 20

result = str(age)

print(result)
print(type(result))
Output: 
20
<class 'str'>

Combining String and Integer

String ani integer directly concatenate karta yet nahit. Integer la string madhye convert karun concatenate karta yete. 

age = 20

message = "My age is " + str(age)

print(message)
Output: 
My age is 20

8. bool() Function

bool() function cha use value Boolean madhye convert karanyasathi hoto.

Boolean madhye fakt don values astat: True ani False.

Example 1
print(bool(1))
print(bool(0))
print(bool(100))
Output: 
True
False
True

String to Boolean

Example 2
print(bool("Python"))
print(bool(""))
Output: 
True
False
Remember: Empty string, zero ani None he Boolean madhye False hotat. Non-empty string ani non-zero numbers True hotat.

9. list(), tuple() and set() Functions

He functions collection data types ekmekanmadhye convert karanyasathi use hotat.

list() Function

Tuple kiwa itar iterable madhun list create karanyasathi list() vapartat. 

numbers = (10, 20, 30)

result = list(numbers)

print(result)
print(type(result))
Output: 
[10, 20, 30]
<class 'list'>

tuple() Function

numbers = [10, 20, 30]

result = tuple(numbers)

print(result)
Output: 
(10, 20, 30)

set() Function

set() function cha use iterable madhil unique values cha set create karanyasathi hoto. 

numbers = [10, 20, 10, 30, 20]

result = set(numbers)

print(result)
Output: 
{10, 20, 30}

10. Type Casting with input()

Python madhye input() function ne user kadun value ghetli tar ti default ne string aste.

User kadun number ghyaycha asel tar tyala int() kiwa float() vaprun convert karave lagte.

Example
age = input("Enter your age: ")

print(type(age))
Example Output: 
Enter your age: 20
<class 'str'>

Correct Way – Convert Input to Integer

age = int(input("Enter your age: "))

print(age)
print(type(age))
Example Output: 
Enter your age: 20
20
<class 'int'>

Practical Example – Addition

num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

total = num1 + num2

print("Total:", total)
Example Output: 
Enter first number: 10
Enter second number: 20
Total: 30
Important: User ne integer madhye convert na honari value dili tar ValueError yeu shakto. Udaharanarth int("hello").

11. Common Type Casting Errors

Mistake 1: Invalid String to Integer

number = int("Python")

print(number)

Error: ValueError

"Python" madhye integer number naslyamule int() conversion successful honar nahi.

Mistake 2: Decimal String to Integer

number = int("10.5")

print(number)

Error: ValueError

Decimal string direct int() madhye convert hot nahi. Pahile float() vapra. 

number = int(float("10.5"))

print(number)

Output: 10

Mistake 3: Adding String and Integer

age = 20

print("Age: " + age)

Error: TypeError

Correct: 

print("Age: " + str(age))
