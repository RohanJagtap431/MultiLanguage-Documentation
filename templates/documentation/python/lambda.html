Python Lambda Functions

Lambda function cha use small ani simple operations ekach expression madhye perform karnyasathi hoto.

📘 Level: Beginner ⏱️ Time: 35–45 Minutes

1. What is Lambda Function?

Lambda ha Python madhil keyword aahe. Tyacha use anonymous function create karnyasathi hoto.

Anonymous function mhanje asa function jyala normal function pramane def vaprun name denyachi garaj naste.

Lambda function madhye ekach expression lihita yeto. Ha expression evaluate houn tyacha result automatically return hoto.

Normal Function Example

def square(number):
    return number * number

print(square(5))
Output: 
25

Lambda Function Example

square = lambda number: number * number

print(square(5))
Output: 
25
Samjun ghe: Donhi examples madhye same calculation hot aahe. Lambda madhye function short form madhye lihila aahe.

2. Lambda Function Syntax

Syntax

lambda arguments: expression

Syntax Explanation

  • lambda – Lambda function create karnyasathi keyword.
  • arguments – Function la milnarya values.
  • : – Arguments ani expression vegale karto.
  • expression – Perform karaychi single expression.

Example

add = lambda a, b: a + b

print(add(10, 20))
Output: 
30

3. Lambda with One Argument

Lambda function madhye ek argument suddha pass karu shakto.

Example – Square

square = lambda x: x * x

print(square(4))
print(square(7))
Output: 
16
49

Example – Cube

cube = lambda x: x * x * x

print(cube(3))
Output: 
27

Example – Even or Odd

check = lambda n: "Even" if n % 2 == 0 else "Odd"

print(check(10))
print(check(7))
Output: 
Even
Odd

4. Lambda with Multiple Arguments

Lambda function madhye multiple arguments pass karu shakto.

Addition

add = lambda a, b: a + b

print(add(10, 20))
Output: 
30

Multiplication

multiply = lambda a, b: a * b

print(multiply(5, 4))
Output: 
20

Maximum of Three Numbers

maximum = lambda a, b, c: max(a, b, c)

print(maximum(10, 50, 30))
Output: 
50

5. Lambda with No Arguments

Lambda function la arguments nasle tari chalate.

Example

greet = lambda: "Hello Python"

print(greet())
Output: 
Hello Python

Ya function madhye arguments nahit. Tari suddha function call kelyavar string return hote.

6. Normal Function vs Lambda Function

Normal Function

def add(a, b):
    return a + b

result = add(10, 20)

print(result)

Lambda Function

add = lambda a, b: a + b

result = add(10, 20)

print(result)
Output of Both: 
30
Normal Function Lambda Function
def keyword vaparto. lambda keyword vaparto.
Function la name deta yeto. Anonymous function create karta yeto.
Multiple statements lihita yetat. Ekach expression lihita yeto.
Complex logic sathi suitable. Small operations sathi suitable.
return statement vaparto. Expression result automatically return hoto.

7. Lambda with map()

map() function iterable madhil pratyek item var dilele function apply karto.

Lambda sobat map() vaprun list madhil pratyek number transform karta yeto.

Syntax

map(function, iterable)

Example – Square Every Number

numbers = [1, 2, 3, 4, 5]

result = map(lambda x: x * x, numbers)

print(list(result))
Output: 
[1, 4, 9, 16, 25]

Example – Add 10 to Every Number

numbers = [5, 10, 15, 20]

result = map(lambda x: x + 10, numbers)

print(list(result))
Output: 
[15, 20, 25, 30]
Important: Python 3 madhye map() iterator return karto. Values pahanyasathi list() vapru shakto.

8. Lambda with filter()

filter() function condition true aslele items select karnyasathi vapartat.

Lambda madhye condition lihun list madhun specific values filter karta yetat.

Syntax

filter(function, iterable)

Example – Even Numbers

numbers = [1, 2, 3, 4, 5, 6, 7, 8]

result = filter(lambda x: x % 2 == 0, numbers)

print(list(result))
Output: 
[2, 4, 6, 8]

Example – Numbers Greater Than 10

numbers = [5, 12, 8, 20, 15, 3]

result = filter(lambda x: x > 10, numbers)

print(list(result))
Output: 
[12, 20, 15]

Example – Filter Passing Marks

marks = [25, 45, 80, 30, 65, 90]

result = filter(lambda x: x >= 35, marks)

print(list(result))
Output: 
[45, 80, 65, 90]

9. Lambda with sorted()

sorted() function iterable madhil values sort karun new list return karto.

key parameter madhye lambda vaprun sorting cha rule define karta yeto.

Example – Sort by Second Element

students = [
    ("Amit", 80),
    ("Rohan", 95),
    ("Neha", 70)
]

result = sorted(students, key=lambda x: x[1])

print(result)
Output: 
[('Neha', 70), ('Amit', 80), ('Rohan', 95)]

Ya example madhye x[1] mhanje tuple madhil second element, arthaat marks. Mhanun students marks nusar ascending order madhye sort hotat.

Example – Descending Order

numbers = [10, 50, 20, 40, 30]

result = sorted(numbers, key=lambda x: x, reverse=True)

print(result)
Output: 
[50, 40, 30, 20, 10]

Example – Sort Names by Length

names = ["Rohan", "Amit", "Christopher", "Neha"]

result = sorted(names, key=lambda name: len(name))

print(result)
Output: 
['Amit', 'Neha', 'Rohan', 'Christopher']

10. Lambda with Conditional Expression

Lambda madhye if-else expression suddha vaparta yete.

Syntax

lambda arguments: value_if_true if condition else value_if_false

Example – Pass or Fail

result = lambda marks: "Pass" if marks >= 35 else "Fail"

print(result(80))
print(result(20))
Output: 
Pass
Fail

Example – Positive or Negative

check = lambda n: "Positive" if n > 0 else "Not Positive"

print(check(10))
print(check(-5))
Output: 
Positive
Not Positive

11. Practical Example – Student Marks Processing

Student marks madhun passing students filter kar. Nantar passing students che marks ascending order madhye sort kar. 

marks = [25, 80, 45, 30, 90, 60, 20]

passing = filter(lambda x: x >= 35, marks)

result = sorted(passing)

print("Passing Marks:", list(result))
Output: 
Passing Marks: [45, 60, 80, 90]

Ya example madhye filter() passing marks select karto ani sorted() tyanna ascending order madhye arrange karto.

12. Difference Between map() and filter()

map() filter()
Pratyek item transform karto. Condition nusar items select karto.
Pratyek input item sathi result deto. Fakt condition true aslele items deto.
Example: Square numbers. Example: Even numbers select karne.

map() Example

numbers = [1, 2, 3]

result = map(lambda x: x * 2, numbers)

print(list(result))
Output: 
[2, 4, 6]

filter() Example

numbers = [1, 2, 3, 4, 5]

result = filter(lambda x: x % 2 == 0, numbers)

print(list(result))
Output: 
[2, 4]

13. Common Beginner Mistakes

Mistake 1: Using Multiple Statements

result = lambda x:
    y = x * x
    return y

Lambda function madhye assignment ani multiple statements normal function pramane lihita yet nahit. 

result = lambda x: x * x

Mistake 2: Forgetting the Colon

add = lambda a, b a + b

Arguments nantar colon dene avashyak aahe. 

add = lambda a, b: a + b

Mistake 3: Forgetting list() with map()

numbers = [1, 2, 3]

result = map(lambda x: x * 2, numbers)

print(result)

Ya mule map object disel. Values pahanyasathi list() vapra. 

print(list(result))

Mistake 4: Wrong Condition in filter()

numbers = [1, 2, 3, 4, 5]

result = filter(lambda x: x > 3, numbers)

print(list(result))

Ha code fakt 3 peksha mothe numbers select karto. Condition samjun gheunach filter vapra. 

[4, 5]
