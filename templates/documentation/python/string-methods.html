Python String Methods

String Methods cha use karun aapan string madhil text change, search, split ani check karu shakto.

📘 Level: Beginner ⏱️ Time: 30–40 Minutes

1. What are String Methods?

Python madhye string var vegvegale operations karnyasathi kahi built-in methods available aahet. Tyanna String Methods ase mhantat.

Udaharanarth, aaplyakade "hello" ha text aahe. Aaplyala tyache letters capital karayche astil tar upper() method vaparta yete. 

name = "hello"

print(name.upper())
Output: 
HELLO
Important: String methods generally original string change karat nahit. Te navin result return kartat.

2. upper() and lower()

upper()

String madhil sarva English letters capital letters madhye convert karnyasathi upper() vapartat. 

text = "python programming"

print(text.upper())
Output: 
PYTHON PROGRAMMING

lower()

String madhil letters small letters madhye convert karnyasathi lower() vapartat. 

text = "PYTHON PROGRAMMING"

print(text.lower())
Output: 
python programming

3. capitalize(), title() and swapcase()

capitalize()

String madhil pahile character capital ani urlele characters lowercase karnyasathi vapartat. 

text = "hello PYTHON"

print(text.capitalize())
Output: 
Hello python

title()

Pratyek word cha pahila character capital karnyasathi title() vapartat. 

text = "python programming language"

print(text.title())
Output: 
Python Programming Language

swapcase()

Capital letters small ani small letters capital karnyasathi vapartat. 

text = "PyThOn"

print(text.swapcase())
Output: 
pYtHoN

4. strip(), lstrip() and rstrip()

String chya suruvatila kiwa shevati extra spaces astil tar te remove karnyasathi ya methods vapartat.

strip()

Donhi bajuche extra spaces remove karto.

text = "   Hello Python   "

print(text.strip())
Output: 
Hello Python

lstrip()

Fakt left side che spaces remove karto.

text = "   Hello"

print(text.lstrip())
Output: 
Hello

rstrip()

Fakt right side che spaces remove karto.

text = "Hello   "

print(text.rstrip())
Output: 
Hello
Lakshat Theva: strip() string chya madhil spaces remove karat nahi.

5. replace()

String madhil ek text dusrya text ne replace karnyasathi replace() vapartat. 

text = "I like Java"

new_text = text.replace("Java", "Python")

print(new_text)
Output: 
I like Python

replace() madhye optional third argument deun kiti replacements karayche te tharavta yete. 

text = "apple apple apple"

print(text.replace("apple", "mango", 2))
Output: 
mango mango apple

6. find() and index()

find()

String madhye specific word kiwa character kuthe aahe he shodhnayasathi find() vapartat. Ha method pahilya matching character cha index return karto. 

text = "Python Programming"

print(text.find("Pro"))
Output: 
7

Search kelelela text sapadla nahi tar find() -1 return karto. 

text = "Python"

print(text.find("Java"))
Output: 
-1

index()

index() suddha substring cha index return karto. Pan substring sapadla nahi tar ValueError error deto. 

text = "Python"

print(text.index("t"))
Output: 
2
Important Difference: find() text na sapadlyas -1 return karto, tar index() ValueError raise karto.

7. count()

String madhye specific character kiwa word kiti vela aala aahe he mojnyasathi count() vapartat. 

text = "banana"

print(text.count("a"))
Output: 
3

Dusre example:

text = "python python java"

print(text.count("python"))
Output: 
2

8. startswith() and endswith()

startswith()

String specific text ne suru hote ka he check karto. Result True kiwa False asto. 

text = "Python Programming"

print(text.startswith("Python"))
Output: 
True

endswith()

String specific text ne end hote ka he check karto. 

filename = "notes.pdf"

print(filename.endswith(".pdf"))
Output: 
True

9. split()

Ek string vegveglya parts madhye divide karun list tayar karnyasathi split() vapartat. 

text = "Python Java Django"

result = text.split()

print(result)
Output: 
['Python', 'Java', 'Django']

Aapan separator suddha deu shakto. 

text = "apple,mango,banana"

result = text.split(",")

print(result)
Output: 
['apple', 'mango', 'banana']
Important: split() method list return karto. To original string change karat nahi.

10. join()

List madhil strings ekatra jodnyasathi join() vapartat. 

words = ["Python", "is", "easy"]

result = " ".join(words)

print(result)
Output: 
Python is easy

Aapan vegvegale separators suddha vapru shakto. 

words = ["2026", "11", "15"]

result = "-".join(words)

print(result)
Output: 
2026-11-15
Note: join() madhye iterable madhil elements strings asne avashyak aahe. Numbers astil tar aadhi tyanna string madhye convert kara.

11. String Checking Methods

String madhye kontya prakarchya characters aahet he check karnyasathi ya methods vapartat.

isalpha()

String madhye fakt letters aahet ka te check karto.

text = "Python"

print(text.isalpha())
Output: 
True

isdigit()

String madhye digits aahet ka te check karto.

text = "12345"

print(text.isdigit())
Output: 
True

isalnum()

String madhye fakt letters ani digits aahet ka te check karto.

text = "Python123"

print(text.isalnum())
Output: 
True

isspace()

String madhye fakt whitespace characters aahet ka te check karto.

text = "   "

print(text.isspace())
Output: 
True

13. Common Beginner Mistakes

Mistake 1: Method la brackets na dene

text = "hello"

print(text.upper)

He method call nahi. Method execute karnyasathi brackets lagtat.

print(text.upper())

Mistake 2: Original string change hote ase samajne

text = "hello"

text.upper()

print(text)

Output hello yeil. Karan upper() cha result variable madhye save kelela nahi. 

text = text.upper()

print(text)

Mistake 3: join() madhye number vaprane

numbers = ["10", "20", "30"]

print("-".join(numbers))

join() la strings asne avashyak aahe. Numbers direct dile tar TypeError yeu shakto.

15. Practical Task – Username Cleaner

User kadun username input ghe. Extra spaces remove kar, lowercase madhye convert kar ani username display kar. 

username = input("Enter username: ")

username = username.strip()
username = username.lower()

print("Username:", username)
Example Output: 
Enter username:    ROHAN123

Username: rohan123

Ya practical madhye input(), strip() ani lower() ya tin concepts cha use kela aahe.
