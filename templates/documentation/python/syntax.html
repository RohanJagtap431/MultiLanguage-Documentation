PYTHON BASICS · LESSON 03

Python Syntax

Python madhye code kasa lihaycha, tyache rules kay aahet ani Python program kasa samjun gheto he ya lesson madhye shiku.

📘 Beginner Level ⏱️ 15–20 Minutes

1. What is Python Syntax?

Syntax mhanje programming language madhye code lihinyache rules.

Jase English language madhye sentence lihitana kahi grammar rules follow karave lagtat, tasech Python madhye program lihitana syntax rules follow karave lagtat.

Simple Example:

Apan computer la Hello display karayla sangnar asu, tar Python madhye khalil code lihito: 

print("Hello")

Ha Python cha valid syntax aahe.

2. Writing Your First Statement

Python madhye ek instruction lihili tar tila statement mhantat.

Khalil example madhye print() he statement aahe. Yachya madatine apan screen var message display karu shakto.

Example:

print("Welcome to Python")
print("I am learning programming")

Output:

Welcome to Python
I am learning programming

Python madhye statements sadharanpane navin line var lihitat. Varil code madhye don statements aahet, mhanun donhi messages vegveglya lines var display hotat.

3. Indentation in Python

Indentation mhanje code chya suruvatila dileli space. Python madhye indentation cha vapar code blocks olakhnyasathi hoto.

Code block mhanje ekach group madhye yenarya statements cha group.

Correct Example:

if 10 > 5:
    print("10 is greater than 5")
    print("Condition is True")

Output:

10 is greater than 5
Condition is True

Explanation:

  • if condition check karanyasathi vapartat.
  • 10 > 5 hi condition aahe.
  • : colon sangto ki pudhe code block suru honar aahe.
  • Donhi print statements chya suruvatila spaces aahet. Mhanun tya if block madhye yetat.
Important Rule:

Python madhye indentation mahatvache aahe. Sadharanpane eka block sathi 4 spaces vapartat. Ekach block madhil statements chi indentation saman asavi.

Incorrect Example:

if 10 > 5:
print("Hello")

Ya code madhye print statement la indentation dileli nahi. Mhanun Python IndentationError deu shakto.

4. Python is Case-Sensitive

Case-sensitive mhanje capital letters ani small letters yanna vegvegale samajle jate.

Python madhye print ani Print he don vegale names aahet.

Correct Example:

print("Hello Python")

Output:

Hello Python

Incorrect Example:

Print("Hello Python")

Print he Python madhil built-in print function che barobar nav nahi. Mhanun ha code NameError deu shakto.

Tip:

Python madhye function, variable ani keywords lihitana capital ani small letters kalajipurvak vapra.

5. Using Quotation Marks

Python madhye text lihinyasathi quotation marks vapartat. Text la programming madhye string mhantat.

String lihinyasathi single quotes (' ') kiwa double quotes (" ") vaparta yetat.

Example 1: Double Quotes

print("Hello World")

Example 2: Single Quotes

print('Hello World')

Output:

Hello World
Hello World

Donhi examples valid aahet. Fakt opening ani closing quotation marks julale pahijet.

Common Mistake:

String suru kartana double quote ani shevti single quote vaparlyas syntax error yeu shakto. 

print("Hello World')

6. Use of Colon (:)

Python madhye kahi statements nantar colon (:) vapartat. Colon mule pudhe ek code block suru honar aahe he samajte.

Udaharanarth if, for, while ani function definition yanchya nantar colon vapartat.

Example:

if 5 > 2:
    print("Five is greater")

Output:

Five is greater

Ya example madhye if condition nantar colon aahe. Tyachyanantar indentation dilela print statement if block madhye execute hoto.

7. Multiple Statements

Python madhye ekach program madhye anek statements lihita yetat.

Beginner sathi pratyek statement vegveglya line var lihine hi changli paddhat aahe.

Example:

print("My Name is Rohan")
print("I am learning Python")
print("My Goal is Backend Developer")

Output:

My Name is Rohan
I am learning Python
My Goal is Backend Developer

8. Semicolon in Python

Python madhye semicolon (;) vaprun ekach line var don statements lihita yetat.

Example:

print("Hello"); print("Python")

Output:

Hello
Python

Pan beginner ne pratyek statement vegveglya line var lihava. Yamule code vachayla ani samjayla sopa hoto.

Remember:

Python madhye semicolon bahutek normal programs madhye avashyak nasto.

9. Common Syntax Errors

Code lihitana rules follow kele nahi tar Python error dakhavu shakto. Ashya errors na syntax-related errors mhantat.

1. Missing Closing Bracket

print("Hello"

Solution: Opening bracket la matching closing bracket dya.

2. Missing Quotation Mark

print("Hello)

Solution: String cha closing quotation mark lava.

3. Missing Colon

if 10 > 5
    print("True")

Solution: if condition chya shevti colon lava.

4. Incorrect Indentation

if 10 > 5:
print("True")

Solution: Code block madhil statement la yogya indentation dya.
