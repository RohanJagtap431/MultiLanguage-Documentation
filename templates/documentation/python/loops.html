Python Loops

Loops cha use ekach code multiple times execute karnyasathi hoto. For loop ani While loop vaprun repetitive tasks easily karta yetat.

📘 Level: Beginner ⏱️ Time: 40–50 Minutes

1. What are Loops?

Python madhye Loop ha control flow statement aahe. Tyacha use ekach code punha-punha execute karnyasathi hoto.

Samja aaplyala Hello 5 times print karaycha aahe. Loop nasel tar print() 5 vela lihava lagel. Loop vaparlyas code ekdach lihava lagto.

Without Loop

print("Hello")
print("Hello")
print("Hello")
print("Hello")
print("Hello")

With Loop

for i in range(5):
    print("Hello")
Output: 
Hello
Hello
Hello
Hello
Hello
Samjun ghe: Loop mule repetitive code kami hoto ani program maintain karne sope hote.

2. Types of Loops in Python

Python madhye mainly don types che loops aahet:

Loop Use
for loop Sequence kiwa iterable madhil items var iterate karto.
while loop Condition True aseparyant code execute karto.

3. for Loop

for loop cha use list, tuple, string, dictionary ani itar iterable madhil items ek-ek karun access karnyasathi hoto.

Syntax

for variable in sequence:
    # Code to execute

Example – Print Numbers

numbers = [10, 20, 30, 40]

for num in numbers:
    print(num)
Output: 
10
20
30
40

Example – Loop Through a String

name = "Python"

for letter in name:
    print(letter)
Output: 
P
y
t
h
o
n
Samjun ghe: for loop pratyek iteration madhye sequence madhil pudhcha item variable madhye store karto.

4. range() Function

range() function numbers chi sequence tayar karto. for loop sobat specific number of times code execute karnyasathi yacha use hoto.

Example 1 – range(stop)

for i in range(5):
    print(i)
Output: 
0
1
2
3
4

range(5) madhye counting 0 pasun suru hote ani 5 chya aadhi stop hote.

Example 2 – range(start, stop)

for i in range(1, 6):
    print(i)
Output: 
1
2
3
4
5

range(1, 6) madhye start 1 aahe ani stop 6 aahe. 6 output madhye include hot nahi.

Example 3 – range(start, stop, step)

for i in range(2, 11, 2):
    print(i)
Output: 
2
4
6
8
10

Step 2 aslyamule pratyek veli number madhye 2 add hote.

Example 4 – Reverse Counting

for i in range(5, 0, -1):
    print(i)
Output: 
5
4
3
2
1
Syntax Meaning
range(5)0 te 4
range(1, 6)1 te 5
range(2, 11, 2)2, 4, 6, 8, 10
range(5, 0, -1)5 te 1 reverse
Important: range() madhye stop value include hot nahi. Step value negative asel tar reverse counting karta yete.

5. while Loop

while loop condition True aseparyant code execute karto. Condition False zalyavar loop stop hoto.

Syntax

while condition:
    # Code to execute

Example – Print 1 to 5

i = 1

while i <= 5:
    print(i)
    i += 1
Output: 
1
2
3
4
5

Code Explanation

  • i = 1 – Counting 1 pasun suru hote.
  • i <= 5 – Condition check hote.
  • print(i) – Current number print hoto.
  • i += 1 – i chi value 1 ne increase hote.
Warning: while loop madhye condition False honar nahi ashi situation asel tar infinite loop tayar hou shakto.

6. Difference Between for and while Loop

for Loop while Loop
Iterable var iterate karto. Condition True aseparyant chalto.
Items kiwa iterations mahit astil tevha useful. Loop kiti vela chalel he condition var depend asel tevha useful.
Automatic next item gheto. Condition ani update swatah manage karave lagtat.
Tip: List madhil items access karayche astil tar for loop natural choice aahe. Condition var depend aslela repetition asel tar while loop useful aahe.

7. Loop Through a List

List madhil pratyek item access karnyasathi for loop vaparta yeto.

    print(fruit)

Banana

Loop Through a Dictionary

student = {
    "name": "Rohan",
    "age": 20,
    "course": "Python"

age : 20
course : Python

8. Nested Loops

Ek loop chya aat dusra loop lihila tar tyala Nested Loop mhantat.

Outer loop chi pratyek iteration zalyavar inner loop purn execute hoto.

Syntax

for i in sequence:
    for j in sequence:
        # Code to execute

Example – Multiplication Pattern

for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)
Output: 
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3

Example – Star Pattern

for i in range(1, 5):
    for j in range(i):
        print("*", end=" ")
    print()
Output: 
*
* *
* * *
* * * *
Samjun ghe: Outer loop rows control karto ani inner loop pratyek row madhil stars print karto.

9. Loop with Conditions

Loop chya aat if condition vaprun specific items filter karu shakto.

Example – Even Numbers

for i in range(1, 11):
    if i % 2 == 0:
        print(i)
Output: 
2
4
6
8
10

Example – Odd Numbers

for i in range(1, 11):
    if i % 2 != 0:
        print(i)
Output: 
1
3
5
7
9

Example – Sum of Numbers

total = 0

for i in range(1, 6):
    total += i

print("Total:", total)
Output: 
Total: 15

10. enumerate() Function

List madhil item sobat tyacha index suddha pahije asel tar enumerate() vaparta yete. 

fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
Output: 
0 Apple
1 Banana
2 Mango

Index 1 pasun suru karaycha asel tar start argument deta yete. 

fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits, start=1):
    print(index, fruit)
Output: 
1 Apple
2 Banana
3 Mango

11. zip() Function

Don kiwa adhik iterables madhil corresponding items ekatra access karnyasathi zip() vapartat. 

names = ["Rohan", "Amit", "Priya"]
marks = [85, 90, 95]

for name, mark in zip(names, marks):
    print(name, mark)
Output: 
Rohan 85
Amit 90
Priya 95
Important: zip() sadharanpane shortest iterable samplyavar thambto.

12. else with Loops

Python madhye for ani while loop sobat else block vaparta yeto. Loop normal paddhatine complete zala tar else execute hoto.

Example – for-else

for i in range(3):
    print(i)
else:
    print("Loop Completed")
Output: 
0
1
2
Loop Completed

Example – while-else

i = 1

while i <= 3:
    print(i)
    i += 1
else:
    print("Loop Completed")
Output: 
1
2
3
Loop Completed
Note: break mule loop terminate zala tar loop cha else block execute hot nahi. Normal completion zalyas else execute hoto.

13. Infinite Loop

Loop chi condition nehmi True rahili tar loop continuously execute hot rahato. Tyala Infinite Loop mhantat.

Example

while True:
    print("Hello")

Ya program madhye condition True aahe ani ti change hot nahi. Mhanun loop swatah thambat nahi.

Warning: Ha example run kelyas output continuously print hot rahil. Terminal madhye Ctrl + C press karun program stop kar.

14. Common Beginner Mistakes

Mistake 1: Infinite while Loop

i = 1

while i <= 5:
    print(i)

i chi value update hot nahi. Mhanun condition nehmi True rahte. 

i = 1

while i <= 5:
    print(i)
    i += 1

Mistake 2: Wrong range() Stop Value

for i in range(1, 5):
    print(i)

Ya code madhye 5 print hot nahi karan stop value include hot nahi. 

for i in range(1, 6):
    print(i)

Mistake 3: Missing Colon

for i in range(5)
    print(i)

for kiwa while statement nantar colon dene avashyak aahe. 

for i in range(5):
    print(i)

Mistake 4: Wrong Indentation

for i in range(5):
print(i)

Loop chya aatil statement la indentation dene avashyak aahe. 

for i in range(5):
    print(i)

17. Practical Task – Student Marks Calculator

total = 0

for mark in marks:
    print("Marks:", mark)
    total += mark

print("Total Marks:", total)
print("Average:", total / len(marks))

Marks: 80
Marks: 65
Marks: 90
Marks: 85
