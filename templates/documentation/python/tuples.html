Python Tuples

Tuple cha use multiple values ekach variable madhye store karnyasathi hoto. Pan List peksha Tuple madhye ek important difference aahe: Tuple immutable asto.

📘 Level: Beginner ⏱️ Time: 30–40 Minutes

1. What is a Tuple?

Python madhye Tuple ha collection data type aahe. Tyat aapan multiple values ekach variable madhye store karu shakto.

Tuple create karnyasathi round brackets () vapartat. Tuple madhil elements comma ne separate kele jatat. 

fruits = ("Apple", "Mango", "Banana")

print(fruits)
Output: 
('Apple', 'Mango', 'Banana')
Important: Tuple ordered asto ani tyat duplicate values suddha store karta yetat.

2. Features of Tuple

  • Ordered: Elements cha order maintain hoto.
  • Immutable: Tuple create kelyanantar tyatil elements change karta yet nahit.
  • Duplicates: Same value multiple times store karta yete.
  • Different Data Types: Vegvegale data types ekach Tuple madhye store karta yetat.
  • Indexed: Pratyek element la index number asto.
student = ("Rohan", 20, 85.5, True)

print(student)
Output: 
('Rohan', 20, 85.5, True)

3. Creating a Tuple

Example 1: String Tuple

fruits = ("Apple", "Mango", "Banana")

print(fruits)
Output: 
('Apple', 'Mango', 'Banana')

Example 2: Number Tuple

numbers = (10, 20, 30, 40, 50)

print(numbers)
Output: 
(10, 20, 30, 40, 50)

Example 3: Mixed Data Types

data = ("Python", 100, 25.5, True)

print(data)
Output: 
('Python', 100, 25.5, True)

Example 4: Empty Tuple

items = ()

print(items)
Output: 
()

Example 5: Single Element Tuple

Single element Tuple create kartana value nantar comma dene avashyak aahe. 

number = (10,)

print(number)
print(type(number))
Output: 
(10,)
<class 'tuple'>
Important: (10) ha integer aahe, Tuple nahi. (10,) ha single-element Tuple aahe.

4. Tuple Indexing

Tuple madhil pratyek element la index number asto. Indexing 0 pasun start hote. 

fruits = ("Apple", "Mango", "Banana", "Orange")

print(fruits[0])
print(fruits[1])
print(fruits[2])
print(fruits[3])
Output: 
Apple
Mango
Banana
Orange

Negative Indexing

Negative indexing madhye last element cha index -1 asto. 

fruits = ("Apple", "Mango", "Banana", "Orange")

print(fruits[-1])
print(fruits[-2])
Output: 
Orange
Banana

Index Position Table

Element Positive Index Negative Index
Apple0-4
Mango1-3
Banana2-2
Orange3-1

5. Tuple Slicing

Tuple madhun ekapeksha jast elements select karnyasathi slicing vapartat.

Syntax:

tuple_name[start : stop : step]

Example 1: Basic Slicing

numbers = (10, 20, 30, 40, 50)

print(numbers[1:4])
Output: 
(20, 30, 40)

Example 2: Start Omitted

numbers = (10, 20, 30, 40, 50)

print(numbers[:3])
Output: 
(10, 20, 30)

Example 3: Stop Omitted

numbers = (10, 20, 30, 40, 50)

print(numbers[2:])
Output: 
(30, 40, 50)

Example 4: Reverse Tuple

numbers = (10, 20, 30, 40, 50)

print(numbers[::-1])
Output: 
(50, 40, 30, 20, 10)
Important: Slicing madhye stop index include hot nahi. Slicing cha result Tuple asto.

6. Tuple is Immutable

Immutable mhanje Tuple create kelyanantar tyatil existing elements direct change, add kiwa remove karta yet nahit. 

fruits = ("Apple", "Mango", "Banana")

fruits[1] = "Orange"

print(fruits)
Output: 
TypeError: 'tuple' object does not support item assignment

Varil code madhye aapan index 1 varil value change karnyacha prayatna kela. Pan Tuple immutable aslyamule error yeto.

Tip: Data create kelyanantar tyat changes karayche nasatil tar Tuple useful tharu shakto.

7. Important Tuple Methods

Tuple madhye List peksha methods kami astat. Tyatil don important methods mhanje count() ani index().

count()

Tuple madhye specific value kiti vela aali aahe he mojnyasathi count() vapartat. 

numbers = (10, 20, 10, 30, 10)

print(numbers.count(10))
Output: 
3

index()

Specific value cha pahila index shodhnayasathi index() vapartat. 

fruits = ("Apple", "Mango", "Banana")

print(fruits.index("Mango"))
Output: 
1
Note: index() madhye value sapadli nahi tar ValueError error yeto.

8. len() Function

Tuple madhye kiti elements aahet he count karnyasathi len() function vapartat. 

fruits = ("Apple", "Mango", "Banana", "Orange")

print(len(fruits))
Output: 
4
Note: len() hi Python built-in function aahe. Ti Tuple method nahi.

9. Tuple Packing

Multiple values ekatra lihun Tuple tayar karnyachya process la Tuple Packing mhantat. 

student = "Rohan", 20, "Computer Science"

print(student)
print(type(student))
Output: 
('Rohan', 20, 'Computer Science')
<class 'tuple'>

Yethe values comma ne separate kelyamule Python ne Tuple tayar kela. Round brackets optional aahet.

10. Tuple Unpacking

Tuple madhil values vegveglya variables madhye assign karnyachya process la Tuple Unpacking mhantat. 

student = ("Rohan", 20, "Computer Science")

name, age, course = student

print(name)
print(age)
print(course)
Output: 
Rohan
20
Computer Science
Important: Unpacking kartana variables chi sankhya Tuple madhil elements chya sankhyeitki asavi. Nahi tar ValueError yeu shakto.

Using Asterisk (*)

Asterisk (*) vaprun remaining values ekach list madhye collect karta yetat. 

numbers = (10, 20, 30, 40, 50)

first, *middle, last = numbers

print(first)
print(middle)
print(last)
Output: 
10
[20, 30, 40]
50

11. Looping Through a Tuple

Tuple madhil pratyek element ek-ek karun access karnyasathi for loop vapartat. 

fruits = ("Apple", "Mango", "Banana")

for fruit in fruits:
    print(fruit)
Output: 
Apple
Mango
Banana

Using range() and len()

fruits = ("Apple", "Mango", "Banana")

for i in range(len(fruits)):
    print(i, fruits[i])
Output: 
0 Apple
1 Mango
2 Banana

12. Membership Operators

Tuple madhye specific value present aahe ka he check karnyasathi in ani not in operators vapartat. 

fruits = ("Apple", "Mango", "Banana")

print("Mango" in fruits)
print("Orange" not in fruits)
Output: 
True
True

13. Tuple Concatenation and Repetition

Concatenation (+)

Don Tuples ekatra jodnyasathi + operator vapartat. 

tuple1 = (10, 20)
tuple2 = (30, 40)

result = tuple1 + tuple2

print(result)
Output: 
(10, 20, 30, 40)

Repetition (*)

Tuple madhil elements multiple times repeat karnyasathi * operator vapartat. 

numbers = (10, 20)

result = numbers * 3

print(result)
Output: 
(10, 20, 10, 20, 10, 20)

14. Difference Between List and Tuple

List Tuple
Square brackets [] vapartat. Round brackets () vapartat.
Mutable asto. Immutable asto.
Elements change karta yetat. Elements direct change karta yet nahit.
Methods jast available aahet. count() ani index() he main methods aahet.
Dynamic data sathi useful. Fixed collection sathi useful.
Example: Shopping cart madhil items change hot astil tar List useful. Fixed coordinates kiwa fixed settings sathi Tuple useful tharu shakto.

15. Converting List into Tuple

List la Tuple madhye convert karnyasathi tuple() function vapartat. 

fruits = ["Apple", "Mango", "Banana"]

result = tuple(fruits)

print(result)
print(type(result))
Output: 
('Apple', 'Mango', 'Banana')
<class 'tuple'>

Converting Tuple into List

Tuple la List madhye convert karnyasathi list() function vapartat. 

numbers = (10, 20, 30)

result = list(numbers)

print(result)
print(type(result))
Output: 
[10, 20, 30]
<class 'list'>

16. Common Beginner Mistakes

Mistake 1: Single Element Tuple madhye comma visarne

number = (10)

print(type(number))

Ha Tuple nahi. Ha integer aahe. 

number = (10,)

print(type(number))

Mistake 2: Tuple madhil value change karne

numbers = (10, 20, 30)

numbers[0] = 100

Tuple immutable aslyamule item assignment karta yet nahi.

Mistake 3: Unpacking madhye values mismatch hone

numbers = (10, 20, 30)

a, b = numbers

Tuple madhye 3 values aahet, pan variables 2 aahet. Mhanun ValueError yeil.
