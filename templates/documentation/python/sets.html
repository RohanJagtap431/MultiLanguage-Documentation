Python Sets

Set cha use unique values store karnyasathi hoto. Set madhye duplicate elements store hot nahit.

📘 Level: Beginner ⏱️ Time: 35–45 Minutes

1. What is a Set?

Python madhye Set ha collection data type aahe. Set cha use multiple unique values ekach variable madhye store karnyasathi hoto.

Set create karnyasathi curly brackets {} vapartat. Set madhye duplicate values automatically remove hotat. 

numbers = {10, 20, 30, 40}

print(numbers)
Example Output: 
{10, 20, 30, 40}
Important: Set madhye elements cha fixed order nasto. Mhanun output madhil elements cha order badlu shakto.

2. Features of Set

  • Unordered: Elements cha fixed position kiwa order nasto.
  • Unique Values: Duplicate values store hot nahit.
  • Mutable: Elements add ani remove karta yetat.
  • Unindexed: Index number vaprun elements access karta yet nahit.
  • Different Data Types: Compatible different data types store karta yetat.
data = {"Python", 100, 25.5, True}

print(data)
Example Output: 
{'Python', 100, 25.5, True}
Note: Set madhye list, dictionary kiwa dusra mutable set element mhanun store karta yet nahi. Immutable values ani tuples (tyatil elements hashable aslyas) vaparta yetat.

3. Creating a Set

Example 1: Number Set

numbers = {10, 20, 30, 40}

print(numbers)
Example Output: 
{10, 20, 30, 40}

Example 2: String Set

fruits = {"Apple", "Mango", "Banana"}

print(fruits)
Example Output: 
{'Apple', 'Mango', 'Banana'}

Example 3: Duplicate Values

Set madhye same value multiple times dili tari ti fakt ekdach store hote. 

numbers = {10, 20, 10, 30, 20, 40}

print(numbers)
Example Output: 
{10, 20, 30, 40}

Example 4: Empty Set

Empty Set create karnyasathi set() vapartat. 

items = set()

print(items)
print(type(items))
Output: 
set()
<class 'set'>
Important: {} ha empty dictionary asto, empty Set nahi. Empty Set sathi set() vapra.

4. Set Does Not Support Indexing

List ani Tuple madhye indexing vaprun elements access karta yetat. Pan Set unordered aslyamule indexing support karat nahi. 

fruits = {"Apple", "Mango", "Banana"}

print(fruits[0])
Output: 
TypeError: 'set' object is not subscriptable

Set madhil elements access karnyasathi for loop vapra. 

fruits = {"Apple", "Mango", "Banana"}

for fruit in fruits:
    print(fruit)
Example Output: 
Apple
Mango
Banana
Note: Set cha output order vegla asu shakto. Varil output fakt example aahe.

5. Adding Elements to a Set

add()

Set madhye ek navin element add karnyasathi add() vapartat. 

fruits = {"Apple", "Mango"}

fruits.add("Banana")

print(fruits)
Example Output: 
{'Apple', 'Mango', 'Banana'}

update()

Dusrya iterable madhil multiple elements Set madhye add karnyasathi update() vapartat. 

fruits = {"Apple", "Mango"}

fruits.update(["Banana", "Orange"])

print(fruits)
Example Output: 
{'Apple', 'Mango', 'Banana', 'Orange'}
Difference: add() ek element add karto. update() iterable madhil elements add karto.

6. Removing Elements from a Set

remove()

Specific element remove karnyasathi remove() vapartat. Element available nasel tar KeyError yeto. 

fruits = {"Apple", "Mango", "Banana"}

fruits.remove("Mango")

print(fruits)
Example Output: 
{'Apple', 'Banana'}

discard()

Specific element remove karnyasathi discard() suddha vapartat. Pan element available nasel tari error yet nahi. 

fruits = {"Apple", "Mango", "Banana"}

fruits.discard("Orange")

print(fruits)
Example Output: 
{'Apple', 'Mango', 'Banana'}

pop()

pop() Set madhil ek arbitrary element remove karto ani to element return karto. 

numbers = {10, 20, 30}

removed = numbers.pop()

print("Removed:", removed)
print("Remaining:", numbers)
Example Output: 
Removed: 10
Remaining: {20, 30}

Pop() konta element remove karel he fixed nasto. Output machine ani Set madhil arrangement nusar badlu shakto.

clear()

Set madhil sarva elements remove karnyasathi clear() vapartat. 

numbers = {10, 20, 30}

numbers.clear()

print(numbers)
Output: 
set()

7. Set Union

Don Sets madhil sarva unique elements ekatra milavnyasathi Union vapartat.

Method: union()

set1 = {10, 20, 30}
set2 = {30, 40, 50}

result = set1.union(set2)

print(result)
Example Output: 
{10, 20, 30, 40, 50}

Union sathi | operator suddha vapru shakto. 

set1 = {10, 20, 30}
set2 = {30, 40, 50}

print(set1 | set2)
Example Output: 
{10, 20, 30, 40, 50}

8. Set Intersection

Don Sets madhye common elements milavnyasathi Intersection vapartat.

Method: intersection()

set1 = {10, 20, 30}
set2 = {20, 30, 40}

result = set1.intersection(set2)

print(result)
Output: 
{20, 30}

Intersection sathi & operator suddha vaparta yeto. 

set1 = {10, 20, 30}
set2 = {20, 30, 40}

print(set1 & set2)
Output: 
{20, 30}

9. Set Difference

Pahilya Set madhil ase elements je dusrya Set madhye nahit, te milavnyasathi difference() vapartat. 

set1 = {10, 20, 30}
set2 = {20, 30, 40}

result = set1.difference(set2)

print(result)
Output: 
{10}

Difference sathi - operator suddha vapru shakto. 

set1 = {10, 20, 30}
set2 = {20, 30, 40}

print(set1 - set2)
Output: 
{10}
Important: set1 - set2 ani set2 - set1 yanche results vegvegale asu shaktat. Difference operation directional aahe.

10. Symmetric Difference

Don Sets madhil common elements sodun urlele unique elements milavnyasathi symmetric_difference() vapartat. 

set1 = {10, 20, 30}
set2 = {20, 30, 40}

result = set1.symmetric_difference(set2)

print(result)
Output: 
{10, 40}

Symmetric difference sathi ^ operator vaparta yeto. 

set1 = {10, 20, 30}
set2 = {20, 30, 40}

print(set1 ^ set2)
Output: 
{10, 40}

11. Subset and Superset

issubset()

Ek Set madhil sarva elements dusrya Set madhye aahet ka he check karnyasathi issubset() vapartat. 

set1 = {10, 20}
set2 = {10, 20, 30, 40}

print(set1.issubset(set2))
Output: 
True

issuperset()

Ek Set madhye dusrya Set che sarva elements aahet ka he check karnyasathi issuperset() vapartat. 

set1 = {10, 20, 30, 40}
set2 = {10, 20}

print(set1.issuperset(set2))
Output: 
True

12. Membership Operators

Set madhye specific element aahe ka he check karnyasathi in ani not in vapartat. 

fruits = {"Apple", "Mango", "Banana"}

print("Mango" in fruits)
print("Orange" not in fruits)
Output: 
True
True

13. len() Function

Set madhye kiti unique elements aahet he count karnyasathi len() function vapartat. 

numbers = {10, 20, 30, 40}

print(len(numbers))
Output: 
4

14. Removing Duplicates from a List

List madhye duplicate values astil tar set() vaprun unique values milavta yetat. 

numbers = [10, 20, 10, 30, 20, 40]

unique_numbers = set(numbers)

print(unique_numbers)
Example Output: 
{10, 20, 30, 40}

Punha List havi asel tar set la list madhye convert karu shakto. 

numbers = [10, 20, 10, 30, 20, 40]

unique_numbers = list(set(numbers))

print(unique_numbers)
Example Output: 
[10, 20, 30, 40]
Important: Set madhye order maintain hot nahi. Original List madhil order preserve karaycha asel tar dict.fromkeys() vaparta yete.

15. Common Beginner Mistakes

Mistake 1: Empty Set sathi {} vaprane

items = {}

print(type(items))

He empty Dictionary create karte, Set nahi. 

items = set()

print(type(items))

Mistake 2: Indexing vaprane

numbers = {10, 20, 30}

print(numbers[0])

Set madhye indexing support hot nahi. Elements access karnyasathi loop vapra.

Mistake 3: remove() ne absent value remove karne

numbers = {10, 20, 30}

numbers.remove(50)

50 Set madhye nahi, mhanun KeyError yeil. Error avoid karnyasathi discard() vapru shakto.

Mistake 4: Set madhye List add karne

data = {10, 20, [30, 40]}

List mutable ani unhashable aslyamule tila Set madhye element mhanun add karta yet nahi.

18. Practical Task – Unique Student Subjects

Don students kontya subjects madhye interested aahet te vegveglya Sets madhye store kar. Common subjects ani sagle unique subjects find kar. 

student1 = {"Python", "Java", "C++"}
student2 = {"Python", "Django", "JavaScript"}

common = student1.intersection(student2)
all_subjects = student1.union(student2)

print("Common Subjects:", common)
print("All Subjects:", all_subjects)
Example Output: 
Common Subjects: {'Python'}
All Subjects: {'Python', 'Java', 'C++', 'Django', 'JavaScript'}

Ya practical madhye intersection() ani union() ya don important Set operations cha use kela aahe.
