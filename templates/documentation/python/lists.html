PYTHON • LESSON 12

Python Lists

List cha use karun aapan multiple values ekach variable madhye store, access, update ani manage karu shakto.

📘 Level: Beginner ⏱️ Time: 35–45 Minutes

1. What is a List?

Python madhye List ha data type aahe. List cha use multiple values ekach variable madhye store karnyasathi hoto.

Udaharanarth, aaplyala 5 students chi nave store karaychi astil, tar pratyek navasathi vegla variable banavnyachi garaj nahi. Aapan ekach list vapru shakto. 

students = ["Rohan", "Amit", "Priya", "Sneha", "Rahul"]

print(students)
Output: 
['Rohan', 'Amit', 'Priya', 'Sneha', 'Rahul']
Important: Python madhye List square brackets [] madhye lihitat. Pratyek element comma ne separate karto.

2. Features of List

Python List chi important features:

  • Ordered: Elements cha order maintain hoto.
  • Mutable: List madhil elements change karta yetat.
  • Duplicates: Same value multiple times store karta yete.
  • Different Data Types: Ekach list madhye vegvegale data types thevta yetat.
  • Dynamic: List madhye elements add ani remove karta yetat.
data = ["Rohan", 21, 85.5, True, "Rohan"]

print(data)
Output: 
['Rohan', 21, 85.5, True, 'Rohan']

3. Creating a List

List create karnyasathi square brackets [] vapartat.

Example 1: String List

fruits = ["Apple", "Mango", "Banana"]

print(fruits)
Output: 
['Apple', 'Mango', 'Banana']

Example 2: Number List

numbers = [10, 20, 30, 40, 50]

print(numbers)
Output: 
[10, 20, 30, 40, 50]

Example 3: Empty List

items = []

print(items)
Output: 
[]

Example 4: Mixed Data Types

student = ["Rohan", 20, 85.5, True]

print(student)
Output: 
['Rohan', 20, 85.5, True]

4. List Indexing

List madhil pratyek element la ek index number asto. Indexing 0 pasun start hote. 

fruits = ["Apple", "Mango", "Banana", "Orange"]

print(fruits[0])
print(fruits[1])
print(fruits[2])
print(fruits[3])
Output: 
Apple
Mango
Banana
Orange

Index Position Table

Element Positive Index Negative Index
Apple0-4
Mango1-3
Banana2-2
Orange3-1

Negative Indexing

Negative indexing madhye last element cha index -1 asto. Tithun ultya direction ne counting hote. 

fruits = ["Apple", "Mango", "Banana", "Orange"]

print(fruits[-1])
print(fruits[-2])
Output: 
Orange
Banana
Tip: Positive index left pasun start hoto ani negative index right pasun start hoto.

5. List Slicing

List madhun ekapeksha jast elements select karnyasathi slicing vapartat.

Syntax:

list_name[start : stop : step]
  • start: Kontya index pasun suru karayche.
  • stop: Kontya index chya aadhi thambayche.
  • step: Kiti index pudhe jayche.

Example 1: Basic Slicing

numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])
Output: 
[20, 30, 40]

Example 2: Start Omitted

numbers = [10, 20, 30, 40, 50]

print(numbers[:3])
Output: 
[10, 20, 30]

Example 3: Stop Omitted

numbers = [10, 20, 30, 40, 50]

print(numbers[2:])
Output: 
[30, 40, 50]

Example 4: Step

numbers = [10, 20, 30, 40, 50, 60]

print(numbers[::2])
Output: 
[10, 30, 50]

Example 5: Reverse List Using Slicing

numbers = [10, 20, 30, 40, 50]

print(numbers[::-1])
Output: 
[50, 40, 30, 20, 10]
Important: Slicing madhye stop index include hot nahi. numbers[1:4] madhye index 1, 2 ani 3 che elements yetat.

6. Updating List Elements

List mutable aslyamule aapan existing element chi value change karu shakto. 

fruits = ["Apple", "Mango", "Banana"]

fruits[1] = "Orange"

print(fruits)
Output: 
['Apple', 'Orange', 'Banana']

Yethe index 1 varil Mango replace karun Orange thevla aahe.

7. Adding Elements to a List

append()

List chya shevati ek element add karnyasathi append() vapartat. 

fruits = ["Apple", "Mango"]

fruits.append("Banana")

print(fruits)
Output: 
['Apple', 'Mango', 'Banana']

insert()

Specific index position var element add karnyasathi insert() vapartat. 

fruits = ["Apple", "Banana"]

fruits.insert(1, "Mango")

print(fruits)
Output: 
['Apple', 'Mango', 'Banana']

extend()

Dusrya iterable madhil elements list chya shevati add karnyasathi extend() vapartat. 

fruits = ["Apple", "Mango"]
more_fruits = ["Banana", "Orange"]

fruits.extend(more_fruits)

print(fruits)
Output: 
['Apple', 'Mango', 'Banana', 'Orange']
Difference: append() ek object add karto. extend() iterable madhil elements ek-ek karun add karto.

8. Removing Elements from a List

remove()

Specific value remove karnyasathi remove() vapartat. Value sapadli nahi tar ValueError yeto. 

fruits = ["Apple", "Mango", "Banana"]

fruits.remove("Mango")

print(fruits)
Output: 
['Apple', 'Banana']

pop()

pop() specific index varil element remove karto ani removed element return karto. Index na dilyas last element remove karto. 

fruits = ["Apple", "Mango", "Banana"]

removed = fruits.pop(1)

print(removed)
print(fruits)
Output: 
Mango
['Apple', 'Banana']

del

Specific index kiwa list madhil range delete karnyasathi del keyword vapartat. 

numbers = [10, 20, 30, 40]

del numbers[1]

print(numbers)
Output: 
[10, 30, 40]

clear()

List madhil sarva elements remove karnyasathi clear() vapartat. 

numbers = [10, 20, 30]

numbers.clear()

print(numbers)
Output: 
[]

9. Important List Methods

sort()

List madhil elements ascending order madhye arrange karnyasathi sort() vapartat. 

numbers = [40, 10, 30, 20]

numbers.sort()

print(numbers)
Output: 
[10, 20, 30, 40]

Descending order sathi:

numbers = [40, 10, 30, 20]

numbers.sort(reverse=True)

print(numbers)
Output: 
[40, 30, 20, 10]

reverse()

List madhil current order reverse karnyasathi reverse() vapartat. 

numbers = [10, 20, 30, 40]

numbers.reverse()

print(numbers)
Output: 
[40, 30, 20, 10]

index()

Specific value cha pahila index shodhnayasathi index() vapartat. 

fruits = ["Apple", "Mango", "Banana"]

print(fruits.index("Mango"))
Output: 
1

count()

Specific value list madhye kiti vela aahe he mojnyasathi count() vapartat. 

numbers = [10, 20, 10, 30, 10]

print(numbers.count(10))
Output: 
3

copy()

List chi shallow copy tayar karnyasathi copy() vapartat. 

original = [10, 20, 30]

new_list = original.copy()

new_list.append(40)

print(original)
print(new_list)
Output: 
[10, 20, 30]
[10, 20, 30, 40]

10. len() Function

List madhye kiti elements aahet he count karnyasathi len() function vapartat. 

fruits = ["Apple", "Mango", "Banana", "Orange"]

print(len(fruits))
Output: 
4
Note: len() hi built-in function aahe. Ti list method nahi.

11. Looping Through a List

List madhil pratyek element ek-ek karun access karnyasathi for loop vapru shakto. 

fruits = ["Apple", "Mango", "Banana"]

for fruit in fruits:
    print(fruit)
Output: 
Apple
Mango
Banana

Using range() and len()

Index cha use karun suddha list madhil elements access karta yetat. 

fruits = ["Apple", "Mango", "Banana"]

for i in range(len(fruits)):
    print(i, fruits[i])
Output: 
0 Apple
1 Mango
2 Banana

12. Membership Operators in List

List madhye specific element present aahe ka he check karnyasathi in ani not in operators vapartat. 

fruits = ["Apple", "Mango", "Banana"]

print("Mango" in fruits)
print("Orange" not in fruits)
Output: 
True
True

13. Nested Lists

Ek list dusrya list madhye store keli asel tar tila Nested List mhantat. 

students = [
    ["Rohan", 85],
    ["Amit", 90],
    ["Priya", 95]
]

print(students[0])
print(students[0][0])
print(students[0][1])
Output: 
['Rohan', 85]
Rohan
85

students[0] pahili inner list access karte. students[0][0] tya list madhil pahile element access karte.

14. Common Beginner Mistakes

Mistake 1: Wrong Index

fruits = ["Apple", "Mango"]

print(fruits[5])

List madhye index 5 available nahi. Mhanun IndexError yeto.

Mistake 2: append() la multiple arguments dene

numbers = [10, 20]

numbers.append(30, 40)

append() ekach object accept karto. 

numbers.extend([30, 40])

Mistake 3: sort() result variable madhye save karne

numbers = [30, 10, 20]

result = numbers.sort()

print(result)

sort() list la in-place sort karto ani None return karto. Sorted list numbers madhyech aste. 

numbers.sort()

print(numbers)

Mistake 4: remove() madhye index dene

numbers = [10, 20, 30]

numbers.remove(1)

remove() index nahi, value remove karto. Index varil element remove karnyasathi pop() kiwa del vapra.

17. Practical Task – Student Marks Manager

Students che marks list madhye store kar. Tyavarun total, highest marks, lowest marks ani average calculate kar. 

marks = [75, 85, 90, 65, 80]

total = sum(marks)
highest = max(marks)
lowest = min(marks)
average = total / len(marks)

print("Total:", total)
print("Highest:", highest)
print("Lowest:", lowest)
print("Average:", average)
Example Output: 
Total: 395
Highest: 90
Lowest: 65
Average: 79.0
Note: sum(), max() ani min() ya Python built-in functions aahet. Tyanchya madatine list var calculation karta yete.
