PYTHON BASICS · LESSON 01

Introduction to Python

Python programming language chi olakh karun gheu. Python kay aahe, ti ka vapartat ani ticha upyog kuthe hoto he agdi soprya bhashet samjun gheu.

📘 Beginner Level ⏱️ 10–15 Minutes

1. What is Python?

Python hi ek high-level, general-purpose programming language aahe.

Soprya shabdat sangayche tar, computer kadun ekhade kaam karun ghenyasathi apan programming language vaparto. Python hi ashi ek language aahe jichya madatine apan computer la instructions deu shakto.

Simple Example:

Samja aplyala computer kadun don numbers chi addition karun ghyaychi aahe. Tar apan Python madhye code lihun computer la te calculation karayla sangu shakto.

2. Why Learn Python?

Python shiknyachi anek karane aahet. Python chi syntax sopi aahe ani code vachayla tasech lihayla suddha sope aahe.

Python che fayde:

  • Easy to Learn: Python chi syntax beginner-friendly aahe.
  • Readable Code: Python code vachayla ani samjayla sopa aahe.
  • Free and Open Source: Python free madhye vaparta yete.
  • Large Community: Python shikanaryansathi bharpur tutorials ani documentation available aahet.
  • Versatile: Python cha anek vegveglya fields madhye upyog hoto.

3. Where is Python Used?

Python fakt ekach prakarchya software sathi nahi. Ticha anek fields madhye upyog hoto.

🌐

Web Development

Websites ani web applications tayar karanyasathi. Django ani Flask hi Python frameworks aahet.

🤖

Artificial Intelligence

AI applications ani Machine Learning models develop karanyasathi.

📊

Data Science

Data analysis, visualization ani data processing karanyasathi.

⚙️

Automation

Repetitive tasks automatic karanyasathi Python vaparta yete.

4. How Does Python Work?

Programmer Python madhye code lihito. Python interpreter code process karun computer la instructions execute karayla madat karto.

Programmer writes Python Code
↓
Python Interpreter
↓
Program Execution
↓
Output
लक्षात theva:

Interpreter ha Python program execute karanyasathi mahatvacha software component aahe.

5. Your First Python Program

Ata apan Python madhil pahila program baghu. Ya program madhye apan screen var ek message display karanar aahot.

Code:

print("Hello World!")

Explanation:

  • print() hi Python madhil built-in function aahe.
  • Ti screen var output display karanyasathi vapartat.
  • "Hello World!" ha display honara text aahe.

Output:

Hello World!
Congratulations!

Tu ata tuzha pahila Python program samjun ghetla aahe.

7. Common Beginner Mistakes

  • print function che spelling chukiche lihine.
  • Text lihitana quotation marks visarne.
  • Opening ani closing brackets na lavne.
  • Code run na karta fakt copy karne.
