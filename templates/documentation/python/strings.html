10. Python Strings

Python madhye text data store karne, access karne, slice karne ani strings var operations perform karne shikuya.

📘 Beginner Level ⏱️ 25-30 Minutes

1. What is a String?

String mhanje characters cha group kiwa text data. Python madhye string cha use words, sentences, names, emails ani messages store karanyasathi hoto.

Simple Definition: A string is a sequence of characters enclosed in quotes.

String madhye letters, numbers ani symbols asu shaktat.

Example
name = "Rohan"
city = "Kolhapur"
message = "Welcome to Python!"
mobile = "9876543210"

print(name)
print(city)
print(message)
print(mobile)
Output: 
Rohan
Kolhapur
Welcome to Python!
9876543210
Important: Mobile number sarkha data string madhye store karne useful aahe, karan tyavar mathematical calculation karaychi naste.

2. Creating Strings

Python madhye string create karanyasathi single quotes, double quotes kiwa triple quotes vapartat.

1. Single Quotes

name = 'Rohan'

print(name)
Output: 
Rohan

2. Double Quotes

language = "Python"

print(language)
Output: 
Python

3. Triple Quotes

Multiple lines madhye string lihinyasathi triple quotes vapartat. 

message = """Welcome to
Python Programming
Language"""

print(message)
Output: 
Welcome to
Python Programming
Language

3. String Indexing

String madhil pratyek character la ek index number asto. Python madhye indexing 0 pasun suru hote.

Example
name = "PYTHON"

print(name[0])
print(name[1])
print(name[2])
print(name[5])
Output: 
P
Y
T
N

Understanding Index Positions

Character P Y T H O N
Positive Index 0 1 2 3 4 5
Negative Index -6 -5 -4 -3 -2 -1

Negative Indexing

String chya shevatchya character pasun access karanyasathi negative indexing vapartat. 

name = "PYTHON"

print(name[-1])
print(name[-2])
print(name[-3])
Output: 
N
O
H

4. String Slicing

String madhun specific part kiwa characters cha group milavnyasathi slicing vapartat.

Syntax: 
string[start : stop : step]
  • start: Kontya index pasun suru karayche.
  • stop: Kontya index chya aadhi thambayche.
  • step: Kiti index gap ne characters ghyayche.

Example 1 – Basic Slicing

text = "PYTHON"

print(text[0:3])
print(text[2:5])
Output: 
PYT
THO

Example 2 – Start Index Omit Karne

text = "PYTHON"

print(text[:3])
Output: 
PYT

Example 3 – Stop Index Omit Karne

text = "PYTHON"

print(text[2:])
Output: 
THON

Example 4 – Negative Slicing

text = "PYTHON"

print(text[-4:-1])
Output: 
THO

Example 5 – Step Slicing

text = "PYTHON"

print(text[::2])
Output: 
PTO

Example 6 – Reverse String

text = "PYTHON"

print(text[::-1])
Output: 
NOHTYP
Tip: text[::-1] hi string reverse karanyachi ek simple Python technique aahe.

5. String Length – len()

String madhye kiti characters aahet he check karanyasathi len() function vapartat.

Example
name = "Rohan"

print(len(name))
Output: 
5

Length with Spaces

message = "Hello World"

print(len(message))
Output: 
11

Space suddha ek character mhanun count hoto.

6. String Concatenation

Don kiwa adhik strings ekatra join karanyachya process la String Concatenation mhantat.

Concatenation sathi + operator vapartat.

Example
first_name = "Rohan"
last_name = "Jagtap"

full_name = first_name + " " + last_name

print(full_name)
Output: 
Rohan Jagtap
Important: String ani integer direct + operator ne join karta yet nahit. Integer la str() madhye convert kara kiwa f-string vapra.

7. String Repetition

Ekach string anek vela repeat karanyasathi * operator vapartat.

Example
text = "Python "

print(text * 3)
Output: 
Python Python Python

8. Strings are Immutable

Python madhye strings immutable astat. Mhanje string create kelyanantar tyatil character directly change karta yet nahi.

Example
name = "Python"

name[0] = "J"

print(name)
Error: TypeError: 'str' object does not support item assignment

String madhil character change karaycha asel tar navin string create karavi lagte.

Correct Way
name = "Python"

new_name = "J" + name[1:]

print(new_name)
Output: 
Jython

9. Checking String Membership

String madhye specific word kiwa character present aahe ka check karanyasathi in ani not in operators vapartat.

Example
message = "Python Programming"

print("Python" in message)
print("Java" in message)
print("Java" not in message)
Output: 
True
False
True
Remember: String membership check case-sensitive asto. "Python" ani "python" he vegale aahet.

10. Escape Characters

String madhye special characters kiwa formatting use karanyasathi Escape Characters vapartat.

Escape Character Meaning
\n New line
\t Tab space
\\ Backslash
\" Double quote
\' Single quote

Example – New Line

print("Hello\nPython")
Output: 
Hello
Python

Example – Tab Space

print("Name:\tRohan")
Output: 
Name:   Rohan

11. Common Beginner Mistakes

Mistake 1: Wrong Index

name = "Python"

print(name[10])

Error: IndexError

String madhye index 10 available nahi.

Mistake 2: String Character Change Karne

name = "Python"
name[0] = "J"

String immutable aslyamule character directly change karta yet nahi.

Mistake 3: String and Integer Add Karne

age = 20

print("Age: " + age)

String ani integer direct concatenate karta yet nahit. str() kiwa f-string vapra.
