Python Loop Control Statements

Loop Control Statements cha use loop cha normal execution control karnyasathi hoto. break, continue ani pass he important statements aahet.

📘 Level: Beginner ⏱️ Time: 30–40 Minutes

1. What are Loop Control Statements?

Python madhye Loop Control Statements cha use loop kasa execute hoil he control karnyasathi hoto.

Samja loop 1 te 10 numbers print kartoy. Pan aaplyala specific number milalyavar loop stop karaycha asel, kiwa kahi numbers skip karayche astil, tar Loop Control Statements vapartat.

Statement Use
break Loop completely stop karto.
continue Current iteration skip karto.
pass Kahi action na karta empty block maintain karto.

2. break Statement

break statement cha use loop madhun immediately baher padnyasathi hoto.

break execute zalyavar loop chi urleli iterations execute hot nahit. Program loop nantaril code execute karto.

Syntax

for item in sequence:
    if condition:
        break

Example 1 – Stop at 5

for i in range(1, 11):
    if i == 5:
        break

    print(i)
Output: 
1
2
3
4

Code Explanation

  • Loop 1 pasun start hoto.
  • 1, 2, 3 ani 4 print hotat.
  • i chi value 5 zalyavar condition True hote.
  • break mule loop lagech stop hoto.
  • 5 print hot nahi.

Example 2 – Search an Item

numbers = [10, 20, 30, 40, 50]

for num in numbers:
    if num == 30:
        print("Number Found")
        break

    print(num)
Output: 
10
20
Number Found
Samjun ghe: 30 sapadlyavar break execute hoto. Tyamule 40 ani 50 check kiwa print hot nahit.

3. continue Statement

continue statement cha use current iteration skip karun loop chya next iteration la janyasathi hoto.

continue mule loop completely stop hot nahi. Fakt current iteration madhil urlela code skip hoto.

Syntax

for item in sequence:
    if condition:
        continue

Example 1 – Skip Number 5

for i in range(1, 11):
    if i == 5:
        continue

    print(i)
Output: 
1
2
3
4
6
7
8
9
10

Code Explanation

  • Loop 1 pasun 10 paryant chalto.
  • 1, 2, 3 ani 4 print hotat.
  • i chi value 5 zalyavar continue execute hoto.
  • 5 print na hota pudhchi iteration suru hote.
  • 6 te 10 print hotat.

Example 2 – Print Only Odd Numbers

for i in range(1, 11):
    if i % 2 == 0:
        continue

    print(i)
Output: 
1
3
5
7
9
Samjun ghe: Number even asel tar continue mule print() skip hoto. Mhanun fakt odd numbers print hotat.

4. pass Statement

pass statement cha use empty code block temporary thevnyasathi hoto.

pass execute zalyavar kontihi action hot nahi. Program error na deta pudhe continue hoto.

Syntax

if condition:
    pass

Example 1 – Empty if Block

age = 20

if age >= 18:
    pass

print("Program Completed")
Output: 
Program Completed

Example 2 – pass in Loop

for i in range(1, 6):
    if i == 3:
        pass

    print(i)
Output: 
1
2
3
4
5

Ya example madhye pass mule number skip hot nahi. pass kahi action karat nahi, tyamule print() execute hoto.

Important: pass ani continue same nahit. pass kahi karat nahi, tar continue current iteration madhil urlela code skip karto.

5. Difference Between break, continue and pass

Statement Behavior
break Complete loop terminate karto.
continue Current iteration skip karto.
pass Kahi action na karta pudhe jato.

One Example for All Three

# break example
for i in range(1, 6):
    if i == 3:
        break
    print(i)

# continue example
for i in range(1, 6):
    if i == 3:
        continue
    print(i)

# pass example
for i in range(1, 6):
    if i == 3:
        pass
    print(i)
break Output: 
1
2
continue Output: 
1
2
4
5
pass Output: 
1
2
3
4
5

6. break with while Loop

break statement while loop madhye suddha vaparta yete.

Example

i = 1

while i <= 10:
    if i == 6:
        break

    print(i)
    i += 1
Output: 
1
2
3
4
5

i chi value 6 zalyavar break execute hoto ani while loop stop hoto.

7. continue with while Loop

while loop madhye continue vapartana update statement yogya jagi lihine important aahe.

Example – Skip Number 3

i = 0

while i < 5:
    i += 1

    if i == 3:
        continue

    print(i)
Output: 
1
2
4
5
Important Warning: while loop madhye continue chya aadhi update statement nasel tar infinite loop hou shakto. Ya example madhye i += 1 he continue chya aadhi aahe.

8. break in Nested Loops

Nested loop madhye break vaparlyas to fakt jya loop madhye lihila aahe toch loop terminate karto.

Example

for i in range(1, 4):
    for j in range(1, 4):
        if j == 2:
            break

        print(i, j)
Output: 
1 1
2 1
3 1

Inner loop madhye j chi value 2 zalyavar inner loop stop hoto. Outer loop matra pudhe chalu rahto.

Important: Nested loops madhye break automatically outer loop terminate karat nahi.

9. Practical Example – Search Student

Students chya list madhye specific student search kar. Student sapadlyavar message print kar ani loop stop kar. 

students = ["Amit", "Rohan", "Priya", "Sneha"]

search_name = "Priya"

for student in students:
    if student == search_name:
        print("Student Found:", student)
        break
else:
    print("Student Not Found")
Output: 
Student Found: Priya

Ya example madhye student sapadlyavar break mule loop stop hoto. Student sapadla nahi ani loop normal complete zala tar else execute hoto.

10. Common Beginner Mistakes

Mistake 1: break Outside Loop

if True:
    break

break ha loop chya baher vaparta yet nahi. To for kiwa while loop chya aat asla pahije.

Mistake 2: Confusing break and continue

for i in range(1, 6):
    if i == 3:
        break
    print(i)

Ya code madhye 3 skip hot nahi, tar loop completely stop hoto. Fakt 3 skip karaycha asel tar continue vapra. 

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

Mistake 3: Missing Update in while Loop

i = 1

while i <= 5:
    if i == 3:
        continue

    print(i)
    i += 1

i chi value 3 zalyavar continue mule i += 1 skip hote. Tyamule loop infinite hoto. 

i = 0

while i < 5:
    i += 1

    if i == 3:
        continue

    print(i)

Mistake 4: Expecting pass to Skip an Item

for i in range(1, 6):
    if i == 3:
        pass

    print(i)

pass mule 3 skip hot nahi. Number skip karnyasathi continue vaprayla pahije.

13. Practical Task – Number Search System

search = int(input("Enter number to search: "))

for num in numbers:
    if num == search:
        print("Number Found")
        break
else:
    print("Number Not Found")

Input and Output: 
Enter number to search: 30
Number Found

Example 2 – Number Not Available

Input and Output:
