Python OOPs

Object-Oriented Programming madhye Class ani Object cha use karun code organize, reuse ani manage karayla shikhuya.

📘 Level: Beginner ⏱️ Time: 60–75 Minutes

1. What is OOP?

OOP cha full form Object-Oriented Programming aahe. Hi programming approach aahe jyamadhye program Classes ani Objects chya madatine design kela jato.

OOP madhye data ani tya data var kaam karanarya methods ekach structure madhye organize karta yetat.

Real-Life Example

Samaj ek Car aahe. Car la kahi properties astat:

  • Color
  • Brand
  • Speed

Car kahi actions suddha karu shakte:

  • Start
  • Stop
  • Accelerate

Python OOP madhye properties data mhanun ani actions methods mhanun represent karta yetat.

Samjun ghe: OOP madhye object ha real entity represent karto. Class ha asha objects create karnyasathi blueprint asto.

2. Advantages of OOP

  • Code Reusability: Existing code punha use karta yeto.
  • Modularity: Code classes madhye organize karta yeto.
  • Maintainability: Code update ani maintain karne sope hote.
  • Data Protection: Data access control karayla madat hote.
  • Scalability: Large applications organize karne sope hote.
Backend Connection: Django madhye Model ha Python class asto. Tyapasun objects create karun database records sobat kaam karta yete.

3. Class in Python

Class mhanje objects create karnyasathi blueprint kiwa template. Class madhye variables ani methods define karta yetat.

Syntax

class ClassName:
    # Variables
    # Methods

Example

class Student:
    name = "Rohan"
    course = "Python"

print(Student.name)
print(Student.course)
Output: 
Rohan
Python

Yethe Student hi class aahe. name ani course he class attributes aahet.

4. Object in Python

Object mhanje class cha instance. Class cha use karun objects create karta yetat.

Syntax

object_name = ClassName()

Example

class Student:
    name = "Rohan"
    course = "Python"

student1 = Student()

print(student1.name)
print(student1.course)
Output: 
Rohan
Python

Multiple Objects

class Student:
    name = "Rohan"

student1 = Student()
student2 = Student()

print(student1.name)
print(student2.name)
Output: 
Rohan
Rohan
Important: Ekach class pasun multiple objects create karta yetat. Pratyek object ha class cha separate instance asto.

5. __init__() Constructor

Python madhye __init__() hi special method aahe. Object create kelyanantar ti automatically call hote.

Object la initial values set karnyasathi __init__() vapartat.

Example

class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age

student1 = Student("Rohan", 20)

print(student1.name)
print(student1.age)
Output: 
Rohan
20

Ya code madhye:

  • __init__() object initialize karte.
  • name ani age he parameters aahet.
  • self.name ani self.age object attributes aahet.
  • Student("Rohan", 20) object create karte.
Important: __init__() la commonly constructor mhantat. Technically Python madhye object creation sathi __new__() ani initialization sathi __init__() vapartat. Beginner level la __init__() la constructor mhanun samju shakto.

6. self Keyword

self ha current object la refer karto. Instance method madhye object che attributes ani methods access karnyasathi self vapartat.

Example

class Student:

    def __init__(self, name):
        self.name = name

    def display(self):
        print("Student Name:", self.name)

student1 = Student("Rohan")
student1.display()
Output: 
Student Name: Rohan

student1.display() call kelyavar student1 object method madhye self mhanun pass hoto.

Remember: self he Python madhil reserved keyword nahi. Pan instance method madhye current object sathi self nav vaprane hi standard convention aahe.

7. Instance Variables

Instance variables he pratyek object sathi separate astat. Usually te __init__() madhye self cha use karun define kartat.

class Student:

student1 = Student("Rohan", 20)

Donhi objects che name ani age vegvegale aahet.

8. Instance Methods

Class madhye define kelele ani object var call kele janare normal methods mhanje Instance Methods.

Instance method cha pahila parameter commonly self asto.

Example

9. Class Variables

Class variables he class madhye pan methods chya baher define kele jatat. Te class chya objects madhye shared astat, jo paryant object tyachya navane vegli instance attribute create karat nahi.

Example

class Student:

    college = "ABC College"

    def __init__(self, name):
        self.name = name

student1 = Student("Rohan")
student2 = Student("Amit")

print(student1.name)
print(student2.name)

print(student1.college)
print(student2.college)
Output: 
Rohan
Amit
ABC College
ABC College

Yethe college ha class variable aahe. Donhi objects madhun tyala access karta yeto.

10. Class Methods

Class method ha class sobat related method asto. Tyacha pahila parameter commonly cls asto.

Class method define karnyasathi @classmethod decorator vapartat.

Example

class Student:

    college = "ABC College"

    @classmethod
    def display_college(cls):
        print(cls.college)

Student.display_college()
Output: 
ABC College

cls current class la refer karto. Class method class variable access kiwa update karu shakto.

11. Static Methods

Static method ha class madhye define kela jato, pan tyala automatic self kiwa cls parameter milat nahi.

Static method define karnyasathi @staticmethod decorator vapartat.

Example

class Calculator:

    @staticmethod
    def add(a, b):
        return a + b

result = Calculator.add(10, 20)

print(result)
Output: 
30

Ya method la object-specific kiwa class-specific data access karnyachi garaj nahi.

12. Encapsulation

Encapsulation mhanje data ani tya data var kaam karanarya methods ekach class madhye organize karne.

Python madhye naming conventions ani properties vaprun attribute access control karnyas madat hote.

Public Variable

class Student:

    def __init__(self):
        self.name = "Rohan"

student = Student()

print(student.name)
Output: 
Rohan

Protected Convention (_)

class Student:

    def __init__(self):
        self._name = "Rohan"

student = Student()

print(student._name)

Single underscore mhanje internal use sathi intended aslyachi convention aahe. Python access la strictly block karat nahi.

Private Name Mangling (__)

class BankAccount:

    def __init__(self, balance):
        self.__balance = balance

    def show_balance(self):
        print("Balance:", self.__balance)

account = BankAccount(5000)

account.show_balance()
Output: 
Balance: 5000
Important: Double underscore mule name mangling hote. Hi complete security mechanism nahi. Python madhye private access la Java sarkha strict restriction nahi.

13. Inheritance

Inheritance mhanje ek class dusrya class che attributes ani methods inherit karu shakto.

Jya class madhun inherit karto tyala Parent Class kiwa Base Class mhantat. Navin class la Child Class kiwa Derived Class mhantat.

Example

class Animal:

    def eat(self):
        print("Animal is eating")


class Dog(Animal):

    def bark(self):
        print("Dog is barking")


dog = Dog()

dog.eat()
dog.bark()
Output: 
Animal is eating
Dog is barking

Dog class ne Animal class madhil eat() method inherit keli aahe.

Types of Inheritance

Type Meaning
Single Ek child class ek parent class inherit karto.
Multiple Ek child class multiple parent classes inherit karto.
Multilevel Inheritance chi chain tayar hote.
Hierarchical Multiple child classes ekach parent inherit kartat.
Hybrid Multiple inheritance patterns combine hotat.

14. super() Function

super() cha use child class madhun parent class chya methods kiwa constructor la access karnyasathi hoto.

Example

class Animal:

    def __init__(self, name):
        self.name = name


class Dog(Animal):

    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed


dog = Dog("Tommy", "Labrador")

print(dog.name)
print(dog.breed)
Output: 
Tommy
Labrador

super().__init__(name) mule parent class cha constructor call hoto.

15. Polymorphism

Polymorphism cha meaning many forms asa hoto. Vegveglya objects sathi same method name vegveglya paddhatine work karu shakto.

Example

class Dog:

    def sound(self):
        print("Dog barks")


class Cat:

    def sound(self):
        print("Cat meows")


dog = Dog()
cat = Cat()

dog.sound()
cat.sound()
Output: 
Dog barks
Cat meows

Donhi classes madhye sound() method aahe. Pan object nusar output vegla milto.

Polymorphism with Function

class Dog:

    def sound(self):
        print("Bark")


class Cat:

    def sound(self):
        print("Meow")


def make_sound(animal):
    animal.sound()


make_sound(Dog())
make_sound(Cat())
Output: 
Bark
Meow

16. Method Overriding

Child class madhye parent class madhil method chya same name ne navin implementation define kelyas tyala Method Overriding mhantat.

Example

class Animal:

    def sound(self):
        print("Animal makes sound")


class Dog(Animal):

    def sound(self):
        print("Dog barks")


dog = Dog()
dog.sound()
Output: 
Dog barks

Dog class madhil sound() method ne parent class madhil sound() method override keli aahe.

17. Abstraction

Abstraction mhanje unnecessary internal details hide karun user la important functionality provide karne.

Python madhye abstract classes create karnyasathi abc module ani ABC class vapartat.

Example

from abc import ABC, abstractmethod


class Animal(ABC):

    @abstractmethod
    def sound(self):
        pass


class Dog(Animal):

    def sound(self):
        print("Dog barks")


dog = Dog()
dog.sound()
Output: 
Dog barks

Animal hi abstract class aahe. Dog class ne abstract sound() method implement keli aahe.

Important: Abstract class cha direct object create karta yet nahi, jar tyat unimplemented abstract methods astil. Concrete child class ne required abstract methods implement karavya lagtat.

19. Practical Example – Bank Account System

Aata Class, Object, Constructor, Methods ani Encapsulation use karun simple Bank Account System create karuya.

Complete Program

class BankAccount:

    def __init__(self, name, balance):
        self.name = name
        self.__balance = balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            print("Amount deposited")
        else:
            print("Invalid amount")

    def withdraw(self, amount):
        if amount <= 0:
            print("Invalid amount")

        elif amount > self.__balance:
            print("Insufficient balance")

        else:
            self.__balance -= amount
            print("Amount withdrawn")

    def show_balance(self):
        print("Account Holder:", self.name)
        print("Balance:", self.__balance)


account = BankAccount("Rohan", 5000)

account.deposit(2000)
account.withdraw(1000)
account.show_balance()
Output: 
Amount deposited
Amount withdrawn
Account Holder: Rohan
Balance: 6000

Ya program madhye:

  • BankAccount hi class aahe.
  • account ha object aahe.
  • __init__() initial values set karto.
  • deposit() paise add karto.
  • withdraw() paise withdraw karto.
  • show_balance() current balance display karto.
  • __balance he double underscore attribute aahe.

20. Common Beginner Mistakes

Mistake 1: Missing self

class Student:

    def display():
        print("Hello")

student = Student()
student.display()

Instance method madhye pahila parameter self asava. 

class Student:

    def display(self):
        print("Hello")

Mistake 2: Wrong Constructor Name

class Student:

    def init(self, name):
        self.name = name

Special method che exact name __init__ aahe. 

def __init__(self, name):
    self.name = name

Mistake 3: Forgetting Object Creation

class Student:

    def display(self):
        print("Hello")

Student.display()

Ha instance method aahe. To object var call kar. 

student = Student()
student.display()

Mistake 4: Wrong Parent Class Name

class Animal:
    pass

class Dog(Animals):
    pass

Parent class che name Animal aahe, Animals nahi. Class name exact match pahije. 

class Dog(Animal):
    pass
