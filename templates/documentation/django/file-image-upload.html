Django File and Image Upload

Learn how to upload, store, display and validate files and images in Django.

Beginner Level 50–60 Minutes

1. File Upload म्हणजे काय?

File Upload म्हणजे User कडून एखादी file किंवा image घेऊन ती server वर store करण्याची प्रक्रिया.

Examples

  • Profile Photo
  • PDF Documents
  • Resume
  • Certificates
  • Product Images

Django मध्ये File Upload साठी FileField आणि Image Upload साठी ImageField वापरतात.

2. FileField

FileField चा use कोणत्याही प्रकारची file upload करण्यासाठी होतो.

from django.db import models

class Document(models.Model):

    title = models.CharField(max_length=100)

    file = models.FileField(
        upload_to="documents/"
    )

upload_to uploaded file कोणत्या folder मध्ये store करायची ते define करते.

media/
    documents/
        notes.pdf
        resume.pdf

3. ImageField

ImageField चा use image files upload करण्यासाठी होतो.

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)

    photo = models.ImageField(
        upload_to="students/"
    )

Install Pillow

pip install Pillow
FileField आणि ImageField database मध्ये file path store करतात. प्रत्यक्ष file media storage मध्ये save होते.

8. Save Uploaded File

def upload_file(request):

11. File Validation

File: forms.py

from django import forms

class UploadForm(forms.Form):

    document = forms.FileField()

    def clean_document(self):

        file = self.cleaned_data["document"]

        if file.size > 5 * 1024 * 1024:
            raise forms.ValidationError(
                "File size must be below 5 MB."
            )

        return file

Image Validation

class ImageUploadForm(forms.Form):

    photo = forms.ImageField()
फक्त extension वर विश्वास ठेवू नका. File size, actual content, type आणि user permissions validate करा.

Step 1: Install Pillow

Step 2: Update Student Model

Step 3: Configure Media Settings

File: config/settings.py

Step 4: Configure Media URLs

File: config/urls.py

from django.contrib import admin
from django.urls import path, include

from django.conf import settings
from django.conf.urls.static import static

urlpatterns = [
    path("admin/", admin.site.urls),
    path("students/", include("students.urls")),
]

if settings.DEBUG:
    urlpatterns += static(
        settings.MEDIA_URL,
        document_root=settings.MEDIA_ROOT
    )

Step 5: Create Upload Form

File: students/forms.py

from django import forms
from .models import Student

class StudentImageForm(forms.ModelForm):

    class Meta:
        model = Student
        fields = ["photo"]

Step 6: Create View

File: students/views.py

from django.shortcuts import render, redirect
from .forms import StudentImageForm

def upload_image(request):

    if request.method == "POST":

        form = StudentImageForm(
            request.POST,
            request.FILES
        )

        if form.is_valid():
            form.save()
            return redirect("upload_image")

    else:
        form = StudentImageForm()

    return render(
        request,
        "students/upload.html",
        {"form": form}
    )

Step 7: Create URL

File: students/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path(
        "upload-image/",
        views.upload_image,
        name="upload_image"
    ),
]

14. Important Revision

  1. FileField कोणत्याही प्रकारच्या files साठी वापरतात.
  2. ImageField images साठी वापरतात.
  3. upload_to upload folder define करते.
  4. MEDIA_ROOT file storage directory define करते.
  5. MEDIA_URL media URL prefix define करते.
  6. request.FILES uploaded files मिळवते.
  7. multipart/form-data file upload साठी आवश्यक आहे.
  8. .url uploaded file चा URL देते.
  9. FieldFile.delete() file delete करते.
  10. Pillow ही ImageField साठी आवश्यक library आहे.
