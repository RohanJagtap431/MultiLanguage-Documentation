1. Django Install Karanyapurvi Kay Avashyak Aahe?

Django install karanyapurvi computer madhye kahi basic development tools asane avashyak aahe.

Tool Use

pip Python packages install karanyasathi.

2. Python Install Aahe Ka Check Kar

Aadhi VS Code open kar ani Terminal open kar. Terminal open karanyasathi keyboard shortcut vapru shakto. 

Ctrl + `

Ata terminal madhye hi command run kar:

python --version

Expected Output

Python 3.x.x

IThe 3.x.x aivaji tujhya computer madhil actual Python version disel.

Jar python command work hot nasel tar hi command try kar: 

py --version
Explanation: Ya command mule computer madhye Python install aahe ka ani konti version available aahe te samajta.

3. pip Check Kar

pip he Python package installer aahe. Django sarkhe Python packages install karanyasathi pip vapartat.

Command

python -m pip --version

Expected Output

pip 25.x from ... (python 3.x)

Jar pip available nasel tar:

python -m ensurepip --upgrade

4. Django Project Sathi Folder Create Kar

Samja aplyala MyDjangoProject navacha folder create karaycha aahe. Terminal madhye khalil commands run kar.

Folder Create Kar

mkdir MyDjangoProject

Folder Madhye Enter Kar

cd MyDjangoProject
Explanation:
  • mkdir navin folder create karto.
  • cd folder madhye enter karto.

5. Virtual Environment Create Kar

Virtual Environment he ek isolated Python environment aahe.

Samja tu don Django projects banavle. Project A madhye Django chi ek version aahe ani Project B madhye dusri version aahe. Donhi projects che packages separate thevanyasathi Virtual Environment vapartat.

Command

python -m venv venv

Command Explanation

  • python - Python interpreter run karto.
  • -m venv - Virtual Environment module run karto.
  • venv - Environment folder che nav aahe.

Project Structure

MyDjangoProject/
│
└── venv/
Important: Pratyek Django project sathi vegala Virtual Environment vaprane changli practice aahe.

6. Virtual Environment Activate Kar

Virtual Environment create kelyanantar te activate karave lagte. Windows PowerShell madhye hi command run kar: 

.\venv\Scripts\Activate.ps1

Expected Output

(venv) PS C:\...\MyDjangoProject>

Terminal madhye (venv) disat asel tar environment active zala aahe.

PowerShell Error Aalyas

Jar script execution policy mule activation block zala tar current terminal session sathi hi command run kar: 

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Nantar activation command punha run kar.

Note: Hi policy fakt current PowerShell process sathi badalte. Navin terminal session madhye garaj padlyas punha command run kar.

7. Django Install Kar

Virtual Environment active aslyachi khatri kar. Ata Django install karanyasathi hi command run kar: 

python -m pip install django

Command Explanation

  • python - Python run karto.
  • -m pip - pip module vaparto.
  • install - Package install karto.
  • django - Install karayche package aahe.

Django Version Check Kar

python -m django --version

Expected Output

6.x

Actual installed Django version terminal madhye disel.

8. Django Project Create Kar

Ata Django project create karuya. Project create karanyasathi khalil command run kar: 

django-admin startproject config .

Command Explanation

  • django-admin - Django command-line tool.
  • startproject - Navin Django project create karto.
  • config - Project configuration package che nav.
  • . - Current folder madhye project create karto.

Project Structure

MyDjangoProject/
│
├── config/
│   ├── __init__.py
│   ├── settings.py
│   ├── urls.py
│   ├── asgi.py
│   └── wsgi.py
│
├── venv/
│
└── manage.py
Important: Command madhil shevatcha dot (.) visaru nakos. Ya mule project current folder madhye create hoto.

12. Database Migrations Run Kar

Django madhye default database setup karanyasathi khalil command run kar:

Ya command mule Django che default database tables create hotat. Tyanchya use authentication, sessions ani admin system sathi hoto.

15. Common Errors

Error 1: Python is not recognized

Python PATH madhye add nasu shakto. Python installation check kar ani hi command try kar: 

py --version

Error 2: No module named django

Virtual Environment activate aahe ka check kar. Nantar Django install kar: 

python -m pip install django

Error 3: PowerShell script execution disabled

Current terminal session sathi: 

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Error 4: Port is already in use

Dusra server tyach port var run hot asel tar dusra port vapr: 

python manage.py runserver 8001

Error 5: manage.py not found

Tu project chya main folder madhye aahes ka te check kar. Jithe manage.py aahe tyach folder madhun command run kar.
