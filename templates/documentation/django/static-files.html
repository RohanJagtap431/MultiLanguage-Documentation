Django Static Files

Learn how to add CSS, JavaScript and Images to Django websites using Static Files.

📘 Beginner Level ⏱️ 35–45 Minutes

1. Static Files mhanje kay?

Static Files mhanje website madhil ase files je normally user request nusar change hot nahit.

Django madhye CSS, JavaScript ani Images sarkhya files static files mhanun olakhlya jatat.

Examples of Static Files

  • CSS – Website la design denyasathi.
  • JavaScript – Website interactive karnyasathi.
  • Images – Website madhye photos display karnyasathi.
  • Icons – Website madhye symbols display karnyasathi.
Remember: Static Files website cha design ani frontend functionality manage karnyasathi vapartat.

3. STATIC_URL Setting

STATIC_URL hi Django setting static files access karnyasathi URL prefix define karte.

File: config/settings.py

STATIC_URL = 'static/'

Ya setting mule browser madhye static files access karnyasathi static/ URL prefix vaparla jato.

Example

/static/css/style.css
/static/js/script.js
/static/images/logo.png
Remember: STATIC_URL hi URL prefix aahe. Ti static folder cha actual filesystem path nahi.

4. STATICFILES_DIRS

STATICFILES_DIRS cha use project madhil additional static folders cha path Django la sangnyasathi hoto.

File: config/settings.py

from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent.parent

STATIC_URL = 'static/'

STATICFILES_DIRS = [
    BASE_DIR / 'static',
]
  • BASE_DIR – Project root directory cha path.
  • STATICFILES_DIRS – Additional static folders chi list.
  • BASE_DIR / 'static' – Project-level static folder cha path.
Important: Existing BASE_DIR ani STATIC_URL settings punha duplicate karu naka. Existing settings madhye required entry add kara.

5. Load Static Tag

Django template madhye static files use karnyasathi load static tag vapartat.

Syntax

{% verbatim %}
{% load static %}
{% endverbatim %}

Ha tag template madhye static template tag library load karto.

Example: home.html

{% verbatim %}
{% load static %}

<!DOCTYPE html>
<html>
<head>
    <title>Home Page</title>

    <link rel="stylesheet"
          href="{% static 'css/style.css' %}">
</head>

<body>
    <h1>Welcome to Django</h1>
</body>
</html>
{% endverbatim %}
Remember: {% templatetag openblock %} load static {% templatetag closeblock %} tag static template tags available karto.

9. STATIC_ROOT and collectstatic

Production deployment madhye static files collect karnyasathi STATIC_ROOT ani collectstatic command vapartat.

File: config/settings.py

STATIC_URL = 'static/'

STATIC_ROOT = BASE_DIR / 'staticfiles'

Command

python manage.py collectstatic

Ha command project ani installed apps madhil static files ekach destination folder madhye collect karto.

Important: STATIC_ROOT ha collected static files cha destination aahe. STATICFILES_DIRS ha source folders specify karto. Donhi settings cha purpose vegla aahe.

Difference

Setting Purpose
STATIC_URL Static files cha URL prefix.
STATICFILES_DIRS Additional static source folders.
STATIC_ROOT Collected files cha destination folder.

10. Complete Practical – Student Profile Page

Ata CSS, JavaScript ani Image ekatra use karun Student Profile Page create karu.

Step 1: Folder Structure

project/
│
├── static/
│   ├── css/
│   │   └── profile.css
│   │
│   ├── js/
│   │   └── profile.js
│   │
│   └── images/
│       └── student.png
│
└── templates/
    └── profile.html

Step 2: static/css/profile.css

body {
    font-family: Arial, sans-serif;
    background: #f1f5f9;
}

.profile {
    width: 300px;
    margin: 50px auto;
    padding: 25px;
    background: white;
    text-align: center;
    border-radius: 12px;
}

.profile img {
    width: 100px;
    height: 100px;
    border-radius: 50%;
}

.profile h2 {
    color: #172033;
}

.profile p {
    color: #64748b;
}

.profile button {
    padding: 10px 18px;
    background: #2563eb;
    color: white;
    border: none;
    border-radius: 6px;
    cursor: pointer;
}

Step 3: static/js/profile.js

function showProfile() {
    alert("Welcome to Student Profile!");
}

Step 4: templates/profile.html

{% verbatim %}
{% load static %}

<!DOCTYPE html>
<html>
<head>
    <title>Student Profile</title>

    <link rel="stylesheet"
          href="{% static 'css/profile.css' %}">
</head>

<body>

    <div class="profile">

        <img src="{% static 'images/student.png' %}"
             alt="Student Photo">

        <h2>Rohan Jagtap</h2>

        <p>BSc Computer Science</p>

        <button onclick="showProfile()">
            View Profile
        </button>

    </div>

    <script src="{% static 'js/profile.js' %}"></script>

</body>
</html>
{% endverbatim %}

Step 5: students/views.py

from django.shortcuts import render

def profile(request):
    return render(request, "profile.html")

Step 6: students/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path("profile/", views.profile, name="profile"),
]

Step 7: config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("students.urls")),
]

Step 8: Run Server

python manage.py runserver

Browser URL

http://127.0.0.1:8000/profile/

Expected Output
