Django Pagination and Search

Learn how to divide large data into pages and search database records using Django ORM.

Intermediate Level 60–75 Minutes

1. Pagination mhanje kay?

Pagination mhanje mothya data list la chotya-chotya pages madhye divide karne.

Example

Samja database madhye 100 students aahet ani pratyek page var 10 students dakhvayche aahet.

  • Page 1 – Students 1 to 10
  • Page 2 – Students 11 to 20
  • Page 3 – Students 21 to 30
  • Page 10 – Students 91 to 100

Yamule ekach veli sagla data load karava lagat nahi.

2. Django Paginator Class

Django madhye pagination sathi Paginator class vapartat.

from django.core.paginator import Paginator

students = Student.objects.all()

paginator = Paginator(students, 10)

page_obj = paginator.get_page(1)
CodeUse
PaginatorData pages madhye divide karte.
studentsDatabase madhil records.
10Pratyek page var 10 records.
get_page(1)First page milavte.
page_objCurrent page cha object.

4. get_page() Method

get_page() method vaprun specific page milavta yete.

page_obj = paginator.get_page(2)

Yamule second page milte.

  • Page number invalid asel tar first page milte.
  • Page number available pages peksha motha asel tar last page milte.

7. Django Search Functionality

Search cha use database madhun specific record shodhnayasathi hoto.

Django ORM madhye filter() ani icontains lookup vaprun case-insensitive search karta yete.

students = Student.objects.filter(
    name__icontains="rohan"
)

Ya query madhye name madhye rohan aslele records miltat. Capital ani small letters madhil farak ignore hoto.

9. Q Objects – Multiple Field Search

Student la name kiwa email donhi madhun search karaycha asel tar Q objects vapartat.

from django.db.models import Q

students = Student.objects.filter(
    Q(name__icontains="rohan") |
    Q(email__icontains="rohan")
)
OperatorUse
Q()Multiple conditions create karte.
|OR condition.
&AND condition.
~NOT condition.

10. Practical – Student Management System with Pagination and Search

Ata Student List madhye Search ani Pagination donhi add karu.

Step 1: Import Required Modules

File: students/views.py

from django.shortcuts import render
from django.core.paginator import Paginator
from django.db.models import Q

from .models import Student

Step 2: Create Student List View

def student_list(request):

    query = request.GET.get("q", "")

    students = Student.objects.all()

    if query:
        students = students.filter(
            Q(name__icontains=query) |
            Q(email__icontains=query) |
            Q(course__icontains=query)
        )

    paginator = Paginator(students, 10)

    page_number = request.GET.get("page")

    page_obj = paginator.get_page(page_number)

    return render(
        request,
        "students/list.html",
        {
            "page_obj": page_obj,
            "query": query
        }
    )

Explanation

  1. request.GET.get("q", "") search value milavte.
  2. Student.objects.all() sagle students ghete.
  3. Q() vaprun name, email ani course madhye search hoto.
  4. Paginator(students, 10) pratyek page var 10 students thevte.
  5. get_page() current page milavte.
  6. render() template la data pathavte.

Step 3: Create URL

File: students/urls.py

from django.urls import path
from . import views

urlpatterns = [

    path(
        "students/",
        views.student_list,
        name="student_list"
    ),

]
