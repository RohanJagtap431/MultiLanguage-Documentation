DJANGO COURSE • TOPIC 09

Django ORM

Learn how to create, retrieve, filter, update and delete database records using Django ORM.

📘 Beginner Level ⏱️ 45–55 Minutes

1. ORM mhanje kay?

ORM cha full form Object Relational Mapper aahe. ORM cha use Python objects ani relational database yanchyamadhye interaction karnyasathi hoto.

Django ORM mule SQL queries manually na lihita Python code vaprun database operations karta yetat.

Example

Without ORM: SQL query lihavi lagte.

With ORM: Python methods vaparta yetat.

Remember: Django ORM Python code la database operations madhye translate karnyas madat karto.

2. Django ORM kase work karte?

Django ORM Model ani Database yanchyamadhye bridge mhanun work karte.

ORM Working Flow

Python Code
↓
Django ORM
↓
SQL Query
↓
Database

Example: Python madhye Student.objects.all() lihilyavar Django ORM database madhun student records retrieve karte.

3. Import Model

ORM operations karnyasathi sarvat aadhi model import karava lagto.

Example: students/views.py

from django.shortcuts import render
from .models import Student

Ya code madhye Student model import kela aahe. Ata apan Student model var ORM methods use karu shakto.

4. Create Record

create() method cha use database madhye new record insert karnyasathi hoto.

Syntax

Model.objects.create(field=value)

Example

from .models import Student

Student.objects.create(
    name="Rohan",
    email="rohan@example.com",
    age=20,
    course="BSc Computer Science"
)

Expected Database Record

Name Email Age Course
Rohan rohan@example.com 20 BSc Computer Science
Remember: create() method record create karte ani save karte.

5. Retrieve All Records

all() method cha use database madhil sarv records retrieve karnyasathi hoto.

Syntax

Model.objects.all()

Example

students = Student.objects.all()

for student in students:
    print(student.name)

Expected Output

Rohan
Rahul
Priya
Remember: all() method QuerySet return karte. QuerySet madhye multiple database records astat.

6. Filter Records

filter() method cha use specific condition match honare records retrieve karnyasathi hoto.

Syntax

Model.objects.filter(condition)

Example 1: Filter by Name

students = Student.objects.filter(
    name="Rohan"
)

Example 2: Filter by Age

students = Student.objects.filter(
    age=20
)

Example 3: Greater Than

students = Student.objects.filter(
    age__gt=18
)

Common Field Lookups

Lookup Meaning
exact Exact match.
contains Text contains value.
icontains Case-insensitive contains.
gt Greater than.
gte Greater than or equal to.
lt Less than.
lte Less than or equal to.
in Value list madhye aahe ka te check karte.

Example: Contains

students = Student.objects.filter(
    name__icontains="ro"
)

7. Get Single Record

get() method cha use specific condition match honara ek record retrieve karnyasathi hoto.

Syntax

Model.objects.get(condition)

Example

student = Student.objects.get(
    id=1
)

print(student.name)

Important Difference

filter() get()
QuerySet return karte. Single object return karte.
Zero records allowed. Zero records asel tar DoesNotExist error.
Multiple records allowed. Multiple records asel tar MultipleObjectsReturned error.
Important: get() vapartana condition unique asne kiwa fakt ekach record match hone garjeche aahe.

8. Exclude Records

exclude() method cha use specific condition match honare records sodun baki records retrieve karnyasathi hoto.

Example

students = Student.objects.exclude(
    age=20
)

Ya example madhye age 20 aslele records exclude hotil. Baki records return hotil.

9. Update Record

update() method cha use database madhil existing records update karnyasathi hoto.

Example

Student.objects.filter(
    id=1
).update(
    age=21
)

Ya example madhye id 1 aslelya student cha age 21 hoil.

Important: update() QuerySet var call karatat. To matching records direct database madhye update karto ani affected rows chi sankhya return karto.

Alternative: Save Method

student = Student.objects.get(id=1)

student.age = 21

student.save()

10. Delete Record

delete() method cha use database madhil records delete karnyasathi hoto.

Example

Student.objects.filter(
    id=1
).delete()

Ya code mule id 1 aslela student record delete hoil.

Delete Single Object

student = Student.objects.get(id=2)

student.delete()
Warning: delete() operation database madhil data delete karte. Real project madhye delete karnyapurvi confirmation ani permissions check kara.

11. Order By

order_by() method cha use records ascending kiwa descending order madhye sort karnyasathi hoto.

Ascending Order

students = Student.objects.order_by("name")

Descending Order

students = Student.objects.order_by("-age")

Examples

Code Sorting
order_by("name") Name A to Z.
order_by("-name") Name Z to A.
order_by("age") Age low to high.
order_by("-age") Age high to low.

12. Count and Exists

Count Method

count() method cha use matching records chi total number count karnyasathi hoto. 

total = Student.objects.count()

print(total)

Exists Method

exists() method matching records available aahet ka te check karte. 

result = Student.objects.filter(
    age=20
).exists()

print(result)

Expected Output

3
True
Remember: count() integer return karte, tar exists() True kiwa False return karte.

13. QuerySet Chaining

Multiple ORM methods ekach query madhye combine karnyas QuerySet Chaining mhantat.

Example

students = Student.objects.filter(
    age__gte=18
).exclude(
    course="BCA"
).order_by("name")

Ya example madhye:

  1. Age 18 kiwa tyapeksha jast aslele records select hotil.
  2. BCA course aslele records exclude hotil.
  3. Remaining records name nusar sort hotil.
Remember: QuerySet methods combine karun readable database queries tayar karta yetat.

14. Complete Practical – Student CRUD

Ata Django ORM vaprun Student records create, read, update ani delete karu.

Step 1: Model

File: students/models.py

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)
    email = models.EmailField(unique=True)
    age = models.IntegerField()
    course = models.CharField(max_length=100)

    def __str__(self):
        return self.name

Step 2: Create Records

File: students/views.py

from django.shortcuts import render
from .models import Student

def create_student(request):

    Student.objects.create(
        name="Rohan",
        email="rohan@example.com",
        age=20,
        course="BSc Computer Science"
    )

    return render(request, "success.html")

Step 3: Read Records

def student_list(request):

    students = Student.objects.all()

    return render(
        request,
        "student_list.html",
        {"students": students}
    )

Step 4: Update Record

def update_student(request):

    Student.objects.filter(
        id=1
    ).update(
        age=21
    )

    return render(request, "success.html")

Step 5: Delete Record

def delete_student(request):

    Student.objects.filter(
        id=1
    ).delete()

    return render(request, "success.html")

Step 6: URL Configuration

File: students/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path("create/", views.create_student, name="create_student"),
    path("students/", views.student_list, name="student_list"),
    path("update/", views.update_student, name="update_student"),
    path("delete/", views.delete_student, name="delete_student"),
]

Step 7: Student List Template

File: templates/student_list.html

{% verbatim %}
<h1>Student List</h1>

{% for student in students %}

    <div>
        <h3>{{ student.name }}</h3>

Practical Note: Ha basic learning example aahe. Create, update ani delete views GET requests ne data change kartat. Real application madhye POST requests, forms, CSRF protection ani permissions vapra. Create URL punha open kelyas duplicate email error yeu shakto, karan email unique aahe.
