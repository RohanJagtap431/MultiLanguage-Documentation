Django Testing

Learn how to test Django models, views and HTTP responses using automated tests.

Intermediate Level 60–75 Minutes

1. Testing mhanje kay?

Testing mhanje application madhil code expected result deto ka he check karne.

Example

Samja Student model madhye student create kela.

student = Student.objects.create(
    name="Rohan",
    email="rohan@example.com",
    age=20,
    course="Computer Science"
)

Testing madhye apan check karu shakto ki student database madhye save zala aahe ka.

self.assertEqual(student.name, "Rohan")

2. Unit Testing

Unit Testing mhanje application madhil ek specific function kiwa small unit test karne.

Example

def add(a, b):
    return a + b

Test

self.assertEqual(add(10, 20), 30)

Ithe add() function cha output check kela aahe.

  • Code madhil errors lavkar samajtat.
  • Code changes nantar functionality check karta yete.
  • Debugging easy hote.
  • Application reliability improve hote.

3. Django TestCase

Django madhye automated testing sathi TestCase class vapartat.

Import

from django.test import TestCase

Basic Example

from django.test import TestCase

class MyTest(TestCase):

    def test_example(self):
        self.assertEqual(10 + 20, 30)
CodeUse
TestCaseTest class create karte.
test_example()Test method.
assertEqual()Don values equal aahet ka check karte.

Django test runner test_ ne suru honarya test methods execute karto.

TestCase tests sathi separate test database vaparte. Test complete zalyavar test data rollback hoto.

5. Model Testing

Model Testing madhye database model properly work karto ka he check karto.

Example

from django.test import TestCase
from .models import Student

class StudentModelTest(TestCase):

    def test_student_creation(self):

        student = Student.objects.create(
            name="Rohan",
            email="rohan@example.com",
            age=20,
            course="CS"
        )

        self.assertEqual(student.name, "Rohan")
        self.assertEqual(student.age, 20)

Student object create kela, database madhye record save zala ani tyache name ani age check kele.

6. View Testing

View Testing madhye Django view expected response dete ka he check karto.

Example View

from django.http import HttpResponse

def home(request):
    return HttpResponse("Welcome to Django")

Test

from django.test import TestCase
from django.urls import reverse

class HomeViewTest(TestCase):

    def test_home_page(self):

        response = self.client.get(
            reverse("home")
        )

        self.assertEqual(response.status_code, 200)
  • self.client.get() request pathavte.
  • reverse("home") URL name varun URL milavte.
  • status_code response status check karto.
  • 200 mhanje request successful aahe.

10. Practical – Student Management System Testing

Ata existing Student model ani Student List view test karu.

Step 1: Create tests.py

File: students/tests.py

from django.test import TestCase
from django.urls import reverse

from .models import Student


class StudentModelTest(TestCase):

    def test_student_creation(self):

        student = Student.objects.create(
            name="Rohan",
            email="rohan@example.com",
            age=20,
            course="CS"
        )

        self.assertEqual(student.name, "Rohan")
        self.assertEqual(student.email, "rohan@example.com")
        self.assertEqual(student.age, 20)


class StudentViewTest(TestCase):

    def setUp(self):

        Student.objects.create(
            name="Rohan",
            email="rohan@example.com",
            age=20,
            course="CS"
        )

    def test_student_list_page(self):

        response = self.client.get(
            reverse("student_list")
        )

        self.assertEqual(response.status_code, 200)

    def test_student_name_display(self):

        response = self.client.get(
            reverse("student_list")
        )

        self.assertContains(response, "Rohan")

Step 2: Understand setUp()

def setUp(self):

    Student.objects.create(
        name="Rohan",
        email="rohan@example.com",
        age=20,
        course="CS"
    )

setUp() method pratyek test method run honyapurvi execute hote.

Step 3: Check URL Name

students/urls.py madhye URL name asa asava:

path(
    "students/",
    views.student_list,
    name="student_list"

Tumchya project madhye URL namespace asel tar reverse() madhye namespace suddha dya.
