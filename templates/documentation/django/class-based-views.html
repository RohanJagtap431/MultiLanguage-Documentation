Django Class-Based Views (CBV)

Learn how to create reusable views using Python classes in Django.

Intermediate Level 60–75 Minutes

1. Class-Based Views mhanje kay?

Class-Based Views (CBV) mhanje Django madhye views create karnyasathi Python Classes cha use karne.

FBV madhye function vaparto, tar CBV madhye class vaparto.

Function-Based View

from django.http import HttpResponse

def home(request):
    return HttpResponse("Welcome to Django")

Class-Based View

from django.views import View
from django.http import HttpResponse

class HomeView(View):

    def get(self, request):
        return HttpResponse("Welcome to Django")
CBV mule code reusable ani organized thevta yeto.

2. FBV vs CBV

FBVCBV
Function vaparto.Class vaparto.
Simple structure.Structured approach.
def vaparto.class vaparto.
if madhun request handle karu shakto.get(), post() methods vaparto.
Small views sathi useful.Complex ani reusable views sathi useful.

3. Django View Class

View hi Django madhil base class aahe. Tichya madatine swatahche CBV create karta yetat.

from django.views import View
from django.http import HttpResponse

class HomeView(View):

    def get(self, request):
        return HttpResponse("Home Page")

    def post(self, request):
        return HttpResponse("POST Request")
  • get() – GET request handle karte.
  • post() – POST request handle karte.

URL Configuration

path("home/", HomeView.as_view())

4. TemplateView

TemplateView cha use HTML template display karnyasathi hoto.

views.py

from django.views.generic import TemplateView

class HomeView(TemplateView):

    template_name = "home.html"

urls.py

path(
    "home/",
    HomeView.as_view(),
    name="home"
)

Simple page display karnyasathi vegla get() method lihinyachi garaj naste.

5. ListView

ListView cha use database madhil multiple records display karnyasathi hoto.

views.py

from django.views.generic import ListView
from .models import Student

class StudentListView(ListView):

    model = Student

    template_name = "students/list.html"

    context_object_name = "students"

urls.py

path(
    "students/",
    StudentListView.as_view(),
    name="student_list"
)

list.html

{% verbatim %}
{% for student in students %}
    <h3>{{ student.name }}</h3>
    <p>{{ student.email }}</p>
{% empty %}
    <p>No students found.</p>
{% endfor %}
{% endverbatim %}

context_object_name mule template madhye students navane records access karta yetat.

6. DetailView

DetailView cha use eka specific record chi information display karnyasathi hoto.

views.py

from django.views.generic import DetailView

class StudentDetailView(DetailView):

    model = Student

    template_name = "students/detail.html"

    context_object_name = "student"

urls.py

path(
    "students/<int:pk>/",
    StudentDetailView.as_view(),
    name="student_detail"
)

detail.html

{% verbatim %}
<h2>{{ student.name }}</h2>
<p>{{ student.email }}</p>
<p>{{ student.age }}</p>
<p>{{ student.course }}</p>
{% endverbatim %}
pk mhanje Primary Key. Tyachya madatine specific record shodhla jato.

7. CreateView

CreateView cha use database madhye navin record create karnyasathi hoto.

views.py

from django.views.generic import CreateView
from django.urls import reverse_lazy
from .models import Student

class StudentCreateView(CreateView):

    model = Student

    fields = ["name", "email", "age", "course"]

    template_name = "students/student_form.html"

    success_url = reverse_lazy("student_list")

urls.py

path(
    "students/add/",
    StudentCreateView.as_view(),
    name="student_add"
)

fields madhye form madhye konti model fields dakhvaychi te define karto.

success_url record successfully create zalyavar kuthe redirect karayche te sangte.

8. UpdateView

views.py

from django.views.generic import UpdateView

class StudentUpdateView(UpdateView):

    template_name = "students/student_form.html"

Step 1: Create Views

File: students/views.py

from django.views.generic import (
    ListView, DetailView, CreateView,
    UpdateView, DeleteView
)

from django.urls import reverse_lazy
from .models import Student


class StudentListView(ListView):
    model = Student
    template_name = "students/list.html"
    context_object_name = "students"


class StudentDetailView(DetailView):
    model = Student
    template_name = "students/detail.html"
    context_object_name = "student"


class StudentCreateView(CreateView):
    model = Student
    fields = ["name", "email", "age", "course"]
    template_name = "students/student_form.html"
    success_url = reverse_lazy("student_list")


class StudentUpdateView(UpdateView):
    model = Student
    fields = ["name", "email", "age", "course"]
    template_name = "students/student_form.html"
    success_url = reverse_lazy("student_list")


class StudentDeleteView(DeleteView):
    model = Student
    template_name = "students/student_confirm_delete.html"
    success_url = reverse_lazy("student_list")
