DJANGO COURSE • TOPIC 21

Django Middleware

Learn how Django middleware processes requests and responses and how to create custom middleware.

Intermediate Level 45–60 Minutes

1. Middleware mhanje kay?

Middleware ha Django madhil ek component aahe jo request ani response process karto.

Middleware cha use authentication checks, security, sessions, request logging ani itar common operations sathi hoto.

Examples

  • User authentication check karne.
  • Request information log karne.
  • Security headers add karne.
  • Session information handle karne.

2. Middleware kasa work karto?

Django madhye request middleware madhun view paryant jate. View madhun response alyanantar response middleware madhun user paryant parat jato.

User / Browser
↓

↓

↓

↓

↓

Middleware request ani response donhi process karu shakto.

Django madhye kahi middleware default available astat.

5. Custom Middleware

Custom Middleware mhanje apan swatah create kelela middleware.

Udaharanarth, website var yenarya pratyek request chi information terminal madhye print karaychi asel tar custom middleware create karu shakto.

Example

File: students/middleware.py

class MyMiddleware:

    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):

        print("Before View")

        response = self.get_response(request)

        print("After View")

        return response

Explanation

  • __init__() – Middleware initialize karte.
  • get_response – Pudhil middleware kiwa view call karte.
  • __call__() – Pratyek request process karte.
  • response – View kadun milalela response.

6. Register Custom Middleware

Middleware create kelyanantar te settings.py madhye register karave lagte.

MIDDLEWARE = [

    "django.contrib.messages.middleware.MessageMiddleware",

    "django.middleware.clickjacking.XFrameOptionsMiddleware",

Ata request alyavar MyMiddleware suddha execute hoil.

7. Middleware Methods

Custom middleware madhye kahi important methods astat.

MethodUse
__init__()Middleware initialize karte.
__call__()Request process karte ani response return karte.
process_view()View execute honyapurvi call hou shakte.
process_exception()View madhye exception alyas call hou shakte.
process_template_response()Template response process karu shakte.
Modern middleware madhye __init__() ani __call__() ha basic pattern aahe. Itar methods optional hooks aahet.

8. Request Logging Middleware

Request Logging Middleware cha use website var yenarya requests chi information record karnyasathi hoto.

Example

File: students/middleware.py

class RequestLoggingMiddleware:

    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):

        print("Path:", request.path)

        print("Method:", request.method)

        response = self.get_response(request)

        print("Status:", response.status_code)

        return response

Example Output

Path: /students/
Method: GET
Status: 200

Ya middleware mule request path, HTTP method ani response status terminal madhye disel.

9. Middleware Order

Django madhye middleware cha order important asto.

  • Request processing madhye middleware list chya order ne execute hotat.
  • Response processing madhye middleware reverse order ne execute hotat.
  • Middleware order chukicha asel tar kahi functionality fail hou shakte.

Example

MIDDLEWARE = [
    "students.middleware.MyMiddleware",
    "django.middleware.security.SecurityMiddleware",
]

Ya example madhye MyMiddleware request processing madhye SecurityMiddleware chya aadhi execute hoil.

Middleware cha order randomly change karu naka. Django default order follow kara. AuthenticationMiddleware la SessionMiddleware nantar thevane avashyak aahe.

        print("Method:", request.method)

        response = self.get_response(request)
