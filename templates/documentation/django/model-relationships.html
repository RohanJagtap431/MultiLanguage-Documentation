Django Model Relationships

Learn how to connect multiple Django models using ForeignKey, OneToOneField and ManyToManyField.

📘 Beginner Level ⏱️ 50–60 Minutes

1. Model Relationships mhanje kay?

Model Relationship mhanje don kiwa adhik database tables madhil sambandh.

Django madhye ek model dusrya model sobat connect karanyasathi relationship fields vapartat.

Example – College Management

  • Ek Department madhye anek Students astat.
  • Ek Student chi ek Profile aste.
  • Ek Student anek Courses select karu shakto.
  • Ek Course anek Students gheu shaktat.
Remember: Django madhye mainly three types of model relationships vapartat: One-to-One, One-to-Many ani Many-to-Many.

2. Types of Model Relationships

Relationship Field Meaning
One-to-One OneToOneField One record connects to one record.
One-to-Many ForeignKey One record connects to many records.
Many-to-Many ManyToManyField Many records connect to many records.

3. One-to-One Relationship

One-to-One relationship madhye ek record dusrya model madhil fakt eka record sobat connect asto.

Example

Ek Student chi ek Student Profile asu shakते. Ek profile fakt eka student chi aste.

Student Student Details
1 ↔ 1
StudentProfile Profile Details

OneToOneField Syntax

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)


class StudentProfile(models.Model):

    student = models.OneToOneField(
        Student,
        on_delete=models.CASCADE
    )

    address = models.CharField(max_length=200)

    phone = models.CharField(max_length=15)

OneToOneField eka record la dusrya model chya ekach record sobat connect karte.

Remember: OneToOneField vaparlyane related model madhye unique relationship maintain hote.

4. One-to-Many Relationship

One-to-Many relationship madhye eka record sobat dusrya model che anek records connect astat.

Example

Ek Department madhye anek Students asu shaktat. Pan pratyek Student eka Department sobat associated asto.

Department Computer Science
1 → Many
Student 1
Student 2
Student 3
Remember: Django madhye One-to-Many relationship sathi ForeignKey vapartat.

5. ForeignKey

ForeignKey cha use eka model la dusrya model sobat connect karnyasathi hoto.

Example

from django.db import models

class Department(models.Model):

    name = models.CharField(max_length=100)


class Student(models.Model):

    name = models.CharField(max_length=100)

    department = models.ForeignKey(
        Department,
        on_delete=models.CASCADE
    )

Ya example madhye Student model madhil ForeignKey Department model la reference karte.

Ek Department anek Students sobat connect hou shakto.

Important: ForeignKey field many-side model madhye define kartat. Ya example madhye ForeignKey Student model madhye aahe.

6. Many-to-Many Relationship

Many-to-Many relationship madhye eka model madhil anek records dusrya model madhil anek records sobat connect hou shaktat.

Example

  • Ek Student anek Courses select karu shakto.
  • Ek Course anek Students sobat connect hou shakto.
Students Student A, Student B
Many ↔ Many
Courses Python, Django, Java

ManyToManyField Syntax

from django.db import models

class Course(models.Model):

    name = models.CharField(max_length=100)


class Student(models.Model):

    name = models.CharField(max_length=100)

    courses = models.ManyToManyField(Course)

Django ManyToManyField sathi automatically intermediate database table create karte.

Remember: ManyToManyField mule donhi models madhil multiple records connect karta yetat.

7. on_delete Options

ForeignKey kiwa OneToOneField madhye related object delete zalyas kay action ghyaycha te on_delete define karte.

Option Meaning
CASCADE Referenced object delete zalyas related object suddha delete hoto.
PROTECT Related objects aslyas deletion block hote.
SET_NULL Related field NULL set hote.
SET_DEFAULT Field default value var set hote.
DO_NOTHING Django automatic action ghet nahi.

CASCADE Example

department = models.ForeignKey(
    Department,
    on_delete=models.CASCADE
)

PROTECT Example

department = models.ForeignKey(
    Department,
    on_delete=models.PROTECT
)

SET_NULL Example

department = models.ForeignKey(
    Department,
    on_delete=models.SET_NULL,
    null=True,
    blank=True
)

SET_DEFAULT Example

department = models.ForeignKey(
    Department,
    on_delete=models.SET_DEFAULT,
    default=1
)
Important: SET_NULL sathi null=True required aahe. SET_DEFAULT sathi valid default value required aahe. DO_NOTHING vaparlyas database constraints mule deletion fail hou shakते.

8. Related Objects

Relationship create kelyanantar related objects access karta yetat.

ForeignKey – Forward Access

student = Student.objects.get(id=1)

department = student.department

print(department.name)

Reverse Access

department = Department.objects.get(id=1)

students = department.student_set.all()

Default reverse manager madhye model name lowercase ani _set suffix vapartat.

9. related_name

related_name cha use reverse relationship access karnyasathi custom name denyasathi hoto.

Example

department = models.ForeignKey(
    Department,
    on_delete=models.CASCADE,
    related_name="students"
)

Reverse Access

department = Department.objects.get(id=1)

students = department.students.all()
Remember: related_name mule department.student_set aivaji department.students vaparta yete.

10. Many-to-Many Queries

Add Course

student = Student.objects.get(id=1)

course = Course.objects.get(id=1)

student.courses.add(course)

Get Student Courses

student = Student.objects.get(id=1)

courses = student.courses.all()

Remove Course

student.courses.remove(course)

Clear All Courses

student.courses.clear()
Important: Many-to-Many relationship add karnyapurvi Student object database madhye save zalele asne required aahe.

11. One-to-One Queries

Create Profile

student = Student.objects.get(id=1)

profile = StudentProfile.objects.create(
    student=student,
    address="Pune",
    phone="9876543210"
)

Get Profile

profile = student.studentprofile

print(profile.address)

Reverse Access with related_name

student = models.OneToOneField(
    Student,
    on_delete=models.CASCADE,
    related_name="profile"
)

Ata student.profile vaprun related profile access karta yete.
