Django Deployment

Learn how to deploy Django applications online using environment variables, PostgreSQL, WhiteNoise and Render.

Intermediate Level 75–90 Minutes

1. Django Deployment mhanje kay?

Deployment mhanje Django application internet var available karne.

Development Environment

  • Project local computer var run hoto.
  • Developer code changes karto.
  • Debugging sathi DEBUG=True vaparta yete.

Production Environment

  • Website internet var live aste.
  • Real users website access kartat.
  • Security ani performance important astat.
  • DEBUG=False thevne avashyak aahe.

2. Environment Variables (.env)

Environment Variables mhanje sensitive information ani configuration code pasun vegli store karne.

  • SECRET_KEY
  • DEBUG
  • DATABASE_URL
  • API keys
  • Database credentials

Create .env File

SECRET_KEY=your-secret-key
DEBUG=True

settings.py

import os
from dotenv import load_dotenv

load_dotenv()

SECRET_KEY = os.getenv("SECRET_KEY")

DEBUG = os.getenv("DEBUG", "False") == "True"

.env file GitHub var upload karu naka.

.gitignore

.env
.venv/
__pycache__/
*.pyc

Production madhye hosting platform chya Environment Variables section madhye values set kara.

4. PostgreSQL Database

PostgreSQL he relational database management system aahe.

SQLitePostgreSQL
File-based databaseDatabase server
Simple setupSeparate database setup
Small projects sathi usefulProduction applications sathi useful
db.sqlite3 fileDatabase URL/credentials

Install Packages

pip install dj-database-url psycopg

settings.py Example

import os
import dj_database_url

DATABASES = {
    "default": dj_database_url.parse(
        os.environ["DATABASE_URL"],
        conn_max_age=600
    )
}

Production madhye DATABASE_URL environment variable hosting platform madhun configure kara.

Local development sathi existing SQLite settings thevu shakta.

5. Static Files ani WhiteNoise

Static Files mhanje website madhil CSS, JavaScript ani images.

WhiteNoise Django application madhun static files serve karanyas madat karto.

Install

pip install whitenoise

settings.py Middleware

MIDDLEWARE = [
    "django.middleware.security.SecurityMiddleware",
    "whitenoise.middleware.WhiteNoiseMiddleware",

    # Other middleware...
]

WhiteNoise middleware ha SecurityMiddleware nantar lagech theva.

Static Settings

STATIC_URL = "static/"

STATIC_ROOT = BASE_DIR / "staticfiles"

STORAGES = {
    "staticfiles": {
        "BACKEND": "whitenoise.storage.CompressedManifestStaticFilesStorage",
    },
}

Collect Static Files

python manage.py collectstatic

Yamule static files STATIC_ROOT madhye collect hotat.

6. Django Production Settings

Production deployment purvi settings.py madhye security settings configure kara.

Example

import os

DEBUG = os.getenv("DEBUG", "False") == "True"

SECRET_KEY = os.environ["SECRET_KEY"]

ALLOWED_HOSTS = os.getenv(
    "ALLOWED_HOSTS",
    "localhost,127.0.0.1"
).split(",")

CSRF_TRUSTED_ORIGINS = os.getenv(
    "CSRF_TRUSTED_ORIGINS",
    ""
).split(",")
SettingUse
DEBUGDebug mode control karte.
SECRET_KEYDjango security key.
ALLOWED_HOSTSAllowed domain names.
CSRF_TRUSTED_ORIGINSTrusted origins for CSRF checks.

Production Environment Variables

DEBUG=False
ALLOWED_HOSTS=myproject.onrender.com
CSRF_TRUSTED_ORIGINS=https://myproject.onrender.com

Tumchya actual deployed domain nusar values set kara.

7. Render var Django Deployment

Render he web applications host karanyasathi platform aahe.

Step 1: GitHub var Project Upload Kara

git add .
git commit -m "Prepare project for deployment"
git push origin main

Step 2: Render Account Open Kara

Render account madhye login kara.

New madhun Web Service select kara.

  • GitHub account connect kara.
  • Tumcha Django repository select kara.

Step 3: Build Command

pip install -r requirements.txt
python manage.py collectstatic --noinput
python manage.py migrate

Step 4: Start Command

gunicorn config.wsgi:application

Ithe config ha Django project package aahe. Tumchya project madhye package name vegla asel tar command madhye to vapra.

Step 5: Environment Variables

Render madhye Web Service chya Environment section madhye variables configure kara.

VariableExample
SECRET_KEYGenerated secret key

ALLOWED_HOSTSmyproject.onrender.com
DATABASE_URLPostgreSQL connection URL
CSRF_TRUSTED_ORIGINShttps://myproject.onrender.com

Step 6: Deploy

  • Create Web Service click kara.
  • Build process complete honyachi wait kara.
  • Logs madhye errors aahet ka check kara.
  • Successful deployment nantar Render URL open kara.

Free Web Service idle zalyavar sleep hou shakto. Pahilya request la server start honyas vel lagu shakto. Free service madhil local filesystem persistent naste. Uploaded files tikvun thevnyasathi persistent storage kiwa external object storage vapra. Production database sathi backup ani persistence plan kara.

8. Domain Configuration

Deployment nantar Render tumhala default subdomain dete.

Example

https://myproject.onrender.com

Custom domain suddha connect karta yete.

www.myproject.com

Steps

  1. Domain provider kadun domain purchase kara.
  2. Render madhye Custom Domains section open kara.
  3. Domain name add kara.
  4. Render ne dilele DNS records domain provider madhye configure kara.
  5. DNS verification complete honyachi wait kara.
  6. HTTPS certificate active zalyachi check kara.

Custom domain sathi domain registration ani renewal charges lagu hotat.
