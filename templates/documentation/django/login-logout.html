Django Login & Logout

Learn how to use Django built-in LoginView and LogoutView to manage user authentication and sessions.

📘 Beginner Level ⏱️ 45–55 Minutes

1. Django Login & Logout mhanje kay?

Login mhanje registered user la username ani password vaprun application madhye access dene.

Logout mhanje current user chi authenticated session terminate karne.

Example

  • Login – User account madhye enter karne.
  • Dashboard – Login user la protected page dakhavne.
  • Logout – Account madhun securely baher padne.
Remember: Django built-in authentication views login ani logout process handle karnyas madat kartat.

2. Django LoginView

LoginView ha Django cha built-in Class-Based View aahe. Tyacha use user login process handle karnyasathi hoto.

Import LoginView

from django.contrib.auth.views import LoginView

Basic URL Configuration

from django.urls import path
from django.contrib.auth.views import LoginView

urlpatterns = [

    path(
        "login/",
        LoginView.as_view(),
        name="login"
    ),

]

Ya URL var user login page open karu shakto. Default template path registration/login.html asto.

Remember: LoginView automatically AuthenticationForm vaprun username ani password validate karte.

3. AuthenticationForm

AuthenticationForm ha Django cha built-in form aahe. Tyacha use user credentials validate karnyasathi hoto.

Import AuthenticationForm

from django.contrib.auth.forms import AuthenticationForm

Use with LoginView

from django.contrib.auth.views import LoginView
from django.contrib.auth.forms import AuthenticationForm

class CustomLoginView(LoginView):

    template_name = "accounts/login.html"

    form_class = AuthenticationForm

AuthenticationForm username ani password ghete ani valid credentials aahet ka te check karte.

Remember: AuthenticationForm login credentials validate karte. LoginView request ani session handling karte.

4. Custom Login Template

Login page cha design customize karnyasathi swatahcha HTML template create karta yeto.

File: templates/accounts/login.html

<h1>User Login</h1>

<form method="POST">

Ya template madhye form.as_p form fields display karte. Hidden next field user la requested page var redirect karnyas madat karte.

Important: POST form madhye csrf_token add karne required aahe. LoginView madhye next parameter automatically handle hoto; hidden field mule to form submission madhye preserve hoto.

5. Custom LoginView

LoginView customize karnyasathi subclass create karun template ani form configuration set karta yete.

Example: views.py

from django.contrib.auth.views import LoginView
from django.contrib.auth.forms import AuthenticationForm

class CustomLoginView(LoginView):

    template_name = "accounts/login.html"

    form_class = AuthenticationForm

    redirect_authenticated_user = True

redirect_authenticated_user=True aslyas already authenticated user login page open kelyavar redirect hoto.

Remember: CustomLoginView madhye LoginView che existing authentication features reuse karta yetat.

6. Django LogoutView

LogoutView ha Django cha built-in Class-Based View aahe. Tyacha use current user la logout karnyasathi hoto.

Import LogoutView

from django.contrib.auth.views import LogoutView

URL Configuration

path(
    "logout/",
    LogoutView.as_view(),
    name="logout"
)

LogoutView current authenticated session terminate karte. Django chya modern versions madhye LogoutView logout sathi POST request accept karte.

Logout Form

{% verbatim %}
<form method="POST" action="{% url 'logout' %}">

    {% csrf_token %}

    <button type="submit">
        Logout
    </button>

</form>
{% endverbatim %}
Important: Logout link sathi GET request vapru naka. POST form ani csrf_token vapra.

7. LOGIN_URL and LOGIN_REDIRECT_URL

Django settings.py madhye login ani redirect behavior configure karta yete.

settings.py

LOGIN_URL = "login"

LOGIN_REDIRECT_URL = "dashboard"

LOGOUT_REDIRECT_URL = "login"
Setting Purpose
LOGIN_URL Login page cha URL define karte.
LOGIN_REDIRECT_URL Successful login nantar redirect page define karte.
LOGOUT_REDIRECT_URL Logout nantar redirect page define karte.
Remember: LOGIN_REDIRECT_URL default redirect destination aahe. Valid next parameter aslyas user requested page var jau shakto.

8. login_required Decorator

login_required decorator cha use protected pages fakt logged-in users sathi available thevnyasathi hoto.

Example: views.py

from django.contrib.auth.decorators import login_required

@login_required
def dashboard(request):

    return render(
        request,
        "accounts/dashboard.html"
    )

User login nasel tar Django LOGIN_URL var redirect karte.

Protected URL

path(
    "dashboard/",
    views.dashboard,
    name="dashboard"
)
Important: login_required user login status check karte. Pan user la specific role kiwa permission pahije asel tar additional authorization checks implement kara.

9. next Parameter

next parameter cha use login nantar user la tyachya originally requested page var redirect karnyasathi hoto.

Example URL

/accounts/login/?next=/accounts/dashboard/

User protected dashboard open karnyacha prayatna karto, pan login naslyamule Django tyala login page var pathavte. Successful login nantar user dashboard var parat jato.

Login Template

        type="hidden"
        name="next"

Remember: Django LoginView next parameter validate karte. Invalid kiwa unsafe external redirect destinations accept kele jat nahit.

10. Login Error Messages

User ne incorrect username kiwa password enter kelyas Django AuthenticationForm validation error provide karte.

Display Form Errors

{% verbatim %}
<form method="POST">

    {% csrf_token %}

    {{ form.as_p }}

    {% if form.errors %}
        <p>Invalid username or password.</p>
    {% endif %}

    <button type="submit">Login</button>

</form>
{% endverbatim %}

form.as_p field errors display karte. Form-level errors sathi form.non_field_errors suddha use karta yetat.

Display Non-field Errors

{% verbatim %}
{% for error in form.non_field_errors %}
    <p>{{ error }}</p>
{% endfor %}
{% endverbatim %}
Remember: Invalid login credentials mule AuthenticationForm non-field error generate karu shakto.

12. Practical – Complete Login & Logout System

Ata LoginView ani LogoutView vaprun custom Login, Dashboard ani Logout System create karu.

Step 1: Create App

python manage.py startapp accounts

App already Topic 14 madhye create kela asel tar punha create karu naka.

Step 2: Register App

File: config/settings.py

INSTALLED_APPS = [

    # Existing Django Apps

    "accounts",
]

Step 3: Create LoginView

File: accounts/views.py

from django.contrib.auth.views import (
    LoginView,
    LogoutView
)

from django.contrib.auth.forms import AuthenticationForm

from django.contrib.auth.decorators import login_required

from django.shortcuts import render


class CustomLoginView(LoginView):

    template_name = "accounts/login.html"

    form_class = AuthenticationForm

    redirect_authenticated_user = True


class CustomLogoutView(LogoutView):

    next_page = "login"


@login_required
def dashboard(request):

    return render(
        request,
        "accounts/dashboard.html"
    )

Step 4: Create URLs

File: accounts/urls.py

from django.urls import path
from .views import (
    CustomLoginView,
    CustomLogoutView,
    dashboard
)

urlpatterns = [

    path(
        "login/",
        CustomLoginView.as_view(),
        name="login"
    ),

    path(
        "logout/",
        CustomLogoutView.as_view(),
        name="logout"
    ),

    path(
        "dashboard/",
        dashboard,
        name="dashboard"
    ),
]

Step 5: Include URLs

File: config/urls.py

from django.contrib import admin
