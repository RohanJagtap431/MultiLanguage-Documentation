01. Introduction to Django

Django mhanje kay, te kase work karte, tyachi garaj ka aahe ani Django vaprun web applications kasha banavtat he samjun gheu.

Beginner Level Topic 01 of 26 Python Backend Development

1. Django Mhanje Kay?

Django he Python madhye banavlele ek High-Level Web Framework aahe.

Framework mhanje website kiwa web application banavnyasathi aadhipasun tayar aslele tools, rules ani structure.

Sopya bhashet, Django aplyala backend development sathi anek ready-made features deto. Tyamule aplyala pratyek feature zero pasun create karave lagat nahi.

Real-Life Example

Samja aplyala Student Management System banvaychi aahe. Tyat khalil features asu shaktat:

  • Student Registration
  • Login and Logout
  • Student Details Save Karane
  • Database madhun Data Milavane
  • Student Information Display Karane
  • Admin Panel Madhun Records Manage Karane

He sagle features Django vaprun structured way madhye develop karta yetat.

2. Django Chi Garaj Ka Padte?

Samja tu ek College Management Website banavtoy. Ya website madhye student, teacher, attendance ani marks yanchi information store karaychi aahe.

Django nasel tar anek backend features swatah develop karave lagtil. Django madhye ya kamansathi built-in support milto.

Feature Use
URL Routing URL nusar page open karane.

3. Django Chi Important Features

1. Open Source

Django free aahe. Tyacha source code available aahe. Developers tyacha use web applications banavnyasathi karu shaktat.

2. Python Based

Django madhye backend development sathi Python programming language vaprali jate.

3. Built-in Admin Panel

Django madhye admin panel aadhipasun available asto. Tyatun database madhil records add, update ani delete karta yetat.

4. ORM (Object Relational Mapping)

ORM mule SQL queries direct lihinyayevaji Python code vaprun database sobat work karta yete.

5. Authentication System

Django madhye user registration, login, logout ani permissions sathi built-in authentication system aahe.

6. Security

Django madhye CSRF protection, SQL injection protection ani XSS sambandhit kahi security protections built-in aahet.

7. Reusable Apps

Django madhye create kelele apps dusrya Django projects madhye suddha reuse karta yetat.

Important: Django security features provide karte. Pan developer ne te yogya prakare configure ani use karane suddha avashyak aahe.

6. First Django Code Example

Aata ek simple example pahu. Browser madhye /hello/ URL open kelyavar Hello, Django! message display karaycha aahe.

File 1: views.py

from django.http import HttpResponse


def home(request):
    return HttpResponse("Hello, Django!")

Code Explanation

  • HttpResponse browser la response pathavnyasathi vapartat.
  • home() hi Django view function aahe.
  • request madhye browser kadun aleli request information aste.
  • return response browser la pathavto.

File 2: urls.py

from django.urls import path
from . import views

urlpatterns = [
    path("hello/", views.home, name="home"),
]

Code Explanation

  • path() URL define karto.
  • "hello/" ha URL cha path aahe.
  • views.home mhanje URL open zalyavar konti view execute karaychi.
  • name="home" he URL che unique name aahe.

Expected Output

http://127.0.0.1:8000/hello/
Hello, Django!
Important: Ya example madhye urls.py ha app-level URL file aahe. Project-level urls.py madhun app URLs include kele aslyas ha path work karel. Ha connection pudhil topics madhye detail madhye samjun gheu.
