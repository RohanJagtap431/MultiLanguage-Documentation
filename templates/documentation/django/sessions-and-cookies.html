Django Sessions and Cookies

Learn how Django stores session data and manages browser cookies.

Beginner Level 40–50 Minutes

1. Sessions म्हणजे काय?

Session म्हणजे server-side वर user ची माहिती काही काळासाठी store करण्याची पद्धत. HTTP requests स्वतंत्र असल्यामुळे session वापरून माहिती पुढील requests मध्ये उपलब्ध ठेवता येते.

Examples

  • User login status
  • Shopping cart data
  • User preferences
  • Temporary visit counter
User BrowserSession ID Cookie पाठवतो
↓
Django ServerSession ID तपासतो
↓
Session StorageSession Data मिळवतो
Remember: Default database-backed session मध्ये session data database मध्ये store होतो आणि browser मध्ये session ID cookie ठेवली जाते.

2. Cookies म्हणजे काय?

Cookie म्हणजे browser मध्ये store होणारा छोटा data. Browser पुढील requests सोबत संबंधित cookies server कडे पाठवू शकतो.

Name: preferred_language
Value: Marathi

Examples

  • Language preference
  • Theme preference
  • Remember-me preference
  • Tracking identifiers

3. Sessions vs Cookies

SessionsCookies
Data default मध्ये server-side store होतो.Data browser मध्ये store होतो.
Browser मध्ये session ID असते.Cookie मध्ये value असते.
Server-side expiry configure करता येते.Cookie expiry configure करता येते.
Server-side data ठेवण्यासाठी उपयुक्त.लहान browser preferences साठी उपयुक्त.
Session ID cookie सुद्धा cookie चाच प्रकार आहे. Session data आणि browser cookie एकच नाहीत.

4. Django Session Setup

Default Django project मध्ये sessions साठी app आणि middleware आधीपासून असतात. settings.py मध्ये तपासा:

INSTALLED_APPS = [
    # Existing apps
    "django.contrib.sessions",
]

MIDDLEWARE = [
    # Existing middleware
    "django.contrib.sessions.middleware.SessionMiddleware",
]

हे आधीपासून असल्यास duplicate add करू नका.

Apply Migrations

python manage.py migrate

5. Set Session Data

Session मध्ये data save करण्यासाठी request.session वापरतात.

def set_session(request):

    request.session["username"] = "Rohan"

    return HttpResponse("Session Saved")

6. Get Session Data

def get_session(request):

    username = request.session.get("username")

    return HttpResponse(username or "No session found")

get() वापरल्यास key उपलब्ध नसेल तर default value देता येते.

7. Delete Session Data

Delete One Key

request.session.pop("username", None)

Clear Entire Session

request.session.flush()
flush() session data clear करते आणि current session key invalidate करते.

8. Session Expiry

request.session.set_expiry(300)

यामुळे session activity नंतर 300 seconds म्हणजे 5 minutes expiry सेट होते.

9. Set Cookies

from django.http import HttpResponse

def set_cookie(request):

    response = HttpResponse("Cookie Saved")

    response.set_cookie(
        "username",
        "Rohan",
        max_age=3600
    )

    return response

max_age=3600 म्हणजे cookie एका तासासाठी set केली आहे.

10. Get Cookies

def get_cookie(request):

    username = request.COOKIES.get("username", "Guest")

    return HttpResponse(username)

Cookie उपलब्ध नसेल तर Guest ही default value मिळेल.

11. Delete Cookies

def delete_cookie(request):

    response = HttpResponse("Cookie Deleted")

    response.delete_cookie("username")

    return response

Cookie delete करताना आवश्यकतेनुसार set करतानाचे path आणि domain attributes जुळले पाहिजेत.

12. Practical – Website Visit Counter

Session वापरून user ने website किती वेळा visit केली हे मोजू.

Step 1: Create View

File: students/views.py

from django.http import HttpResponse

def visit_counter(request):

    visits = request.session.get("visits", 0)

    visits += 1

    request.session["visits"] = visits

    return HttpResponse(
        f"Your Visit Count: {visits}"
    )

Step 2: Create URL

File: students/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path(
        "visits/",
        views.visit_counter,
        name="visit_counter"
    ),
]

Step 3: Include App URLs

File: config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("students/", include("students.urls")),
]

students URLs आधीपासून include असतील तर duplicate करू नका.

Step 4: Run Server

python manage.py runserver

Step 5: Open URL

http://127.0.0.1:8000/students/visits/

Expected Output

First visit: Your Visit Count: 1

Second visit: Your Visit Count: 2

Third visit: Your Visit Count: 3

प्रत्येक browser session मध्ये counter वेगळा असू शकतो. Session clear किंवा expire झाल्यास count पुन्हा सुरू होऊ शकतो.

14. Important Revision

  1. Session म्हणजे server-side user data storage.
  2. Cookie म्हणजे browser मध्ये store होणारा छोटा data.
  3. request.session session access करण्यासाठी वापरतात.
  4. request.session.get() session value मिळवते.
  5. request.session.pop() एक key delete करते.
  6. request.session.flush() संपूर्ण session clear करते.
  7. set_expiry() session expiry configure करते.
  8. set_cookie() browser मध्ये cookie set करते.
  9. request.COOKIES cookie value मिळवते.
  10. delete_cookie() cookie delete करते.
