DJANGO COURSE • TOPIC 14

Django Authentication

Learn how to register users, authenticate login requests, manage sessions and protect pages using Django.

📘 Beginner Level ⏱️ 50–60 Minutes

1. Authentication mhanje kay?

Authentication mhanje user chi identity verify karne. User kharach valid aahe ka te check karnyasathi Authentication system vapartat.

Udaharanarth, user website var Login kartana Username ani Password enter karto. Django tyachi information verify karte.

Common Authentication Features

  • User Registration – New account create karne.
  • User Login – Existing account madhye login karne.
  • User Logout – Account madhun logout karne.
  • Password Management – Password change kiwa reset karne.
  • Session Management – User login status maintain karne.
Remember: Django built-in authentication system user accounts ani login management handle karte.

2. Authentication vs Authorization

Authentication ani Authorization ya donhi security concepts aahet. Pan tyanchya purpose madhye difference aahe.

Authentication Authorization
User kon aahe te verify karte. User la kay access aahe te check karte.
Identity verification. Permission verification.
Username and Password. Roles and Permissions.
Login process. Access control.

Example

Student login karto, he Authentication aahe. Student la Admin Panel access milto ka nahi, he Authorization aahe.

3. Django User Model

Django madhye built-in User Model available aahe. Ya Model cha use application madhil user information store karnyasathi hoto.

Import User Model

from django.contrib.auth.models import User

Common User Fields

Field Purpose
username User cha unique username.
password Hashed password store hoto.
email User cha email address.
first_name User cha first name.
last_name User cha last name.
is_active User account active aahe ka.
is_staff User Admin Site access karu shakto ka.
is_superuser User la all permissions aahet ka.

Create User

from django.contrib.auth.models import User

user = User.objects.create_user(
    username="rohan",
    email="rohan@example.com",
    password="StrongPassword123"
)
Important: Password direct User.objects.create() vaprun set karu naka. create_user() password hash karun save karte.

4. User Registration

User Registration cha use new user account create karnyasathi hoto.

Django madhye UserCreationForm built-in form available aahe. Ha form username, password ani password confirmation handle karto.

Import UserCreationForm

from django.contrib.auth.forms import UserCreationForm

Create Registration Form

form = UserCreationForm()

Register User

form = UserCreationForm(request.POST)

if form.is_valid():

    user = form.save()

Ya code madhye valid information aslyas new user account database madhye create hoto.

Remember: UserCreationForm password validation ani password confirmation handle karte.

5. User Login

Login process madhye user username ani password enter karto. Django tyachi identity verify karte.

authenticate() Function

authenticate() function username ani password verify karte. Credentials valid aslyas User object return hoto, nahi tar None return hoto. 

from django.contrib.auth import authenticate

user = authenticate(
    username="rohan",
    password="StrongPassword123"
)

login() Function

login() function authenticated user la current session sobat connect karte. 

from django.contrib.auth import login

login(request, user)

Login Flow Example

user = authenticate(
    request,
    username=username,
    password=password
)

if user is not None:

    login(request, user)
Remember: authenticate() user verify karte, tar login() user chi session create karte.

6. User Logout

Logout cha use current user chi login session terminate karnyasathi hoto.

Import logout

from django.contrib.auth import logout

Logout Example

def user_logout(request):

    logout(request)

    return redirect("login")

Ya code madhye logout() current session madhil authentication information clear karte.

Important: Logout operation POST request madhun karne changli security practice aahe. GET request madhun logout trigger karu naye.

7. Password Hashing

Password Hashing mhanje original password la one-way cryptographic hash format madhye convert karne.

Django user password plain text madhye store karat nahi. Django password hashing system vaprun password securely database madhye store karte.

Set Password

user.set_password("NewPassword123")

user.save()

Check Password

user.check_password("NewPassword123")

Example Output

True

Password correct aslyas check_password() True return karte. Wrong password aslyas False return karte.

Important: Password manually hash karun store karu naka. Django che set_password(), create_user() ani authentication functions vapra.

8. login_required Decorator

login_required decorator cha use specific page fakt authenticated users sathi available thevnyasathi hoto.

Example

from django.contrib.auth.decorators import login_required

@login_required
def dashboard(request):

    return render(
        request,
        "dashboard.html"
    )

User login nasel tar Django tyala login page kade redirect karte.

Settings Configuration

LOGIN_URL = "login"

settings.py madhye LOGIN_URL set kelyas login_required decorator ya URL var redirect karte.

Remember: login_required decorator function-based views protect karnyasathi vapartat.

9. Check User Login Status

Django template madhye user.is_authenticated vaprun current user login aahe ka te check karta yete.

Example

{% verbatim %}

Step 2: Create Views

File: accounts/views.py

from django.shortcuts import (
    render,
    redirect
)

from django.contrib.auth import (
    login,
    logout
)

from django.contrib.auth.forms import (
    UserCreationForm,
    AuthenticationForm
)

from django.contrib.auth.decorators import login_required


# Registration

def register_view(request):

    if request.method == "POST":

        form = UserCreationForm(request.POST)

        if form.is_valid():

            user = form.save()

            login(request, user)

            return redirect("dashboard")

    else:
        form = UserCreationForm()

    return render(
        request,
        "accounts/register.html",
        {"form": form}
    )


# Login

def login_view(request):

    if request.method == "POST":

        form = AuthenticationForm(
            request,
            data=request.POST
        )

        if form.is_valid():

            user = form.get_user()

            login(request, user)

            return redirect("dashboard")

    else:
        form = AuthenticationForm()

    return render(
        request,
        "accounts/login.html",
        {"form": form}
    )


# Dashboard

@login_required
def dashboard(request):

    return render(
        request,
        "accounts/dashboard.html"
    )


# Logout

@login_required
def logout_view(request):

    if request.method == "POST":

        logout(request)

        return redirect("login")

    return redirect("dashboard")

Problem Solution
