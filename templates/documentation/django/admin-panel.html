DJANGO COURSE • TOPIC 16

Django Admin Panel

Learn how to manage database records using Django's built-in administration interface.

📘 Beginner Level ⏱️ 40–50 Minutes

1. Django Admin Panel mhanje kay?

Django Admin Panel he Django madhye built-in administration interface aahe.

Admin Panel cha use database madhil records add, view, update ani delete karnyasathi hoto.

Example – Student Management

  • New Student add karne.
  • Existing Student details view karne.
  • Student information update karne.
  • Student record delete karne.
  • Students search ani filter karne.
Remember: Django Admin Panel automatically generate hoto. Aapan models register karun tyanna Admin madhye manage karu shakto.

2. Django Admin URL

Django project create kartana default admin URL configuration already available aste.

File: config/urls.py

from django.contrib import admin
from django.urls import path

urlpatterns = [

    path("admin/", admin.site.urls),

]

Ya URL mule Django Admin Panel access karta yeto.

Admin URL

http://127.0.0.1:8000/admin/
Remember: Project madhye admin URL already asel tar punha duplicate URL add karu naka.

3. Create Superuser

Admin Panel madhye login karnyasathi Superuser account create karava lagto.

Command

Command run kelyavar Django details vicharte:

Valid details enter kelyanantar Superuser account create hoto.

Run Server

Ata browser madhye Admin URL open karun Superuser credentials vaprun login kara.

Important: Superuser create karnyapurvi database migrations apply kelelya asne necessary aahe.

4. Model Registration

Model Registration mhanje Django model la Admin Panel madhye available karun dene.

Model register karnyasathi app madhil admin.py file use keli jate.

Example: students/admin.py

from django.contrib import admin
from .models import Student

admin.site.register(Student)

Ata Student model Admin Panel madhye disel. Admin user Student records manage karu shakel.

Remember: Model create karne ani Admin Panel madhye register karne ya don vegalya goshti aahet.

5. ModelAdmin Class

ModelAdmin class cha use Admin Panel madhil model display ani behavior customize karnyasathi hoto.

Basic Example

from django.contrib import admin
from .models import Student

@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):

    pass

@admin.register(Student) decorator Student model la StudentAdmin configuration sobat register karto.

Remember: ModelAdmin mule Admin Panel madhye columns, search, filters ani ordering customize karta yetat.

6. list_display

list_display cha use Admin Panel madhil list page var konti fields columns mhanun display karaychi te tharavnyasathi hoto.

Example

@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "id",
        "name",
        "email",
        "age",
        "course",
    )

Expected Columns

ID Name Email Age Course
1 Rahul rahul@example.com 20 BSc CS
2 Amit amit@example.com 21 BCA
Remember: list_display madhye model fields kiwa model varil suitable methods specify karta yetat.

7. search_fields

search_fields cha use Admin Panel madhye records search karnyasathi hoto.

Example

class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "name",
        "email",
        "course",
    )

    search_fields = (
        "name",
        "email",
        "course",
    )

Ata Admin Panel madhye name, email ani course vaprun Student search karta yeil.

Remember: search_fields madhye searchable text fields specify kara.

8. list_filter

list_filter cha use records filter karnyasathi hoto.

Example

class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "name",
        "age",
        "course",
    )

    list_filter = (
        "course",
        "age",
    )

Ata Admin Panel madhye course ani age nusar Student records filter karta yetil.

Remember: list_filter sidebar madhye filtering options provide karte.

9. ordering

ordering cha use Admin Panel madhil records default order madhye display karnyasathi hoto.

Example

class StudentAdmin(admin.ModelAdmin):

    ordering = ("name",)

Ya mule records name nusar ascending order madhye display hotil.

Descending Order

ordering = ("-name",)

Field chya pudhe minus (-) dilyas descending order milto.

10. list_editable

list_editable cha use list page varun kahi field values directly edit karnyasathi hoto.

Example

class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "name",
        "email",
        "age",
        "course",
    )

    list_editable = (
        "age",
        "course",
    )

Ata Student list madhye age ani course values edit karta yetil.

Important: list_editable madhil fields list_display madhye asne required aahe. list_display madhil pahila field list_editable madhye thevu naye.

11. readonly_fields

readonly_fields cha use Admin form madhye kahi fields read-only thevnyasathi hoto.

Example

class StudentAdmin(admin.ModelAdmin):

    readonly_fields = (
        "created_at",
    )

Ata created_at field Admin form madhye display hoil, pan manually edit karta yenar nahi.

12. date_hierarchy

date_hierarchy cha use date field nusar records navigate ani filter karnyasathi hoto.

Example

class StudentAdmin(admin.ModelAdmin):

    date_hierarchy = "created_at"

Admin Panel madhye created_at date nusar date navigation available hote.

Note: date_hierarchy sathi model madhye suitable DateField kiwa DateTimeField asne required aahe.

13. Admin Panel Customization

Django Admin Site cha title ani header customize karnyasathi admin site properties use karta yetat.

Example: students/admin.py

admin.site.site_header = "Student Management"

admin.site.index_title = "Welcome to Admin Panel"

Ya properties mule Admin Panel madhil heading ani browser title customize karta yetat.

15. Practical – Professional Student Admin

Ata existing Student model vaprun Admin Panel customize karu.

Step 1: Check Student Model

File: students/models.py

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)

    email = models.EmailField(unique=True)

    age = models.IntegerField()

    course = models.CharField(max_length=100)

    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.name

Ha model Topic 08 madhye create kela asel tar punha create karu naka. Existing model check kara.

Step 2: Configure Admin

File: students/admin.py

from django.contrib import admin
from .models import Student


@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "id",
        "name",
        "email",
        "age",
        "course",
        "created_at",
    )

    search_fields = (
        "name",
        "email",
        "course",
    )

    list_filter = (
        "course",
        "age",
    )

    ordering = ("name",)

    list_per_page = 10

    readonly_fields = (
        "created_at",
    )


admin.site.site_header = "Student Management System"

admin.site.site_title = "Student Admin"

admin.site.index_title = "Welcome to Student Admin Panel"
