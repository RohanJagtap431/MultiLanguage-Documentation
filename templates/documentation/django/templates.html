1. Django Template mhanje kay?

Django Template mhanje HTML file jyamadhye dynamic data display karnyasathi Django Template Language (DTL) vapartat.

Template cha use user la dynamic web pages display karnyasathi hoto.

Example: Student Website

  • HTML – Website cha structure tayar karte.
  • Template Variables – Dynamic data display kartat.
  • Template Tags – Conditions ani loops handle kartat.
  • Template Filters – Data format kartat.
Remember: Django Template madhye HTML sobat DTL syntax vaprun dynamic content display karta yete.

2. Template Folder Structure

Django madhye HTML templates store karnyasathi templates folder create karu shakto.

Project Structure

project/
│
├── config/
│   ├── settings.py
│   └── urls.py
│
├── students/
│   ├── views.py
│   ├── models.py
│   └── urls.py
│
├── templates/
│   ├── home.html
│   ├── about.html
│   └── student.html
│
└── manage.py

Template Settings

File: config/settings.py

TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [BASE_DIR / 'templates'],
        'APP_DIRS': True,
        'OPTIONS': {
            'context_processors': [
                'django.template.context_processors.request',
                'django.contrib.auth.context_processors.auth',
                'django.contrib.messages.context_processors.messages',
            ],
        },
    },
]
  • DIRS – Project-level templates folder cha path.
  • APP_DIRS – Installed apps madhil templates folder search karte.
  • BACKEND – Django Template Engine specify karte.
Important: Existing TEMPLATES setting delete karu naka. Fakt DIRS madhye templates folder cha path add kara.

3. Template Variables

Template Variable cha use View madhun alela data HTML madhye display karnyasathi hoto.

File: students/views.py

from django.shortcuts import render

def student(request):
    context = {
        "name": "Rohan",
        "age": 20,
        "course": "BSc Computer Science"
    }

    return render(request, "student.html", context)

File: templates/student.html

{% verbatim %}
<h1>Student Details</h1>

<p>Name: {{ name }}</p>
<p>Age: {{ age }}</p>
<p>Course: {{ course }}</p>
{% endverbatim %}

Expected Output

127.0.0.1:8000/student/

Student Details

Name: Rohan

Age: 20

Course: BSc Computer Science

Remember: {% templatetag openvariable %} variable {% templatetag closevariable %} ya syntax madhye variable chi value display hote.

4. Template Tags

Template Tags cha use template madhye programming logic execute karnyasathi hoto.

Common Template Tags

Tag Use
{% templatetag openblock %} if {% templatetag closeblock %} Condition check karte.
{% templatetag openblock %} for {% templatetag closeblock %} Loop execute karte.
{% templatetag openblock %} empty {% templatetag closeblock %} Loop empty asel tar content display karte.
{% templatetag openblock %} else {% templatetag closeblock %} Condition false asel tar content display karte.
{% templatetag openblock %} comment {% templatetag closeblock %} Template madhye comment lihinyasathi.
{% templatetag openblock %} url {% templatetag closeblock %} Named URL generate karte.
{% templatetag openblock %} extends {% templatetag closeblock %} Parent template inherit karte.
{% templatetag openblock %} include {% templatetag closeblock %} Dusri template include karte.

5. If-Else Conditions

If-Else cha use condition true kiwa false aahe he check karun vegvegla content display karnyasathi hoto.

File: students/views.py

from django.shortcuts import render

def result(request):
    context = {
        "marks": 75
    }

    return render(request, "result.html", context)

File: templates/result.html

{% verbatim %}
<h1>Exam Result</h1>

{% if marks >= 35 %}
    <p>Result: Pass</p>
{% else %}
    <p>Result: Fail</p>
{% endif %}
{% endverbatim %}

Expected Output

Exam Result

Marks: 75

Result: Pass

Multiple Conditions

{% verbatim %}
{% if marks >= 75 %}
    <p>Distinction</p>
{% elif marks >= 60 %}
    <p>First Class</p>
{% elif marks >= 35 %}
    <p>Pass</p>
{% else %}
    <p>Fail</p>
{% endif %}
{% endverbatim %}
  • if – First condition check karte.
  • elif – Additional condition check karte.
  • else – Remaining condition handle karte.
  • endif – If block close karte.

6. For Loop in Template

For Loop cha use list kiwa queryset madhil multiple records display karnyasathi hoto.

File: students/views.py

from django.shortcuts import render

def students(request):
    student_list = [
        "Rohan",
        "Rahul",
        "Priya",
        "Amit"
    ]

    return render(
        request,
        "students.html",
        {"students": student_list}
    )

File: templates/students.html

{% verbatim %}
<h1>Student List</h1>

{% for student in students %}
    <p>{{ student }}</p>
{% empty %}
    <p>No students found.</p>
{% endfor %}
{% endverbatim %}

Expected Output

127.0.0.1:8000/students/

Student List

Rohan

Rahul

Priya

Amit

Remember: {% templatetag openblock %} empty {% templatetag closeblock %} ha loop madhye ekahi item nasel tar execute hoto.

7. Template Filters

Template Filters cha use variable chi value format kiwa modify karnyasathi hoto.

Common Template Filters

Filter Use
upper Text uppercase karte.
lower Text lowercase karte.
title Words che first letters uppercase karte.
length Items kiwa characters chi length dete.
default Value empty asel tar default value dete.
date Date format karte.

Example

{% verbatim %}
<p>{{ name|upper }}</p>
<p>{{ name|lower }}</p>
<p>{{ name|title }}</p>
<p>{{ students|length }}</p>
<p>{{ city|default:"Not Available" }}</p>
{% endverbatim %}

8. Template Inheritance

Template Inheritance cha use common HTML layout multiple pages madhye reuse karnyasathi hoto.

Udaharanarth Header, Navbar ani Footer ekach parent template madhye create karun child templates madhye reuse karta yetat.

File: templates/base.html

{% verbatim %}
<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>

    <header>
        <h1>My Website</h1>
    </header>

    {% block content %}
    {% endblock %}

    <footer>
        <p>Copyright 2026</p>
    </footer>

</body>
</html>
{% endverbatim %}

File: templates/home.html

{% verbatim %}
{% extends "base.html" %}

{% block content %}
    <h2>Welcome to Home Page</h2>
    <p>This is my website.</p>
{% endblock %}
{% endverbatim %}
Remember: Child template madhye extends tag parent template inherit karte. Block madhye child page cha content lihila jato.

9. Include Template

Include tag cha use ek HTML component multiple templates madhye reuse karnyasathi hoto.

Folder Structure

templates/
│
├── base.html
├── home.html
│
└── components/
    ├── navbar.html
    └── footer.html

File: templates/components/navbar.html

<nav>
    <a href="/">Home</a>
    <a href="/about/">About</a>
</nav>

File: templates/base.html

{% verbatim %}
<body>

    {% include "components/navbar.html" %}

    {% block content %}
    {% endblock %}

    {% include "components/footer.html" %}

</body>
{% endverbatim %}
Important: extends parent template cha layout inherit karnyasathi, tar include reusable template component add karnyasathi vapartat.

10. Complete Practical – Student Details Page

Ata Variables, Conditions ani Loops ekatra use karun Student Details page create karu.

Step 1: students/views.py

from django.shortcuts import render

def student_details(request):

    students = [
        {"name": "Rohan", "marks": 85},
        {"name": "Rahul", "marks": 65},
        {"name": "Priya", "marks": 30}
    ]

    context = {
        "students": students,
        "college": "ABC College"
    }

    return render(
        request,
        "student_details.html",
        context
    )

Step 2: students/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path(
        "student-details/",
        views.student_details,
        name="student_details"
    ),
]

Step 3: config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("students.urls")),
]

Step 4: templates/student_details.html

{% verbatim %}
<h1>{{ college }}</h1>
<h2>Student Details</h2>

{% for student in students %}

    <div>
        <h3>{{ student.name }}</h3>
        <p>Marks: {{ student.marks }}</p>

        {% if student.marks >= 35 %}
            <p>Result: Pass</p>
        {% else %}
            <p>Result: Fail</p>
        {% endif %}
    </div>

{% empty %}
    <p>No students available.</p>
{% endfor %}
{% endverbatim %}

Step 5: Browser URL

http://127.0.0.1:8000/student-details/
