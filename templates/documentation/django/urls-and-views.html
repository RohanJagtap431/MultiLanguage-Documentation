Django URLs and Views

Learn URL routing, Function-Based Views and dynamic URLs with practical Django examples.

📘 Beginner Level ⏱️ 35–45 Minutes

1. URL mhanje kay?

URL cha full form Uniform Resource Locator aahe. URL ha website madhil specific page kiwa resource cha address asto.

Example

http://127.0.0.1:8000/students/
  • http:// – Protocol
  • 127.0.0.1 – Local development server
  • 8000 – Server port
  • students/ – URL path

User browser madhye URL enter karto. Django tya URL nusar yogya View execute karto.

2. URL Routing mhanje kay?

3. Project URLs and App URLs

Django project madhye URL configuration don levels var organize karta yete.

Project URL – config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("students.urls")),
]

App URL – students/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path("students/", views.student_list, name="student_list"),
]

Important Functions

  • path() – URL pattern define karte.
  • include() – App madhil URL patterns project sobat connect karte.
  • urlpatterns – URL patterns chi list aste.
  • views.student_list – Request handle karnari View function.
  • name – URL la unique name dete.
Important: App madhye urls.py nasel tar manually create karave lagte.

4. Function-Based View (FBV)

Function-Based View mhanje Python function cha use karun HTTP request handle karne.

File: students/views.py

from django.http import HttpResponse

def home(request):
    return HttpResponse("Welcome to Django!")

URL Configure Kara

File: students/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path("", views.home, name="home"),
]

File: config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("students.urls")),
]

Browser Output

http://127.0.0.1:8000/
127.0.0.1:8000/

Welcome to Django!

Code Explanation

  • HttpResponse – Browser la HTTP response pathavte.
  • home() – View function aahe.
  • request – Browser kadun aleli HTTP request.
  • return – Response browser kade pathavte.

5. HttpResponse() mhanje kay?

HttpResponse() cha use browser la direct text kiwa HTML response pathavnyasathi hoto.

Example 1: Simple Text

from django.http import HttpResponse

def about(request):
    return HttpResponse("This is About Page")

Example 2: HTML Response

from django.http import HttpResponse

def contact(request):
    html = "<h1>Contact Us</h1>"
    return HttpResponse(html)
Remember: HttpResponse() simple text kiwa HTML response sathi useful aahe. Full HTML pages sathi render() vaprane adhik convenient aahe.

6. render() mhanje kay?

render() function cha use HTML Template browser la display karnyasathi hoto. View madhun Template la data suddha pathavta yeto.

File: students/views.py

from django.shortcuts import render

def home(request):
    return render(request, "home.html")

File: templates/home.html

<!DOCTYPE html>
<html>
<head>
    <title>Home Page</title>
</head>
<body>
    <h1>Welcome to My Website</h1>
</body>
</html>

render() with Context Data

File: students/views.py

from django.shortcuts import render

def student(request):
    context = {
        "name": "Rohan",
        "course": "BSc Computer Science"
    }

    return render(request, "student.html", context)

File: templates/student.html

{% verbatim %}
<h1>Student Details</h1>
<p>Name: {{ name }}</p>
<p>Course: {{ course }}</p>
{% endverbatim %}

Expected Output

127.0.0.1:8000/student/

Student Details

Name: Rohan

Course: BSc Computer Science

7. Dynamic URLs

Dynamic URL madhye URL cha kahi part user request nusar change hoto. Yacha use specific student, product kiwa article display karnyasathi hoto.

Example: Student ID

File: students/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path("student/<int:id>/", views.student_detail, name="student_detail"),
]

File: students/views.py

from django.http import HttpResponse

def student_detail(request, id):
    return HttpResponse(f"Student ID: {id}")

Browser URLs

http://127.0.0.1:8000/student/1/
http://127.0.0.1:8000/student/2/
http://127.0.0.1:8000/student/10/

Output Example

URL: /student/10/

Browser Output: Student ID: 10

Common URL Converters

Converter Use Example
int Integer number 10
str Non-empty string rohan
slug Letters, numbers, hyphens, underscores django-notes
uuid UUID value UUID string

8. Multiple URL Parameters

Ekach URL madhye multiple parameters pass karta yetat.

File: students/urls.py

path(
    "student/<str:name>/<int:age>/",
    views.student_info,
    name="student_info"
),

File: students/views.py

from django.http import HttpResponse

def student_info(request, name, age):
    return HttpResponse(
        f"Name: {name}, Age: {age}"
    )

Browser URL

http://127.0.0.1:8000/student/Rohan/20/

Expected Output

Name: Rohan, Age: 20

Important: URL madhil parameter names ani View function madhil argument names match asne avashyak aahe.

9. name and reverse URL

Template madhye URL use karne

10. Complete Practical – Student Pages

Ata multiple pages create karun URL ani View connect karu.

Step 1: students/views.py

from django.http import HttpResponse

def home(request):
    return HttpResponse("Welcome to Student Website")

def about(request):
    return HttpResponse("This is About Page")

def student_detail(request, id):
    return HttpResponse(f"Student ID: {id}")

from django.urls import path
from . import views

    path("", views.home, name="home"),
    path("about/", views.about, name="about"),
    path("student/<int:id>/", views.student_detail, name="student_detail"),

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("students.urls")),
]
