Django Forms

Learn how to create forms, accept user input, validate data and save form information.

1. Django Forms mhanje kay?

Django Forms cha use user kadun information collect karnyasathi ani tyachi validation karnyasathi hoto.

Udaharanarth, Registration Form madhun user cha Name, Email ani Password gheta yeto.

Common Form Examples

  • Registration Form – New user registration.
  • Login Form – User authentication.
  • Contact Form – User messages collect karne.
  • Feedback Form – User feedback collect karne.
  • Search Form – Information search karne.
Remember: Django Forms user input handle karne ani server-side validation karnyas madat kartat.

2. HTML Forms vs Django Forms

HTML Forms browser madhye form structure tayar kartat. Django Forms Python madhye form fields ani validation rules define karu detat.

HTML Forms Django Forms
HTML madhye create hotat. Python madhye create hotat.
Basic form structure. Form fields ani validation support.
Validation manually karavi lagte. Built-in validation available aahe.
Server processing swatah handle karavi lagte. Django form processing simplify karte.

5. Form Field Options

Form Field Options cha use input field che rules, labels ani default values define karnyasathi hoto.

Option Purpose
required Field required aahe ka te define karte.
max_length Maximum text length.
min_length Minimum text length.
label Field cha display name.
initial Initial value set karte.
help_text Field sathi extra information.

Example

from django import forms

class StudentForm(forms.Form):

    name = forms.CharField(
        max_length=100,
        min_length=3,
        label="Student Name",
        required=True,
        help_text="Enter your full name"
    )

    email = forms.EmailField(
        label="Email Address",
        required=True
    )

    age = forms.IntegerField(
        min_value=16,
        max_value=60
    )

11. Display Form Errors

User ne invalid data submit kelyas Django form errors provide karte. Te template madhye display karta yetat.

Example: views.py

def student_form(request):

    if request.method == "POST":

        form = StudentForm(request.POST)

        if form.is_valid():
            print(form.cleaned_data)

    else:
        form = StudentForm()

    return render(
        request,
        "student_form.html",
        {"form": form}
    )

Remember: Invalid form parat render kelyavar entered values ani validation errors user la display karta yetat.

12. Custom Form Validation

Built-in validation sobat custom rules define karnyasathi clean_fieldname() method vapartat.

Example: Validate Name

from django import forms

class StudentForm(forms.Form):

    name = forms.CharField(max_length=100)

    def clean_name(self):

        name = self.cleaned_data["name"]

        if name.isdigit():
            raise forms.ValidationError(
                "Name cannot contain only numbers."
            )

        return name

Ya example madhye name madhye fakt numbers aslyas custom validation error display hoil.

Remember: clean_name() method name field sathi custom validation perform karte. Cleaned value return karavi lagte.

Step 3: Create View

File: students/views.py

from django.shortcuts import render, redirect
from .forms import StudentForm
from .models import Student

def register_student(request):

    if request.method == "POST":

        form = StudentForm(request.POST)

        if form.is_valid():

            Student.objects.create(
                name=form.cleaned_data["name"],
                email=form.cleaned_data["email"],
                age=form.cleaned_data["age"],
                course=form.cleaned_data["course"]
            )

            return redirect("register_student")

    else:
        form = StudentForm()

    return render(
        request,
        "register_student.html",
        {"form": form}
    )
