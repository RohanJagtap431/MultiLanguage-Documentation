Django CRUD Operations

Learn how to Create, Read, Update and Delete database records using Django.

📘 Beginner Level ⏱️ 50–60 Minutes

1. CRUD mhanje kay?

CRUD ha four basic database operations cha group aahe. Ya operations cha use application madhil data manage karnyasathi hoto.

Operation Meaning Example
Create New record add karne. New Student add karne.
Read Existing records display karne. Student list pahane.
Update Existing record change karne. Student email update karne.
Delete Record remove karne. Student delete karne.
Remember: CRUD operations cha use almost every database-based application madhye hoto.

2. CRUD Working Flow

User browser madhun request pathavto. Django View request process karte ani ORM cha use karun Database sobat communicate karte.

User Browser Request
↓
URL Request Routing
↓
View Business Logic
↓
Django ORM Database Query
↓
Database Store or Retrieve Data
Remember: Django ORM Python code madhun Database operations perform karnyas madat karte.

3. Create Operation

Create operation cha use Database madhye new record insert karnyasathi hoto.

Using create()

from .models import Student

Student.objects.create(
    name="Rohan",
    email="rohan@example.com",
    age=20,
    course="Computer Science"
)

Ya code madhye Student Model madhye new record create hoto ani database madhye save hoto.

Using ModelForm

form = StudentForm(request.POST)

if form.is_valid():

    form.save()

ModelForm vaprun validated form data directly database madhye save karta yeto.

Remember: create() ani form.save() donhi new database record create karnyasathi vaparta yetat.

4. Read Operation

Read operation cha use Database madhil records retrieve ani display karnyasathi hoto.

Get All Records

students = Student.objects.all()

Get Specific Records

students = Student.objects.filter(
    course="Computer Science"
)

Get Single Record

student = Student.objects.get(id=1)

Display Records in View

def student_list(request):

    students = Student.objects.all()

    return render(
        request,
        "student_list.html",
        {"students": students}
    )
Remember: all() multiple records return karte. filter() matching records return karte. get() ek matching record return karte.
Important: get() la matching record sapadla nahi tar DoesNotExist exception yeu shakto. Multiple records match zalyas MultipleObjectsReturned exception yeu shakto.

5. Update Operation

Update operation cha use existing database record madhil information change karnyasathi hoto.

Using save()

student = Student.objects.get(id=1)

student.name = "Rohan Jagtap"

student.save()

Ya code madhye ID 1 aslelya student cha name update hoil ani save() database madhye changes save karte.

Using update()

Student.objects.filter(
    id=1
).update(
    name="Rohan Jagtap"
)

update() QuerySet madhil matching records directly update karte.

Difference: save() Model instance var call karte. QuerySet update() direct SQL UPDATE perform karte ani Model save() method call karat nahi.

6. Delete Operation

Delete operation cha use Database madhun existing record remove karnyasathi hoto.

Delete Single Record

student = Student.objects.get(id=1)

student.delete()

Delete Multiple Records

Student.objects.filter(
    course="Computer Science"
).delete()

Ya code madhye Computer Science course aslele matching records delete hotil.

Warning: delete() operation database madhil records remove karte. Production application madhye user confirmation, permissions ani proper authorization implement kara.

8. CRUD Using Django Views

Django Views madhye CRUD operations implement karun browser requests handle karta yetat.

Create View

def add_student(request):

    if request.method == "POST":

        form = StudentForm(request.POST)

        if form.is_valid():
            form.save()

            return redirect("student_list")

    else:
        form = StudentForm()

    return render(
        request,
        "student_form.html",
        {"form": form}
    )

Read View

def student_list(request):

    students = Student.objects.all()

    return render(
        request,
        "student_list.html",
        {"students": students}
    )

Update View

def update_student(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    if request.method == "POST":

        form = StudentForm(
            request.POST,
            instance=student
        )

        if form.is_valid():
            form.save()

            return redirect("student_list")

    else:
        form = StudentForm(instance=student)

    return render(
        request,
        "student_form.html",
        {"form": form}
    )

Delete View

def delete_student(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    if request.method == "POST":

        student.delete()

        return redirect("student_list")

    return render(
        request,
        "confirm_delete.html",
        {"student": student}
    )
Remember: get_object_or_404() matching object sapadla nahi tar HTTP 404 response return karte.

9. URL Routing

URL Routing cha use browser madhun yenarya request specific View paryant pathavnyasathi hoto.

File: students/urls.py

from django.urls import path
from . import views

urlpatterns = [

    path(
        "students/",
        views.student_list,
        name="student_list"
    ),

    path(
        "students/add/",
        views.add_student,
        name="add_student"
    ),

    path(
        "students/update/<int:pk>/",
        views.update_student,
        name="update_student"
    ),

    path(
        "students/delete/<int:pk>/",
        views.delete_student,
        name="delete_student"
    ),
]

URL Examples

URL Operation
/students/ Read
/students/add/ Create
/students/update/1/ Update
/students/delete/1/ Delete Confirmation
Important: students/urls.py project chya main urls.py madhye include kele pahije.

Step 3: Create Views

File: students/views.py

from django.shortcuts import (
    render,
    redirect,
    get_object_or_404
)

from .models import Student
from .forms import StudentForm


# CREATE AND READ

def student_list(request):

    if request.method == "POST":

        form = StudentForm(request.POST)

        if form.is_valid():

            form.save()

            return redirect("student_list")

    else:
        form = StudentForm()

    students = Student.objects.all()

    return render(
        request,
        "student_list.html",
        {
            "form": form,
            "students": students
        }
    )


# UPDATE

def update_student(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    if request.method == "POST":

        form = StudentForm(
            request.POST,
            instance=student
        )

        if form.is_valid():

            form.save()

            return redirect("student_list")

    else:
        form = StudentForm(
            instance=student
        )

    return render(
        request,
        "student_update.html",
        {
            "form": form,
            "student": student
        }
    )


# DELETE

def delete_student(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    if request.method == "POST":

        student.delete()

        return redirect("student_list")

    return render(
        request,
        "student_confirm_delete.html",
        {"student": student}
    )

11. Common Mistakes

Problem Solution
DoesNotExist error get_object_or_404() vapra.
Form not saving is_valid() ani form.save() check kara.
Update creates new record instance parameter pass kara.
Delete without confirmation POST confirmation form vapra.
CSRF verification failed csrf_token add kara.
Page not found URL patterns check kara.
TemplateDoesNotExist Template path check kara.

12. Important Revision

  1. CRUD means Create, Read, Update and Delete.
  2. Create operation new records add karte.
  3. Read operation records retrieve karte.
  4. Update operation existing records change karte.
  5. Delete operation records remove karte.
  6. objects.create() new record create karte.
  7. objects.all() all records return karte.
  8. objects.filter() matching records return karte.
  9. save() Model instance save karte.
  10. delete() database record remove karte.
  11. get_object_or_404() object nahi sapadlyas 404 dete.
  12. POST request database changes sathi vapra.
