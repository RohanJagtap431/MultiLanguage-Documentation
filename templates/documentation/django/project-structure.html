DJANGO COURSE • TOPIC 03

Django Project and App Structure

Understand Django project folders, important files, project configuration and app URL connection.

📘 Beginner Level ⏱️ 25–35 Minutes

1. Django Project mhanje kay?

Django Project mhanje aaplya complete website kiwa web application cha main setup.

Example: College Management System

  • Students – Student information manage karne.
  • Teachers – Teacher information manage karne.
  • Attendance – Attendance manage karne.
  • Fees – Fees records manage karne.

2. Django App mhanje kay?

Django App mhanje project madhil ek specific functionality handle karanara module.

Remember:

Project = Complete Website / Application

App = Website madhil Specific Feature

Ek Django project madhye multiple apps asu shaktat.

4. manage.py

manage.py hi Django project madhil important file aahe. Ya file cha use project management commands run karnyasathi hoto. 

python manage.py runserver
python manage.py startapp students
python manage.py migrate
python manage.py createsuperuser
Remember: Django project var vegvegale management commands run karnyasathi manage.py use karto.

5. config Folder

config ha project cha main configuration package aahe.

A. __init__.py

  • Python la folder ha package aahe he identify karayla madat karto.
  • Generally ya file madhye kahi lihinyachi garaj naste.

B. settings.py

Hi Django project chi main settings file aahe. Yamadhye project chi configuration keli jate.

INSTALLED_APPS

Project madhye kontya apps use honar aahet te register karto.

INSTALLED_APPS = [
    "django.contrib.admin",
    "django.contrib.auth",
    "django.contrib.contenttypes",
    "django.contrib.sessions",
    "django.contrib.messages",
    "django.contrib.staticfiles",

    "students",
]

Other Important Settings

Setting Use
DATABASES Database connection configure karte.
TEMPLATES HTML templates configure karte.
STATIC_URL CSS, JS ani images sathi use hote.
DEBUG Development madhye errors display karte.
ALLOWED_HOSTS Allowed hostnames define karte.

C. urls.py

Project-level URL configuration file aahe. User chya URL nusar konta view execute karaycha he tharavnyasathi use hote. 

from django.contrib import admin
from django.urls import path

urlpatterns = [
    path("admin/", admin.site.urls),
]

D. asgi.py

ASGI cha full form Asynchronous Server Gateway Interface. Asynchronous applications serve karnyasathi deployment entry point mhanun use hote.

E. wsgi.py

WSGI cha full form Web Server Gateway Interface. Traditional synchronous Django applications sathi deployment entry point mhanun use hote.

7. Practical – Project URL ani App URL Connect Karne

Ata students app la project sobat connect karu.

Step 1: students/urls.py

students folder madhye urls.py file create kara.

from django.urls import path
from . import views

urlpatterns = [
    path("", views.home, name="home"),
]

Step 2: students/views.py

from django.http import HttpResponse

def home(request):
    return HttpResponse("Welcome to Students App!")

Step 3: config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("students/", include("students.urls")),
]
Important: include() cha use students app madhil URL patterns project sobat connect karnyasathi kela aahe.

Step 4: Server Run Kara

python manage.py runserver

Browser madhye hi URL open kara:

http://127.0.0.1:8000/students/

Expected Output

Welcome to Students App!

9. Common Mistakes

Mistake Solution
App register kele nahi INSTALLED_APPS madhye add kara.
App madhye urls.py nahi Manually create kara.
include import kele nahi include import kara.
Wrong view name URL madhil view name check kara.
Wrong URL open keli /students/ open kara.

10. Important Revision

  1. Django Project mhanje complete application.
  2. Django App mhanje specific functionality.
  3. manage.py project commands run karte.
  4. settings.py project configuration karte.
  5. urls.py URL routing karte.
  6. views.py request handle karte.
  7. models.py database models define karte.
  8. admin.py models admin panel madhye register karte.
  9. migrations database changes track karte.
  10. include() app URLs connect karte.
