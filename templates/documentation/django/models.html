2. Database mhanje kay?

Database mhanje data systematically store, organize ani manage karnyasathi vaparla janara system.

Popular Databases

  • SQLite – Lightweight database.
  • MySQL – Popular relational database.
  • PostgreSQL – Advanced relational database.

Django Default Database

4. Model Field Types

Django madhye vegveglya types cha data store karnyasathi vegvegale Model Fields available aahet.

Field Purpose
CharField Short text store karnyasathi.
TextField Long text store karnyasathi.
IntegerField Integer numbers store karnyasathi.
FloatField Decimal numbers store karnyasathi.
EmailField Email address store karnyasathi.
DateField Date store karnyasathi.
DateTimeField Date ani time store karnyasathi.
BooleanField True kiwa False value store karnyasathi.
DecimalField Fixed precision decimal values sathi.
URLField URL store karnyasathi.

Example

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)
    description = models.TextField()
    age = models.IntegerField()
    percentage = models.FloatField()
    email = models.EmailField()
    birth_date = models.DateField()
    is_active = models.BooleanField(default=True)

5. Field Options

Field Options cha use model field che rules ani default values define karnyasathi hoto.

Common Field Options

Option Purpose
max_length Maximum text length define karte.
default Default value set karte.
null Database madhye NULL allow karte.
blank Form validation madhye empty value allow karte.
unique Duplicate values prevent karte.
choices Allowed options define karte.
primary_key Field la primary key banavte.

Example

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)

    email = models.EmailField(unique=True)

    age = models.IntegerField(default=18)

    address = models.TextField(
        blank=True,
        null=True
    )

    is_active = models.BooleanField(default=True)
Important: blank ani null same nahi. blank form validation shi related aahe, tar null database madhil NULL value shi related aahe.

6. __str__() Method

__str__() method cha use model object la readable string representation denyasathi hoto.

Without __str__()

Student object (1)

With __str__()

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)
    age = models.IntegerField()

    def __str__(self):
        return self.name

Expected Output

Student Object: Rahul

Student Object: Priya

Remember: __str__() method Django Admin madhye object identify karnyasathi useful aahe.

8. Database Migrations

Migration cha use Django Model madhil changes database schema madhye apply karnyasathi hoto.

Step 1: Make Migrations

python manage.py makemigrations

Ha command models.py madhil changes detect karun migration file create karto.

Step 2: Migrate

python manage.py migrate

Ha command pending migrations database madhye apply karto.

Step 3: Show Migrations

python manage.py showmigrations

Ya command mule migrations chi status list display hote.

Migration Flow

models.py
↓
makemigrations
↓
Migration File
↓
migrate
↓
Database Table
Important: makemigrations ani migrate ya don vegveglya commands aahet. Donhi commands cha purpose samjun ghya.

from django.db import models

class Student(models.Model):

    email = models.EmailField(unique=True)
