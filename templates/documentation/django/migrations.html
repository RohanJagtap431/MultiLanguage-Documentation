Django Migrations

Learn how to create migration files, apply database changes, check migration history and manage model updates.

📘 Beginner Level ⏱️ 40–50 Minutes

1. Migration mhanje kay?

Migration mhanje Django Model madhye kelelya changes Database Schema madhye apply karnyachi process.

Udaharanarth, Student Model madhye new field add kela, tar migration mule Database Table madhye suddha required change apply karta yeto.

Example

Before:

Student
- id
- name
- age

After adding email field:

Student
- id
- name
- age
- email
Remember: Migration Model ani Database Schema madhil changes synchronize karnyas madat karte.

2. Migration Files

Django migration files automatically create karte. Ya files app madhil migrations folder madhye store hotat.

Folder Structure

students/
│
├── migrations/
│   ├── __init__.py
│   ├── 0001_initial.py
│   ├── 0002_student_email.py
│   └── 0003_student_phone.py
│
├── models.py
├── admin.py
├── views.py
└── apps.py
  • __init__.py – Migrations folder Python package banavte.
  • 0001_initial.py – First migration file.
  • 0002_student_email.py – Email field add karnyachi migration.
  • 0003_student_phone.py – Phone field add karnyachi migration.
Important: Migration file manually edit kiwa delete karu naka, jo paryant tyachi garaj ani result purnapane samajlela nahi.

3. makemigrations Command

makemigrations command cha use Model madhil changes detect karun migration files create karnyasathi hoto.

Command

python manage.py makemigrations

Example

File: students/models.py

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)
    age = models.IntegerField()
    email = models.EmailField()

Terminal madhye command run kara:

python manage.py makemigrations students

Expected Output

Migrations for 'students':
  students/migrations/0002_student_email.py
    + Add field email to student
Remember: makemigrations migration file create karte. Ti database madhye changes apply karat nahi.

4. migrate Command

migrate command cha use pending migration files Database madhye apply karnyasathi hoto.

Command

python manage.py migrate

Expected Output

Operations to perform:
  Apply all migrations

Running migrations:
  Applying students.0002_student_email... OK

Ya command mule migration madhye define kelelya database changes apply hotat.

Important: makemigrations ani migrate ya don vegveglya commands aahet. Migration file create karne ani ti apply karne ya don veglya processes aahet.

5. showmigrations Command

showmigrations command cha use project madhil migrations ani tyanchi applied status check karnyasathi hoto.

Command

python manage.py showmigrations

Expected Output

admin
 [X] 0001_initial
 [X] 0002_logentry_remove_auto_add

auth
 [X] 0001_initial
 [X] 0002_alter_permission_name_max_length

students
 [X] 0001_initial
 [X] 0002_student_email

Status Meaning

  • [X] – Migration apply zali aahe.
  • [ ] – Migration ajun apply zali nahi.
Remember: showmigrations database madhil migration status samajnyas madat karte.

6. sqlmigrate Command

sqlmigrate command cha use specific migration file sathi Django konti SQL statements generate karel te pahanyasathi hoto.

Syntax

python manage.py sqlmigrate app_name migration_number

Example

python manage.py sqlmigrate students 0002

Expected SQL Example

BEGIN;

ALTER TABLE "students_student"
ADD COLUMN "email" varchar(254) NOT NULL;

COMMIT;

Actual SQL database engine ani migration madhil operations nusar vegli asu shakte.

Remember: sqlmigrate SQL statements display karte. Ti migration database madhye apply karat nahi.

8. Model Changes and Migrations

Model madhye new field add, existing field modify kiwa field remove kelyas migration create karavi lagte.

Example 1: Add New Field

class Student(models.Model):

    name = models.CharField(max_length=100)
    age = models.IntegerField()
    email = models.EmailField()

    phone = models.CharField(
        max_length=15,
        blank=True
    )

Commands:

python manage.py makemigrations
python manage.py migrate

Example 2: Modify Field

Before:

name = models.CharField(max_length=50)

After:

name = models.CharField(max_length=150)

Ata migration create karun database madhye apply kara.

Example 3: Remove Field

# Remove phone field from Student model

10. Rollback Migration

Rollback cha use specific app la previous migration state madhye parat aananyasathi hoto.

Example

python manage.py migrate students 0001

Ya command mule students app la 0001 migration paryant parat aanle jate. Tyapudhil applied migrations reverse karnyacha prayatna hoto.

Warning: Rollback mule database schema kiwa data madhye changes hou shaktat. Command run karnyapurvi migration plan ani data backup check kara.

11. Common Migration Errors

Error / Problem Solution
No changes detected Model madhye actual changes aahet ka check kara.
No such table Required migrations apply kara.
App not installed INSTALLED_APPS madhye app add kara.
Duplicate column Database schema ani migration history check kara.
NOT NULL constraint failed Existing records sathi suitable default kiwa data migration plan kara.
Conflicting migrations Migration dependencies ani conflict carefully resolve kara.

12. Complete Practical – Add Fields to Student Model

Step 2: Add New Fields

Student Model update kara:

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)

    email = models.EmailField(unique=True)

    age = models.IntegerField()

    course = models.CharField(max_length=100)

    phone = models.CharField(
        max_length=15,
        blank=True
    )

    address = models.TextField(
        blank=True
    )

    def __str__(self):
        return self.name

Step 3: Create Migration

python manage.py makemigrations students

Step 4: Apply Migration

python manage.py migrate

Step 5: Check Migration Status
