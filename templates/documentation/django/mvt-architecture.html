Django MVT Architecture

Understand Model, View and Template architecture with a practical Student Management example.

📘 Beginner Level ⏱️ 30–40 Minutes

1. MVT Architecture mhanje kay?

MVT cha full form Model, View ani Template aahe. Hi Django madhye application organize karnyachi architecture pattern aahe.

Pratyek component la specific responsibility aste.

Example: Student Management System

  • Model – Student cha data database madhye store karto.
  • View – Student cha data retrieve ani process karto.
  • Template – Student cha data HTML madhye display karto.

MODEL

Database madhil data manage karto.

↕

VIEW

Request process karun Model ani Template connect karto.

↕

TEMPLATE

HTML madhye data display karte.

2. Model mhanje kay?

Model ha Django madhil database layer aahe. Model cha use database madhye data create, store, update ani retrieve karnyasathi hoto.

File: students/models.py

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()
    course = models.CharField(max_length=100)

    def __str__(self):
        return self.name

Code Explanation

  • models.Model – Student class la Django Model banavte.
  • name – Student che name store karte.
  • CharField – Text data store karnyasathi.
  • max_length=100 – Maximum 100 characters.
  • IntegerField – Integer number store karnyasathi.
  • __str__() – Object chi readable representation return karte.
Important: Model varun Django database table tayar karu shakto.

Migration Commands

python manage.py makemigrations
python manage.py migrate

3. View mhanje kay?

View ha Django madhil logic layer aahe. View user kadun request receive karto, Model madhun data gheto ani Template render karun response pathavto.

File: students/views.py

from django.shortcuts import render
from .models import Student

def student_list(request):

    students = Student.objects.all()

    return render(
        request,
        "students/student_list.html",
        {"students": students}
    )

Code Explanation

  • render – HTML template render karte.
  • Student – Model import karto.
  • Student.objects.all() – Sarva student records retrieve karto.
  • request – User chi HTTP request.
  • student_list.html – Template file cha path.
  • {"students": students} – Template la data pathavto.

4. Template mhanje kay?

Template ha presentation layer aahe. Template cha use HTML madhye data display karnyasathi hoto.

File: templates/students/student_list.html

{% verbatim %}
<!DOCTYPE html>
<html>
<head>
    <title>Student List</title>
</head>
<body>

    <h1>Student List</h1>

    {% for student in students %}

        <h3>{{ student.name }}</h3>
        <p>Age: {{ student.age }}</p>
        <p>Course: {{ student.course }}</p>

    {% empty %}

        <p>No students found.</p>

    {% endfor %}

</body>
</html>
{% endverbatim %}

Template Syntax

Syntax Use
{% templatetag openvariable %} variable {% templatetag closevariable %} Variable chi value display karte.
{% templatetag openblock %} for student in students {% templatetag closeblock %} Loop start karte.
{% templatetag openblock %} endfor {% templatetag closeblock %} Loop end karte.
{% templatetag openblock %} if condition {% templatetag closeblock %} Condition check karte.
{% templatetag openblock %} empty {% templatetag closeblock %} Loop madhye items naslyas content display karte.

5. URL Dispatcher mhanje kay?

User browser madhye URL open karto. Django URL configuration request la yogya View kade route karte.

File: students/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path("students/", views.student_list, name="student_list"),
]

File: config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("students.urls")),
]
Remember: include() cha use app madhil URL patterns project sobat connect karnyasathi hoto.

Browser madhye hi URL open kara:

http://127.0.0.1:8000/students/

8. MVC vs MVT Architecture

MVC ani MVT ya donhi software architecture patterns aahet. Django madhye MVT pattern vaparla jato.

MVC Django MVT
Model Model
View Template
Controller View
Controller request handle karto. Django View request handle karto.
View presentation handle karto. Template presentation handle karte.
Remember: Django madhye View ani Template yanchi responsibility MVC peksha veglya prakare map keli jate.
