Django Messages Framework

Learn how to display temporary notifications such as success, error, warning and information messages in Django.

Intermediate Level 45–60 Minutes

1. Messages Framework mhanje kay?

Django Messages Framework ha built-in feature aahe. Tyachya madatine user la temporary notification messages display karta yetat.

Examples

  • Student Added Successfully!
  • Student Updated Successfully!
  • Student Deleted Successfully!
  • Invalid Data!
  • Please Login First!

Message usually pudhchya response madhye display hoto ani read zalyavar remove hoto.

4. Success Message

Operation successfully complete zalyavar success message display karnyasathi messages.success() vapartat.

from django.contrib import messages

    request,
    "Student Added Successfully!"
)
✓ Student Added Successfully!

11. Practical – Student CRUD Notifications

Ata Student Management System madhye Student Add, Update ani Delete zalyavar success messages display karu.

Step 1: Import Messages

File: students/views.py

from django.contrib import messages

Step 2: Student Create View

from django.shortcuts import render, redirect
from django.contrib import messages
from .forms import StudentForm

def add_student(request):

    if request.method == "POST":

        form = StudentForm(request.POST)

        if form.is_valid():

            form.save()

            messages.success(
                request,
                "Student Added Successfully!"
            )

            return redirect("student_list")

        else:

            messages.error(
                request,
                "Please correct the errors."
            )

    else:

        form = StudentForm()

    return render(
        request,
        "students/add.html",
        {"form": form}
    )

Step 3: Student Update View

from django.shortcuts import get_object_or_404

def update_student(request, pk):

    student = get_object_or_404(Student, pk=pk)

    if request.method == "POST":

        form = StudentForm(
            request.POST,
            instance=student
        )

        if form.is_valid():

            form.save()

            messages.success(
                request,
                "Student Updated Successfully!"
            )

            return redirect("student_list")

    else:

        form = StudentForm(instance=student)

    return render(
        request,
        "students/add.html",
        {"form": form}
    )

Step 4: Student Delete View

def delete_student(request, pk):

    student = get_object_or_404(Student, pk=pk)

    if request.method == "POST":

        student.delete()

        messages.success(
            request,
            "Student Deleted Successfully!"
        )

        return redirect("student_list")

    return render(
        request,
        "students/delete.html",
        {"student": student}
    )

Important Notes
  • Messages Framework madhye default storage sathi session ani cookie-based fallback mechanism vaparla jau shakto.
  • Messages display kelyanantar normally consume hotat.
  • messages.error() mule database operation automatic rollback hot nahi.
  • CRUD operations sathi POST request, CSRF protection ani permissions vapra.
