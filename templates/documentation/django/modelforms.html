Django ModelForms

Learn how to create forms directly from models, validate user input and perform database operations.

📘 Beginner Level ⏱️ 45–55 Minutes

1. ModelForms mhanje kay?

Django ModelForm ha built-in class aahe. Tyacha use Django Model var based Form create karnyasathi hoto.

ModelForm automatically Model madhil fields vaprun Form tayar karto. Valid data save karnyasathi form.save() method vaparta yete.

Example

Samja Student Model madhye name, email, age ani course he fields aahet. ModelForm vaprun ya fields sathi Form automatically create karta yeto.

Remember: ModelForm mule Model ani Form madhil connection soppe hote.

2. Forms vs ModelForms

Django madhye forms.Form ani forms.ModelForm donhi user input collect ani validate karnyasathi vapartat. Pan tyanchya working madhye difference aahe.

forms.Form forms.ModelForm
Fields manually define karave lagtat. Model madhun fields generate hotat.
Model sobat direct connection nahi. Specific Model sobat connected asto.
Data manually save karava lagto. form.save() vaprun save karta yeto.
Custom forms sathi useful. Database Model based forms sathi useful.

3. Create a ModelForm

ModelForm create karnyasathi django.forms madhun ModelForm import karava lagto.

File: students/forms.py

from django import forms
from .models import Student

class StudentForm(forms.ModelForm):

    class Meta:
        model = Student
        fields = "__all__"

Ya code madhye:

  • forms.ModelForm – ModelForm base class.
  • class Meta – ModelForm configuration define karte.
  • model = Student – Student Model select karto.
  • fields = "__all__" – Model madhil sarva editable fields include karto.
Remember: ModelForm madhye Meta class vaprun Model ani Form madhye konthe fields pahijet te define kartat.

4. Meta Class

ModelForm madhye Meta class cha use Form chi configuration define karnyasathi hoto.

Important Meta Options

Option Purpose
model Kontya Model var Form based aahe te sangte.
fields Form madhye konthe fields pahijet te select karte.
exclude Specific Model fields Form madhun exclude karte.
widgets Form fields che widgets customize karte.
labels Fields che display labels customize karte.
help_texts Fields sathi help information define karte.

Example

from django import forms
from .models import Student

class StudentForm(forms.ModelForm):

    class Meta:
        model = Student

        fields = [
            "name",
            "email",
            "age",
            "course"
        ]

Ya example madhye Student Model madhil fakt name, email, age ani course fields Form madhye include hotil.

5. fields and exclude

ModelForm madhye fields ani exclude cha use Form madhye konthe fields display karayche te control karnyasathi hoto.

Using fields

class StudentForm(forms.ModelForm):

    class Meta:
        model = Student
        fields = ["name", "email", "age"]

Ya Form madhye fakt name, email ani age fields display hotil.

Using exclude

class StudentForm(forms.ModelForm):

    class Meta:
        model = Student
        exclude = ["created_at"]

Ya example madhye created_at field Form madhun exclude hoil. Itar editable Model fields include hotil.

Important: fields ani exclude donhi ekach Meta configuration madhye vapru naye. Explicit fields list vaprane applications madhye adhik safe aahe.

6. Customize ModelForm Widgets

ModelForm madhye widgets vaprun input fields cha appearance customize karta yeto.

Example: forms.py

from django import forms
from .models import Student

class StudentForm(forms.ModelForm):

    class Meta:
        model = Student

        fields = [
            "name",
            "email",
            "age",
            "course"
        ]

        widgets = {
            "name": forms.TextInput(
                attrs={
                    "placeholder": "Enter name"
                }
            ),

            "email": forms.EmailInput(
                attrs={
                    "placeholder": "Enter email"
                }
            ),

            "age": forms.NumberInput(
                attrs={
                    "min": 16
                }
            ),

            "course": forms.TextInput(
                attrs={
                    "placeholder": "Enter course"
                }
            )
        }

widgets madhye attrs dictionary vaprun placeholder, class, id ani itar HTML attributes set karta yetat.

7. form.save() Method

form.save() method cha use validated ModelForm data database madhye save karnyasathi hoto.

Example

form = StudentForm(request.POST)

if form.is_valid():

    form.save()

Ya code madhye form valid aslyas Django automatically Student Model madhye record create karte.

save(commit=False)

save(commit=False) vaparlyas Model object tayar hoto, pan to lagech database madhye save hot nahi. 

form = StudentForm(request.POST)

if form.is_valid():

    student = form.save(commit=False)

    student.course = "Computer Science"

    student.save()
Remember: commit=False mule object database madhye save karnyapurvi additional changes karta yetat.

8. Update Form using instance

Existing database record update karnyasathi ModelForm madhye instance parameter vapartat.

Example

student = Student.objects.get(id=1)

form = StudentForm(
    instance=student
)

Ya code madhye existing student cha data Form madhye automatically fill hoil.

Submit Updated Data

student = Student.objects.get(id=1)

form = StudentForm(
    request.POST,
    instance=student
)

if form.is_valid():

    form.save()

Ya example madhye existing student record update hoil. Navin record create honar nahi.

Important: instance pass na kelyas form.save() navin object create karu shakto. Existing record update karaycha aslyas instance vapra.

9. ModelForm Validation

ModelForm automatically Model fields var based validation perform karto.

Example

from django import forms
from .models import Student

class StudentForm(forms.ModelForm):

    class Meta:
        model = Student
        fields = [
            "name",
            "email",
            "age",
            "course"
        ]

    def clean_name(self):

        name = self.cleaned_data["name"]

        if name.isdigit():
            raise forms.ValidationError(
                "Name cannot contain only numbers."
            )

        return name

Ya example madhye name field sathi custom validation add keli aahe.

Important Validation Methods

  • is_valid() – Submitted data validate karte.
  • cleaned_data – Validated data provide karte.
  • clean_name() – Name field sathi custom validation.
  • ValidationError – Custom error display karte.
Remember: ModelForm madhye Model field validation ani custom validation donhi use karta yetat.

Step 3: Create Views

File: students/views.py

from django.shortcuts import (
    render,
    redirect,
    get_object_or_404
)

from .models import Student
from .forms import StudentForm


# Display and Create Student

def student_list(request):

    if request.method == "POST":

        form = StudentForm(request.POST)

        if form.is_valid():
            form.save()
            return redirect("student_list")

    else:
        form = StudentForm()

    students = Student.objects.all()

    return render(
        request,
        "student_list.html",
        {
            "form": form,
            "students": students
        }
    )


# Update Student

def student_update(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    if request.method == "POST":

        form = StudentForm(
            request.POST,
            instance=student
        )

        if form.is_valid():
            form.save()
            return redirect("student_list")

    else:
        form = StudentForm(
            instance=student
        )

    return render(
        request,
        "student_update.html",
        {
            "form": form,
            "student": student
        }
    )


# Delete Student

def student_delete(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    if request.method == "POST":

        student.delete()

        return redirect("student_list")

    return render(
        request,
        "student_confirm_delete.html",
        {"student": student}
    )
Important: Delete operation POST request madhun keli aahe. GET request madhun database record delete karu naye. Real application madhye ya views la authentication ani permission checks suddha add kara.
