DJANGO COURSE • TOPIC 24

Django Security

Learn how to protect Django applications, user accounts and database information from common security attacks.

Intermediate Level 60–75 Minutes

1. Django Security mhanje kay?

Django Security mhanje website, user data ani database la unauthorized access ani attacks pasun protect karne.

Example

Student Management System madhye:

  • Student login karto.
  • Student personal information baghto.
  • Admin student records manage karto.

Security nasel tar dusra user unauthorized access karu shakto.

Django madhye anek built-in security features aahet.

2. SQL Injection

SQL Injection ha database attack aahe. Attacker input field madhye malicious SQL code takun database madhil data access kiwa modify karanyacha prayatna karto.

Unsafe Example

query = "SELECT * FROM students WHERE name = '" + username + "'"
cursor.execute(query)

Ya code madhye user input direct SQL query madhye add hot aahe. He dangerous aahe.

Safe Example – Django ORM

students = Student.objects.filter(
    name=username
)

Django ORM parameterized database queries vaparte. Mhanun normal ORM queries madhye user input direct SQL code mhanun execute hot nahi.

Important

Database queries sathi Django ORM prefer kara. Raw SQL vaprat asal tar parameters bind kara; string concatenation karu naka.

3. CSRF Protection

CSRF cha full form Cross-Site Request Forgery aahe.

Ha attack user login asatana tyachya browser madhun tyala nakalat unwanted request pathavnyacha prayatna karto.

Example

Samja user bank website madhye login aahe. Attacker user kadun tyachya nakalat money transfer request submit karun ghenyacha prayatna karto.

Django madhye CSRF protection built-in aahe.

HTML Form Example

{% verbatim %}
<form method="POST">

    {% csrf_token %}

    <input type="text" name="username">

    <button type="submit">
        Submit
    </button>

</form>
{% endverbatim %}

{% templatetag openblock %} csrf_token {% templatetag closeblock %} form madhye CSRF token add karto.

  • POST form madhye csrf_token vapra.
  • Django madhye CsrfViewMiddleware enabled theva.
  • CSRF protection disable karu naka.

4. XSS Attack

XSS cha full form Cross-Site Scripting aahe.

Attacker website madhye malicious JavaScript inject karanyacha prayatna karto.

Example

<script>alert("Hacked")</script>

Jar website ha input unsafe HTML mhanun display karat asel tar browser madhye script execute hou shakto.

Django Safe Output

{% verbatim %}
<p>{{ student.name }}</p>
{% endverbatim %}

Django templates madhye autoescaping default enabled aste. Normal variable output madhil HTML special characters escape hotat.

Dangerous Example

{% verbatim %}
{{ student.name|safe }}
{% endverbatim %}

safe filter output la trusted HTML samjun render karte. Untrusted user input var ha filter vapru naka.

  • Template madhye normal variable output vapra.
  • Untrusted data var safe filter vapru naka.
  • User input validate kara.
  • Rich HTML allow karaycha asel tar trusted sanitizer vapra.

5. Clickjacking Protection

Clickjacking madhye attacker dusrya website cha page invisible frame madhye load karun user kadun nakalat click karun ghenyacha prayatna karto.

Django madhye XFrameOptionsMiddleware protection dete.

Settings Example

MIDDLEWARE = [
    "django.middleware.security.SecurityMiddleware",
    "django.contrib.sessions.middleware.SessionMiddleware",
    "django.middleware.common.CommonMiddleware",
    "django.middleware.csrf.CsrfViewMiddleware",
    "django.contrib.auth.middleware.AuthenticationMiddleware",
    "django.contrib.messages.middleware.MessageMiddleware",
    "django.middleware.clickjacking.XFrameOptionsMiddleware",
]

Default Django setup madhye XFrameOptionsMiddleware enabled aste.

X-Frame-Options Setting

X_FRAME_OPTIONS = "DENY"

Yamule website dusrya site chya frame madhye load honyapasun block hote.

6. Secure Password Handling

User passwords secure thevne khup important aahe. Django password hashing system vaparte.

Unsafe Example

password = "rohan123"

Password plain text madhye store karne unsafe aahe.

Safe Example

from django.contrib.auth.hashers import make_password

hashed_password = make_password("rohan123")

Password Verify

from django.contrib.auth.hashers import check_password

check_password("rohan123", hashed_password)

Django chya built-in User system madhye set_password() ani check_password() suddha vaparta yetat.

  • Password database madhye plain text madhye store karu naka.
  • Django authentication system vapra.
  • Password hash swatah manually create karu naka.
  • Password user la parat display karu naka.

7. HTTPS ani Secure Cookies

HTTPS website ani user browser madhil communication encrypt karte.

Example URL

8. Important Django Security Settings

Production website secure thevnyasathi settings.py madhye kahi settings configure karavya lagtat.

DEBUG = False

ALLOWED_HOSTS = [
    "example.com",
]

SECURE_CONTENT_TYPE_NOSNIFF = True

X_FRAME_OPTIONS = "DENY"

SESSION_COOKIE_HTTPONLY = True

CSRF_COOKIE_HTTPONLY = False
SettingMeaning
DEBUG = FalseProduction madhye detailed error pages hide karte.
ALLOWED_HOSTSValid hostnames specify karte.
SECURE_CONTENT_TYPE_NOSNIFFBrowser la content type guess karanyapasun rokhte.
X_FRAME_OPTIONSClickjacking pasun protection dete.
SESSION_COOKIE_HTTPONLYJavaScript madhun session cookie access block karte.
CSRF_COOKIE_HTTPONLYJavaScript madhun CSRF cookie access block karte.

CSRF_COOKIE_HTTPONLY = False he Django madhil default behavior aahe. JavaScript-based CSRF token handling sathi kahi applications madhye cookie read karavi lagte. Tumchya application chi garaj samjun setting kara.

9. Django Security Checklist

Production website deploy karanyapurvi he points check kara:

  • DEBUG = False theva.
  • SECRET_KEY environment variable madhye theva.
  • ALLOWED_HOSTS madhye valid domains dya.
  • HTTPS enable kara.
  • CSRF middleware enabled theva.
  • User input validate kara.
  • Password Django authentication system ne handle kara.
  • Database credentials .env madhye theva.
  • Sensitive information GitHub var upload karu naka.
  • Django security updates install kara.

Security Check Command

python manage.py check --deploy

Ha command production deployment sathi security-related warnings dakhavto. Warnings review karun appropriate settings configure kara.

10. Practical – Secure Student Management System

Ata existing Student Management System madhye security settings configure karu.

    "example.com",
