CSS Flexbox

CSS Flexbox cha use webpage madhil elements arrange ani align karanyasathi hoto.

📘 Beginner Level ⏱️ 30 Minutes 📄 Page 15

1. Introduction to Flexbox

Flexbox mhanje Flexible Box Layout. Yacha use container madhil child elements eka row kiwa column madhye arrange karanyasathi hoto.

Flexbox mule elements chi alignment, spacing ani size control karne sope hote.

Definition: CSS Flexbox is a one-dimensional layout system used to arrange elements in rows or columns.

Flexbox madhil don important terms

  • Flex Container: Jya parent element la display: flex dile aahe.
  • Flex Items: Flex container madhil direct child elements.

2. Display: Flex

Flexbox start karanyasathi parent container la display: flex dyave lagte. Tyamule tyache direct child elements flex items bantat.

CSS Code

.container {
    display: flex;
}

3. Flex Direction

flex-direction property cha use flex items kontya direction madhye arrange hotil he set karanyasathi hoto.

Available Values

  • row: Items left to right arrange hotat.
  • row-reverse: Items right to left arrange hotat.
  • column: Items top to bottom arrange hotat.
  • column-reverse: Items bottom to top arrange hotat.

CSS Code

.container {
    display: flex;
    flex-direction: row;
}

4. Justify Content

justify-content property cha use main axis var flex items chi alignment ani spacing control karanyasathi hoto.

Available Values

  • flex-start: Items suruvatila align hotat.
  • flex-end: Items shevati align hotat.
  • center: Items center la yetat.
  • space-between: Items madhye equal space aste.
  • space-around: Items chya around space aste.
  • space-evenly: Saglikade equal space aste.

CSS Code

.container {
    display: flex;
    justify-content: center;
}

5. Align Items

align-items property cha use cross axis var flex items chi alignment control karanyasathi hoto.

Available Values

  • stretch: Items cross axis var stretch hotat. (Default)
  • flex-start: Suruvatila align hotat.
  • flex-end: Shevati align hotat.
  • center: Center la align hotat.
  • baseline: Text baseline nusar align hotat.

CSS Code

.container {
    display: flex;
    align-items: center;
    height: 150px;
}

6. Flex Wrap

flex-wrap property cha use items container madhye fit hot nastil tar te next line madhye jayche ki nahi he control karanyasathi hoto.

Available Values

  • nowrap: Items eka line madhye rahatat. (Default)
  • wrap: Items garaj padlyas next line madhye jatat.
  • wrap-reverse: Items reverse cross direction madhye wrap hotat.

.container {
    display: flex;

8. Flex Grow, Shrink and Basis

Ya properties cha use flex items la available space nusar size denyasathi kiwa size kami karanyasathi hoto.

Flex Grow

flex-grow property extra available space items madhye kasha prakare divide hoil he control karte. 

.item {
    flex-grow: 1;
}

Flex Shrink

flex-shrink property container madhye space kami aslyas item kiti shrink hou shakto he control karte. 

.item {
    flex-shrink: 1;
}

Flex Basis

flex-basis property item cha initial main size set karte. 

.item {
    flex-basis: 200px;
}

Combined Example

.item {
    flex: 1 1 200px;
}

Ya shorthand madhye values cha order flex-grow, flex-shrink ani flex-basis asa asto.

9. Practical Flexbox Layout

Aata Flexbox vaprun ek simple card layout tayar karuya.

HTML Code

<div class="card-container">

    <div class="card">
        <h3>HTML</h3>
        <p>Learn HTML basics.</p>
    </div>

    <div class="card">
        <h3>CSS</h3>
        <p>Learn CSS styling.</p>
    </div>

    <div class="card">
        <h3>JavaScript</h3>
        <p>Learn JavaScript basics.</p>
    </div>

</div>

CSS Code

.card-container {
    display: flex;
    flex-wrap: wrap;
    gap: 15px;
}

.card {
    flex: 1 1 200px;
    padding: 20px;
    background-color: #eff6ff;
    border: 1px solid #2563eb;
}

Output

HTML

Learn HTML basics.

CSS

Learn CSS styling.

JavaScript

Learn JavaScript basics.

10. Important Points

  • display: flex parent element la flex container banavte.
  • Direct children flex items bantat.
  • flex-direction items chi direction set karte.
  • justify-content main axis var alignment karte.
  • align-items cross axis var alignment karte.
  • flex-wrap items la next line madhye jau dete.
  • gap items madhil space set karte.
  • flex-grow extra space divide karte.
  • flex-shrink available space kami aslyas shrinking control karte.
  • flex-basis initial main size set karte.
