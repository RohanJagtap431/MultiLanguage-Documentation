CSS Selectors

CSS Selectors cha use HTML madhil specific elements select karanyasathi hoto. Select kelelya elements la aapan CSS vaprun vegveglya styles deu shakto.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 04

1. CSS Selectors Mhanje Kay?

CSS Selector mhanje HTML madhil konta element style karaycha aahe he tharavnyachi paddhat.

Samja aaplya webpage var anek headings ani paragraphs aahet. Aaplyala fakt heading cha color blue karaycha asel, tar CSS Selector vaprun aapan fakt headings select karu shakto.

Definition: CSS Selector cha use HTML elements select karun tyanna CSS styles apply karanyasathi hoto.

CSS Selectors Che Prakar

h1 Element Selector
# ID Selector
. Class Selector
* Universal Selector
, Grouping Selector
Space Descendant Selector

2. Element Selector

Element Selector cha use HTML tag chya navavarun elements select karanyasathi hoto.

Udaharanarth, aaplyala webpage varil saglya h1 headings cha color blue karaycha asel, tar aapan h1 selector vapru shakto.

HTML Code

<h1>CSS Shika</h1>

<h1>Web Development</h1>

<p>Ha ek paragraph aahe.</p>

CSS Code

h1 {
    color: blue;
}

p {
    color: gray;
}

Output

CSS Shika

Web Development

Ha ek paragraph aahe.

Lakshat Theva: Element Selector vaparlyas tyach navache sagle HTML elements select hotat.

3. ID Selector

ID Selector cha use HTML madhil ek specific element select karanyasathi hoto.

CSS madhye ID select karanyasathi hash (#) symbol vapartat. HTML madhye dilele ID ani CSS madhil ID selector yanche nav same asle pahije.

HTML Code

<h1 id="title">
    Majhi Pahili Website
</h1>

<p>Majhya Website Madhye Tumche Swagat Aahe.</p>

CSS Code

#title {
    color: red;
    text-align: center;
}

Output

Majhi Pahili Website

Majhya Website Madhye Tumche Swagat Aahe.

Important: Eka HTML page madhye ekach ID multiple elements na deu naye. ID unique thevane yogya aahe.

4. Class Selector

Class Selector cha use ekach class name aslele anek HTML elements select karanyasathi hoto.

CSS madhye Class Selector lihitana dot (.) symbol vapartat. HTML madhil class name ani CSS madhil class selector same asla pahije.

HTML Code

<p class="message">
    Pahila Sandesh
</p>

<p class="message">
    Dusra Sandesh
</p>

<p>
    Sadharan Paragraph
</p>

CSS Code

.message {
    color: green;
    font-size: 20px;
}

Output

Pahila Sandesh

Dusra Sandesh

Sadharan Paragraph

Lakshat Theva: Ekach class name anek HTML elements na deta yeto. Mhanun Class Selector cha use khup jast hoto.

5. Universal Selector

Universal Selector cha use webpage varil sarva HTML elements select karanyasathi hoto.

Universal Selector sathi asterisk (*) symbol vapartat. Yacha use common styling denyasathi kela jato.

HTML Code

<h1>Namaskar</h1>

<p>Pahila Paragraph</p>

<h2>Amchyabaddal</h2>

CSS Code

* {
    font-family: Arial, sans-serif;
    box-sizing: border-box;
}

Ya CSS mule webpage varil saglya elements na Arial font ani border-box sizing lagu hote.

Important: Universal Selector cha use basic global styling ani CSS reset sathi suddha kela jato.

6. Grouping Selector

Grouping Selector cha use ekach CSS style anek vegveglya selectors na denyasathi hoto.

Selectors separate karanyasathi comma (,) symbol vapartat.

Samja h1, h2 ani p ya tinhi elements cha color same thevaycha aahe. Tar tin vegle CSS rules lihinyapeksha Grouping Selector vapru shakto.

HTML Code

<h1>Main Heading</h1>

<h2>Sub Heading</h2>

<p>CSS Shika ani Practice Kara.</p>

CSS Code

h1, h2, p {
    color: purple;
    font-family: Arial, sans-serif;
}

Output

Main Heading

Sub Heading

CSS Shika ani Practice Kara.

Lakshat Theva: Grouping Selector mule same CSS code punha punha lihinyachi garaj rahat nahi.

7. Descendant Selector

Descendant Selector cha use eka parent element chya aat aslele elements select karanyasathi hoto.

Ya selector madhye parent ani child selector yanchya madhye space vapartat.

Udaharanarth, eka div chya aat aslele sagle paragraphs select karayche astil tar .container p asa selector lihitat.

HTML Code

<div class="container">

    <p>Container Chya Aatla Paragraph</p>

</div>

<p>Container Chya Bahercha Paragraph</p>

CSS Code

.container p {
    color: blue;
    font-weight: bold;
}

Output

Container Chya Aatla Paragraph

Container Chya Bahercha Paragraph

Ya example madhye fakt container chya aatla paragraph blue ani bold hoil. Bahercha paragraph normal rahil.

Important: Descendant Selector madhye space vapartat. Tyamule parent chya aat nested aslele elements suddha select hotat.

8. CSS Selectors Madhil Farak

Aata paryant aapan sahaa CSS Selectors pahile. Tyanchyatila main farak khalil table madhye samjun gheu.

Selector Symbol / Syntax Use
Element h1 Saman tag aslele elements select karto.
ID #title Specific ID aslela element select karto.
Class .box Saman class aslele elements select karto.
Universal * Sarva HTML elements select karto.
Grouping h1, p Anek selectors ekatra select karto.
Descendant .box p Parent chya aatle paragraphs select karto.

9. CSS Selectors Madhil Common Mistakes

CSS lihitana kahi chuka hotat. Tya chuka talnyasathi khalil examples lakshat theva.

Chuk 1: Class sathi # vaprane 
#message {
    color: red;
}

Ha selector ID sathi aahe. Class select karanyasathi dot (.) vaprayla hava.

Yogya Code

.message {
    color: red;
}
Chuk 2: ID sathi . vaprane 
.title {
    color: blue;
}

Ha selector Class sathi aahe. ID select karanyasathi hash (#) vaprayla hava.

Yogya Code

#title {
    color: blue;
}
Chuk 3: Descendant Selector madhye Space visarne 
.containerp {
    color: green;
}

Ya code madhye container ani p yanchya madhye space nahi. Yogya selector .container p asa aahe.

Yogya Code

.container p {
    color: green;
}

10. Mahatvache Mudde

  • CSS Selector cha use HTML elements select karanyasathi hoto.
  • Element Selector madhye tag name vapartat.
  • ID Selector sathi # symbol vapartat.
  • Class Selector sathi . symbol vapartat.
  • Universal Selector sathi * symbol vapartat.
  • Grouping Selector sathi comma vapartat.
  • Descendant Selector madhye space vapartat.
  • Ek ID eka HTML page madhye unique asava.
  • Ekach Class anek HTML elements na deta yeto.

11. Practice Task

Task: CSS Selectors Vaprun Webpage Tayaar Kara

Ek simple HTML page tayaar kara ani khalil tasks complete kara.

  1. Element Selector vaprun don headings cha color change kara.
  2. ID Selector vaprun eka heading la red color dya.
  3. Class Selector vaprun don paragraphs green kara.
  4. Universal Selector vaprun webpage cha font set kara.
  5. Grouping Selector vaprun headings cha color same theva.
  6. Descendant Selector vaprun div chya aatla paragraph style kara.
Practice Tip: Pratyek selector swata lihun bagha. Fakt code copy-paste karu naka. Browser madhye output check kara.
