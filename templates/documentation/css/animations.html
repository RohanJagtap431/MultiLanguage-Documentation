CSS Animations

CSS Animations cha use HTML elements la automatic movement, rotation, color changes ani visual effects denyasathi hoto.

📘 Beginner Level ⏱️ 30 Minutes 📄 Page 20

1. Introduction to CSS Animations

CSS Animation cha use element chya style madhye time nusar changes karanyasathi hoto. Animation automatic start hou shakte ani anek vela repeat suddha hou shakte.

Udaharanarth, ek box left to right move karane, button cha color change karane kiwa loading spinner rotate karane.

Definition: CSS Animation allows elements to change their styles automatically over time using keyframes.

Basic Syntax

@keyframes animation-name {
    from {
        property: value;
    }

    to {
        property: value;
    }
}

selector {
    animation-name: animation-name;
    animation-duration: 2s;
}

Animation tayar karanyasathi @keyframes ani animation properties vapartat.

2. @keyframes

@keyframes cha use animation chya different stages madhil styles define karanyasathi hoto.

Animation madhye from ani to vaprun starting ani ending styles define karta yetat.

CSS Code

@keyframes changeColor {
    from {
        background-color: blue;
    }

    to {
        background-color: red;
    }
}

Ya example madhye animation blue color pasun start houn red color paryant jail.

Percentage Values

@keyframes moveBox {
    0% {
        transform: translateX(0);
    }

    50% {
        transform: translateX(100px);
    }

    100% {
        transform: translateX(0);
    }
}

0%, 50% ani 100% vaprun animation che different stages define karta yetat.

Output

3. animation-name

animation-name property cha use konti @keyframes animation run karaychi aahe he tharavanyasathi hoto.

CSS Code

.box {
    animation-name: moveBox;
}

Ithe moveBox he @keyframes che nav aahe.

4. animation-duration

animation-duration property cha use animation complete honyasathi kiti vel lagel he tharavanyasathi hoto.

CSS Code

.box {
    animation-duration: 3s;
}
  • 1s - One second.
  • 2s - Two seconds.
  • 500ms - Half second.
Important: animation-duration specify na kelyas tyachi default value 0s aste. Mhanun animation visible hot nahi.

5. animation-delay

animation-delay property cha use animation suru honyapurvi kiti vel thambayche he tharavanyasathi hoto.

CSS Code

.box {
    animation-delay: 2s;
}

Ya example madhye animation suru honyapurvi 2 seconds wait karel.

6. animation-iteration-count

animation-iteration-count property cha use animation kiti vela repeat honar he tharavanyasathi hoto.

CSS Code

.box {
    animation-iteration-count: 3;
}

Common Values

  • 1 - Animation ekda run hoil.
  • 3 - Animation teen vela run hoil.
  • infinite - Animation satat repeat hoil.

Output

7. animation-direction

animation-direction property cha use animation kontya direction madhye run honar he tharavanyasathi hoto.

Common Values

Value Meaning
normal Animation forward direction madhye run hote.
reverse Animation reverse direction madhye run hote.
alternate Forward ani reverse direction alternate hotat.
alternate-reverse Reverse pasun suru houn direction alternate hote.

CSS Code

.box {
    animation-direction: alternate;
}

8. animation-timing-function

animation-timing-function property cha use animation cha speed pattern tharavanyasathi hoto.

Common Values

  • ease - Slow start, fast middle ani slow end.
  • linear - Constant speed.
  • ease-in - Slow start.
  • ease-out - Slow end.
  • ease-in-out - Slow start ani slow end.

CSS Code

.box {
    animation-timing-function: linear;
}

9. animation-fill-mode

animation-fill-mode property cha use animation suru honyapurvi kiwa complete zalyanantar element konti style maintain karel he tharavanyasathi hoto.

Common Values

Value Meaning
none Animation chya baher keyframe styles apply hot nahit.
forwards Animation complete zalyavar ending style maintain karte.
backwards Delay madhye first relevant keyframe style apply karte.
both Backwards ani forwards donhi effects apply karte.

CSS Code

.box {
    animation-fill-mode: forwards;
}

10. Animation Shorthand

Animation chya anek properties ekach line madhye lihinyasathi animation shorthand property vapartat.

Syntax

animation: name duration timing-function
           delay iteration-count direction
           fill-mode;

Example

.box {
    animation: moveBox 2s ease 1s infinite
               alternate forwards;
}

Ya example madhye moveBox animation 2 seconds chalel, 1 second delay asel, ani ti infinite vela alternate direction madhye repeat hoil.

Note: Shorthand madhye duration aadhi ani delay nantar lihitat. Udaharan: 2s 1s.

11. Practical Example - Moving Box

Ya example madhye ek box left side pasun right side la move hoil ani parat left side la yeil.

CSS Code

@keyframes moveRight {
    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(150px);
    }
}

.box {
    animation: moveRight 2s ease-in-out
               infinite alternate;
}

Output

12. Important Points

  • CSS Animation automatic visual effects sathi vapartat.
  • @keyframes animation che stages define karte.
  • animation-name animation che nav tharavte.
  • animation-duration animation cha vel tharavte.
  • animation-delay animation suru honyacha delay tharavte.
  • animation-iteration-count repeat count tharavte.
  • animation-direction direction tharavte.
  • animation-timing-function speed pattern tharavte.
  • animation-fill-mode animation chya baher style maintain karte.
  • animation shorthand madhye multiple properties ekatra lihita yetat.
