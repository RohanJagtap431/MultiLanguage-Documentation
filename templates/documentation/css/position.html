CSS Position Property

CSS Position property cha use HTML elements webpage var specific location la place karanyasathi hoto.

📘 Beginner Level ⏱️ 25 Minutes 📄 Page 14

1. Introduction to Position

Normal webpage layout madhye HTML elements tyanchya default order nusar display hotat. CSS position property vaprun aapan elements chi position change karu shakto.

Definition: The CSS position property specifies how an element is positioned in a webpage.

Position Values

  • static
  • relative
  • absolute
  • fixed
  • sticky

2. Position: Static

static hi HTML elements chi default position aste. Element normal document flow madhye display hoto.

Static element var top, right, bottom ani left properties cha effect hot nahi.

CSS Code

.box {
    position: static;
}

3. Position: Relative

relative position mule element tyachya original position chya reference ne move karta yeto.

Element move zala tari tyachi original layout space reserve rahate.

CSS Code

.box {
    position: relative;
    top: 20px;
    left: 30px;
}

Output

Original Position
Relative Element
Tip: Relative position cha use absolute positioned child element sathi reference container tayar karanyasathi suddha hoto.

4. Position: Absolute

absolute position mule element normal document flow madhun baher yeto ani tyachya nearest positioned ancestor chya reference ne place hoto.

Positioned ancestor nasel tar element initial containing block chya reference ne position hoto.

CSS Code

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 10px;
    right: 10px;
}

Output

Parent Container
Absolute Box
Important: Absolute element normal layout madhye space reserve karat nahi.

5. Position: Fixed

fixed position mule element viewport chya reference ne position hoto.

Page scroll kela tari element tyach position var rahato.

CSS Code

.button {
    position: fixed;
    bottom: 20px;
    right: 20px;
}

Output

Fixed elements viewport chya reference ne position hotat.

Fixed Example
Tip: Fixed position cha use floating buttons, chat buttons ani back-to-top buttons tayar karanyasathi hoto.

6. Position: Sticky

sticky position mule element suruvatila normal flow madhye rahato. Scroll kartana specified offset paryant pohachlyavar to stick hoto.

CSS Code

.heading {
    position: sticky;
    top: 0;
}

7. Top, Right, Bottom and Left

top, right, bottom ani left properties positioned element chi location set karanyasathi vapartat.

CSS Code

.box {
    position: relative;
    top: 10px;
    right: 15px;
    bottom: 20px;
    left: 25px;
}

Properties

  • top: Top side pasun offset set karte.
  • right: Right side pasun offset set karte.
  • bottom: Bottom side pasun offset set karte.
  • left: Left side pasun offset set karte.
Lakshat Thev: Ya offset properties cha effect static position var hot nahi.

8. Z-Index

z-index property cha use overlapping elements madhye konta element samor disel he control karanyasathi hoto.

Jya element cha z-index value jast aste, to same stacking context madhye samor display hou shakto.

CSS Code

.box-one {
    position: relative;
    z-index: 1;
}

.box-two {
    position: relative;
    z-index: 2;
}

Output

Z-Index: 1
Z-Index: 2
Important: z-index cha result stacking context var depend karto. Fakt mothi value dilyane element nehmich saglyanchya samor yeil ase nahi.

9. Difference Between Position Values

Position Behavior
static Default position; normal flow madhye rahato.
relative Original position chya reference ne move hoto.
absolute Positioned ancestor chya reference ne place hoto.
fixed Viewport chya reference ne fixed rahato.
sticky Scroll kartana specified offset var stick hoto.

10. Important Points

  • static hi default position aahe.
  • relative element chi original space reserve rahate.
  • absolute element normal flow madhun baher yeto.
  • fixed element viewport chya reference ne position hoto.
  • sticky element scrolling darmyan stick hoto.
  • top, right, bottom ani left offset set kartat.
  • z-index overlapping elements cha stacking order control karto.
