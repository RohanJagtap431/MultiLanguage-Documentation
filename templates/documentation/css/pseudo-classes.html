CSS Pseudo-Classes

CSS Pseudo-Classes cha use HTML elements chya specific state kiwa position nusar style apply karanyasathi hoto.

📘 Beginner Level ⏱️ 25 Minutes 📄 Page 17

1. Introduction to Pseudo-Classes

Pseudo-Class hi CSS selector chi ek special keyword aahe. Ti element chya specific state kiwa position la target karte.

Udaharanarth, user mouse button var gheun gela tar hover state apply hote. Input field select kela tar focus state apply hote.

Definition: A CSS pseudo-class is used to style an element based on its state or position.

Syntax

selector:pseudo-class {
    property: value;
}

Pseudo-class chya adhi colon (:) vapartat.

2. :hover

:hover pseudo-class cha use user mouse element var gheun gelyavar style change karanyasathi hoto.

CSS Code

.button:hover {
    background-color: blue;
    color: white;
}

Output

Mouse button var gheun ja.

3. :active

:active pseudo-class cha use user element click kiwa press karat astana style change karanyasathi hoto.

CSS Code

.button:active {
    background-color: red;
    transform: scale(0.95);
}

Output

Button press karun theva.

4. :focus

:focus pseudo-class cha use element keyboard kiwa mouse ne select kelyavar tyachi style change karanyasathi hoto.

Input field var click kara kiwa Tab key vaprun tyala focus kara.

CSS Code

input:focus {
    border-color: blue;
    outline: 2px solid lightblue;
}

Output

Input field select karun paha.

5. :visited

:visited pseudo-class cha use user ne already visit kelelya links la vegli style denyasathi hoto.

CSS Code

a:visited {
    color: purple;
}

Output

Example Visited Link

Link open kelyanantar browser madhye tyachi visited style disu shakte.

Important: :visited cha use links sathi hoto. Browser privacy mule visited links var fakt kahi CSS properties, jase color, apply karta yetat.

6. :first-child

:first-child pseudo-class cha use parent madhil pahilya child element la style denyasathi hoto.

CSS Code

li:first-child {
    color: blue;
    font-weight: bold;
}

Output

  • First Item
  • Second Item
  • Third Item
  • Fourth Item

7. :last-child

:last-child pseudo-class cha use parent madhil shevatchya child element la style denyasathi hoto.

CSS Code

li:last-child {
    color: green;
    font-weight: bold;
}

Output

  • First Item
  • Second Item
  • Third Item
  • Last Item

8. :nth-child()

:nth-child() pseudo-class cha use parent madhil specific position var aslelya child element la select karanyasathi hoto.

Common Examples

  • :nth-child(2) - Dusra child select karto.
  • :nth-child(odd) - Odd position children select karto.
  • :nth-child(even) - Even position children select karto.

CSS Code

li:nth-child(2) {
    color: blue;
}

li:nth-child(even) {
    background-color: #e0f2fe;
}

Output

  • Item 1
  • Item 2
  • Item 3
  • Item 4
  • Item 5
  • Item 6

9. :not()

:not() pseudo-class cha use dilelya selector shi match na honare elements select karanyasathi hoto.

CSS Code

p:not(.special) {
    color: gray;
}

Ya example madhye special class naslelya paragraph elements la style apply hoil.

Output

Normal Paragraph

Special Paragraph

Another Normal Paragraph

10. Difference Between Pseudo-Classes

Pseudo-Class Use
:hover Mouse element var gelyavar.
:active Element press kiwa click hot astana.
:focus Element focus madhye astana.
:visited Already visited link sathi.
:first-child Pahilya child element sathi.
:last-child Shevatchya child element sathi.
:nth-child() Specific position varil child sathi.
:not() Dilelya selector shi match na honarya elements sathi.

11. Important Points

  • Pseudo-Classes sathi colon (:) vapartat.
  • :hover mouse hover state select karte.
  • :active press kiwa click state select karte.
  • :focus focused element select karte.
  • :visited visited links select karte.
  • :first-child pahila child select karte.
  • :last-child shevatcha child select karte.
  • :nth-child() position nusar child select karte.
  • :not() dilelya selector la match na honare elements select karte.

12. Practice Task

Task: Create a Styled List and Buttons

Ek HTML page tayar kara ani:

  1. Button la :hover style dya.
  2. Button la :active style dya.
  3. Input field la :focus style dya.
  4. List madhil pahilya item la :first-child vaprun style dya.
  5. Shevatchya item la :last-child vaprun style dya.
  6. Even items la :nth-child(even) vaprun background dya.
  7. .special class naslelya paragraph la :not() vaprun style dya.
