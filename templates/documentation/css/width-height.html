CSS Width, Height and Max-Width

CSS Width and Height Properties cha use HTML elements cha size control karanyasathi hoto.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 12

1. Introduction

Website design kartana pratyek element la yogya width ani height dene mahatvache aste. CSS madhil width ani height properties cha use element cha size set karanyasathi hoto.

Definition: CSS Width and Height properties are used to control the width and height of HTML elements.

2. CSS Width

width property cha use HTML element chi width set karanyasathi hoto.

CSS Code

.box {
    width: 300px;
}

Output

Width: 150px
Width: 250px
Width: 350px
Lakshat Thev: Width sathi px, %, rem ani vw sarkhe units vaparta yetat.

3. CSS Height

height property cha use HTML element chi height set karanyasathi hoto.

CSS Code

.box {
    height: 150px;
}

Output

Height: 60px
Height: 100px
Height: 150px

4. Min-Width

min-width property cha use element chi minimum width set karanyasathi hoto.

Element chi width ya value peksha kami hou shakat nahi.

CSS Code

.box {
    min-width: 200px;
}

Output

Minimum Width: 200px

5. Max-Width

max-width property cha use element chi maximum width set karanyasathi hoto.

Element chi width ya value peksha jast hou shakat nahi.

CSS Code

.container {
    width: 100%;
    max-width: 600px;
}

Output

Maximum Width: 600px
Important: width: 100% mule element available space gheto ani max-width mule tyachi maximum width limit hote.

6. Min-Height

min-height property cha use element chi minimum height set karanyasathi hoto.

Content kami asla tari element chi height minimum value peksha kami honar nahi.

CSS Code

.box {
    min-height: 150px;
}

Output

Minimum Height: 150px

7. Max-Height

max-height property cha use element chi maximum height limit set karanyasathi hoto.

Content jast asel tar to available area madhye fit karnyasathi overflow property vapravi lagu shakte.

CSS Code

.box {
    max-height: 100px;
    overflow: auto;
}

Output

This is an example of maximum height. CSS controls the maximum height of an element. Extra content can be handled using overflow. Scrollbar appears when required.

8. Auto Value

auto value cha use browser la element cha size kiwa margin automatic calculate karu denyasathi hoto.

CSS Code

.box {
    width: 300px;
    height: auto;
    margin: 0 auto;
}

Output

Auto Width Example

Ha box available layout madhye horizontal center la aahe.

9. Responsive Width Example

Responsive design madhye element mobile, tablet ani desktop screen nusar adjust honyasathi width ani max-width vapartat.

HTML Code

<div class="responsive-card">
    <h2>Responsive Card</h2>
    <p>This card adjusts to screen size.</p>
</div>

CSS Code

.responsive-card {
    width: 100%;
    max-width: 400px;
    min-height: 150px;
    margin: 20px auto;
    padding: 20px;
    box-sizing: border-box;
}

Output

Responsive Card

This card adjusts to screen size.

Tip: width: 100% ani max-width ekatra vaparlyane card la available space nusar width milte, pan tyachi maximum width limit rahate.

10. Difference Between Width and Height Properties

Property Use
width Element chi width set karte.
height Element chi height set karte.
min-width Minimum width set karte.
max-width Maximum width set karte.
min-height Minimum height set karte.
max-height Maximum height set karte.
auto Browser la size automatic calculate karu dete.

11. Important Points

  • width element chi width set karte.
  • height element chi height set karte.
  • min-width minimum width limit karte.
  • max-width maximum width limit karte.
  • min-height minimum height limit karte.
  • max-height maximum height limit karte.
  • auto value browser la automatic calculation karu dete.
  • Responsive cards sathi width: 100% ani max-width upyogi aahe.

12. Practice Task

Task: Create a Responsive Container

  2. Max-width 500px set kara.
  3. Min-height 200px set kara.
  4. Padding 20px dya.
  5. Margin 20px auto dya.
  6. Mobile screen var container test kara.
