Ways to Add CSS

HTML page madhye CSS add karnyachya teen paddhati samjun ghya ani tyanchi practical examples paha.

📘 Beginner Level ⏱️ 15 Minutes 📄 Page 03

1. Introduction

Aapan HTML document madhye CSS add karnyasathi teen vegveglya paddhati vaparu shakto. Ya paddhatincha vapar HTML elements la design ani style denyasathi hoto.

CSS add karnyachya teen paddhati:
  1. Inline CSS
  2. Internal CSS
  3. External CSS

2. Inline CSS

Inline CSS madhye aapan HTML element lach direct style deu shakto. Yasathi HTML element madhye style attribute vaparla jato.

Inline CSS ha HTML element chya opening tag madhye lihila jato.

Example

<h1 style="color: blue;">
    Welcome to CSS
</h1>

<p style="font-size: 18px;">
    This is an example of Inline CSS.
</p>

Output

Welcome to CSS

This is an example of Inline CSS.

Fayde

  • Ekhadya single element la style dene sope aste.
  • Lavkar styling karnyasathi upyogi aste.

Tote

  • Anek elements sathi same CSS punha vaparta yet nahi.
  • HTML code motha ani sambhalayla kathin hoto.
  • HTML structure ani CSS design ekach thikani yetat.
Lakshat Theva: Inline CSS madhye HTML element chya aat style attribute vaparla jato.

3. Internal CSS

Internal CSS madhye CSS code ha HTML document chya head section madhil style element chya aat lihila jato.

Ekach HTML page la design dyaycha asel tar Internal CSS upyogi padte.

Example

HTML Code:

<!DOCTYPE html>
<html>
<head>
    <title>Internal CSS</title>
    <style>
        h1 {
            color: green;
            text-align: center;
        }

        p {
            font-size: 18px;
        }
    </style>
</head>

<body>
    <h1>Welcome to CSS</h1>
    <p>This is Internal CSS.</p>
</body>
</html>

Output

Welcome to CSS

This is Internal CSS.

Fayde

  • Ekach page madhil anek elements la style deta yete.
  • Vegli CSS file tayar karnyachi garaj naste.

Tote

  • Dusrya HTML pages madhye hech CSS direct reuse karta yet nahi.
  • Motha HTML code sambhalne kathin hote.
Lakshat Theva: Internal CSS madhye head section chya aat style element vaparla jato.

4. External CSS

External CSS madhye CSS code ha veglya file madhye lihila jato. Ya file cha extension .css asa asto.

External CSS file la HTML document sobat jodnyasathi link element vaparla jato.

HTML Code

<!DOCTYPE html>
<html>
<head>
    <title>External CSS</title>
    <link rel="stylesheet" href="style.css">
</head>

<body>
    <h1>Welcome to CSS</h1>
    <p>This is External CSS.</p>
</body>
</html>

CSS Code (style.css)

h1 {
    color: purple;
    text-align: center;
}

p {
    font-size: 18px;
    color: gray;
}

Output

Welcome to CSS

This is External CSS.

Fayde

  • Ekach CSS file anek HTML pages sathi vaparta yete.
  • HTML ani CSS code vegvegla rahto.
  • Design madhye badal karne ani code sambhalne sope hote.
  • Mothya websites sathi upyogi aste.

Tote

  • Vegli CSS file tayar karavi lagte.
  • CSS file cha path chukicha asel tar styling load honar nahi.
Best Practice: Real-world websites madhye External CSS vaprane sahasa changle aste. Karan yamule HTML structure ani CSS design vegvegale rahtat.
