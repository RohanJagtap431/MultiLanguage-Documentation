CSS Margin and Padding

CSS Margin and Padding cha use HTML elements madhil spacing control karanyasathi hoto.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 10

1. Introduction

Website design kartana elements madhye yogya spacing thevne mahatvache aste. CSS madhye spacing sathi Margin ani Padding ya don properties vapartat.

Definition: Margin is the space outside an element's border, while Padding is the space between the content and the border.

2. CSS Margin

margin property cha use HTML element chya border chya baher space denyasathi hoto.

Margin mule don HTML elements madhye antar tayar karta yete.

Margin Properties

  • margin-top – Varil bajula space dete.
  • margin-bottom – Khalil bajula space dete.
  • margin-left – Davya bajula space dete.
  • margin-right – Ujvya bajula space dete.

CSS Code

.box {
    margin-top: 20px;
    margin-bottom: 30px;
    margin-left: 15px;
    margin-right: 15px;
}

Output

CSS Box

3. Margin Shorthand

Margin shorthand cha use charhi bajunchya margin values ekach line madhye set karanyasathi hoto.

Four Values

.box {
    margin: 10px 20px 30px 40px;
}
  • 1st value – Top
  • 2nd value – Right
  • 3rd value – Bottom
  • 4th value – Left

Other Shorthand Examples

CSS Code Meaning
margin: 20px; All four sides 20px.
margin: 10px 20px; Top/Bottom 10px, Left/Right 20px.
margin: 10px 20px 30px; Top 10px, Left/Right 20px, Bottom 30px.
margin: 10px 20px 30px 40px; Top, Right, Bottom, Left.
Shortcut Lakshat Thev: Four values cha order Top → Right → Bottom → Left asa asto.

4. Margin Auto

margin: auto; cha use fixed kiwa maximum width aslelya block element la horizontal direction madhye center karanyasathi karta yeto.

CSS Code

.box {
    width: 200px;
    margin: 0 auto;
}

Output

Centered Box
Important: margin: auto mule element vertical direction madhye automatically center hot nahi. Ya example madhye horizontal centering hote.

5. CSS Padding

padding property cha use content ani border yanchya madhye space denyasathi hoto.

Padding mule element madhil content la border pasun antar milte.

Padding Properties

  • padding-top – Varil bajula internal space dete.
  • padding-bottom – Khalil bajula internal space dete.
  • padding-left – Davya bajula internal space dete.
  • padding-right – Ujvya bajula internal space dete.

CSS Code

.box {
    padding-top: 20px;
    padding-bottom: 20px;
    padding-left: 30px;
    padding-right: 30px;
}

Output

CSS Padding Example

6. Padding Shorthand

Padding shorthand cha use charhi bajunchya padding values ekach declaration madhye set karanyasathi hoto.

CSS Code

.box {
    padding: 10px 20px 30px 40px;
}
  • 1st value – Top
  • 2nd value – Right
  • 3rd value – Bottom
  • 4th value – Left

Other Shorthand Examples

CSS Code Meaning
padding: 20px; All four sides 20px.
padding: 10px 20px; Top/Bottom 10px, Left/Right 20px.
padding: 10px 20px 30px; Top 10px, Left/Right 20px, Bottom 30px.
padding: 10px 20px 30px 40px; Top, Right, Bottom, Left.

7. Difference Between Margin and Padding

Margin Padding
Element chya baher space dete. Content ani border madhye space dete.
Elements madhye antar tayar karte. Content chya around internal space dete.
Background element chya border-box paryant asto. Background padding area madhyehi disato.
Margin negative asu shakto. Padding negative asu shakat nahi.

8. Practical Example

Khali dilelya example madhye aapan margin, padding ani border vaprun ek simple card tayar karanar aahot.

HTML Code

<div class="card">
    <h2>CSS Learning</h2>
    <p>Learn Margin and Padding.</p>
</div>

CSS Code

.card {
    width: 300px;
    padding: 20px;
    margin: 30px auto;
    border: 1px solid #ccc;
    background-color: #f0f4ff;
}

Output

9. Important Points

  • Margin element chya baher space dete.
  • Padding content ani border madhye space dete.
  • Margin madhye char directional properties astat.
  • Padding madhyehi char directional properties astat.
  • Shorthand mule charhi values ekach line madhye set karta yetat.
  • margin: auto horizontal centering sathi upyogi aahe.
  • Negative margin possible aahe, pan negative padding allowed nahi.
