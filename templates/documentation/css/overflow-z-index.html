CSS Overflow and Z-Index

CSS Overflow cha use extra content control karanyasathi ani Z-Index cha use overlapping elements cha stacking order control karanyasathi hoto.

📘 Beginner Level ⏱️ 25 Minutes 📄 Page 22

1. Introduction to CSS Overflow

Jevha HTML element madhil content tyachya fixed width kiwa height peksha motha hoto, tevha extra content box chya baher jau shakto.

Ashya extra content la kasa display karaycha he tharavanyasathi CSS overflow property vapartat.

Definition: CSS Overflow controls what happens when content is too large to fit inside an element.

Syntax

selector {
    overflow: value;
}

Common Values

  • visible
  • hidden
  • scroll
  • auto

2. overflow: visible

visible hi overflow property chi default value aahe. Extra content element chya baher suddha visible rahte.

CSS Code

.box {
    width: 180px;
    height: 70px;
    overflow: visible;
}

Output

Ha content box chya baher suddha visible rahnar aahe.

3. overflow: hidden

hidden value cha use element chya boundary baher janara extra content hide karanyasathi hoto.

CSS Code

.box {
    width: 180px;
    height: 70px;
    overflow: hidden;
}

Output

Ha content box chya baher gelyavar hide hoil. Extra text disnar nahi. Ha ajun kahi extra content aahe.

4. overflow: scroll

scroll value cha use extra content pahanyasathi scrollbar display karanyasathi hoto. Content fit asla tari scrollbar display hoto.

CSS Code

.box {
    width: 200px;
    height: 100px;
    overflow: scroll;
}

Output

First line - CSS Overflow.

Second line - HTML Elements.

Third line - Extra Content.

Fourth line - CSS Properties.

Fifth line - Scroll to see more.

Sixth line - More content here.

5. overflow: auto

auto value cha use content overflow zalyas garjenusar scrollbar display karanyasathi hoto. Content fit asel tar scrollbar chi garaj naste.

CSS Code

.box {
    width: 200px;
    height: 100px;
    overflow: auto;
}

Output

First line - CSS Overflow.

Second line - HTML Elements.

Third line - Extra Content.

Fourth line - CSS Properties.

Fifth line - Scroll to see more.

Sixth line - More content here.

6. overflow-x and overflow-y

overflow-x cha use horizontal direction madhil overflow control karanyasathi hoto.

overflow-y cha use vertical direction madhil overflow control karanyasathi hoto.

CSS Code

.box {
    overflow-x: auto;
    overflow-y: hidden;
}

Difference

  • overflow-x - Left ani right direction.
  • overflow-y - Top ani bottom direction.

Output

Horizontal Content - Scroll Left and Right

7. Introduction to CSS Z-Index

Z-Index property cha use ekmekanvar overlap honarya elements madhye konta element samor kiwa mage disel he tharavanyasathi hoto.

Z-Index cha use cards, dropdowns, menus, modals ani overlays madhye kela jato.

Definition: CSS z-index controls the stacking order of overlapping elements.

Syntax

selector {
    position: relative;
    z-index: 2;
}
Important: Normal positioned elements sathi z-index apply karanyasathi position relative, absolute, fixed kiwa sticky asne avashyak aahe. Flex ani Grid items sathi positioned nasle tari z-index lagu hou shakto.

8. Z-Index with Position

Don kiwa adhik elements ekmekanvar overlap hot astil tar z-index value vaprun tyanchi stacking order control karta yete.

Mothi z-index value aslela element generally tyach stacking context madhil lahan value aslelya element chya samor disel.

CSS Code

.box-one {
    position: relative;
    z-index: 1;
}

.box-two {
    position: relative;
    z-index: 2;
}

Output

Z-Index: 1
Z-Index: 2
Z-Index: 3

9. Understanding Stacking Order

Stacking Order mhanje overlapping elements kontya order ne display hotat he.

Ekach stacking context madhye z-index value compare karun element cha order tharavta yeto.

Example

.first {
    position: relative;
    z-index: 1;
}

.second {
    position: relative;
    z-index: 5;
}

Ya example madhye second element first element chya samor disel.

Tip: Parent element madhye navin stacking context tayar zala asel tar child element cha motha z-index suddha dusrya parent chya baher jau shakat nahi.

10. Difference Between Overflow Values

Value Meaning
visible Extra content baher visible rahte.
hidden Extra content hide hote.
scroll Scrollbar display hoto.
auto Garaj asel tevhach scrollbar display hoto.

11. Important Points

  • Overflow extra content control karte.
  • visible hi default overflow value aahe.
  • hidden extra content hide karte.
  • scroll scrollbar display karte.
  • auto garjenusar scrollbar display karte.
  • overflow-x horizontal overflow control karte.
  • overflow-y vertical overflow control karte.
  • z-index overlapping elements cha order control karte.
  • Mothi z-index value generally samor display hote.
  • Stacking context mule z-index comparison limit hou shakto.

12. Practice Task

Task: Create Overflow Boxes and Overlapping Cards

Ek HTML page tayar kara ani:

  1. Ek fixed width ani height cha box create kara.
  2. overflow: hidden vaprun extra content hide kara.
  3. Dusrya box madhye overflow: scroll vapra.
  4. Tisrya box madhye overflow: auto vapra.
  5. overflow-x ani overflow-y properties try kara.
  6. Tin overlapping div elements create kara.
  7. Pratyek div la vegvegli z-index value dya.
  8. Konti z-index value samor diste te observe kara.
