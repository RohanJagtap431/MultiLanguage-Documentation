CSS Transitions and Transforms

CSS Transitions ani Transforms cha use website madhye smooth effects ani element movements tayar karanyasathi hoto.

📘 Beginner Level ⏱️ 30 Minutes 📄 Page 19

1. Introduction to CSS Transitions

CSS Transition cha use element chi CSS property change hotana smooth animation effect denyasathi hoto.

Udaharanarth, button cha background color change hotana to ekdam change na hota halu-halu change hou shakto.

Definition: CSS Transition allows property changes to happen smoothly over a specified duration.

Syntax

selector {
    transition: property duration;
}

Example

.button {
    background-color: blue;
    transition: 0.5s;
}

.button:hover {
    background-color: red;
}

Output

Button var mouse gheun ja.

2. transition-property

transition-property cha use kontya CSS property var transition effect apply karaycha aahe he tharavanyasathi hoto.

CSS Code

.box {
    transition-property: background-color;
}

Ya example madhye fakt background-color property smoothly change hoil.

Common Values

  • background-color - Background color change.
  • width - Width change.
  • transform - Transform effect change.
  • all - Sarva supported changing properties.

3. transition-duration

transition-duration cha use transition effect purna honyasathi kiti vel lagel he tharavanyasathi hoto.

CSS Code

.box {
    transition-duration: 1s;
}
Time Units: s mhanje seconds ani ms mhanje milliseconds. 1s = 1000ms.

Examples

  • 0.5s - Half second.
  • 1s - One second.
  • 200ms - 0.2 second.

4. transition-delay

transition-delay cha use transition effect suru honyapurvi kiti vel thambayche he tharavanyasathi hoto.

CSS Code

.box {
    transition-delay: 1s;
}

Ya example madhye transition suru honyapurvi 1 second delay hoil.

5. transition-timing-function

transition-timing-function cha use transition effect cha speed pattern tharavanyasathi hoto.

Common Values

Value Meaning
ease Slow start, fast middle, slow end.
linear Constant speed.
ease-in Slow start.
ease-out Slow end.
ease-in-out Slow start and slow end.

CSS Code

.box {
    transition-timing-function: ease-in-out;
}

6. Transition Shorthand

Transition chya sarva properties ekach line madhye lihinyasathi shorthand property vapartat.

Syntax

transition: property duration timing-function delay;

Example

.button {
    background-color: blue;

    transition:
        background-color
        0.5s
        ease
        0.2s;
}

Output

7. CSS Transform - translate()

transform: translate() cha use element la horizontal kiwa vertical direction madhye move karanyasathi hoto.

CSS Code

.box {
    transform: translate(30px, 20px);
}

Pahili value horizontal (X-axis) ani dusari value vertical (Y-axis) movement dakhavte.

Output

Translate

8. CSS Transform - rotate()

transform: rotate() cha use element la clockwise kiwa anti-clockwise rotate karanyasathi hoto.

CSS Code

.box {
    transform: rotate(45deg);
}

deg mhanje degree. Positive value clockwise ani negative value anti-clockwise rotation dete.

Output

Rotate

9. CSS Transform - scale()

transform: scale() cha use element cha size motha kiwa lahan karanyasathi hoto.

CSS Code

.box {
    transform: scale(1.2);
}
  • scale(1) - Original size.
  • scale(1.5) - 1.5 times size.
  • scale(0.5) - Half size.

Output

Scale

10. CSS Transform - skew()

transform: skew() cha use element la horizontal kiwa vertical direction madhye tilt karanyasathi hoto.

CSS Code

.box {
    transform: skew(15deg);
}

Output

Skew

11. Difference Between Transition and Transform

Transition Transform
Style changes smooth karte. Element cha shape, size kiwa position change karte.
Duration vaparte. Translate, rotate, scale, skew vaparte.
transition: 0.5s; transform: rotate(45deg);

12. Important Points

  • Transition smooth style changes sathi vapartat.
  • transition-property konti property change honar te tharavte.
  • transition-duration effect cha vel tharavte.
  • transition-delay effect suru honyacha delay tharavte.
  • transition-timing-function speed pattern tharavte.
  • translate() element move karte.
  • rotate() element rotate karte.
  • scale() element cha size change karte.
  • skew() element tilt karte.

13. Practice Task

Task: Create an Animated Button

  3. transition: 0.5s vapra.
  4. :hover vaprun button cha color change kara.
  5. Hover kelyavar transform: scale(1.1) vapra.
  6. Ek box tayar karun rotate() effect dya.
