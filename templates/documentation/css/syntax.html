CSS Syntax and Rules

CSS code lihinyachi basic paddhat, Selectors, Properties, Values ani Declarations samjun ghya.

📘 Beginner Level ⏱️ 15 Minutes 📄 Page 02

1. CSS Syntax Mhanje Kay?

CSS Syntax mhanje CSS code lihinyache kahi tharavik niyam. Ya niyamanusar aapan CSS code lihito ani browser la HTML elements var konti style lavaychi he sangto.

Pratyek CSS Rule madhye ek Selector ani ek Declaration Block asto.

Definition: CSS Syntax mhanje Selectors, Properties ani Values yanchya madatine CSS Rules lihinyachi tharavik paddhat.

2. Basic CSS Syntax

CSS Rule lihinyasathi khalil basic structure vaparla jato. 

selector {
    property: value;
}

Example:

h1 {
    color: blue;
    font-size: 30px;
}

Ya Example madhye:

  • h1: Ha Selector aahe.
  • color: Hi Property aahe.
  • blue: Hi Value aahe.
  • font-size: Hi dusri Property aahe.
  • 30px: Hi tya Property chi Value aahe.

3. CSS Rule Che Bhag

Ek CSS Rule tayar honyasathi teen mahatvache bhag astat.

1 Selector
2 Property
3 Value

1. Selector

Selector cha vapar kontya HTML element la style dyaychi aahe he tharavnyasathi hoto.

2. Property

Property mhanje aaplyala kontya design madhye badal karaycha aahe te sangnara bhag. Udaharanarth: color, font-size.

3. Value

Value mhanje Property la dileli setting. Udaharanarth: blue, red kiwa 20px.

4. CSS Declaration

Declaration mhanje Property ani Value yanchi jodi. Ya donhi goshti ekatra lihilya ki ek CSS Declaration tayar hote.

Pratyek Declaration chya shevati Semicolon (;) vaparla jato. 

p {
    color: red;
}

Ya Example madhye color: red; ha ek CSS Declaration aahe.

Mahatvache: Declaration Block chi suruvat Opening Curly Bracket { ne hote ani shevat Closing Curly Bracket } ne hoto.

5. Multiple CSS Declarations

Aapan eka CSS Rule madhye ekapeksha jast Declarations lihू shakto. Yamule ekach HTML element la vegveglya styles deta yetat. 

h1 {
    color: green;
    font-size: 32px;
    text-align: center;
    background-color: lightgray;
}

Ya Example madhye h1 element la char vegveglya Properties vaprun style dili aahe.

  • color: Text cha rang badalto.
  • font-size: Text cha aakar badalto.
  • text-align: Text kuthe align karaycha te tharavto.
  • background-color: Background cha rang badalto.

6. CSS Syntax Example

Aata ek HTML Heading ani Paragraph la CSS vaprun style kashi dyaychi te pahu.

HTML Code

<h1>Welcome to CSS</h1>
<p>Learning CSS is easy.</p>

CSS Code

h1 {
    color: blue;
    text-align: center;
}

p {
    color: gray;
    font-size: 18px;
}

Output

Welcome to CSS

Learning CSS is easy.

7. CSS Syntax Madhil Common Mistakes

Mistake 1: Semicolon Lihaycha Rahane 
h1 {
    color: blue
}

Pratyek Declaration nantar Semicolon lavayla visru naka.

Mistake 2: Curly Brackets Lihayla Visarane 
h1
    color: blue;

CSS Declaration Block lihitana Opening ani Closing Curly Brackets vaprane avashyak aahe.

Mistake 3: Colon Lihayla Visarane 
h1 {
    color blue;
}

Property ani Value yanchya madhye Colon (:) vaprane avashyak aahe.

Tip: CSS code lihitana Brackets, Colon ani Semicolon barobar aahet ka he nehmi tapasun paha.

8. Mahatvache Mudde

  • CSS Rule madhye Selector ani Declaration astat.
  • Selector HTML element nivadto.
  • Property konti style badlaychi te sangte.
  • Value Property chi setting tharavte.
  • Declaration madhye Property ani Value astat.
  • Declarations vegle karnyasathi Semicolon vapartat.
  • Curly Brackets madhye CSS Declarations lihitat.

9. Saravasaathi Kruti

Task: Heading la Style dya

Ek HTML page tayar kara. Tyamadhye ek Heading ani ek Paragraph add kara.

  1. Heading cha color red kara.
  2. Heading cha font-size 35px theva.
  3. Heading la center madhye align kara.
  4. Paragraph cha color green kara.
  5. Paragraph cha font-size 18px theva.
