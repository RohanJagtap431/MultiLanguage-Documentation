CSS Grid

CSS Grid cha use webpage madhil elements rows ani columns madhye arrange karanyasathi hoto.

📘 Beginner Level ⏱️ 30 Minutes 📄 Page 16

1. Introduction to CSS Grid

CSS Grid hi two-dimensional layout system aahe. Yachya madatine aapan elements rows ani columns donhi directions madhye arrange karu shakto.

Grid madhye parent element la Grid Container ani tyachya direct child elements la Grid Items mhanatat.

Definition: CSS Grid is a two-dimensional layout system used to create rows and columns on a webpage.

Grid madhil important terms

  • Grid Container: Grid layout cha parent element.
  • Grid Items: Container madhil direct child elements.
  • Rows: Horizontal divisions.
  • Columns: Vertical divisions.
  • Grid Gap: Rows ani columns madhil space.

2. Display: Grid

Grid layout start karanyasathi parent container la display: grid dyave lagte. Tyamule tyache direct children grid items bantat.

CSS Code

.container {
    display: grid;
}

Output

Item 1
Item 2
Item 3
Item 4

Fakt display: grid dilyane explicit columns define kelelya nastat. Grid items default automatic placement nusar arrange hotat.

3. Grid Template Columns

grid-template-columns property cha use Grid madhye kiti columns astil ani tyanchi width kiti asel he set karanyasathi hoto.

CSS Code

.container {
    display: grid;
    grid-template-columns: 200px 200px 200px;
}

Ya example madhye 3 columns tayar hotil. Pratyek column chi width 200px asel.

4. Grid Template Rows

grid-template-rows property cha use Grid madhil rows chi height set karanyasathi hoto.

CSS Code

.container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    grid-template-rows: 80px 120px;
}

Ya example madhye don columns ani don specified rows tayar hotil.

Output

Row 1 - Item 1
Row 1 - Item 2
Row 2 - Item 3
Row 2 - Item 4

5. Gap, Row Gap and Column Gap

Grid items madhye space denyasathi gap properties vapartat.

  • gap: Rows ani columns donhi madhye space set karte.
  • row-gap: Rows madhil space set karte.
  • column-gap: Columns madhil space set karte.

CSS Code

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    row-gap: 20px;
    column-gap: 10px;
}

8. Repeat() Function and FR Unit

Repeat() Function

repeat() function cha use same size che columns kiwa rows punha-punha define karanyasathi hoto. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 200px);
}

Ya code madhye 200px width che 3 columns tayar hotil.

FR Unit

fr mhanje fractional unit. Grid container madhil available space cha ek hissa darshavnyasathi fr vapartat. 

.container {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
}

Ya example madhye columns cha proportion 1 : 2 : 1 asel.

Output

1fr
2fr
1fr
Tip: Responsive Grid tayar karanyasathi repeat() ani fr unit khup upyogi aahet.

9. Responsive Grid Layout

Responsive Grid madhye screen size nusar columns chi sankhya automatic change karta yete.

HTML Code

<div class="responsive-grid">

    <div class="card">HTML</div>
    <div class="card">CSS</div>
    <div class="card">JavaScript</div>
    <div class="card">Python</div>

</div>

CSS Code

.responsive-grid {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(180px, 1fr));
    gap: 15px;
}

Output

HTML
CSS
JavaScript
Python
Tip: auto-fit ani minmax() mule available width nusar Grid columns adjust hotat.

10. Important Points

  • CSS Grid hi two-dimensional layout system aahe.
  • display: grid parent la Grid Container banavte.
  • grid-template-columns columns define karte.
  • grid-template-rows rows define karte.
  • gap rows ani columns madhil space set karte.
  • grid-column item cha column span set karte.
  • grid-row item cha row span set karte.
  • repeat() repeated tracks define karte.
  • fr available space cha fraction darshavte.
  • auto-fit ani minmax() responsive Grid sathi upyogi aahet.
