CSS Text Properties

Learn how to control text alignment, decoration, transformation, spacing and shadows using CSS.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 06

1. Introduction to Text Properties

CSS Text Properties cha use web page varil text cha appearance ani arrangement control karanyasathi hoto.

Ya properties mule text chi position, decoration, size madhil spacing ani shadow control karta yete.

Definition: CSS Text Properties are used to control the appearance and alignment of text in HTML elements.

2. Text Align

text-align property cha use text la left, right, center kiwa justify karanyasathi hoto.

Common Values

Value Meaning
left Text davya bajula align hoto.
right Text ujvya bajula align hoto.
center Text madhyabhagi align hoto.
justify Text donhi bajunni align hoto.

HTML Code

<p class="left-text">Left Aligned Text</p>

<p class="center-text">Center Aligned Text</p>

<p class="right-text">Right Aligned Text</p>

CSS Code

.left-text {
    text-align: left;
}

.center-text {
    text-align: center;
}

.right-text {
    text-align: right;
}

Output

Left Aligned Text

Center Aligned Text

Right Aligned Text

3. Text Decoration

text-decoration property cha use text la underline, overline kiwa line-through denyasathi hoto.

Common Values

  • underline – Text khali line yete.
  • overline – Text var line yete.
  • line-through – Text madhun line jate.
  • none – Text decoration remove hote.

HTML Code

<p class="underline">Underline Text</p>

<p class="overline">Overline Text</p>

<p class="line-through">Line Through Text</p>

<a href="#" class="no-decoration">Normal Link</a>

CSS Code

.underline {
    text-decoration: underline;
}

.overline {
    text-decoration: overline;
}

.line-through {
    text-decoration: line-through;
}

.no-decoration {
    text-decoration: none;
}

Output

Underline Text

Overline Text

Line Through Text

Normal Link
Lakshat Thev: Links varil default underline remove karanyasathi text-decoration: none vapartat.

4. Text Transform

text-transform property cha use text madhil letters uppercase, lowercase kiwa capitalize karanyasathi hoto.

Common Values

  • uppercase – Sarva letters capital hotat.
  • lowercase – Sarva letters small hotat.
  • capitalize – Pratyek word cha pahila letter capital hoto.
  • none – Original text transformation hot nahi.

HTML Code

<p class="uppercase">welcome to css</p>

<p class="lowercase">WELCOME TO CSS</p>

<p class="capitalize">welcome to css</p>

CSS Code

.uppercase {
    text-transform: uppercase;
}

.lowercase {
    text-transform: lowercase;
}

.capitalize {
    text-transform: capitalize;
}

Output

welcome to css

WELCOME TO CSS

welcome to css

5. Text Indent

text-indent property cha use paragraph madhil first line la thoda space denyasathi hoto.

CSS Code

p {
    text-indent: 40px;
}

Output

CSS is used to style HTML web pages. It helps us change the appearance of text, colors, backgrounds and layouts.

Remember: text-indent fakt paragraph chi first line indent karte.

6. Line Height

line-height property cha use paragraph madhil eka line ani dusrya line madhil vertical spacing control karanyasathi hoto.

CSS Code

p {
    line-height: 1.8;
}

Output

CSS is used to design web pages. It makes websites attractive and readable. We can control text spacing using CSS.

Note: line-height: 1.8 mhanje font size chya 1.8 pat line height. Udaharanarth, 16px font asel tar line height 28.8px hote.

7. Letter Spacing

letter-spacing property cha use letters madhil horizontal antar vadhavnyasathi kiwa kami karanyasathi hoto.

CSS Code

h2 {
    letter-spacing: 4px;
}

Output

WELCOME TO CSS

8. Word Spacing

word-spacing property cha use don words madhil horizontal antar control karanyasathi hoto.

CSS Code

p {
    word-spacing: 10px;
}

Output

Welcome to CSS Documentation

9. Text Shadow

text-shadow property cha use text chya mage shadow effect denyasathi hoto.

Syntax

text-shadow: horizontal vertical blur color;

CSS Code

h1 {
    text-shadow: 2px 2px 4px gray;
}

Output

Welcome to CSS

Important: Text shadow madhil pahile value horizontal distance, dusre vertical distance, tisre blur ani chauthe shadow cha color darshavte.

10. Difference Between Text Properties

Property Use
text-align Text alignment set karte.
text-decoration Text la underline kiwa line-through dete.
text-transform Letters che case change karte.
text-indent First line indent karte.
line-height Lines madhil vertical antar set karte.
letter-spacing Letters madhil antar set karte.
word-spacing Words madhil antar set karte.
text-shadow Text la shadow effect dete.

11. Important Points

  • text-align text chi alignment control karte.
  • text-decoration text la decoration dete.
  • text-transform letters che case change karte.
  • text-indent first line la space dete.
  • line-height lines madhil vertical antar control karte.
  • letter-spacing letters madhil antar control karte.
  • word-spacing words madhil antar control karte.
  • text-shadow text la shadow dete.
