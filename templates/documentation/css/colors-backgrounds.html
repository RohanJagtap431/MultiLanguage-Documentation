CSS Colors and Backgrounds

Learn how to change text colors and apply different background styles using CSS.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 05

1. Introduction to CSS Colors

CSS madhye colors cha use text, background, borders ani itar elements la color denyasathi hoto.

CSS madhye color specify karanyasathi vegveglya methods vaparta yetat.

Definition: CSS Color properties are used to set the color of text and other HTML elements.

2. Color Property

color property cha use HTML element madhil text cha color change karanyasathi hoto.

Syntax

selector {
    color: value;
}

HTML Code

<h1>Welcome to CSS</h1>
<p>Learning CSS is easy.</p>

CSS Code

h1 {
    color: blue;
}

p {
    color: green;
}

Output

Welcome to CSS

Learning CSS is easy.

Lakshat Thev: color property fakt text cha color change karte. Background color change karanyasathi background-color property vapartat.

3. Background Color

background-color property cha use HTML element chya background la color denyasathi hoto.

HTML Code

<div class="box">
    Welcome to CSS
</div>

CSS Code

.box {
    background-color: lightblue;
    padding: 20px;
}

Output

Welcome to CSS
Important: color ani background-color ya donhi properties vegvegale kaam kartat.

4. Different Ways to Write Colors

CSS madhye colors lihinyachya kahi common methods aahet.

1. Color Names

Aapan color che direct names vapru shakto. Udaharanarth: red, blue, green, black ani white. 

h1 {
    color: red;
}

p {
    color: blue;
}

2. HEX Colors

HEX mhanje Hexadecimal Color Code. Ha color lihinyacha ek common format aahe.

HEX code madhye # symbol nantar 6 hexadecimal characters astat. 

h1 {
    color: #ff0000;
}

p {
    color: #0000ff;
}

div {
    background-color: #f0f0f0;
}

3. RGB Colors

RGB cha full form Red, Green, Blue asa aahe. Ya tin colors chya values vaprun vegvegale colors tayar karta yetat.

Pratyek RGB value 0 te 255 ya range madhye aste. 

h1 {
    color: rgb(255, 0, 0);
}

p {
    color: rgb(0, 0, 255);
}

div {
    background-color: rgb(0, 255, 0);
}

4. RGBA Colors

RGBA madhye A mhanje Alpha. Alpha value color chi transparency control karte.

Alpha value 0 te 1 ya range madhye aste. 0 mhanje transparent ani 1 mhanje fully visible. 

.box {
    background-color: rgba(255, 0, 0, 0.5);
}

Color Examples

Red #ff0000
Blue #0000ff
Green #008000
Black #000000

5. Background Image

background-image property cha use HTML element chya background madhye image lavanyasathi hoto.

Image cha path url() madhye lihava lagto.

HTML Code

<div class="image-box">
    Welcome to My Website
</div>

CSS Code

.image-box {
    background-image: url("background.jpg");
    background-size: cover;
    background-position: center;
}
Tip: background.jpg hi image CSS file chya relative path nusar yogya location var theva. Image load zali nahi tar path check kara.

6. Background Repeat

background-repeat property image background madhye repeat karaychi ki nahi he tharavte.

Common Values

Value Meaning
repeat Image repeat hote.
no-repeat Image repeat hot nahi.
repeat-x Image horizontal direction madhye repeat hote.
repeat-y Image vertical direction madhye repeat hote.

CSS Example

.box {
    background-image: url("pattern.png");
    background-repeat: no-repeat;
}

7. Background Position

background-position property background image element madhye kuthe disavi he tharavte.

Common Values

  • center – Image madhye diste.
  • top – Image varchya bajula diste.
  • bottom – Image khalchya bajula diste.
  • left – Image davya bajula diste.
  • right – Image ujvya bajula diste.

CSS Example

.box {
    background-image: url("background.jpg");
    background-repeat: no-repeat;
    background-position: center;
}

8. Background Size

background-size property background image cha size control karte.

Common Values

Value Meaning
cover Element purnapane cover hoto; image cha kahi bhag crop hou shakto.
contain Purn image element madhye fit hote; rikami jaga rahu shakte.
100% 100% Image element chya width ani height pramane stretch hote.

CSS Example

.box {
    background-image: url("background.jpg");
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}
Important: cover vaparlyas image cha kahi bhag crop hou shakto. contain vaparlyas purn image diste, pan element madhye rikami jaga rahu shakte.

9. Common Mistakes

Mistake 1: Using color for Background 
.box {
    color: yellow;
}

color property text cha color change karte. Background sathi background-color vapra.

Mistake 2: Incorrect Image Path 
.box {
    background-image: url("wrong.jpg");
}

Image cha file path chukla tar background image load honar nahi.

Mistake 3: Missing URL Function 
.box {
    background-image: "image.jpg";
}

Background image sathi url() function vapra.

10. Important Points

  • color property text cha color change karte.
  • background-color property background color set karte.
  • CSS madhye Color Names, HEX, RGB ani RGBA vaparta yetat.
  • RGBA madhil Alpha transparency control karte.
  • background-image image set karte.
  • background-repeat image repeat control karte.
  • background-position image chi position tharavte.
  • background-size image cha size control karte.

  2. Paragraph la blue color dya.
  3. Ek div tayar karun background-color dya.
  4. HEX ani RGB colors vaprun paha.
  5. Ek background image add kara.
  6. background-size: cover vaprun paha.
