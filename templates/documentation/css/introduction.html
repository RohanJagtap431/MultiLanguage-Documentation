Introduction to CSS

CSS mhanje kay, tyacha vapar ka kartat ani website la sundar va responsive banvanyasathi CSS kashi madat karte te samjun ghya.

📘 Beginner Level ⏱️ 10 Minutes 📄 Page 01

1. CSS Mhanje Kay?

CSS cha full form Cascading Style Sheets asa aahe. CSS hi ek Stylesheet Language aahe. Ticha vapar HTML Web Pages la design ani style denyasathi kela jato.

HTML website cha structure tayar karte, tar CSS tya website cha look ani design tharavte.

Definition: CSS hi HTML Documents cha design ani presentation tharavnyasathi vaprali janari Language aahe.

2. CSS Ka Vapartat?

Fakt HTML vaprun aapan ek basic web page tayar karu shakto. Pan CSS vaparlyamule to page adhik sundar, vyavasthit ani vaparnyas sopa banto.

CSS cha vapar khalil goshtinsathi hoto:

  • Text ani Background cha color badalnyasathi.
  • Font size ani Font style set karnyasathi.
  • HTML elements madhye spacing denyasathi.
  • Website che Layout ani Design tayar karnyasathi.
  • Website vegveglya screen sizes var changli disnyasathi.
  • Animations ani Visual Effects add karnyasathi.

3. HTML vs CSS

HTML

HTML web page cha structure tayar karte.

  • Headings
  • Paragraphs
  • Images
  • Links

CSS

CSS web page cha design tharavte.

  • Colors
  • Fonts
  • Spacing
  • Layouts

4. CSS Che Fayde

  • Easy Styling: Website la sundar design deta yete.
  • Time Saving: Ek CSS file vaprun anek pages la design deta yete.
  • Reusable: Ekda lihilele CSS Rules punha vaparta yetat.
  • Responsive Design: Website vegveglya screen sizes var changli disnyas madat hote.
  • Easy Maintenance: HTML structure na badalta website cha design badalta yeto.

5. CSS Kashi Kaam Karte?

Browser sarvat aadhi HTML Document vachto. Tyanantar HTML elements sobat match honare CSS Rules shodhun tyanna apply karto.

6. Simple CSS Example

Ya Example madhye HTML cha vapar Heading ani Paragraph tayar karnyasathi kela aahe. CSS cha vapar tyanna design denyasathi kela aahe.

HTML Code

<h1>Welcome to CSS</h1>
<p>CSS makes websites beautiful.</p>

CSS Code

h1 {
    color: blue;
    font-size: 32px;
}

p {
    color: gray;
    font-size: 18px;
}

Output

Welcome to CSS

CSS makes websites beautiful.

7. Mahatvache Mudde

  • CSS cha full form Cascading Style Sheets aahe.
  • CSS cha vapar HTML Documents la design denyasathi hoto.
  • HTML structure tayar karte, tar CSS design karte.
  • CSS mule Responsive Websites tayar karta yetat.
  • Ek CSS file anek Web Pages sathi vaparta yete.

8. Saravasaathi Kruti

Khalil goshti vaprun ek simple HTML page tayar kara:

  1. Ek Heading tayar kara: My First CSS Page
  2. Swatahbaddal mahiti denara ek Paragraph liha.
  3. CSS vaprun Heading cha color badla.
  4. Paragraph cha font-size badla.
