Project 1 - Profile Card

Profile Card madhye user che nav, role ani short introduction display kele jate. Ya project madhye aapan padding, margin, border-radius, box-shadow ani text properties vaparnar aahot.

HTML Code

<div class="profile-card">

    <div class="profile-avatar">RJ</div>

    <h2>Rohan Jagtap</h2>

    <p class="profile-role">
        Python Backend Developer
    </p>

    <p class="profile-description">
        I build web applications using Python
        and Django.
    </p>

    <button class="profile-button">
        View Profile
    </button>

</div>

CSS Code

.profile-card {
    width: 280px;
    padding: 25px;
    margin: 20px auto;
    text-align: center;
    background: white;
    border-radius: 12px;
    box-shadow: 0 4px 15px #00000015;
}

.profile-avatar {
    width: 75px;
    height: 75px;
    margin: 0 auto 15px;
    display: flex;
    justify-content: center;
    align-items: center;
    background: #2563eb;
    color: white;
    border-radius: 50%;
    font-size: 24px;
    font-weight: bold;
}

.profile-card h2 {
    margin: 10px 0;
    color: #172033;
}

.profile-role {
    color: #2563eb;
    font-size: 14px;
}

.profile-description {
    color: #64748b;
    font-size: 13px;
    line-height: 1.7;
}

.profile-button {
    padding: 10px 20px;
    background: #2563eb;
    color: white;
    border: none;
    border-radius: 6px;
    cursor: pointer;
}

Output

RJ

Rohan Jagtap

Python Backend Developer

I build web applications using Python and Django.

CSS Concepts: Flexbox, Padding, Margin, Border Radius, Box Shadow and Text Styling.

Project 2 - Responsive Navigation Bar

Navigation Bar cha use website madhil vegveglya pages var navigate karanyasathi hoto. Ya project madhye Flexbox ani Media Queries vaparnar aahot.

HTML Code

<nav class="project-navbar">

    <h2 class="project-logo">MyWebsite</h2>

    <div class="project-nav-links">
        <a href="#">Home</a>
        <a href="#">About</a>
        <a href="#">Services</a>
        <a href="#">Contact</a>
    </div>

</nav>

CSS Code

.project-navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 18px 25px;
    background: #172033;
}

.project-logo {
    color: white;
    margin: 0;
    font-size: 20px;
}

.project-nav-links {
    display: flex;
    gap: 20px;
}

.project-nav-links a {
    color: white;
    text-decoration: none;
}

.project-nav-links a:hover {
    color: #93c5fd;
}

/* Mobile */

@media (max-width: 600px) {

    .project-navbar {
        flex-direction: column;
        gap: 15px;
    }

    .project-nav-links {
        flex-wrap: wrap;
        justify-content: center;
        gap: 12px;
    }

}

Output

MyWebsite

Home About Services Contact
CSS Concepts: Flexbox, Gap, Hover, Media Queries and Responsive Design.

Project 3 - Login Form

Login Form madhye user email ani password enter karu shakto. Ya project madhye aapan form elements, input styling ani focus effects shiknar aahot.

HTML Code

<div class="login-card">

    <h2>Welcome Back</h2>

    <p>Login to your account</p>

    <form>

        <label for="login-email">Email</label>
        <input
            type="email"
            id="login-email"
            placeholder="Enter your email"
        >

        <label for="login-password">Password</label>
        <input
            type="password"
            id="login-password"
            placeholder="Enter your password"
        >

        <button type="submit">Login</button>

    </form>

</div>

CSS Code

.login-card {
    width: 100%;
    max-width: 350px;
    margin: 20px auto;
    padding: 25px;
    box-sizing: border-box;
    background: white;
    border-radius: 12px;
    box-shadow: 0 4px 15px #00000015;
}

.login-card h2 {
    color: #172033;
    margin: 0 0 8px;
}

.login-card p {
    color: #64748b;
    font-size: 13px;
    margin-bottom: 20px;
}

.login-card label {
    display: block;
    margin: 12px 0 6px;
    font-size: 13px;
    font-weight: 600;
}

.login-card input {
    width: 100%;
    padding: 11px;
    box-sizing: border-box;
    border: 1px solid #cbd5e1;
    border-radius: 6px;
    outline: none;
}

.login-card input:focus {
    border-color: #2563eb;
}

.login-card button {
    width: 100%;
    padding: 12px;
    margin-top: 20px;
    background: #2563eb;
    color: white;
    border: none;
    border-radius: 6px;
    cursor: pointer;
}

Output

Welcome Back

Login to your account

Note: Ha fakt frontend design demo aahe. Actual login system sathi backend authentication, form validation ani security implement karavi lagte.
CSS Concepts: Form Styling, Input, Focus, Border, Padding and Box Shadow.

Project 6 - Responsive Image Gallery

Image Gallery madhye multiple images grid format madhye display kele jatat. Ya project madhye CSS Grid ani Media Queries vaparnar aahot.

HTML Code

<div class="gallery">

    <div class="gallery-item">Image 1</div>
    <div class="gallery-item">Image 2</div>
    <div class="gallery-item">Image 3</div>
    <div class="gallery-item">Image 4</div>
    <div class="gallery-item">Image 5</div>
    <div class="gallery-item">Image 6</div>

</div>

CSS Code

.gallery {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

.gallery-item {
    min-height: 120px;
    display: flex;
    justify-content: center;
    align-items: center;
    background: #dbeafe;
    color: #1e40af;
    border-radius: 8px;
}

/* Tablet */

@media (max-width: 900px) {
    .gallery {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Mobile */

@media (max-width: 600px) {
    .gallery {
        grid-template-columns: 1fr;
    }
}
