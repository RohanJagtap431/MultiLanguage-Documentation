CSS Shadows and Gradients

CSS Shadows cha use elements la depth effect denyasathi ani Gradients cha use multiple colors mix karun attractive backgrounds tayar karanyasathi hoto.

📘 Beginner Level ⏱️ 25 Minutes 📄 Page 21

1. Introduction to CSS Shadows

CSS Shadow cha use HTML elements chya mage shadow effect tayar karanyasathi hoto. Shadow mule website madhil cards, buttons ani boxes attractive distat.

CSS madhye mainly don types che shadows aahet:

  • box-shadow - Box kiwa element la shadow dete.
  • text-shadow - Text la shadow dete.
Definition: CSS Shadow properties are used to add shadow effects to elements and text.

2. box-shadow

box-shadow property cha use div, card, button kiwa itar box elements la shadow denyasathi hoto.

Syntax

box-shadow: horizontal vertical blur spread color;

CSS Code

.box {
    box-shadow: 5px 5px 10px gray;
}

Properties Meaning

  • Horizontal - Shadow left kiwa right move karte.
  • Vertical - Shadow up kiwa down move karte.
  • Blur - Shadow soft kiwa blur karte.
  • Spread - Shadow cha size vadhavte kiwa kami karte.
  • Color - Shadow cha color tharavte.

Output

Box Shadow

3. text-shadow

text-shadow property cha use text chya mage shadow effect denyasathi hoto.

Syntax

text-shadow: horizontal vertical blur color;

CSS Code

h2 {
    text-shadow: 2px 2px 4px gray;
}

Output

CSS TEXT SHADOW

4. inset Shadow

inset keyword cha use box-shadow la element chya baher aivaji aatmadhe shadow effect denyasathi hoto.

CSS Code

.box {
    box-shadow: inset 3px 3px 8px gray;
}

Output

Inset Shadow

5. Multiple Shadows

Ekach element la comma (,) vaprun multiple shadows deta yetat.

CSS Code

.box {
    box-shadow:
        2px 2px 5px gray,
        5px 5px 10px lightblue;
}

Output

Multiple Shadows

6. Introduction to CSS Gradients

CSS Gradient cha use ekach background madhye don kiwa adhik colors smoothly mix karanyasathi hoto.

Gradient cha use buttons, banners, cards ani website backgrounds madhye kela jato.

Definition: CSS Gradients allow smooth transitions between two or more colors.

Types of Gradients

  • Linear Gradient
  • Radial Gradient
  • Conic Gradient

7. linear-gradient()

linear-gradient() cha use colors la straight line direction madhye mix karanyasathi hoto.

CSS Syntax

background: linear-gradient(direction, color1, color2);

CSS Code

.box {
    background: linear-gradient(
        to right,
        blue,
        purple
    );
}

Common Directions

  • to right - Left to right.
  • to left - Right to left.
  • to bottom - Top to bottom.
  • to top - Bottom to top.

Output

Linear Gradient

8. radial-gradient()

radial-gradient() cha use colors la center pasun circular kiwa elliptical pattern madhye mix karanyasathi hoto.

CSS Code

.box {
    background: radial-gradient(
        circle,
        yellow,
        orange,
        red
    );
}

Output

Radial Gradient

9. conic-gradient()

conic-gradient() cha use center point chya around colors circular angle pattern madhye display karanyasathi hoto.

CSS Code

.box {
    background: conic-gradient(
        red,
        yellow,
        green,
        blue,
        red
    );
}

Output

Conic

10. Gradient Direction and Color Stops

Gradient madhye direction ani color stops vaprun colors kuthe ani kase display honar he control karta yete.

Example 1 - Direction

background: linear-gradient(
    to right,
    blue,
    red
);

Example 2 - Angle

background: linear-gradient(
    45deg,
    blue,
    red
);

Example 3 - Color Stops

background: linear-gradient(
    to right,
    blue 0%,
    purple 50%,
    red 100%
);

Color stop madhye percentage vaprun specific color kuthe start kiwa end honar he tharavta yete.

Output

Color Stops

11. Difference Between Shadows and Gradients

Shadows Gradients
Element la depth effect detat. Multiple colors smoothly mix kartat.
box-shadow ani text-shadow vapartat. linear, radial ani conic gradient vapartat.
Cards ani text sathi useful. Backgrounds ani buttons sathi useful.

12. Important Points

  • box-shadow element la shadow dete.
  • text-shadow text la shadow dete.
  • inset mule inner shadow tayar hote.
  • Multiple shadows comma vaprun deta yetat.
  • linear-gradient straight line madhye colors mix karte.
  • radial-gradient circular pattern madhye colors mix karte.
  • conic-gradient center chya around colors display karte.
  • Color stops percentage vaprun control karta yetat.
