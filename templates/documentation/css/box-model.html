CSS Box Model

CSS Box Model cha use HTML elements madhil content, padding, border ani margin samjun layout design karanyasathi hoto.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 09

1. Introduction to CSS Box Model

HTML madhil pratyek element browser madhye rectangular box pramane display hoto. Ya box la CSS Box Model mhantat.

Box Model madhye 4 main parts astat: Content, Padding, Border ani Margin.

Definition: CSS Box Model is a concept that describes how HTML elements are structured using content, padding, border and margin.

2. Parts of CSS Box Model

1. Content

Content ha element cha actual text, image kiwa other HTML content asto. Ha box cha madhla bhag asto.

2. Padding

Padding mhanje content ani border madhil space. Padding mule content chya around internal space tayar hote.

3. Border

Border ha padding ani content chya baher asnari boundary line aahe.

4. Margin

Margin mhanje element chya border chya baher asnari space. Yacha use don elements madhye antar thevnyasathi hoto.

4. CSS Code Example

Khali dilelya example madhye aapan eka box la width, padding, border ani margin dile aahet.

HTML Code

<div class="box">
    Welcome to CSS Box Model
</div>

CSS Code

.box {
    width: 200px;
    padding: 20px;
    border: 5px solid blue;
    margin: 30px;
}

Output

Welcome to CSS Box Model
Calculation: Default content-box model madhye total width = 200px content + 40px padding + 10px border = 250px. Margin add kelyavar donhi bajunchi extra space milun 310px hote.

5. Box Sizing Property

box-sizing property cha use element chi total width ani height kashi calculate hoil he control karanyasathi hoto.

5.1 Content-Box

content-box hi default value aahe. Yat width ani height fakt content sathi astat. Padding ani border he extra add hotat.

CSS Code

.box {
    width: 200px;
    padding: 20px;
    border: 5px solid blue;
    box-sizing: content-box;
}

5.2 Border-Box

border-box madhye width ani height madhye content, padding ani border ya sarvांचा samavesh hoto.

CSS Code

.box {
    width: 200px;
    padding: 20px;
    border: 5px solid blue;
    box-sizing: border-box;
}

Output Comparison

content-box
250px Total Width
border-box
200px Total Width
Important: border-box vaparlyas width calculate karne sope hote. Mhanun responsive layouts madhye hi property commonly vapartat.

6. Difference Between Content-Box and Border-Box

Property content-box border-box
Width Fakt content width. Content + padding + border.
Padding Extra add hote. Width madhye include hote.
Border Extra add hote. Width madhye include hote.
Default Yes No

7. Common Box Model Properties

Property Use
width Content chi width set karte.
height Content chi height set karte.
padding Content chya around internal space dete.
border Element la boundary dete.
margin Element chya baher space dete.
box-sizing Width ani height calculation control karte.

8. Important Points

  • Pratyek HTML element box pramane display hoto.
  • Box Model madhye 4 main parts astat.
  • Content ha actual element content asto.
  • Padding content ani border madhil space aahe.
  • Border element chi boundary aahe.
  • Margin element chya baher space dete.
  • content-box hi default box-sizing value aahe.
  • border-box madhye padding ani border width madhye include hotat.
