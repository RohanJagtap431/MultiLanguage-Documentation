CSS Fonts

CSS Fonts cha use website madhil text cha font, size, thickness ani style change karanyasathi hoto.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 07

1. Introduction to CSS Fonts

Font mhanje text lihinyachi visual style. CSS madhil font properties vaprun aapan website varil text cha appearance badlu shakto.

Udaharanarth, heading mothi karne, text bold karne kiwa italic style dene.

Definition: CSS Font Properties are used to control the typeface, size, weight and style of text.

2. Font Family

font-family property cha use text sathi konta font vapraycha he tharavnyasathi hoto.

Common Font Families

  • Arial
  • Verdana
  • Georgia
  • Times New Roman
  • Courier New

CSS Code

body {
    font-family: Arial, sans-serif;
}

h1 {
    font-family: Georgia, serif;
}

Output

Welcome to CSS

This paragraph uses Arial font.

This paragraph uses Georgia font.

Lakshat Thev: Ekapeksha jast fonts dile tar browser pahila available font vaparto. Shevti generic font family dene changli practice aahe.

3. Font Size

font-size property cha use text cha size motha kiwa lahan karanyasathi hoto.

Common Units

  • px – Fixed pixel size.
  • em – Parent element chya font size nusar.
  • rem – Root element chya font size nusar.
  • % – Parent font size chya percentage nusar.

CSS Code

.small-text {
    font-size: 14px;
}

.medium-text {
    font-size: 20px;
}

.large-text {
    font-size: 30px;
}

Output

Small Text - 14px

Medium Text - 20px

Large Text - 30px

4. Font Weight

font-weight property cha use text kiti bold kiwa light disel he control karanyasathi hoto.

Common Values

  • normal – Normal text.
  • bold – Bold text.
  • 100 to 900 – Text chi thickness set karte.

CSS Code

.normal-text {
    font-weight: normal;
}

.bold-text {
    font-weight: bold;
}

.heavy-text {
    font-weight: 900;
}

Output

Normal Text

Bold Text

Heavy Text

5. Font Style

font-style property cha use text normal kiwa italic style madhye dakhavnyasathi hoto.

Common Values

  • normal – Normal text.
  • italic – Italic text.
  • oblique – Slanted text.

CSS Code

.normal-style {
    font-style: normal;
}

.italic-style {
    font-style: italic;
}

.oblique-style {
    font-style: oblique;
}

Output

Normal Font Style

Italic Font Style

Oblique Font Style

6. Font Variant

font-variant property cha use lowercase letters la small capital letters mhanjech small-caps style madhye dakhavnyasathi hoto.

Common Values

  • normal – Normal text.
  • small-caps – Small capital letters.

CSS Code

.normal-variant {
    font-variant: normal;
}

.small-caps {
    font-variant: small-caps;
}

Output

Welcome to CSS

Welcome to CSS

7. Google Fonts

Google Fonts hi free font library aahe. Yatun website sathi vegvegale fonts vaparta yetat.

Google Font vaparnyasathi font select karun tyachi stylesheet HTML madhye link karavi lagte.

Step 1: Google Fonts

Google Fonts Website open kara ani avadlela font select kara.

Step 2: HTML Code

<head>
    <link rel="preconnect"
          href="https://fonts.googleapis.com">

    <link rel="preconnect"
          href="https://fonts.gstatic.com"
          crossorigin>

    <link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap"
          rel="stylesheet">
</head>

Step 3: CSS Code

body {
    font-family: 'Roboto', sans-serif;
}
Important: Google Fonts vaparnyasathi internet connection lagte. External font service vapratana website chi privacy ani loading requirements lakshat ghya.

8. Font Shorthand Property

font hi shorthand property aahe. Yachya madatine anek font properties ekach declaration madhye set karta yetat.

Syntax

font: style weight size family;

CSS Code

p {
    font: italic bold 20px Arial, sans-serif;
}

Output

Welcome to CSS Documentation

Lakshat Thev: Shorthand madhye font-size ani font-family dene avashyak aahe. Font-style ani font-weight optional aahet.

9. Difference Between Font Properties

Property Use
font-family Font cha type select karte.
font-size Text cha size set karte.
font-weight Text chi thickness set karte.
font-style Normal kiwa italic style dete.
font-variant Small-caps style dete.
font Anek font properties ekatra set karte.

10. Important Points

  • font-family text cha type select karte.
  • font-size text cha size change karte.
  • font-weight text bold kiwa light karte.
  • font-style italic kiwa oblique style dete.
  • font-variant small-caps style dete.
  • Google Fonts madhun external fonts vaparta yetat.
  • font shorthand madhye anek properties ekatra lihita yetat.

11. Practice Task

Task: Create a Font Styling Page

  6. Google Fonts madhun Roboto vapra.
  7. Font shorthand property vaprun text style kara.
