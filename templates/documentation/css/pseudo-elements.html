CSS Pseudo-Elements

CSS Pseudo-Elements cha use HTML element chya specific part la style denyasathi kiwa content add karanyasathi hoto.

📘 Beginner Level ⏱️ 25 Minutes 📄 Page 18

1. Introduction to Pseudo-Elements

Pseudo-Elements he CSS madhil special keywords aahet. Tyanchya madatine HTML element chya specific part la style karta yete.

Udaharanarth, paragraph madhil pahile letter mothya size madhye dakhavane kiwa element chya content aadhi kahi text add karane.

Definition: A CSS pseudo-element is used to style a specific part of an HTML element or insert content before or after an element.

Syntax

selector::pseudo-element {
    property: value;
}

Pseudo-Elements sathi generally double colon (::) vapartat.

Important: Pseudo-Class sathi single colon (:) ani Pseudo-Element sathi double colon (::) vapartat.

2. ::before

::before pseudo-element cha use element chya content chya aadhi extra content add karanyasathi hoto.

Content add karanyasathi CSS madhye content property vapravi lagte.

CSS Code

.message::before {
    content: "Note: ";
    color: blue;
    font-weight: bold;
}

Output

CSS makes websites attractive.

3. ::after

::after pseudo-element cha use element chya content nantar extra content add karanyasathi hoto.

CSS Code

.message::after {
    content: " ✓";
    color: green;
    font-weight: bold;
}

Output

Task Completed

Tip: ::before ani ::after cha use decorative icons, labels, badges ani design elements add karanyasathi hoto.

4. ::first-letter

::first-letter pseudo-element cha use paragraph kiwa text madhil pahilya letter la style denyasathi hoto.

CSS Code

p::first-letter {
    color: blue;
    font-size: 35px;
    font-weight: bold;
}

Output

Welcome to CSS learning. Practice every day to improve your web development skills.

5. ::first-line

::first-line pseudo-element cha use paragraph chya pahilya visible line la style denyasathi hoto.

Screen size nusar paragraph chi first line badlu shakte.

CSS Code

p::first-line {
    color: blue;
    font-weight: bold;
}

Output

CSS is used to style HTML elements. It controls colors, spacing, fonts, layouts and the overall appearance of a website.

6. ::selection

::selection pseudo-element cha use user text select karto tevha selected text ani background chi style change karanyasathi hoto.

CSS Code

::selection {
    background-color: blue;
    color: white;
}

Output

Select this text using your mouse to see the selection effect.

Try it: Varil text mouse ne select karun paha.

7. ::marker

::marker pseudo-element cha use list madhil bullet points kiwa numbering la style denyasathi hoto.

CSS Code

li::marker {
    color: blue;
    font-size: 20px;
}

Output

  • HTML
  • CSS
  • JavaScript
  • Python

8. ::placeholder

::placeholder pseudo-element cha use input field madhil placeholder text la style denyasathi hoto.

CSS Code

input::placeholder {
    color: gray;
    font-style: italic;
}

Output

9. Difference Between Pseudo-Class and Pseudo-Element

Pseudo-Class Pseudo-Element
Single colon (:) vapartat. Double colon (::) vapartat.
Element chi state kiwa position select karte. Element cha specific part select karte.
:hover ::before
:focus ::after
:first-child ::first-letter

10. Important Points

  • Pseudo-Elements sathi double colon (::) vapartat.
  • ::before content chya aadhi content add karte.
  • ::after content chya nantar content add karte.
  • ::first-letter pahilya letter la style karte.
  • ::first-line pahilya visible line la style karte.
  • ::selection selected text la style karte.
  • ::marker list markers la style karte.
  • ::placeholder input placeholder text la style karte.
  • ::before ani ::after sathi content property mahatvachi aahe.
