CSS Display Property

CSS Display property cha use HTML elements webpage var kase display hotil he control karanyasathi hoto.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 13

1. Introduction to Display

HTML madhil pratyek element cha default display behavior asto. Kahi elements new line pasun start hotat, tar kahi same line madhye display hotat.

CSS madhil display property vaprun aapan element cha display behavior change karu shakto.

Definition: The CSS display property specifies how an HTML element is displayed on a webpage.

2. Display: Block

Block elements nehmich new line pasun start hotat ani available width gheu shaktat.

Width ani height properties block elements var apply karta yetat.

Examples of Block Elements

  • <div>
  • <p>
  • <h1> to <h6>
  • <section>

CSS Code

.box {
    display: block;
    width: 200px;
    padding: 15px;
}

Output

Block Element 1
Block Element 2
Block Element 3

3. Display: Inline

Inline elements same line madhye display hotat. Tyanna content purtich width milte.

Normal inline elements var width ani height properties apply hot nahit.

Examples of Inline Elements

  • <span>
  • <a>
  • <strong>
  • <em>

CSS Code

.item {
    display: inline;
    background-color: lightblue;
}

Output

Inline 1 Inline 2 Inline 3

4. Display: Inline-Block

Inline-block elements same line madhye display hotat. Pan tyanna width ani height properties apply karta yetat.

CSS Code

.box {
    display: inline-block;
    width: 120px;
    height: 70px;
    padding: 10px;
}

Output

Box 1
Box 2
Box 3

5. Display: None

display: none mule element webpage var disat nahi ani tyane layout madhye kontihi space occupy hot nahi.

CSS Code

.box {
    display: none;
}

Output

Visible Element 1
Hidden Element
Visible Element 2
Important: display: none mule element layout madhun remove hoto. visibility: hidden mule element disat nahi, pan tyachi space rahate.

6. Display: Flex

display: flex cha use container madhil child elements eka flexible layout madhye arrange karanyasathi hoto.

Flexbox mule elements horizontal kiwa vertical direction madhye arrange karta yetat.

CSS Code

.container {
    display: flex;
    gap: 10px;
}

Output

Item 1
Item 2
Item 3
Tip: Flexbox cha use navbar, cards, buttons ani alignment sathi khup hoto.

7. Display: Grid

display: grid cha use rows ani columns madhye elements arrange karanyasathi hoto.

CSS Code

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}

Output

1
2
3
4
5
6
Tip: CSS Grid cha use image gallery, dashboard ani multi-column layouts tayar karanyasathi hoto.

8. Difference Between Display Properties

Property Behavior
block New line pasun start hoto.
inline Same line madhye display hoto.
inline-block Same line madhye rahato ani width-height accept karto.
none Element disat nahi ani space pan ghet nahi.
flex Flexible layout tayar karto.
grid Rows ani columns madhye layout tayar karto.

9. Important Points

  • Block element new line pasun start hoto.
  • Inline element same line madhye display hoto.
  • Inline-block width ani height accept karto.
  • display: none element la layout madhun remove karto.
  • Flexbox flexible layout sathi vapartat.
  • Grid rows ani columns sathi vapartat.
