CSS Specificity and Inheritance

CSS Specificity mule konta CSS rule apply hoil he tharavta yete. Inheritance mule parent element chi kahi CSS properties child elements madhye pass hotat.

📘 Beginner Level ⏱️ 30 Minutes 📄 Page 26

1. What is CSS Specificity?

Specificity mhanje CSS selectors chi priority. Ekach HTML element la vegveglya selectors madhun CSS rules apply hot astil tar specificity compare karun winning rule tharavla jato.

Jya selector chi specificity jast aste, tyacha rule generally apply hoto.

Definition: CSS Specificity is the priority system used by browsers to decide which CSS rule applies when multiple rules target the same element.

Example

p {
    color: blue;
}

.text {
    color: green;
}

#title {
    color: red;
}

Jar ekach paragraph la p, .text ani #title he tinhī selectors match hot astil tar #title selector la jast specificity asel.

2. CSS Specificity Levels

CSS selectors chi specificity vegvegli aste. Basic specificity order khalilpramane aahe.

Selector Type Specificity Weight
Inline Style 1000
ID Selector 100
Class Selector 10
Element Selector 1
Universal Selector (*) 0
Important: He basic specificity weights samjun ghenyasathi dile aahet. Browser actual specificity columns madhye compare karto. Inline style ani !important sathi cascade che additional rules suddha lagu hotat.

3. Element Selector Specificity

Element Selector HTML tag la target karto. Udaharanarth p, h1, div ani button.

Element selector chi specificity value 1 aste.

CSS Code

p {
    color: blue;
}

Explanation

Ya rule mule sarva matching paragraph elements cha text blue hoil, jar higher priority cha dusra rule nasel.

4. Class Selector Specificity

Class Selector cha use class attribute aslelya HTML elements la target karanyasathi hoto.

Class selector chi specificity value 10 aste.

HTML Code

<p class="message">
    Hello World
</p>

CSS Code

.message {
    color: green;
}

Class selector chi priority element selector peksha jast aste.

5. ID Selector Specificity

ID Selector cha use specific ID aslelya HTML element la target karanyasathi hoto.

ID selector chi specificity value 100 aste.

HTML Code

<p id="heading">
    Welcome
</p>

CSS Code

#heading {
    color: red;
}

ID selector chi priority class ani element selectors peksha jast aste.

Tip: Ekach HTML element la ID ani class donhi asu shaktat. Pan ID unique thevne hi recommended practice aahe.

6. Inline CSS Specificity

Inline CSS hi HTML element chya style attribute madhye lihili jate.

Basic specificity comparison madhye inline style la ID, class ani element selectors peksha jast priority aste.

HTML Code

<p style="color: purple;">
    Hello World
</p>

Explanation

Ya example madhye paragraph cha text purple display hoil, jar higher-priority important rule tyala override karat nasel.

Note: Inline style ani !important yanchya priority comparison sathi CSS Cascade che rules samjun ghene avashyak aahe.

7. Specificity Calculation

Ekach selector madhye multiple selector types astil tar tyanchi specificity calculate karta yete.

Example 1

p {
    color: blue;
}

Element selector = 1

Example 2

.card p {
    color: green;
}

Class = 10, Element = 1 Total = 11

Example 3

#main .card p {
    color: red;
}

ID = 100, Class = 10, Element = 1 Total = 111

Remember: Specificity compare kartana ID, Class ani Element ya columns cha order ne comparison hoto. Fakt total number baghun comparison karne nehmich yogya naste.

8. !important Rule

!important declaration cha use CSS property la important priority denyasathi hoto.

CSS Code

p {
    color: blue !important;
}

p {
    color: red;
}

Ya example madhye blue color apply hoil, karan pahilya rule madhye !important aahe.

Important: !important cha unnecessary use karu naye. Tyamule CSS maintain karne ani debugging karne kathin hou shakte. !important declarations madhye suddha cascade rules ani specificity lagu hotat.

9. What is CSS Inheritance?

Inheritance mhanje parent HTML element madhil kahi CSS property values tyachya child elements madhye automatically pass hone.

Udaharanarth, parent div la color red dila tar tyachya child paragraph la dusra color nasel tar to red inherit karu shakto.

Definition: CSS Inheritance is the process by which certain CSS property values pass from parent elements to their child elements.

HTML Code

<div class="parent">

    <p>This is child paragraph.</p>

</div>

CSS Code

.parent {
    color: blue;
}

Output

This is child paragraph.

10. Inherited and Non-Inherited Properties

CSS madhil sarva properties inherit hot nahit. Kahi properties naturally inherit hotat, tar kahi properties inherit hot nahit.

Inherited Properties Non-Inherited Properties
color margin
font-family padding
font-size border
line-height width
text-align height
Tip: Jar non-inherited property child element la dyaychi asel tar ti property child selector madhye explicitly lihavi lagte.

11. Practical Example

Ata Specificity ani Inheritance donhi concepts ekatra use karun example pahu.

HTML Code

<div class="parent-card">

    <h2>Welcome</h2>

    <p class="child-text">
        Learning CSS
    </p>

</div>

CSS Code

.parent-card {
    color: blue;
}

.parent-card p {
    color: green;
}

.child-text {
    font-size: 18px;
}

Output

Welcome

Learning CSS

Parent cha blue color h2 la inherit hoto. Paragraph la .parent-card p selector mule green color milto. Paragraph cha font-size class selector mule 18px hoto.

12. Important Points

  • Specificity CSS selectors chi priority tharavte.
  • Inline style la normal selector rules peksha jast priority aste.
  • ID selector specificity 100 aste.
  • Class selector specificity 10 aste.
  • Element selector specificity 1 aste.
  • Universal selector chi specificity 0 aste.
  • !important declaration cascade madhye special priority dete.
  • Inheritance mule kahi properties parent kadun child kade pass hotat.
  • color ani font-family naturally inherit hotat.
  • margin ani padding naturally inherit hot nahit.
