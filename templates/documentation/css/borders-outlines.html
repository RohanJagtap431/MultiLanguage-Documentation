CSS Borders and Outlines

CSS Borders and Outlines cha use HTML elements la boundary, color, style ani special effects denyasathi hoto.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 11

1. Introduction to CSS Border

CSS Border cha use HTML element chya around boundary line tayar karanyasathi hoto. Border mule element vegala disnyas madat hote.

Definition: CSS Border is a property used to create a visible boundary around an HTML element.

Basic CSS Code

.box {
    border: 2px solid blue;
}

Output

CSS Border Example

2. Border Width

border-width property cha use border chi thickness set karanyasathi hoto.

Common Values

  • thin – Patal border.
  • medium – Madhyam border.
  • thick – Jada border.
  • px value – Specific thickness set karte.

CSS Code

.box {
    border-style: solid;
    border-width: 5px;
}

Output

Thin Border
Medium Border
Thick Border

3. Border Style

border-style property cha use border cha pattern kiwa design set karanyasathi hoto.

Common Border Styles

  • solid – Saral continuous line.
  • dashed – Dash pattern madhil line.
  • dotted – Dots madhil line.
  • double – Don continuous lines.
  • groove – 3D groove effect.
  • ridge – 3D ridge effect.
  • inset – Element aat gelyasarkha effect.
  • outset – Element baher aalyasarkha effect.
  • none – Border disat nahi.
  • hidden – Border hide karte.

CSS Code

.solid {
    border: 3px solid blue;
}

.dashed {
    border: 3px dashed blue;
}

.dotted {
    border: 3px dotted blue;
}

.double {
    border: 5px double blue;
}

Output

Solid Border
Dashed Border
Dotted Border
Double Border

4. Border Color

border-color property cha use border cha color set karanyasathi hoto.

CSS Code

.box {
    border-style: solid;
    border-width: 3px;
    border-color: red;
}

Output

Red Border
Green Border
Blue Border

5. Border Shorthand Property

border hi shorthand property aahe. Yachya madatine border width, style ani color ekach declaration madhye set karta yetat.

Syntax

border: width style color;

CSS Code

.box {
    border: 3px solid blue;
}

Ya example madhye 3px border width, solid border style ani blue border color aahe.

Lakshat Thev: Border shorthand mule teen properties ekach line madhye lihita yetat.

6. Individual Border Sides

CSS madhye pratyek side la vegala border denyasathi individual border properties vapartat.

Available Properties

  • border-top – Varil border.
  • border-bottom – Khalil border.
  • border-left – Davya bajucha border.
  • border-right – Ujvya bajucha border.

CSS Code

.box {
    border-top: 3px solid red;
    border-bottom: 3px solid blue;
    border-left: 3px dashed green;
    border-right: 3px dotted orange;
}

Output

Different Border Sides

7. Border Radius

border-radius property cha use element che corners round karanyasathi hoto.

CSS Code

.box {
    border: 2px solid blue;
    border-radius: 15px;
}

Output

5px Radius
15px Radius
30px Radius
Circle
Tip: border-radius: 50% vaprun square element la circular shape deta yete.

8. CSS Outline

outline property cha use HTML element chya border chya baher ek line dakhavnyasathi hoto.

Outline ha border peksha vegala asto. Outline mule element chi actual width ani height change hot nahi.

CSS Code

.box {
    border: 2px solid blue;
    outline: 3px solid red;
}

Output

Border and Outline Example

9. Outline Offset

outline-offset property cha use border ani outline yanchya madhye distance thevnyasathi hoto.

CSS Code

.box {
    outline: 3px solid red;
    outline-offset: 5px;
}

Output

Outline Offset Example

10. Difference Between Border and Outline

Border Outline
Element chya border area madhye asto. Border chya baher draw hoto.
Width ani height calculation var parinam hoto. Layout madhye space occupy karat nahi.
Pratyek side la vegala border deta yeto. Individual sides sathi separate outline properties nahit.
border-radius vaprun corners round karta yetat. Outline la border-radius cha effect lagu hot nahi.

11. Important Points

  • Border element chya around boundary tayar karto.
  • border-width thickness set karte.
  • border-style pattern set karte.
  • border-color color set karte.
  • border shorthand teen properties ekatra set karte.
  • border-radius corners round karte.
  • Outline border chya baher draw hoto.
  • outline-offset border ani outline madhye gap dete.
