CSS Units

CSS Units cha use elements cha size, width, height, spacing ani font-size set karanyasathi hoto.

📘 Beginner Level ⏱️ 20 Minutes 📄 Page 08

1. Introduction to CSS Units

CSS madhye kontyahi element cha size kiwa spacing set karanyasathi units vapartat.

Udaharanarth, font-size: 20px mhanje text cha size 20 pixels set hoto.

Definition: CSS Units are used to define the size of elements, text, spacing, width and height.

Types of CSS Units

  • Absolute Units
  • Relative Units
  • Viewport Units

2. Absolute Units

Absolute units madhye size ek fixed measurement pramane define hoto. He units parent element kiwa viewport chya size var depend nastat.

Common Absolute Units

Unit Meaning
px Pixel
cm Centimeter
mm Millimeter
in Inch
pt Point
pc Pica

CSS Code

.box {
    width: 200px;
    height: 100px;
}

.heading {
    font-size: 24px;
}

Output

200px × 100px

Heading Size: 24px

Lakshat Thev: Web development madhye px ha commonly used absolute unit aahe. Print design madhye cm, mm ani in upyogi padtat.

3. Relative Units

Relative units madhye element cha size dusrya element chya size kiwa root font-size nusar tharato.

3.1 Percentage (%)

Percentage unit cha use parent element chya size chya tulanet child element cha size set karanyasathi hoto.

CSS Code

.parent {
    width: 300px;
}

.child {
    width: 50%;
}

Output

Parent - 300px
Child - 50%

3.2 EM Unit

em unit ha element chya inherited kiwa computed font-size var depend karto. Font-size property sathi em cha base parent cha computed font-size asto.

CSS Code

.parent {
    font-size: 20px;
}

.child {
    font-size: 2em;
}

Output

Parent Text - 20px

Child Text - 2em (40px)

3.3 REM Unit

rem unit ha HTML root element chya font-size var depend karto.

CSS Code

html {
    font-size: 16px;
}

h1 {
    font-size: 2rem;
}

Output

Root Font Size: 16px

Heading Size: 2rem = 32px

Important: 1em cha exact size context nusar badlu shakto. 1rem cha base nehemi root element cha computed font-size asto.

4. Viewport Units

Viewport mhanje browser madhil visible area. Viewport units cha use screen chya size nusar element cha size set karanyasathi hoto.

4.1 VW (Viewport Width)

1vw mhanje viewport width cha 1%. Yacha use width kiwa responsive font-size set karanyasathi hoto.

CSS Code

.box {
    width: 50vw;
}

Mhanje viewport width 1000px asel tar 50vw = 500px.

4.2 VH (Viewport Height)

1vh mhanje viewport height cha 1%. Yacha use height set karanyasathi hoto.

CSS Code

.box {
    height: 50vh;
}

Mhanje viewport height 800px asel tar 50vh = 400px.

Output

50vw Width
50vh Height

5. VMIN and VMAX

vmin ani vmax he viewport chya width ani height paiki lahan kiwa mothya dimension var depend astat.

  • vmin – Viewport madhil smaller dimension cha 1%.
  • vmax – Viewport madhil larger dimension cha 1%.

CSS Code

.box {
    width: 50vmin;
    height: 30vmax;
}
Example: Viewport width 1000px ani height 800px asel tar 1vmin = 8px ani 1vmax = 10px.

6. Difference Between px, em and rem

Unit Depends On
px Fixed CSS pixel value.
em Element cha font-size context.
rem Root element cha font-size.
% Property nusar containing element cha size.
vw Viewport width.
vh Viewport height.
Important: Responsive website banavatana relative ani viewport units upyogi thartat. Pan pratyek property sathi ekach unit best asto ase nahi.

7. Practical Example

Khali ek responsive card che example dile aahe. Yat percentage, rem ani px units vaprale aahet.

HTML Code

<div class="card">
    <h2>CSS Learning</h2>
    <p>Learn CSS step by step.</p>
</div>

CSS Code

.card {
    width: 80%;
    max-width: 400px;
    padding: 1.5rem;
    margin: 20px auto;
    border: 1px solid #ccc;
}

.card h2 {
    font-size: 1.5rem;
}

.card p {
    font-size: 1rem;
}

Output

CSS Learning

Learn CSS step by step.

8. Important Points

  • CSS units size ani spacing define kartat.
  • px ha absolute unit aahe.
  • % ha relative unit aahe.
  • em parent kiwa element chya font-size context var depend karto.
  • rem root element chya font-size var depend karto.
  • vw viewport width nusar size set karto.
  • vh viewport height nusar size set karto.
  • vmin ani vmax viewport dimensions compare kartat.

Task: Create a Responsive Card

  6. Card la margin auto dya.
