CSS Variables

CSS Variables cha use CSS madhil values store karanyasathi ani tya values punha-punha reuse karanyasathi hoto.

📘 Beginner Level ⏱️ 25 Minutes 📄 Page 25

1. What are CSS Variables?

CSS Variables mhanje CSS madhye values store karanyachi paddhat. Ya values la variable name dile jate ani nantar tya variable cha use vegveglya CSS properties madhye karta yeto.

Udaharanarth, website madhye ekach blue color anek elements sathi vapraycha asel tar to variable madhye store karu shakto.

Definition: CSS Variables are reusable values that can be stored and used in different CSS properties.

Example

:root {
    --main-color: blue;
}

h1 {
    color: var(--main-color);
}

p {
    color: var(--main-color);
}

Ya example madhye --main-color variable madhye blue value store keli aahe. Hich value heading ani paragraph sathi vaprali aahe.

2. Why CSS Variables are Useful?

CSS Variables mule code maintain karne ani values update karne sope hote.

Advantages

  • Same value anek thikani reuse karta yete.
  • Code madhil repetition kami hote.
  • Color ani spacing change karne sope hote.
  • CSS code maintain karne sope hote.
  • Website cha design consistent thevta yeto.
Important: Variable chi value ekda change keli ki tya variable cha use karanarya CSS rules madhye updated value apply hote.

3. CSS Variables Syntax

CSS Variable declare kartana variable name chya suruvatila double hyphen (--) vapartat.

Syntax

selector {
    --variable-name: value;
}

Example

:root {
    --primary-color: #2563eb;
    --font-size: 18px;
    --main-padding: 20px;
}

Explanation

  • --primary-color ha variable name aahe.
  • #2563eb hi tyachi value aahe.
  • --font-size madhye 18px store kele aahe.
  • --main-padding madhye 20px store kele aahe.

4. :root Selector

:root ha CSS pseudo-class selector aahe. To document chya root element la select karto. HTML document madhye ha normally html element la represent karto.

Global CSS Variables declare karanyasathi :root selector cha commonly use kela jato.

CSS Code

:root {
    --primary-color: #2563eb;
    --secondary-color: #16a34a;
    --text-color: #334155;
}
Tip: :root madhye declare kelelya variables normally sampurna document madhye access karta yetat.

5. var() Function

CSS Variable madhil value use karanyasathi var() function vapartat.

Syntax

property: var(--variable-name);

CSS Code

:root {
    --main-color: #2563eb;
}

h1 {
    color: var(--main-color);
}

button {
    background-color: var(--main-color);
}

Output

CSS Variables

Same variable value heading ani button donhi thikani use keli aahe.

6. Global CSS Variables

Global Variables ase variables astat je document madhil anek selectors madhye access karta yetat.

Global Variables sathi normally :root selector vapartat.

CSS Code

:root {
    --primary-color: #2563eb;
    --background-color: #eff6ff;
}

h1 {
    color: var(--primary-color);
}

.card {
    background: var(--background-color);
}

button {
    background: var(--primary-color);
}

Ya example madhye ekach variables vegveglya selectors madhye reuse kele aahet.

7. Local CSS Variables

Local Variables he specific selector madhye declare kele jatat. Te tya selector chya scope madhye ani tyachya child elements madhye access karta yetat.

CSS Code

.card {
    --card-color: #16a34a;

    border-color: var(--card-color);
    color: var(--card-color);
}

Explanation

  • --card-color variable .card madhye declare kele aahe.
  • Te .card ani tyachya descendants madhye access karta yete.
  • Unrelated elements madhye te normally available naste.
Important: Local Variable cha scope selector var depend karto. Child elements parent madhil inherited custom property access karu shaktat.

8. CSS Variable Fallback Value

Variable available nasel kiwa valid value nasel tar fallback value cha use karta yeto.

Fallback value hi var() function madhye comma nantar lihitat.

Syntax

property: var(--variable-name, fallback-value);

CSS Code

h1 {
    color: var(--heading-color, blue);
}

Jar --heading-color variable available nasel tar heading cha color blue hoil.

Tip: Fallback value mule variable available naslyas alternative value use karta yete.

9. Practical Example - Theme Colors

Ata CSS Variables vaprun ek simple card design karu. Ya example madhye colors ani spacing variables madhye store kele aahet.

HTML Code

<div class="theme-card">

    <h2>My Website</h2>

    <p>
        Learning CSS Variables.
    </p>

    <button>Explore</button>

</div>

CSS Code

:root {
    --primary-color: #2563eb;
    --card-background: #eff6ff;
    --card-padding: 20px;
}

.theme-card {
    background: var(--card-background);
    padding: var(--card-padding);
    border-radius: 10px;
}

.theme-card h2 {
    color: var(--primary-color);
}

.theme-card button {
    background: var(--primary-color);
    color: white;
    padding: 10px 18px;
    border: none;
    border-radius: 6px;
}

Output

My Website

Learning CSS Variables.

10. Important Points

  • CSS Variables values store karatat.
  • Variable name chya suruvatila -- vapartat.
  • :root madhye global variables declare karatat.
  • var() function variable value access karte.
  • Local Variables specific selector madhye declare hotat.
  • Variables child elements madhye inherit hou shaktat.
  • Fallback value alternative value dete.
  • CSS Variables mule code maintain karne sope hote.
