CSS Media Queries

CSS Media Queries cha use screen size ani device conditions nusar website cha layout ani styling change karanyasathi hoto.

📘 Beginner Level ⏱️ 25 Minutes 📄 Page 24

1. What are CSS Media Queries?

Media Queries hi CSS madhil technique aahe. Tichya madatine screen width, height ani device conditions check karun vegvegli CSS apply karta yete.

Udaharanarth, desktop var heading cha font size 36px thevu shakto ani mobile var 24px karu shakto.

Definition: CSS Media Queries allow us to apply different CSS styles based on device or screen conditions.

Why Media Queries?

  • Mobile responsive layout tayar karanyasathi.
  • Different screen sizes support karanyasathi.
  • Font size ani spacing adjust karanyasathi.
  • Navbar ani cards cha layout change karanyasathi.

2. Media Query Syntax

Media Query lihinyasathi CSS madhye @media rule vapartat.

Syntax

@media (condition) {

    selector {
        property: value;
    }

}

Example

h1 {
    font-size: 36px;
}

@media (max-width: 600px) {
    h1 {
        font-size: 24px;
    }
}

Ya example madhye screen width 600px kiwa tyapeksha kami asel tar heading cha font size 24px hoil.

3. max-width Media Query

max-width cha use maximum screen width condition set karanyasathi hoto.

Screen width dilelya value peksha kami kiwa saman asel tar Media Query madhil CSS apply hote.

CSS Code

@media (max-width: 600px) {

    .box {
        background: blue;
        width: 100%;
    }

}

Explanation

  • 600px kiwa tyapeksha kami width asel tar CSS apply hoil.
  • 600px peksha mothi width asel tar hi CSS apply honar nahi.
Important: max-width: 600px mhanje screen width 600px kiwa tyapeksha kami asne.

4. min-width Media Query

min-width cha use minimum screen width condition set karanyasathi hoto.

Screen width dilelya value evadhi kiwa tyapeksha mothi asel tar Media Query madhil CSS apply hote.

CSS Code

@media (min-width: 768px) {

    .box {
        width: 80%;
        margin: auto;
    }

}

Explanation

  • 768px kiwa tyapeksha mothi width asel tar CSS apply hoil.
  • 768px peksha kami width asel tar hi CSS apply honar nahi.

5. Using the and Operator

Ekach Media Query madhye don kiwa adhik conditions check karanyasathi and operator vapartat.

CSS Code

@media (min-width: 600px) and
       (max-width: 900px) {

    .box {
        background: green;
    }

}

Explanation

Ya example madhye screen width 600px kiwa tyapeksha jast ani 900px kiwa tyapeksha kami asel tarch CSS apply hoil.

Tip: and operator vaparlyavar dilelya sarva conditions true asne avashyak aahe.

6. Multiple Breakpoints

Website la mobile, tablet ani desktop sathi vegvegli styling denyasathi multiple Media Queries vaparta yetat.

CSS Code

/* Mobile */

@media (max-width: 599px) {
    .container {
        width: 100%;
    }
}

/* Tablet */

@media (min-width: 600px) and
       (max-width: 991px) {
    .container {
        width: 90%;
    }
}

/* Desktop */

@media (min-width: 992px) {
    .container {
        width: 85%;
        max-width: 1100px;
    }
}

Common Breakpoints

Device Screen Width
Mobile Up to 599px
Tablet 600px to 991px
Desktop 992px and above
Note: He common example breakpoints aahet. Pratyek website sathi hech breakpoints vaprane compulsory nahi. Design chi garaj baghun breakpoints tharavtat.

7. Responsive Navbar Example

Ata Media Query vaprun ek simple navbar responsive kasa karaycha te pahu.

HTML Code

<nav class="demo-navbar">

    <div class="logo">MyWebsite</div>

    <div class="nav-links">
        <a href="#">Home</a>
        <a href="#">About</a>
        <a href="#">Services</a>
        <a href="#">Contact</a>
    </div>

</nav>

CSS Code

.demo-navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 18px;
    background: #172033;
}

.logo {
    color: white;
    font-weight: bold;
}

.nav-links {
    display: flex;
    gap: 20px;
}

.nav-links a {
    color: white;
    text-decoration: none;
}

/* Mobile */

@media (max-width: 600px) {

    .demo-navbar {
        flex-direction: column;
        gap: 15px;
    }

    .nav-links {
        flex-direction: column;
        align-items: center;
        gap: 12px;
    }

}

Output

MyWebsite
Home About Services Contact

Browser window chi width kami karun navbar cha layout change hotana paha.

8. Important Points

  • Media Queries responsive CSS sathi vapartat.
  • @media ha Media Query rule aahe.
  • max-width maximum width condition check karte.
  • min-width minimum width condition check karte.
  • and operator multiple conditions check karto.
  • Multiple breakpoints vaprun different layouts banavta yetat.
  • Breakpoints design nusar select karayche astat.
  • Media Queries madhye HTML change karanyachi garaj naste; CSS change karta yete.
