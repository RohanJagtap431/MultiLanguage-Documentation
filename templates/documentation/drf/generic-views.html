17. Generic Views in DRF

Learn how to create reusable API views using GenericAPIView and built-in generic views.

1. What are Generic Views?

Generic Views ya DRF madhil pre-built views aahet. Tyanchya madatine common API operations kami code madhye create karta yetat.

Definition

Generic Views are reusable views provided by Django REST Framework to perform common API operations.

Why use Generic Views?

  • Code kami lihava lagto.
  • Common API operations ready-made miltat.
  • Code reusable ani organized rahto.
  • CRUD APIs create karne sope hote.

Generic Views Flow

Client Request API request pathavto
↓
Generic View Common operation handle karte
↓
Serializer Data convert ani validate karto
↓
Response Client la result milto

2. What is GenericAPIView?

GenericAPIView hi DRF madhil base class aahe. Itar generic views ya class var based astat.

Definition

GenericAPIView is a base class that provides common functionality for building reusable API views.

Import GenericAPIView

from rest_framework.generics import GenericAPIView

Important Attributes

Attribute Purpose
queryset View kontya model records var work karte te define karto.
serializer_class Data serialize ani validate karanyasathi serializer select karto.
lookup_field Single object lookup karanyasathi model field select karto.
get_queryset() View sathi queryset return karte.
get_serializer_class() Use karaycha serializer class return karte.

Basic Example

File: api/views.py

from rest_framework.generics import GenericAPIView
from rest_framework.response import Response

from .models import Student
from .serializers import StudentSerializer


class StudentView(GenericAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    def get(self, request):

        students = self.get_queryset()

        serializer = self.get_serializer(
            students,
            many=True
        )

        return Response(serializer.data)

Code Explanation

  • GenericAPIView: Base class inherit keli.
  • queryset: Student records select kele.
  • serializer_class: StudentSerializer set kela.
  • get_queryset(): Records milavle.
  • get_serializer(): Serializer instance tayar kela.

3. ListAPIView

ListAPIView cha use database madhil multiple records fetch karanyasathi hoto.

Definition

ListAPIView is used to retrieve a list of objects from the database.

Example

from rest_framework.generics import ListAPIView

class StudentListView(ListAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Working

  • GET request accept karte.
  • Sarve student records fetch karte.
  • Serializer data convert karto.
  • Client la response milto.

URL

GET /api/students/

4. CreateAPIView

CreateAPIView cha use database madhye navin record create karanyasathi hoto.

Definition

CreateAPIView is used to create a new object using a POST request.

Example

from rest_framework.generics import CreateAPIView

class StudentCreateView(CreateAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Request Body

{
    "name": "Rohan",
    "email": "rohan@example.com",
    "age": 20
}

URL

POST /api/students/create/

Valid data asel tar navin student create hoto ani HTTP 201 Created response milto.

5. RetrieveAPIView

RetrieveAPIView cha use ek specific record fetch karanyasathi hoto.

Definition

RetrieveAPIView is used to retrieve a single object using its lookup value.

Example

from rest_framework.generics import RetrieveAPIView

class StudentDetailView(RetrieveAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

URL

GET /api/students/1/

Ithe ID 1 aslela student fetch hoto. Record sapadla nahi tar 404 response milto.

6. UpdateAPIView

UpdateAPIView cha use existing record update karanyasathi hoto.

Definition

UpdateAPIView is used to update an existing object using PUT or PATCH requests.

Example

from rest_framework.generics import UpdateAPIView

class StudentUpdateView(UpdateAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Supported Methods

  • PUT: Complete update.
  • PATCH: Partial update.

PATCH Request Body

{
    "age": 21
}

URL

PATCH /api/students/1/update/

7. DestroyAPIView

DestroyAPIView cha use database madhil existing record delete karanyasathi hoto.

Definition

DestroyAPIView is used to delete an existing object using a DELETE request.

Example

from rest_framework.generics import DestroyAPIView

class StudentDeleteView(DestroyAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

URL

DELETE /api/students/1/delete/

Request successful zalyas record delete hoto ani default response HTTP 204 No Content asto.

8. ListCreateAPIView

ListCreateAPIView madhye GET ani POST donhi operations ekach view madhye handle hotat.

Definition

ListCreateAPIView is used to list multiple objects and create a new object.

Example

from rest_framework.generics import ListCreateAPIView

class StudentListCreateView(ListCreateAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Supported Methods

Method Operation
GET All students fetch karne.
POST New student create karne.

URL

/api/students/

9. RetrieveUpdateDestroyAPIView

RetrieveUpdateDestroyAPIView ekach view madhye single object var GET, PUT, PATCH ani DELETE operations perform karte.

Definition

RetrieveUpdateDestroyAPIView is used to retrieve, update and delete a single object.

Example

from rest_framework.generics import (
    RetrieveUpdateDestroyAPIView
)

class StudentDetailView(RetrieveUpdateDestroyAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Supported Methods

Method Operation
GET Single student read karne.
PUT Complete student update karne.
PATCH Partial student update karne.
DELETE Student delete karne.

URL

/api/students/1/

10. Generic Views Comparison

Generic View HTTP Methods Purpose
ListAPIView GET List records
CreateAPIView POST Create record
RetrieveAPIView GET Read single record
UpdateAPIView PUT, PATCH Update record
DestroyAPIView DELETE Delete record
ListCreateAPIView GET, POST List and create
RetrieveUpdateDestroyAPIView GET, PUT, PATCH, DELETE Read, update and delete

11. Practical Student CRUD API

Ata aapan don Generic Views vaprun complete Student CRUD API create karuya.

Step 1 – Model

Ya practical sathi Topic 15 madhil Student model ani StudentSerializer use karu.

File: api/models.py

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)
    email = models.EmailField(unique=True)
    age = models.PositiveIntegerField()

    def __str__(self):
        return self.name

Step 2 – Serializer

File: api/serializers.py

from rest_framework import serializers
from .models import Student

class StudentSerializer(serializers.ModelSerializer):

    class Meta:
        model = Student
        fields = '__all__'

Step 3 – Views

File: api/views.py

from rest_framework.generics import (
    ListCreateAPIView,
    RetrieveUpdateDestroyAPIView
)

from .models import Student
from .serializers import StudentSerializer


class StudentListCreateView(ListCreateAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer


class StudentDetailView(RetrieveUpdateDestroyAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Step 4 – URLs

File: api/urls.py

from django.urls import path

from .views import (
    StudentListCreateView,
    StudentDetailView
)

urlpatterns = [

    path(
        'students/',
        StudentListCreateView.as_view(),
        name='student_list'
    ),

    path(
        'students/<int:pk>/',
        StudentDetailView.as_view(),
        name='student_detail'
    ),

]

Step 5 – Main URLs

File: config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('api/', include('api.urls')),
]
Important: Student model ani serializer Topic 15 madhye already create kele astil tar tyanna punha create karu naka. Existing files madhyech code use kara.
