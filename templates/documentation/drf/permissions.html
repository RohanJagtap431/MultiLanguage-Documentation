DJANGO REST FRAMEWORK

23. Permissions in DRF

Learn how to control access to API endpoints using Django REST Framework permissions.

1. What are Permissions?

Permission mhanje user la specific API access karaychi permission aahe ka he check karne.

Definition

Permissions determine whether a user is allowed to access a particular API resource or perform an action.

Example

Samja ek College Management API aahe.

  • Student la swatachi profile baghta yete.
  • Teacher la attendance update karta yete.
  • Admin la users manage karta yetat.

Ya pratyek user sathi vegvegale access rules define karanyasathi permissions vapartat.

2. Authentication vs Permissions

Authentication ani Permissions ya donhi concepts API security sathi important aahet.

Authentication Permissions
User kon aahe te verify karte. User la access aahe ka te check karte.
Who are you? What can you access?
Identity verify karte. Access control karte.
Example: Login Example: Admin-only API
Important: Authentication user identify karte. Permissions tyachya nantar user la API access dyaycha ki nahi te tharavtat.

3. Types of Built-in Permissions

DRF madhye kahi built-in permission classes available aahet.

Permission Class Purpose
AllowAny All users can access the API.
IsAuthenticated Only authenticated users can access.
IsAdminUser Only admin or staff users can access.
IsAuthenticatedOrReadOnly Authenticated users can make any allowed request. Others get read-only access.

4. AllowAny Permission

AllowAny permission madhye authenticated ani unauthenticated donhi users API access karu shaktat.

Definition

AllowAny allows unrestricted access to the API, regardless of authentication status.

Import

from rest_framework.permissions import AllowAny

Example

from rest_framework.views import APIView
from rest_framework.permissions import AllowAny
from rest_framework.response import Response

class PublicAPIView(APIView):

    permission_classes = [AllowAny]

    def get(self, request):
        return Response({
            "message": "This is a public API"
        })

Use Cases

  • Public information API.
  • Public product listing.
  • Registration API.
  • Login API.

5. IsAuthenticated Permission

IsAuthenticated permission fakt authenticated users na API access dete.

Definition

IsAuthenticated allows access only to users who have successfully authenticated.

Import

from rest_framework.permissions import IsAuthenticated

Example

from rest_framework.views import APIView
from rest_framework.permissions import IsAuthenticated
from rest_framework.response import Response

class ProfileAPIView(APIView):

    permission_classes = [IsAuthenticated]

    def get(self, request):
        return Response({
            "message": "Welcome to your profile",
            "username": request.user.username
        })

Result

  • Authenticated user – API access allowed.
  • Unauthenticated user – API access denied.

6. IsAdminUser Permission

IsAdminUser permission fakt staff status aslelya users na API access dete.

Definition

IsAdminUser allows access only to users whose is_staff attribute is True.

Import

from rest_framework.permissions import IsAdminUser

Example

from rest_framework.views import APIView
from rest_framework.permissions import IsAdminUser
from rest_framework.response import Response

class AdminAPIView(APIView):

    permission_classes = [IsAdminUser]

    def get(self, request):
        return Response({
            "message": "Welcome Admin"
        })

Important Points

  • Normal authenticated user la access milat nahi.
  • is_staff=True aslelya user la access milto.
  • Superuser users sadharanpane staff status suddha have astat.
Important: IsAdminUser hi permission fakt is_staff check karte. Ti custom role system kiwa business-specific admin rules automatically check karat nahi.

7. IsAuthenticatedOrReadOnly

Ya permission madhye unauthenticated users la read-only requests karta yetat. Authenticated users na write requests suddha karta yetat.

Definition

IsAuthenticatedOrReadOnly allows read-only access to everyone and write access only to authenticated users.

Read-only Methods

  • GET
  • HEAD
  • OPTIONS

Write Methods

  • POST
  • PUT
  • PATCH
  • DELETE

Example

from rest_framework.viewsets import ModelViewSet
from rest_framework.permissions import IsAuthenticatedOrReadOnly

from .models import Student
from .serializers import StudentSerializer

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    permission_classes = [
        IsAuthenticatedOrReadOnly
    ]

Result

User GET POST / PUT / DELETE
Unauthenticated Allowed Denied
Authenticated Allowed Allowed

8. Global Permission Settings

Pratyek API view madhye permission define karanyapeksha settings.py madhye default permission set karta yete.

File: config/settings.py

REST_FRAMEWORK = {

    'DEFAULT_PERMISSION_CLASSES': [
        'rest_framework.permissions.IsAuthenticated',
    ],

}

Explanation

  • Default permission sarva DRF views la apply hote.
  • Authenticated users na access milto.
  • Public API sathi AllowAny explicitly set karu shakto.

Public API Example

from rest_framework.permissions import AllowAny

class PublicAPIView(APIView):

    permission_classes = [AllowAny]

9. View-level Permissions

View-level permission mhanje specific API view sathi permission class define karne.

Example

from rest_framework.views import APIView
from rest_framework.permissions import IsAdminUser
from rest_framework.response import Response

class AdminDashboardAPIView(APIView):

    permission_classes = [IsAdminUser]

    def get(self, request):
        return Response({
            "message": "Admin Dashboard"
        })

Ya view la access karanyasathi user cha is_staff attribute True asne avashyak aahe.

10. Object-level Permissions

Object-level permission specific database object access karanyachi permission check karte.

Example

Student la fakt swatachi profile edit karta yavi ani dusrya student chi profile edit karta yeu naye.

Custom Permission Example

File: api/permissions.py

from rest_framework.permissions import BasePermission

class IsOwnerOrReadOnly(BasePermission):

    def has_object_permission(self, request, view, obj):

        if request.method in ["GET", "HEAD", "OPTIONS"]:
            return True

        return obj.owner == request.user

How it works?

  • GET request sarva allowed users sathi available aahe.
  • Read-only methods la permission milte.
  • Write request madhye object cha owner check hoto.
  • Fakt owner la object modify karta yeto.
Note: Ya example madhye Student model madhye owner field asne avashyak aahe. Tasech object-level permission check honyasathi view madhun object retrieve zala pahije.

11. Custom Permission Class

DRF madhye aaplya application chya requirement nusar custom permission class create karta yete.

Example – Only Staff Users

from rest_framework.permissions import BasePermission

class OnlyStaffUser(BasePermission):

    def has_permission(self, request, view):

        return (
            request.user
            and request.user.is_authenticated
            and request.user.is_staff
        )

Use Custom Permission

from rest_framework.views import APIView
from rest_framework.response import Response

from .permissions import OnlyStaffUser

class StaffAPIView(APIView):

    permission_classes = [OnlyStaffUser]

    def get(self, request):
        return Response({
            "message": "Staff access granted"
        })

Important Methods

Method Purpose
has_permission() View-level access check karte.
has_object_permission() Specific object cha access check karte.

12. Practical – Admin-only Student API

Ata aapan Student API fakt staff users sathi available karuya.

Step 1 – Imports

File: api/views.py

from rest_framework.viewsets import ModelViewSet
from rest_framework.permissions import IsAdminUser

from .models import Student
from .serializers import StudentSerializer

Step 2 – Create ViewSet

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    permission_classes = [IsAdminUser]

Step 3 – Register Router

File: api/urls.py

from rest_framework.routers import DefaultRouter
from .views import StudentViewSet

router = DefaultRouter()

router.register(
    "students",
    StudentViewSet,
    basename="student"
)

urlpatterns = router.urls

Step 4 – Run Server

python manage.py runserver

Step 5 – Test API

http://127.0.0.1:8000/api/students/
  • Staff user – API access allowed.
  • Normal user – API access denied.
  • Unauthenticated user – API access denied.
Important: IsAdminUser authentication perform karat nahi. API access sathi authentication class suddha configure asne avashyak aahe. Udaharanarth BasicAuthentication, SessionAuthentication kiwa TokenAuthentication.

13. Important Points to Remember

  • Permissions API access control kartat.
  • AllowAny sarva users na access dete.
  • IsAuthenticated fakt authenticated users na access dete.
  • IsAdminUser is_staff=True users na access dete.
  • IsAuthenticatedOrReadOnly unauthenticated users na read-only access dete.
  • Global permissions settings.py madhye define karta yetat.
  • View-level permissions specific view sathi astat.
  • Object-level permissions specific object protect kartat.
  • Custom permissions BasePermission inherit karun create karta yetat.
