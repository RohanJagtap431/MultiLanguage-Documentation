DJANGO REST FRAMEWORK

09. Serializers in DRF

Serializers mhanje kay, data JSON madhye convert kasa hoto ani API madhye data validate kasa hoto te shikuya.

1. What is a Serializer?

Serializer ha Django REST Framework madhil ek important component aahe. To Python objects ani complex data la API sathi suitable format madhye convert karto.

Definition

A Serializer converts complex data such as Django model instances into Python native data types that can be easily converted into JSON.

Simple Example

Samaj aaplyakade Python madhye Student object aahe. API madhun ha data JSON format madhye pathavaycha aahe. 

student = {
    "id": 1,
    "name": "Rohan",
    "course": "BSc CS"
}

Serializer ya data la API response sathi suitable format madhye convert karayla madat karto.

2. Why do we use Serializers?

DRF madhye Serializers cha use mainly khalil kamansathi hoto.

  • Python objects cha data API response madhye convert karne.
  • Incoming API data validate karne.
  • JSON data process karanyasathi madat karne.
  • Data fields define karne.
  • Data create ani update karanyasathi madat karne.
Remember: Serializer fakt JSON conversion sathi nahi. To incoming data validation ani deserialization sathi suddha use hoto.

3. Serialization

Serialization mhanje complex Python data la simple Python native data types madhye convert karne. Ha data nantar JSON sarkhya format madhye render karta yeto.

Definition

Serialization is the process of converting complex data into Python native data types suitable for rendering.

Example

Aaplyakade Student data aahe. 

student = {
    "id": 1,
    "name": "Rohan",
    "course": "BSc CS"
}

Serializer vaprun ha data process karu. 

from rest_framework import serializers

class StudentSerializer(serializers.Serializer):

    id = serializers.IntegerField()
    name = serializers.CharField()
    course = serializers.CharField()

Ata serializer la Student data pass karu. 

serializer = StudentSerializer(student)

print(serializer.data)

Output

{
    'id': 1,
    'name': 'Rohan',
    'course': 'BSc CS'
}

serializer.data madhun serialized Python data milto.

4. Deserialization

Deserialization mhanje client kadun aalela data process karun Python native data madhye convert karne. Ya process madhye data validation suddha karta yete.

Definition

Deserialization is the process of converting incoming data into Python native data types after validation.

Example

Samaj client ne API la ha data pathavla. 

{
    "name": "Rohan",
    "course": "BSc CS"
}

Ha data serializer madhye pass karu. 

serializer = StudentSerializer(data={
    "id": 1,
    "name": "Rohan",
    "course": "BSc CS"
})

if serializer.is_valid():
    print(serializer.validated_data)

Output

{
    'id': 1,
    'name': 'Rohan',
    'course': 'BSc CS'
}

is_valid() data valid aahe ka te check karto. Valid data validated_data madhun milto.

5. Serializer Fields

Serializer madhye fields define kele jatat. Pratyek field specific type cha data accept karto.

Common Serializer Fields

Field Purpose
CharField Text data
IntegerField Integer numbers
FloatField Decimal numbers
BooleanField True or False
EmailField Email address
DateField Date values
DateTimeField Date and time
ChoiceField Fixed choices madhun value

Example

from rest_framework import serializers

class StudentSerializer(serializers.Serializer):

    name = serializers.CharField()
    age = serializers.IntegerField()
    email = serializers.EmailField()
    is_active = serializers.BooleanField()

Ithe pratyek field la specific data type dilela aahe.

6. Required and Optional Fields

Serializer madhye kahi fields required astat, tar kahi optional thevta yetat.

Required Field

name = serializers.CharField()

Default ne required field chi value dene garjeche aste.

Optional Field

age = serializers.IntegerField(required=False)

required=False mule age field request madhye nasla tari validation fail hot nahi.

Allow Blank

name = serializers.CharField(
    allow_blank=True
)

allow_blank=True mule empty string value accept karta yete.

7. Data Validation

API la client kadun data milalyanantar to valid aahe ka he check karne garjeche aste. Ya process la Validation mhantat.

Definition

Validation is the process of checking whether incoming data follows the required rules.

Example

from rest_framework import serializers

class StudentSerializer(serializers.Serializer):

    name = serializers.CharField()
    age = serializers.IntegerField()

    def validate_age(self, value):

        if value < 18:
            raise serializers.ValidationError(
                "Age must be 18 or above."
            )

        return value

Validation Explanation

  • validate_age(): Age field validate karto.
  • value: User ne pathavleli age.
  • ValidationError: Invalid data aslyas error raise karto.
  • return value: Valid value return karto.
Remember: Field-level validation method che nav validate_fieldname() ya format madhye aste.

8. is_valid() Method

is_valid() method serializer madhil incoming data valid aahe ki nahi he check karte.

Example

serializer = StudentSerializer(data={
    "name": "Rohan",
    "age": 20
})

if serializer.is_valid():
    print("Valid Data")
else:
    print(serializer.errors)

Possible Output

Valid Data

Data valid nasel tar serializer.errors madhye validation errors miltat.

Invalid Data Example

serializer = StudentSerializer(data={
    "name": "Rohan",
    "age": 15
})

if serializer.is_valid():
    print("Valid Data")
else:
    print(serializer.errors)

Possible Output

{
    'age': ['Age must be 18 or above.']
}

9. validated_data and errors

Serializer validation successful zalyanantar validated_data madhun cleaned data milto. 

if serializer.is_valid():
    print(serializer.validated_data)

Validation fail zalyas errors madhun problem samajto. 

if not serializer.is_valid():
    print(serializer.errors)
Property Purpose
serializer.data Serialized output data
serializer.validated_data Validated incoming data
serializer.errors Validation errors
serializer.is_valid() Data validation check

10. Complete Student Serializer

Ata aapan shiklelya concepts cha use karun complete Student Serializer banavu.

File: api/serializers.py

from rest_framework import serializers

class StudentSerializer(serializers.Serializer):

    name = serializers.CharField(max_length=100)

    age = serializers.IntegerField()

    course = serializers.CharField(max_length=100)

    email = serializers.EmailField()

    def validate_age(self, value):

        if value < 18:
            raise serializers.ValidationError(
                "Age must be 18 or above."
            )

        return value

11. Serialization vs Deserialization

Serialization Deserialization
Complex data to Python native data Incoming data to Python native data
Data response sathi prepare hoto Data input sathi process hoto
serializer = StudentSerializer(student) StudentSerializer(data=request.data)
serializer.data serializer.is_valid()

13. Interview Questions

Q1. What is a Serializer in DRF?

A Serializer converts complex data into Python native data types and helps validate incoming data.

Q2. What is Serialization?

Serialization converts complex data into Python native data types suitable for rendering.

Q3. What is Deserialization?

Deserialization processes incoming data into Python native data types after validation.

Q4. What is is_valid()?

is_valid() checks whether incoming data follows the serializer's validation rules.

Q5. What is validated_data?

validated_data contains the incoming data after successful validation.

Q6. What is serializer.errors?

It contains the errors generated when serializer validation fails.
