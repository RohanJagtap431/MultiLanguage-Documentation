05. HTTP Methods

GET, POST, PUT, PATCH ani DELETE ya HTTP Methods cha use simple Roman Marathi madhye samjun ghya.

1. What are HTTP Methods?

HTTP Methods mhanje client server la konti action karaychi aahe he sangnyache methods aahet.

REST API madhye HTTP Methods cha use data read, create, update ani delete karanyasathi hoto.

Definition

HTTP Methods define the action that a client wants to perform on a server resource.

Example

Samaj aaplyakade Student Management API aahe. Aaplyala students var vegveglya actions perform karaychya aahet.

  • Students chi list baghaychi.
  • New student add karaycha.
  • Student chi information update karaychi.
  • Student delete karaycha.

Ya actions sathi aapan HTTP Methods vaparto.

2. Types of HTTP Methods

Method Purpose
GET Data read karne
POST New data create karne
PUT Complete resource replace/update karne
PATCH Resource madhil specific data update karne
DELETE Data delete karne

3. GET Method

GET method cha use server kadun data retrieve kiwa read karanyasathi hoto.

Definition

GET is an HTTP method used to retrieve data from a server.

Example

Aaplyala students chi complete list havi aahe.

GET /api/students/

Single Student Example

Aaplyala ID 1 aslelya student chi information havi aahe. 

GET /api/students/1/

Server Response

{
    "id": 1,
    "name": "Rahul",
    "course": "BSc Computer Science"
}
Remember: GET cha use data read karanyasathi hoto. GET request cha purpose server var data create kiwa update karne nahi.

4. POST Method

POST method cha use server var navin resource create karanyasathi hoto.

Definition

POST is an HTTP method used to submit data to a server, commonly to create a new resource.

Example

Aaplyala navin student add karaycha aahe. 

POST /api/students/

Request Body

Client server la navin student cha data pathavto. 

{
    "name": "Rohan",
    "course": "BSc Computer Science"
}

Server Response

{
    "id": 3,
    "name": "Rohan",
    "course": "BSc Computer Science"
}

Server ne navin student create kela ani tyachi information response madhye return keli.

Remember: POST cha use navin data create karanyasathi hoto.

5. PUT Method

PUT method cha use existing resource replace karanyasathi hoto.

PUT request madhye resource chi complete representation pathavli jate.

Definition

PUT is an HTTP method used to replace an existing resource with the supplied data.

Existing Student Data

{
    "name": "Rahul",
    "course": "BCA",
    "city": "Pune"
}

API Request

PUT /api/students/1/

Request Body

{
    "name": "Rohan",
    "course": "BSc Computer Science",
    "city": "Kolhapur"
}

Ya request madhye resource chi complete information navin values ne replace keli jate.

Remember: PUT madhye complete resource representation pathavli jate. Required fields missing aslyas API validation error deu shakte.

6. PATCH Method

PATCH method cha use existing resource madhil specific fields update karanyasathi hoto.

Definition

PATCH is an HTTP method used to make partial updates to an existing resource.

Existing Student Data

{
    "name": "Rahul",
    "course": "BCA",
    "city": "Pune"
}

API Request

PATCH /api/students/1/

Request Body

Aaplyala fakt student cha city change karaycha aahe. 

{
    "city": "Kolhapur"
}

Updated Student Data

{
    "name": "Rahul",
    "course": "BCA",
    "city": "Kolhapur"
}

Ithe fakt city update zala. Name ani course same rahile.

Remember: PATCH cha use specific fields update karanyasathi hoto.

7. DELETE Method

DELETE method cha use server varil existing resource delete karanyasathi hoto.

Definition

DELETE is an HTTP method used to remove a resource from the server.

Example

Aaplyala ID 1 aslela student delete karaycha aahe. 

DELETE /api/students/1/

Possible Server Response

204 No Content

204 No Content mhanje request successful zali, pan response body madhye data nahi.

Remember: DELETE cha use existing resource delete karanyasathi hoto.

8. Difference Between PUT and PATCH

PUT ani PATCH donhi update sathi vapartat. Pan tyanchya working madhye difference aahe.

PUT PATCH
Complete resource replace karto Partial update karto
Complete representation pathavtat Fakt change honari fields pathavtat
Multiple fields update karu shakto Specific fields update karu shakto
PUT request generally idempotent aahe PATCH idempotent aselach ase nahi

Simple Example

PUT: Student chi complete information pathavane.

PATCH: Student cha fakt city change karane.

9. What is Idempotency?

Idempotency mhanje same request ekda kiwa anek vela pathavli tari server varil final result same rahane.

Definition

An HTTP method is idempotent if making the same request multiple times has the same intended effect as making it once.

Example

Samaj tu PUT request pathavun student cha city Kolhapur set kelas.

Tech PUT request punha pathavli tari city Kolhapur ch rahil.

HTTP Method Idempotent?
GET Yes
POST Generally No
PUT Yes
PATCH Not necessarily
DELETE Yes

Idempotency cha arth response pratyek veli same asel asa nahi. Arth server varil intended effect same asto.

10. HTTP Methods in Real Projects

Samaj tu Student Management REST API banavtoy. Tar API endpoints ase asu shaktat:

Method Endpoint Action

GET /api/students/1/ Single student
POST /api/students/ Create student
PUT /api/students/1/ Replace student
PATCH /api/students/1/ Partial update
DELETE /api/students/1/ Delete student

12. Interview Questions

Q1. What is GET method?

GET is an HTTP method used to retrieve data from a server.

Q2. What is POST method?

POST is an HTTP method commonly used to create a new resource on the server.

Q3. What is the difference between PUT and PATCH?

PUT replaces a complete resource, whereas PATCH updates only specific fields of a resource.

Q4. What is DELETE method?

DELETE is an HTTP method used to remove a resource from the server.

Q5. What is Idempotency?

Idempotency means repeated identical requests have the same intended effect as a single request.
