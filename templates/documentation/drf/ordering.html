29. Ordering in DRF

Learn how to sort API records in ascending and descending order.

1. What is Ordering?

Ordering mhanje database madhil records specific field nusar sequence madhye arrange karne.

Definition

Ordering is the process of arranging records in a specific sequence, such as ascending or descending order.

Example

Samja Student database madhye students chi list aahe. Aaplyala students age nusar arrange karayche aahet.

Before Ordering

Rohan - 22
Amit  - 18
Rahul - 20

After Ordering by Age

Amit  - 18
Rahul - 20
Rohan - 22

2. Types of Ordering

DRF madhye aapan mainly don types of ordering use karto.

Type Meaning Example
Ascending Small to large / A to Z age
Descending Large to small / Z to A -age

Ascending Order

Ascending order madhye records small to large kiwa A to Z sequence madhye arrange hotat. 

18, 20, 22, 25, 30

Descending Order

Descending order madhye records large to small kiwa Z to A sequence madhye arrange hotat. 

30, 25, 22, 20, 18

3. What is OrderingFilter?

OrderingFilter ha Django REST Framework madhil built-in filter backend aahe. To API records specific field nusar sort karto.

Definition

OrderingFilter allows API clients to sort queryset results using URL query parameters.

Import OrderingFilter

from rest_framework.filters import OrderingFilter

OrderingFilter vaparnyasathi separate package install karanyachi garaj nahi.

4. What is ordering_fields?

ordering_fields madhye kontya model fields nusar records sort karayche aahet te define kele jate.

Example

File: api/views.py

from rest_framework.viewsets import ModelViewSet
from rest_framework.filters import OrderingFilter

from .models import Student
from .serializers import StudentSerializer


class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [OrderingFilter]

    ordering_fields = ['name', 'age']

Ya example madhye API name ani age ya fields nusar records sort karu shakte.

5. Ascending Ordering

Ascending ordering madhye records small to large kiwa alphabetical order madhye arrange hotat.

API Request

/api/students/?ordering=age

Ya request madhye students age chya ascending order madhye return hotil.

Another Example

/api/students/?ordering=name

Ya request madhye students name chya A to Z order madhye arrange hotil.

6. Descending Ordering

Descending ordering madhye field name chya pudhe minus (-) symbol vapartat.

API Request

/api/students/?ordering=-age

Ya request madhye students age chya descending order madhye return hotil.

Another Example

/api/students/?ordering=-name

Ya request madhye names Z to A order madhye arrange hotil.

Remember: Minus (-) symbol nasel tar ascending order. Minus (-) symbol asel tar descending order.

7. Multiple Field Ordering

Ekach API request madhye multiple fields nusar records sort karta yetat.

Example

ordering_fields = ['name', 'age']

API Request

/api/students/?ordering=name,-age

Ya request madhye:

  • First name ascending order madhye arrange hoil.
  • Same name aslele records age descending order madhye arrange hotil.
Important: Multiple ordering fields comma (,) vaprun separate kele jatat. Pahilya field la priority aste.

8. Default Ordering

User ne URL madhye ordering parameter pass kela nahi, tar default ordering vaparta yete.

Example

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [OrderingFilter]

    ordering_fields = ['name', 'age']

    ordering = ['name']

Ya example madhye user ne ordering parameter pass kela nahi tar students name nusar ascending order madhye return hotil.

Default Descending Ordering

ordering = ['-age']

Ata default ordering age descending order madhye hoil.

9. Global Ordering Configuration

DRF settings madhye global default ordering backend configure karta yeto.

File: config/settings.py

REST_FRAMEWORK = {

    'DEFAULT_FILTER_BACKENDS': [
        'rest_framework.filters.OrderingFilter',
    ],

}

Ya configuration mule OrderingFilter globally enable hoil. Specific views madhye allowed ordering fields ani default ordering define karu shakto.

10. Search + Filter + Ordering Together

DRF madhye Filtering, Searching ani Ordering ekatra use karta yetat.

Example

from rest_framework.viewsets import ModelViewSet
from rest_framework.filters import SearchFilter, OrderingFilter
from django_filters.rest_framework import DjangoFilterBackend

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [
        DjangoFilterBackend,
        SearchFilter,
        OrderingFilter
    ]

    filterset_fields = ['course']

    search_fields = ['name', 'email']

    ordering_fields = ['name', 'age']

    ordering = ['name']

API Request

/api/students/?course=ComputerScience&search=Rohan&ordering=-age

Ya request madhye:

  • course nusar filtering hoil.
  • name ani email madhye Rohan search hoil.
  • Matching records age descending order madhye arrange hotil.

11. Practical Student API Ordering

Ata aapan Student API madhye complete ordering functionality implement karuya.

Step 1 – Update views.py

from rest_framework.viewsets import ModelViewSet
from rest_framework.filters import OrderingFilter

from .models import Student
from .serializers import StudentSerializer


class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [OrderingFilter]

    ordering_fields = [
        'name',
        'age',
        'course'
    ]

    ordering = ['name']

Step 2 – Run Server

python manage.py runserver

Step 3 – Test API

# Name ascending
/api/students/?ordering=name

# Age ascending
/api/students/?ordering=age

# Age descending
/api/students/?ordering=-age

# Multiple fields
/api/students/?ordering=name,-age

Ata Student API madhye name, age ani course ya fields nusar records sort karta yetil.

Note: Ha example Student model madhye name, age ani course fields available aahet ase gruhit dharto. Tumchya actual model madhil field names vapra.

12. Important Points to Remember

  • Ordering records specific sequence madhye arrange karte.
  • OrderingFilter DRF madhye built-in available aahe.
  • ordering_fields allowed fields define karte.
  • ordering parameter URL madhun pass karto.
  • Ascending order sathi minus (-) vaprat nahi.
  • Descending order sathi minus (-) vapartat.
  • Multiple fields comma (,) vaprun pass karta yetat.
  • Default ordering sathi ordering attribute vapartat.
  • Search, Filtering ani Ordering ekatra use karta yetat.

14. Interview Questions

Q1. What is OrderingFilter?

OrderingFilter is a built-in DRF backend used to sort queryset records.

Q2. What is ordering_fields?

It defines which fields are allowed for ordering.

Q3. How do you perform descending ordering?

We use a minus (-) symbol before the field name. Example: ordering=-age

Q4. How do you perform multiple field ordering?

We pass multiple field names separated by commas.

Q5. What is Default Ordering?

Default Ordering defines the sorting sequence when the client does not provide an ordering parameter.

Q6. Can we use SearchFilter and OrderingFilter together?

Yes. Both filter backends can be configured in the same ViewSet.
