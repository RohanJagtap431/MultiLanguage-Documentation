11. Serialization and Deserialization in Practice

API madhye data receive karne, validate karne, database madhye save karne ani response return karne he practical example madhun shikuya.

1. Serialization and Deserialization

DRF madhye Serialization ani Deserialization ya don important processes aahet.

Serialization

Serialization is the process of converting complex data, such as model instances, into Python native data types for API responses.

Deserialization

Deserialization is the process of processing incoming data into Python native data types after validation.

Simple Workflow

Client JSON data pathavto
↓
Deserialization Data process ani validate hoto
↓
Database Valid data save hoto
↓
Serialization Model data response sathi convert hoto
↓
API Response

2. What is request.data?

Client jevha POST request madhun JSON data pathavto, tevha DRF madhye request.data vaprun incoming data access karta yeto.

Definition

request.data is used to access the parsed incoming data sent by the client in an API request.

Example Request Body

{
    "name": "Rohan",
    "age": 20,
    "course": "BSc CS",
    "email": "rohan@example.com"
}

Access Data in View

data = request.data

print(data)

Ithe client ne pathavlela parsed data request.data madhun milto.

3. What is serializer.is_valid()?

Client kadun aalela data database madhye save karanyapurvi validate karne garjeche aahe.

Definition

is_valid() checks whether the incoming data follows the serializer's field and validation rules.

Example

serializer = StudentSerializer(
    data=request.data
)

if serializer.is_valid():
    print("Valid Data")
else:
    print(serializer.errors)

Explanation

  • StudentSerializer: Student data validate karto.
  • data=request.data: Client cha data serializer la deto.
  • is_valid(): Data valid aahe ka check karto.
  • serializer.errors: Validation errors return karto.

4. What is validated_data?

is_valid() successful zalyanantar validated_data madhye validated incoming data available hoto.

Definition

validated_data contains the incoming data after successful serializer validation.

Example

if serializer.is_valid():
    print(serializer.validated_data)

Possible Output

{
    'name': 'Rohan',
    'age': 20,
    'course': 'BSc CS',
    'email': 'rohan@example.com'
}

Ha data validation rules pass zalyanantar validated_data madhye milto.

5. What is serializer.save()?

serializer.save() cha use validated data database madhye save karanyasathi hoto.

Definition

serializer.save() creates a new model instance or updates an existing instance using validated data.

Example

if serializer.is_valid():
    student = serializer.save()

Important Points

  • save() call karanyapurvi is_valid() successful asne garjeche aahe.
  • New object asel tar ModelSerializer cha create() method use hoto.
  • Existing object asel tar update() method use hoto.
  • save() nantar created kiwa updated model instance return karto.
Remember: ModelSerializer madhye default create() ani update() methods available astat. Custom behavior sathi aapan he methods override karu shakto.

6. What is serializer.errors?

Client ne invalid data pathavla tar serializer errors madhye validation errors store karto.

Example

if not serializer.is_valid():
    print(serializer.errors)

Possible Output

{
    "name": [
        "This field is required."
    ],
    "email": [
        "Enter a valid email address."
    ]
}

Ithe name field missing aahe ani email format invalid aahe.

7. Create POST API

Ata aapan Student create karanyasathi complete POST API banavu.

File: api/views.py

Code

from rest_framework.decorators import api_view
from rest_framework.response import Response
from rest_framework import status

from .serializers import StudentSerializer

@api_view(['POST'])
def create_student(request):

    serializer = StudentSerializer(
        data=request.data
    )

    if serializer.is_valid():

        student = serializer.save()

        return Response(
            StudentSerializer(student).data,
            status=status.HTTP_201_CREATED
        )

    return Response(
        serializer.errors,
        status=status.HTTP_400_BAD_REQUEST
    )

Code Explanation

  • request.data: Client kadun incoming data gheto.
  • StudentSerializer: Data validate karto.
  • is_valid(): Data check karto.
  • serializer.save(): Student database madhye create karto.
  • StudentSerializer(student).data: Created student cha serialized response deto.
  • 201_CREATED: Resource successfully create zala he sangto.
  • 400_BAD_REQUEST: Invalid data aslyas error return karto.

8. Configure POST API URL

Ata create_student view la URL sobat connect karu.

File: api/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path(
        'students/',
        views.student_list,
        name='student_list'
    ),

    path(
        'students/create/',
        views.create_student,
        name='create_student'
    ),
]

Ata POST API cha URL asa asel:

http://127.0.0.1:8000/api/students/create/
