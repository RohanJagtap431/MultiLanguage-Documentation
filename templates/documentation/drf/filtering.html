27. Filtering in DRF

Learn how to retrieve specific records from an API using filters and query parameters.

1. What is Filtering?

Filtering mhanje database madhun specific condition match honare records retrieve karne.

Definition

Filtering is the process of retrieving records that match specific conditions.

Example

Samja Student database madhye 500 students aahet. Aaplyala fakt Computer Science course madhil students pahije.

Without Filtering

API all available student records return karte.

With Filtering

API fakt Computer Science course madhil students return karte.

2. Why is Filtering Required?

  • Specific records search karanyasathi.
  • Unnecessary data retrieve karne talnyasathi.
  • Frontend madhye search ani filter features denyasathi.
  • Database records conditions nusar retrieve karanyasathi.

3. What are Query Parameters?

Query Parameters URL madhye question mark (?) nantar pass kele jatat. Tyanchya help ne API la filtering conditions pathavta yetat.

Example URL

/api/students/?course=ComputerScience

Ya URL madhye course ha query parameter aahe ani ComputerScience hi tyachi value aahe.

Multiple Query Parameters

/api/students/?course=ComputerScience&age=20

Multiple parameters pass karanyasathi ampersand (&) vapartat.

5. DjangoFilterBackend

DjangoFilterBackend ha DRF madhil filtering backend aahe. To query parameters vaprun queryset filter karto.

Definition

DjangoFilterBackend allows API clients to filter queryset results using URL query parameters.

Import

from django_filters.rest_framework import DjangoFilterBackend

Example

File: api/views.py

from rest_framework.viewsets import ModelViewSet
from django_filters.rest_framework import DjangoFilterBackend

from .models import Student
from .serializers import StudentSerializer

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [DjangoFilterBackend]

Fakt DjangoFilterBackend add kelyane kontya fields var filtering karaychi te automatically define hot nahi. Tyasathi filterset_fields vapartat.

6. filterset_fields

filterset_fields madhye kontya model fields var filtering allow karaychi te define kele jate.

Example

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [DjangoFilterBackend]

    filterset_fields = ['course', 'age']

Test API URLs

/api/students/?course=ComputerScience

/api/students/?age=20

/api/students/?course=ComputerScience&age=20

Explanation

  • course field var filtering karta yete.
  • age field var filtering karta yete.
  • Multiple fields ekach request madhye filter karta yetat.
  • Multiple conditions default ne AND logic vapartat.
Important: filterset_fields madhye dileli fields Student model madhye available asne avashyak aahe. Tumchya model madhye vegli field names astil tar ti vapra.

7. Exact Filtering

Exact filtering madhye field chi exact value match honare records retrieve kele jatat.

Example

filterset_fields = ['course']

API Request

/api/students/?course=ComputerScience

Ya request madhye course chi value ComputerScience aslele records return hotil.

8. Multiple Field Filtering

Ekach API request madhye multiple fields vaprun records filter karta yetat.

Example

filterset_fields = ['course', 'age']

API Request

/api/students/?course=ComputerScience&age=20

Ya request madhye course ComputerScience ani age 20 aslele students return hotil.

Note: Default filtering madhye multiple conditions AND logic ne combine hotat. Donhi conditions match hone avashyak aahe.

9. Custom FilterSet Class

filterset_fields madhye basic filtering karta yete. Advanced filtering sathi custom FilterSet class create karu shakto.

Step 1 – Create filters.py

File: api/filters.py

import django_filters

from .models import Student

class StudentFilter(django_filters.FilterSet):

    age = django_filters.NumberFilter(
        field_name='age',
        lookup_expr='exact'
    )

    class Meta:
        model = Student
        fields = ['course', 'age']

Step 2 – Apply FilterSet

File: api/views.py

from rest_framework.viewsets import ModelViewSet
from django_filters.rest_framework import DjangoFilterBackend

from .models import Student
from .serializers import StudentSerializer
from .filters import StudentFilter

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [DjangoFilterBackend]
    filterset_class = StudentFilter

Explanation

  • StudentFilter custom filtering rules define karte.
  • NumberFilter numeric field filter karanyasathi vapartat.
  • field_name model madhil field select karte.
  • lookup_expr filtering operation define karte.

10. Lookup Expressions

Lookup expressions mule exact match, greater than, less than kiwa range sarkhe filters create karta yetat.

Lookup Purpose
exact Exact value match karte.
iexact Case-insensitive exact match.
contains Text madhye value search karte.
icontains Case-insensitive text search.
gt Greater than.
gte Greater than or equal to.
lt Less than.
lte Less than or equal to.

Example – Greater Than

age = django_filters.NumberFilter(
    field_name='age',
    lookup_expr='gt'
)

API Request

/api/students/?age=18

Ya example madhye age 18 peksha jast aslele students return hotil.

Example – Contains

name = django_filters.CharFilter(
    field_name='name',
    lookup_expr='icontains'
)
/api/students/?name=rah

Name madhye rah text aslele matching records case-insensitive padhatine return hotil.

11. Range Filtering

Range filtering madhye don values madhil records retrieve karta yetat.

Example – Age Range

File: api/filters.py

import django_filters

from .models import Student

class StudentFilter(django_filters.FilterSet):

    min_age = django_filters.NumberFilter(
        field_name='age',
        lookup_expr='gte'
    )

    max_age = django_filters.NumberFilter(
        field_name='age',
        lookup_expr='lte'
    )

    class Meta:
        model = Student
        fields = ['course']

API Request

/api/students/?min_age=18&max_age=25

Ya request madhye age 18 te 25 ya range madhil records return hotil.

12. Practical Student API Filtering

Ata aapan Student API madhye filtering implement karuya.

Step 1 – Create filters.py

import django_filters

from .models import Student

class StudentFilter(django_filters.FilterSet):

    name = django_filters.CharFilter(
        field_name='name',
        lookup_expr='icontains'
    )

    min_age = django_filters.NumberFilter(
        field_name='age',
        lookup_expr='gte'
    )

    max_age = django_filters.NumberFilter(
        field_name='age',
        lookup_expr='lte'
    )

    class Meta:
        model = Student
        fields = ['course']

Step 2 – Update views.py

from rest_framework.viewsets import ModelViewSet
from django_filters.rest_framework import DjangoFilterBackend

from .models import Student
from .serializers import StudentSerializer
from .filters import StudentFilter

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [DjangoFilterBackend]
    filterset_class = StudentFilter

Step 3 – Register Router

File: api/urls.py

from rest_framework.routers import DefaultRouter
from .views import StudentViewSet

router = DefaultRouter()

router.register(
    'students',
    StudentViewSet,
    basename='student'
)

urlpatterns = router.urls

Step 4 – Run Server

python manage.py runserver

Step 5 – Test API

/api/students/?course=ComputerScience&min_age=18&max_age=25
Important: Ya practical madhye Student model madhye name, age ani course fields asne avashyak aahe. Tumchya model madhye vegli fields astil tar tyapramane code change kara.
