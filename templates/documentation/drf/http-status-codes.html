06. HTTP Status Codes

HTTP Status Codes mhanje kay, tyache types ani API madhye tyacha use simple Roman Marathi madhye samjun ghya.

1. What are HTTP Status Codes?

HTTP Status Codes he server kadun client la milnare numerical codes aahet.

Client ne server la request pathavlyanantar server request cha result Status Code madhun sangto.

Definition

HTTP Status Codes are numerical codes sent by a server to indicate the result of an HTTP request.

Simple Example

Samaj tu Student Management API la request pathavli. Server ne students chi list successfully return keli. 

GET /api/students/

200 OK

Ithe 200 ha Status Code aahe. Yacha arth request successfully complete zali.

Remember: Status Code mule client la request successful zali ki error aala he samajta.

2. Types of HTTP Status Codes

HTTP Status Codes che 5 main categories aahet. Pratyek category specific type cha result represent karte.

Category Code Range Meaning
1xx 100–199 Informational
2xx 200–299 Success
3xx 300–399 Redirection
4xx 400–499 Client Error
5xx 500–599 Server Error

Simple Explanation

  • 1xx: Request process hot aahe.
  • 2xx: Request successful zali.
  • 3xx: Redirect karanyachi garaj aahe.
  • 4xx: Client request madhye problem aahe.
  • 5xx: Server request process kartana fail zala.

3. 200 OK

200 OK cha arth request successfully complete zali.

Meaning

200 OK indicates that the request was successful.

Example

Aaplyala students chi list retrieve karaychi aahe. 

GET /api/students/

200 OK

Response

[
    {
        "id": 1,
        "name": "Rahul"
    },
    {
        "id": 2,
        "name": "Amit"
    }
]

Server ne students chi list successfully return keli.

4. 201 Created

201 Created cha arth server var navin resource successfully create zala.

Meaning

201 Created indicates that a new resource has been successfully created.

Example

Aaplyala Student API madhye navin student add karaycha aahe. 

POST /api/students/

Request Body

{
    "name": "Rohan",
    "course": "BSc Computer Science"
}

Response

201 Created

{
    "id": 3,
    "name": "Rohan",
    "course": "BSc Computer Science"
}

Server ne navin student create kela.

5. 204 No Content

204 No Content cha arth request successfully complete zali, pan response body madhye kontahi data nahi.

Meaning

204 No Content indicates that the request was successful, but there is no response body.

Example

Aaplyala student delete karaycha aahe. 

DELETE /api/students/1/

204 No Content

Student successfully delete zala. Server ne response body return keli nahi.

Remember: 204 response madhye response body nasto.

6. 400 Bad Request

400 Bad Request cha arth client ne pathavlelya request madhye problem aahe.

Meaning

400 Bad Request indicates that the server cannot process the request because of a client-side request problem.

Example

Samaj student create kartana required name field pathavli nahi. 

POST /api/students/

Request Body

{
    "course": "BCA"
}

Possible Response

400 Bad Request

{
    "name": [
        "This field is required."
    ]
}

Required name field missing aslyamule request reject zali.

7. 401 Unauthorized

401 Unauthorized cha arth request la valid authentication credentials milale nahit.

Meaning

401 Unauthorized indicates that valid authentication credentials are missing or invalid.

Example

Samaj Student API madhil private data access karanyasathi login required aahe.

Pan client ne valid login token pathavla nahi. 

GET /api/profile/

401 Unauthorized

Server ne request reject keli karan valid authentication credentials available nahit.

8. 403 Forbidden

403 Forbidden cha arth server la request samajli, pan client la ti action perform karanyachi permission nahi.

Meaning

403 Forbidden indicates that the client does not have permission to access the resource.

Example

Samaj College Management API madhye fakt Admin la student delete karanyachi permission aahe.

Student user delete request pathavto. Tyachyakade required permission nahi. 

DELETE /api/students/1/

403 Forbidden
401 vs 403: 401 madhye valid authentication credentials nahit. 403 madhye request karanarya user la action chi permission nahi.

9. 404 Not Found

404 Not Found cha arth requested resource server var sapadla nahi.

Meaning

404 Not Found indicates that the requested resource could not be found.

Example

Samaj aaplyakade student ID 10 available nahi. Pan client ID 10 chi information magto. 

GET /api/students/10/

404 Not Found

Server la ID 10 cha student sapadla nahi.

10. 500 Internal Server Error

500 Internal Server Error cha arth server madhye unexpected problem aali ani request complete karta aali nahi.

Meaning

500 Internal Server Error indicates that the server encountered an unexpected condition while processing the request.

Example

Samaj Django backend madhye code error aala kiwa server madhil unexpected exception mule API request fail zali. 

GET /api/students/

500 Internal Server Error

Ashya veli developer ne server logs check karun error debug karava.

12. HTTP Status Codes in Django REST Framework

DRF madhye status codes use karanyasathi status module available aahe.

Example Code

from rest_framework.response import Response
from rest_framework import status

def student_view(request):

    return Response(
        {"message": "Student created"},
        status=status.HTTP_201_CREATED
    )

Code Explanation

  • Response: API response return karte.
  • status: HTTP Status Codes provide karto.
  • HTTP_201_CREATED: 201 status code represent karto.

Another Example

return Response(
    {"message": "Student not found"},
    status=status.HTTP_404_NOT_FOUND
)

Ya example madhye API 404 Not Found response return karte.

Remember: DRF madhye status.HTTP_200_OK, status.HTTP_201_CREATED ani status.HTTP_404_NOT_FOUND sarkhe constants vaparta yetat.

14. Interview Questions

Q1. What is HTTP Status Code?

HTTP Status Code is a numerical code sent by the server to indicate the result of a request.

Q2. What is the difference between 401 and 403?

401 means valid authentication credentials are missing or invalid, whereas 403 means access is forbidden due to insufficient permission.

Q3. What is 404 Not Found?

404 indicates that the requested resource could not be found on the server.

Q4. What is 500 Internal Server Error?

500 indicates that an unexpected server-side error occurred while processing the request.

Q5. Which status code indicates successful creation?

201 Created indicates that a new resource has been successfully created.
