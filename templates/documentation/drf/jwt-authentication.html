25. JWT Authentication in DRF

Learn how to secure APIs using JSON Web Tokens and Access and Refresh Tokens.

1. What is JWT Authentication?

JWT mhanje JSON Web Token. Ha ek token format aahe jo user authentication sathi vaparla jato.

Definition

JWT Authentication is a method of authenticating API requests using digitally signed JSON Web Tokens.

User login kartana server credentials verify karto. Tyानंतर server Access Token ani Refresh Token generate karto.

Uses of JWT

  • Secure API authentication.
  • Login-based applications.
  • Mobile application authentication.
  • Frontend ani backend madhil authentication.

2. How JWT Authentication Works

1. Login Request Client username ani password pathavto.
↓
2. Credential Verification Server credentials verify karto.
↓
3. JWT Generation Server Access ani Refresh Tokens return karto.
↓
4. API Request Client Access Token pathavto.
↓
5. Token Verification Server token verify karto.
↓
6. API Response Valid token asel tar access milto.

3. JWT Structure

JWT token madhye three main parts astat.

Part Purpose
Header Token type ani signing algorithm information.
Payload Claims, jase user ID ani expiry information.
Signature Token chi integrity verify karanyasathi.

JWT Format

header.payload.signature

He three parts dot (.) ne separate kele jatat.

Security: JWT payload normally encoded asto, encrypted aselach ase nahi. Mhanun password kiwa sensitive information payload madhye store karu naye.

4. Access Token and Refresh Token

Simple JWT madhye commonly don types che tokens miltat.

Access Token

Access Token protected API endpoints access karanyasathi vapartat.

Refresh Token

Refresh Token cha use navin Access Token milavnyasathi hoto.

Access Token Refresh Token
API access sathi. New Access Token milavnyasathi.
Short lifetime. Longer lifetime.
Every protected request madhye pathavtat. Refresh endpoint la pathavtat.

5. Install Simple JWT

Django REST Framework madhye JWT authentication implement karanyasathi Simple JWT package vapru shakto.

Installation Command

pip install djangorestframework-simplejwt

Ya package mule JWT login, token refresh ani token verification endpoints available hotat.

6. Configure JWT Authentication

Ata Django project chya settings.py madhye JWT authentication configure karuya.

File: config/settings.py

REST_FRAMEWORK = {

    'DEFAULT_AUTHENTICATION_CLASSES': [
        'rest_framework_simplejwt.authentication.JWTAuthentication',
    ],

    'DEFAULT_PERMISSION_CLASSES': [
        'rest_framework.permissions.IsAuthenticated',
    ],

}

Explanation

  • JWTAuthentication JWT token verify karte.
  • IsAuthenticated authenticated users na access dete.
  • Ya settings mule default DRF APIs protected hotat.
Important: Global IsAuthenticated mule public endpoints suddha protected hotat. Public login ani registration endpoints sathi AllowAny explicitly set kara.

7. Create JWT Login API

Simple JWT madhye TokenObtainPairView built-in available aahe. Ha username ani password verify karun Access ani Refresh Tokens return karto.

Step 1 – Import JWT Views

from rest_framework_simplejwt.views import (
    TokenObtainPairView,
    TokenRefreshView,
    TokenVerifyView
)

Step 2 – Configure URLs

File: api/urls.py

from django.urls import path, include
from rest_framework.routers import DefaultRouter

from rest_framework_simplejwt.views import (
    TokenObtainPairView,
    TokenRefreshView,
    TokenVerifyView
)

from .views import StudentViewSet

router = DefaultRouter()

router.register(
    'students',
    StudentViewSet,
    basename='student'
)

urlpatterns = [

    path(
        'token/',
        TokenObtainPairView.as_view(),
        name='token_obtain_pair'
    ),

    path(
        'token/refresh/',
        TokenRefreshView.as_view(),
        name='token_refresh'
    ),

    path(
        'token/verify/',
        TokenVerifyView.as_view(),
        name='token_verify'
    ),

    path('', include(router.urls)),
]

Step 3 – Project URLs

File: config/urls.py

from django.urls import path, include

urlpatterns = [
    path('api/', include('api.urls')),
]

8. JWT Login Request

Ata Postman madhun login endpoint la POST request pathavu.

Request Method

POST

Request URL

http://127.0.0.1:8000/api/token/

Request Body – JSON

{
    "username": "your_username",
    "password": "your_password"
}

Successful Response

{
    "refresh": "your_refresh_token",
    "access": "your_access_token"
}

Credentials valid astil tar donhi tokens return hotat.

9. Access Protected API Using JWT

Protected API access karanyasathi Access Token Authorization header madhye pathavava lagto.

Header Format

Authorization: Bearer your_access_token

Example Request

GET http://127.0.0.1:8000/api/students/

How it works?

  • Client Access Token pathavto.
  • JWTAuthentication token verify karte.
  • IsAuthenticated permission access check karte.
  • Valid token asel tar API response milto.

10. Refresh Access Token

Access Token expire zalyanantar Refresh Token vaprun navin Access Token milavta yeto.

Request Method

POST

Request URL

http://127.0.0.1:8000/api/token/refresh/

Request Body – JSON

{
    "refresh": "your_refresh_token"
}

Successful Response

{
    "access": "new_access_token"
}

Valid Refresh Token asel tar server navin Access Token return karto.

11. Verify JWT Token

TokenVerifyView vaprun JWT token valid aahe ka te check karta yete.

Request URL

POST http://127.0.0.1:8000/api/token/verify/

Request Body

{
    "token": "your_access_token"
}

Token valid asel tar success response milto. Invalid kiwa expired token asel tar error response milto.

12. Logout Using Token Blacklisting

JWT Access Token logout zalyavar automatically invalid hot nahi. Refresh Token blacklist karun tyacha pudhil use block karta yeto.

Step 1 – Add Blacklist App

File: config/settings.py

INSTALLED_APPS = [
    # Other apps
    'rest_framework',
    'rest_framework_simplejwt.token_blacklist',
]

Step 2 – Run Migrations

python manage.py migrate

Step 3 – Add Logout URL

File: api/urls.py

from rest_framework_simplejwt.views import TokenBlacklistView

urlpatterns = [
    path(
        'token/blacklist/',
        TokenBlacklistView.as_view(),
        name='token_blacklist'
    ),
]

Ha URL existing urlpatterns madhye add kara.

Step 4 – Logout Request

POST http://127.0.0.1:8000/api/token/blacklist/

Request Body

{
    "refresh": "your_refresh_token"
}

Successful blacklist nantar Refresh Token punha vaparta yenar nahi.

Important: Default logout blacklist mule Refresh Token revoke hoto. Existing Access Token tyachya expiry paryant valid rahu shakto. Immediate Access Token revocation sathi additional server-side strategy lagte.

13. Configure Token Lifetime

Simple JWT madhye Access ani Refresh Token chi lifetime configure karta yete.

File: config/settings.py

from datetime import timedelta

SIMPLE_JWT = {

    'ACCESS_TOKEN_LIFETIME': timedelta(minutes=15),

    'REFRESH_TOKEN_LIFETIME': timedelta(days=1),

}

Explanation

  • Access Token 15 minutes valid rahil.
  • Refresh Token 1 day valid rahil.
  • Expiry nantar token refresh kiwa login karava lagel.
Note: He example settings aahet. Actual production lifetime application chya security requirements nusar tharva.

14. Token Authentication vs JWT

Token Authentication JWT Authentication
Database madhye token store hoto. Signed JWT token use hoto.
Built-in DRF authtoken package. Simple JWT package commonly vapartat.
Default expiry support nahi. Token expiry configure karta yete.
Token lookup database madhun hoto. Signature ani claims verify kele jatat.
Simple token system. Access ani Refresh Token support.

16. Important Points to Remember

  • JWT means JSON Web Token.
  • JWT madhye Header, Payload ani Signature astat.
  • Access Token protected APIs access karte.
  • Refresh Token navin Access Token milavte.
  • Simple JWT package JWT authentication provide karte.
  • TokenObtainPairView login tokens generate karte.
  • TokenRefreshView Access Token refresh karte.
  • TokenVerifyView token verify karte.
  • TokenBlacklistView Refresh Token blacklist karte.
  • JWT payload madhye sensitive data thevu naye.

18. Interview Questions

Q1. What is JWT?

JWT stands for JSON Web Token. It is a digitally signed token format used for securely transmitting claims.

Q2. What are the three parts of JWT?

Header, Payload and Signature.

Q3. What is an Access Token?

An Access Token is used to access protected API endpoints.

Q4. What is a Refresh Token?

A Refresh Token is used to obtain a new Access Token.

Q5. What is Simple JWT?

Simple JWT is a package used to implement JWT authentication in Django REST Framework.

Q6. What is Token Blacklisting?

Token Blacklisting prevents a refresh token from being used again.

Q7. Does JWT payload contain encrypted data?

Not by default. A standard signed JWT payload is encoded, not encrypted.
