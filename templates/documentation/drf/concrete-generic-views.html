19. Concrete Generic Views in DRF

Learn how to use ready-made generic view classes to build REST APIs with less code.

1. What are Concrete Generic Views?

Concrete Generic Views ya DRF madhil ready-made view classes aahet. Ya classes GenericAPIView ani Mixins chi functionality combine kartat.

Definition

Concrete Generic Views are ready-made API view classes that combine GenericAPIView and Mixins to perform common API operations.

Why use Concrete Generic Views?

  • Code kami lihava lagto.
  • Common API operations ready-made miltat.
  • GET, POST, PUT, PATCH ani DELETE handle karne sope hote.
  • API code clean ani reusable rahto.
Important: Concrete Generic Views madhye common HTTP methods internally handle kele jatat. Aplyala pratyek method manually define karanyachi garaj naste.

2. Types of Concrete Generic Views

DRF madhye commonly use honarya Concrete Generic Views khalilpramane aahet.

View Class HTTP Methods Purpose

CreateAPIView POST New record create karne.
RetrieveAPIView GET Single record fetch karne.
UpdateAPIView PUT, PATCH Record update karne.
DestroyAPIView DELETE Record delete karne.

3. ListAPIView

ListAPIView cha use database madhil multiple records fetch karanyasathi hoto.

Definition

ListAPIView is used to retrieve a list of objects using a GET request.

Example

from rest_framework.generics import ListAPIView

class StudentListView(ListAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer
API Request 
GET /api/students/

Ya request mule database madhil sarva students fetch hotat.

4. CreateAPIView

CreateAPIView cha use database madhye navin record create karanyasathi hoto.

Definition

CreateAPIView is used to create a new object using a POST request.

Example

from rest_framework.generics import CreateAPIView

class StudentCreateView(CreateAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Request Body

{
    "name": "Rohan",
    "email": "rohan@example.com",
    "age": 20
}
API Request 
POST /api/students/create/

Valid data asel tar student create hoto ani HTTP 201 Created response milto.

5. RetrieveAPIView

RetrieveAPIView cha use ek specific record fetch karanyasathi hoto.

Definition

RetrieveAPIView is used to retrieve a single object using its lookup value.

Example

from rest_framework.generics import RetrieveAPIView

class StudentDetailView(RetrieveAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer
API Request 
GET /api/students/1/

Ithe primary key 1 aslela student fetch hoto. Record sapadla nahi tar HTTP 404 response milto.

6. UpdateAPIView

UpdateAPIView cha use existing record update karanyasathi hoto.

Definition

UpdateAPIView is used to update an existing object using PUT or PATCH requests.

Example

from rest_framework.generics import UpdateAPIView

class StudentUpdateView(UpdateAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Supported Methods

  • PUT: Complete object update karte.
  • PATCH: Specific fields update karte.
API Request 
PUT   /api/students/1/
PATCH /api/students/1/

7. DestroyAPIView

DestroyAPIView cha use database madhil existing record delete karanyasathi hoto.

Definition

DestroyAPIView is used to delete an existing object using a DELETE request.

Example

from rest_framework.generics import DestroyAPIView

class StudentDeleteView(DestroyAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer
API Request 
DELETE /api/students/1/

Successful delete nantar HTTP 204 No Content response milto.

8. ListCreateAPIView

ListCreateAPIView madhye GET ani POST donhi operations ekach view madhye handle hotat.

Definition

ListCreateAPIView is used to list multiple objects and create a new object.

Example

from rest_framework.generics import ListCreateAPIView

class StudentListCreateView(ListCreateAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Supported Methods

  • GET: All students fetch karne.
  • POST: New student create karne.
API Endpoint 
/api/students/

9. RetrieveUpdateAPIView

RetrieveUpdateAPIView ek specific object fetch ani update karanyasathi use hote.

Definition

RetrieveUpdateAPIView is used to retrieve and update a single object.

Example

from rest_framework.generics import RetrieveUpdateAPIView

class StudentRetrieveUpdateView(RetrieveUpdateAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Supported Methods

  • GET: Single student fetch karne.
  • PUT: Complete student update karne.
  • PATCH: Partial student update karne.
API Endpoint 
/api/students/1/

10. RetrieveDestroyAPIView

RetrieveDestroyAPIView ek specific object fetch ani delete karanyasathi use hote.

Definition

RetrieveDestroyAPIView is used to retrieve and delete a single object.

Example

from rest_framework.generics import RetrieveDestroyAPIView

class StudentRetrieveDeleteView(RetrieveDestroyAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Supported Methods

  • GET: Single student fetch karne.
  • DELETE: Student delete karne.
API Endpoint 
/api/students/1/

11. RetrieveUpdateDestroyAPIView

RetrieveUpdateDestroyAPIView ekach view madhye single object var GET, PUT, PATCH ani DELETE operations perform karte.

Definition

RetrieveUpdateDestroyAPIView is used to retrieve, update and delete a single object.

Example

from rest_framework.generics import (
    RetrieveUpdateDestroyAPIView
)

class StudentDetailView(RetrieveUpdateDestroyAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Supported Methods

  • GET: Student fetch karne.
  • PUT: Complete data update karne.
  • PATCH: Partial data update karne.
  • DELETE: Student delete karne.
API Endpoint 
/api/students/1/

12. Practical Student CRUD API

Ata aapan fakt don Concrete Generic Views vaprun complete Student CRUD API create karuya.

Step 1 – Model

Student model Topic 15 madhye create kela asel tar toch model use kara. 

# api/models.py

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)
    email = models.EmailField(unique=True)
    age = models.PositiveIntegerField()

    def __str__(self):
        return self.name

Step 2 – Serializer

# api/serializers.py

from rest_framework import serializers
from .models import Student

class StudentSerializer(serializers.ModelSerializer):

    class Meta:
        model = Student
        fields = '__all__'

Step 3 – Views

File: api/views.py

from rest_framework.generics import (
    ListCreateAPIView,
    RetrieveUpdateDestroyAPIView
)

from .models import Student
from .serializers import StudentSerializer


class StudentListCreateView(ListCreateAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer


class StudentDetailView(RetrieveUpdateDestroyAPIView):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Step 4 – URLs

File: api/urls.py

from django.urls import path

from .views import (
    StudentListCreateView,
    StudentDetailView
)

urlpatterns = [

    path(
        'students/',
        StudentListCreateView.as_view(),
        name='student_list'
    ),

    path(
        'students/<int:pk>/',
        StudentDetailView.as_view(),
        name='student_detail'
    ),

]

Step 5 – Main URLs

File: config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('api/', include('api.urls')),
]
Important: Existing Student model ani serializer already astil tar punha create karu naka. Existing URL patterns sobat duplicate routes add karu naka.

14. Generic Views vs Mixins vs Concrete Generic Views

GenericAPIView Mixins Concrete Generic Views
Base class Reusable operation classes Ready-made view classes
Provides queryset and serializer support. Provides methods such as list() and create(). Combines common functionality.
More manual code. Methods manually call karave lagtat. Very less code.
Custom API views. Flexible API operations. Common API operations quickly create karne.
