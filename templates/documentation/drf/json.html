04. JSON (JavaScript Object Notation)

JSON kay aahe, tyachi structure ani API madhye JSON cha use simple Roman Marathi madhye samjun ghya.

1. What is JSON?

JSON cha full form JavaScript Object Notation asa aahe.

JSON ha ek lightweight data format aahe. Tyacha use don applications madhye data exchange karanyasathi hoto.

Definition

JSON is a lightweight data format used to store and exchange data between applications.

Simple Example

Samaj tu Student Management API tayar keli aahe. Tula student chi information mobile application la pathvaychi aahe.

Server student cha data JSON format madhye return karu shakto. 

{
    "id": 1,
    "name": "Rahul",
    "course": "BSc Computer Science"
}

Ha JSON data aahe. Yat student chi ID, name ani course store kele aahe.

2. Why Do We Use JSON?

Aajkal web applications ani mobile applications ekmekansobat data exchange kartat.

JSON mule data simple ani structured format madhye pathavta ani receive karta yeto.

JSON che uses

  • Frontend ani Backend madhye data exchange
  • Mobile App ani Server madhye communication
  • REST API responses madhye data return karne
  • Structured data store karne
  • Different programming languages madhye data exchange
Remember: JSON ha data exchange format aahe. To programming language kiwa database nahi.

3. JSON Key-Value Pairs

JSON madhye data Key-Value Pair format madhye represent kela jato.

Key mhanje data cha name ani Value mhanje tya key madhye store kelela data.

Example

{
    "name": "Rohan",
    "age": 20,
    "course": "BSc Computer Science"
}

Ya example madhye:

  • name hi Key aahe.
  • "Rohan" hi Value aahe.
  • age hi Key aahe.
  • 20 hi Value aahe.
  • course hi Key aahe.
Important: JSON madhye keys double quotes madhye lihitat. Example: "name"

4. JSON Data Types

JSON madhye vegveglya prakarchya values store karta yetat. Tyanna JSON Data Types mhantat.

1. String

Text value store karanyasathi String vapartat. 

{
    "name": "Rohan"
}

2. Number

Integer kiwa decimal number store karanyasathi Number vapartat. 

{
    "age": 20,
    "percentage": 85.5
}

3. Boolean

True kiwa False value store karanyasathi Boolean vapartat. 

{
    "is_active": true,
    "is_completed": false
}

4. Array

Multiple values ekach variable madhye store karanyasathi Array vapartat. 

{
    "subjects": [
        "Python",
        "Django",
        "JavaScript"
    ]
}

5. Object

Related Key-Value Pairs ekatra store karanyasathi Object vapartat. 

{
    "student": {
        "name": "Rohan",
        "age": 20
    }
}

6. Null

Value available nasel kiwa empty value represent karaychi asel tar null vapartat. 

{
    "address": null
}
Data Type Example
String "Rohan"
Number 20
Boolean true / false
Array ["Python", "Django"]
Object {"name": "Rohan"}
Null null

5. What is JSON Object?

JSON Object ha curly brackets { } madhye lihila jato. Tyamadhye multiple Key-Value Pairs astat.

Example

{
    "id": 1,
    "name": "Amit",
    "age": 21,
    "course": "BCA"
}

Ya JSON Object madhye eka student chi complete information store keli aahe.

Remember: JSON Object sathi { } curly brackets vapartat.

6. What is JSON Array?

JSON Array ha square brackets [ ] madhye lihila jato. Tyamadhye multiple values kiwa objects store karta yetat.

Simple Array Example

[
    "Python",
    "Django",
    "JavaScript"
]

Array of Objects Example

[
    {
        "id": 1,
        "name": "Rahul"
    },
    {
        "id": 2,
        "name": "Amit"
    },
    {
        "id": 3,
        "name": "Rohan"
    }
]

Ya example madhye multiple students chi information ekach Array madhye store keli aahe.

Remember: JSON Array sathi [ ] square brackets vapartat.

7. JSON Syntax Rules

JSON lihitana kahi important rules follow karave lagtat.

  • JSON Object sathi { } vapartat.
  • JSON Array sathi [ ] vapartat.
  • Keys double quotes madhye lihitat.
  • String values double quotes madhye lihitat.
  • Key ani Value madhye colon (:) vapartat.
  • Multiple pairs madhye comma (,) vapartat.
  • Boolean values true kiwa false asatat.
  • Null value sathi null lihitat.
  • JSON madhye comments allowed nahit.
  • Last item nantar extra comma lihaycha nahi.

Correct JSON

{
    "name": "Rohan",
    "age": 20
}

Incorrect JSON

{
    name: "Rohan",
    "age": 20,
}

Incorrect example madhye name la double quotes nahi ani last value nantar extra comma aahe.

8. JSON in Django REST Framework

DRF madhye API response JSON format madhye return karta yeto.

Samaj aaplyakade Student model aahe. API madhun student information frontend la pathvaychi aahe.

Example JSON Response

{
    "id": 1,
    "name": "Rohan",
    "course": "BSc Computer Science",
    "is_active": true
}

DRF madhye Serializer model data la JSON-compatible format madhye convert karanyas madat karto.

Client kadun JSON data aala tar DRF tyala process karanyasathi suddha madat karto.

Remember: DRF madhye JSON data handle karanyasathi Serializer ani Parser sarkhe components vapartat. He aapan pudhil topics madhye shiku.

Q1. What is JSON?

JSON is a lightweight data format used to exchange data between applications.

Q2. What is a JSON Object?

A JSON Object is a collection of Key-Value Pairs enclosed within curly brackets.

Q3. What is a JSON Array?

A JSON Array is a collection of values or objects enclosed within square brackets.

Q4. Can JSON store different data types?

Yes. JSON supports String, Number, Boolean, Array, Object and Null data types.
