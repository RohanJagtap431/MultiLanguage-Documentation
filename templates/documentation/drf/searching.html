28. Searching in DRF

Learn how to search records in an API using SearchFilter and query parameters.

1. What is Searching?

Searching mhanje database madhil records madhun specific text kiwa keyword shodhun matching records retrieve karne.

Definition

Searching is the process of finding records that match a given search keyword.

Example

Samja Student database madhye 500 students aahet. Aaplyala Rohan navacha student shodhaycha aahe.

Search Request

/api/students/?search=Rohan

API madhye Rohan keyword match honare student records return hotil.

2. Filtering vs Searching

Filtering ani Searching donhi API madhun specific records retrieve karanyasathi vapartat. Pan tyanchya use madhye farak aahe.

Filtering Searching
Specific field value filter karte. Keyword match karun records shodhte.
Example: course=ComputerScience Example: search=Rohan
DjangoFilterBackend vapartat. SearchFilter vapartat.
Exact values kiwa lookup conditions vaparta yetat. Text-based search sathi upyogi aahe.

3. What is SearchFilter?

SearchFilter ha Django REST Framework madhil built-in filter backend aahe. To API madhye search functionality provide karto.

Definition

SearchFilter allows API clients to search records using a keyword passed through a query parameter.

Import SearchFilter

from rest_framework.filters import SearchFilter

SearchFilter vaparnyasathi django-filter package install karne avashyak nahi. SearchFilter DRF madhye built-in available aahe.

4. What is search_fields?

search_fields madhye kontya model fields madhye search karaycha aahe te define kele jate.

Example

File: api/views.py

from rest_framework.viewsets import ModelViewSet
from rest_framework.filters import SearchFilter

from .models import Student
from .serializers import StudentSerializer

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [SearchFilter]

    search_fields = ['name']

Ya example madhye API Student model chya name field madhye search karel.

API Request

/api/students/?search=Rohan

5. Single Field Search

Ekach model field madhye search karanyasathi search_fields madhye ek field define karu shakto.

Example

search_fields = ['name']

API Requests

/api/students/?search=Rohan

/api/students/?search=Rahul

/api/students/?search=Amit

Search keyword name field madhye match honare records return hotil.

6. Multiple Field Search

Ekach API madhye multiple fields var search karaycha asel tar search_fields madhye multiple fields define karu shakto.

Example

search_fields = [
    'name',
    'email',
    'course'
]

API Request

/api/students/?search=Rohan

/api/students/?search=computer

/api/students/?search=gmail

Ata API name, email ani course ya tinhi fields madhye search keyword check karel.

Important: search_fields madhye dilelya field names Student model madhye available asne avashyak aahe.

7. Case-Insensitive Search

DRF SearchFilter madhye default search case-insensitive aste. Mhanje uppercase ani lowercase letters madhil farak consider kela jat nahi.

Example

/api/students/?search=rohan

/api/students/?search=ROHAN

/api/students/?search=Rohan

Default SearchFilter configuration madhye ya keywords sathi case-insensitive matching hote.

8. Search Lookup Prefixes

search_fields madhye prefix vaprun search cha behaviour change karta yeto.

Prefix Lookup Meaning
^ istartswith Text chi suruvat keyword ne hote.
= iexact Case-insensitive exact match.
@ search Database full-text search.
$ iregex Case-insensitive regular expression.

Example – Starts With

search_fields = ['^name']

Ya configuration madhye name field chi suruvat search keyword ne honare records match hotil.

Example – Exact Match

search_fields = ['=email']

Ya configuration madhye email field cha case-insensitive exact match search hoto.

Note: @ prefix cha behaviour database backend var depend karto. To supported database madhye full-text search sathi vaparla jato.

9. Related Field Searching

DRF SearchFilter vaprun related model fields madhye suddha search karta yeto.

Related field access karanyasathi Django ORM madhil double underscore (__) notation vapartat.

Example

Samja Student model madhye department navacha ForeignKey field aahe ani Department model madhye name field aahe. 

search_fields = [
    'name',
    'department__name'
]

API Request

/api/students/?search=Computer

Ata Student cha name ani related Department cha name ya donhi fields madhye search hoil.

10. Search with Pagination

SearchFilter ani Pagination ekatra use karta yetat. Search result madhil records pages madhye divide karta yetat.

Example Configuration

from rest_framework.viewsets import ModelViewSet
from rest_framework.filters import SearchFilter
from rest_framework.pagination import PageNumberPagination

class StudentPagination(PageNumberPagination):
    page_size = 5


class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [SearchFilter]
    search_fields = ['name', 'course']

    pagination_class = StudentPagination

API Request

/api/students/?search=Rohan&page=1

/api/students/?search=Rohan&page=2

Ya example madhye search result madhun eka page var 5 records return hotil, jar tyapeksha jast matching records available astil.

11. Practical Student API Search

Ata aapan Student API madhye complete search functionality implement karuya.

Step 1 – Update views.py

from rest_framework.viewsets import ModelViewSet
from rest_framework.filters import SearchFilter

from .models import Student
from .serializers import StudentSerializer


class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [SearchFilter]

    search_fields = [
        'name',
        'email',
        'course'
    ]

Step 2 – Register Router

Jar StudentViewSet router madhye already register asel, tar punha register karanyachi garaj nahi.

File: api/urls.py

from rest_framework.routers import DefaultRouter
from .views import StudentViewSet

router = DefaultRouter()

router.register(
    'students',
    StudentViewSet,
    basename='student'
)

urlpatterns = router.urls

Step 3 – Run Server

python manage.py runserver

Step 4 – Test API

/api/students/?search=Rohan

/api/students/?search=gmail

/api/students/?search=Computer

Ata API madhye name, email ani course ya fields var search karta yeil.

Important: Ya practical madhye Student model madhye name, email ani course fields available asne avashyak aahe. Tumchya project madhil actual field names vapra.

12. Filtering and Searching Together

DRF madhye Filtering ani Searching donhi ekach ViewSet madhye use karta yetat.

Example

from django_filters.rest_framework import DjangoFilterBackend
from rest_framework.filters import SearchFilter

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    filter_backends = [
        DjangoFilterBackend,
        SearchFilter
    ]

    filterset_fields = ['course']
    search_fields = ['name', 'email']

API Request

/api/students/?course=ComputerScience&search=Rohan

Ya request madhye course filter ani name/email search donhi apply hotil.

13. Important Points to Remember

  • SearchFilter DRF madhye built-in available aahe.

  • Related fields sathi double underscore notation vapartat.
  • SearchFilter ani Pagination ekatra use karta yetat.
  • Filtering ani Searching ekatra use karta yetat.

SearchFilter is a built-in DRF filter backend used to search records using keywords.

Q2. What is search_fields?

search_fields defines the model fields in which the API performs searching.

Q3. Which query parameter is used by default?

The default query parameter is search.

Q4. Can we search multiple fields?

Yes. We can define multiple model fields inside search_fields.

Q5. Is SearchFilter case-sensitive?

No. The default SearchFilter performs case-insensitive searching.

Q6. Can we search related fields?

Yes. We can use double underscore notation to search related model fields.
