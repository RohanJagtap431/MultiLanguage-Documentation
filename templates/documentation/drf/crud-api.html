15. CRUD API in DRF

Learn how to create, read, update and delete database records using Django REST Framework.

1. What is CRUD?

CRUD hi database madhil data manage karanyasathi use honari four basic operations aahet. DRF madhye HTTP methods vaprun CRUD API create karta yete.

Definition

CRUD stands for Create, Read, Update and Delete. These operations are used to manage data in a database.

Operation HTTP Method Purpose
Create POST New record add karne
Read GET Record fetch karne
Update PUT / PATCH Existing record update karne
Delete DELETE Record remove karne

CRUD Flow

CREATE POST - New record
↓
READ GET - Fetch records
↓
UPDATE PUT / PATCH - Change record
↓
DELETE DELETE - Remove record

from .models import Student

class StudentSerializer(serializers.ModelSerializer):

6. Create CRUD API Views

Ata aapan ekach API view madhye GET ani POST methods handle karu.

File: api/views.py

GET – Read All Students

from rest_framework.decorators import api_view
from rest_framework.response import Response
from rest_framework import status

from django.shortcuts import get_object_or_404

from .models import Student
from .serializers import StudentSerializer


@api_view(['GET', 'POST'])
def student_list(request):

    if request.method == 'GET':

        students = Student.objects.all()

        serializer = StudentSerializer(
            students,
            many=True
        )

        return Response(serializer.data)

Explanation

  • Student.objects.all(): Sarve students fetch karte.
  • many=True: Multiple records serialize karte.
  • serializer.data: API response sathi data return karto.

POST – Create Student

Tyach student_list function madhye POST condition add kara. 

    elif request.method == 'POST':

        serializer = StudentSerializer(
            data=request.data

        if serializer.is_valid():
            serializer.save()

            return Response(
                serializer.data,
                status=status.HTTP_201_CREATED
            )

            serializer.errors,
            status=status.HTTP_400_BAD_REQUEST

Valid data asel tar navin student database madhye save hoto. Invalid data asel tar validation errors return hotat.

7. Read, Update and Delete Single Student

Ata student cha ID vaprun specific record fetch, update ani delete karuya.

Complete Detail View

File: api/views.py

@api_view(['GET', 'PUT', 'PATCH', 'DELETE'])
def student_detail(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    if request.method == 'GET':

        serializer = StudentSerializer(student)

        return Response(serializer.data)

    elif request.method == 'PUT':

        serializer = StudentSerializer(
            student,
            data=request.data
        )

    elif request.method == 'PATCH':

        serializer = StudentSerializer(
            student,
            data=request.data,
            partial=True
        )

    elif request.method == 'DELETE':

        student.delete()

        return Response(
            status=status.HTTP_204_NO_CONTENT
        )

    if serializer.is_valid():
        serializer.save()

        return Response(serializer.data)

    return Response(
        serializer.errors,
        status=status.HTTP_400_BAD_REQUEST
    )

Method Explanation

Method Working
GET Specific student fetch karto.
PUT Complete student data update karto.
PATCH Selected fields update karto.
DELETE Student record delete karto.
Important: get_object_or_404() la student sapadla nahi tar 404 Not Found response milto. DELETE madhye 204 No Content return kelyamule response body naste.

12. Important Points to Remember

  • CRUD stands for Create, Read, Update and Delete.
  • POST method creates a new record.
  • GET method reads existing records.
  • PUT updates complete data.
  • PATCH updates selected fields.
  • DELETE removes a record.
  • Model defines the database structure.
  • Serializer converts and validates data.
  • serializer.save() saves valid data.
  • get_object_or_404() returns 404 if a record does not exist.

14. Interview Questions

Q1. What is CRUD?

CRUD stands for Create, Read, Update and Delete. It represents four basic database operations.

Q2. Which HTTP method is used to create data?

POST method is used to create a new resource.

Q3. What is the difference between PUT and PATCH?

PUT is used for complete updates, whereas PATCH is used for partial updates.

Q4. What is ModelSerializer?

ModelSerializer is used to create serializers based on Django models.

Q5. What is the use of many=True?

many=True allows a serializer to handle multiple objects.

Q6. What is HTTP 204?

HTTP 204 means No Content. It indicates that the request was successful and no response body is returned.
