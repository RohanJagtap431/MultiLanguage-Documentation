03. REST API Basics

REST API chi basic concept, structure ani working simple Roman Marathi madhye samjun ghya.

1. What is REST?

REST cha full form Representational State Transfer aahe.

REST hi software applications madhye API design karanyasathi vaprali janari architectural style aahe.

REST mule client ani server yanchyamadhye standard rules follow karun communication karta yete.

Definition

REST is an architectural style used to design network-based applications.

Simple Example

Samaj tu Student Management application banavli aahe. Ya application madhye students chi mahiti server var aahe.

Mobile app la student chi mahiti havi asel tar ti server la request pathavel. Server required data response madhye return karel.

2. What is REST API?

REST principles follow karun banavlelya API la REST API mhantat.

REST API madhye client HTTP request pathavto ani server HTTP response return karto.

Definition

REST API is an API that follows REST architectural principles to communicate between client and server.

Remember: REST hi architectural style aahe. REST API hi REST principles follow karun tayar kelele API aahe.

3. What is Client and Server?

REST API madhye Client ani Server he don important parts aahet.

Client

Client mhanje request pathavnari application.

Examples:

  • Web Browser
  • React Application
  • Android Mobile App
  • Desktop Application

Server

Server mhanje client chi request receive karun process karanari system.

Examples:

  • Django Backend
  • Database Server
  • Application Server

Example

Tu mobile madhye Student App open kelas. Student App ha Client aahe.

Django backend request process karto. To Server cha part aahe.

4. What is Resource?

REST API madhye Resource mhanje server var available aslela data kiwa object.

Udaharanarth, Student Management System madhye Student ha ek Resource aahe.

Examples of Resources

  • Students
  • Teachers
  • Products
  • Orders
  • Users

Pratyek resource la API madhye unique URL path kiwa endpoint ne access karta yete.

5. What is API Endpoint?

API Endpoint mhanje server varil specific resource access karanyasathi vaparla janara URL path.

Definition

An API endpoint is a specific URL path through which a client accesses a resource.

Example

GET /api/students/

Ya example madhye:

  • GET - HTTP Method
  • /api/ - API URL prefix
  • students/ - Resource path
Important: Endpoint ha URL path asto. GET ha HTTP method aahe. Ya donhi goshti veglya aahet.

6. What is Statelessness?

REST chi ek important constraint mhanje Statelessness.

Statelessness mhanje server pratyek request la independent request mhanun handle karto.

Server ne previous request madhil client state lakshat thevne required naste. Pratyek request madhye required information pathavli pahije.

Simple Example

Samaj tu student details magnyasathi request pathavtos. Nantar student marks magnyasathi dusri request pathavtos.

Donhi requests madhye server la required information independently milali pahije.

Remember: Statelessness mhanje server la previous request chi application state maintain karavi lagat nahi. Authentication sathi token sarkhi information pratyek request sobat pathavli jau shakte.

8. Basic REST API Example

Samaj aaplyakade Students API aahe. Aaplyala server kadun students chi list havi aahe.

API Request

GET /api/students/

API Response

[
    {
        "id": 1,
        "name": "Rahul",
        "course": "BSc Computer Science"
    },
    {
        "id": 2,
        "name": "Amit",
        "course": "BCA"
    }
]

Server ne JSON format madhye students chi list return keli. Client ya data cha use karun screen var student details display karu shakto.
