30. Throttling in DRF

Learn how to control the number of API requests made by users within a specific time period.

1. What is Throttling?

Throttling mhanje API la specific time period madhye kiti requests allow karaychya he control karne.

Definition

Throttling is a technique used to limit the number of API requests made by a client within a specific time period.

Example

Samja ek API user la 1 minute madhye maximum 10 requests allow karte.

Request Limit

Allowed Requests: 10 per minute

Request 1  - Allowed
Request 2  - Allowed
Request 3  - Allowed
...
Request 10 - Allowed
Request 11 - Throttled

Limit exceed zalyavar API 429 Too Many Requests response deu shakte.

2. Why is Throttling Required?

  • API requests control karanyasathi.
  • Excessive requests limit karanyasathi.
  • API resources cha usage manage karanyasathi.
  • Fair usage policy implement karanyasathi.
  • Unnecessary repeated requests kami karanyasathi.
Important: Throttling he complete security protection nahi. Sensitive APIs secure karanyasathi authentication, permissions ani proper security controls suddha avashyak aahet.

3. What is Rate Limiting?

Rate Limiting mhanje ek user kiwa client specific time period madhye kiti requests karu shakto yachi limit define karne.

Examples

Rate Limit Meaning
10/minute 1 minute madhye 10 requests.
100/hour 1 hour madhye 100 requests.
1000/day 1 day madhye 1000 requests.

4. Types of Throttling in DRF

Django REST Framework madhye commonly three built-in throttling classes vapartat.

Throttle Class Purpose
AnonRateThrottle Unauthenticated users sathi request limit.
UserRateThrottle Authenticated users sathi request limit.
ScopedRateThrottle Specific API scope nusar request limit.

5. AnonRateThrottle

AnonRateThrottle ha unauthenticated users sathi request limit apply karto.

Mhanje login na kelele users sathi IP address nusar request limit lagu hote.

Step 1 – Import

from rest_framework.throttling import AnonRateThrottle

Step 2 – Configure in settings.py

REST_FRAMEWORK = {

    'DEFAULT_THROTTLE_CLASSES': [
        'rest_framework.throttling.AnonRateThrottle',
    ],

    'DEFAULT_THROTTLE_RATES': {
        'anon': '10/minute',
    },

}

Explanation

  • AnonRateThrottle unauthenticated requests limit karto.
  • anon ha default rate scope aahe.
  • 10/minute mhanje configured rate 10 requests per minute.

6. UserRateThrottle

UserRateThrottle ha authenticated users sathi request limit apply karto.

Authenticated user chi request limit user identity nusar track keli jate.

Configuration

File: config/settings.py

REST_FRAMEWORK = {

    'DEFAULT_THROTTLE_CLASSES': [
        'rest_framework.throttling.UserRateThrottle',
    ],

    'DEFAULT_THROTTLE_RATES': {
        'user': '100/day',
    },

}

Explanation

  • UserRateThrottle authenticated users sathi aahe.
  • user ha default rate scope aahe.
  • 100/day mhanje 1 day madhye 100 requests chi configured limit.

7. ScopedRateThrottle

ScopedRateThrottle vaprun specific API endpoints sathi vegvegli request limits define karta yetat.

Step 1 – Configure in settings.py

REST_FRAMEWORK = {

    'DEFAULT_THROTTLE_CLASSES': [
        'rest_framework.throttling.ScopedRateThrottle',
    ],

    'DEFAULT_THROTTLE_RATES': {
        'student_api': '20/minute',
        'report_api': '5/minute',
    },

}

Step 2 – Apply Scope in View

File: api/views.py

from rest_framework.viewsets import ModelViewSet

from .models import Student
from .serializers import StudentSerializer


class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    throttle_scope = 'student_api'

Explanation

  • throttle_scope view cha rate scope define karto.
  • student_api la 20 requests per minute limit aahe.
  • Different API views sathi different scopes define karta yetat.
Note: ScopedRateThrottle authenticated user kiwa unauthenticated client chi request identity track karto. Fakat scope define kelyane rate limit enable hot nahi; ScopedRateThrottle class suddha configure asne avashyak aahe.

8. DEFAULT_THROTTLE_CLASSES

DEFAULT_THROTTLE_CLASSES madhye API sathi default throttling classes define kele jatat.

Example

REST_FRAMEWORK = {

    'DEFAULT_THROTTLE_CLASSES': [
        'rest_framework.throttling.AnonRateThrottle',
        'rest_framework.throttling.UserRateThrottle',
    ],

}

Ya configuration madhye unauthenticated users ani authenticated users donhinsathi throttle classes enable hotat.

9. DEFAULT_THROTTLE_RATES

DEFAULT_THROTTLE_RATES madhye pratyek throttle class sathi request limit define keli jate.

Example

REST_FRAMEWORK = {

    'DEFAULT_THROTTLE_CLASSES': [
        'rest_framework.throttling.AnonRateThrottle',
        'rest_framework.throttling.UserRateThrottle',
    ],

    'DEFAULT_THROTTLE_RATES': {
        'anon': '10/minute',
        'user': '100/day',
    },

}

Supported Time Periods

Unit Meaning
second Per second
minute Per minute
hour Per hour
day Per day

10. Custom Throttling

DRF madhye aapan custom throttle class suddha create karu shakto.

Step 1 – Create throttles.py

File: api/throttles.py

from rest_framework.throttling import UserRateThrottle


class CustomUserThrottle(UserRateThrottle):

    scope = 'custom_user'

Step 2 – Configure Rate

File: config/settings.py

REST_FRAMEWORK = {

    'DEFAULT_THROTTLE_CLASSES': [
        'api.throttles.CustomUserThrottle',
    ],

    'DEFAULT_THROTTLE_RATES': {
        'custom_user': '20/hour',
    },

}

Explanation

  • CustomUserThrottle hi custom throttle class aahe.
  • Ti UserRateThrottle inherit karte.
  • scope madhye custom_user define kele aahe.
  • Settings madhye tyacha rate 20/hour define kela aahe.

11. Throttling with a Specific View

Throttling global settings madhye configure na karta specific API view madhye suddha apply karta yete.

Example

from rest_framework.viewsets import ModelViewSet
from rest_framework.throttling import UserRateThrottle

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    throttle_classes = [UserRateThrottle]

Ya view madhye UserRateThrottle apply hoil. Tyacha rate settings madhil user scope nusar configure karava lagel.

12. Throttling Response

Configured request limit exceed zalyas DRF request reject karu shakto.

Example Response

HTTP 429 Too Many Requests

{
    "detail": "Request was throttled."
}

429 ha HTTP status code client ne allowed request rate exceed kelyache darshavto.

Important: DRF throttling ha approximate rate limiting mechanism aahe. To security protection kiwa strict request counting system samju naye.

13. Practical API Rate Limiting

Ata aapan Student API sathi authenticated ani unauthenticated users che request limits configure karuya.

Step 1 – Update settings.py

REST_FRAMEWORK = {

    'DEFAULT_THROTTLE_CLASSES': [
        'rest_framework.throttling.AnonRateThrottle',
        'rest_framework.throttling.UserRateThrottle',
    ],

    'DEFAULT_THROTTLE_RATES': {
        'anon': '10/minute',
        'user': '100/day',
    },

}

Step 2 – Create Student API

File: api/views.py

from rest_framework.viewsets import ModelViewSet

from .models import Student
from .serializers import StudentSerializer


class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

Step 3 – Run Server

python manage.py runserver

Step 4 – Test API

GET /api/students/

Unauthenticated user sathi configured limit 10 requests per minute aahe. Authenticated user sathi 100 requests per day aahe.

Limit exceed zalyas API 429 response deu shakte.

14. Important Points to Remember

  • Throttling API requests limit karte.
  • Rate Limiting request count ani time period define karte.
  • AnonRateThrottle unauthenticated users sathi aahe.
  • UserRateThrottle authenticated users sathi aahe.
  • ScopedRateThrottle specific API scopes sathi aahe.
  • DEFAULT_THROTTLE_CLASSES throttle classes configure karte.
  • DEFAULT_THROTTLE_RATES request limits define karte.
  • Custom throttling class create karta yete.
  • 429 Too Many Requests ha throttling response aahe.
  • Throttling ha complete security solution nahi.
