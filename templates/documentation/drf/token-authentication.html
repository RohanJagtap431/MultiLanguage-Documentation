24. Token Authentication in DRF

Learn how to authenticate API users using token keys and protect API endpoints.

1. What is Token Authentication?

Token Authentication hi API madhye user chi identity verify karanyachi ek method aahe.

Definition

Token Authentication is a method in which a client uses a token key to authenticate API requests.

Simple Example

Samja user application madhye login karto. Server username ani password verify karun user la ek unique token key deto.

Pudhil API requests madhye client ha token pathavto. Server token verify karun user identify karto.

2. How Token Authentication Works

1. Login Request Client username ani password pathavto.
↓
2. Credential Verification Server user credentials verify karto.
↓
3. Token Generation Server user cha token return karto.
↓
4. API Request Client request sobat token pathavto.
↓
5. Token Verification Server token verify karto.
↓
6. API Response Valid token asel tar access milto.

6. Configure Token Authentication

Ata settings.py madhye default authentication ani permission classes configure karuya.

File: config/settings.py

REST_FRAMEWORK = {

    'DEFAULT_AUTHENTICATION_CLASSES': [
        'rest_framework.authentication.TokenAuthentication',
    ],

    'DEFAULT_PERMISSION_CLASSES': [
        'rest_framework.permissions.IsAuthenticated',
    ],

}

Explanation

  • TokenAuthentication token verify karte.
  • IsAuthenticated authenticated users na access dete.
  • Default settings sarva DRF views la apply hotat.
Important: Ya global settings mule public API suddha protected hote. Public endpoint sathi AllowAny permission explicitly define kara.

7. Create Token Login API

DRF madhye obtain_auth_token view built-in available aahe. Tyacha use karun username ani password verify karun token milavta yeto.

Step 1 – Import

from rest_framework.authtoken.views import obtain_auth_token

Step 2 – Add URL

File: api/urls.py

from django.urls import path, include
from rest_framework.routers import DefaultRouter
from rest_framework.authtoken.views import obtain_auth_token

from .views import StudentViewSet

router = DefaultRouter()

router.register(
    'students',
    StudentViewSet,
    basename='student'
)

urlpatterns = [
    path('token/', obtain_auth_token, name='api_token_auth'),
    path('', include(router.urls)),
]

Ya example madhye project-level URL madhye api app include kelela asne avashyak aahe.

File: config/urls.py

from django.urls import path, include

urlpatterns = [
    path('api/', include('api.urls')),
]

Token Login URL

http://127.0.0.1:8000/api/token/

8. Login API Request

Ata Postman madhun token login API la POST request pathavu.

Request Method

POST

Request URL

http://127.0.0.1:8000/api/token/

Request Body – JSON

{
    "username": "your_username",
    "password": "your_password"
}

Successful Response

{
    "token": "your_generated_token_key"
}

Credentials valid astil tar server token return karto. Invalid credentials aslyas login fail hoto.

9. Send Token in API Request

Login nantar milalela token pudhil API requests madhye Authorization header madhun pathavaycha.

Authorization Header

Authorization: Token your_generated_token_key

Example Request

GET http://127.0.0.1:8000/api/students/

How it works?

  • Client token header madhye pathavto.
  • DRF TokenAuthentication token verify karte.
  • Valid token asel tar request authenticated hote.
  • IsAuthenticated permission access allow karte.

11. Generate Token Manually

Django shell madhun suddha user sathi token create karta yeto.

Step 1 – Open Django Shell

python manage.py shell

Step 2 – Import User and Token

from django.contrib.auth.models import User
from rest_framework.authtoken.models import Token

Step 3 – Get User

user = User.objects.get(username='your_username')

Step 4 – Create or Get Token

token, created = Token.objects.get_or_create(user=user)

print(token.key)

get_or_create mule user sathi token nasel tar navin token create hoto. Already token asel tar toch return hoto.

Note: Custom user model asel tar User import karanyasathi get_user_model() vapra.

12. Logout and Delete Token

DRF built-in TokenAuthentication madhye default logout endpoint nahi. Logout sathi current user's token delete karu shakto.

Step 1 – Create Logout API

File: api/views.py

from rest_framework.views import APIView
from rest_framework.permissions import IsAuthenticated
from rest_framework.authentication import TokenAuthentication
from rest_framework.response import Response
from rest_framework import status

class LogoutAPIView(APIView):

    authentication_classes = [TokenAuthentication]
    permission_classes = [IsAuthenticated]

    def post(self, request):

        request.user.auth_token.delete()

        return Response(
            {"message": "Logout successful"},
            status=status.HTTP_200_OK
        )

Step 2 – Add URL

File: api/urls.py

from .views import LogoutAPIView

urlpatterns = [
    path('token/', obtain_auth_token, name='api_token_auth'),
    path('logout/', LogoutAPIView.as_view(), name='api_logout'),
    path('', include(router.urls)),
]

Step 3 – Send Logout Request

POST http://127.0.0.1:8000/api/logout/

Request sobat valid token pathva. Token delete zalyanantar tyach token cha use karun pudhil request authenticate honar nahi.

13. Important Points to Remember

  • Token Authentication API users identify karte.
  • Token sathi rest_framework.authtoken app add karave lagte.
  • Database migrations run karavya lagtat.
  • obtain_auth_token built-in login token view aahe.
  • Token Authorization header madhun pathavla jato.
  • Header format: Authorization: Token your_token_key.
  • Token secret thevne avashyak aahe.
  • Token delete kelyavar to token invalid hoto.
Security: Built-in DRF TokenAuthentication token expiry automatically provide karat nahi. Production madhye HTTPS vapra, tokens securely store kara ani token rotation/expiry requirements vicharat ghya.

15. Interview Questions

Q1. What is Token Authentication?

Token Authentication is a method that uses a token key to authenticate API requests.

Q2. Which app is required for DRF Token Authentication?

rest_framework.authtoken is required.

Q3. What is obtain_auth_token?

It is a built-in DRF view that verifies login credentials and returns an authentication token.

Q4. How is a token sent to the API?

The token is sent using the Authorization header in the format Authorization: Token your_token_key.

Q5. How can we logout using Token Authentication?

We can delete the authenticated user's token to invalidate that token.

Q6. Does DRF TokenAuthentication provide automatic expiry?

No. The built-in TokenAuthentication does not provide automatic token expiry.
