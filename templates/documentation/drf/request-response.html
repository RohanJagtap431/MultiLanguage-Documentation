14. Request and Response in DRF

Understand how DRF receives client requests and sends responses back to the client.

1. What is Request and Response?

API madhye client server la request pathavto. Server request process karun client la response return karto.

Request

A request is a message sent by the client to the server to perform an operation or get some data.

Response

A response is a message sent by the server to the client after processing the request.

Request and Response Flow

Client API request pathavto
↓
DRF Request Request data receive karte
↓
API View Request process karte
↓
DRF Response Response prepare karte
↓
Client Response receive karto

2. DRF Request Object

Django REST Framework madhye request object client kadun aaleli information access karanyasathi use hoto.

Definition

The DRF Request object provides information about the incoming API request, such as data, method, headers and query parameters.

Example

from rest_framework.decorators import api_view
from rest_framework.response import Response

@api_view(['GET'])
def student_api(request):

    return Response({
        "method": request.method
    })

Ithe request.method madhun request kontya HTTP method ne aali aahe te samajte.

3. request.data

request.data cha use client kadun POST, PUT ani PATCH request madhye pathavlela data access karanyasathi hoto.

Definition

request.data is used to access the parsed data sent by the client in an API request.

Example

@api_view(['POST'])
def student_create(request):

    name = request.data.get('name')
    age = request.data.get('age')

    return Response({
        "name": name,
        "age": age
    })

Client Request Body

{
    "name": "Rohan",
    "age": 20
}

API Response

{
    "name": "Rohan",
    "age": 20
}
Remember: request.data madhye client kadun aalela parsed request body data milto. To fakt JSON purta limited nahi; DRF supported parsers nusar form data suddha access karta yeto.

4. request.method

request.method cha use client ne konti HTTP method pathavli aahe he check karanyasathi hoto.

Example

@api_view(['GET', 'POST'])
def student_api(request):

    if request.method == 'GET':

        return Response({
            "message": "Get request received"
        })

    elif request.method == 'POST':

        return Response({
            "message": "Post request received"
        })

Common Values

Method Purpose
GET Read data
POST Create data
PUT Update complete data
PATCH Update partial data
DELETE Delete data

5. request.query_params

request.query_params cha use URL madhil query parameters access karanyasathi hoto.

Definition

request.query_params is used to access query parameters from the URL.

Example URL

http://127.0.0.1:8000/api/students/?name=Rohan&age=20

Example Code

@api_view(['GET'])
def student_search(request):

    name = request.query_params.get('name')
    age = request.query_params.get('age')

    return Response({
        "name": name,
        "age": age
    })

Response

{
    "name": "Rohan",
    "age": "20"
}
Important: Query parameter values normally string format madhye miltat. Number mhanun use karayche asel tar conversion kara.

6. request.headers

request.headers cha use client kadun request sobat pathavlele HTTP headers access karanyasathi hoto.

Definition

request.headers provides access to the HTTP headers included in an incoming request.

Example

@api_view(['GET'])
def header_api(request):

    content_type = request.headers.get(
        'Content-Type'
    )

    user_agent = request.headers.get(
        'User-Agent'
    )

    return Response({
        "content_type": content_type,
        "user_agent": user_agent
    })

Common HTTP Headers

Header Purpose
Content-Type Request body cha format sangto.
Accept Client la konta response format hava aahe te sangto.
Authorization Authentication credentials pathavto.
User-Agent Client software chi information deto.

7. DRF Response Object

Response object cha use API madhun client la data return karanyasathi hoto.

Definition

Response is a DRF class used to return content from an API view to the client.

Import Response

from rest_framework.response import Response

Basic Example

@api_view(['GET'])
def welcome_api(request):

    return Response({
        "message": "Welcome to DRF"
    })

Example Response

{
    "message": "Welcome to DRF"
}

DRF Response object content negotiation nusar response render karanyas madat karto.

8. Response Status Codes

API response sobat HTTP status code suddha return karu shakto. Status code request cha result kay aahe te sangto.

Example using status number

return Response(
    {"message": "Student created"},
    status=201
)

Using DRF status module

from rest_framework import status
from rest_framework.response import Response

@api_view(['POST'])
def student_create(request):

    return Response(
        {"message": "Student created"},
        status=status.HTTP_201_CREATED
    )

Common Status Codes

Status Code Meaning
200 OK
201 Created
204 No Content
400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
500 Internal Server Error
Remember: 204 No Content response madhye response body naste. Successful DELETE request sathi ha status code use karu shakto.

9. request.data vs request.query_params

Donhi client kadun information access karanyasathi use hotat, pan tyanchi source vegli aste.

request.data request.query_params
Request body madhil data. URL madhil query parameters.
POST, PUT, PATCH madhye commonly used. GET filtering ani searching madhye commonly used.
JSON kiwa form data asu shakto. URL madhun values miltat.
request.data.get('name') request.query_params.get('name')

Request Body Example

{
    "name": "Rohan"
}

Query Parameter Example

/api/students/?name=Rohan

10. Practical API Example

Ata request.data, request.method, request.query_params ani Response ekatra use karuya.

File: api/views.py

from rest_framework.decorators import api_view
from rest_framework.response import Response
from rest_framework import status

@api_view(['GET', 'POST'])
def student_api(request):

    if request.method == 'GET':

        name = request.query_params.get('name')

        return Response({
            "message": "Student search",
            "name": name
        })

    elif request.method == 'POST':

        name = request.data.get('name')
        age = request.data.get('age')

        return Response(
            {
                "message": "Student data received",
                "name": name,
                "age": age
            },
            status=status.HTTP_201_CREATED
        )

GET Request

GET /api/student/?name=Rohan

POST Request Body

{
    "name": "Rohan",
    "age": 20
}

Ya example madhye data database madhye save hot nahi. To fakt request madhun read karun response madhye return hoto.

11. Important Points to Remember

  • Request client kadun server kade yete.
  • Response server kadun client kade jato.
  • request.data body madhil parsed data access karte.
  • request.method HTTP method return karte.
  • request.query_params URL parameters access karte.
  • request.headers HTTP headers access karte.
  • Response() API madhun data return karte.
  • status parameter response cha HTTP status set karto.
  • status module madhye named HTTP status constants astat.

13. Interview Questions

Q1. What is request.data?

request.data is used to access parsed data sent by the client in an API request.

Q2. What is request.method?

request.method returns the HTTP method used in the incoming request.

Q3. What is request.query_params?

It is used to access query parameters from the URL.

Q4. What is request.headers?

It provides access to the HTTP headers included in the incoming request.

Q5. What is Response()?

Response() is used to return API content from the view to the client.

Q6. What is HTTP 201 status code?

HTTP 201 means Created. It indicates that a resource has been successfully created.
