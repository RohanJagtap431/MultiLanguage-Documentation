DJANGO REST FRAMEWORK

02. Django vs Django REST Framework

Django ani Django REST Framework madhil difference simple Roman Marathi madhye samjun ghya.

1. What is Django?

Django he Python madhil ek high-level Web Framework aahe. Django cha use karun aapan complete websites ani web applications develop karu shakto.

Definition

Django is a high-level Python web framework used to build secure and maintainable web applications.

Django cha use kuthe hoto?

  • Blog Website
  • Student Management System
  • E-commerce Website
  • College Management System
  • Admin Dashboard

Simple Example

Samaj tu Django vaprun Student Management Website tayar keli aahe.

Student browser madhye website open karto. Django backend request process karto ani HTML page browser la return karto.

2. What is Django REST Framework?

Django REST Framework la short madhye DRF mhantat. He Django sobat vaparla janara toolkit aahe.

DRF cha use karun aapan REST APIs create karu shakto. Ya API madhun frontend, mobile application kiwa dusri application data gheu shakte.

Definition

Django REST Framework is a toolkit used to build Web APIs using Django.

DRF cha use kuthe hoto?

  • Student API
  • User Registration API
  • Login API
  • Product API
  • Mobile Application Backend

3. Main Difference Between Django and DRF

Django ani DRF yanche purpose samjun ghenyasathi khalil table bagh.

Django Django REST Framework
Full Web Framework API Toolkit
Complete web applications banavto Web APIs banavnyas madat karto
HTML pages return karu shakto JSON responses provide karu shakto
Django Templates vaparto Serializers vaparto
Traditional web forms handle karto API requests handle karto
Browser-based websites sathi useful Web ani mobile applications sathi useful
Important: DRF he Django cha replacement nahi. DRF he Django var build keleले toolkit aahe. DRF vaparnyasathi Django project lagto.

7. Can We Build API Without DRF?

Ho! Django madhye DRF nasतानाही API create karta yete. Django madhye JsonResponse vaprun JSON data return karu shakto.

Pan authentication, serializers, permissions, validation ani API views sarkhya features sathi DRF khup useful tharto.

Remember: Django madhye API banavne possible aahe. Pan REST API development soppe ani organized karanyasathi DRF vapartat.

10. Interview Questions

Q1. What is the difference between Django and DRF?

Django is a Python web framework used to build web applications, whereas DRF is a toolkit used to build Web APIs using Django.

Q2. Is DRF a replacement for Django?

No. DRF is built on top of Django and is used for API development.

Q3. Can Django create APIs without DRF?

Yes. Django can return JSON data using JsonResponse. DRF provides additional tools that simplify API development.
