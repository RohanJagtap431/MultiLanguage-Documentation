DJANGO REST FRAMEWORK

26. Pagination in DRF

Learn how to divide large API responses into smaller pages using Django REST Framework.

1. What is Pagination?

Pagination mhanje mothya data la small pages madhye divide karne. Pratyek API request madhye limited records return kele jatat.

Definition

Pagination is the process of dividing large data into smaller pages for easier access and management.

Example

Samja database madhye 1,000 students aahet. Ekach request madhye 1,000 records pathavnyapeksha pratyek page madhye 10 records pathavu shakto.

Without Pagination

One API request returns all 1,000 student records.

With Pagination

Page 1 → 10 records

Page 2 → 10 records

Page 3 → 10 records

And so on...

2. Why is Pagination Required?

Large database madhun data retrieve kartana pagination useful tharte.

  • API response madhil records limit karta yetat.
  • Large responses manage karne sope hote.
  • Frontend madhye page-wise data display karta yeto.
  • Network var unnecessary data transfer kami hoto.
  • Large datasets efficiently browse karta yetat.
Important: Pagination mule pratyek request madhye limited records return hotat. Pan database query ani performance efficient thevnyasathi proper indexing suddha important aahe.

3. Types of Pagination in DRF

Django REST Framework madhye three common built-in pagination classes aahet.

Pagination Class Purpose
PageNumberPagination Page number vaprun records retrieve karte.
LimitOffsetPagination Limit ani offset vaprun records retrieve karte.
CursorPagination Cursor position vaprun records retrieve karte.

4. PageNumberPagination

PageNumberPagination madhye page number specify karun records retrieve karta yetat.

Definition

PageNumberPagination divides API results into pages and allows clients to request a specific page number.

Example URL

/api/students/?page=1

Ya request madhye first page che records return hotil.

Step 1 – Create Pagination Class

File: api/pagination.py

from rest_framework.pagination import PageNumberPagination

class StudentPagination(PageNumberPagination):

    page_size = 10

Step 2 – Apply Pagination

File: api/views.py

from rest_framework.viewsets import ModelViewSet

from .models import Student
from .serializers import StudentSerializer
from .pagination import StudentPagination

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    pagination_class = StudentPagination

Step 3 – Test API

GET /api/students/?page=1
GET /api/students/?page=2
GET /api/students/?page=3

Example Response

{
    "count": 100,
    "next": "http://127.0.0.1:8000/api/students/?page=2",
    "previous": null,
    "results": [
        {
            "id": 1,
            "name": "Rahul"
        },
        {
            "id": 2,
            "name": "Amit"
        }
    ]
}

Ya response madhye count, next, previous ani results he important fields astat.

5. Customize Page Size

Client la URL madhun page size change karaychi permission dyaychi asel tar page_size_query_param use karu shakto.

Example

from rest_framework.pagination import PageNumberPagination

class StudentPagination(PageNumberPagination):

    page_size = 10
    page_size_query_param = 'page_size'
    max_page_size = 50

Example URLs

/api/students/?page=1&page_size=20

/api/students/?page=2&page_size=30

Explanation

  • page_size = 10 means default 10 records.
  • page_size_query_param = 'page_size' allows client to request a page size.
  • max_page_size = 50 limits the maximum requested page size.

6. LimitOffsetPagination

LimitOffsetPagination madhye limit ani offset parameters vaprun records retrieve kele jatat.

Definition

LimitOffsetPagination uses a limit to control the number of records and an offset to determine where to start.

Example URL

/api/students/?limit=10&offset=0

Step 1 – Create Pagination Class

File: api/pagination.py

from rest_framework.pagination import LimitOffsetPagination

class StudentLimitPagination(LimitOffsetPagination):

    default_limit = 10
    max_limit = 50

Step 2 – Apply Pagination

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    pagination_class = StudentLimitPagination

Example URLs

/api/students/?limit=10&offset=0

/api/students/?limit=10&offset=10

/api/students/?limit=20&offset=20

Explanation

  • limit = 10 means 10 records return hotil.
  • offset = 0 means first record pasun start hoil.
  • offset = 10 means first 10 records skip hotil.
  • max_limit = 50 means maximum 50 records request karta yetil.

7. CursorPagination

CursorPagination madhye records access karanyasathi cursor position vaprali jate.

Definition

CursorPagination uses a cursor to navigate through a dataset instead of using page numbers or offsets.

Step 1 – Create Pagination Class

File: api/pagination.py

from rest_framework.pagination import CursorPagination

class StudentCursorPagination(CursorPagination):

    page_size = 10
    ordering = '-created_at'

Step 2 – Apply Pagination

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    pagination_class = StudentCursorPagination
Important: Ya example madhye Student model madhye created_at field asne avashyak aahe. CursorPagination sathi ordering stable ani suitable field var asne important aahe.

How it works?

  • First request madhye initial records miltat.
  • Response madhye next cursor URL milto.
  • Next URL use karun pudhil records retrieve karta yetat.
  • Page number manually specify karanyachi garaj naste.

8. Global Pagination Settings

Pratyek ViewSet madhye pagination class define karanyapeksha settings.py madhye global pagination configure karta yete.

File: config/settings.py

REST_FRAMEWORK = {

    'DEFAULT_PAGINATION_CLASS':
        'rest_framework.pagination.PageNumberPagination',

    'PAGE_SIZE': 10,

}

Explanation

  • DEFAULT_PAGINATION_CLASS default pagination class select karte.
  • PAGE_SIZE pratyek page madhil default records tharavte.
  • Ya settings generic views ani viewsets sathi apply hotat.
Note: Plain APIView madhye pagination automatically apply hot nahi. Tithe pagination manually implement karavi lagte.

9. Custom Pagination Class

Application chya requirement nusar custom pagination class create karta yete.

Example

File: api/pagination.py

from rest_framework.pagination import PageNumberPagination

class CustomStudentPagination(PageNumberPagination):

    page_size = 5
    page_size_query_param = 'size'
    max_page_size = 20

Apply Custom Pagination

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    pagination_class = CustomStudentPagination

Example URL

/api/students/?page=1&size=10

10. Disable Pagination for a View

Specific ViewSet sathi pagination disable karaychi asel tar pagination_class None set karu shakto.

Example

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    pagination_class = None

Ya view madhye global pagination settings apply honar nahi.

11. Practical Student API Pagination

Ata aapan Student API madhye PageNumberPagination implement karuya.

Step 1 – Create Pagination File

File: api/pagination.py

from rest_framework.pagination import PageNumberPagination

class StudentPagination(PageNumberPagination):

    page_size = 10
    page_size_query_param = 'page_size'
    max_page_size = 50

Step 2 – Update ViewSet

File: api/views.py

from rest_framework.viewsets import ModelViewSet

from .models import Student
from .serializers import StudentSerializer
from .pagination import StudentPagination

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all().order_by('id')
    serializer_class = StudentSerializer
    pagination_class = StudentPagination

Step 3 – Register Router

File: api/urls.py

from rest_framework.routers import DefaultRouter
from .views import StudentViewSet

router = DefaultRouter()

router.register(
    'students',
    StudentViewSet,
    basename='student'
)

urlpatterns = router.urls

Step 4 – Run Server

python manage.py runserver

Step 5 – Test API

http://127.0.0.1:8000/api/students/?page=1

Test Different Page Sizes

http://127.0.0.1:8000/api/students/?page=1&page_size=20

http://127.0.0.1:8000/api/students/?page=2&page_size=20
Note: Ha practical existing Student model ani StudentSerializer var based aahe. Te already project madhye astil tar punha create karu naka.

12. Important Points to Remember

  • Pagination large data small pages madhye divide karte.
  • PageNumberPagination page number vaparte.
  • LimitOffsetPagination limit ani offset vaparte.
  • CursorPagination cursor position vaparte.
  • page_size default records tharavte.
  • page_size_query_param client la page size change karu dete.
  • max_page_size maximum page size limit karte.
  • Global pagination settings.py madhye define karta yetat.
  • ViewSet madhye pagination_class vaparta yete.
  • pagination_class = None pagination disable karte.
