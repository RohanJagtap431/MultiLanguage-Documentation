18. Mixins in DRF

Learn how to use reusable mixin classes with GenericAPIView to build API endpoints.

1. What are Mixins?

Mixins ya DRF madhil reusable classes aahet. Tyanchya madatine aapan API madhil common operations perform karu shakto.

Definition

Mixins are reusable classes that provide methods for performing common API operations such as listing, creating, retrieving, updating and deleting objects.

Why use Mixins?

  • Common API operations sathi ready-made methods miltat.
  • Code repetition kami hote.
  • GenericAPIView sobat use karta yetat.
  • Custom API views tayar karne sope hote.
Important: Mixins swatah complete API view nahit. Te GenericAPIView sobat inherit karun use kele jatat.

2. Types of Mixins

DRF madhye mainly five important model mixins aahet.

Mixin Method Purpose
ListModelMixin list() Multiple records fetch karne.
CreateModelMixin create() New record create karne.
RetrieveModelMixin retrieve() Single record fetch karne.
UpdateModelMixin update() Record update karne.
DestroyModelMixin destroy() Record delete karne.

Import Mixins

from rest_framework import mixins

3. ListModelMixin

ListModelMixin cha use database madhil multiple records fetch karanyasathi hoto.

Definition

ListModelMixin provides the list() method to retrieve multiple objects.

Example

from rest_framework import mixins
from rest_framework.generics import GenericAPIView

class StudentListView(
    mixins.ListModelMixin,
    GenericAPIView
):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    def get(self, request):
        return self.list(request)

Explanation

  • ListModelMixin: list() method provide karte.
  • GenericAPIView: Queryset ani serializer support dete.
  • get(): GET request handle karte.
  • self.list(): Student records fetch karun response dete.
API Request 
GET /api/students/

4. CreateModelMixin

CreateModelMixin cha use database madhye new record create karanyasathi hoto.

Definition

CreateModelMixin provides the create() method to create a new object.

Example

class StudentCreateView(
    mixins.CreateModelMixin,
    GenericAPIView
):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    def post(self, request):
        return self.create(request)

Explanation

  • POST request accept hote.
  • Request madhil data serializer kade jato.
  • Serializer data validate karto.
  • Valid data database madhye save hoto.
API Request 
POST /api/students/

5. RetrieveModelMixin

RetrieveModelMixin cha use ek specific object fetch karanyasathi hoto.

Definition

RetrieveModelMixin provides the retrieve() method to retrieve a single object.

Example

class StudentDetailView(
    mixins.RetrieveModelMixin,
    GenericAPIView
):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    def get(self, request, *args, **kwargs):
        return self.retrieve(request, *args, **kwargs)

Explanation

  • GET request accept hote.
  • URL madhil primary key vaprun object find hoto.
  • Serializer object convert karto.
  • Client la single student cha response milto.
API Request 
GET /api/students/1/

6. UpdateModelMixin

UpdateModelMixin cha use existing object update karanyasathi hoto.

Definition

UpdateModelMixin provides update() and partial_update() methods to update an object.

Example

class StudentUpdateView(
    mixins.UpdateModelMixin,
    GenericAPIView
):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    def put(self, request, *args, **kwargs):
        return self.update(request, *args, **kwargs)

    def patch(self, request, *args, **kwargs):
        return self.partial_update(
            request,
            *args,
            **kwargs
        )

HTTP Methods

  • PUT: Complete object update karte.
  • PATCH: Object madhil specific fields update karte.
API Request 
PUT   /api/students/1/
PATCH /api/students/1/

7. DestroyModelMixin

DestroyModelMixin cha use existing object delete karanyasathi hoto.

Definition

DestroyModelMixin provides the destroy() method to delete an existing object.

Example

class StudentDeleteView(

):

    queryset = Student.objects.all()

Explanation

  • DELETE request accept hote.
  • Primary key vaprun object find hoto.
  • destroy() method object delete karte.
  • Successful delete nantar HTTP 204 response milto.
API Request

8. GenericAPIView with Multiple Mixins

Aapan ekach view madhye multiple mixins inherit karun multiple API operations handle karu shakto.

Example: List and Create API

class StudentListCreateView(
    mixins.ListModelMixin,
    mixins.CreateModelMixin,
    GenericAPIView
):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    def get(self, request):
        return self.list(request)

    def post(self, request):
        return self.create(request)

Example: Retrieve, Update and Delete API

class StudentDetailView(
    mixins.RetrieveModelMixin,
    mixins.UpdateModelMixin,
    mixins.DestroyModelMixin,
    GenericAPIView
):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    def get(self, request, *args, **kwargs):
        return self.retrieve(request, *args, **kwargs)

    def put(self, request, *args, **kwargs):
        return self.update(request, *args, **kwargs)

    def patch(self, request, *args, **kwargs):
        return self.partial_update(
            request,
            *args,
            **kwargs
        )

    def delete(self, request, *args, **kwargs):
        return self.destroy(request, *args, **kwargs)

9. Practical Student CRUD API using Mixins

Ata aapan Mixins vaprun complete Student CRUD API create karuya.

Step 1 – Model

Topic 17 madhil Student model already asel tar toch model use kara. 

# api/models.py

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)
    email = models.EmailField(unique=True)
    age = models.PositiveIntegerField()

    def __str__(self):
        return self.name

Step 2 – Serializer

# api/serializers.py

from rest_framework import serializers
from .models import Student

class StudentSerializer(serializers.ModelSerializer):

    class Meta:
        model = Student
        fields = '__all__'

Step 3 – Views

# api/views.py

from rest_framework import mixins
from rest_framework.generics import GenericAPIView

from .models import Student
from .serializers import StudentSerializer


class StudentListCreateView(
    mixins.ListModelMixin,
    mixins.CreateModelMixin,
    GenericAPIView
):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    def get(self, request):
        return self.list(request)

    def post(self, request):
        return self.create(request)


class StudentDetailView(
    mixins.RetrieveModelMixin,
    mixins.UpdateModelMixin,
    mixins.DestroyModelMixin,
    GenericAPIView
):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    def get(self, request, *args, **kwargs):
        return self.retrieve(request, *args, **kwargs)

    def put(self, request, *args, **kwargs):
        return self.update(request, *args, **kwargs)

    def patch(self, request, *args, **kwargs):
        return self.partial_update(
            request,
            *args,
            **kwargs
        )

    def delete(self, request, *args, **kwargs):
        return self.destroy(request, *args, **kwargs)

Step 4 – URLs

# api/urls.py

from django.urls import path

from .views import (
    StudentListCreateView,
    StudentDetailView
)

urlpatterns = [

    path(
        'students/',
        StudentListCreateView.as_view(),
        name='student_list'
    ),

    path(
        'students/<int:pk>/',
        StudentDetailView.as_view(),
        name='student_detail'
    ),

]

Step 5 – Main URL Configuration

# config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('api/', include('api.urls')),
]
Important: Topic 17 madhil Student CRUD API sobat same URL patterns duplicate add karu naka. Ya practical sathi existing views replace kara kiwa separate URL prefix use kara. Model ani Serializer already astil tar te punha create karu naka.
