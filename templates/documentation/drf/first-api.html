DJANGO REST FRAMEWORK

08. Your First API

Django REST Framework vaprun pahili API create karayla ani browser madhye test karayla shikuya.

1. What is an API?

API mhanje Application Programming Interface. API mule don applications ekmekansobat data exchange karu shaktat.

Definition

An API is a way for two software applications to communicate with each other.

Simple Example

Samaj ek mobile application la Django server madhun students chi list pahije aahe.

Mobile application API la request pathavte. Django server data JSON format madhye return karto.

Client Request pathavto
↓
Django API Request process karte
↓
JSON Response Data return hoto

2. Create a Django App

Sarvat aadhi Django project madhye API sathi ek separate app create karu.

Step 1: Create App

python manage.py startapp api

Ya command mule api navache Django application create hote.

Step 2: Register App

File: config/settings.py 

INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',

    'rest_framework',
    'api',
]

Ithe aapan api app ani rest_framework register kele aahet.

3. Create Your First API View

Ata API cha logic lihinyasathi api app madhil views.py file open kara.

File: api/views.py

Code

from rest_framework.decorators import api_view
from rest_framework.response import Response

@api_view(['GET'])
def student_list(request):

    students = [
        {
            "id": 1,
            "name": "Rahul",
            "course": "BCA"
        },
        {
            "id": 2,
            "name": "Amit",
            "course": "BSc CS"
        },
        {
            "id": 3,
            "name": "Rohan",
            "course": "BSc CS"
        }
    ]

    return Response(students)

Code Explanation

Code Purpose
api_view Function-based API view create karanyasathi decorator.
Response API madhun response return karto.
@api_view(['GET']) View GET requests accept karte.
request Client kadun aaleli request.
students Student data store karanari Python list.
Response(students) Student data API response madhye return karto.
Remember: @api_view(['GET']) mule hi API GET request accept karte. POST kiwa DELETE request sathi vegale allowed methods configure karave lagtat.

4. Configure API URLs

Ata API view la URL sobat connect karayche aahe. Tyasathi api app madhye navin urls.py file create kara.

File: api/urls.py

Code

from django.urls import path
from . import views

urlpatterns = [
    path('students/', views.student_list, name='student_list'),
]

Explanation

  • path: URL route define karto.
  • views: API view import karto.
  • students/: API cha URL path aahe.
  • student_list: Request alyavar execute honari view.

Connect API URLs to Main Project

Ata main project madhil urls.py open kara.

File: config/urls.py 

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),

    path('api/', include('api.urls')),
]

Ithe include() mule api app madhil URL patterns main project sobat connect hotat.

5. Understand the API URL

Aapan project madhye don URL paths connect kele aahet. 

path('api/', include('api.urls'))

path('students/', views.student_list)

Donhi paths combine zalyanantar final API URL asa banto:

http://127.0.0.1:8000/api/students/

Ha URL browser madhye open kelyavar student_list view execute hoil.

7. What is Browsable API?

Django REST Framework madhye Browsable API feature available aahe.

Browser madhye API URL open kelyavar data sobat HTML interface suddha disu shakto.

Definition

Browsable API is a user-friendly HTML interface provided by DRF to interact with APIs through a browser.

Advantages

  • Browser madhye API response baghta yeto.
  • API manually test karta yete.
  • JSON data samjun ghene sope hote.
  • Developer la debugging madhye madat hote.

11. Interview Questions

Q1. How do you create your first API in DRF?

We create a function-based view using @api_view and return data using the Response class.

Q2. What is @api_view?

It is a decorator used to create function-based API views in Django REST Framework.

Q3. What is Response in DRF?

Response is used to return API data to the client. It can render the data into formats such as JSON.

Q4. What is the purpose of Browsable API?

It provides a browser-based interface to view and interact with API endpoints.
