DJANGO REST FRAMEWORK

22. Authentication in DRF

Learn how Django REST Framework identifies users and protects API endpoints.

1. What is Authentication?

Authentication mhanje user chi identity verify karne. API la request pathavnara user kon aahe he authentication process madhun samajte.

Definition

Authentication is the process of verifying the identity of a user.

Example

Samja ek website aahe. User login kartana username ani password enter karto. System credentials verify karte.

  • Correct username ani password asel tar user identify hoto.
  • Invalid credentials asel tar authentication fail hote.
  • Authenticated user chi information request sobat available hote.

2. Why is Authentication Required?

Authentication cha use private API endpoints protect karanyasathi hoto.

  • User identity verify karanyasathi.
  • Private user data protect karanyasathi.
  • Unauthorized access control karanyasathi.
  • Login-based applications develop karanyasathi.
Important: Authentication user kon aahe he verify karte. Pan user la konti action perform karaychi permission aahe he Permission Classes tharavtat.

3. Authentication vs Authorization

Authentication ani Authorization ya don veglya concepts aahet.

Authentication Authorization
User chi identity verify karte. User la access permission aahe ka te check karte.
Who are you? What can you access?
Login credentials verify karte. Permissions ani access rules check karte.
Example: Login Example: Admin-only page access

Simple Example

User login karto. System tyachi identity verify karte. Ha Authentication aahe.

Login zalyanantar fakt admin la admin dashboard access milto. Ha Authorization aahe.

4. Authentication Flow in DRF

Client Request User API request pathavto
↓
Authentication User identity verify hote
↓
Permission Check User la access allowed aahe ka te check hote
↓
API View Allowed request process hote
↓
Response Client la response milto

Authentication fail zalyas request unauthenticated rahu shakte. Permission check fail zalyas API access deny karte.

5. Authentication Classes in DRF

DRF madhye authentication sathi vegveglya classes available aahet.

Authentication Class Purpose
BasicAuthentication Username ani password HTTP Basic credentials madhun verify karte.
SessionAuthentication Django session madhun user identify karte.
TokenAuthentication Token key vaprun user identify karte.

6. BasicAuthentication

BasicAuthentication madhye client username ani password HTTP Basic Authentication header madhun pathavto.

Definition

BasicAuthentication uses a username and password to authenticate a user through an HTTP Authorization header.

Import

from rest_framework.authentication import BasicAuthentication

Example

from rest_framework.views import APIView
from rest_framework.authentication import BasicAuthentication
from rest_framework.permissions import IsAuthenticated
from rest_framework.response import Response

class StudentAPIView(APIView):

    authentication_classes = [BasicAuthentication]
    permission_classes = [IsAuthenticated]

    def get(self, request):
        return Response({
            "message": "Welcome to Student API"
        })

How it works?

  • Client username ani password pathavto.
  • BasicAuthentication credentials verify karte.
  • Valid user asel tar request authenticated hote.
  • Permission class access allow karte.
Security: BasicAuthentication production madhye fakt HTTPS sobat use kara. HTTP var credentials secure nastat.

7. SessionAuthentication

SessionAuthentication Django chya session system cha use karun user identify karte.

Definition

SessionAuthentication authenticates users using Django's existing session framework.

Import

from rest_framework.authentication import SessionAuthentication

Example

from rest_framework.views import APIView
from rest_framework.authentication import SessionAuthentication
from rest_framework.permissions import IsAuthenticated
from rest_framework.response import Response

class StudentAPIView(APIView):

    authentication_classes = [SessionAuthentication]
    permission_classes = [IsAuthenticated]

    def get(self, request):
        return Response({
            "message": "Session authentication successful"
        })

How it works?

  • User Django website madhye login karto.
  • Django session create karte.
  • Browser session cookie pathavto.
  • DRF session madhun user identify karte.
Important: SessionAuthentication madhye unsafe methods (POST, PUT, PATCH, DELETE) sathi CSRF protection lagu hote. Browser-based applications madhye CSRF token pathavne avashyak asu shakte.

8. IsAuthenticated Permission

IsAuthenticated hi permission class aahe. Ti fakt authenticated users na API access dete.

Definition

IsAuthenticated allows access only to authenticated users.

Import

from rest_framework.permissions import IsAuthenticated

Example

from rest_framework.views import APIView
from rest_framework.permissions import IsAuthenticated
from rest_framework.response import Response

class PrivateAPIView(APIView):

    permission_classes = [IsAuthenticated]

    def get(self, request):
        return Response({
            "message": "You are authenticated"
        })

Response Behavior

User Status Result
Authenticated Permission check pass hote.
Unauthenticated Access deny hote.

Unauthenticated request la authentication setup nusar HTTP 401 Unauthorized kiwa HTTP 403 Forbidden response milu shakto.

9. Global Authentication Settings

Pratyek view madhye authentication classes define karanyapeksha settings.py madhye global configuration set karta yete.

Example

File: config/settings.py

REST_FRAMEWORK = {

    'DEFAULT_AUTHENTICATION_CLASSES': [
        'rest_framework.authentication.BasicAuthentication',
        'rest_framework.authentication.SessionAuthentication',
    ],

    'DEFAULT_PERMISSION_CLASSES': [
        'rest_framework.permissions.IsAuthenticated',
    ],

}

Explanation

  • DEFAULT_AUTHENTICATION_CLASSES authentication methods set karte.
  • DEFAULT_PERMISSION_CLASSES default access rules set karte.
  • Views madhye specific settings deun defaults override karta yetat.
Important: Global IsAuthenticated set kelyas public endpoints sathi AllowAny explicitly set karava lagel. Udaharanarth registration kiwa public login API.

10. request.user and request.auth

DRF madhye authenticated request chi information request object madhun access karta yete.

request.user

request.user authenticated user object provide karte.

request.auth

request.auth authentication class ne return keleli authentication information provide karte.

Example

from rest_framework.views import APIView
from rest_framework.permissions import IsAuthenticated
from rest_framework.response import Response

class ProfileAPIView(APIView):

    permission_classes = [IsAuthenticated]

    def get(self, request):

        return Response({
            "username": request.user.username,
            "user_id": request.user.id
        })

Explanation

  • request.user.username authenticated user cha username dete.
  • request.user.id user cha database ID dete.
  • request.auth authentication information dete.

11. TokenAuthentication Introduction

TokenAuthentication madhye user la ek token key dileli aste. Client API requests sobat hi token key pathavto.

Definition

TokenAuthentication uses a token key to identify an authenticated user.

Example Authorization Header

Authorization: Token your_token_key

Important Points

  • Pratyek user sathi token generate karta yete.
  • Client token API request sobat pathavto.
  • Server token verify karun user identify karto.
  • Token secret thevne avashyak aahe.

TokenAuthentication chi installation, configuration, token generation ani login API aapan pudhchya topic madhye detail madhye shiknar aahot.

12. Practical Protected Student API

Ata aapan ModelViewSet vaprun authenticated users sathi Student API protect karuya.

Step 1 – Imports

File: api/views.py

from rest_framework.viewsets import ModelViewSet
from rest_framework.authentication import (
    BasicAuthentication,
    SessionAuthentication
)
from rest_framework.permissions import IsAuthenticated

from .models import Student
from .serializers import StudentSerializer

Step 2 – Protected ViewSet

class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    authentication_classes = [
        BasicAuthentication,
        SessionAuthentication
    ]

    permission_classes = [
        IsAuthenticated
    ]

Step 3 – Router

Topic 20 ani Topic 21 madhil DefaultRouter configuration vapru shakto. 

# api/urls.py

from rest_framework.routers import DefaultRouter
from .views import StudentViewSet

router = DefaultRouter()

router.register(
    'students',
    StudentViewSet,
    basename='student'
)

urlpatterns = router.urls

Step 4 – Create a Superuser

Test karanyasathi Django superuser create karu shakto. 

python manage.py createsuperuser

Step 5 – Run Server

python manage.py runserver

Step 6 – Test API

http://127.0.0.1:8000/api/students/

Important: Ya example madhye authentication ani permission donhi configure kele aahet. Fakt authentication class add kelyane API automatically private hot nahi.
