DJANGO REST FRAMEWORK

16. URL Routing in DRF

Learn how to connect API views with URLs using Django URL routing.

1. What is URL Routing?

URL Routing mhanje client kadun aaleli URL request yogya view function kiwa class paryant pohachavnyachi process.

Definition

URL Routing is the process of mapping URL patterns to their corresponding views in Django.

Simple Example

Samaj client la Student API access karaychi aahe. Tyasathi client khalil URL request karto. 

http://127.0.0.1:8000/api/students/

Django URL pattern check karto ani request student_list view kade pathavto.

Client URL request pathavto
↓
URL Router URL pattern match karto
↓
API View Request handle karte
↓
Response Client la result return hoto

2. What is path()?

path() ha Django madhil function aahe. To URL pattern la view sobat connect karto.

Definition

path() is used to define a URL pattern and connect it to a view.

Syntax

path(route, view, name=None)

Example

from django.urls import path
from . import views

urlpatterns = [
    path(
        'students/',
        views.student_list,
        name='student_list'
    ),
]

Explanation

  • route: URL pattern define karto.
  • view: Request handle karanara view select karto.
  • name: URL la unique name deto.

3. Project-Level URL Configuration

Project-level URLs madhye complete Django project che main URL patterns define kele jatat.

File: config/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [

    path('admin/', admin.site.urls),

    path('api/', include('api.urls')),

]

Explanation

  • admin/: Django admin panel cha URL.
  • api/: API URLs sathi prefix.
  • include(): API app madhil URLs include karto.

4. What is include()?

include() cha use dusrya URL configuration file madhil URL patterns main project URL madhye include karanyasathi hoto.

Definition

include() is used to include URL patterns from another URL configuration module.

Example

File: config/urls.py

path('api/', include('api.urls'))

File: api/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path(
        'students/',
        views.student_list,
        name='student_list'
    ),
]

Final URL

/api/ + students/

/api/students/

Project URL madhil api/ prefix ani app URL madhil students/ route ekatra houn final URL tayar hoto.

5. App-Level URL Configuration

App-level URLs madhye specific Django app che URL patterns define kele jatat.

File: api/urls.py

from django.urls import path
from . import views

urlpatterns = [

    path(
        'students/',
        views.student_list,
        name='student_list'
    ),

    path(
        'students/<int:pk>/',
        views.student_detail,
        name='student_detail'
    ),

]

Ithe don URL patterns aahet.

  • students/ – All students sathi.
  • students/1/ – Specific student sathi.

6. Dynamic URL Parameters

Dynamic URL parameter cha use URL madhun variable value view function paryant pathavnyasathi hoto.

Definition

Dynamic URL parameters allow us to capture values from a URL and pass them to a view.

Example

path(
    'students/<int:pk>/',
    views.student_detail,
    name='student_detail'
)

Example URLs

/api/students/1/
/api/students/2/
/api/students/3/

URL madhil ID view function la pk parameter madhun milto.

View Example

@api_view(['GET'])
def student_detail(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    serializer = StudentSerializer(student)

    return Response(serializer.data)

URL madhil pk value vaprun specific student fetch karto.

7. Django Path Converters

Path converters URL madhun kontya type chi value capture karaychi te define kartat.

Converter Purpose Example
str Non-empty string capture karto. <str:name>
int Positive integer capture karto. <int:id>
slug Letters, numbers, hyphens ani underscores capture karto. <slug:topic>
uuid UUID value capture karto. <uuid:id>
path Slash sahit path capture karto. <path:file_path>

Example

urlpatterns = [

    path(
        'students/<int:id>/',
        views.student_detail
    ),

    path(
        'topics/<slug:topic>/',
        views.topic_detail
    ),

]
Remember: Converter URL madhil value match ani convert karto. Tyamule view la milnari value converter chya type nusar aste.

8. URL Routing with Function-Based Views

Function-Based View la URL sobat direct connect karu shakto.

View

File: api/views.py

from rest_framework.decorators import api_view
from rest_framework.response import Response

@api_view(['GET'])
def student_list(request):

    return Response({
        "message": "Student list API"
    })

URL

File: api/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path(
        'students/',
        views.student_list,
        name='student_list'
    ),
]

FBV la connect karanyasathi function name direct pass karto.

9. URL Routing with Class-Based Views

Class-Based View la URL sobat connect karanyasathi as_view() method use karto.

View

File: api/views.py

from rest_framework.views import APIView
from rest_framework.response import Response

class StudentView(APIView):

    def get(self, request):

        return Response({
            "message": "Student API"
        })

URL

File: api/urls.py

from django.urls import path
from .views import StudentView

urlpatterns = [
    path(
        'students/',
        StudentView.as_view(),
        name='student_list'
    ),
]

What is as_view()?

as_view() hi class-based view la Django URL system madhye use karta yeil asha callable view madhye convert karte.

Remember: FBV madhye function direct pass karto. CBV madhye ClassName.as_view() use karto.

10. URL Names and Reverse URLs

URL la name dilyamule URL hardcode na karta tyacha name vaprun URL generate karta yeto.

Example URL

path(
    'students/',
    views.student_list,
    name='student_list'
)

Using reverse()

from django.urls import reverse

url = reverse('student_list')

print(url)

Output

/students/

reverse() URL name vaprun tyacha actual URL path generate karte. Project-level prefix ani namespace asel tar tyapramane output badlu shakto.

Common URL Errors

  • 404 Not Found: URL pattern match hot nahi kiwa requested record sapadat nahi.
  • ImportError: View import kartana error.
  • AttributeError: URL madhye wrong view reference.
  • TypeError: View function la expected parameters milat nahit.

  • App-level URLs specific app che routes define kartat.
  • Dynamic parameters URL madhun values capture kartat.
  • int, str, slug, uuid ani path he common converters aahet.
  • FBV la direct function name pass karto.
  • CBV sathi as_view() use karto.
  • reverse() URL name vaprun URL generate karto.
