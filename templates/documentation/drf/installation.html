DJANGO REST FRAMEWORK

07. DRF Installation and Setup

Django project madhye Django REST Framework install ani configure kase karayche te shikuya.

1. What is Installation?

Django REST Framework (DRF) he Django var based Python package aahe. Django project madhye API develop karanyasathi aapan DRF install karto.

Definition

Django REST Framework is a powerful toolkit used to build Web APIs using Django.

Why do we install DRF?

  • REST APIs create karanyasathi.
  • JSON data handle karanyasathi.
  • API authentication implement karanyasathi.
  • API permissions manage karanyasathi.
  • CRUD operations develop karanyasathi.

2. Requirements

DRF install karanyapurvi system madhye kahi basic requirements asne garjeche aahe.

Requirement Purpose
Python Programming Language
Django Web Framework
pip Python Package Installer
VS Code Code Editor
Virtual Environment Project Dependencies Manage karne

3. Create a Django Project

Sarvat aadhi terminal open karun Django project create karaycha aahe.

Step 1: Create Project Folder

mkdir drf_project
cd drf_project

mkdir: New folder create karto.
cd: Folder madhye enter karto.

Step 2: Create Virtual Environment

python -m venv venv

Virtual Environment mule project che Python packages separate manage karta yetat.

Step 3: Activate Virtual Environment

Windows CMD:

venv\Scripts\activate

PowerShell:

.\venv\Scripts\Activate.ps1

Activate zalyanantar terminal madhye (venv) disel.

Step 4: Install Django

pip install django

Step 5: Create Django Project

django-admin startproject config .

Ya command mule current folder madhye Django project create hoto.

4. Install Django REST Framework

Django install zalyanantar DRF install karanyasathi terminal madhye hi command run kara. 

pip install djangorestframework

Explanation

  • pip: Python package installer.
  • install: Package install karto.
  • djangorestframework: DRF package che nav.
Important: Command run karanyapurvi virtual environment activate aahe yachi khatri kara.

5. Add DRF to INSTALLED_APPS

DRF install zalyanantar Django la DRF app register karun dyava lagto.

File: config/settings.py 

INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',

    'rest_framework',
]

Explanation

INSTALLED_APPS madhye Django project madhye use honare applications register kele jatat.

rest_framework add kelyamule Django project madhye DRF features available hotat.

6. Verify DRF Installation

DRF successfully install zala aahe ka he check karanyasathi terminal madhye command run kara. 

pip show djangorestframework

Package chi information dislyas DRF install zala aahe ase samajta yeil.

Check Django Project

python manage.py check

Project madhye configuration errors naslyas Django system check successful message dakhavel.

7. Run Django Server

Django project run karanyasathi hi command use kara. 

python manage.py runserver

Browser madhye hi address open kara: 

http://127.0.0.1:8000/

Django project successfully run zalyas browser madhye Django welcome page disel.

8. Project Folder Structure

Installation complete zalyanantar project structure sadharanpane asa asel. 

drf_project/
│
├── venv/
│
├── config/
│   ├── __init__.py
│   ├── settings.py
│   ├── urls.py
│   ├── asgi.py
│   └── wsgi.py
│
├── manage.py
└── db.sqlite3

Important Files

  • manage.py: Django project commands run karto.
  • settings.py: Project configuration manage karto.
  • urls.py: URL routing manage karto.
  • venv: Project dependencies separate thevto.

A virtual environment is an isolated Python environment used to manage project dependencies.
