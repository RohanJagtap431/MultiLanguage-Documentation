12. API Views in DRF

API Views mhanje kay, Function-Based Views ani Class-Based Views kase work kartat te shikuya.

1. What are API Views?

API View hi Django REST Framework madhil ek view aahe. Ti client kadun request receive karte, request process karte ani response return karte.

Definition

API Views are used to handle API requests and return responses to clients in Django REST Framework.

Simple Example

Samaj mobile application la Student API madhun student chi information pahije aahe.

Client GET request pathavto. API View request process karun student cha data return karte.

Client API request pathavto
↓
API View Request process karte
↓
Response Client la data return hoto

2. Types of API Views

DRF madhye API Views create karanyasathi don commonly used approaches aahet.

1. Function-Based Views (FBV)

Function-Based Views madhye Python function vaprun API request handle keli jate.

2. Class-Based Views (CBV)

Class-Based Views madhye Python class vaprun API request handle keli jate.

Approach Used Structure
FBV Python Function
CBV Python Class

3. Function-Based Views (FBV)

Function-Based View madhye normal Python function vaprun API create keli jate.

Definition

A Function-Based View is an API view created using a Python function and the api_view decorator.

Example

File: api/views.py

from rest_framework.decorators import api_view
from rest_framework.response import Response

@api_view(['GET'])
def student_list(request):

    students = [
        {
            "id": 1,
            "name": "Rohan"
        },
        {
            "id": 2,
            "name": "Amit"
        }
    ]

    return Response(students)

Code Explanation

  • api_view: API view create karanyasathi decorator.
  • @api_view(['GET']): View GET request accept karte.
  • student_list: API view function.
  • request: Client kadun aaleli request.
  • Response: Client la API response return karto.

4. What is @api_view() Decorator?

@api_view() ha DRF madhil decorator aahe. To normal Django function la API view madhye convert karanyasathi use hoto.

Example

@api_view(['GET'])
def student_list(request):
    return Response({
        "message": "Student list"
    })

Multiple HTTP Methods

Ekach function madhye multiple HTTP methods allow karu shakto. 

@api_view(['GET', 'POST'])
def student_list(request):

    if request.method == 'GET':
        return Response({
            "message": "Get students"
        })

    elif request.method == 'POST':
        return Response({
            "message": "Create student"
        })

Ithe function GET ani POST donhi requests accept karte.

Remember: @api_view() madhye allow kelelya methods vyatirikta dusri method request keli tar DRF 405 Method Not Allowed response return karte.

5. Class-Based Views (CBV)

Class-Based View madhye Python class vaprun API requests handle kelya jatat.

Definition

A Class-Based View is an API view created using a Python class to handle HTTP methods.

Example using APIView

File: api/views.py

from rest_framework.views import APIView
from rest_framework.response import Response

class StudentView(APIView):

    def get(self, request):

        return Response({
            "message": "Get students"
        })

    def post(self, request):

        return Response({
            "message": "Create student"
        })

Code Explanation

  • APIView: DRF madhil base class.
  • StudentView: Aapli API class.
  • get(): GET request handle karte.
  • post(): POST request handle karte.
  • Response(): API response return karte.

6. What is APIView?

APIView hi Django REST Framework madhil base class aahe. Aapan ya class la inherit karun swatachi API view class create karu shakto.

Definition

APIView is a base class provided by DRF for creating class-based API views.

Basic Structure

from rest_framework.views import APIView
from rest_framework.response import Response

class MyAPIView(APIView):

    def get(self, request):
        return Response({
            "message": "GET request"
        })

    def post(self, request):
        return Response({
            "message": "POST request"
        })

APIView madhye HTTP method pramane vegveglya methods define karta yetat.

7. FBV vs CBV

FBV CBV
Function use hote. Class use hote.
@api_view decorator use hoto. APIView inherit keli jate.
HTTP methods request.method ne check karu shakto. GET sathi get(), POST sathi post() method aste.
Simple APIs sathi useful. Structured APIs sathi useful.
Function-based approach. Object-oriented approach.

8. Configure API URLs

API view create kelyanantar tila URL sobat connect karave lagte.

File: api/urls.py

Function-Based View URL

from django.urls import path
from . import views

urlpatterns = [
    path(
        'students/',
        views.student_list,
        name='student_list'
    ),
]

Class-Based View URL

from django.urls import path
from .views import StudentView

urlpatterns = [
    path(
        'students/',
        StudentView.as_view(),
        name='student_list'
    ),
]

Class-Based View la URL sobat connect karanyasathi as_view() use karto.

Important: FBV ani CBV donhi sathi same URL path use karat aslyas ekach view route active theva. Donhi examples ekach urlpatterns madhye duplicate karu naka.

9. When to Use FBV and CBV?

Use FBV When:

  • API simple asel.
  • Limited HTTP methods handle karayche astil.
  • Simple function-based logic lihaycha asel.

Use CBV When:

  • API madhye multiple HTTP methods astil.
  • Code structured thevaycha asel.
  • Class inheritance cha use karaycha asel.
  • Common behavior reuse karaycha asel.

Donhi approaches useful aahet. Project chya requirements nusar approach select karava.
