DJANGO REST FRAMEWORK

10. ModelSerializer

Django Model vaprun Serializer automatically kasa create karaycha te practical example sobat shikuya.

1. What is ModelSerializer?

ModelSerializer ha Django REST Framework madhil ek special Serializer class aahe.

Ha Django Model madhil fields cha use karun automatically serializer fields create karto.

Definition

ModelSerializer is a shortcut class that automatically creates serializer fields based on a Django model.

Simple Example

Samaj aaplyakade Student model aahe. Tyache fields manually Serializer madhye define karanyachi garaj nahi.

ModelSerializer model madhun fields automatically generate karu shakto.

2. Why do we use ModelSerializer?

ModelSerializer mule API development madhye code kami lihava lagto.

  • Model fields automatically generate hotat.
  • Field types automatically determine hotat.
  • Basic validation rules generate hotat.
  • Model objects create karne sope hote.
  • Model objects update karne sope hote.
Remember: ModelSerializer ha Django Model sobat work karto. Simple Serializer madhye aaplyala fields manually define karave lagtat.

3. Create a Student Model

Sarvat aadhi aaplyala Django Model create karava lagel.

File: api/models.py

Code

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)

    age = models.IntegerField()

    course = models.CharField(max_length=100)

    email = models.EmailField()

    def __str__(self):
        return self.name

Code Explanation

  • Student: Model class aahe.
  • name: Student che nav store karto.
  • age: Student che vay store karto.
  • course: Course store karto.
  • email: Email address store karto.
  • __str__(): Object che readable name return karto.

Run Migrations

4. Create a ModelSerializer

Ata Student model sathi ModelSerializer create karu.

File: api/serializers.py

Code

from rest_framework import serializers
from .models import Student

class StudentSerializer(serializers.ModelSerializer):

    class Meta:
        model = Student
        fields = '__all__'

Code Explanation

  • ModelSerializer: Model-based serializer create karto.
  • Student: Aapla Django model.
  • Meta: Serializer configuration define karte.
  • model: Konta Django model use karaycha te sangte.
  • fields: Kontya model fields serializer madhye include karaychya te sangte.
Remember: ModelSerializer madhye model ani fields he Meta class madhye define karave lagtat.

5. What is Meta Class?

Meta hi Serializer madhil nested configuration class aahe. Tichya madhye serializer che settings define kele jatat.

Example

class StudentSerializer(serializers.ModelSerializer):

    class Meta:
        model = Student
        fields = '__all__'

Ithe Meta class Django la sangte ki Student model use karaycha ani tyache sagle fields include karayche.

6. fields = '__all__'

fields = '__all__' mule model madhil sarva eligible fields serializer madhye include hotat.

Example

class Meta:
    model = Student
    fields = '__all__'

Aaplya Student model madhye name, age, course ani email he fields aahet. Te sagle serializer madhye include hotil. Database madhil automatic id field suddha include hoil.

7. Select Specific Fields

Aaplyala model madhil sarva fields nako astil, tar specific fields select karta yetat.

Example

class Meta:
    model = Student
    fields = ['id', 'name', 'course']

Ata serializer fakt id, name ani course fields include karel.

Remember: fields madhye je fields define kele aahet, fakt tech serializer output madhye yetil.

8. read_only_fields

read_only_fields cha use kahi fields fakt response madhye dakhavnyasathi hoto.

Read-only field la incoming data madhun create kiwa update karta yet nahi.

Example

class Meta:
    model = Student
    fields = '__all__'
    read_only_fields = ['id']

Ithe id field API response madhye disel, pan client request madhun id change karta yenar nahi.

9. Serializer vs ModelSerializer

Serializer ModelSerializer
Fields manually define karave lagtat. Model madhun fields automatically generate hotat.
Django Model compulsory nahi. Django Model required aahe.
More manual code. Less manual code.
create() ani update() logic swatah lihava lagu shakto. Basic model create ani update support built-in asto.

10. Use ModelSerializer in API View

Ata ModelSerializer vaprun database madhil Student data API madhun return karu.

File: api/views.py

Code

from rest_framework.decorators import api_view
from rest_framework.response import Response
from .models import Student
from .serializers import StudentSerializer

@api_view(['GET'])
def student_list(request):

    students = Student.objects.all()

    serializer = StudentSerializer(
        students,
        many=True
    )

    return Response(serializer.data)

Code Explanation

  • Student.objects.all(): Database madhil sarva students retrieve karto.
  • many=True: Multiple model objects serialize karanyasathi use hoto.
  • StudentSerializer: Student objects serialize karto.
  • serializer.data: Serialized output return karto.
  • Response(): API response pathavto.
Important: Single object serialize kartana many=True lagat nahi. Multiple objects serialize kartana many=True use kara.

12. Important ModelSerializer Options

Option Purpose
model Model select karto.
fields Serializer madhye fields select karto.
exclude Kahi model fields exclude karto.
read_only_fields Fields read-only banavto.
extra_kwargs Existing fields che extra options configure karto.

Example: exclude

class Meta:
    model = Student
    exclude = ['email']

Ithe email field serializer madhun exclude hoil. fields ani exclude donhi ekach Meta class madhye use karu naye.

14. Interview Questions

Q1. What is ModelSerializer?

ModelSerializer is a DRF class that automatically creates serializer fields based on a Django model.

Q2. What is the purpose of the Meta class?

Meta class defines serializer configuration such as model and fields.

Q3. What is fields = '__all__'?

It includes all eligible fields of the model in the serializer.

Q4. What are read_only_fields?

They are fields that can be included in output but cannot be modified through incoming data.

Q5. What is many=True?

It is used when serializing multiple objects with the same serializer.
