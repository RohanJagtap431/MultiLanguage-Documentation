33. API Testing in DRF

Learn how to test REST APIs using Django and Django REST Framework testing tools.

1. What is API Testing?

API Testing mhanje API yogya prakare kaam karte ka, request accept karte ka ani expected response dete ka he check karne.

Definition

API Testing is the process of checking whether an API works correctly by sending requests and verifying responses.

Example

Samja Student API madhye GET request pathavli. Tar API students chi list return karte ka he test karne mhanje API Testing.

API Testing Process

Test Case
    |
    v
Send API Request
    |
    v
Receive API Response
    |
    v
Check Status Code
    |
    v
Verify Response Data
    |
    v
Test Passed / Failed

Why is API Testing Important?

  • API madhil errors shodhnyasathi.
  • API expected output dete ka he check karanyasathi.
  • CRUD operations test karanyasathi.
  • Authentication ani permissions check karanyasathi.
  • Code changes mule existing features break hot nahit he check karanyasathi.

2. Django TestCase

Django madhye TestCase class cha use automated tests lihinyasathi hoto.

Definition

TestCase is a Django testing class used to write and execute automated test cases.

Import

from django.test import TestCase

Example

File: api/tests.py

from django.test import TestCase


class StudentTest(TestCase):

    def test_example(self):

        result = 10 + 20

        self.assertEqual(result, 30)

Explanation

  • TestCase testing class aahe.
  • test_ pasun suru honari method test mhanun run hote.
  • assertEqual expected ani actual value compare karte.

3. What is APITestCase?

APITestCase hi Django REST Framework madhil testing class aahe.

Definition

APITestCase is used to write tests for REST APIs by providing an API test client.

Import

from rest_framework.test import APITestCase

Example

from rest_framework.test import APITestCase


class StudentAPITest(APITestCase):

    def test_example(self):

        self.assertEqual(5, 5)

APITestCase madhye API requests pathvun response test karta yeto.

4. What is APIClient?

APIClient cha use test madhun API la GET, POST, PUT, PATCH ani DELETE requests pathavnyasathi hoto.

Definition

APIClient is a testing tool provided by DRF to send API requests without running a real server.

Import

from rest_framework.test import APIClient

Example

from rest_framework.test import APIClient

client = APIClient()

response = client.get('/api/students/')

Common APIClient Methods

Method Purpose
client.get() GET request send karte.
client.post() POST request send karte.
client.put() PUT request send karte.
client.patch() PATCH request send karte.
client.delete() DELETE request send karte.

5. GET Request Testing

GET request test karun API students chi list return karte ka he check karta yete.

Example

File: api/tests.py

from rest_framework.test import APITestCase
from rest_framework import status

from .models import Student


class StudentAPITest(APITestCase):

    def test_get_students(self):

        Student.objects.create(name="Rohan")

        response = self.client.get('/api/students/')

        self.assertEqual(
            response.status_code,
            status.HTTP_200_OK
        )

        self.assertEqual(len(response.data), 1)

Explanation

  • Student.objects.create() test database madhye student create karte.
  • self.client.get() GET request pathavte.
  • HTTP_200_OK success response check karte.
  • len(response.data) returned records count check karte.

6. POST Request Testing

POST request test karun API navin student create karte ka he check karta yete.

Example

def test_create_student(self):

    data = {
        "name": "Rohan"
    }

    response = self.client.post(
        '/api/students/',
        data,
        format='json'
    )

    self.assertEqual(
        response.status_code,
        status.HTTP_201_CREATED
    )

    self.assertEqual(
        Student.objects.count(),
        1
    )

Explanation

  • data madhye student information aste.
  • self.client.post() POST request pathavte.
  • format='json' request JSON format madhye pathavte.
  • HTTP_201_CREATED successful creation check karte.
  • Student.objects.count() database madhil records count check karte.

7. PUT and PATCH Request Testing

PUT ani PATCH requests existing student information update karanyasathi vapartat.

Method Purpose
PUT Resource replace/update karanyasathi.
PATCH Resource madhil specific fields update karanyasathi.

PUT Example

def test_update_student(self):

    student = Student.objects.create(name="Rohan")

    data = {
        "name": "Rahul"
    }

    response = self.client.put(
        f'/api/students/{student.id}/',
        data,
        format='json'
    )

    self.assertEqual(
        response.status_code,
        status.HTTP_200_OK
    )

    student.refresh_from_db()

    self.assertEqual(student.name, "Rahul")

PATCH Example

def test_partial_update_student(self):

    student = Student.objects.create(name="Rohan")

    data = {
        "name": "Amit"
    }

    response = self.client.patch(
        f'/api/students/{student.id}/',
        data,
        format='json'
    )

    self.assertEqual(
        response.status_code,
        status.HTTP_200_OK
    )

    student.refresh_from_db()

    self.assertEqual(student.name, "Amit")

refresh_from_db() database madhun updated information parat load karte.

8. DELETE Request Testing

DELETE request test karun API student record delete karte ka he check karta yete.

Example

def test_delete_student(self):

    student = Student.objects.create(name="Rohan")

    response = self.client.delete(
        f'/api/students/{student.id}/'
    )

    self.assertEqual(
        response.status_code,
        status.HTTP_204_NO_CONTENT
    )

    self.assertEqual(
        Student.objects.count(),
        0
    )

Explanation

  • Student.objects.create() student create karte.
  • self.client.delete() DELETE request pathavte.
  • HTTP_204_NO_CONTENT successful deletion check karte.
  • Student.objects.count() record delete zala ka te check karte.

9. Authentication Testing

Authentication Testing madhye API authorized user la access dete ka ani unauthenticated user la restrict karte ka he check kele jate.

Example – Force Authentication

from django.contrib.auth import get_user_model
from rest_framework.test import APITestCase
from rest_framework import status

User = get_user_model()


class AuthenticationTest(APITestCase):

    def test_authenticated_access(self):

        user = User.objects.create_user(
            username="rohan",
            password="testpass123"
        )

        self.client.force_authenticate(user=user)

        response = self.client.get('/api/students/')

        self.assertEqual(
            response.status_code,
            status.HTTP_200_OK
        )

Explanation

  • create_user() test user create karte.
  • force_authenticate() test request sathi user authenticate karte.
  • GET request protected API la pathavli jate.
  • HTTP_200_OK access successful aahe ka te check karte.
Important: force_authenticate() testing sathi aahe. Actual login ani token authentication flow test karanyasathi real credentials kiwa token vapra.
