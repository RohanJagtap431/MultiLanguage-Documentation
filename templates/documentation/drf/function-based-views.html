13. Function-Based Views (FBV)

Learn how to create CRUD APIs using Function-Based Views in Django REST Framework.

1. What is Function-Based View?

Function-Based View (FBV) hi normal Python function aste. DRF madhye @api_view() decorator vaprun aapan function la API View banavu shakto.

Definition

A Function-Based View is an API view created using a Python function and the @api_view() decorator.

Basic Syntax

from rest_framework.decorators import api_view
from rest_framework.response import Response

@api_view(['GET'])
def my_api(request):

    return Response({
        "message": "Hello API"
    })

How it works

Client Request pathavto
↓
@api_view() Allowed method check karto
↓
Python Function Request process karte
↓
Response Client la result milto

2. The @api_view() Decorator

@api_view() decorator API madhye kontya HTTP methods allow aahet te specify karto.

Example

@api_view(['GET'])
def student_list(request):
    pass

Ya example madhye API fakt GET request accept karte.

Allow Multiple Methods

@api_view(['GET', 'POST'])
def student_list(request):
    pass

Ya API madhye GET ani POST donhi methods allow aahet.

Important: API ne allow na keleli HTTP method request keli tar DRF 405 Method Not Allowed response return karte.

3. HTTP Methods in FBV

Method Purpose Example

POST New data create karne Student add karne
PUT Complete data update karne Student details replace karne
PATCH Partial data update karne Fakt student name change karne

5. GET Method – Read Data

GET method database madhun student records fetch karanyasathi use hote.

File: api/views.py

from rest_framework.decorators import api_view
from rest_framework.response import Response

from .models import Student
from .serializers import StudentSerializer

@api_view(['GET'])
def student_list(request):

    students = Student.objects.all()

    serializer = StudentSerializer(
        students,
        many=True
    )

    return Response(serializer.data)

Explanation

  • Student.objects.all(): Sarve students fetch karte.
  • many=True: Multiple objects serialize karte.
  • serializer.data: Serialized data return karto.
  • Response(): API response pathavto.

6. POST Method – Create Data

POST method database madhye navin student record create karanyasathi use hote. 

@api_view(['POST'])
def student_create(request):

    serializer = StudentSerializer(
        data=request.data
    )

    if serializer.is_valid():
        serializer.save()

        return Response(
            serializer.data,
            status=201
        )

    return Response(
        serializer.errors,
        status=400
    )

Explanation

  • request.data: Client kadun aalela data.
  • is_valid(): Data validation karte.
  • serializer.save(): Valid data database madhye save karto.
  • serializer.errors: Validation errors return karto.

POST Request Body

{
    "name": "Rohan",
    "email": "rohan@example.com",
    "age": 20
}

Data successfully create zalyas HTTP 201 Created response milto.

7. PUT Method – Update Complete Data

PUT method existing student cha complete data update karanyasathi use hote. 

from django.shortcuts import get_object_or_404

@api_view(['PUT'])
def student_update(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    serializer = StudentSerializer(
        student,
        data=request.data
    )

    if serializer.is_valid():
        serializer.save()

        return Response(serializer.data)

    return Response(
        serializer.errors,
        status=400
    )

Example Request Body

{
    "name": "Rohan Jagtap",
    "email": "rohan@example.com",
    "age": 21
}
Remember: PUT madhye serializer la partial=True dilele nahi. Mhanun required fields complete pathavane apekshit aste.

8. PATCH Method – Update Partial Data

PATCH method existing record madhil fakt kahi fields update karanyasathi use hote. 

@api_view(['PATCH'])
def student_partial_update(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    serializer = StudentSerializer(
        student,
        data=request.data,
        partial=True
    )

    if serializer.is_valid():
        serializer.save()

        return Response(serializer.data)

    return Response(
        serializer.errors,
        status=400
    )

Example Request Body

{
    "age": 22
}

Ithe fakt age update hoil. Name ani email change honar nahit.

Important: PATCH madhye partial=True use karane mahatvache aahe. Tyamule required naslele fields pathavnyachi garaj naste.

9. DELETE Method – Delete Data

DELETE method database madhun existing student record delete karanyasathi use hote. 

@api_view(['DELETE'])
def student_delete(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    student.delete()

    return Response(
        {"message": "Student deleted successfully"},
        status=200
    )

Explanation

  • get_object_or_404(): Student sapadla nahi tar 404 return karte.
  • student.delete(): Database madhun record delete karte.
  • status=200: Success response return karto.

10. Complete CRUD Views

Ata GET ani POST ekach function madhye ani PUT, PATCH, DELETE dusrya function madhye handle karu shakto.

File: api/views.py

from django.shortcuts import get_object_or_404

from rest_framework.decorators import api_view
from rest_framework.response import Response

from .models import Student
from .serializers import StudentSerializer


@api_view(['GET', 'POST'])
def student_list(request):

    if request.method == 'GET':

        students = Student.objects.all()

        serializer = StudentSerializer(
            students,
            many=True
        )

        return Response(serializer.data)

    elif request.method == 'POST':

        serializer = StudentSerializer(
            data=request.data
        )

        if serializer.is_valid():
            serializer.save()

            return Response(
                serializer.data,
                status=201
            )

        return Response(
            serializer.errors,
            status=400
        )


@api_view(['GET', 'PUT', 'PATCH', 'DELETE'])
def student_detail(request, pk):

    student = get_object_or_404(
        Student,
        pk=pk
    )

    if request.method == 'GET':

        serializer = StudentSerializer(student)

        return Response(serializer.data)

    elif request.method == 'PUT':

        serializer = StudentSerializer(
            student,
            data=request.data
        )

    elif request.method == 'PATCH':

        serializer = StudentSerializer(
            student,
            data=request.data,
            partial=True
        )

    elif request.method == 'DELETE':

        student.delete()

        return Response(
            {"message": "Student deleted"},
            status=200
        )

    if serializer.is_valid():
        serializer.save()

        return Response(serializer.data)

    return Response(
        serializer.errors,
        status=400
    )
Note: Ha complete CRUD code aahe. Separate GET, POST, PUT, PATCH ani DELETE examples samjun ghetlyanantar ha combined code vapra. Donhi versions ekach URL var duplicate register karu naka.

15. Interview Questions

Q1. What is FBV in DRF?

FBV is an API view created using a Python function and the @api_view() decorator.

Q2. What is the use of request.data?

request.data is used to access the data sent by the client in an API request.

Q3. What is the difference between PUT and PATCH?

PUT updates the complete resource, whereas PATCH updates only selected fields.

Q4. What is partial=True?

partial=True allows a serializer to update selected fields without requiring every field.

Q5. What is get_object_or_404()?

It returns the requested object or raises an HTTP 404 error if the object does not exist.

Q6. What is CRUD?

CRUD stands for Create, Read, Update and Delete.
