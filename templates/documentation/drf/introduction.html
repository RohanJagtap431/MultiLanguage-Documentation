DJANGO REST FRAMEWORK

01. Introduction to Django REST Framework

DRF agdi basic pasun shika. API, REST API ani Django REST Framework simple Roman Marathi madhye samjun ghya.

1. What is API?

API cha full form Application Programming Interface asa aahe.

API he don software applications madhye communication karanyasathi vaparla janara madhyam aahe.

Definition

API is an interface that allows two software applications to communicate with each other.

Simple Example

Samaj tu restaurant madhye jevayla gela aahes. Tula Pizza order karaycha aahe.

  • Tu waiter la order sangtos.
  • Waiter kitchen madhye order deto.
  • Kitchen pizza tayar karte.
  • Waiter pizza tujhya table var anto.

Ithe waiter customer ani kitchen yanchyamadhye communication karto.

Software madhye API suddha asech communication karte.

Remember: Frontend → API → Backend → Database

2. Why Do We Need API?

Samaj aaplyakade ek Student Management Website aahe. Ya website madhye students chi mahiti database madhye save aahe.

Ata aaplyala tyach students chi mahiti Android Mobile App madhye suddha dakhvaychi aahe.

Tyasathi mobile app backend la request pathavel. Backend API chya madhyamatun student data return karel.

Example

Mobile App Request:

GET /api/students/

Server Response:

[
    {
        "id": 1,
        "name": "Rahul",
        "course": "BSc Computer Science"
    },
    {
        "id": 2,
        "name": "Amit",
        "course": "BCA"
    }
]

Mhanje website ani mobile app donhi ekach backend madhun data gheu shaktat.

3. What is REST API?

REST cha full form Representational State Transfer aahe.

REST hi API design karanyachi architectural style aahe. REST API madhye client server la request pathavto ani server response deto.

Definition

REST API is an API that follows the principles of Representational State Transfer.

REST API Example

GET /api/students/

Ya request cha arth server kadun students chi list magne. 

POST /api/students/

Ya request cha arth navin student create karanyasathi data pathavne.

Important: REST API madhye GET, POST, PUT, PATCH ani DELETE sarkhe HTTP methods vapartat. He aapan pudhil topic madhye detail madhye shiku.

4. What is Django REST Framework?

Django REST Framework cha short form DRF aahe.

DRF he Django madhil ek powerful toolkit aahe. Tyacha use karun aapan Web APIs ani REST APIs tayar karu shakto.

Definition

Django REST Framework is a powerful toolkit used to build Web APIs using Django.

DRF cha use kuthe hoto?

  • Student Management API
  • User Registration API
  • Login API
  • Product API
  • Blog API
  • Mobile Application Backend

5. Django vs Django REST Framework

Django ani DRF he vegvegale frameworks nahit. DRF he Django sobat vaparla janara toolkit aahe.

Django Django REST Framework
Full Web Framework API Toolkit
HTML Pages render karto API Responses provide karto
Django Templates vaparto Serializers vaparto
Traditional Web Forms API Requests
Web Applications REST API Applications
Remember: Django vaprun website banavta yete. DRF vaprun tyach Django backend madhun API banavta yete.

6. How Does API Work?

API madhye client ani server yanchyamadhye request ani response exchange hoto.

Client Request pathavto
↓
API Request receive karte
↓
Backend Logic execute karto
↓
Database Data provide karte
↓
Response Client la result milto
  1. Client server la request pathavto.
  2. API request receive karte.
  3. Backend required logic execute karto.
  4. Database madhun data milto.
  5. Server client la response pathavto.

7. Advantages of Django REST Framework

  • REST APIs easily build karta yetat.
  • JSON data handle karta yeto.
  • Built-in authentication support milto.
  • Permission system available aahe.
  • API testing sathi Browsable API milte.
  • Serialization ani validation soppe hote.
  • Frontend ani mobile apps sobat connect karta yete.
