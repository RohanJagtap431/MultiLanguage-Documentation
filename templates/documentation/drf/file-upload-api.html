32. File Upload API in DRF

Learn how to upload files and images through Django REST Framework APIs.

1. What is File Upload?

File Upload mhanje client kadun server var image, PDF, document kiwa other files pathavne.

Definition

File Upload is the process of sending files from a client to a server through an API.

Example

Samja Student API madhye student cha profile photo upload karaycha aahe.

File Upload Process

Client
   |
   | Select Image
   |
   v
Django REST API
   |
   | Validate File
   |
   v
Server Media Storage
   |
   v
Image URL Response

Common File Types

  • Images – JPG, PNG
  • Documents – PDF, DOCX
  • Text Files – TXT
  • Other files – as allowed by the application

2. FileField and ImageField

Django models madhye files ani images store karanyasathi FileField ani ImageField vapartat.

Field Purpose
FileField Different types of files upload karanyasathi.
ImageField Image files upload karanyasathi.

Example – Student Model

File: api/models.py

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)

    profile_photo = models.ImageField(
        upload_to='students/',
        blank=True,
        null=True
    )

    document = models.FileField(
        upload_to='documents/',
        blank=True,
        null=True
    )

Explanation

  • ImageField image upload karanyasathi vapartat.
  • FileField general file upload karanyasathi vapartat.
  • upload_to file store honyacha subfolder define karte.
  • blank=True mule form madhye field optional aste.
  • null=True mule database madhye empty value allow hote.
Important: ImageField vaparnyasathi Pillow package install asne avashyak aahe. 
pip install Pillow

3. What is MultiPartParser?

MultiPartParser ha DRF madhil parser aahe. To multipart/form-data format madhun uploaded files ani form data read karto.

Definition

MultiPartParser parses multipart form data, including uploaded files.

Import

from rest_framework.parsers import MultiPartParser

Example

from rest_framework.parsers import MultiPartParser

class StudentViewSet(ModelViewSet):

    parser_classes = [MultiPartParser]

Ya parser mule API multipart/form-data request madhil uploaded files process karu shakte.

4. What is FormParser?

FormParser ha DRF madhil parser aahe. To application/x-www-form-urlencoded format madhil form data parse karto.

Import

from rest_framework.parsers import FormParser

Use Both Parsers

from rest_framework.parsers import (
    MultiPartParser,
    FormParser
)

class StudentViewSet(ModelViewSet):

    parser_classes = [
        MultiPartParser,
        FormParser
    ]

MultiPartParser ani FormParser ekatra use kelyas API multipart form data ani URL-encoded form data accept karu shakte.

5. Serializer with FileField

Serializer cha use model fields ani uploaded file data validate karun API madhye represent karanyasathi hoto.

Example

File: api/serializers.py

from rest_framework import serializers
from .models import Student

class StudentSerializer(serializers.ModelSerializer):

    class Meta:
        model = Student
        fields = [
            'id',
            'name',
            'profile_photo',
            'document'
        ]

ModelSerializer model madhil ImageField ani FileField automatically serializer madhye include karto.

6. File Upload API View

Ata aapan Student API madhye file upload support add karuya.

Example

File: api/views.py

from rest_framework.viewsets import ModelViewSet
from rest_framework.parsers import (
    MultiPartParser,
    FormParser
)

from .models import Student
from .serializers import StudentSerializer


class StudentViewSet(ModelViewSet):

    queryset = Student.objects.all()
    serializer_class = StudentSerializer

    parser_classes = [
        MultiPartParser,
        FormParser
    ]

Explanation

  • ModelViewSet CRUD operations provide karte.
  • StudentSerializer file fields handle karte.
  • parser_classes uploaded files parse karte.
  • Uploaded files model madhye save hotat.

7. Media Settings in Django

Uploaded files store ani serve karanyasathi Django madhye MEDIA_ROOT ani MEDIA_URL configure karave lagtat.

Step 1 – Configure settings.py

File: config/settings.py

MEDIA_URL = '/media/'

MEDIA_ROOT = BASE_DIR / 'media'

Explanation

  • MEDIA_ROOT server var uploaded files store honyachi directory aahe.
  • MEDIA_URL uploaded media files access karanyasathi URL prefix aahe.

Step 2 – Configure urls.py

File: config/urls.py

from django.conf import settings
from django.conf.urls.static import static
from django.urls import path, include

urlpatterns = [
    path('api/', include('api.urls')),
]

if settings.DEBUG:
    urlpatterns += static(
        settings.MEDIA_URL,
        document_root=settings.MEDIA_ROOT
    )
Note: static() configuration hi development sathi aahe. Production madhye media files serve karanyasathi proper storage service kiwa web server configure kara.

8. Upload File Using Postman

Postman cha use karun aapan API madhye image kiwa document upload karu shakto.

Steps

  1. Postman open kara.
  2. Student API URL enter kara.
  3. HTTP method POST select kara.
  4. Body tab open kara.
  5. form-data select kara.
  6. name field madhye student name enter kara.
  7. profile_photo field add kara ani type File select kara.
  8. document field add karun File select kara.
  9. File select karun Send click kara.

Example Request

POST /api/students/

Body: form-data

document      File    certificate.pdf

Postman madhye Content-Type manually set karu naka. form-data select kelyavar Postman multipart boundary sahit header automatically set karto.

10. File Upload Validation

API madhye file upload kartana file size ani file type validate karne mahatvache aahe.

Example – Image Extension Validation

File: api/serializers.py

from rest_framework import serializers
from .models import Student


class StudentSerializer(serializers.ModelSerializer):

    def validate_profile_photo(self, value):

        allowed_extensions = ['jpg', 'jpeg', 'png']

        extension = value.name.rsplit('.', 1)[-1].lower()

        if extension not in allowed_extensions:
            raise serializers.ValidationError(
                "Only JPG and PNG images are allowed."
            )

        return value

    class Meta:
        model = Student
        fields = [
            'id',
            'name',
            'profile_photo',
            'document'
        ]
Security Note: File extension check karne evdhach purase nahi. Production madhye file size, actual file content, MIME type ani secure storage suddha validate kara.
