HTML Forms

HTML Forms vaprun website var user kadun information collect karne ani server kade submit karne ya lesson madhye shikuya.

Beginner Level 40–45 Minutes

1. What are HTML Forms?

HTML Form cha use website var user kadun information collect karnyasathi hoto.

User form madhye information enter karto ani Submit button click karun ti information server kade pathavu shakto.

Examples:

  • Registration Form
  • Login Form
  • Contact Form
  • Feedback Form
  • Search Form
  • Job Application Form
Simple Definition: HTML Form mhanje user kadun data collect karnyasathi vaparla janara HTML structure.

2. HTML Form Elements

HTML Form create karnyasathi different elements vapartat.

Element Purpose
<form> Form create karto.
<input> User kadun input gheto.
<label> Input field la label dete.
<textarea> Multiple lines text input ghete.
<button> Button create karto.
<select> Dropdown list create karto.
<option> Dropdown madhil option define karto.
<fieldset> Related form controls group karto.
<legend> Fieldset la title dete.

3. Form Element

form element cha use HTML madhye form create karnyasathi hoto.

Syntax:


<form>

    Form Elements

</form>

Example:


<form>

    <label>Name:</label>

    <input type="text">

    <button type="submit">
        Submit
    </button>

</form>

Tip: Form element ha form madhil inputs ani controls cha parent container asto.

4. Input Element

input element cha use user kadun information receive karnyasathi hoto.

Input element madhil type attribute nusar input field cha behavior change hoto.

<input type="text">

Example:

label element cha use Input Field la meaningful name kiwa description denyasathi hoto.

label chya for attribute chi value ani input chya id chi value same asavi.

Example:


<label for="username">
    Username:
</label>

<input type="text" id="username">

Output:

Explanation:

  • label user la field cha purpose samjavte.
  • for attribute input chya id sobat connect hote.
  • Label click kelyavar connected input focus hoto.
Important: Accessibility sathi pratyek important input la proper label dene recommended aahe.

6. Textarea Element

textarea element cha use user kadun multiple lines text receive karnyasathi hoto.

Long messages, comments ani feedback collect karnyasathi textarea useful aahe.

Syntax:


<textarea></textarea>

Example:


<label for="message">Message:</label>

<textarea
    id="message"
    name="message"
    rows="5"
    cols="30"
    placeholder="Enter your message">
</textarea>

Output:

Important Attributes:

  • rows = Textarea madhil visible rows specify karte.
  • cols = Approximate visible character width specify karte.
  • placeholder = Hint text display karte.
  • name = Submitted data cha field name specify karte.

9. Action Attribute

action attribute specify karto ki Form submit zalyavar data kontya URL kade pathavaycha aahe.

Syntax:


<form action="/register/">

    Form Fields

</form>

Example:


<form action="/register/" method="post">

    <input type="text" name="username">

    <button type="submit">
        Register
    </button>

</form>

Ya example madhye form submit zalyavar data /register/ URL kade pathavla jato.

Important: HTML madhil action attribute fakt destination specify karto. Actual data processing server-side application karte.

10. Method Attribute

method attribute specify karto ki Form data server kade kontya HTTP method ne pathavla jail.

Commonly GET ani POST methods vapartat.

GET Method:

GET method madhye form data URL chya query parameters madhye pathavla jato.

Example:


<form action="/search/" method="get">

    <input type="text" name="query">

    <button type="submit">
        Search
    </button>

</form>

Example URL: 


/search/?query=python

POST Method:

POST method madhye form data HTTP request body madhye pathavla jato.

Example:


<form action="/register/" method="post">

    <input type="text" name="username">

    <button type="submit">
        Register
    </button>

</form>

GET vs POST:

GET POST
Data URL query parameters madhye jato. Data request body madhye jato.
Search ani data retrieval sathi common. Data submit ani create karnyasathi common.
URL madhye data visible asu shakto. Data URL madhye normally visible nasto.
URL bookmark kiwa share karta yete. Normal form submission madhye URL query data nasato.
Security Note: POST method mhanje data automatically secure hot nahi. Sensitive data sathi HTTPS, server-side validation ani proper security required aahe.

11. Name Attribute

name attribute form field cha name specify karto. Form submit hotana data identify karnyasathi name attribute important aahe.

Example:


<form>

    <input type="text" name="username">

    <input type="email" name="email">

</form>

Explanation:

  • username = First input cha field name.
  • email = Second input cha field name.
  • Server form data name nusar access karu shakto.
Important: name attribute nasel tar normal form submission madhye tya input chi value form data madhye include hot nahi.

14. Required, Readonly and Disabled

Ya attributes cha use Form fields var specific restrictions apply karnyasathi hoto.

Required:

required attribute mule field fill karne compulsory hote. 


<input type="text" required>

Readonly:

readonly field madhil value user change karu shakat nahi. Pan field form submission madhye include hou shakto. 


<input type="text" value="Rohan" readonly>

Disabled:

disabled field inactive asto ani normal form submission madhye include hot nahi. 


<input type="text" value="Rohan" disabled>

Output:

Attribute User Editing Submitted Normally?
required Allowed Yes, if valid
readonly Not allowed Yes
disabled Not allowed No

16. Complete Registration Form

Ata apan previously shiklele Form elements vaprun ek simple Registration Form create karu.

<h1>Student Registration</h1>

<form action="/register/" method="post">

    <label for="name">Full Name:</label>
    <input type="text"
           id="name"
           name="name"
           placeholder="Enter your name"
           required>

    <label for="email">Email:</label>
    <input type="email"
           id="email"
           name="email"
           placeholder="Enter your email"
           required>

    <label for="password">Password:</label>
    <input type="password"
           id="password"
           name="password"
           required>

    <label for="course">Course:</label>

    <select id="course" name="course" required>
        <option value="">Select Course</option>
        <option value="bsc">BSc CS</option>
        <option value="bca">BCA</option>
    </select>

    <label for="address">Address:</label>

    <textarea id="address"
              name="address"
              rows="4"></textarea>

    <button type="submit">
        Register
    </button>

    <button type="reset">
        Reset
    </button>

</form>

Output:

Student Registration

Ha demonstration form aahe. Yatil data kontyahi server kade submit hot nahi.

Explanation:

  • form element complete registration form create karto.
  • label fields chi information dete.
  • input user kadun name, email ani password gheto.
  • select user la course choose karu deto.
  • textarea address enter karnyasathi aahe.
  • submit button form submit karnyasathi vapartat.
  • reset button form fields reset karto.

17. HTML Form and Django Backend

HTML Form ha Django Backend Developer sathi important concept aahe.

User form submit karto. Browser HTTP request Django server kade pathavto. Django view request madhil data process karu shakto.

Simple Django Example:


# views.py

from django.shortcuts import render

def register(request):

    if request.method == "POST":

        username = request.POST.get("username")

        email = request.POST.get("email")

        print(username, email)

    return render(request, "register.html")

HTML Form:


<form method="post">

    {% csrf_token %}

    <input
        type="text"
        name="username"
        placeholder="Username">

    <input
        type="email"
        name="email"
        placeholder="Email">

    <button type="submit">
        Register
    </button>

</form>
Important: Django madhye POST form submit kartana {% csrf_token %} vaprane required aahe, jar CSRF protection enabled asel tar. Actual project madhye server-side validation ani secure password handling suddha required aahe.

18. Common Beginner Mistakes

Mistake 1: Input la name attribute na dene

Normal form submission madhye name naslela input submit hot nahi.

Mistake 2: Label ani input connect na karne

Label cha for ani input cha id same thev.

Mistake 3: GET ani POST confuse karne

Data retrieval ani data submission sathi appropriate HTTP method select kar.

Mistake 4: Password GET method ne pathavne

Password sarkhya sensitive data sathi GET vapru naye. POST, HTTPS ani proper backend security vapr.

Mistake 5: Submit button cha type na dene

Form madhye button cha type explicitly specify kar.

Mistake 6: Fakt HTML validation var depend rahane

Browser validation sobat server-side validation suddha karne important aahe.
