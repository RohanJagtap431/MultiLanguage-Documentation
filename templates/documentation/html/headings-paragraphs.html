HTML Headings and Paragraphs

HTML madhye headings, paragraphs, line breaks, horizontal rules ani preformatted text kase vaprayche he ya lesson madhye shikuya.

Beginner Level 35–40 Minutes

1. What are HTML Headings?

HTML Headings cha use webpage madhye titles ani subtitles create karnyasathi hoto. Headings mule webpage cha content व्यवस्थित sections madhye divide karta yeto.

HTML madhye total 6 heading elements aahet. Te h1 pasun h6 paryant astat.

HTML Heading Elements:

Tag Purpose
<h1> Primary heading
<h2> Second-level heading
<h3> Third-level heading
<h4> Fourth-level heading
<h5> Fifth-level heading
<h6> Sixth-level heading
Remember: h1 ha highest-level heading aahe ani h6 ha lowest-level heading aahe.

2. HTML Heading Syntax

Heading create karnyasathi opening heading tag, content ani closing heading tag vapartat.

Syntax:


<h1>Heading Text</h1>

Example:


<h1>Welcome to My Website</h1>
<h2>About Us</h2>
<h3>Our Services</h3>
<h4>Web Development</h4>
<h5>HTML Tutorial</h5>
<h6>Introduction</h6>

Output:

Welcome to My Website

About Us

Our Services

Web Development

HTML Tutorial
Introduction

Browser pratyek heading la default font size ani bold styling provide karto. CSS vaprun he appearance change karta yete.

3. Heading Hierarchy

Heading hierarchy mhanje webpage madhil content logical order madhye arrange karne. Main topic sathi h1 ani tyachya subtopics sathi h2, h3 ase headings vapartat.

Example:


<h1>Web Development</h1>

    <h2>Frontend Development</h2>

        <h3>HTML</h3>

        <h3>CSS</h3>

        <h3>JavaScript</h3>

    <h2>Backend Development</h2>

        <h3>Python</h3>

        <h3>Django</h3>

Heading Structure:

Web Development

Frontend Development

HTML

CSS

JavaScript

Backend Development

Python

Django

Important: Heading levels content cha logical structure dakhavtat. Fakt text motha kiwa bold karnyasathi heading tags vapru naye. Tyasathi CSS vapr.

4. What is HTML Paragraph?

HTML Paragraph cha use webpage madhye normal text kiwa information display karnyasathi hoto. Paragraph create karnyasathi p tag vapartat.

Syntax:


<p>Your paragraph text goes here.</p>

Example:


<h1>About Me</h1>

<p>
    My name is Rohan.
    I am learning web development.
</p>

<p>
    I want to become a backend developer.
</p>

Output:

About Me

My name is Rohan. I am learning web development.

I want to become a backend developer.

Remember: Browser paragraph chya adhi ani nantar normally margin provide karto.

5. Multiple Paragraphs

Webpage madhye anek paragraphs create karta yetat. Pratyek paragraph sathi separate p element vapartat.

Example:


<h1>My College</h1>

<p>
    My college provides quality education.
</p>

<p>
    I am studying Computer Science.
</p>

<p>
    I enjoy learning programming.
</p>

Output:

My College

My college provides quality education.

I am studying Computer Science.

I enjoy learning programming.

Pratyek p element independent paragraph create karto. Tyamule browser madhye paragraphs vegvegale display hotat.

6. HTML Line Break (br)

br element cha use text madhye line break create karnyasathi hoto. Ya mule pudhil content next line madhye display hoto.

Syntax:


<br>

br ha void element aahe. Tyala closing tag chi garaj naste.

Example:


<p>
    My name is Rohan.<br>
    I am a Computer Science student.<br>
    I love programming.
</p>

Output:

My name is Rohan.
I am a Computer Science student.
I love programming.

Tip: br cha use address kiwa poem sarkhya content madhye meaningful line break sathi kar. Layout spacing create karnyasathi repeated br vapru naye.

7. HTML Horizontal Rule (hr)

hr element cha use webpage madhye thematic break kiwa content madhil section separation dakhavnyasathi hoto. Browser normally horizontal line display karto.

Syntax:


<hr>

Example:


<h2>About Us</h2>

<p>We are learning web development.</p>

<hr>

<h2>Our Services</h2>

<p>We provide web development services.</p>

Output:

About Us

We are learning web development.

Our Services

We provide web development services.

Remember: hr ha suddha void element aahe. Tyala closing tag chi garaj naste.

8. HTML Preformatted Text (pre)

pre element cha use preformatted text display karnyasathi hoto. Ya element madhye spaces ani line breaks normally preserve kele jatat.

Syntax:


<pre>
    Your formatted text
</pre>

Example:


<pre>
Name: Rohan
Course: B.Sc Computer Science
College: Kasegaon
</pre>

Output:

Name: Rohan
Course: B.Sc Computer Science
College: Kasegaon

pre element madhye lihilele spaces ani line breaks browser preserve karto.

Tip: Code examples, formatted text ani spacing important aslelya content sathi pre element useful aahe.

9. Difference Between br, hr and p

Element Purpose
p Paragraph create karne.
br Line break create karne.
hr Thematic break create karne.
pre Spaces ani line breaks preserve karne.
Important: p, br, hr ani pre he vegvegale HTML elements aahet. Tyanchya purpose madhye difference aahe.

10. Text Formatting vs Headings

Headings cha use content structure define karnyasathi hoto. Text formatting elements cha use text la specific meaning kiwa emphasis denyasathi hoto.

Example:


<h1>HTML Tutorial</h1>

<p>
    HTML is <strong>important</strong>
    for web development.
</p>

<p>
    Learn <em>HTML carefully</em>.
</p>

Output:

HTML Tutorial

HTML is important for web development.

Learn HTML carefully.

strong element important content darshavto, tar em element emphasis darshavto.

Remember: Heading, paragraph ani text formatting yanche purposes vegvegale aahet.

11. Complete Practical Example

Ata headings, paragraphs, br ani hr vaprun ek simple personal introduction webpage tayar karu.

HTML Code:


<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Introduction</title>
</head>

<body>

    <h1>My Introduction</h1>

    <p>
        Hello! My name is Rohan.<br>
        I am a Computer Science student.
    </p>

    <hr>

    <h2>My Education</h2>

    <p>
        I am studying B.Sc Computer Science.
    </p>

    <hr>

    <h2>My Skills</h2>

    <p>
        Python, Django, HTML and CSS.
    </p>

</body>

</html>

Output:

My Introduction

Hello! My name is Rohan.
I am a Computer Science student.

My Education

I am studying B.Sc Computer Science.

My Skills

Python, Django, HTML and CSS.

12. Common Beginner Mistakes

Mistake 1: Heading order ignore karne

Content structure madhye unnecessary heading levels skip karne avoid kar. Logical hierarchy maintain kar.

Mistake 2: Paragraph sathi br cha repeated use

Vegvegale paragraphs create karnyasathi separate p elements vapr.

Mistake 3: br ani hr confuse karne

br line break sathi ani hr thematic separation sathi aahe.

Mistake 4: Closing tags विसरणे

h1, h2 ani p sarkhya elements che closing tags properly lih.

Mistake 5: Heading fakt font size sathi vaprane

Text motha karaycha asel tar CSS vapr. Heading cha use content structure sathi kar.
