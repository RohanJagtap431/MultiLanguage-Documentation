HTML Audio and Video

HTML madhye audio ani video files website var embed karne ani browser madhye play karne shikuya.

Beginner Level 35–40 Minutes

1. What are HTML Audio and Video?

HTML madhye audio ani video elements cha use webpage var multimedia content display ani play karnyasathi hoto.

Audio Element

Audio element cha use music, voice recording, podcast kiwa sound files play karnyasathi hoto.

Video Element

Video element cha use video files webpage var play karnyasathi hoto.

Simple Definition: Audio element sound play karto ani Video element video play karto.

2. HTML Audio Element

HTML madhye <audio> element vaprun webpage var audio file add karta yete.

Syntax:


<audio controls>

    <source src="music.mp3" type="audio/mpeg">

</audio>

Explanation:

  • audio = Audio player create karto.
  • controls = Play, Pause ani Volume controls display karto.
  • source = Audio file cha path provide karto.
  • src = Audio file location specify karto.
  • type = Audio file cha media type specify karto.

Example:


<h2>My Audio</h2>

<audio controls>

    <source src="music.mp3" type="audio/mpeg">

    Your browser does not support audio.

</audio>

Ya example madhye browser audio player display karto. Music file available asel tar user ti play karu shakto.

3. Audio Controls

Audio element madhye different attributes vaprun audio player cha behavior control karta yeto.

Attribute Purpose
controls Audio player controls display karto.
autoplay Audio automatically play karnyacha prayatna karto.
loop Audio samplyavar punha play karto.
muted Audio suruvatila mute thevto.
preload Audio load karnyabaddal browser la hint deto.

Example:


<audio controls loop>

    <source src="music.mp3" type="audio/mpeg">

</audio>

Ya example madhye audio play karta yeil ani audio complete zalyavar to repeat hoil.

Important: Modern browsers madhye sound aslela autoplay normally block kela jau shakto. Autoplay sathi browser policy ani user interaction lakshat ghene important aahe.

4. Audio File Formats

Audio files vegveglya formats madhye available astat.

Format Description MIME Type
MP3 Common compressed audio format. audio/mpeg
WAV Usually uncompressed audio format. audio/wav
OGG Open multimedia container format. audio/ogg

Example:


<audio controls>

    <source src="song.mp3" type="audio/mpeg">

    <source src="song.ogg" type="audio/ogg">

    Your browser does not support audio.

</audio>

Browser supported source format select karun audio play karnyacha prayatna karto.

5. Source Element

<source> element audio kiwa video sathi media file cha path ani format specify karnyasathi vaparto.

Ekach audio kiwa video sathi multiple source elements provide karta yetat.

Example:


<audio controls>

    <source src="song.mp3" type="audio/mpeg">

    <source src="song.ogg" type="audio/ogg">

</audio>
Tip: Multiple source formats provide kelyane different browser support sathi madat hou shakte.

6. HTML Video Element

HTML madhye <video> element vaprun webpage var video file add karta yete.

Syntax:


<video controls width="500">

    <source src="movie.mp4" type="video/mp4">

</video>

Explanation:

  • video = Video player create karto.
  • controls = Video player controls display karto.
  • width = Video chi width set karto.
  • source = Video file cha path provide karto.
  • src = Video file location specify karto.
  • type = Video file cha media type specify karto.

Example:


<h2>My Video</h2>

<video controls width="500">

    <source src="movie.mp4" type="video/mp4">

    Your browser does not support video.

</video>

Ya example madhye browser video player display karto.

7. Video Controls

Video element madhye different attributes vaprun video player control karta yeto.

Attribute Purpose
controls Play, Pause, Volume ani other controls display karto.
autoplay Video automatically play karnyacha prayatna karto.
loop Video samplyavar punha play karto.
muted Video cha sound mute thevto.
poster Video play honyapurvi preview image display karto.
width Video chi width set karto.
height Video chi height set karto.
preload Video loading baddal browser la hint deto.

8. Important Video Attributes

Autoplay

Autoplay attribute video automatically play karnyacha prayatna karto. 


<video autoplay muted>

    <source src="movie.mp4" type="video/mp4">

</video>

Muted

Muted attribute video cha sound mute thevto. 


<video controls muted>

    <source src="movie.mp4" type="video/mp4">

</video>

Loop

Loop attribute video complete zalyavar punha play karto. 


<video controls loop>

    <source src="movie.mp4" type="video/mp4">

</video>

Poster

Poster attribute video play honyapurvi preview image display karto. 


<video controls
       poster="thumbnail.jpg">

    <source src="movie.mp4" type="video/mp4">

</video>

Preload

Preload browser la video data kiti load karaycha yachi hint deto. 


<video controls preload="metadata">

    <source src="movie.mp4" type="video/mp4">

</video>

Preload values:

  • none = Media data preload karu naye.
  • metadata = Basic media information load karne.
  • auto = Browser garjenusar media preload karu shakto.
Important: Preload hi browser sathi hint aahe. Browser network ani device conditions nusar loading behavior decide karu shakto.

10. Audio and Video Difference

Audio Video
Sound play karto. Moving visuals ani sound play karu shakto.
<audio> element vaparto. <video> element vaparto.
Audio player display karto. Video player display karto.
MP3, WAV, OGG formats. MP4, WebM, OGG formats.

11. Practical Media Player

Ata audio ani video elements vaprun ek simple Media Player section create karu.

HTML Code:


<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Media Player</title>

</head>

<body>

    <h1>My Media Player</h1>

    <h2>My Audio</h2>

    <audio controls>

        <source src="music.mp3" type="audio/mpeg">

        Your browser does not support audio.

    </audio>

    <h2>My Video</h2>

    <video controls width="500"
           poster="thumbnail.jpg">

        <source src="movie.mp4" type="video/mp4">

        Your browser does not support video.

    </video>

</body>

</html>

Folder Structure:


MediaPlayer/
│
├── index.html
│
├── music.mp3
│
├── movie.mp4
│
└── thumbnail.jpg
Important: HTML file ani media files yogya folder madhye asne necessary aahe. File path chukla tar media play honar nahi.

12. Common Beginner Mistakes

Mistake 1: Controls attribute विसरणे

Controls naslyas user la browser cha default player interface milnar nahi.

Mistake 2: Wrong File Path

Audio kiwa video file cha path correct asne necessary aahe.

Mistake 3: Wrong MIME Type

Source element madhye file nusar correct type specify kar.

Mistake 4: Autoplay nehmich work hoil ase samajne

Browser autoplay policies mule sound aslela autoplay block hou shakto.

Mistake 5: Large Video Files Directly Load karne

Large files mule loading slow hou shakte. File size ani hosting optimize kar.

Mistake 6: Only One Format Provide karne

Garjenusar multiple supported formats provide karu shakto.
