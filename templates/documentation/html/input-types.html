HTML Input Types

HTML input element madhil different types vaprun user kadun different formats madhye information receive karayla shikuya.

Beginner Level 40–45 Minutes

1. What are HTML Input Types?

HTML madhye input element cha type attribute input field cha behavior ani purpose define karto.

Type change kelyavar browser vegvegale input controls display karto.

Examples:

  • Text field
  • Password field
  • Email field
  • Number field
  • Date picker
  • Radio button
  • Checkbox
  • File upload
Simple Definition: Input Types mhanje input element cha type attribute vaprun different types che form controls create karne.

2. Text Input

type="text" cha use user kadun normal single-line text receive karnyasathi hoto.

Syntax:


<input type="text">

Example:


<label for="username">Username:</label>

<input
    type="text"
    id="username"
    name="username"
    placeholder="Enter username">

Output:

Ya field madhye user name, city, address kiwa other normal text enter karu shakto.

3. Password Input

type="password" cha use password enter karnyasathi hoto.

Browser madhye password characters normally masked format madhye display hotat.

Example:


<label for="password">Password:</label>

<input
    type="password"
    id="password"
    name="password"
    placeholder="Enter password">

Output:

Important: Password input characters mask karto. Pan fakt type="password" vaparlyane data secure hot nahi. HTTPS ani secure backend processing suddha required aahe.

5. Number Input

type="number" cha use numeric values enter karnyasathi hoto.

Example:


<label for="age">Age:</label>

<input
    type="number"
    id="age"
    name="age"
    min="1"
    max="100">

Output:

Important Attributes:

  • min = Minimum allowed value.
  • max = Maximum allowed value.
  • step = Allowed increment interval.

Step Example:


<input
    type="number"
    min="0"
    max="100"
    step="5">

Ya example madhye 5 chya intervals ne number select karta yetat.

14. Hidden Input

type="hidden" cha use form sobat additional data submit karnyasathi hoto, jo normal webpage var visible nasto.

Example:

    type="hidden"
    name="user_id"
    value="101">

Hidden input user la normal form field mhanun visible hot nahi.

Security Note: Hidden input madhil data secure kiwa secret nasto. User browser madhye to inspect ani modify karu shakto. Sensitive information hidden input madhye thevu naye.

18. Input Validation Attributes

Input fields madhye user kadun योग्य data receive karnyasathi validation attributes vaparta yetat.

Attribute Purpose
required Field compulsory karte.
min Minimum value specify karte.
max Maximum value specify karte.
minlength Minimum text length specify karte.
maxlength Maximum text length specify karte.
pattern Regular expression pattern specify karte.
step Allowed numeric increment specify karte.
multiple Multiple values kiwa files allow karte, supported input type nusar.

Example:


<form>

    <input
        type="text"
        name="username"
        minlength="3"
        maxlength="15"
        required>

    <input
        type="number"
        name="age"
        min="18"
        max="60"
        required>

    <button type="submit">
        Submit
    </button>

</form>

Output:

Important: HTML validation browser madhye hote. Security ani correct data sathi backend madhye suddha validation karne necessary aahe.

20. Common Beginner Mistakes

Mistake 1: Radio Buttons la different name dene

Ekach group madhil radio buttons sathi same name vapr.

Mistake 2: Checkbox ani Radio confuse karne

Ek option sathi Radio ani multiple options sathi Checkbox vapr.

Mistake 3: File Upload madhye enctype विसरणे

File upload form sathi enctype="multipart/form-data" vapr.

Mistake 4: Number validation ignore karne

Garjenusar min, max ani step attributes vapr.

Mistake 5: Hidden Input la secure samajne

Hidden input user inspect karu shakto. Sensitive data tyat store karu naye.

Mistake 6: Fakt browser validation var depend rahane

Backend madhye suddha input validation kar.
