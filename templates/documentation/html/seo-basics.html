SEO Basics

Search Engine Optimization samjun gheuya ani HTML webpage search engines sathi optimize kasa karaycha te shikuya.

Beginner Level 35–40 Minutes

1. What is SEO?

SEO cha full form Search Engine Optimization aahe. Website search engine madhye easily discover ani understand vhavi yasathi kelelya process la SEO mhantat.

Google sarkhe search engines webpages crawl, index ani rank karu shaktat. SEO mule website chi search results madhil visibility improve honyas madat hote.

Example:

Samja user Google var "Python Tutorial" search karto.

Tumchi website Python tutorials provide karat asel ani ti properly optimized asel tar search results madhye disnyachi possibility improve hou shakte.

Simple Definition: SEO mhanje website search engines sathi optimize karne, jyamule relevant users la website shodhne sope hote.

2. Types of SEO

SEO che mainly three important types aahet.

1. On-Page SEO

Website chya webpage madhye kelelya optimization la On-Page SEO mhantat.

  • Proper page title
  • Meta description
  • Heading tags
  • Image alt attributes
  • Useful content
  • Internal links

2. Off-Page SEO

Website chya baher kelelya activities mule website chi reputation ani authority improve karnyacha prayatna kela jato.

  • Quality backlinks
  • Brand mentions
  • Content promotion
  • Relevant website references

3. Technical SEO

Website chi technical performance ani search engine accessibility improve karnyala Technical SEO mhantat.

  • Website loading speed
  • Mobile-friendly design
  • HTTPS security
  • XML Sitemap
  • Robots.txt
  • Proper URL structure
Remember: HTML madhye title, headings, meta description ani alt attributes he On-Page SEO che important parts aahet.

3. Importance of SEO in HTML

HTML webpage cha structure define karte. Proper HTML structure mule search engines la webpage madhil content samjun ghenyas madat hote.

Important HTML SEO Elements:

HTML Element SEO Purpose
<title> Page title define karto.
<meta> Page information provide karto.
<h1> to <h6> Content headings organize kartat.
<img> Image content display karto.
<a> Links create karto.
<main> Main content identify karto.
<article> Independent content define karto.

4. Title Tag

<title> tag webpage cha title define karto. Ha tag HTML document chya <head> section madhye lihitat.

Search results madhye title link mhanun display hou shakto.

Syntax:


<head>

    <title>Python Tutorial for Beginners</title>

</head>

Important Points:

  • Pratyek page sathi descriptive title liha.
  • Title page content shi relevant asava.
  • Unnecessary keywords repeat karu naka.
  • Pratyek webpage cha title unique theva.
Important: Title tag ani h1 tag vegale aahet. Title browser tab ani search results sathi, tar h1 page madhil main heading sathi asto.

5. Meta Description

Meta description hi webpage cha short summary aste. Ti HTML document chya head section madhye lihitat.

Syntax:


<meta name="description"
      content="Learn Python programming with easy
      examples and practical tutorials.">

Example:


<head>

    <title>Python Tutorial</title>

    <meta name="description"
          content="Learn Python from basics with
          simple examples and exercises.">

</head>

Important Points:

  • Page content cha accurate summary dya.
  • Pratyek page sathi relevant description liha.
  • Unnecessary keywords avoid kara.
  • Description user la page baddal mahiti dete.
Tip: Google kahi vela tumchi meta description use karto, pan search result madhye vegla text suddha show karu shakto.

6. Heading Tags and SEO

HTML madhye h1 te h6 ase six heading tags aahet. Ya tags cha use webpage madhil content organize karnyasathi hoto.

Example:


<h1>Python Tutorial</h1>

<h2>Python Basics</h2>

<h3>Variables</h3>

<h3>Data Types</h3>

<h2>Python Functions</h2>

Output:

Python Tutorial

Python Basics

Variables

Data Types

Python Functions

Important Points:

  • Page cha main topic clearly explain kara.
  • Headings logical order madhye use kara.
  • Headings cha use content structure sathi kara.
  • Fakt text motha karnyasathi heading tags vapru naka.
Remember: Heading hierarchy user ani search engines donhanna content samjun ghenyas madat karte.

7. Image Alt Attribute

Alt attribute image cha text description provide karto.

Image load zali nahi kiwa screen reader use kela tar alt text useful tharto.

Example:


<img src="python-logo.png"
     alt="Python programming language logo">

Important Points:

  • Image cha meaning describe kara.
  • Relevant alt text liha.
  • Keyword stuffing karu naka.
  • Decorative image sathi empty alt vapru shakta.

Decorative Image Example:


<img src="decoration.png" alt="">
Important: Alt text ha image cha description asto. To image filename kiwa keyword list nasava.

8. Semantic HTML and SEO

Semantic HTML elements webpage madhil content cha meaning clear kartat.

Example:


<header>

    <h1>Technology Blog</h1>

</header>

<main>

    <article>

        <h2>Learn Web Development</h2>

        <p>
            Web development includes HTML, CSS and JavaScript.
        </p>

    </article>

</main>

<footer>

    <p>Copyright 2026</p>

</footer>

Benefits:

  • Content structure clear hote.
  • Accessibility improve honyas madat hote.
  • Code readable ani maintainable hoto.
  • Search engines la content context samajnyas madat hote.
Tip: Semantic HTML use kelyane automatic top Google ranking milat nahi. Pan clear structure tayar honyas madat hote.

9. Internal and External Links

1. Internal Links

Same website madhil eka page varun dusrya page var janarya links la Internal Links mhantat. 


<a href="/python/">
    Python Tutorial
</a>

2. External Links

Dusrya website var janarya links la External Links mhantat. 


<a href="https://www.python.org/"
   target="_blank"
   rel="noopener noreferrer">

    Official Python Website

</a>

Benefits of Links:

  • Users la related pages shodhne sope hote.
  • Website navigation improve hote.
  • Search engines la pages discover karnyas madat hote.
  • Relevant external resources provide karta yetat.

10. SEO-Friendly URL Structure

URL mhanje webpage cha web address. Clear ani descriptive URL users la page cha topic samajnyas madat karto.

Bad URL:


https://example.com/page?id=12345

Better URL:


https://example.com/python-tutorial/

Important Points:

  • URL short ani descriptive theva.
  • Words separate karnyasathi hyphen vapra.
  • Unnecessary parameters avoid kara.
  • URL page content shi related asava.

11. Sitemap and Robots.txt

1. XML Sitemap

XML Sitemap hi website madhil important URLs chi list aste.

Sitemap mule search engines la website madhil important pages discover karnyas madat hou shakte.

Example: sitemap.xml


<?xml version="1.0" encoding="UTF-8"?>

<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">

    <url>

        <loc>https://example.com/</loc>

    </url>

    <url>

        <loc>https://example.com/python-tutorial/</loc>

    </url>

</urlset>

2. Robots.txt

Robots.txt file madhye crawlers sathi crawl rules specify karta yetat.

Example: robots.txt


User-agent: *

Allow: /

Disallow: /admin/

Sitemap: https://example.com/sitemap.xml
Important: Robots.txt hi security system nahi. Disallow rule mule private pages secure hot nahit. Sensitive pages sathi proper authentication ani access control vapra.

12. Complete SEO-Friendly HTML Page

Ata apan title, meta description, semantic elements, headings ani image alt attributes vaprun ek SEO-friendly HTML page create karu.

HTML Code:


<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Python Tutorial for Beginners</title>

    <meta name="description"
          content="Learn Python programming with
          simple examples and practical tutorials.">

</head>

<body>

    <header>

        <h1>Python Tutorial</h1>

    </header>

    <nav>

        <a href="/python/">Home</a>

        <a href="/python/basics/">Basics</a>

    </nav>

    <main>

        <article>

            <h2>Learn Python Programming</h2>

            <p>
                Python is a beginner-friendly programming language.
            </p>

            <img src="python-logo.png"
                 alt="Python programming language logo"
                 width="200">

            <h2>Why Learn Python?</h2>

            <p>
                Python is used in web development,
                automation and data science.
            </p>

            <a href="https://www.python.org/">
                Official Python Website
            </a>

        </article>

    </main>

    <footer>

        <p>Copyright &copy; 2026</p>

    </footer>

</body>

</html>

Output:

Python Tutorial

Home Basics

Learn Python Programming

Python is a beginner-friendly programming language.

Python Logo Image

Why Learn Python?

Python is used in web development, automation and data science.

Official Python Website

Copyright © 2026

13. Common SEO Mistakes

Mistake 1: Missing Title Tag

Page sathi descriptive title provide na karne.

Mistake 2: Missing Meta Description

Page content cha useful summary provide na karne.

Mistake 3: Missing Alt Attribute

Images sathi meaningful alternative text na dene.

Mistake 4: Keyword Stuffing

Ranking milavnyasathi same keywords unnecessary repeat karne.

Mistake 5: Poor Heading Structure

Content la proper headings ani logical structure na dene.

Mistake 6: Broken Links

Working naslele links website madhye thevne.
