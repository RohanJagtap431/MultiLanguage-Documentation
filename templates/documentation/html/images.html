HTML Images

HTML webpage madhye images add karne, image paths, src ani alt attributes, image dimensions, responsive images ani figure elements ya lesson madhye shikuya.

Beginner Level 35–40 Minutes

1. What are HTML Images?

HTML Images cha use webpage madhye pictures, photographs, graphics ani visual content display karnyasathi hoto.

Images mule webpage adhik informative ani visually attractive banto.

Examples:

  • Website madhye company logo display karne.
  • Product photographs show karne.
  • Profile pictures display karne.
  • Blog madhye photographs add karne.
  • Educational diagrams display karne.
Simple Definition: HTML Images cha use webpage madhye visual content display karnyasathi hoto.

2. HTML img Element

HTML madhye image add karnyasathi img element vapartat. Ha void element aahe. Tyala closing tag chi garaj naste.

Syntax:


<img src="image.jpg" alt="Image Description">

Example:


<img src="flower.jpg" alt="Beautiful Flower">

Explanation:

  • img = Image element.
  • src = Image file cha path.
  • alt = Image cha alternative text.
Important: img ha void element aahe. Tyamule <img> vapr. </img> closing tag vaparnyachi garaj nahi.

3. src Attribute

src cha full form source aahe. Ya attribute cha use image file kuthe aahe he browser la sangnyasathi hoto.

Example:


<img src="flower.jpg" alt="Red Flower">

Ithe flower.jpg hi image file browser load karnyacha prayatna karel.

Different Image Formats:

Format Common Use
JPG / JPEG Photographs ani regular images.
PNG Transparency support aslelya images.
GIF Simple animations.
SVG Logos, icons ani vector graphics.
WebP Modern compressed web images.
AVIF Modern efficient image format.
Tip: Website madhye image format select kartana image quality, file size ani browser compatibility lakshat ghe.

4. alt Attribute

alt cha full form alternative text aahe. Ya attribute madhye image baddal text description lihitat.

Image load zali nahi tar kahi paristhitit alt text display hou shakto. Screen reader users na image cha meaning samjnyasathi suddha alt text useful aahe.

Example:


<img
    src="student.jpg"
    alt="Student studying at a desk"
>

Decorative Image:


<img src="decoration.png" alt="">

Image fakt decoration sathi asel ani additional information det nasel tar empty alt text vaparta yeto.

Important: Meaningful image sathi descriptive alt text lih. Alt attribute completely omit karnyapeksha appropriate alt value dene changle.

5. width and height Attributes

width ani height attributes cha use image chi dimensions specify karnyasathi hoto.

Example:


<img
    src="flower.jpg"
    alt="Red Flower"
    width="300"
    height="200"
>

Ithe image chi width 300 pixels ani height 200 pixels specify keli aahe.

Output:

300 × 200 Image dimensions example
Tip: width ani height specify kelyane browser la image sathi space reserve karta yete. Yogya dimensions dene layout shifting kami karnyas madat karte.

6. Relative Image Path

Relative path madhye image cha location current HTML document chya location nusar specify karto.

Example 1: Same Folder


<img src="photo.jpg" alt="My Photo">

Ithe photo.jpg ani HTML file same folder madhye aahet.

Example 2: Images Folder


<img src="images/photo.jpg" alt="My Photo">

Ithe photo.jpg hi file images folder madhye aahe.

Example 3: Parent Folder


<img src="../photo.jpg" alt="My Photo">

../ mule current folder chya parent folder madhil photo.jpg file access hote.

Folder Structure:


my-website/
│
├── index.html
│
├── photo.jpg
│
└── images/
    ├── flower.jpg
    └── student.png
Important: Relative path ha HTML document chya location nusar resolve hoto. File path barobar lihine khup important aahe.

7. Absolute Image Path

Absolute URL madhye image cha complete web address specify kelela asto.

Example:


<img
    src="https://example.com/images/flower.jpg"
    alt="Flower"
>

Ya example madhye image external website varun load karnyacha prayatna kela jato.

Remember: External image URL vapartana image publicly accessible aahe ka ani website tyacha use allow karte ka he check kar.

8. Image Folder Structure

Website project madhye images sathi separate folder create karne hi common practice aahe.

Example Folder Structure:


my-website/
│
├── index.html
│
├── about.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
└── images/
    ├── logo.png
    ├── profile.jpg
    └── banner.webp

HTML Code:


<img src="images/logo.png" alt="Website Logo">

<img src="images/profile.jpg" alt="Profile Photo">

<img src="images/banner.webp" alt="Website Banner">

Ya prakare images ekach folder madhye व्यवस्थित organize karta yetat.

9. Image as a Link

Image la clickable banvanyasathi img element anchor element chya aat place kartat.

Example:


<a href="https://www.google.com">

    <img
        src="google-logo.png"
        alt="Visit Google"
        width="150"
    >

</a>

Ata user image var click kelyavar Google website open hoil.

Remember: Anchor element madhye image thevlyane image hyperlink mhanun work karte.

10. Figure and Figcaption Elements

figure element cha use image, diagram, illustration kiwa other self-contained content group karnyasathi hoto.

figcaption element cha use figure madhil content sathi caption kiwa description denyasathi hoto.

Syntax:


<figure>

    <img src="flower.jpg" alt="Red Rose">

    <figcaption>
        A beautiful red rose.
    </figcaption>

</figure>

Output:

Tip: Image la meaningful caption dyaycha asel tar figure ani figcaption elements useful aahet.

11. Responsive Images with CSS

Responsive image mhanje screen size nusar available space madhye adjust honari image.

CSS madhye max-width: 100% vaprun image container peksha mothi honar nahi yachi kalji gheta yete.

HTML Code:


<img
    src="landscape.jpg"
    alt="Beautiful Landscape"
    class="responsive-image"
>

CSS Code:


.responsive-image {
    max-width: 100%;
    height: auto;
    display: block;
}

Output:

Responsive Image Container width nusar adjust hoil
Important: height: auto mule image che original proportions maintain karnyas madat hote.

12. loading Attribute

img element madhil loading attribute browser la image loading behavior baddal hint dete.

Common Values:

Value Purpose
lazy Image viewport javal alyavar load karnyasathi hint dete.
eager Image normally lagech load karnyasathi hint dete.

Example:


<img
    src="product.jpg"
    alt="Product Image"
    loading="lazy"
>

Ya example madhye browser image la lazy loading hint follow karnyasathi sangto.

Tip: Page chya khali aslelya images sathi lazy loading useful asu shakate. Above-the-fold main image sathi unnecessary lazy loading avoid kar.

13. Responsive Images with srcset

srcset attribute cha use ekach image chya different sizes kiwa resolutions browser la available karun denyasathi hoto.

Browser device ani display conditions nusar suitable image resource select karu shakto.

Example:


<img
    src="small.jpg"
    srcset="
        small.jpg 480w,
        medium.jpg 800w,
        large.jpg 1200w
    "
    sizes="(max-width: 600px) 100vw, 800px"
    alt="Beautiful Landscape"
>

Explanation:

  • src = Default image source.
  • srcset = Available image sources ani tyanchi width.
  • sizes = Layout madhye image kiti width gheil yachi hint.
  • 480w, 800w, 1200w = Image resource widths.
Important: srcset ani sizes vaprun browser la different screen conditions sathi suitable image select karnyas madat hote.

14. Picture Element

picture element cha use different screen conditions kiwa image formats nusar alternative image resources provide karnyasathi hoto.

picture madhye source elements ani img element vapartat.

Example:


<picture>

    <source
        media="(max-width: 600px)"
        srcset="mobile.jpg"
    >

    <source
        media="(min-width: 601px)"
        srcset="desktop.jpg"
    >

    <img
        src="desktop.jpg"
        alt="Website Banner"
    >

</picture>

Explanation:

  • picture = Alternative image sources group karte.
  • source = Alternative image resource specify karte.
  • media = CSS media condition specify karte.
  • img = Default ani fallback image provide karte.
Remember: picture element vapartana img element suddha provide karne important aahe.

15. Complete Practical Example

Ata apan image, alt, dimensions, figure, figcaption ani responsive CSS vaprun ek simple profile section tayar karu.

HTML Code:


<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Student Profile</title>

    <style>

        .profile-image {
            max-width: 100%;
            height: auto;
            display: block;
            border-radius: 10px;
        }

    </style>

</head>

<body>

    <h1>Student Profile</h1>

    <figure>

        <img
            src="images/student.jpg"
            alt="Student Profile Photo"
            width="250"
            height="250"
            class="profile-image"
        >

        <figcaption>
            My Student Profile
        </figcaption>

    </figure>

    <h2>About Me</h2>

    <p>
        I am learning web development.
    </p>

</body>

</html>

Expected Output Structure:

Student Profile

About Me

I am learning web development.

Actual image display honyasathi project madhye images/student.jpg file available asne avashyak aahe.

16. Common Beginner Mistakes

Mistake 1: Wrong Image Path

src madhye incorrect path dilyas image load hot nahi. Folder structure check kar.

Mistake 2: alt Attribute Ignore Karne

Meaningful image sathi descriptive alt text dene important aahe.

Mistake 3: Wrong File Extension

Image cha actual file format ani src madhil extension match hot aahe ka te check kar.

Mistake 4: width ani height madhye distortion

Image che proportions maintain karnyasathi CSS madhye height: auto vapr.

Mistake 5: Missing Image File

HTML madhye image path dila pan actual image project madhye nasel tar image display honar nahi.

Mistake 6: Saglya Images la Lazy Loading

Main visible image la unnecessary lazy loading deu naye. Lazy loading appropriate images sathi vapr.
