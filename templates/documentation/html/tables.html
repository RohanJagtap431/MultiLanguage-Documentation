HTML Tables

HTML Tables vaprun data rows ani columns madhye व्यवस्थित display karayla shikuya.

Beginner Level 35–40 Minutes

1. What are HTML Tables?

HTML Table cha use data rows ani columns chya format madhye display karnyasathi hoto.

Table mule related information व्यवस्थित organize hote ani data compare karne easy hote.

Examples:

  • Student Records
  • Employee Details
  • Product Prices
  • Exam Results
  • Attendance Records
Simple Definition: HTML Table mhanje data rows ani columns madhye display karnyasathi vaparla janara HTML structure.

2. HTML Table Elements

HTML Table create karnyasathi different elements vapartat.

Element Meaning Purpose
<table> Table Complete table create karto.
<tr> Table Row Table madhye row create karto.
<th> Table Header Heading cell create karto.
<td> Table Data Data cell create karto.
<caption> Table Caption Table la title deto.
<thead> Table Head Header rows group karto.
<tbody> Table Body Main data rows group karto.
<tfoot> Table Footer Footer rows group karto.

3. Basic HTML Table

Table create karnyasathi sarvat aadhi table element vapartat.

Syntax:


<table>

    <tr>
        <th>Heading 1</th>
        <th>Heading 2</th>
    </tr>

    <tr>
        <td>Data 1</td>
        <td>Data 2</td>
    </tr>

</table>

Explanation:

  • table = Complete table create karto.
  • tr = Table madhye ek row create karto.
  • th = Heading cell create karto.
  • td = Normal data cell create karto.
Important: Table madhye rows create karnyasathi tr ani cells create karnyasathi th kiwa td vapartat.

4. Table Row (tr)

tr element cha use HTML Table madhye ek row create karnyasathi hoto.

Example:


<table>

    <tr>
        <td>Rohan</td>
        <td>Computer Science</td>
    </tr>

    <tr>
        <td>Amit</td>
        <td>Mathematics</td>
    </tr>

</table>

Output:

Rohan Computer Science
Amit Mathematics

Ya example madhye two table rows create kele aahet.

5. Table Heading (th)

th element cha use Table madhye heading kiwa column title define karnyasathi hoto.

Browser normally th text bold ani center aligned display karto.

Example:


<table>

    <tr>
        <th>Name</th>
        <th>Age</th>
        <th>Course</th>
    </tr>

</table>

Output:

Name Age Course
Note: Table headings sathi th element vapr. Normal data sathi td element vapr.

6. Table Data (td)

td element cha use Table madhye actual information kiwa data display karnyasathi hoto.

Example:


<table>

    <tr>
        <td>Rohan</td>
        <td>20</td>
        <td>BSc CS</td>
    </tr>

</table>

Output:

Rohan 20 BSc CS

8. Table Border and CSS Styling

CSS vaprun Table la border, background color, padding, text alignment ani spacing deta yete.

HTML Code:


<table class="student-table">

    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Rohan</td>
        <td>85</td>
    </tr>

    <tr>
        <td>Amit</td>
        <td>78</td>
    </tr>

</table>

CSS Code:


.student-table {
    width: 100%;
    border-collapse: collapse;
}

.student-table th,
.student-table td {
    border: 1px solid #ccc;
    padding: 12px;
    text-align: left;
}

.student-table th {
    background: #2563eb;
    color: white;
}

.student-table tr:nth-child(even) {
    background: #f1f5f9;
}

Output:

Name Marks
Rohan 85
Amit 78

Important CSS Properties:

Property Purpose
border Table cells la border dete.
padding Cell chya aat spacing dete.
text-align Text alignment set karte.
width Table chi width set karte.
border-collapse Adjacent cell borders combine karte.
background Background color set karte.

9. colspan Attribute

colspan attribute cha use ek table cell multiple columns madhye spread karnyasathi hoto.

Example:


<table>

    <tr>
        <th colspan="2">Student Details</th>
    </tr>

    <tr>
        <td>Name</td>
        <td>Rohan</td>
    </tr>

</table>

Output:

Student Details
Name Rohan
Important: colspan="2" mhanje cell don columns chi space cover karto.

10. rowspan Attribute

rowspan attribute cha use ek table cell multiple rows madhye spread karnyasathi hoto.

Example:


<table>

    <tr>
        <th>Name</th>
        <th>Subject</th>
    </tr>

    <tr>
        <td rowspan="2">Rohan</td>
        <td>Computer Science</td>
    </tr>

    <tr>
        <td>Mathematics</td>
    </tr>

</table>

Output:

Name Subject
Rohan Computer Science
Mathematics
Important: rowspan="2" mhanje cell don rows chi space cover karto.

11. Table Sections

Large Tables व्यवस्थित organize karnyasathi thead, tbody ani tfoot elements vapartat.

Element Purpose
thead Table header rows group karto.
tbody Main table data rows group karto.
tfoot Table footer rows group karto.

Example:


<table>

    <thead>
        <tr>
            <th>Product</th>
            <th>Price</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Laptop</td>
            <td>50000</td>
        </tr>

        <tr>
            <td>Mouse</td>
            <td>500</td>
        </tr>
    </tbody>

    <tfoot>
        <tr>
            <td>Total</td>
            <td>50500</td>
        </tr>
    </tfoot>

</table>

Output:

Product Price
Laptop 50000
Mouse 500
Total 50500
Tip: Large tables madhye data organize karnyasathi thead, tbody ani tfoot useful aahet.

12. Table Caption

        <td>Rohan</td>

13. Responsive Tables

Mobile devices madhye large table screen peksha wide asu shakto. Ashya veli horizontal scrolling provide karne useful aahe.

HTML Code:


<div class="table-container">

    <table>

        <tr>
            <th>ID</th>
            <th>Name</th>
            <th>Course</th>
            <th>Email</th>
        </tr>

        <tr>
            <td>1</td>
            <td>Rohan</td>
            <td>BSc CS</td>
            <td>rohan@example.com</td>
        </tr>

    </table>

</div>

CSS Code:


.table-container {
    width: 100%;
    overflow-x: auto;
}

.table-container table {
    min-width: 600px;
}
Tip: Responsive table sathi table la wrapper div madhye thevun overflow-x: auto vapru shakto.

14. Table Accessibility

Table screen readers vaparnarya users sathi suddha understandable asne important aahe.

Important Practices:

  • Table la meaningful caption de.
  • Column headings sathi th element vapr.
  • Heading cells sathi scope attribute vapr.
  • Table cha use tabular data sathi kar.
  • Mobile users sathi horizontal scrolling provide kar.

Example:


<table>

    <caption>Student Information</caption>

    <tr>
        <th scope="col">Name</th>
        <th scope="col">Course</th>
    </tr>

    <tr>
        <td>Rohan</td>
        <td>BSc CS</td>
    </tr>

</table>

scope="col" mule heading ha column sathi aahe he assistive technologies la samajnyas madat hote.

15. Common Beginner Mistakes

Mistake 1: tr element visarne

Table madhil cells properly row madhye organize karnyasathi tr vapr.

Mistake 2: th ani td confuse karne

Headings sathi th ani normal data sathi td vapr.

Mistake 3: colspan ani rowspan confuse karne

colspan columns merge karto ani rowspan rows merge karto.

Mistake 4: Table madhye CSS na vaprane

CSS vaprun table readable ani attractive banav.

Mistake 5: Table cha use layout sathi karne

Website layout sathi modern CSS Flexbox kiwa Grid vapr. HTML Tables cha use tabular data sathi kar.

Mistake 6: Responsive design ignore karne

Mobile screen var large tables overflow hou shaktat. Table wrapper madhye horizontal scrolling provide kar.
