HTML projects mule aplyala HTML tags, attributes, forms, tables, links ani semantic elements practically use karta yetat.

PROJECT 01

2. Personal Profile Webpage

Objective:

Swatachi basic information display karnyasathi personal profile webpage create karne.

HTML Elements Used:

  • h1, h2, p
  • img
  • ul, li
  • a
  • header, main, footer

Complete HTML Code:


<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My Profile</title>
</head>

<body>

    <header>
        <h1>My Profile</h1>
    </header>

    <main>

        <h2>Hello, I am Rohan</h2>

        <p>I am a Computer Science student.</p>

        <h2>My Skills</h2>

        <ul>
            <li>Python</li>
            <li>Django</li>
            <li>HTML</li>
            <li>CSS</li>
        </ul>

        <h2>Contact Me</h2>

        <a href="mailto:example@gmail.com">
            Send Email
        </a>

    </main>

    <footer>
        <p>My Personal Website</p>
    </footer>

</body>
</html>

I am a Computer Science student.

My Skills

  • Python

PROJECT 02

3. Student Registration Form

Objective:

Student chi personal information collect karnyasathi registration form create karne.

HTML Elements Used:

  • form, label, input
  • select, option
  • textarea
  • button, fieldset, legend

Complete HTML Code:


<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Student Registration</title>
</head>

<body>

    <h1>Student Registration Form</h1>

    <form action="#" method="post">

        <fieldset>

            <legend>Student Details</legend>

            <label for="name">Full Name:</label>
            <input type="text" id="name"
                   name="name" required>

            <br><br>

            <label for="email">Email:</label>
            <input type="email" id="email"
                   name="email" required>

            <br><br>

            <label for="age">Age:</label>
            <input type="number" id="age"
                   name="age" min="1" required>

            <br><br>

            <label for="course">Course:</label>

            <select id="course" name="course">
                <option value="bsc">B.Sc. CS</option>
                <option value="bca">BCA</option>
                <option value="bcom">B.Com</option>
            </select>

            <br><br>

            <label for="address">Address:</label>
            <textarea id="address"
                      name="address"></textarea>

            <br><br>

            <button type="submit">Register</button>

        </fieldset>

    </form>

</body>
</html>

Expected Output:

Student Registration Form

13. Common Beginner Mistakes

Mistake 1: Missing HTML Structure

DOCTYPE, html, head ani body tags properly use na karne.

Mistake 2: Incorrect File Names

Links madhye HTML files chi incorrect names kiwa paths use karne.

Mistake 3: Missing Form Labels

Input fields sathi labels provide na karne.

Mistake 4: Improper Nesting

HTML tags incorrect order madhye close karne.

Mistake 5: Expecting HTML to Save Data

HTML form automatically database madhye data save karat nahi. Backend necessary aahe.
