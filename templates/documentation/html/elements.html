HTML Elements and Tags

HTML tags ani elements mhanje kay, tyanchi structure, types, nesting ani webpage madhye tyanchya uses baddal ya lesson madhye detail madhye shikuya.

Beginner Level 35–40 Minutes

1. What are HTML Tags?

HTML Tags mhanje browser la webpage madhil content kasa structure karaycha he sangnarya markup instructions. HTML tags angle brackets madhye lihitat.

HTML tag chi suruvat less-than sign (<) ne hote ani tyacha shevat greater-than sign (>) ne hoto.

Example:


<h1>

Ithe h1 ha HTML tag aahe. Ha tag webpage madhye main level heading define karto.

More HTML Tag Examples:


<p>          Paragraph tag

<h1>         Heading tag

<a>          Link tag

<img>        Image tag

<div>        Division tag

<button>     Button tag
Definition: HTML Tag mhanje angle brackets madhye lihileli markup instruction ji browser la content cha type kiwa structure samjavte.

2. Types of HTML Tags

HTML tags che common types mhanje opening tags, closing tags ani void tags.

A. Opening Tag

Opening tag element chi suruvat karto. Yala start tag suddha mhantat. 


<p>

B. Closing Tag

Closing tag element cha shevat karto. Closing tag madhye tag name chya aadhi forward slash (/) vapartat. 


</p>

C. Void Tag

Void elements madhye content thevta yet nahi ani tyanna closing tag nasato. 


<br>
<hr>
<img src="photo.jpg" alt="Photo">
<input type="text">
Important: Void elements na closing tag lihaycha nasato. HTML madhye br, hr, img ani input he common void elements aahet.

3. What is an HTML Element?

HTML Element mhanje opening tag, content ani closing tag yanchi combination.

Eka complete HTML element madhye tag ani tyachya content cha samavesh hoto.

Example:


<p>Welcome to HTML</p>

Ya example madhil parts:

<p> Opening Tag
Welcome to HTML Content
</p> Closing Tag
  • <p>: Paragraph chi suruvat.
  • Welcome to HTML: Paragraph madhil content.
  • </p>: Paragraph cha shevat.
Remember: Opening tag + Content + Closing tag = HTML Element.

4. Difference Between HTML Tag and Element

Tag ani Element he don related concepts aahet, pan doghancha meaning same nahi.

HTML Tag HTML Element
Markup instruction aste. Complete HTML structure aste.
Opening kiwa closing tag asu shakto. Opening tag, content ani closing tag yanchi combination asu shakte.
Example: <p> Example: <p>Hello</p>
Tag ha element cha ek part aahe. Element madhye tags ani content astat.
Example: 

<h1>My Website</h1>

<h1> ha opening tag aahe. </h1> ha closing tag aahe. Sampurna code ha HTML element aahe.

5. Empty and Void Elements

HTML madhye kahi elements na content kiwa closing tag nasato. Ashya elements na void elements mhantat.

Beginners tyanna empty elements suddha mhantat, pan HTML standard madhye void elements ha adhik precise term aahe.

Common Void Elements:

Element Purpose
<br> Line break denyasathi.
<hr> Thematic break kiwa divider denyasathi.
<img> Image display karnyasathi.
<input> User input ghenyasathi.
<meta> Document metadata denyasathi.
<link> External resource connect karnyasathi.
<area> Image map madhye clickable area define karnyasathi.
<source> Audio kiwa video sathi media source denyasathi.

Example:


<p>Hello<br>Welcome to HTML</p>

<hr>

<img src="photo.jpg" alt="My Photo">

Output:

Hello
Welcome to HTML

Image example: photo.jpg file available asel tar image display hoil.

Important: HTML void elements la </br> kiwa </img> ashe closing tags lihayche nahit.

6. Nested HTML Elements

Eka HTML element chya aat dusra HTML element lihila, tar tyala Nested Element mhantat.

Modern webpages madhye nesting khup common aahe. Eka section madhye heading, paragraph, image ani links asu shaktat.

Example:


<div>

    <h1>My Website</h1>

    <p>
        Welcome to my
        <strong>Website</strong>.
    </p>

</div>

Explanation:

  • <div> ha outer element aahe.
  • <h1> ha div chya aat aahe.
  • <p> ha suddha div chya aat aahe.
  • <strong> ha paragraph chya aat aahe.

Output:

My Website

Welcome to my Website.

Tip: HTML elements nest kartana opening ani closing tags yogya order madhye lihine important aahe.

7. Parent and Child Elements

Nested HTML structure madhye outer element la Parent Element mhantat ani tyachya aat asnarya element la Child Element mhantat.

Example:


<div>

    <h2>Student Details</h2>

    <p>Name: Rohan</p>

</div>

Relationship:

<div> - Parent Element
<h2> - Child Element
<p> - Child Element
  • <div> ha h2 ani p cha parent aahe.
  • <h2> ani <p> he div che children aahet.

Important Terms:

  • Parent: Jyachya aat dusra element asto.
  • Child: Jo element parent chya direct aat asto.
  • Sibling: Ekach parent che children aslele elements.
  • Descendant: Parent chya aat direct kiwa indirectly asnara element.

8. Proper HTML Nesting

HTML elements ekmekanchya aat lihitana closing tags yogya order madhye lihine avashyak aahe. Ya process la proper nesting mhantat.

Correct Nesting:


<p>
    This is
    <strong>important</strong>
    text.
</p>

Incorrect Nesting:


<p>
    This is
    <strong>important
</p>
    </strong>
Correct Rule: Jo element shevti open kela aahe, to sarvat aadhi close karaycha. Tyala Last In, First Out order mhantat.

Another Example:


<div>
    <p>
        <strong>Hello World</strong>
    </p>
</div>

9. Block-Level Elements

Block-level elements normally navin line pasun suru hotat ani available horizontal space ghetat. CSS ne tyanchi display behavior badalta yete.

Common Block-Level Elements:

  • <div> - General content container.
  • <p> - Paragraph.
  • <h1> to <h6> - Headings.
  • <section> - Page section.
  • <article> - Independent content.
  • <ul> - Unordered list.
  • <ol> - Ordered list.
  • <header> - Header section.
  • <footer> - Footer section.

Example:


<h2>First Heading</h2>

<p>First Paragraph</p>

<div>First Division</div>

Output:

First Heading

First Paragraph

First Division

Ya example madhye pratyek block element normally veglya line var display hoto.

10. Inline Elements

Inline elements normally tyanchya content purtich space ghetat ani same line madhye display hotat.

Common Inline Elements:

  • <span> - Inline container.
  • <a> - Hyperlink.
  • <strong> - Strong importance.
  • <em> - Emphasis.
  • <b> - Attention sathi bold text.
  • <i> - Alternate voice kiwa mood text.
  • <label> - Form control label.
  • <small> - Small print.

Example:


<p>
    Welcome to
    <strong>HTML</strong>
    and
    <em>CSS</em>.
</p>

Output:

Welcome to HTML and CSS.

Ya example madhye strong ani em he paragraph chya same line madhye display hotat.

11. Block vs Inline Elements

Block Elements Inline Elements
Normally new line pasun start hotat. Normally same line madhye display hotat.
Available width ghetat. Content purtich width ghetat.
Example: div, p, h1. Example: span, a, strong.
CSS display property ne behavior change karta yete. CSS display property ne behavior change karta yete.
Important: Block ani Inline he elements che traditional display behavior samjnyasathi vaprale janare terms aahet. CSS display property mule final layout badlu shakto.

12. Practical Example - Student Details

Ata apan HTML tags, elements, nesting, block ani inline elements use karun ek simple Student Details section tayar karu.

Code:


<div>

    <h2>Student Details</h2>

    <p>Name: Rohan Jagtap</p>

    <p>Course: <strong>B.Sc Computer Science</strong></p>

    <p>Subject: <span>Computer Science</span></p>

</div>

Output:

Student Details

Name: Rohan Jagtap

Course: B.Sc Computer Science

Subject: Computer Science

Explanation:

  • <div> complete content group karte.
  • <h2> student details chi heading dakhavte.
  • <p> student information display karte.
  • <strong> course la importance dete.
  • <span> inline content group karte.

13. Common Beginner Mistakes

Mistake 1: Closing Tag visarne

Paragraph kiwa heading sarkhya elements che closing tags yogya prakare lihayla havet.

Mistake 2: Incorrect Nesting

Elements open ani close kartana proper order maintain karne avashyak aahe.

Mistake 3: Void Element la Closing Tag dene

img, br ani input sarkhya void elements na closing tags nastat.

Mistake 4: Tag ani Element same samajne

Tag ha markup instruction aahe, tar element hi complete HTML structure aahe.

Mistake 5: Block ani Inline madhil difference mahit nasne

Donhi elements chi normal display behavior vegli aste. CSS ne ti change karta yete.

14. Quick Revision

  • Inline elements normally same line madhye display hotat.
