HTML Iframes

Iframe vaprun eka webpage madhye dusra webpage, YouTube video kiwa Google Maps embed karne shikuya.

Beginner Level 35–40 Minutes

1. What is an Iframe?

Iframe mhanje Inline Frame. HTML madhye <iframe> element cha use eka webpage madhye dusra webpage kiwa external content display karnyasathi hoto.

Examples:

  • Website madhye YouTube video display karne.
  • Website madhye Google Maps display karne.
  • External webpage embed karne.
  • Online documents kiwa other supported content display karne.
Simple Definition: Iframe mhanje eka webpage madhye dusra webpage kiwa external content display karnyasathi vaparla janara HTML element.

2. HTML Iframe Element

Iframe create karnyasathi <iframe> element vaparto.

Syntax:


<iframe src="https://example.com">

</iframe>

Explanation:

  • iframe = Inline Frame create karto.
  • src = Display karaychya webpage cha URL specify karto.
  • Closing iframe tag = Iframe element close karto.

Example:


<iframe
    src="https://example.com"
    title="Example Website">
</iframe>

Ya example madhye browser example.com webpage iframe madhye load karnyacha prayatna karto.

Important: Pratyek website iframe madhye load hoilach ase nahi. Website security settings mule embedding block karu shakte.

3. Iframe Width and Height

Iframe chi width ani height set karnyasathi width ani height attributes vaparta yetat.

Example:


<iframe
    src="https://example.com"
    width="600"
    height="400"
    title="Example Website">
</iframe>

Explanation:

  • width = Iframe chi width set karto.
  • height = Iframe chi height set karto.

4. Iframe Important Attributes

Attribute Purpose
src External content cha URL specify karto.

width Iframe chi width set karto.
height Iframe chi height set karto.

allow Iframe madhil content la specific features chi permission deto.
sandbox Iframe madhil content var additional restrictions apply karto.
referrerpolicy Referrer information kashi send karaychi te control karto.
allowfullscreen Iframe content la fullscreen mode allow karto.

5. YouTube Video Embed

Website madhye YouTube video display karnyasathi iframe vaparta yeto.

Step 1: YouTube Video Open Kar

YouTube var video open kar ani Share option madhun Embed option select kar.

Step 2: Embed URL Samjun Ghe

YouTube embed URL cha format asa asto: 


https://www.youtube.com/embed/VIDEO_ID

VIDEO_ID chya jagi actual YouTube video ID specify karaychi aste.

Step 3: HTML Code


<iframe
    width="560"
    height="315"
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="YouTube Video Player"
    allowfullscreen>
</iframe>
Remember: YouTube video chi normal watch URL ani embed URL vegli asu shakte. Embed karnyasathi YouTube cha Embed option vaprane best aahe.
Important: VIDEO_ID replace karun actual video ID tak. Video owner ne embedding allow keli nasel tar video iframe madhye play honar nahi.

6. Google Maps Embed

Website madhye location kiwa address display karnyasathi Google Maps iframe embed karta yeto.

Step 1: Google Maps Open Kar

Google Maps madhye required location search kar.

Step 2: Share Option Select Kar

Share option madhye Embed a map select kar. Tyanantar HTML embed code copy kar.

Step 3: HTML Code


<iframe
    src="GOOGLE_MAPS_EMBED_URL"
    width="600"
    height="450"
    title="Google Maps Location"
    loading="lazy">
</iframe>
Tip: Google Maps cha actual embed URL use kar. Fakt normal Google Maps link iframe madhye taklyane map display hoilach ase nahi.

7. Loading Attribute

Loading attribute iframe browser madhye kevha load karaycha yachi hint provide karto.

Loading Lazy:

loading="lazy" vaparlyas iframe viewport chya javal alyavar load honyas madat hote. 


<iframe
    src="https://example.com"
    title="Example Website"
    loading="lazy">
</iframe>

Loading Eager:

loading="eager" vaparlyas iframe lavkar load karnyacha browser prayatna karto. 


<iframe
    src="https://example.com"
    title="Example Website"
    loading="eager">
</iframe>
Remember: Lazy loading mule initial page loading madhye unnecessary external content load karne kami hou shakte.

8. Allow Attribute

Allow attribute iframe madhil content la specific browser features use karnyachi permission denyasathi vaparto.

Udaharanarth autoplay, fullscreen kiwa picture-in-picture.

Example:


<iframe
    src="VIDEO_EMBED_URL"
    title="Video Player"
    allow="fullscreen; picture-in-picture"
    allowfullscreen>
</iframe>
Important: Allow attribute permission specify karto. Pan browser settings, user permissions ani iframe provider restrictions suddha apply hotat.

9. Sandbox Attribute

Sandbox attribute iframe madhil content var additional restrictions apply karnyasathi vaparto.

Example:


<iframe
    src="https://example.com"
    title="Restricted Content"
    sandbox>
</iframe>

Sandbox attribute without permissions vaparlyas iframe madhil content var strict restrictions apply hotat.

Common Sandbox Permissions:

Permission Purpose
allow-scripts Iframe madhil scripts execute karu deto.
allow-forms Forms submit karu deto.
allow-popups Popups open karnyas permission deto.
allow-downloads Downloads allow karto.
allow-same-origin Content la tyacha normal origin retain karu deto.

Example with Permissions:


<iframe
    src="https://example.com"
    title="Sandbox Example"
    sandbox="allow-scripts allow-forms">
</iframe>
Security Note: Sandbox permissions vicharpurvak vapr. allow-scripts ani allow-same-origin ekatra same-origin content sathi vaparlyas sandbox protection kamjor hou shakte.

10. Referrer Policy

Referrerpolicy attribute external website kade request jatana referrer information kashi send karaychi te control karto.

Example:


<iframe
    src="https://example.com"
    title="Example Website"
    referrerpolicy="strict-origin-when-cross-origin">
</iframe>

Ya example madhye browser cross-origin request sathi full URL path share na karta policy nusar referrer information handle karto.

11. Responsive Iframe Design

Website mobile, tablet ani desktop var properly display honyasathi iframe responsive banavne important aahe.

HTML Code:


<div class="iframe-container">

    <iframe
        src="VIDEO_EMBED_URL"
        title="Responsive Video"
        allowfullscreen>
    </iframe>

</div>

CSS Code:


.iframe-container {
    position: relative;
    width: 100%;
    aspect-ratio: 16 / 9;
}

.iframe-container iframe {
    width: 100%;
    height: 100%;
    border: none;
}

12. Iframe Security and Permissions

Iframe madhye external website load hot aslyamule security ani privacy lakshat ghene important aahe.

  • Trusted websites cha content embed kar.
  • Garjenusar sandbox attribute vapr.
  • Iframe la meaningful title provide kar.
  • Unnecessary permissions allow karu naye.
  • External content cha loading carefully handle kar.
  • Sensitive information iframe madhye expose karu naye.
Important: Iframe content third-party website control karte. Tya website cha content, privacy ani security policies suddha lakshat ghe.

13. Common Beginner Mistakes

Mistake 1: Wrong URL

Iframe madhye correct webpage kiwa embed URL provide karne necessary aahe.

Mistake 2: Title Attribute विसरणे

Accessibility sathi iframe la meaningful title provide kar.

Mistake 3: Every Website Embed Hoil Ase Samajne

Website security policies mule iframe embedding block hou shakte.

Mistake 4: Responsive Design Ignore Karne

Fixed width mule mobile layout madhye horizontal scrolling hou shakte.

Mistake 5: Unnecessary Permissions Denе

Allow ani sandbox attributes vicharpurvak vapr.

Mistake 6: Wrong Embed URL

YouTube ani Google Maps sathi tyanchya official embed options madhun URL ghe.
