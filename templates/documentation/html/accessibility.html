HTML Accessibility

Website sarva users sathi accessible, understandable ani easy to use kashi banvaychi te shikuya.

Beginner Level 35–40 Minutes

1. What is Web Accessibility?

Web Accessibility mhanje website ashi design ani develop karne ki sarva lokanna website access ani use karta yeil.

Yat visual, hearing, physical kiwa cognitive difficulties aslelya users cha suddha vichar kela jato.

Examples:

  • Blind users screen readers use karu shaktat.
  • Hearing difficulties aslelya users sathi captions.
  • Keyboard vaprun website navigate karta yene.
  • Text readable ani clear asne.
  • Images sathi alternative text provide karne.
Simple Definition: Web Accessibility mhanje website sarva users sathi accessible ani usable banavne.

2. Importance of Accessibility

Accessibility mule website jast users sathi usable bante.

Benefits:

  • More users website use karu shaktat.
  • Screen reader users na content samajto.
  • Keyboard navigation improve hote.
  • Forms use karne sope hote.
  • Website cha overall user experience improve hoto.
Remember: Accessibility hi website development madhil important requirement aahe.

3. Alt Attribute

Alt attribute image cha text description provide karto.

Screen reader image cha alt text read karu shakto. Image load zali nahi tari description useful tharte.

Example:


<img src="student.jpg"
     alt="Student studying computer science">

Decorative Image:

Image fakt decoration sathi asel ani additional information det nasel tar empty alt attribute vapru shakto. 


<img src="decoration.png" alt="">

Important Points:

  • Image cha meaning describe kara.
  • Meaningful alt text liha.
  • Unnecessary keywords add karu naka.
  • Decorative images sathi alt="" vapra.
Important: Alt text image chya purpose nusar asava. Fakt image cha filename alt madhye deu naka.

4. Labels and Form Accessibility

Form madhil input fields sathi proper label use karne important aahe.

Label mule screen reader users la input field cha purpose samajto.

Example:


<label for="username">
    Username:
</label>

<input type="text"
       id="username"
       name="username">

Important Points:

  • Label cha for attribute input chya id shi match asava.
  • Pratyek important input la label dya.
  • Placeholder ha label cha replacement nahi.
  • Error messages clear ani understandable theva.

5. Semantic HTML and Accessibility

Semantic HTML elements webpage madhil content cha meaning define kartat.

Screen readers ani assistive technologies semantic elements cha use karun webpage structure samjun gheu shaktat.

Important Elements:

Element Purpose
<header> Header section define karto.
<nav> Navigation area define karto.
<main> Main content define karto.
<article> Independent content define karto.
<section> Thematic section define karto.
<footer> Footer information define karto.

Example:


<header>
    <h1>My Website</h1>
</header>

<nav aria-label="Main navigation">
    <a href="/">Home</a>
    <a href="/about/">About</a>
</nav>

<main>
    <article>
        <h2>About HTML</h2>
        <p>HTML creates webpage structure.</p>
    </article>
</main>

<footer>
    <p>Copyright 2026</p>
</footer>
Tip: Semantic HTML vaparlyane unnecessary generic div elements cha use kami hoto ani document structure clear hote.

6. Keyboard Navigation

Kahi users mouse aivaji keyboard vaprun website operate kartat.

Keyboard navigation mule user webpage madhil links, buttons ani form controls access karu shakto.

Important Keyboard Keys:

Key Purpose
Tab Next focusable element var jate.
Shift + Tab Previous focusable element var jate.
Enter Focused link kiwa button activate karto.
Space Button activate karto.
Arrow Keys Kahi controls madhye navigation kartat.

Example:


<a href="/home/">Home</a>

<button type="button">
    Click Me
</button>

<input type="text" placeholder="Enter name">
Practical Test: Mouse use na karta Tab key press karun webpage madhil interactive elements navigate kar.

7. tabindex Attribute

tabindex attribute element keyboard focus order madhye include karayla kiwa focus programmatically set karayla use hoto.

Important Values:

Value Meaning
tabindex="0" Normal keyboard tab order madhye include hoto.
tabindex="-1" Tab key ne normally focus hot nahi, pan script ne focus karta yeto.
tabindex="1" Positive tab order create karto.

Example:


<div tabindex="0">
    This element can receive keyboard focus.
</div>

<div tabindex="-1">
    This element can receive programmatic focus.
</div>
Important: Positive tabindex values generally avoid kara. Te natural keyboard navigation order confusing banvu shaktat.

8. ARIA Attributes

ARIA cha full form Accessible Rich Internet Applications aahe.

ARIA attributes assistive technologies la elements cha role, state ani additional information samjun ghenyas madat kartat.

Important ARIA Attributes:

Attribute Purpose
aria-label Element la accessible name provide karto.
aria-labelledby Dusrya element cha text label mhanun use karto.
aria-describedby Additional description connect karto.
aria-hidden Assistive technology pasun content hide karto.
aria-expanded Expandable content chi state sangto.

Example 1: aria-label


<button aria-label="Close menu">
    X
</button>

Example 2: aria-describedby


<label for="password">
    Password:
</label>

<input type="password"
       id="password"
       aria-describedby="passwordHelp">

<p id="passwordHelp">
    Password must contain at least 8 characters.
</p>
Important: Native HTML elements first prefer kara. ARIA mule missing accessibility features provide karta yetat, pan ARIA semantic HTML cha replacement nahi.

9. Accessible HTML Tables

Table madhil data samjun ghenyasathi proper table headings ani structure use karne important aahe.

Example:


<table>

    <caption>Student Marks</caption>

    <thead>
        <tr>
            <th scope="col">Name</th>
            <th scope="col">Marks</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <th scope="row">Rohan</th>
            <td>85</td>
        </tr>
    </tbody>

</table>

Output:

Student Marks
Name Marks
Rohan 85

Important Points:

  • Table sathi caption provide kara.
  • Column headings sathi th use kara.
  • scope attribute cha proper use kara.
  • Table layout sathi nahi, tabular data sathi use kara.

10. Color Contrast and Readability

Website madhil text ani background madhye sufficient color contrast asne important aahe.

Low contrast mule kahi users na text vachne difficult hou shakte.

Good Contrast Example:

This text is easy to read.

Poor Contrast Example:

This text is difficult to read.

Important Points:

  • Text readable color madhye theva.
  • Text ani background madhye contrast theva.
  • Fakt color vaprun information deu naka.
  • Text size ani spacing proper theva.
WCAG Reference: WCAG 2.2 AA madhye normal text sathi generally 4.5:1 contrast ratio ani large text sathi 3:1 ratio required aahe.

11. Complete Accessible HTML Form

Ata apan labels, fieldset, legend, required ani aria-describedby vaprun accessible registration form create karu.

HTML Code:


<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Accessible Registration Form</title>

</head>

<body>

    <main>

        <h1>Registration Form</h1>

        <form>

            <fieldset>

                <legend>Personal Information</legend>

                <label for="name">
                    Full Name:
                </label>

                <input type="text"
                       id="name"
                       name="name"
                       required>

                <label for="email">
                    Email:
                </label>

                <input type="email"
                       id="email"
                       name="email"
                       required>

                <label for="password">
                    Password:
                </label>

                <input type="password"
                       id="password"
                       name="password"
                       aria-describedby="passwordHelp"
                       required>

                <p id="passwordHelp">
                    Password must contain at least 8 characters.
                </p>

                <button type="submit">
                    Register
                </button>

            </fieldset>

        </form>

    </main>

</body>

</html>

Output:

Registration Form

Personal Information

Password must contain at least 8 characters.

Tip: Fieldset related form fields group karto ani legend tya group cha title provide karto.

12. Common Accessibility Mistakes

Mistake 1: Missing Alt Text

Meaningful images sathi appropriate alt description provide na karne.

Mistake 2: Missing Form Labels

Input fields la proper label connect na karne.

Mistake 3: Poor Color Contrast

Text ani background madhye insufficient contrast thevne.

Mistake 4: Keyboard Navigation Block Karne

Website mouse shivay use karta na yene.

Mistake 5: Unnecessary ARIA

Native HTML element available asatana unnecessary ARIA attributes use karne.

Mistake 6: Removing Focus Indicator

Keyboard user la current focused element samajnyasathi visual indication nasne.
