HTML Entities

HTML madhye special characters, symbols ani reserved characters display karnyasathi HTML Entities kasa vapraycha te shikuya.

Beginner Level 30–35 Minutes

1. What are HTML Entities?

HTML Entities mhanje special characters kiwa reserved symbols webpage var display karnyasathi vaparlya janarya special codes.

HTML madhye kahi characters la special meaning aste. Tyamule te direct use karnyapeksha tyanchi entity vaprane necessary aste.

Examples:

  • &lt; = Less Than (<)
  • &gt; = Greater Than (>)
  • &amp; = Ampersand (&)
  • &copy; = Copyright (©)
  • &nbsp; = Non-Breaking Space
Simple Definition: HTML Entities mhanje special characters display karnyasathi vaparlya janarya character codes.

2. Why HTML Entities are Used?

HTML madhye kahi characters reserved astat. Tyanna normal text mhanun display karnyasathi HTML Entities vapartat.

Reasons:

  • Reserved characters display karnyasathi.
  • Special symbols display karnyasathi.
  • Currency symbols display karnyasathi.
  • Mathematical symbols display karnyasathi.
  • Copyright ani trademark symbols display karnyasathi.
  • Non-breaking spaces create karnyasathi.
Important: HTML madhye less-than (<) ani greater-than (>) characters tags define karnyasathi vapartat. Tyanna normal text mhanun display karnyasathi entities vaprane important aahe.

3. HTML Entity Syntax

HTML Entities lihinyasathi mainly don formats vaparta yetat.

1. Entity Name


&entity_name;

2. Entity Number


&#entity_number;

Numeric entities madhye decimal character code vapartat.

3. Hexadecimal Entity Number


&#xhexadecimal_number;

Hexadecimal entity madhye number chya aadhi x vapartat.

Example:


<p>&copy;</p>

<p>&#169;</p>

<p>&#xA9;</p>

Output:

©

©

©

Tinhihi examples madhye same copyright symbol display hoto.

4. Reserved HTML Characters

HTML madhye kahi characters special purpose sathi reserved astat.

Entity Character Meaning
&lt; < Less Than
&gt; > Greater Than
&amp; & Ampersand
&quot; " Double Quote
&apos; ' Apostrophe

Example:


<p>5 &lt; 10</p>

<p>10 &gt; 5</p>

<p>HTML &amp; CSS</p>

<p>He said &quot;Hello&quot;</p>

<p>It&apos;s my website.</p>

Output:

5 < 10

10 > 5

HTML & CSS

He said "Hello"

It's my website.

5. Copyright and Trademark Symbols

HTML Entities vaprun copyright, trademark ani registered symbols display karta yetat.

Example:

6. Non-Breaking Space

&nbsp; mhanje Non-Breaking Space. Yacha use don words madhye space denyasathi hoto, pan browser la tya space var line break karu det nahi.

Example:


<p>Rohan&nbsp;Jagtap</p>

Output:

Rohan Jagtap

Ya example madhye Rohan ani Jagtap ya don words madhye non-breaking space aahe.

Tip: Normal spacing ani layout design sathi CSS vaprane better aahe. &nbsp; cha use specific non-breaking space garjesathi kar.

8. Mathematical Symbols

HTML Entities vaprun mathematical ani comparison symbols suddha display karta yetat.

Entity Symbol Meaning
&plusmn; ± Plus Minus
&times; × Multiplication
&divide; ÷ Division
&ne; ≠ Not Equal
&le; ≤ Less Than or Equal
&ge; ≥ Greater Than or Equal
&infin; ∞ Infinity
&radic; √ Square Root

Example:


<p>10 &plusmn; 2</p>

<p>5 &times; 4 = 20</p>

<p>10 &divide; 2 = 5</p>

<p>5 &ne; 10</p>

<p>5 &le; 10</p>

<p>10 &ge; 5</p>

<p>Infinity: &infin;</p>

<p>Square Root: &radic;25 = 5</p>

Output:

10 ± 2

5 × 4 = 20

10 ÷ 2 = 5

5 ≠ 10

5 ≤ 10

10 ≥ 5

Infinity: ∞

Square Root: √25 = 5

10. HTML Entity Names vs Entity Numbers

Ekach character display karnyasathi entity name kiwa numeric entity donhi vaparta yetat.

Entity Name Entity Number Output
&copy; &#169; ©
&reg; &#174; ®
&trade; &#8482; ™
&lt; &#60; <
&gt; &#62; >

Example:


<p>&copy;</p>

<p>&#169;</p>

<p>&#xA9;</p>

Tinhihi methods ne copyright symbol display hoto.

Tip: Entity names lakshat thevne generally easy aste. Pan kahi characters sathi numeric entities suddha vaparta yetat.

12. Common Beginner Mistakes

Mistake 1: Less Than Character Directly Use Karne

Normal text madhye less-than symbol display karnyasathi &lt; vapr.

Mistake 2: Entity Semicolon Visarne

Entity name lihilyanantar normally semicolon vapr. Udaharan: &copy;

Mistake 3: Wrong Entity Name

Entity name exact lih. Spelling chuklyas expected character display honar nahi.

Mistake 4: Normal Space Sathi Khup NBSP Vap rane

Layout spacing sathi CSS vapr. Non-breaking space fakt garjenusar vapr.

Mistake 5: Entity Name Ani Number Confuse Karne

Entity name ani numeric entity yanchi syntax vegli aste. Donhi formats yogya vapr.
