HTML Links

HTML madhye hyperlinks kase create karayche, href attribute, absolute ani relative URLs, email links, telephone links ani bookmark links ya lesson madhye shikuya.

Beginner Level 35–40 Minutes

1. What are HTML Links?

HTML Links mhanje hyperlinks. Hyperlink cha use eka webpage varun dusrya webpage var navigate karnyasathi hoto.

Links mule apan external websites, same website madhil pages, email addresses ani webpage madhil specific sections open karu shakto.

Examples:

  • Google website open karne.
  • Website madhil About page open karne.
  • Email application open karne.
  • Page madhil specific section var jane.
Simple Definition: HTML Links he hyperlinks aahet je users la eka webpage kiwa resource varun dusrya resource var navigate karu detat.

2. Anchor (<a>) Element

HTML madhye link create karnyasathi anchor element vapartat. Anchor element cha tag a aahe.

Anchor element madhye href attribute vaprun link cha destination define kartat.

Syntax:


<a href="URL">Link Text</a>

Example:


<a href="https://www.google.com">
    Visit Google
</a>

Output:

Visit Google

Explanation:

  • a = Anchor element.
  • href = Link destination define karte.
  • https://www.google.com = Destination URL.
  • Visit Google = User la disnara link text.
Important: href attribute nasel tar anchor element normal working hyperlink create karat nahi.

3. href Attribute

href cha full form Hypertext Reference aahe. Ya attribute cha use hyperlink cha destination specify karnyasathi hoto.

Syntax:


<a href="destination">Click Here</a>

Example:


<a href="https://www.wikipedia.org">
    Open Wikipedia
</a>

Output:

Open Wikipedia

User link var click kelyavar browser specified destination open karto.

4. Absolute URL

Absolute URL madhye resource cha complete web address specify kelela asto. Ya URL madhye protocol ani domain name samavisht astat.

Example:


<a href="https://www.google.com">
    Google
</a>

Another Example:


<a href="https://www.youtube.com">
    YouTube
</a>

Output:

Google

YouTube

Remember: External websites la link detana absolute URL commonly vapartat.

5. Relative URL

Relative URL madhye current webpage chya location nusar dusrya file cha path specify karto. Ya URL madhye complete domain name denyachi garaj naste.

Example:


<a href="about.html">
    About Us
</a>

Ithe about.html hi file current directory madhye asel tar browser ti file open karel.

Folder madhil Page:


<a href="pages/contact.html">
    Contact Us
</a>

Ithe pages folder madhil contact.html file open karnyacha path dila aahe.

Parent Folder madhil Page:


<a href="../index.html">
    Home
</a>

../ cha use current directory chya parent folder madhye janyasathi hoto.

Folder Structure Example:


my-website/
│
├── index.html
│
├── about.html
│
└── pages/
    └── contact.html
Important: Relative URL cha path current document chya location nusar resolve hoto. Folder structure samjun gheun path lihine important aahe.

6. Internal Page Links

Internal links cha use same website madhil dusrya webpage var navigate karnyasathi hoto.

Example:


<!-- Home Page -->

<a href="about.html">
    About Us
</a>

<a href="contact.html">
    Contact Us
</a>

Explanation:

  • about.html About page open karel.
  • contact.html Contact page open karel.

Practical Example:


<h1>My Website</h1>

<a href="about.html">About</a>

<a href="services.html">Services</a>

<a href="contact.html">Contact</a>

Ya prakare website navigation create karta yete.

7. External Website Links

External link cha use aplya website varun dusrya website var navigate karnyasathi hoto.

Example:


<a href="https://www.github.com">
    Visit GitHub
</a>

Output:

Visit GitHub

User ya link var click kelyavar GitHub website open hoil.

8. target Attribute

target attribute cha use link kuthe open karaychi he specify karnyasathi hoto.

Common target Values:

Value Purpose
_self Same browsing context madhye open hote. Ha default aahe.
_blank New tab kiwa browsing context madhye open hote.
_parent Parent browsing context madhye open hote.
_top Top-level browsing context madhye open hote.

Example 1: Same Tab


<a href="https://www.google.com" target="_self">
    Open Google
</a>

Example 2: New Tab


<a
    href="https://www.google.com"
    target="_blank"
    rel="noopener"
>
    Open Google in New Tab
</a>

Output:

Open Google in Same Tab

Open Google in New Tab

Important: target="_blank" vapratana rel="noopener" include karne hi changli security practice aahe.

9. Email Links

HTML madhye mailto: scheme vaprun email link create karta yete. User link var click kelyavar default email application open honyasathi request keli jate.

Syntax:


<a href="mailto:email@example.com">
    Send Email
</a>

Example:


<a href="mailto:rohan@example.com">
    Contact Me
</a>

Output:

Contact Me

Email with Subject:


<a href="mailto:rohan@example.com?subject=Project%20Inquiry">
    Send Project Inquiry
</a>

Ya example madhye email sobat subject suddha specify kelela aahe.

Tip: mailto link vaparlyane email automatically send hot nahi. Email application open hote ani user la email send karavi lagte.

10. Telephone Links

HTML madhye tel: scheme vaprun telephone link create karta yete. Mobile device var click kelyavar phone application open honyasathi request keli jate.

Syntax:


<a href="tel:+911234567890">
    Call Us
</a>

Example:


<a href="tel:+911234567890">
    Call Now
</a>

Output:

Call Now
Remember: Telephone link mobile websites ani contact pages madhye useful aahe.

11. Bookmark Links

Bookmark links cha use same webpage madhil specific section var direct navigate karnyasathi hoto.

Tyasathi destination element la id attribute detat ani anchor chya href madhye # sobat ti id value lihitat.

Example:


<a href="#contact">
    Go to Contact Section
</a>

<h2 id="contact">
    Contact Us
</h2>

<p>
    Contact us for more information.
</p>

Output:

Go to Contact Section

Other webpage content...

More information...

Contact Us

Contact us for more information.

Explanation:

  • href="#contact" destination id specify karte.
  • id="contact" destination element identify karte.
  • Link click kelyavar browser tya section kade navigate karto.

12. Download Attribute

download attribute cha use link target file download karnyasathi suggest karnyasathi hoto. Browser download action karu shakto.

Syntax:


<a href="file.pdf" download>
    Download PDF
</a>

Example:


<a href="notes.pdf" download>
    Download Notes
</a>

Ya example madhye notes.pdf file download karnyacha option dila aahe.

Important: download attribute cha behavior browser ani resource origin var depend karu shakto. Cross-origin URLs sathi download force hoilach ase nahi.

13. Image as a Link

Anchor element madhye image element place karun image la clickable link banavta yete.

Example:


<a href="https://www.google.com">

    <img
        src="google-logo.png"
        alt="Visit Google"
        width="150"
    >

</a>

Ata image var click kelyavar Google website open hoil.

Output Example:

Google Website
Tip: Image link vapratana alt text madhye link cha purpose describe karne useful aahe.

14. Links with CSS

CSS vaprun links cha color, background, underline ani hover effect change karta yeto.

HTML Code:


<a class="my-link" href="https://www.google.com">
    Visit Google
</a>

CSS Code:


.my-link {
    color: blue;
    text-decoration: none;
}

.my-link:hover {
    color: red;
    text-decoration: underline;
}

Output:

Visit Google

Mouse link var gheun gelyavar hover effect apply hoto.

15. Link States in CSS

CSS madhye link chya vegveglya states sathi pseudo-classes vaparta yetat.

State Purpose
:link Unvisited link select karte.
:visited Visited link select karte.
:hover Mouse pointer link var asatana select karte.
:active Link activate hot asatana select karte.
:focus Keyboard kiwa dusrya method ne focus milaleli link select karte.

CSS Example:


a:link {
    color: blue;
}

a:visited {
    color: purple;
}

a:hover {
    color: red;
}

a:active {
    color: green;
}

a:focus {
    outline: 2px solid blue;
}
Important: Keyboard users sathi focus style visible thevne accessibility sathi important aahe.

16. Common Beginner Mistakes

Mistake 1: href attribute विसरणे

Working hyperlink sathi destination specify karnyasathi href vapr.

Mistake 2: Wrong URL lihine

URL kiwa relative file path chukicha asel tar link expected page open karu shakat nahi.

Mistake 3: Relative ani Absolute URL confuse karne

External website sathi complete URL ani same project madhil files sathi appropriate relative path vapr.

Mistake 4: target="_blank" sobat security ignore karne

New tab madhye external link open kartana rel="noopener" include karne changli practice aahe.

Mistake 5: Empty Link Text vaprane

Link text meaningful thev, jenekarun user la link kuthe gheun jail he samjel.

Mistake 6: Bookmark sathi wrong ID vaprane

href madhil # nantar dileli value ani destination element chi id same pahije.
