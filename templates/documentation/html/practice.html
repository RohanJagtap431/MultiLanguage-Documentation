2. HTML Basics Questions

Q1. What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

Q2. Is HTML a programming language?

No. HTML is a markup language, not a programming language.

Q3. What is the full form of HTML?

HyperText Markup Language.

Q4. What is the use of DOCTYPE?

DOCTYPE tells the browser that the document uses HTML5.

Q5. What is the use of the title tag?

The title tag defines the title displayed in the browser tab.

Q6. What is the difference between HTML and CSS?

HTML creates the structure of a webpage, while CSS controls its appearance and design.

3. HTML Document Structure Questions

Q1. What is the root element of an HTML document?

The html element is the root element.

Q2. What is the use of the head tag?

It contains document information such as title, metadata and linked resources.

Q3. What is the use of the body tag?

It contains the content displayed on the webpage.

Q4. What is the use of meta charset?

It defines the character encoding of the HTML document.

Basic HTML Structure


<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My Webpage</title>
</head>

<body>

    <h1>Hello World</h1>
    <p>Welcome to HTML.</p>

</body>
</html>

4. Elements and Attributes Questions

Q1. What is an HTML element?

An HTML element generally consists of an opening tag, content and a closing tag.

Q2. What are void elements?

Void elements do not have closing tags or child content.

Examples: img, br, hr, input and meta.

Q3. What are HTML attributes?

Attributes provide additional information about HTML elements.

Q4. What is the use of the id attribute?

The id attribute gives a unique identifier to an HTML element within a document.

Q5. What is the difference between id and class?

An id identifies a particular element, while a class can be shared by multiple elements.

Example:


<h1 id="heading">Welcome</h1>

<p class="description">
    Learn HTML step by step.
</p>

5. Headings, Links, Images and Lists

Q1. How many heading tags are available in HTML?

There are six heading tags, from h1 to h6.

Q2. Which tag is used to create a hyperlink?

The anchor tag (a) is used to create hyperlinks.

Q3. Which attribute is used to specify a link?

The href attribute is used.

Q4. Which tag is used to display an image?

The img tag is used to display images.

Q5. What is the difference between ul and ol?

ul creates an unordered list, while ol creates an ordered list.

Example:


<h1>My Skills</h1>

<ul>
    <li>Python</li>
    <li>Django</li>
    <li>HTML</li>
</ul>

<a href="https://example.com">
    Visit Website
</a>

<img src="photo.jpg" alt="My Photo">

6. Tables and Forms Questions

Q1. Which tag creates an HTML table?

The table tag creates an HTML table.

Q2. What is the use of tr?

tr defines a table row.

Q3. What is the difference between th and td?

th defines a header cell, while td defines a normal data cell.

Q4. What is the use of the form tag?

The form tag collects and submits user data.

Q5. What is the difference between GET and POST?

GET sends form data through URL parameters. POST sends data in the request body.

Q6. Why is the name attribute important in forms?

The name attribute identifies form fields when their data is submitted.

Q7. What is the use of required?

It makes a form field mandatory before normal form submission.

7. Semantic HTML Questions

Q1. What is Semantic HTML?

Semantic HTML uses meaningful elements that describe the purpose of content.

Q2. What is the use of header?

It represents introductory content or a section header.

Q3. What is the use of nav?

It represents a section containing important navigation links.

Q4. What is the use of main?

It represents the main content of the webpage.

Q5. What is the use of article?

It represents independent and self-contained content.

Example:


<header>
    <h1>My Website</h1>
</header>

<nav>
    <a href="#home">Home</a>
    <a href="#about">About</a>
</nav>

<main>
    <article>
        <h2>HTML Tutorial</h2>
        <p>Learn HTML basics.</p>
    </article>
</main>

<footer>
    <p>Copyright 2026</p>
</footer>

8. HTML5 Features Questions

Q1. What is HTML5?

HTML5 is a major revision of HTML that introduced features such as semantic elements and native audio and video support.

Q2. Which tag is used to play audio?

The audio tag is used.

Q3. Which tag is used to play video?

The video tag is used.

Q4. What is the use of canvas?

Canvas provides a drawing area that can be controlled using JavaScript.

Q5. What is the difference between localStorage and sessionStorage?

localStorage stores data across browser sessions, while sessionStorage stores data for a page session.

9. SEO and Accessibility Questions

Q1. What is SEO?

SEO stands for Search Engine Optimization. It helps improve a website's visibility in search engine results.

Q2. What is the use of meta description?

It provides a short description of a webpage for search engines.

Q3. What is the use of alt attribute?

It provides alternative text for an image.

Q4. What is Web Accessibility?

Accessibility means making websites usable for people with different abilities.

Q5. Why are labels important in forms?

Labels identify form controls and help users understand their purpose.
