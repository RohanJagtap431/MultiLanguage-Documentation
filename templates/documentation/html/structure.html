HTML Document Structure

HTML document chi basic structure, important tags, head section, body section ani complete HTML boilerplate ya lesson madhye samjun gheu.

Beginner Level 30–35 Minutes

1. What is HTML Document Structure?

HTML Document Structure mhanje HTML webpage madhil vegveglya sections chi arrangement. Pratyek HTML document la ek basic structure aste.

Ya structure mule browser la webpage madhil content kasa organize kela aahe he samajte. HTML document madhye document type declaration, html element, head section ani body section astat.

Simple Definition: HTML Document Structure mhanje webpage tayar karnyasathi vaparlya janarya HTML elements chi proper arrangement.

2. Basic HTML Document Structure

Khali ek basic HTML document structure dile aahe. Pratyek HTML page lihitana ya structure cha use karto.

Basic Syntax:


<!DOCTYPE html>

<html lang="en">

    <head>
        <title>My First Website</title>
    </head>

    <body>

        <h1>Hello World</h1>

        <p>Welcome to my website.</p>

    </body>

</html>

Structure Explanation:

  1. <!DOCTYPE html> - Browser la document HTML5 standard vaparto he sangte.
  2. <html> - Complete HTML document cha root element aahe.
  3. <head> - Webpage baddal metadata ani settings thevnyasathi.
  4. <title> - Browser tab madhye webpage che title dakhavte.
  5. <body> - Webpage var disnara main content thevte.

3. DOCTYPE Declaration

DOCTYPE cha full meaning Document Type Declaration asa aahe. HTML document chya suruvatila DOCTYPE declaration lihitat.

HTML5 madhye tyachi syntax: 


<!DOCTYPE html>

Why is DOCTYPE Used?

  • Browser la HTML document cha standard sangte.
  • Browser la standards mode madhye render karayla madat karte.
  • Modern HTML documents madhye hi declaration vapartat.
Important: DOCTYPE ha HTML tag nahi. Hi document type declaration aahe. Hi HTML document madhye sarvat aadhi lihaychi aste.

Example:


<!DOCTYPE html>
<html>
    <body>
        <h1>My Website</h1>
    </body>
</html>

4. HTML Root Element

<html> ha HTML document cha root element aahe. Document madhil itar HTML elements ya root element chya aat astat.

Syntax:


<html lang="en">

    <head>
        <title>My Website</title>
    </head>

    <body>
        <h1>Welcome</h1>
    </body>

</html>

lang Attribute:

lang attribute mule document madhil main language konti aahe he browser ani assistive technologies la samajnyas madat hote. 


<html lang="en">

Ithe en mhanje English language. Marathi document sathi lang="mr" vaparta yete.

Tip: HTML document madhye root element la lang attribute dene hi changli practice aahe.

5. Head Section

<head> element madhye webpage baddal mahiti, metadata, title, CSS links ani itar settings thevtat.

Head madhil bahutek content directly webpage var disat nahi. To browser ani search engines sathi useful asto.

Syntax:


<head>

    <title>My Website</title>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

</head>

Head madhye vaparlya janarya elements:

  • <title>: Browser tab madhye page title dakhavte.
  • <meta>: Document baddal metadata provide karte.
  • <link>: External CSS file connect karnyasathi vapartat.
  • <style>: Internal CSS lihinyasathi vapartat.
  • <script>: JavaScript file kiwa code include karnyasathi vapartat.

6. Title Element

<title> element cha use webpage che title define karnyasathi hoto. He title browser tab madhye diste.

Syntax:


<head>
    <title>Student Registration</title>
</head>

Example:


<!DOCTYPE html>
<html>
<head>
    <title>My Portfolio</title>
</head>
<body>
    <h1>Welcome to My Portfolio</h1>
</body>
</html>
Output: Browser tab madhye My Portfolio he title disel. Webpage chya content madhye Welcome to My Portfolio hi heading disel.
Important: <title> ani <h1> he don vegale elements aahet. Title browser tab sathi aahe, tar h1 webpage var main heading dakhavnyasathi aahe.

7. Meta Tags

<meta> element webpage baddal additional information provide karte. Ya information la metadata mhantat.

Meta elements head section madhye lihitat. Tyanna closing tag nasto.

A. Charset Meta Tag


<meta charset="UTF-8">

UTF-8 character encoding vaparlyamule English, Marathi ani itar anek languages madhil characters yogya prakare handle karta yetat.

B. Viewport Meta Tag


<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

Ya meta tag mule webpage chi viewport width device screen width nusar set hote. Mobile responsive design sathi he important aahe.

C. Description Meta Tag


<meta name="description"
      content="Learn HTML in Roman Marathi.">

Ya tag madhye webpage baddal short description deta yete. Search engines hi information search results madhye vapru shaktat.

D. Author Meta Tag


<meta name="author" content="Website Author">

Ya tag madhye webpage cha author kon aahe he define karta yete.

Tip: UTF-8 ani viewport meta tags pratyek modern HTML webpage madhye include karne changli practice aahe.

8. Body Section

<body> element madhye webpage var display honara main content lihitat.

User la browser madhye je content diste te body section madhye aste.

Body madhye vaparlya janarya elements:

  • Headings
  • Paragraphs
  • Images
  • Links
  • Lists
  • Tables
  • Forms
  • Audio ani Video

Example:


<body>

    <h1>Welcome to My Website</h1>

    <p>This is my first webpage.</p>

    <a href="https://example.com">
        Visit Website
    </a>

</body>

Output:

Welcome to My Website

This is my first webpage.

Visit Website

9. Difference Between Head and Body

HTML document madhye head ani body he don important sections aahet. Pan doghanchi kame vegvegli aahet.

Head Body
Webpage chi metadata thevte. Webpage cha main content thevte.
Title ani meta tags astat. Headings ani paragraphs astat.
CSS links include karu shakto. Images, links, tables ani forms astat.
Bahutek content directly display hot nahi. Content browser madhye display hoto.

10. HTML Comments in Document

HTML comments cha use code madhye notes lihinyasathi hoto. Browser comments webpage var display karat nahi.

Syntax:


<!-- This is an HTML comment -->

Example:


<body>

    <!-- Main heading -->
    <h1>My Website</h1>

    <!-- Introduction paragraph -->
    <p>Welcome to my website.</p>

</body>

Output:

My Website

Welcome to my website.

Tip: Comments code samjun ghenyasathi useful astat. Sensitive information comments madhye thevu naye, karan page source madhun comments disu shaktat.

11. Complete HTML Boilerplate

HTML Boilerplate mhanje navin HTML webpage suru karnyasathi vaparla janara basic ready structure. Pratyek navin HTML project madhye ha structure use karta yeto.

Complete Code:


<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <meta name="description"
          content="My first HTML webpage">

    <title>My First Webpage</title>

</head>

<body>

    <h1>Hello World</h1>

    <p>Welcome to my first HTML webpage.</p>

</body>

</html>

Output:

Hello World

Welcome to my first HTML webpage.

Code Explanation:

  1. DOCTYPE browser la HTML standard sangte.
  2. HTML root element complete document contain karte.
  3. Head madhye metadata ani title define kele aahe.
  4. Body madhye heading ani paragraph lihila aahe.
  5. Browser body madhil content webpage var display karto.

12. Common Beginner Mistakes

Mistake 1: DOCTYPE lihayla visarne

HTML document chya beginning la <!DOCTYPE html> lihayla visaru naye.

Mistake 2: Head ani Body confuse karne

Title ani metadata head madhye thevayche, tar visible content body madhye thevaycha.

Mistake 3: Viewport Meta Tag skip karne

Responsive webpage sathi viewport meta tag include karne important aahe.

Mistake 4: Multiple title elements lihine

Eka HTML document madhye ekach title element thevne yogya aahe.

Mistake 5: HTML elements chi nesting chukvine

HTML elements yogya order madhye close karne ani proper nesting thevne avashyak aahe.

13. Important Points

  • HTML document chi basic structure fixed aste.
  • DOCTYPE declaration sarvat aadhi lihitat.
  • HTML ha document cha root element aahe.
  • Head section madhye metadata aste.
  • Title browser tab madhye display hote.
  • Meta tag additional information provide karte.
  • Body section madhye visible webpage content aste.
  • Comments browser madhye display hot nahit.
  • HTML Boilerplate navin webpage sathi basic structure aahe.
