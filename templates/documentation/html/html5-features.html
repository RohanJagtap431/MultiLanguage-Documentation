HTML5 Features

HTML5 madhil modern elements, multimedia, forms ani browser APIs yanchi mahiti gheuya.

Beginner Level 40–45 Minutes

1. What is HTML5?

HTML5 hi HTML chi modern version aahe. Webpages create karnyasathi HTML5 madhye semantic elements, audio-video support, improved forms ani anek navin features introduce kele gele.

HTML5 mule multimedia ani interactive webpages create karne sope zale.

HTML5 Features:

  • Semantic Elements
  • Audio and Video Support
  • New Form Input Types
  • Canvas and SVG Graphics
  • Web Storage
  • Geolocation API
  • Drag and Drop API
Simple Definition: HTML5 hi HTML chi modern version aahe, ji webpages madhye structure, multimedia ani interactive features support karte.

2. HTML4 vs HTML5

HTML4 ani HTML5 madhye kahi important differences aahet.

HTML4 HTML5
Older HTML standard Modern HTML standard
Multimedia sathi plugins commonly lagat Native audio-video elements
Limited semantic elements header, nav, main, footer etc.
Limited form input types New input types such as email, date
Canvas built-in navhata Canvas element available
Doctype declaration lamb hoti Simple DOCTYPE declaration

HTML5 DOCTYPE:


<!DOCTYPE html>
Important: HTML5 sathi simple DOCTYPE declaration vapartat. Browser la document HTML standard nusar interpret karayla madat hote.

3. HTML5 Semantic Elements

Semantic elements webpage madhil content cha meaning browser ani developers la samjun ghenyas madat kartat.

Important Semantic Elements:

Element Purpose

<nav> Navigation links
<main> Main page content
<section> Thematic content section
<article> Independent content
<aside> Related side content
<footer> Footer information

Example:


<header>
    <h1>My Website</h1>
</header>

4. Audio and Video Support

HTML5 madhye audio ani video play karnyasathi built-in elements available aahet. External plugins chi normally garaj naste.

Audio Element:


<audio controls>

    <source src="music.mp3" type="audio/mpeg">

    Your browser does not support audio.

</audio>

Video Element:


<video width="400" controls>

    <source src="video.mp4" type="video/mp4">

    Your browser does not support video.

</video>
Tip: controls attribute mule play, pause ani volume sarkhe controls display hotat.

6. HTML5 Canvas Element

<canvas> element cha use webpage var graphics, shapes, animations ani drawings create karnyasathi hoto.

Canvas var graphics draw karnyasathi JavaScript chi garaj aste.

Example:


<canvas id="myCanvas"
        width="300"
        height="150">
</canvas>

<script>

    const canvas = document.getElementById("myCanvas");

    const ctx = canvas.getContext("2d");

    ctx.fillStyle = "blue";

    ctx.fillRect(30, 30, 150, 80);

</script>

Output:

Ya example madhye JavaScript cha use karun blue rectangle draw kela aahe.

Remember: Canvas he bitmap-based drawing surface aahe. Drawing create karnyasathi JavaScript vapartat.

8. HTML5 Web Storage

Web Storage API browser madhye data store karnyasathi use hote.

Web Storage che don main types aahet.

1. Local Storage

Local Storage madhye data browser madhye store hoto ani normally browser close kelyanantar suddha available rahto. 


// Store Data

localStorage.setItem("username", "Rohan");

// Get Data

let name = localStorage.getItem("username");

// Remove Data

localStorage.removeItem("username");

2. Session Storage

Session Storage madhye data current browser tab session purta store hoto. Tab kiwa window session end zalyavar data clear hoto. 


// Store Data

sessionStorage.setItem("username", "Rohan");

// Get Data

let name = sessionStorage.getItem("username");

// Remove Data

sessionStorage.removeItem("username");

Difference:

Local Storage Session Storage
Data generally persistent asto Current tab session purta asto
Browser restart nantar suddha rahto Tab session end zalyavar clear hoto
Same origin chya pages madhye share hoto Pratyek tab cha session vegla asto
Security Note: Local Storage ani Session Storage madhye passwords, secret keys kiwa sensitive tokens store karu naye. JavaScript access mule XSS attack madhye data expose hou shakto.

9. Geolocation API

Geolocation API cha use user chi location permission gheun access karnyasathi hoto.

Location access karnyapurvi browser user permission magto.

Example:


function getLocation() {

    if (navigator.geolocation) {

        navigator.geolocation.getCurrentPosition(
            function(position) {

                console.log(position.coords.latitude);

                console.log(position.coords.longitude);

            }
        );

    } else {

        console.log("Geolocation not supported.");

    }

}

Important Points:

  • Browser user permission magto.
  • Latitude location chi north-south position sangte.
  • Longitude location chi east-west position sangte.
  • Generally HTTPS kiwa localhost required aste.
  • User permission deny karu shakto.
Example Uses: Maps, nearby services ani location-based applications madhye Geolocation API useful aahe.

10. HTML Drag and Drop

Drag and Drop API mule user webpage var elements eka thikanahun dusrya thikani drag ani drop karu shakto.

Important Attributes and Events:

Name Purpose
draggable Element draggable banavto
ondragstart Dragging start zalyavar
ondragover Element drop area var asatana
ondrop Element drop kelyavar

Example:


<p id="item"
   draggable="true"
   ondragstart="drag(event)">

   Drag Me

</p>

<div id="box"
     ondragover="allowDrop(event)"
     ondrop="drop(event)">

     Drop Here

</div>

<script>

function drag(event) {

    event.dataTransfer.setData(
        "text",
        event.target.id
    );

}

function allowDrop(event) {

    event.preventDefault();

}

function drop(event) {

    event.preventDefault();

    const id = event.dataTransfer.getData("text");

    event.currentTarget.appendChild(
        document.getElementById(id)
    );

}

</script>

Output:

Drag Me

Drop Here
Tip: Drop area var ondragover event madhye event.preventDefault() call karne important aahe.

12. Common Beginner Mistakes

Mistake 1: Canvas Without JavaScript

Canvas element graphics automatically draw karat nahi. Drawing sathi JavaScript vaprave lagte.

Mistake 2: SVG and Canvas Same Samajne

Canvas bitmap-based aahe, tar SVG vector-based graphics format aahe.

Mistake 3: Local Storage Madhye Password Store Karne

Sensitive information browser storage madhye store karne unsafe tharu shakte.

Mistake 4: Geolocation Permission Ignore Karne

Location access karnyasathi user permission ani supported browser environment necessary aahe.

Mistake 5: Drop Event Madhye preventDefault Visarne

Drag and Drop madhye drop area chya dragover event madhye preventDefault() vaprave.
