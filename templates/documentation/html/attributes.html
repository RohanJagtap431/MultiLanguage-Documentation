HTML Attributes

HTML attributes mhanje kay, attributes chi syntax, common attributes, global attributes ani tyanchya practical uses baddal ya lesson madhye shikuya.

Beginner Level 35–40 Minutes

1. What are HTML Attributes?

HTML Attributes he HTML elements baddal additional information provide kartat. Attributes mule element che behavior, properties kiwa settings define karta yetat.

HTML attributes normally opening tag madhye lihitat. Attribute madhye attribute name ani tyachi value aste.

Example:


<a href="https://www.google.com">
    Visit Google
</a>

Explanation:

  • a: Anchor element aahe.
  • href: Attribute name aahe.
  • https://www.google.com: Attribute value aahe.
Simple Definition: HTML Attributes he elements la additional information kiwa configuration denyasathi vapartat.

2. HTML Attribute Syntax

HTML attribute ha opening tag madhye lihitat. Attribute name nantar equal sign (=) lihitat ani tyachya pudhe value quotes madhye detat.

Syntax:


<element attribute="value">

Example:


<img src="flower.jpg" alt="Red Flower">

Ya example madhye:

  • img = HTML element.
  • src = Attribute name.
  • flower.jpg = Attribute value.
  • alt = Dusra attribute.
  • Red Flower = Alt attribute chi value.
Important: Attribute values double quotes (" ") madhye lihine hi recommended practice aahe.

3. href Attribute

href attribute cha use hyperlink cha destination define karnyasathi hoto. Ha attribute mainly anchor (<a>) element sobat vapartat.

Syntax:


<a href="URL">Link Text</a>

Example:


<a href="https://www.google.com">
    Visit Google
</a>

Output:

Visit Google

Internal Page Link:


<a href="about.html">
    About Us
</a>

Ya example madhye about.html ya webpage chi link dili aahe.

Email Link:


<a href="mailto:example@gmail.com">
    Send Email
</a>
Tip: href attribute vaprun external website, internal webpage ani email link tayar karta yete.

4. src Attribute

src attribute cha full form source asa aahe. Ya attribute cha use image, audio, video kiwa external script cha source path define karnyasathi hoto.

Image Example:


<img src="photo.jpg" alt="My Photo">

Ithe photo.jpg hi image file browser la kuthe shodhaychi te src attribute sangte.

JavaScript Example:


<script src="script.js"></script>

Video Example:


<video controls src="movie.mp4"></video>
Important: src attribute source file cha path define karte. File path chukicha asel tar browser la resource load karta yenar nahi.

5. alt Attribute

alt attribute cha full form alternative text asa aahe. Ha attribute image element sobat vapartat.

Image load zali nahi tar kahi paristhitit alt text dakhavla jau shakto. Screen reader vaparnarya users na image cha meaning samjnyasathi suddha alt text useful aahe.

Syntax:


<img src="flower.jpg" alt="Red Rose Flower">

Good Alt Text Example:


<img
    src="student.jpg"
    alt="Student studying at a desk"
>

Decorative Image Example:


<img src="decoration.png" alt="">

Image fakt decoration sathi asel ani additional information det nasel tar empty alt text vaparta yete.

Tip: Meaningful images sathi descriptive alt text lih. Fakt image.jpg kiwa photo1 ase generic text lihun fayda hot nahi.

6. id Attribute

id attribute cha use specific HTML element la unique identity denyasathi hoto.

Ekach HTML document madhye ekach id value normally eka element la dyavi.

Syntax:


<element id="unique-name">

Example:


<h1 id="main-heading">
    Welcome to My Website
</h1>

CSS sobat id cha use:


#main-heading {
    color: blue;
    font-size: 30px;
}

CSS madhye id selector select karnyasathi hash (#) symbol vapartat.

JavaScript sobat id cha use:


document.getElementById("main-heading");

Ya JavaScript method mule main-heading id aslela element select karta yeto.

Important: id value unique thev. Eka document madhye same id anek elements na dene avoid kar.

7. class Attribute

class attribute cha use ek kiwa anek HTML elements la group identity denyasathi hoto. CSS styling ani JavaScript selection sathi class useful aahe.

Syntax:


<element class="class-name">

Example:


<h2 class="heading">First Heading</h2>

<p class="heading">First Paragraph</p>

<h3 class="heading">Second Heading</h3>

CSS Example:


.heading {
    color: green;
}

Ya CSS mule heading class aslele sagle elements green color madhye display hotil.

Multiple Classes:


<p class="text-box highlight">
    Important Information
</p>

Eka element la multiple classes deta yetat. Class names madhye space vapartat.

Remember: id specific element sathi unique identity aahe. class anek elements madhye reuse karta yete.

8. title Attribute

title attribute element baddal additional information provide karte. Desktop browser madhye kahi vela mouse pointer element var thevlyavar tooltip display hoto.

Syntax:


<element title="Additional Information">
    Content
</element>

Example:


<p title="This is additional information">
    Move your mouse over this text.
</p>

Output:

Move your mouse over this text.

Tip: title attribute la essential information cha ekmev replacement samju naye. Mobile ani keyboard users sathi tooltip nehmich available asel ase nahi.

9. style Attribute

style attribute cha use specific HTML element la inline CSS denyasathi hoto.

Syntax:


<element style="property: value;">

Example:


<h1 style="color: blue;">
    Welcome
</h1>

<p style="font-size: 20px;">
    Learn HTML
</p>

Output:

Welcome

Learn HTML

Multiple CSS Properties:


<p style="color: red; font-size: 18px; background-color: yellow;">
    Important Text
</p>
Important: style attribute inline CSS sathi aahe. Large website madhye separate CSS file vaprane maintainability sathi adhik changle aste.

10. width and height Attributes

width ani height attributes kahi HTML elements chi dimensions define karnyasathi vapartat. Image element madhye he attributes commonly vapartat.

Example:


<img
    src="flower.jpg"
    alt="Red Flower"
    width="300"
    height="200"
>

Ithe image chi width 300 pixels ani height 200 pixels aahe.

Important: img chya width ani height attributes madhye normally numeric values CSS pixels madhye specify kartat. Responsive layout sathi CSS suddha vaparta yete.

11. Boolean Attributes

Boolean attributes he ase attributes aahet jyanchi presence true value darshavte. Tyanna separate true kiwa false string value denyachi garaj naste.

Attribute present asel tar feature enable hoto. Attribute absent asel tar feature enable hot nahi.

Common Boolean Attributes:

  • disabled
  • required
  • checked
  • readonly
  • multiple
  • autofocus
  • selected
  • hidden

Disabled Example:


<button disabled>
    Submit
</button>

Output:

Ithe disabled attribute mule button click karta yet nahi.

Required Example:


<input type="text" required>

Required attribute mule form submit karnyapurvi ya field madhye value dene avashyak hote.

Checked Example:


<input type="checkbox" checked>

Checked attribute mule checkbox initially selected asto.

Tip: Boolean attribute true karaycha asel tar to present thev. False karaycha asel tar attribute remove kar.

12. Global Attributes

Global attributes he ase attributes aahet je bahutek HTML elements sobat vaparta yetat. Pratyek element sathi pratyek attribute applicable aselach ase nahi.

Common Global Attributes:

Attribute Purpose
id Element la unique identity dene.
class Elements group karne.
style Inline CSS dene.
title Additional information dene.
hidden Element render madhye hide karne.
lang Content chi language specify karne.
dir Text direction specify karne.
contenteditable Element content user la edit karta yene.
data-* Custom data store karne.

13. data-* Custom Attributes

data-* attributes cha use HTML elements madhye custom data store karnyasathi hoto. Ya data cha use JavaScript madhun karta yeto.

Example:


<button data-user-id="101">
    View User
</button>

JavaScript Example:


const button = document.querySelector("button");

console.log(button.dataset.userId);

Ya example madhye dataset.userId mule 101 hi value access karta yete.

Remember: data-user-id he HTML madhil custom data attribute aahe. JavaScript madhye dataset.userId ya format madhye tyachi value access karta yete.

14. Multiple Attributes

Eka HTML element la ekapeksha jast attributes deta yetat. Attributes opening tag madhye lihitat.

Example:


<img
    src="student.jpg"
    alt="Student Photo"
    width="200"
    height="200"
    title="Student Profile"
    class="profile-image"
    id="student-photo"
>

Explanation:

  • src image file cha path dete.
  • alt image cha alternative text dete.
  • width image chi width define karte.
  • height image chi height define karte.
  • title additional information dete.
  • class CSS group identity dete.
  • id unique identity dete.
Tip: Attributes cha order normally important nasto. Pan code readable ani consistent thev.

15. Practical Example - Student Profile

Ata apan different HTML attributes vaprun ek simple student profile tayar karu.

HTML Code:


<div id="student-card" class="profile-card">

    <h2 title="Student Name">
        Rohan Jagtap
    </h2>

    <p class="course">
        Course: B.Sc Computer Science
    </p>

    <img
        src="student.jpg"
        alt="Student Profile Photo"
        width="150"
        height="150"
    >

    <a href="https://example.com">
        Visit Website
    </a>

</div>

Output:

Rohan Jagtap

Course: B.Sc Computer Science

Profile image file available asel tar image display hoil.

Visit Website

Explanation:

  • id student-card element la unique identity dete.
  • class profile-card styling sathi use hote.
  • title student name baddal additional information dete.
  • src profile image cha path dete.
  • alt image cha alternative text dete.
  • width ani height image dimensions define kartat.
  • href website chi link define karte.

16. Common Beginner Mistakes

Mistake 1: Attribute wrong place madhye lihine

Attributes normally opening tag madhye lihayche astat, closing tag madhye nahi.

Mistake 2: Attribute value quotes madhye na lihine

Attribute values quotes madhye lihine hi recommended practice aahe.

Mistake 3: Same ID anek elements na dene

Eka document madhye id values unique thevne important aahe.

Mistake 4: Image la alt attribute na dene

Meaningful images sathi descriptive alt text dyava.

Mistake 5: src ani href confuse karne

href link destination sathi ani src resource file source sathi vapartat.

Mistake 6: Boolean attribute la false string dene

disabled="false" lihilyane button enable hot nahi. Boolean attribute present asel tar to active asto.
