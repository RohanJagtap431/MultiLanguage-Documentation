Promises and Async/Await

Ya lesson madhye asynchronous operations handle karne, Promise states, then(), catch(), async ani await shikuya.

Beginner Level 40–45 Minutes

1. What is a Promise?

Promise ha JavaScript object aahe jo asynchronous operation cha future result represent karto.

Operation successful zali tar result milto ani operation fail zali tar error milto.

Definition: A Promise is an object that represents the eventual completion or failure of an asynchronous operation.

Real Life Example:

Samja apan online food order kela.

  • Order place zali – Pending.
  • Order successfully deliver zali – Fulfilled.
  • Order cancel zali – Rejected.

2. Promise States

Promise chya teen main states astat.

State Meaning
Pending Operation ajun complete zalele nahi.
Fulfilled Operation successfully complete zali.
Rejected Operation fail zali.
Important: Promise ekda Fulfilled kiwa Rejected zalyavar tyachi state badalat nahi. Ya donhi states na Settled mhantat.

3. Creating a Promise

Promise tayar karnyasathi new Promise() constructor vapartat. Tyala executor function dila jato.

Syntax:

const promise = new Promise((resolve, reject) => {
    // Asynchronous operation
});

Important Points:

  • resolve() promise successful complete zalyache represent karto.
  • reject() promise fail zalyache represent karto.
  • Executor function lagech execute hoto.
  • Promise chi state ekdach settle hote.

Example:

const myPromise = new Promise((resolve, reject) => {
    let success = true;

    if (success) {
        resolve("Operation Successful");
    } else {
        reject("Operation Failed");
    }
});

console.log(myPromise);

Output:

Promise { fulfilled: "Operation Successful" }

Console madhye Promise display honyachi paddhat browser nusar vegli asu shakte. Resolve zalyanantar promise fulfilled hote.

4. then() Method

then() method cha use Promise successfully fulfilled zalyavar result handle karnyasathi hoto.

Syntax:

promise.then((result) => {
    // Success code
});

Example:

const promise = new Promise((resolve) => {
    resolve("Data Loaded");
});

promise.then((result) => {
    console.log(result);
});

Output:

Data Loaded
Remember: then() Promise fulfilled zalyavar success handler execute karto.

5. catch() Method

catch() method cha use Promise reject zalyavar error handle karnyasathi hoto.

Example:

const promise = new Promise((resolve, reject) => {
    reject("Something went wrong");
});

promise.catch((error) => {
    console.log(error);
});

Output:

Something went wrong
Important: Promise reject zalyavar catch() madhil error handler execute hoto.

6. finally() Method

finally() method cha use Promise fulfilled kiwa rejected zalyanantar common code execute karnyasathi hoto.

Example:

const promise = new Promise((resolve) => {
    resolve("Task Completed");
});

promise
    .then((result) => {
        console.log(result);
    })
    .catch((error) => {
        console.log(error);
    })
    .finally(() => {
        console.log("Process Finished");
    });

Output:

Task Completed
Process Finished

Uses:

  • Loading indicator hide karne.
  • Common cleanup code execute karne.
  • Operation complete zalyachi information denyasathi.

7. Promise Chaining

Ek Promise madhun milalela result pudhchya then() madhye use karnyala Promise Chaining mhantat.

Example:

Promise.resolve(10)
    .then((number) => {
        return number * 2;
    })
    .then((result) => {
        return result + 5;
    })
    .then((finalResult) => {
        console.log(finalResult);
    });

Output:

25

Explanation:

  1. Starting value 10 aahe.
  2. First then() madhye 10 * 2 = 20 hote.
  3. Second then() madhye 20 + 5 = 25 hote.
  4. Final result 25 print hoto.

8. What is async?

async keyword function la asynchronous function banavto. Async function nehmich Promise return karto.

Example:

async function greet() {
    return "Hello Rohan";
}

greet().then((result) => {
    console.log(result);
});

Output:

Hello Rohan

Function madhun normal string return keli tari async function tya value la fulfilled Promise madhye wrap karto.

9. What is await?

await keyword cha use Promise settle honyachi wait karun tyacha result milavnyasathi hoto.

await nehmich async function madhye use karta yeto. JavaScript module madhye top-level await suddha available aahe.

Example:

function getData() {
    return Promise.resolve("Data Received");
}

async function showData() {
    const result = await getData();

    console.log(result);
}

showData();

Output:

Data Received

Explanation:

  • getData() ek Promise return karto.
  • showData() async function aahe.
  • await Promise settle honyachi wait karto.
  • Result result variable madhye store hoto.
  • Tyachyanantar console.log() execute hoto.
Important: await mule sampurna JavaScript application block hot nahi. To current async function cha pudhil execution suspend karto.

10. try...catch with Async/Await

await vapartana Promise reject zalyas error handle karnyasathi try...catch vaparta yete.

Example:

function getData() {
    return Promise.reject("Data Not Found");
}

async function showData() {
    try {
        const result = await getData();

        console.log(result);

    } catch (error) {
        console.log(error);
    }
}

showData();

Output:

Data Not Found

Explanation:

  • try block madhye asynchronous operation execute hote.
  • Promise reject zalyas error throw hoto.
  • catch block error handle karto.
  • Application madhye error handling karne sope hote.

11. Promise vs Async/Await

Promise Methods Async/Await
then() ani catch() vapartat. async ani await vapartat.
Chaining style madhye code lihitat. Sequential style madhye code lihitat.
Multiple then() chains asu shaktat. await mule code readable hou shakto.
catch() ne error handle kartat. try...catch ne error handle kartat.
Remember: Async/Await he Promises varach based aahe. Te Promise cha replacement nahi.

12. Practical Example – API Request

fetch() cha use server kadun data request karnyasathi hoto. To Promise return karto.

JavaScript:

async function getUser() {
    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users/1"
        );

        if (!response.ok) {
            throw new Error("Request Failed");
        }

        const data = await response.json();

        console.log(data.name);
        console.log(data.email);

    } catch (error) {
        console.log("Error:", error.message);
    }
}

getUser();

Possible Output:

Leanne Graham
Sincere@april.biz

Explanation:

  1. fetch() API request pathavto.
  2. await response yenyachi wait karto.
  3. response.ok HTTP response success aahe ka check karto.
  4. response.json() response body parse karto.
  5. data madhun name ani email access karto.
  6. Error alyas catch block execute hoto.
Important: fetch() network error mule reject hou shakto. Pan HTTP 404 kiwa 500 sarkhya status codes sathi Promise automatically reject hot nahi. Mhanun response.ok check karne avashyak aahe.

13. Common Beginner Mistakes

Mistake 1: await async function baher use karne

Normal JavaScript function madhye await vaparta yet nahi. Async function madhye vapra.

Mistake 2: catch() na vaprane

Rejected Promise sathi error handling kara.

Mistake 3: async function normal value return karto samajne

Async function nehmich Promise return karto.

Mistake 4: await visarne

Promise cha resolved result hava asel tar await vapra kiwa then() vapra.

Mistake 5: fetch() madhye HTTP error check na karne

response.ok check karun HTTP errors handle kara.
