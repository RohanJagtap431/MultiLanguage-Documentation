Asynchronous JavaScript

Ya lesson madhye synchronous ani asynchronous code, timers, Call Stack, Callback Queue ani Event Loop shikuya.

Beginner Level 35–40 Minutes

1. What is Synchronous JavaScript?

Synchronous JavaScript madhye code ekamagun ek execute hoto. Ek statement complete zalyashivay pudhcha statement execute hot nahi.

Definition: Synchronous execution means code runs one statement at a time in a sequential order.

Example:

console.log("First");

console.log("Second");

console.log("Third");

Output:

First
Second
Third

Explanation:

  • First statement execute hoto.
  • Tyachyanantar Second execute hoto.
  • Shevati Third execute hoto.
  • Execution sequence maintain hote.

2. What is Asynchronous JavaScript?

Asynchronous JavaScript madhye kahi operations background madhye process hou shaktat. Tyamule main JavaScript execution pudhe chalu rahu shakto.

Asynchronous operation complete zalyavar tyacha callback execute honyasathi schedule hoto.

Definition: Asynchronous JavaScript allows certain operations to complete later without blocking the main JavaScript execution.

Example:

console.log("First");

setTimeout(function() {
    console.log("Second");
}, 2000);

console.log("Third");

Output:

First
Third
Second

Explanation:

  • First print hoto.
  • setTimeout() callback delay nantar execute honyasathi schedule karto.
  • JavaScript pudhcha statement execute karto.
  • Third print hoto.
  • Timer complete zalyanantar callback execute hoto.
  • Second print hoto.

3. Synchronous vs Asynchronous

Synchronous Asynchronous
Code sequentially execute hoto. Kahi operations later complete hotat.
Ek statement pudhchya statement la wait karu shakto. Main execution pudhe chalu rahu shakto.
Simple calculations. Timers ani network requests.
Blocking operation asu shakto. Non-blocking operation asu shakto.

4. JavaScript Single Thread

JavaScript cha main execution thread ekaveles ekach task execute karto. Yala Single Threaded execution model mhantat.

Browser timers, network operations ani itar asynchronous facilities handle karu shakto. JavaScript callbacks yogya veles execute honyasathi Event Loop madat karto.

Important: JavaScript single-threaded aahe mhanje browser madhil sarv operations ekach thread var hotat ase nahi. Browser kahi operations swatah handle karto.

5. Blocking vs Non-Blocking

Blocking operation mule pudhil JavaScript code execute honyasathi wait karu shakto.

Non-blocking operation madhye operation complete honyachi wait kartana main JavaScript execution pudhe chalu rahu shakto.

Blocking Example:

console.log("Start");

let total = 0;

for (let i = 0; i < 1000000000; i++) {
    total += i;
}

console.log("Calculation Complete");
console.log("End");

Ya loop la vel lagu shakto. Loop complete zalyashivay pudhil statements execute honar nahit.

Non-Blocking Example:

console.log("Start");

setTimeout(function() {
    console.log("Task Complete");
}, 2000);

console.log("End");

Output:

Start
End
Task Complete

6. setTimeout() Method

setTimeout() cha use ek callback function specified delay nantar execute karnyasathi hoto.

Syntax:

setTimeout(callback, delay);

Example:

setTimeout(function() {
    console.log("Hello Rohan");
}, 3000);

Output:

Approximately 3 seconds later:
Hello Rohan

Important Points:

  • Delay milliseconds madhye dila jato.
  • 1000 milliseconds = 1 second.
  • setTimeout() callback la ekda schedule karto.
  • Exact execution time guarantee hot nahi.
Remember: setTimeout() cha delay ha minimum waiting time aahe, exact execution time nahi.

7. setInterval() Method

setInterval() cha use callback function repeated intervals madhye execute karnyasathi hoto.

Syntax:

setInterval(callback, interval);

Example:

let count = 1;

const timer = setInterval(function() {
    console.log(count);

    count++;

    if (count > 5) {
        clearInterval(timer);
    }

}, 1000);

Output:

1
2
3
4
5

Explanation:

  • setInterval() callback repeat karto.
  • Pratyek interval 1000 milliseconds aahe.
  • clearInterval() timer stop karto.
  • Ya example madhye 5 numbers print hotat.

8. clearTimeout() and clearInterval()

clearTimeout() pending timeout cancel karnyasathi ani clearInterval() interval stop karnyasathi vapartat.

clearTimeout() Example:

const timer = setTimeout(function() {
    console.log("Hello");
}, 3000);

clearTimeout(timer);

Ya example madhye callback execute honyapurvich timeout cancel kela aahe.

clearInterval() Example:

let count = 0;

const timer = setInterval(function() {
    count++;
    console.log(count);

    if (count === 3) {
        clearInterval(timer);
    }
}, 1000);

Output:

1
2
3

9. Call Stack

Call Stack hi JavaScript madhil data structure aahe. Function calls track karnyasathi ti use hote.

Example:

function first() {
    console.log("First Function");
}

function second() {
    first();
    console.log("Second Function");
}

second();

Output:

First Function
Second Function

Explanation:

  • second() Call Stack madhye add hoto.
  • second() madhun first() call hoto.
  • first() execute houn Stack madhun remove hoto.
  • second() cha urlela code execute hoto.
Remember: Call Stack LIFO principle follow karto. LIFO mhanje Last In, First Out.

10. Callback Queue

Asynchronous callback ready zalyavar to task queue madhye wait karu shakto. Browser timers sathi callback queue ha shabda commonly vaparla jato.

Call Stack empty zalyavar Event Loop callback queue madhil task execute honyasathi pathavto.

Remember: Callback Queue madhil task lagech execute hot nahi. Call Stack available asne avashyak aahe.

11. Event Loop

Event Loop Call Stack ani task queues yanchyat coordination karto. Call Stack empty zalyavar queued callbacks execute honyasathi pathavto.

Example:

console.log("Start");

setTimeout(function() {
    console.log("Timer");
}, 0);

console.log("End");

Output:

Start
End
Timer

Explanation:

  1. Start print hoto.
  2. setTimeout() callback schedule karto.
  3. End print hoto.
  4. Call Stack empty hoto.
  5. Event Loop timer callback execute honyasathi pathavto.
  6. Timer print hoto.
Important: setTimeout(callback, 0) mhanje callback lagech execute hoil asa nahi. Synchronous code complete zalyanantar callback execute hoto.

12. JavaScript Execution Flow

Asynchronous JavaScript madhye Call Stack, Browser APIs, Task Queue ani Event Loop yanchi mahattvachi role aste.

JavaScript Code
↓
Call Stack
↓
Browser APIs
↓
Callback / Task Queue
↓
Event Loop
↓
Call Stack (when available)

13. Common Beginner Mistakes

Mistake 1: setTimeout() exact time samajne

Delay complete zalyavar callback schedule hoto. Exact execution time guarantee naste.

Mistake 2: setInterval() stop na karne

Repeated timer band karnyasathi clearInterval() vapra.

Mistake 3: Asynchronous code blocking samajne

setTimeout() sarkhya operations mule main execution pudhe chalu rahu shakto.

Mistake 4: setTimeout(callback, 0) lagech execute hoil samajne

Synchronous code complete zalyanantar callback execute hoto.

Mistake 5: Call Stack ani Callback Queue confuse karne

Call Stack function calls execute karto, tar Queue scheduled tasks wait madhye thevte.

14. Quick Revision

  • Synchronous code sequentially execute hoto.
  • Asynchronous operations main execution block karat nahit.
  • JavaScript main execution thread single-threaded aahe.
  • setTimeout() callback delay nantar schedule karto.
  • setInterval() callback repeated intervals madhye schedule karto.
  • clearTimeout() pending timeout cancel karto.
  • clearInterval() interval stop karto.
  • Call Stack LIFO principle follow karto.
  • Event Loop queued callbacks execute honyasathi coordinate karto.
