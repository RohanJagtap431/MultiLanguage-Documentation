Ways to Add JavaScript

HTML page madhye JavaScript code add karnyachya vegveglya methods shikuya. Inline, Internal ani External JavaScript practical examples sahit samjun gheuya.

Beginner Level 30–35 Minutes

1. Introduction

JavaScript code HTML webpage sobat connect karnyasathi aplyakade 3 main methods aahet.

01 Inline JavaScript
02 Internal JavaScript
03 External JavaScript
Simple Definition: JavaScript add karnyachya methods mhanje HTML webpage madhye JavaScript code lihinyache kiwa external file connect karnyache vegvegale ways.

2. Inline JavaScript

Inline JavaScript madhye JavaScript code directly HTML element chya event attribute madhye lihila jato.

Udaharanarth, button click zalyavar action perform karaychi asel tar onclick attribute madhye JavaScript code lihita yeto.

Example:

<button onclick="alert('Hello Rohan')">
    Click Me
</button>

Explanation:

  • button: HTML madhye button tayar karto.
  • onclick: User button click kelyavar action trigger karto.
  • alert(): Browser madhye message popup dakhavto.

Output:

Button click kelyavar browser madhye alert popup disel.

Advantages:

  • Small examples sathi code lihine sope aahe.
  • Vegli JavaScript file tayar karavi lagat nahi.

Disadvantages:

  • HTML code madhye JavaScript mix hote.
  • Large project madhye code manage karne kathin hote.
  • Same code anek buttons sathi repeat karava lagu shakto.
Important: Inline JavaScript fakt small demonstrations sathi upayogi aahe. Large projects madhye code separate thevne adhik changle.

3. Internal JavaScript

Internal JavaScript madhye JavaScript code HTML file madhyech script tag vaprun lihila jato.

JavaScript code lihinyasathi HTML madhye <script> ani </script> tags vapartat.

Example:

<!DOCTYPE html>
<html>
<head>
    <title>Internal JavaScript</title>
</head>
<body>

    <h1>My Website</h1>

    <script>
        console.log("Hello Rohan");
        alert("Welcome to my website");
    </script>

</body>
</html>

Explanation:

  • <script>: JavaScript code lihinyasathi vapartat.
  • console.log(): Browser Developer Console madhye message display karto.
  • alert(): Browser madhye popup message dakhavto.
  • </script>: JavaScript code block close karto.

Output:

My Website

Page load zalyavar Welcome to my website asa alert disel.

Console madhye Hello Rohan message disel.

Internal JavaScript kuthe lihayche?

JavaScript code <head> madhye kiwa <body> madhye lihita yeto. Beginner sathi script tag body chya shevati lihine sope aste.

Tip: Script body chya shevati asel tar tyachya aadhi HTML elements load honyachi shakyata aste. Mhanun element select kartana loading order chi kalji ghyavi.

Advantages:

  • Small webpage sathi convenient aahe.
  • JavaScript code tyach HTML file madhye rahto.
  • Separate file create karavi lagat nahi.

Disadvantages:

  • HTML file mothi hou shakte.
  • Multiple pages madhye code reuse karne kathin hote.
  • HTML ani JavaScript maintain karne avghad hou shakte.

4. External JavaScript

External JavaScript madhye JavaScript code veglya .js file madhye lihila jato ani HTML file sobat script tag vaprun connect kela jato.

Large websites ani professional projects madhye hi method adhik upayogi aahe.

Step 1: Folder Structure

MyWebsite/
│
├── index.html
├── style.css
└── script.js

Step 2: HTML Code (index.html)

<!DOCTYPE html>
<html>
<head>
    <title>External JavaScript</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <h1 id="heading">Hello World</h1>

    <button id="changeBtn">Click Me</button>

    <script src="script.js" defer></script>

</body>
</html>

Step 3: CSS Code (style.css)

body {
    font-family: Arial, sans-serif;
    text-align: center;
    padding: 40px;
}

button {
    padding: 10px 20px;
    background: #ca8a04;
    color: white;
    border: none;
    border-radius: 6px;
    cursor: pointer;
}

Step 4: JavaScript Code (script.js)

const button = document.getElementById("changeBtn");

const heading = document.getElementById("heading");

button.addEventListener("click", function() {
    heading.innerText = "Welcome to JavaScript!";
});

Code Explanation:

  • src="script.js": HTML la external JavaScript file cha path sangto.
  • defer: HTML parsing complete zalyanantar JavaScript execute honyas madat karto.
  • getElementById(): HTML madhil id vaprun element select karto.
  • addEventListener(): Button var click event listen karto.
  • innerText: Heading madhil text change karto.

Output:

Hello World

Button click kelyavar heading change hoil.

Advantages:

  • HTML ani JavaScript code separate rahto.
  • Same JavaScript file multiple HTML pages madhye vaparta yete.
  • Code maintain karne sope hote.
  • Large projects sathi upayogi aahe.

Disadvantages:

  • JavaScript sathi separate file create karavi lagte.
  • File path chukla tar JavaScript load honar nahi.

5. Difference Between Three Methods

Method Code Location Use
Inline HTML element attribute Small actions
Internal HTML madhil script tag Small webpages
External Separate .js file Large projects
Important: Professional projects madhye External JavaScript vaprane sadharanpane adhik changle aste.

6. Script Tag: Head vs Body

JavaScript file connect kartana script tag kuthe lihila aahe yacha code execution var parinam hou shakto.

A. Script in Head

<head>
    <script src="script.js"></script>
</head>

Ya method madhye browser HTML parse karnyapurvi JavaScript file load ani execute karu shakto. JavaScript la ajun load na zalele HTML elements access karayche asel tar problem yeu shakto.

B. Script at End of Body

<body>

    <h1 id="title">Hello</h1>

    <script src="script.js"></script>

</body>

Ya method madhye script chya aadhi HTML elements parse zale astat. Mhanun JavaScript la te elements access karne sope hote.

C. Script with Defer

<head>
    <script src="script.js" defer></script>
</head>

Defer attribute mule browser JavaScript file background madhye download karto ani HTML parsing complete zalyanantar script execute karto.

Tip: External JavaScript sathi defer ha upayogi option aahe. To script la HTML document parse zalyanantar execute karto.

7. Async vs Defer

Async ani defer he external JavaScript files load karnyasathi vaprale janare attributes aahet.

Defer Async
HTML parsing complete zalyavar execute hoto. File download complete zalyavar execute hoto.
Scripts cha order maintain karto. Scripts cha order guaranteed nasto.
DOM var depend aslelya scripts sathi upayogi. Independent scripts sathi upayogi.

Defer Example:

<script src="script.js" defer></script>

Async Example:

<script src="analytics.js" async></script>
Important: Async script execute honyachi vel download var depend aste. Mhanun ekmekanvar depend aslelya scripts sathi async vapartana kalji ghya.

8. External JavaScript in Django

Django project madhye JavaScript files sadharanpane static folder madhye thevlya jatat.

Folder Structure:

myproject/
│
├── documentation/
├── templates/
│   └── documentation/
│       └── home.html
│
└── static/
    └── js/
        └── home.js

HTML Template (home.html):

{% load static %}

<h1 id="heading">Hello Django</h1>

<button id="myButton">Click Me</button>

<script src="{% static 'js/home.js' %}" defer></script>

JavaScript File (home.js):

const button = document.getElementById("myButton");

const heading = document.getElementById("heading");

button.addEventListener("click", function() {
    heading.innerText = "JavaScript with Django!";
});
Django sathi lakshat thev: {% templatetag openblock %} load static {% templatetag closeblock %} mule Django static files cha {% templatetag openblock %} static 'js/home.js' {% templatetag closeblock %} mule browser la JavaScript file cha URL milto.
Backend Developer Tip: Django templates madhye HTML ani JavaScript connect karayla external static JS files vaprane upayogi aahe. Pudhe API responses display kartana hech knowledge vaparta yeil.

9. Common Beginner Mistakes

Mistake 1: JavaScript file cha path chukavne

src madhil file path barobar aahe ka te check kar.

Mistake 2: Script tag close karayla visarne

Script tag properly close karne avashyak aahe.

Mistake 3: HTML element load honyapurvi select karne

Script la HTML elements access karayche astil tar defer vapra kiwa script body chya shevati theva.

Mistake 4: Django madhye static tag visarne

Django template madhye static file connect karnyasathi {% load static %} ani static tag vapra.
