Object Methods and Destructuring

Ya lesson madhye Object Methods, this keyword, Destructuring, Shorthand Properties, Optional Chaining ani Spread Operator shikuya.

Beginner Level 40–45 Minutes

1. Object Methods

Object madhye function store kela asel tar tyala Object Method mhantat. Method cha use object sobat sambandhit operation perform karnyasathi hoto.

Example:

let student = {
    name: "Rohan",

    greet: function() {
        return "Hello " + this.name;
    }
};

console.log(student.greet());

Output:

Hello Rohan

Ithe greet() hi object method aahe. student.greet() vaprun ti call keli aahe.

Remember: Object property madhye function asel tar tyala Method mhantat.

2. this Keyword

Object method madhye this keyword cha use current object cha reference milavnyasathi hoto.

Example:

let student = {
    name: "Rohan",
    age: 20,

    showDetails: function() {
        console.log(this.name);
        console.log(this.age);
    }
};

student.showDetails();

Output:

Rohan
20

Explanation:

  • this.name current object madhil name access karte.
  • this.age current object madhil age access karte.
  • student.showDetails() call kelyamule this student object la refer karte.
Important: this cha meaning function kasa call kela aahe yavar depend karto. Arrow function madhye this surrounding scope madhun milto. Mhanun object method sathi normal function vaprane beginner level la sope aste.

3. Method Shorthand

Object madhye method lihinyasathi function keyword vaparnyachi garaj nahi. Short syntax suddha vaparta yete.

Normal Method:

let student = {
    greet: function() {
        return "Hello!";
    }
};

Shorthand Method:

let student = {
    greet() {
        return "Hello!";
    }
};

console.log(student.greet());

Output:

Hello!
Remember: Shorthand method madhye function keyword lihinyachi garaj naste.

4. Object Destructuring

Object Destructuring cha use object madhun specific properties chi values veglya variables madhye kadhnyasathi hoto.

Without Destructuring:

let student = {
    name: "Rohan",
    age: 20,
    course: "BSc CS"
};

let name = student.name;
let age = student.age;

console.log(name);
console.log(age);

With Destructuring:

let student = {
    name: "Rohan",
    age: 20,
    course: "BSc CS"
};

let { name, age } = student;

console.log(name);
console.log(age);

Output:

Rohan
20

Ithe name ani age ya properties chi values direct variables madhye store zali aahet.

Important: Object Destructuring madhye variable names default ne object property names shi match zale pahijet.

5. Destructuring with Rename

Object madhil property chi value veglya variable name madhye store karaychi asel tar rename syntax vaparta yete.

Example:

let student = {
    name: "Rohan",
    age: 20
};

let { name: studentName, age: studentAge } = student;

console.log(studentName);
console.log(studentAge);

Output:

Rohan
20

name chi value studentName madhye ani age chi value studentAge madhye store zali aahe.

6. Default Values in Destructuring

Object madhye property available nasel tar destructuring kartana default value set karta yete.

Example:

let student = {
    name: "Rohan"
};

let { name, city = "Kolhapur" } = student;

console.log(name);
console.log(city);

Output:

Rohan
Kolhapur
Note: Default value fakt property missing kiwa undefined asel tevha vaprali jate. Value null asel tar default apply hot nahi.

7. Nested Object Destructuring

Object madhye dusra object asel tar tyatil properties suddha destructuring ne access karta yetat.

Example:

let student = {
    name: "Rohan",

    address: {
        city: "Kolhapur",
        state: "Maharashtra"
    }
};

let {
    address: { city, state }
} = student;

console.log(city);
console.log(state);

Output:

Kolhapur
Maharashtra
Remember: Nested destructuring madhye inner object madhil property names match karne avashyak aahe.

8. Shorthand Properties

Variable ani object property che names same astil tar object create kartana short syntax vaparta yete.

Without Shorthand:

let name = "Rohan";
let age = 20;

let student = {
    name: name,
    age: age
};

console.log(student);

With Shorthand:

let name = "Rohan";
let age = 20;

let student = {
    name,
    age
};

console.log(student);

Output:

{ name: "Rohan", age: 20 }

Donhi examples madhye same object tayar hoto. Shorthand mule code short hoto.

9. Optional Chaining (?.)

Optional Chaining cha use object madhil property safe paddhatine access karnyasathi hoto.

Property chya madhil object null kiwa undefined asel tar error yenya aivaji undefined milte.

Without Optional Chaining:

let student = {
    name: "Rohan"
};

console.log(student.address.city);

Ithe address property available nahi. Mhanun city access kartana error yeto.

With Optional Chaining:

let student = {
    name: "Rohan"
};

console.log(student.address?.city);

Output:

undefined

Another Example:

let student = {
    name: "Rohan",
    address: {
        city: "Kolhapur"
    }
};

console.log(student.address?.city);

Output:

Kolhapur
Use: API response madhye kahi properties missing astil tar Optional Chaining upyogi padte.

10. Spread Operator with Objects

Spread Operator (...) cha use existing object madhil properties dusrya object madhye copy karnyasathi hoto.

Example:

let student = {
    name: "Rohan",
    age: 20
};

let newStudent = {
    ...student,
    city: "Kolhapur"
};

console.log(newStudent);

Output:

{
    name: "Rohan",
    age: 20,
    city: "Kolhapur"
}

Ithe student madhil properties newStudent madhye copy zalyat ani city hi new property add zali.

Important: Object Spread ha shallow copy karto. Nested objects kiwa arrays sathi inner references share hou shaktat.

11. Updating Objects with Spread

Spread Operator vaprun original object madhye direct badal na karta updated new object tayar karta yeto.

Example:

let student = {
    name: "Rohan",
    age: 20,
    city: "Kolhapur"
};

let updatedStudent = {
    ...student,
    age: 21
};

console.log(updatedStudent);
console.log(student.age);

Output:

{
    name: "Rohan",
    age: 21,
    city: "Kolhapur"
}
20

Ithe updatedStudent madhye age 21 aahe. Original student madhil age 20 ch rahte.

12. Object.assign()

Object.assign() method cha use eka kiwa adhik source objects madhil properties target object madhye copy karnyasathi hoto.

Example:

let student = {
    name: "Rohan"
};

let details = {
    age: 20,
    city: "Kolhapur"
};

let result = Object.assign({}, student, details);

console.log(result);

Output:

{
    name: "Rohan",
    age: 20,
    city: "Kolhapur"
}
Remember: Object.assign() suddha shallow copy karte. Empty object {} target dilyamule source objects madhye direct badal hot nahi.

13. Important Concepts Comparison

Concept Use
Object Method Object madhye function store karne.
this Current object cha reference access karne.
Destructuring Object madhun values veglya variables madhye kadhne.
Shorthand Same property ani variable name sathi short syntax.
Optional Chaining Missing nested property safe paddhatine access karne.
Spread Operator Object properties copy karne ani update karne.
Object.assign() Source object properties target object madhye copy karne.

14. Common Beginner Mistakes

Mistake 1: Destructuring madhye property name mismatch

Object madhil property name ani destructuring madhil name match nasel tar value undefined milu shakte.

Mistake 2: this ani arrow function confuse karne

Arrow function swatahcha this tayar karat nahi. To surrounding scope madhun milto.

Mistake 3: Optional Chaining cha wrong use

Missing property access karaychi asel tar yogya level var ?. vapra.

Mistake 4: Spread la deep copy samajne

Object Spread fakt shallow copy karto. Nested object references share hou shaktat.
