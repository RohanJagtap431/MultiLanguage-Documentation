JavaScript Operators

JavaScript madhye calculation, comparison, conditions ani values assign karnyasathi operators kase vapartat he practical examples sahit shikuya.

Beginner Level 40–45 Minutes

1. What are Operators?

Operator mhanje ek symbol kiwa keyword jo values kiwa variables var specific operation perform karto.

Udaharanarth, don numbers add karnyasathi + operator vapartat.

Example:

let a = 10;
let b = 5;

let result = a + b;

console.log(result);

Output:

15

Explanation:

  • a ani b: Values store karnare variables.
  • +: Don values add karnara operator.
  • result: Addition cha result store karto.
Simple Definition: Values var calculation kiwa dusri operation perform karnyasathi operators vapartat.

3. Arithmetic Operators

Arithmetic operators cha use mathematical calculations karnyasathi hoto.

Arithmetic Operators Table:

Operator Name Use
+ Addition Don values add karto.
- Subtraction Ek value dusryatun kami karto.
* Multiplication Don values multiply karto.
/ Division Bhagakar karto.

** Exponentiation Power calculate karto.
++ Increment Value madhye 1 add karto.
-- Decrement Value madhun 1 kami karto.

Example:

let a = 10;
let b = 3;

console.log(a + b);
console.log(a - b);

Modulus Operator (%)

Modulus operator division kelyanantar urleli remainder value return karto. 

let number = 10;

console.log(number % 2);
console.log(number % 3);

Output:

0
1

10 la 2 ne divide kelyavar remainder 0 yeto. 10 la 3 ne divide kelyavar remainder 1 yeto.

Increment and Decrement:

let count = 5;

count++;

console.log(count);

count--;

console.log(count);

Output:

6
5
Important: count++ mhanje count = count + 1. count-- mhanje count = count - 1.

4. Assignment Operators

Assignment operators cha use variable madhye value assign karnyasathi kiwa tyachi value update karnyasathi hoto.

Assignment Operators Table:

Operator Example Meaning
= x = 10 x madhye 10 assign karto.
+= x += 5 x = x + 5
-= x -= 5 x = x - 5
*= x *= 5 x = x * 5
/= x /= 5 x = x / 5
%= x %= 5 x = x % 5

Example:

let x = 10;

x += 5;
console.log(x);

x -= 3;
console.log(x);

x *= 2;
console.log(x);

x /= 4;
console.log(x);

Output:

15
12
24
6

Explanation:

  • x += 5: 10 + 5 = 15
  • x -= 3: 15 - 3 = 12
  • x *= 2: 12 × 2 = 24
  • x /= 4: 24 ÷ 4 = 6

5. Comparison Operators

Comparison operators cha use don values compare karnyasathi hoto. Comparison cha result Boolean mhanje true kiwa false asto.

Comparison Operators Table:

Operator Name Meaning
== Equal Values equal aahet ka te check karto.
=== Strict Equal Value ani data type donhi check karto.
!= Not Equal Values equal nahit ka te check karto.
!== Strict Not Equal Value kiwa data type vegla aahe ka te check karto.
> Greater Than Mothi value check karto.
< Less Than Lahan value check karto.
>= Greater Than or Equal Mothi kiwa equal value check karto.
<= Less Than or Equal Lahan kiwa equal value check karto.

Example:

let a = 10;
let b = 5;

console.log(a == b);
console.log(a > b);
console.log(a < b);
console.log(a >= b);
console.log(a != b);

Output:

false
true
false
true
true

Difference Between == and ===

== operator comparison kartana garaj padlyas data type convert karu shakto. === operator value ani data type donhi check karto. 

let a = 10;
let b = "10";

console.log(a == b);
console.log(a === b);

Output:

true
false
Important: Modern JavaScript code madhye comparison sathi shakya asel tithe === ani !== vapra. Tyamule unexpected type conversion talta yete.

6. Logical Operators

Logical operators cha use multiple conditions combine karnyasathi kiwa condition cha result reverse karnyasathi hoto.

Logical Operators Table:

Operator Name Meaning
&& AND Donhi conditions true asne avashyak.
|| OR Kamitate ek condition true asne avashyak.
! NOT Boolean result reverse karto.

A. AND Operator (&&)

let age = 20;
let hasID = true;

console.log(age >= 18 && hasID === true);

Output:

true

Donhi conditions true aslyamule final result true aahe.

B. OR Operator (||)

let hasEmail = false;
let hasPhone = true;

console.log(hasEmail || hasPhone);

Output:

true

Ek tari condition true aslyamule result true aahe.

C. NOT Operator (!)

let isLoggedIn = true;

console.log(!isLoggedIn);

Output:

false

! operator true la false ani false la true karto.

Tip: Login, registration, eligibility ani form validation madhye logical operators khup upyogi aahet.

7. String Operator

JavaScript madhye + operator cha use strings ekatra jodnyasathi suddha hoto. Yala string concatenation mhantat.

Example:

let lastName = "Jagtap";

let fullName = firstName + " " + lastName;

console.log(fullName);

Output:

Rohan Jagtap

String and Number:

let result = "Age: " + 20;

console.log(result);

Output:

Age: 20
Important: String sobat + vaparlyas value concatenate hou shakate. Mhanun calculation kartana data types check kara.

8. Ternary Operator

Ternary operator ha short condition lihinyasathi vaparla jato. To condition true kiwa false aslyavar vegvegli value return karto.

Syntax:

condition ? valueIfTrue : valueIfFalse;

Example:

let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);

Output:

Adult

Explanation:

  • age >= 18: Condition check karte.
  • ?: True aslyas pahili value nivadte.
  • : False aslyas dusri value nivadte.
Tip: Simple if-else condition sathi ternary operator upyogi aahe. Khup complex conditions sathi if-else vaprane adhik readable aste.

10. Operator Precedence

Ekach expression madhye anek operators astil tar konti operation aadhi perform honar he operator precedence tharavte.

Example:

let result = 10 + 5 * 2;

console.log(result);

Output:

20

Multiplication chi precedence addition peksha jast aahe. Mhanun 5 * 2 aadhi calculate hote.

Using Parentheses:

let result = (10 + 5) * 2;

console.log(result);

Output:

30
Tip: Complex calculation madhye parentheses () vapra. Tyamule code vachayla ani samjayla sopa hoto.

11. Practical Example - Student Result

Ata operators vaprun student cha result calculate karu.

JavaScript Code:

let maths = 80;
let science = 75;
let english = 85;

let total = maths + science + english;

let percentage = total / 3;

let isPassed = maths >= 35 &&
               science >= 35 &&
               english >= 35;

let result = isPassed ? "Pass" : "Fail";

console.log("Total:", total);
console.log("Percentage:", percentage);
console.log("Result:", result);

Output:

Total: 240
Percentage: 80
Result: Pass

Explanation:

  • +: Tin subjects che marks add kele.
  • /: Average percentage calculate keli.
  • >=: Pratyek subject madhye passing marks check kele.
  • &&: Tinhi subjects pass asne avashyak thevle.
  • ?: Pass kiwa Fail result nivadla.

12. Common Beginner Mistakes

Mistake 1: = ani == madhye confusion

= value assign karto, tar == values compare karto.

Mistake 2: == ani === same samajne

=== value ani data type donhi check karto.

Mistake 3: % operator cha result samjun na ghene

% remainder return karto, percentage calculate karat nahi.

Mistake 4: && ani || madhye confusion

&& sathi donhi conditions true pahijet. || sathi kamitate ek condition true pahije.

Mistake 5: String ani Number ekatra add karne

"10" + 5 cha result "105" yeu shakto. Calculation aadhi data type check kara.
