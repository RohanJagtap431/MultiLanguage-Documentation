JavaScript Variables (var, let, const)

JavaScript madhye data store karnyasathi variables kase vapartat, var, let ani const madhil difference kay aahe ani tyanchya practical uses kay aahet he shikuya.

Beginner Level 35–40 Minutes

1. What is a Variable?

Variable mhanje data store karnyasathi vaparla janara named storage container.

Program madhye aplyala name, age, city, marks kiwa price sarkhya values store karavya lagtat. Ya values variables madhye store karta yetat.

Simple Definition: Variable mhanje ek name dileli jagah jyamadhye program cha data store karta yeto.

Real-Life Example:

Samaj tujhya notebook madhye vegveglya subjects che marks lihile aahet. Pratyek subject sathi vegli value aahe. Programming madhye ya values variables madhye store karta yetat.

Example:

let name = "Rohan";
let age = 20;
let city = "Kolhapur";

console.log(name);
console.log(age);
console.log(city);

Output:

Rohan
20
Kolhapur

Explanation:

  • name: Variable che name aahe.
  • =: Assignment operator aahe. To value variable madhye assign karto.
  • "Rohan": Store keli janari string value aahe.
  • 20: Number value aahe.
  • console.log(): Variable madhil value console madhye display karto.

2. How to Declare a Variable?

JavaScript madhye variable declare karnyasathi var, let kiwa const ya keywords cha use karto.

Basic Syntax:

let variableName = value;

Example:

let studentName = "Rohan";

Ya code madhil parts:

  • let: Variable declare karnyacha keyword.
  • studentName: Variable che name.
  • =: Assignment operator.
  • "Rohan": Variable madhye store honari value.
  • ; Statement cha end.
Tip: JavaScript madhye variable declare karne mhanje variable tayar karne. Value assign karne mhanje tyamadhye data thevne.

3. JavaScript var Keyword

var ha JavaScript madhye variable declare karnyasathi vaparla janara keyword aahe.

Example:

var name = "Rohan";

console.log(name);

Output:

Rohan

Reassigning a var Variable

var vaprun declare kelelya variable chi value nantar change karta yete. 

var city = "Kolhapur";

city = "Pune";

console.log(city);

Output:

Pune

Redeclaring a var Variable

var vaprun same scope madhye same variable punha declare karta yeto. 

var age = 20;

var age = 21;

console.log(age);

Output:

21
Important: var madhye same variable redeclare karta yeto. Pan mothya projects madhye yamule confusion ani unexpected errors yeu shaktat.

4. JavaScript let Keyword

let ha variable declare karnyasathi vaparla janara modern JavaScript keyword aahe.

let vaprun declare kelelya variable chi value nantar change karta yete. Pan same scope madhye to variable punha declare karta yet nahi.

Example:

let name = "Rohan";

console.log(name);

Output:

Rohan

Reassigning a let Variable

let age = 20;

age = 21;

console.log(age);

Output:

21

Redeclaring a let Variable

let city = "Kolhapur";

// Same scope madhye he error deil
let city = "Pune";
Important: Same scope madhye let variable punha declare kelyas SyntaxError yeto. Pan tyachi value change karne allowed aahe.

5. JavaScript const Keyword

const ha constant variable declare karnyasathi vaparla janara keyword aahe.

const vaprun declare kelelya variable la declaration kartanach value assign karavi lagte. Nantar tyala dusri value assign karta yet nahi.

Example:

const country = "India";

console.log(country);

Output:

India

Reassigning a const Variable

const age = 20;

// He code error deil
age = 21;
Important: const variable la punha value assign karta yet nahi. Tyamule reassignment kelyas TypeError yeto.

Redeclaring a const Variable

const city = "Kolhapur";

// Same scope madhye he error deil
const city = "Pune";

const variable declare kartana value dene compulsory aahe.

Wrong Example:

const name;

// Value assign kelel naslyamule error yeil

Correct Example:

const name = "Rohan";

console.log(name);

6. Difference Between var, let and const

var, let ani const ya tinhi keywords cha use variables declare karnyasathi hoto. Pan tyanchya rules madhye difference aahe.

Feature var let const
Reassign Yes Yes No
Redeclare in same scope Yes No No
Block Scope No Yes Yes
Declaration without value Yes Yes No
Modern usage Usually avoid Use when value changes Use by default
Learning Tip: Navin JavaScript code lihitana default const vapra. Value change karaychi asel tar let vapra. var ha keyword samjun ghya, pan navin code madhye sadharanpane talava.

7. Variable Scope

Scope mhanje variable program madhye kuthe access karta yeil he tharavnari boundary.

JavaScript madhye var, let ani const yanchi scope behavior vegli aste.

A. Global Scope

Function kiwa block chya baher declare kelelya variable la global scope asu shakto. To tyach script madhil anek thikani access karta yeto. 

let name = "Rohan";

function showName() {
    console.log(name);
}

showName();

console.log(name);

Output:

Rohan
Rohan

B. Function Scope

Function madhye declare kelelya var variable la function scope asto. 

function showAge() {
    var age = 20;

    console.log(age);
}

showAge();

// Function chya baher age access karta yet nahi

Output:

20

C. Block Scope

Curly brackets { } madhil block la block scope mhantat. let ani const variables block chya baher access karta yet nahit. 

{
    let city = "Kolhapur";
    const country = "India";

    console.log(city);
    console.log(country);
}

Output:

Kolhapur
India
Important: var ha block-scoped nahi. To function-scoped asto. let ani const he block-scoped astat.

8. Variable Hoisting

Hoisting hi JavaScript chi behavior aahe. JavaScript code execute karnyapurvi declarations process karte.

var, let ani const ya tinhi declarations babtit hoisting hote, pan tyanchi initialization behavior vegli aste.

var Example:

console.log(age);

var age = 20;

Ya code madhye var declaration hoist hote ani suruvatila tyachi value undefined aste.

Output:

undefined

let Example:

console.log(age);

let age = 20;

Ya code madhye variable initialize honyapurvi access kelyamule ReferenceError yeto.

const Example:

console.log(city);

const city = "Kolhapur";

const suddha initialize honyapurvi access karta yet nahi.

Important: let ani const declarations Temporal Dead Zone (TDZ) madhye astat. Mhanun declaration chya aadhi tyanna access karu naye.

9. Variable Naming Rules

JavaScript madhye variable la name detana kahi rules follow karave lagtat.

Rules:

  • Variable name letters ne suru hou shakto.
  • Underscore (_) kiwa dollar sign ($) ne suddha suru hou shakto.
  • Variable name number ne suru hou shakat nahi.
  • Variable name madhye spaces allowed nahit.
  • JavaScript reserved keywords variable name mhanun vaparta yet nahit.
  • Variable names case-sensitive astat.

Valid Variable Names:

let name = "Rohan";
let studentAge = 20;
let total_marks = 450;
let $price = 100;
let _count = 5;

Invalid Variable Names:

// He invalid examples aahet

let 1name = "Rohan";
let student name = "Rohan";
let let = 20;
Tip: Variable name meaningful thev. Udaharanarth, studentAge he age1 peksha vachayla ani samjayla sope aahe.

10. Practical Example - Student Details

Ata apan var, let ani const vaprun ek student details program tayar karu.

JavaScript Code:

let age = 20;
let city = "Kolhapur";

age = 21;

console.log("Student:", studentName);
console.log("Age:", age);
console.log("City:", city);

Explanation:

  • studentName: Student che nav store kele. Te change karayche naslyamule const vaparla.
  • age: Student che vay store kele. Nantar change kelyamule let vaparla.
  • city: Student che city store kele.
  • age = 21: Age chi value 20 varun 21 keli.

Output:

Student: Rohan
Age: 21
City: Kolhapur

11. Practical Example - HTML, CSS and JavaScript

Ata apan ek simple counter tayar karu. Button click kelyavar counter chi value increase hoil.

0

Concept Samjun Ghe: count chi value change hot aahe mhanun let vaparla. Button ani output elements che references punha assign karayche nahit mhanun const vaparla.

12. Common Beginner Mistakes

Mistake 1: const variable la navin value assign karne

const variable la reassignment karta yet nahi. Value change karaychi asel tar let vapra.

Mistake 2: let variable same scope madhye redeclare karne

Same scope madhye let variable punha declare kelyas SyntaxError yeto.

Mistake 3: Variable name madhye space dene

student name ase variable name valid nahi. studentName ase name vapra.

Mistake 4: var, let ani const cha use confuse karne

Default const vapra. Value change honar asel tar let vapra.

Mistake 5: Variable declare karnyapurvi access karne

let ani const variables declaration chya aadhi access kelyas ReferenceError yeu shakto.
