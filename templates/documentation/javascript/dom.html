DOM Introduction

Ya lesson madhye DOM mhanje kay, HTML ani DOM madhil difference, DOM Tree, document object ani JavaScript HTML page sobat kasa interact karte te shikuya.

Beginner Level 35–40 Minutes

1. What is DOM?

DOM cha full form Document Object Model aahe. Browser HTML document load karto tevha tyachi ek tree-like structure tayar karto. Ya structure la DOM mhantat.

DOM mule JavaScript la HTML elements access karta yetat ani tyanchya content, style ani attributes madhye badal karta yeto.

Definition: DOM is a programming interface that represents an HTML document as a tree of objects.

DOM cha use:

  • HTML elements access karne.
  • Element madhil text change karne.
  • CSS styles change karne.
  • New HTML elements add karne.
  • Existing elements remove karne.
  • User events handle karne.

2. HTML vs DOM

HTML ani DOM he same nahit. HTML hi webpage chi structure lihinyasathi vaprali janari markup language aahe. DOM hi browser ne tayar kelele object structure aahe.

HTML Example:

<h1>Hello World</h1>
<p>Welcome to JavaScript</p>

DOM madhye kay hote?

Browser ya HTML madhil elements la objects mhanun represent karto. JavaScript ya objects sobat interact karu shakte.

HTML DOM
Markup language aahe. Programming interface aahe.
Page chi structure lihite. Page la objects madhye represent karte.
HTML tags vaparte. Objects ani properties vaparte.
Browser HTML read karto. JavaScript DOM madhun page change karu shakte.

3. DOM Tree Structure

DOM document la tree structure madhye represent karto. Ya tree madhye pratyek HTML element ha ek node asto.

Example HTML:

<html>
    <head>
        <title>My Page</title>
    </head>

    <body>
        <h1>Hello</h1>
        <p>Welcome</p>
    </body>
</html>

DOM Tree:

document
html
head
title
body
h1
p

Important Terms:

  • Parent: Dusrya node la contain karanara node.
  • Child: Parent node chya aat asanara node.
  • Sibling: Same parent share karanare nodes.
  • Root: Tree madhil top-level node.
Remember: body madhil h1 ani p he doghe html elements aahet ani doghancha parent body aahe.

4. What is document Object?

JavaScript madhye document ha object aahe. To browser madhye load zalele HTML document represent karto.

DOM sobat kaam kartana document ha entry point mhanun vaparla jato.

Example:

console.log(document);

console.log(document.title);

console.log(document.body);

Explanation:

  • document: Complete HTML document access karto.
  • document.title: Page cha title milavto.
  • document.body: HTML madhil body element milavto.
Important: document object browser environment madhye available asto. To Node.js madhye default ne available nasto.

5. How JavaScript Interacts with HTML

JavaScript document object cha use karun HTML elements access karte ani tyanchyamadhye badal karu shakte.

JavaScript kay karu shakte?

  • HTML madhil text change karu shakte.
  • Element cha color change karu shakte.
  • New elements create karu shakte.
  • Elements delete karu shakte.
  • Button click sarkhe events handle karu shakte.

Simple Example:

<h1 id="heading">Hello World</h1>

<button id="changeButton">
    Change Text
</button>

<script>
    const heading = document.getElementById("heading");
    const button = document.getElementById("changeButton");

    button.addEventListener("click", function() {
        heading.textContent = "Welcome to DOM!";
    });
</script>

Output:

Hello World

Button click kelyavar JavaScript heading madhil text change karte. Ha DOM cha basic use aahe.

6. DOM and Browser

Browser HTML file read karto ani tyavarun DOM tree tayar karto. JavaScript ya DOM tree madhil nodes access karu shakte.

Working Process:

  1. Browser HTML document load karto.
  2. HTML madhun DOM Tree tayar hote.
  3. JavaScript document object vaprun elements access karte.
  4. JavaScript elements madhye changes karte.
  5. Browser updated page screen var dakhavto.
HTML page chi original file ani browser madhil DOM he vegale astat. JavaScript ne DOM madhye kelela badal automatic HTML file madhye save hot nahi.

7. Common Beginner Mistakes

Mistake 1: DOM ani HTML same samajne

HTML markup aahe, tar DOM hi browser madhil object structure aahe.

Mistake 2: Wrong element ID vaprane

JavaScript madhil ID ani HTML madhil ID same asne avashyak aahe.

Mistake 3: Element load honyapurvi JavaScript chalavne

JavaScript element load honyapurvi run zali tar element null milu shakto. Script yogya thikani theva kiwa defer vapra.

Mistake 4: document object cha use na samajne

document ha loaded HTML document access karnyasathi vaparla janara main object aahe.

8. Quick Revision

  • DOM cha full form Document Object Model aahe.
  • Browser HTML document pasun DOM Tree tayar karto.
  • DOM HTML la objects madhye represent karto.

  • JavaScript DOM vaprun HTML content change karu shakte.
  • DOM vaprun styles ani elements suddha change karta yetat.
