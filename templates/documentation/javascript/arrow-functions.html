JavaScript Arrow Functions

Arrow Function hi JavaScript madhye function lihinyachi short syntax aahe. Ya lesson madhye arrow function, parameters, return ani tyache practical uses shikuya.

Beginner Level 25–30 Minutes

1. What is an Arrow Function?

Arrow Function hi normal function lihinyachi short syntax aahe. Arrow Function madhye => ya arrow symbol cha use hoto.

Normal Function:

function greet() {
    console.log("Hello Rohan");
}

greet();

Arrow Function:

const greet = () => {
    console.log("Hello Rohan");
};

greet();

Output:

Hello Rohan
Simple Definition: => symbol vaprun function lihinyachya short syntax la Arrow Function mhantat.

2. Arrow Function Syntax

Arrow Function madhye const kiwa let vaprun function variable madhye store karta yeto.

Syntax:

const functionName = () => {
    // Code to execute
};

Example:

const welcome = () => {
    console.log("Welcome to JavaScript");
};

welcome();

Output:

Welcome to JavaScript

Explanation:

  • const: Function variable declare karto.
  • welcome: Function che name.
  • (): Parameters lihinyasathi.
  • => Arrow symbol.
  • { }: Function cha code block.
  • welcome(): Function call karto.

3. Arrow Function with Parameters

Normal function pramane Arrow Function madhye suddha parameters ani arguments pass karta yetat.

Example:

const greet = (name) => {
    console.log("Hello " + name);
};

greet("Rohan");
greet("Amit");

Output:

Hello Rohan
Hello Amit

Multiple Parameters:

const add = (a, b) => {
    console.log(a + b);
};

add(10, 20);
add(5, 15);

Output:

30
20
Tip: Multiple parameters astil tar parentheses () vaprane avashyak aahe.

4. Single Parameter Arrow Function

Fakt ek parameter asel tar parentheses () vaprane optional aahe.

With Parentheses:

const square = (number) => {
    return number * number;
};

console.log(square(5));

Without Parentheses:

const square = number => {
    return number * number;
};

console.log(square(5));

Output:

25
Important: Ek parameter asel tar parentheses optional aahet. Zero kiwa multiple parameters astil tar () vaprave lagtat.

5. Implicit Return

Arrow Function madhye fakt ek expression return karaycha asel tar return keyword ani curly brackets {} skip karta yetat.

Normal Return:

const add = (a, b) => {
    return a + b;
};

console.log(add(10, 20));

Implicit Return:

const add = (a, b) => a + b;

console.log(add(10, 20));

Output:

30

Another Example:

const square = number => number * number;

console.log(square(6));

Output:

36
Important: Curly brackets {} vaparlyas explicit return lihava lagto. Curly brackets naslyas expression automatically return hote.

6. Arrow Function with Multiple Statements

Function madhye anek statements astil tar curly brackets ani return keyword vaprave lagtat.

Example:

const calculate = (a, b) => {

    let sum = a + b;

    let result = sum * 2;

    return result;
};

console.log(calculate(10, 5));

Output:

30

Explanation:

  • Function don values accept karto.
  • sum madhye donhi values add hotat.
  • result madhye sum la 2 ne multiply kele jate.
  • return result final value parat karto.

7. Arrow Function vs Normal Function

Normal Function Arrow Function
function keyword vaparto. => symbol vaparto.
Syntax comparatively mothi aste. Syntax short aste.
Swatacha this context asto. this surrounding scope madhun gheto.
Constructor mhanun use karta yeto. Constructor mhanun use karta yet nahi.
Function declaration ani expression donhi shakya. Sahasa variable madhye store karto.
Important: Arrow Function ha normal function cha fakt shorter replacement nahi. this ani constructor behavior vegle aslyamule yogya situation madhye yogya function vapra.

8. Where are Arrow Functions Used?

Arrow Functions cha use JavaScript madhye anek thikani hoto. Visheshatah callbacks ani array methods madhye.

Example:

let numbers = [10, 20, 30];

numbers.forEach(number => {
    console.log(number);
});

Output:

10
20
30

forEach() madhye arrow function callback mhanun pass kela aahe. Array madhil pratyek value sathi ha callback execute hoto.

Backend Relevance: Array methods, data processing ani asynchronous callbacks madhye Arrow Functions upyogi padtat.

9. Common Beginner Mistakes

Mistake 1: Arrow symbol visarne

Arrow Function madhye => symbol vaprane avashyak aahe.

Mistake 2: Implicit return madhye curly brackets vaprane

Curly brackets vaparlyas return keyword lihava lagto.

Mistake 3: Multiple parameters sathi parentheses skip karne

Multiple parameters astil tar parentheses () avashyak aahet.

Mistake 4: Function call karayla visarne

Function execute karnyasathi tyala call karave lagte.

Mistake 5: Arrow Function la constructor samajne

Arrow Function sobat new keyword vaprun object create karta yet nahi.
