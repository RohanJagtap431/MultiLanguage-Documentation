JavaScript Data Types

JavaScript madhye data che vegvegale types astat. String, Number, Boolean, Object ani itar data types kase vapartat he examples sahit shikuya.

Beginner Level 35–40 Minutes

1. What are Data Types?

Data Type mhanje variable madhye kontya prakarcha data store aahe he sangnara type.

Udaharanarth, aplyala student che name, age, result ani address store karayche asel tar pratyek value cha data type vegla asu shakto.

Example:

let studentName = "Rohan";
let age = 20;
let isPassed = true;

console.log(studentName);
console.log(age);
console.log(isPassed);

Output:

Rohan
20
true

Explanation:

  • "Rohan": String data type.
  • 20: Number data type.
  • true: Boolean data type.
Simple Definition: Data Type aplyala variable madhye kontya prakarcha data aahe he samjun ghenyas madat karto.

2. Types of JavaScript Data Types

JavaScript madhye data types che don main groups aahet.

Primitive Data Types

String, Number, Boolean, Undefined, Null, BigInt, Symbol

Non-Primitive Data Type

Object. Arrays ani functions suddha object-related structures aahet.

Important: JavaScript madhye 7 primitive data types aahet. Object ha non-primitive category madhye yeto.

3. String Data Type

String cha use text kiwa characters store karnyasathi hoto. String value single quotes, double quotes kiwa backticks madhye lihili jate.

Example:

let firstName = "Rohan";
let city = 'Kolhapur';
let course = `Computer Science`;

console.log(firstName);
console.log(city);
console.log(course);

Output:

Rohan
Kolhapur
Computer Science

String Concatenation:

Don kiwa adhik strings ekatra jodnyasathi + operator vaparta yeto. 

let firstName = "Rohan";
let lastName = "Jagtap";

let fullName = firstName + " " + lastName;

console.log(fullName);

Output:

Rohan Jagtap

Template Literals:

Backticks vaprun string madhye variable chi value direct insert karta yete. Yala template literal mhantat. 

let name = "Rohan";
let age = 20;

console.log(`My name is ${name} and my age is ${age}.`);

Output:

My name is Rohan and my age is 20.

4. Number Data Type

Number cha use numerical values store karnyasathi hoto. JavaScript madhye integer ani decimal values donhi Number type madhye yetat.

Example:

let age = 20;
let price = 99.50;
let temperature = -5;

console.log(age);
console.log(price);
console.log(temperature);

Output:

20
99.5
-5

Mathematical Operations:

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Output:

15
5
50
2
Tip: JavaScript madhye 10 ani 10.5 ya donhi values Number data type madhye yetat.

5. Boolean Data Type

Boolean data type madhye fakt don values astat: true kiwa false.

Conditions, login status, result ani yes/no type decisions ghenyasathi Boolean vapartat.

Example:

let isLoggedIn = true;
let isPassed = false;

console.log(isLoggedIn);
console.log(isPassed);

Output:

true
false

Practical Example:

let marks = 75;

let isPassed = marks >= 35;

console.log(isPassed);

Output:

true

Marks 35 kiwa tyapeksha jast aslyamule condition true zali.

6. Undefined Data Type

Variable declare kela pan tyala value assign keli nahi tar tyachi value undefined aste.

Example:

let studentName;

console.log(studentName);

Output:

undefined

Assigning a Value:

let age;

age = 20;

console.log(age);

Output:

20
लक्षात ठेव: undefined mhanje variable declare zala aahe, pan tyala ajun value assign kelel nahi.

7. Null Data Type

Null cha use janivpurvak empty kiwa absent value dakhavnyasathi hoto.

Example:

let selectedUser = null;

console.log(selectedUser);

Output:

null

Undefined vs Null:

let a;

let b = null;

console.log(a);
console.log(b);

Output:

undefined
null
Undefined Null
Value assign kelel naste. Janivpurvak empty value dili aste.
JavaScript default value dete. Programmer null assign karto.
Important: typeof null cha result "object" yeto. Hi JavaScript madhil ek juna historical behavior aahe. Null ha primitive data type aahe.

8. BigInt Data Type

BigInt cha use khup mothya integer numbers represent karnyasathi hoto.

Normal Number type madhye safe integer limit aste. Tyapeksha mothya integers sathi BigInt upyogi aahe.

Example:

let bigNumber = 12345678901234567890n;

console.log(bigNumber);
console.log(typeof bigNumber);

Output:

12345678901234567890n
bigint
Important: BigInt value chya shevati n lihitat. BigInt ani Number yanchi direct arithmetic operation karta yet nahi.

9. Symbol Data Type

Symbol ha unique identifier tayar karnyasathi vaparla janara primitive data type aahe.

Example:

let id1 = Symbol("id");
let id2 = Symbol("id");

console.log(id1 === id2);

Output:

false

Donhi symbols madhye same description asle tari pratyek Symbol value unique aste.

Tip: Symbol cha advanced JavaScript madhye object properties sathi unique keys tayar karnyasathi use hou shakto.

10. Object Data Type

Object madhye related data key-value pairs chya format madhye store karta yeto.

Example:

const student = {
    name: "Rohan",
    age: 20,
    city: "Kolhapur"
};

console.log(student);

Output:

{
  name: "Rohan",
  age: 20,
  city: "Kolhapur"
}

Access Object Properties:

console.log(student.name);
console.log(student.age);
console.log(student.city);

Output:

Rohan
20
Kolhapur

Array Example:

Array madhye ekach variable madhye anek values store karta yetat. JavaScript madhye array ha object cha ek special type aahe. 

const fruits = ["Apple", "Mango", "Banana"];

console.log(fruits);
console.log(fruits[0]);
console.log(fruits[1]);

Output:

["Apple", "Mango", "Banana"]
Apple
Mango
Note: Object, Array ani Function he vegvegale structures aahet. Function sathi typeof operator "function" return karto, tar Array sathi "object" return karto.

11. typeof Operator

typeof operator cha use variable kiwa value cha data type check karnyasathi hoto.

Syntax:

typeof value;

Example:

let name = "Rohan";
let age = 20;
let isPassed = true;
let city;

console.log(typeof name);
console.log(typeof age);
console.log(typeof isPassed);
console.log(typeof city);

Output:

string
number
boolean
undefined

More Examples:

console.log(typeof null);
console.log(typeof []);
console.log(typeof {});
console.log(typeof function() {});

Output:

object
object
object
function
Important: typeof null ani typeof array donhi "object" return kartat. Array check karnyasathi Array.isArray() vapra.

Array Check Example:

const fruits = ["Apple", "Mango"];

console.log(Array.isArray(fruits));

Output:

true

12. Dynamic Typing

JavaScript hi dynamically typed language aahe. Mhanje ekach variable madhye vegveglya veli vegveglya data types chya values assign karta yetat.

Example:

let value = "Hello";

console.log(typeof value);

value = 100;

console.log(typeof value);

value = true;

console.log(typeof value);

Output:

string
number
boolean

Suruvatila value String hoti. Nantar Number ani shevati Boolean zali.

Tip: JavaScript madhye variable cha data type value nusar badlu shakto. Mhanun variable madhye konti value aahe he lakshat thevne mahatvache aahe.

13. Type Conversion

Ek data type dusrya data type madhye convert karnyala Type Conversion mhantat.

String to Number:

let age = "20";

let result = Number(age);

console.log(result);
console.log(typeof result);

Output:

20
number

Number to String:

let price = 100;

let result = String(price);

console.log(result);
console.log(typeof result);

Output:

100
string

Value to Boolean:

let value = 1;

let result = Boolean(value);

console.log(result);

Output:

true
लक्षात ठेव: Number(), String() ani Boolean() ya functions cha use explicit type conversion sathi hoto.

14. Common Beginner Mistakes

Mistake 1: Number ani String madhil difference na samajne

"20" hi String aahe, tar 20 ha Number aahe.

Mistake 2: true ani false la quotes madhye lihine

true he Boolean aahe, pan "true" hi String aahe.

Mistake 3: Undefined ani Null same samajne

Undefined hi value assign na zalyamule yete. Null hi janivpurvak assign kelel empty value aahe.

Mistake 4: Array cha type number kiwa array aahe ase samajne

typeof array cha result "object" yeto. Array.isArray() vaprun array check kara.

Mistake 5: typeof null cha result null asel ase samajne

typeof null cha result "object" yeto. Ha JavaScript madhil historical behavior aahe.
