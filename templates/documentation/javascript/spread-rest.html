Spread and Rest Operators

JavaScript madhye three dots (...) vaprun array, object ani function arguments sobat kam kase karayche te ya lesson madhye shikuya.

Beginner Level 35–40 Minutes

1. What are Spread and Rest Operators?

Spread ani Rest donhi sathi three dots (...) syntax vapartat. Pan tyanchya uses vegveglya aahet.

  • Spread: Array kiwa object madhil values spread karto.
  • Rest: Multiple values ekatra collect karto.
Remember: Spread values expand karto, tar Rest values collect karto.

2. Spread Operator with Arrays

Spread Operator cha use array madhil elements vegale karnyasathi hoto.

Example:

const numbers = [10, 20, 30];

console.log(...numbers);

Output:

10 20 30

...numbers mule array madhil elements spread hotat.

3. Copy an Array using Spread

Spread Operator vaprun existing array chi shallow copy tayar karta yete.

Example:

const original = [10, 20, 30];

const copy = [...original];

console.log(copy);

Output:

[10, 20, 30]

Explanation:

  • original madhye original array aahe.
  • ...original elements spread karto.
  • copy madhye navin array tayar hoto.
  • Top-level elements change kele tar original array change hot nahi.
Important: Spread chi copy shallow aste. Nested arrays kiwa objects aslyas tyanchya inner references share hou shaktat.

4. Merge Two Arrays

Don kiwa adhik arrays ekatra combine karnyasathi Spread Operator vaparta yeto.

Example:

const first = [10, 20];

const second = [30, 40];

const combined = [...first, ...second];

console.log(combined);

Output:

[10, 20, 30, 40]

Explanation:

  • first array madhil values spread hotat.
  • second array madhil values suddha spread hotat.
  • combined madhye donhi arrays merge hotat.

5. Add Elements to an Array

Existing array chi copy karun tyat navin elements add karnyasathi Spread Operator vaparta yeto.

Example:

const fruits = ["Apple", "Mango"];

const newFruits = [...fruits, "Banana"];

console.log(newFruits);

Output:

["Apple", "Mango", "Banana"]

Ya example madhye original fruits array change hot nahi. Navin array tayar hoto.

6. Spread Operator with Objects

Spread Operator vaprun object chi shallow copy tayar karta yete.

Example:

const student = {
    name: "Rohan",
    age: 20
};

const copy = { ...student };

console.log(copy);

Output:

{ name: "Rohan", age: 20 }

...student mule student object madhil properties copy object madhye spread hotat.

7. Merge Two Objects

Don objects ekatra combine karnyasathi Spread Operator vaparta yeto.

Example:

const student = {
    name: "Rohan"
};

const course = {
    subject: "Computer Science"
};

const details = {
    ...student,
    ...course
};

console.log(details);

Output:

{
    name: "Rohan",
    subject: "Computer Science"
}
Remember: Donhi objects madhye same key asel tar nantar spread kelelya object chi value final object madhye rahte.

8. Rest Parameters in Functions

Rest Parameters cha use function madhye dilele multiple arguments ekach array madhye collect karnyasathi hoto.

Example:

function add(...numbers) {

    let total = 0;

    for (const number of numbers) {
        total += number;
    }

    return total;
}

console.log(add(10, 20, 30));

Output:

60

Explanation:

  • ...numbers multiple arguments collect karte.
  • numbers ha array asto.
  • for...of loop pratyek number access karto.
  • total madhye sarv numbers add hotat.
  • return final answer deto.

9. Rest with Normal Parameters

Rest Parameter chya adhi normal parameters suddha lihita yetat. Pan Rest Parameter ha function madhil last parameter asla pahije.

Example:

function showStudent(name, ...subjects) {

    console.log(name);
    console.log(subjects);

}

showStudent("Rohan", "Python", "Django", "JavaScript");

Output:

Rohan
["Python", "Django", "JavaScript"]

Explanation:

  • name madhye first argument store hoto.
  • ...subjects urlele arguments collect karto.
  • subjects ha array asto.
Important: Rest Parameter function madhye last position varach asla pahije. Tyachyanantar dusra parameter lihita yet nahi.

10. Spread vs Rest

Spread Rest
Values expand karto. Values collect karto.
Array ani object copy/merge sathi use hoto. Function arguments collect karnyasathi use hoto.
Existing values spread karto. Multiple values ekatra array madhye thevto.
Example: [...numbers] Example: function add(...numbers)

11. Common Beginner Mistakes

Mistake 1: Spread ani Rest madhil difference na samajne

Spread values expand karto, tar Rest multiple values collect karto.

Mistake 2: Rest Parameter last position var na thevne

Rest Parameter function madhil last parameter asla pahije.

Mistake 3: Spread la deep copy samajne

Spread Operator shallow copy tayar karto. Nested objects ani arrays share hou shaktat.

Mistake 4: Object madhil duplicate keys visarne

Same key asel tar nantar spread kelelya object chi value overwrite karu shakte.

12. Quick Revision

  • Spread ani Rest sathi ... syntax vapartat.
  • Spread array ani object values expand karto.
  • Spread vaprun arrays copy ani merge karta yetat.
  • Spread vaprun objects copy ani merge karta yetat.
  • Rest multiple function arguments collect karto.
  • Rest Parameter function madhye last position var asto.
  • Spread chi copy shallow aste.
