JavaScript Array Methods

Array Methods cha use array madhil data add, remove, search, filter ani calculate karnyasathi hoto. Ya lesson madhye important methods practical examples sahit shikuya.

Beginner Level 40–45 Minutes

1. What are Array Methods?

JavaScript madhye array var vegvegli operations perform karnyasathi built-in methods available aahet. Tyanna Array Methods mhantat.

Example:

let fruits = ["Apple", "Mango"];

fruits.push("Banana");

console.log(fruits);

Output:

["Apple", "Mango", "Banana"]
Simple Definition: Array var specific operation perform karanarya built-in functions na Array Methods mhantat.

2. push() and pop()

push() Method

push() method array chya shevati ek kiwa adhik elements add karto. 

let fruits = ["Apple", "Mango"];

fruits.push("Banana");

console.log(fruits);

Output:

["Apple", "Mango", "Banana"]

pop() Method

pop() method array madhil shevatcha element remove karto ani remove kelela element return karto. 

let fruits = ["Apple", "Mango", "Banana"];

let removed = fruits.pop();

console.log(removed);
console.log(fruits);

Output:

Banana
["Apple", "Mango"]
Remember: push() element add karto, tar pop() shevatcha element remove karto.

3. shift() and unshift()

shift() Method

shift() method array madhil pahila element remove karto ani to element return karto. 

let fruits = ["Apple", "Mango", "Banana"];

let removed = fruits.shift();

console.log(removed);
console.log(fruits);

Output:

Apple
["Mango", "Banana"]

unshift() Method

unshift() method array chya suruvatila ek kiwa adhik elements add karto. 

let fruits = ["Mango", "Banana"];

fruits.unshift("Apple");

console.log(fruits);

Output:

["Apple", "Mango", "Banana"]
Revision: shift() pahila element remove karto. unshift() suruvatila element add karto.

4. slice() Method

slice() method array madhil specific range madhil elements chi new array tayar karto.

Original array madhye badal hot nahi.

Syntax:

array.slice(start, end);
  • start: Kontya index pasun copy suru karaychi.
  • end: Kontya index chya aadhi thambayche. End index include hot nahi.

Example:

let numbers = [10, 20, 30, 40, 50];

let result = numbers.slice(1, 4);

console.log(result);
console.log(numbers);

Output:

[20, 30, 40]
[10, 20, 30, 40, 50]
Important: slice() original array change karat nahi. End index cha element result madhye include hot nahi.

5. splice() Method

splice() method array madhye elements add, remove kiwa replace karnyasathi vapartat.

splice() original array madhye badal karto.

Syntax:

array.splice(start, deleteCount, item1, item2);
  • start: Badal kontya index pasun karaycha.
  • deleteCount: Kiti elements remove karayche.
  • item1, item2: Nave elements add karayche aslyas.

Example – Remove Element:

let fruits = ["Apple", "Mango", "Banana"];

fruits.splice(1, 1);

console.log(fruits);

Output:

["Apple", "Banana"]

Example – Add Element:

let fruits = ["Apple", "Banana"];

fruits.splice(1, 0, "Mango");

console.log(fruits);

Output:

["Apple", "Mango", "Banana"]

Example – Replace Element:

let fruits = ["Apple", "Mango", "Banana"];

fruits.splice(1, 1, "Orange");

console.log(fruits);

Output:

["Apple", "Orange", "Banana"]

6. map() Method

map() method array madhil pratyek element var callback function execute karto ani new array return karto.

Original array change hot nahi.

Example:

let numbers = [1, 2, 3, 4, 5];

let doubled = numbers.map(number => number * 2);

console.log(doubled);

Output:

[2, 4, 6, 8, 10]

Explanation:

  • map() pratyek number access karto.
  • Pratyek number la 2 ne multiply karto.
  • Result new array madhye store hoto.
  • Original numbers array tasach rahto.

Another Example:

let prices = [100, 200, 300];

let updatedPrices = prices.map(price => price + 50);

console.log(updatedPrices);

Output:

[150, 250, 350]
Use: Array madhil pratyek value transform karun new array tayar karaycha asel tar map() vapra.

7. filter() Method

filter() method condition check karto ani condition true aslelya elements chi new array return karto.

Original array change hot nahi.

Example:

let numbers = [10, 15, 20, 25, 30];

let evenNumbers = numbers.filter(number => number % 2 === 0);

console.log(evenNumbers);

Output:

[10, 20, 30]

Explanation:

  • filter() pratyek number check karto.
  • number % 2 === 0 hi even number chi condition aahe.
  • Fakt condition true aslele numbers new array madhye yetat.

Another Example:

let marks = [25, 40, 75, 30, 90];

let passed = marks.filter(mark => mark >= 35);

console.log(passed);

Output:

[40, 75, 90]
Use: API data madhun specific records select karnyasathi filter() khup upyogi aahe.

8. reduce() Method

reduce() method array madhil sarva elements process karun ek final value tayar karto.

Syntax:

array.reduce((accumulator, currentValue) => {
    return accumulator + currentValue;
}, initialValue);

Example:

let numbers = [10, 20, 30, 40];

let total = numbers.reduce((sum, number) => {
    return sum + number;
}, 0);

console.log(total);

Output:

100

Explanation:

  • sum: Accumulator mhanje jama hot janari value.
  • number: Current element.
  • 0: Initial value.
  • Pratyek number sum madhye add hoto.
  • Shevati ek final total milto.

Step-by-Step:

Step Current Number Sum
Initial - 0
1 10 10
2 20 30
3 30 60
4 40 100
Use: Shopping cart total, marks total ani data madhil values calculate karnyasathi reduce() vaparta yeto.

9. find() Method

find() method condition true honara pahila element return karto.

Matching element sapadla nahi tar undefined return hoto.

Example:

let numbers = [10, 25, 30, 45, 50];

let result = numbers.find(number => number > 30);

console.log(result);

Output:

45

Explanation:

  • find() array madhil elements ek-ek karun check karto.
  • 10 ani 25 condition pass karat nahit.
  • 30 suddha condition pass karat nahi.
  • 45 pahila matching element aslyamule return hoto.
  • Tyachyanantar pudhil elements check hot nahit.

10. forEach() Method

forEach() method array madhil pratyek element sathi callback function execute karto.

forEach() new array return karat nahi.

Example:

let fruits = ["Apple", "Mango", "Banana"];

fruits.forEach(fruit => {
    console.log(fruit);
});

Output:

Apple
Mango
Banana

Index Access Example:

let fruits = ["Apple", "Mango", "Banana"];

fruits.forEach((fruit, index) => {
    console.log(index, fruit);
});

Output:

0 Apple
1 Mango
2 Banana
Important: forEach() madhun array return hot nahi. New array tayar karaycha asel tar map() vapra.

11. includes() Method

includes() method array madhye specific value aahe ka te check karto.

Example:

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits.includes("Mango"));
console.log(fruits.includes("Orange"));

Output:

true
false

Value present asel tar true ani nasel tar false return hoto.

12. Difference Between Important Methods

Method Use Result
map() Elements transform karto. New Array
filter() Condition nusar elements select karto. New Array
reduce() Elements process karun final value deto. Single Value
find() Pahila matching element shodhto. Element / undefined
forEach() Pratyek element var callback chalavto. undefined
includes() Value present aahe ka check karto. Boolean
slice() Array cha kahi bhag copy karto. New Array
splice() Elements add, remove kiwa replace karto. Removed Elements

13. Common Beginner Mistakes

Mistake 1: map() ani forEach() confuse karne

map() new array return karto, tar forEach() return value mhanun undefined deto.

Mistake 2: slice() ani splice() confuse karne

slice() original array change karat nahi. splice() original array madhye badal karto.

Mistake 3: filter() madhye condition visarne

filter() callback madhun true kiwa false milne avashyak aahe.

Mistake 4: reduce() madhye initial value na dene

Initial value dene anek calculations madhye adhik safe ani predictable aste. Empty array sathi suddha te mahatvache aahe.

Mistake 5: find() ani filter() confuse karne

find() pahila matching element deto, tar filter() sarva matching elements chi array deto.
