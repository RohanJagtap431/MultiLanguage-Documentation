DOM Manipulation

Ya lesson madhye JavaScript vaprun HTML content, CSS styles ani webpage madhil elements kase change, add ani remove karayche te shikuya.

Beginner Level 40–45 Minutes

1. What is DOM Manipulation?

DOM Manipulation mhanje JavaScript vaprun HTML document madhil elements ani tyanchya properties madhye badal karne.

DOM Manipulation mule webpage reload na karta content, style ani structure update karta yete.

Definition: DOM Manipulation is the process of changing HTML elements, content, styles and structure using JavaScript.

DOM Manipulation cha use:

  • HTML text change karne.
  • HTML madhye new elements add karne.
  • Existing elements remove karne.
  • CSS styles change karne.
  • Webpage dynamic banavne.

2. textContent

textContent property cha use HTML element madhil text read ani change karnyasathi hoto.

HTML:

<h1 id="heading">Hello World</h1>

JavaScript:

const heading = document.getElementById("heading");

heading.textContent = "Welcome to JavaScript!";

console.log(heading.textContent);

Output:

Welcome to JavaScript!

Explanation:

  • getElementById() heading select karte.
  • textContent madhil text change karte.
  • console.log() updated text print karte.
Remember: Fakt text change karaycha asel tar textContent vaprane sope ani safe aste.

3. innerHTML

innerHTML property cha use element madhil HTML content read ani replace karnyasathi hoto.

HTML:

<div id="content">
    Old Content
</div>

JavaScript:

const content = document.getElementById("content");

content.innerHTML = "<h2>New Heading</h2>";

console.log(content.innerHTML);

Output:

<h2>New Heading</h2>

Ithe div madhil junya content chya jagi navin h2 element tayar hoto ani browser to heading mhanun display karto.

Security Warning: User kadun milalela untrusted data direct innerHTML madhye taku naka. Tyamule Cross-Site Scripting (XSS) cha risk asto. Plain text sathi textContent vapra.

4. textContent vs innerHTML

textContent innerHTML
Text read ani change karte. HTML content read ani replace karte.
HTML tags text mhanun dakhavte. HTML tags parse karte.
Plain text sathi safe choice. Untrusted input sathi risky.
HTML elements create karat nahi. HTML markup madhun elements tayar karu shakte.

5. Changing CSS with style

JavaScript madhye style property vaprun HTML element cha CSS style change karta yeto.

HTML:

<h1 id="title">Hello Student</h1>

JavaScript:

const title = document.getElementById("title");

title.style.color = "blue";
title.style.backgroundColor = "yellow";
title.style.fontSize = "30px";

Explanation:

  • style.color text cha color change karte.
  • style.backgroundColor background color change karte.
  • style.fontSize text size change karte.
Important: CSS madhye background-color ase lihitat. JavaScript style property madhye backgroundColor ase lihitat. CSS property madhil hyphen remove karun camelCase vapartat.

6. createElement()

createElement() method cha use JavaScript madhun navin HTML element create karnyasathi hoto.

JavaScript:

const heading = document.createElement("h2");

heading.textContent = "New Heading";

console.log(heading);

Explanation:

  • document.createElement("h2") navin h2 element tayar karte.
  • textContent vaprun tyat text add karto.
  • Element tayar hoto, pan ajun webpage var display hot nahi.
Remember: createElement() element tayar karte. To webpage var dakhavnyasathi appendChild() vapra.

7. appendChild()

appendChild() method cha use parent element chya shevti navin child element add karnyasathi hoto.

HTML:

<div id="container"></div>

JavaScript:

const container = document.getElementById("container");

const paragraph = document.createElement("p");

paragraph.textContent = "Welcome to DOM!";

container.appendChild(paragraph);

Output:

Welcome to DOM!

Working Process:

  1. Container select kela.
  2. New paragraph create kela.
  3. Paragraph madhye text add kela.
  4. appendChild() vaprun paragraph container madhye add kela.

8. remove()

remove() method cha use HTML document madhun existing element remove karnyasathi hoto.

HTML:

<p id="message">This message will be removed.</p>

JavaScript:

const message = document.getElementById("message");

message.remove();

Output:

Paragraph webpage madhun remove hoto.
Remember: remove() call kelyavar selected element DOM madhun remove hoto.

9. Practical Example – Add and Remove Items

Ya example madhye apan input madhun item gheun list madhye add karu ani button vaprun item remove karu.

HTML:

<input id="itemInput" type="text">

<button id="addButton">Add Item</button>

<ul id="itemList"></ul>

JavaScript:

const input = document.getElementById("itemInput");
const addButton = document.getElementById("addButton");
const list = document.getElementById("itemList");

addButton.addEventListener("click", function() {

    const value = input.value.trim();

    if (value === "") {
        return;
    }

    const li = document.createElement("li");

    li.textContent = value;

    const removeButton = document.createElement("button");
    removeButton.textContent = "Remove";

    removeButton.addEventListener("click", function() {
        li.remove();
    });

    li.appendChild(removeButton);
    list.appendChild(li);

    input.value = "";
});

Live Output:

    Item add karnyasathi nav type kara. Remove button vaprun item delete kara.

    10. Common Beginner Mistakes

    Mistake 1: textContent ani innerHTML confuse karne

    textContent plain text handle karte, tar innerHTML HTML markup parse karte.

    Mistake 2: createElement() nantar append na karne

    Fakt element create kelyane to webpage var disat nahi. Parent madhye append karava lagto.

    Mistake 3: CSS property wrong lihine

    JavaScript madhye background-color aivaji backgroundColor vapra.

    Mistake 4: Empty input add karne

    Input value trim() karun empty aahe ka te check kara.

    Mistake 5: Untrusted input innerHTML madhye takne

    User input sathi textContent vapra. Untrusted HTML mule security problem hou shakto.
