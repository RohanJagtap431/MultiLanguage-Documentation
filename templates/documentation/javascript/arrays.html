JavaScript Arrays

Array cha use ekach variable madhye anek values store karnyasathi hoto. Ya lesson madhye array create karne, elements access karne, add, update ani delete karne shikuya.

Beginner Level 35–40 Minutes

1. What is an Array?

Array ha ek special variable aahe jyamadhye anek values ekach thikani store karta yetat.

Samja aplyala 5 students chi nave store karaychi aahet. Vegvegale variables tayar karnyapeksha apan ek array vapru shakto.

Without Array:

let student1 = "Rohan";
let student2 = "Amit";
let student3 = "Rahul";
let student4 = "Sagar";
let student5 = "Akash";

With Array:

let students = [
    "Rohan",
    "Amit",
    "Rahul",
    "Sagar",
    "Akash"
];
Simple Definition: Ekach variable madhye multiple values store karanarya data structure la Array mhantat.

2. Creating an Array

JavaScript madhye array tayar karnyasathi square brackets [] vapartat.

Syntax:

let arrayName = [value1, value2, value3];

Example:

let fruits = ["Apple", "Mango", "Banana"];

let numbers = [10, 20, 30, 40];

let mixed = ["Rohan", 20, true];

Array madhye strings, numbers, booleans ani vegveglya data types chya values suddha store karta yetat.

Empty Array:

let colors = [];

console.log(colors);

Output:

[]

3. Array Index

Array madhil pratyek element la ek number dilela asto. Tyala Index mhantat.

JavaScript madhye array index 0 pasun suru hoto. Mhanje pahilya element cha index 0 asto.

Example:

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits[0]);
console.log(fruits[1]);
console.log(fruits[2]);

Output:

Apple
Mango
Banana

Array Index Structure:

Index 0 Apple
Index 1 Mango
Index 2 Banana
Important: Array cha index 0 pasun start hoto. 3 elements aslelya array madhye valid indexes 0, 1 ani 2 astat.

4. Accessing Array Elements

Array madhil specific value access karnyasathi arrayName[index] asa syntax vapartat.

Example:

let students = ["Rohan", "Amit", "Rahul"];

let firstStudent = students[0];

console.log(firstStudent);

Output:

Rohan

Accessing Last Element:

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits[fruits.length - 1]);

Output:

Banana

length - 1 mule array madhil shevatchya element cha index milto.

5. Array length Property

Array madhye ekun kiti elements aahet he janun ghenyasathi length property vapartat.

Example:

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits.length);

Output:

3

Another Example:

let numbers = [10, 20, 30, 40, 50];

console.log("Total Elements:", numbers.length);

Output:

Total Elements: 5
Tip: Array madhil elements chi sankhya check karnyasathi length property vapra.

6. Updating Array Elements

Array madhil existing value change karnyasathi tya element cha index vapartat.

Example:

let fruits = ["Apple", "Mango", "Banana"];

fruits[1] = "Orange";

console.log(fruits);

Output:

["Apple", "Orange", "Banana"]

Explanation:

  • Suruvatila index 1 var Mango hota.
  • fruits[1] = "Orange" mule value update zali.
  • Ata index 1 var Orange aahe.

7. Adding Elements to an Array

Array madhye nave elements add karnyasathi push() ani unshift() methods vapartat.

push() Method:

push() method array chya shevati nave element add karto. 

let fruits = ["Apple", "Mango"];

fruits.push("Banana");

console.log(fruits);

Output:

["Apple", "Mango", "Banana"]

unshift() Method:

unshift() method array chya suruvatila nave element add karto. 

let fruits = ["Apple", "Mango"];

fruits.unshift("Banana");

console.log(fruits);

Output:

["Banana", "Apple", "Mango"]
Remember: push() = शेवटी element add karto. unshift() = सुरुवातीला element add karto.

8. Removing Elements from an Array

Array madhun elements remove karnyasathi pop() ani shift() methods vapartat.

pop() Method:

pop() method array madhil shevatcha element remove karto. 

let fruits = ["Apple", "Mango", "Banana"];

fruits.pop();

console.log(fruits);

Output:

["Apple", "Mango"]

shift() Method:

shift() method array madhil pahila element remove karto. 

let fruits = ["Apple", "Mango", "Banana"];

fruits.shift();

console.log(fruits);

Output:

["Mango", "Banana"]
Remember: pop() = शेवटचा element remove karto. shift() = पहिला element remove karto.

9. Checking Array Elements

Array madhye specific value aahe ka he check karnyasathi includes() method vapartat.

Example:

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits.includes("Mango"));
console.log(fruits.includes("Orange"));

Output:

true
false

includes() method value sapadlyas true ani value naslyas false return karto.

10. Loop Through an Array

Array madhil sarva elements ek-ek karun access karnyasathi loop vapru shakto.

Using for Loop:

let fruits = ["Apple", "Mango", "Banana"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}

Output:

Apple
Mango
Banana

Using for...of:

let fruits = ["Apple", "Mango", "Banana"];

for (let fruit of fruits) {
    console.log(fruit);
}

Output:

Apple
Mango
Banana
Tip: Array madhil values access karnyasathi for...of ha simple option aahe. Index chi garaj asel tar traditional for loop vapra.

11. Array is a Reference Type

JavaScript madhye array ha object type madhye yeto. Array variable madhye array cha reference store hoto.

Example:

let numbers = [10, 20, 30];

let anotherNumbers = numbers;

anotherNumbers.push(40);

console.log(numbers);
console.log(anotherNumbers);

Output:

[10, 20, 30, 40]
[10, 20, 30, 40]

Explanation:

  • anotherNumbers madhye numbers cha reference assign kela.
  • Donhi variables ekach array la refer kartat.
  • anotherNumbers madhye 40 add kelyavar original array suddha change hoto.
Important: Array copy karaycha asel tar spread operator (...) kiwa slice() vaparta yeto. Ya topic cha detail pudhil lessons madhye pahu.

12. Common Beginner Mistakes

Mistake 1: Index 1 pasun start samajne

JavaScript array index 0 pasun suru hoto.

Mistake 2: length la function samajne

length hi property aahe. fruits.length ase vapra, fruits.length() ase nahi.

Mistake 3: push() ani unshift() confuse karne

push() shevati ani unshift() suruvatila element add karto.

Mistake 4: pop() ani shift() confuse karne

pop() shevatcha ani shift() pahila element remove karto.

Mistake 5: Invalid index access karne

Array madhye naslela index access kelyas undefined milu shakto.

Mistake 6: Array copy samjun reference assign karne

let second = first kelyane independent array copy tayar hot nahi.
