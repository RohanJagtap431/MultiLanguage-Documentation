JavaScript Strings and String Methods

String cha use text data store ani handle karnyasathi hoto. Ya lesson madhye String properties, important methods ani practical examples shikuya.

Beginner Level 35–45 Minutes

1. What is a String?

JavaScript madhye text data la String mhantat. String single quotes, double quotes kiwa backticks madhye lihili jate.

Example:

let firstName = "Rohan";

let city = 'Kolhapur';

let message = `Hello Rohan`;

console.log(firstName);
console.log(city);
console.log(message);

Output:

Rohan
Kolhapur
Hello Rohan
Remember: String mhanje characters cha group, jo text represent karto.

2. String Length

length property String madhil total characters chi sankhya return karte. Spaces suddha count hotat.

Example:

let name = "Rohan";

console.log(name.length);

Output:

5

Example with Spaces:

let message = "Hello World";

console.log(message.length);

Output:

11
Note: length hi property aahe, method nahi. Mhanun length() ase lihayche nahi.

3. Access String Characters

String madhil character tyachya index cha use karun access karta yeto. Index 0 pasun suru hoto.

Using Index:

let name = "Rohan";

console.log(name[0]);
console.log(name[1]);

Output:

R
o

Using charAt():

charAt() method dilelya index varil character return karte. 

let name = "Rohan";

console.log(name.charAt(2));

Output:

h

4. toUpperCase() and toLowerCase()

toUpperCase()

String madhil sarva English letters capital letters madhye convert karte. 

let name = "Rohan Jagtap";

console.log(name.toUpperCase());

Output:

ROHAN JAGTAP

toLowerCase()

String madhil sarva English capital letters small letters madhye convert karte. 

let email = "ROHAN@GMAIL.COM";

console.log(email.toLowerCase());

Output:

rohan@gmail.com
Use: User input madhil text standard format madhye convert karnyasathi he methods upyogi aahet.

5. trim() Method

trim() method String chya suruvatila ani shevati aslele extra whitespace remove karte.

Example:

let username = "   Rohan   ";

let result = username.trim();

console.log(result);
console.log(result.length);

Output:

Rohan
5

Other Trim Methods:

let text = "   Hello   ";

console.log(text.trimStart());
console.log(text.trimEnd());

Output:

Hello
   Hello
  • trim(): Donhi bajunche whitespace remove karte.
  • trimStart(): Fakt suruvaticha whitespace remove karte.
  • trimEnd(): Fakt shevatacha whitespace remove karte.

6. slice() Method

slice() method String madhil specific part extract karun new String return karte.

Syntax:

string.slice(start, end);
  • start: Starting index.
  • end: Jya index chya aadhi thambayche.

Example:

let language = "JavaScript";

let result = language.slice(0, 4);

console.log(result);

Output:

Java

Negative Index Example:

let language = "JavaScript";

console.log(language.slice(-6));

Output:

Script
Important: slice() original String change karat nahi. End index result madhye include hot nahi.

7. replace() and replaceAll()

replace()

replace() method String madhil matching text replace karte. Normal String search vaparlyas pahila matching part replace hoto. 

let message = "Hello Rohan";

let result = message.replace("Rohan", "Rahul");

console.log(result);

Output:

Hello Rahul

replaceAll()

replaceAll() method matching text chya sarva occurrences replace karte. 

let message = "Java is easy. Java is popular.";

let result = message.replaceAll("Java", "Python");

console.log(result);

Output:

Python is easy. Python is popular.
Difference: replace() pahila matching part replace karto, tar replaceAll() sarva matching parts replace karto.

8. includes() Method

includes() method String madhye specific text present aahe ka te check karte.

Example:

let message = "I am learning JavaScript";

console.log(message.includes("JavaScript"));
console.log(message.includes("Python"));

Output:

true
false

includes() true kiwa false return karte. Hi method case-sensitive aahe.

9. startsWith() and endsWith()

startsWith()

String dilelya text ne suru hote ka te check karte. 

let name = "Rohan Jagtap";

console.log(name.startsWith("Rohan"));

Output:

true

endsWith()

String dilelya text ne sampte ka te check karte. 

let file = "notes.pdf";

console.log(file.endsWith(".pdf"));

Output:

true

10. split() Method

split() method String la specific separator nusar parts madhye divide karte ani new array return karte.

Example:

let fruits = "Apple,Mango,Banana";

let result = fruits.split(",");

console.log(result);

Output:

["Apple", "Mango", "Banana"]

Split Using Space:

let name = "Rohan Jagtap";

let result = name.split(" ");

console.log(result);

Output:

["Rohan", "Jagtap"]
Use: Comma-separated text la array madhye convert karnyasathi split() khup upyogi aahe.

11. join() Method

join() method array madhil elements ekatra karun String tayar karte.

Example:

let fruits = ["Apple", "Mango", "Banana"];

let result = fruits.join(", ");

console.log(result);

Output:

Apple, Mango, Banana

Another Example:

let words = ["JavaScript", "is", "easy"];

console.log(words.join(" "));

Output:

JavaScript is easy
Remember: split() String la Array madhye convert karte. join() Array la String madhye convert karte.

12. Template Literals

Template Literals cha use String madhye variables ani expressions insert karnyasathi hoto. Yat backticks (`) vapartat.

Example:

let name = "Rohan";
let age = 20;

let message = `My name is ${name} and I am ${age} years old.`;

console.log(message);

Output:

My name is Rohan and I am 20 years old.
Remember: ${} chya madhye variable kiwa JavaScript expression lihita yeto.

13. String Methods Summary

Method / Property Use Return
length Characters count karte. Number
charAt() Index varil character dete. String
toUpperCase() Capital letters madhye convert karte. New String
toLowerCase() Small letters madhye convert karte. New String
trim() Donhi bajunche whitespace remove karte. New String
slice() String cha specific part dete. New String
replace() Matching text replace karte. New String
includes() Text present aahe ka check karte. Boolean
startsWith() Starting text check karte. Boolean
endsWith() Ending text check karte. Boolean
split() String la Array madhye divide karte. Array
join() Array la String madhye convert karte. String

14. Important Concept – Strings are Immutable

JavaScript madhye Strings immutable astat. Mhanje ekda String create zalyanantar tichya characters madhye direct change karta yet nahi.

Example:

let name = "Rohan";

name[0] = "M";

console.log(name);

Output:

Rohan

Character change zala nahi. Nave String tayar karun variable la assign karave lagte. 

let name = "Rohan";

name = "Mohan";

console.log(name);

Output:

Mohan

15. Common Beginner Mistakes

Mistake 1: length() vaprane

length hi property aahe. length() ase lihayche nahi. 

let name = "Rohan";

console.log(name.length);
Mistake 2: trim() original String change karte ase samajne

trim() new String return karte. Original String tasach rahto.

Mistake 3: includes() case-sensitive aahe he visarne

"JavaScript" ani "javascript" he vegale text aahet.

Mistake 4: split() ani join() confuse karne

split() String pasun Array banavte, tar join() Array pasun String banavte.
