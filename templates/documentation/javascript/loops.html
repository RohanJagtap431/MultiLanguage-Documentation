JavaScript Loops

JavaScript madhye ekach code anek vela execute karnyasathi loops vapartat. Ya lesson madhye for, while, do...while, for...of ani for...in shikuya.

Beginner Level 35–40 Minutes

1. What are Loops?

Loop mhanje ekach code specific condition purna hoiparyant punha-punha execute karanyachi process.

Samja aplyala 1 te 5 numbers print karayche aahet. Pratyek number sathi vegvegla console.log() lihinyapeksha loop vaprun he kam kami code madhye karta yete.

Without Loop:

console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);

With Loop:

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Output:

1
2
3
4
5
Simple Definition: Condition true asel toparyant code repeat karnyasathi loops vapartat.

2. for Loop

for loop cha use tevha hoto jevha aplyala loop kiti vela execute karaycha aahe he mahit aste.

Syntax:

for (initialization; condition; update) {
    // Code to execute
}

Example:

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Output:

1
2
3
4
5

for Loop che 3 Parts:

1. Initialization let i = 1

Loop variable chi starting value set karte.

2. Condition i <= 5

Condition true asel tar loop execute hoto.

3. Update i++

Pratyek round nantar variable chi value vadhavto.

Step-by-Step Execution:

Round i Value Condition Output
1 1 true 1
2 2 true 2
3 3 true 3
4 4 true 4
5 5 true 5
6 6 false Loop stops
Tip: Fixed number of repetitions astil tar for loop vaprane sahaj aste.

3. while Loop

while loop madhye condition aadhi check keli jate. Condition true asel tar loop madhil code execute hoto.

Condition false zalyavar loop thambto.

Syntax:

while (condition) {
    // Code to execute
}

Example:

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

Output:

1
2
3
4
5

Explanation:

  • Suruvatila i = 1 set kele.
  • while condition i <= 5 check karte.
  • Condition true aslyas number print hoto.
  • i++ mule i chi value 1 ne vadhte.
  • i chi value 6 zalyavar condition false hote.
  • Tyamule loop stop hoto.
Important: while loop madhye variable update karayla visru naka. Nahi tar infinite loop tayar hou shakto.

4. do...while Loop

do...while loop madhye aadhi code execute hoto ani nantar condition check keli jate.

Mhanun condition false asli tari do block madhil code kamit kami ekda execute hoto.

Syntax:

do {
    // Code to execute
} while (condition);

Example:

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

Output:

1
2
3
4
5

Condition False Example:

let i = 10;

do {
    console.log(i);
} while (i <= 5);

Output:

10
Remember: do...while madhye code pahilyanda execute hoto. while madhye condition pahilyanda check hote.

5. for...of Loop

for...of loop cha use array kiwa string madhil values ek-ek karun access karnyasathi hoto.

Syntax:

for (let value of iterable) {
    // Code to execute
}

Array Example:

let fruits = ["Apple", "Mango", "Banana"];

for (let fruit of fruits) {
    console.log(fruit);
}

Output:

Apple
Mango
Banana

String Example:

let name = "Rohan";

for (let letter of name) {
    console.log(letter);
}

Output:

R
o
h
a
n
Tip: Array madhil values kiwa string madhil characters access karayche astil tar for...of upyogi aahe.

6. for...in Loop

for...in loop cha use object madhil property names kiwa keys access karnyasathi hoto.

Syntax:

for (let key in object) {
    // Code to execute
}

Object Example:

let student = {
    name: "Rohan",
    age: 20,
    course: "BSc CS"
};

for (let key in student) {
    console.log(key);
}

Output:

name
age
course

Values Access Karne:

let student = {
    name: "Rohan",
    age: 20,
    course: "BSc CS"
};

for (let key in student) {
    console.log(student[key]);
}

Output:

Rohan
20
BSc CS
Important: Object chya keys sathi for...in vapra. Array values sathi sahasa for...of kiwa for loop vapra.

7. break Statement

break statement cha use loop la lagech stop karnyasathi hoto. Condition purna zalyavar pudhil repetitions hot nahit.

Example:

for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        break;
    }

    console.log(i);
}

Output:

1
2

Explanation:

  • Loop 1 pasun start hoto.
  • 1 ani 2 print hotat.
  • i === 3 zalyavar break execute hoto.
  • Loop lagech stop hoto.

8. continue Statement

continue statement cha use current iteration skip karun loop chi pudhil iteration suru karnyasathi hoto.

Example:

for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}

Output:

1
2
4
5

Explanation:

  • Loop 1 pasun 5 paryant chalto.
  • i chi value 3 zalyavar continue execute hoto.
  • 3 print hot nahi.
  • Loop pudhil value 4 pasun continue hoto.

9. Difference Between JavaScript Loops

Loop Use
for Repetitions chi sankhya mahit asel tevha.
while Condition true asel toparyant.
do...while Code kamit kami ekda execute karaycha asel tevha.
for...of Array kiwa string madhil values sathi.
for...in Object madhil keys sathi.

break vs continue

break continue
Complete loop stop karto. Current iteration skip karto.
Pudhil iterations execute hot nahit. Pudhil iteration suru hote.

10. Practical Example - Array Total

Ata array madhil sarva numbers chi addition loop vaprun kashi karaychi te pahu.

JavaScript Code:

let numbers = [10, 20, 30, 40, 50];

let total = 0;

for (let number of numbers) {
    total = total + number;
}

console.log("Total:", total);

Output:

Total: 150

Explanation:

  • numbers array madhye 5 numbers aahet.
  • total chi starting value 0 aahe.
  • for...of pratyek number access karto.
  • Pratyek number total madhye add hoto.
  • Shevati total 150 milto.
Backend Relevance: Django madhun milalelya data var calculations karne, arrays madhil records process karne ani repeated tasks karne ya sathi loops upyogi padtat.

11. Common Beginner Mistakes

Mistake 1: Update विसरणे

for kiwa while loop madhye variable update karayla visarlyas infinite loop hou shakto.

Mistake 2: Wrong condition lihine

i <= 5 ani i < 5 ya conditions madhye output cha farak asto.

Mistake 3: for...in ani for...of confuse karne

for...in object keys sathi ani for...of values access karnyasathi vapra.

Mistake 4: break ani continue confuse karne

break complete loop stop karto, tar continue fakt current iteration skip karto.

Mistake 5: do...while madhil semicolon visarne

do...while statement chya shevati semicolon vapra.
