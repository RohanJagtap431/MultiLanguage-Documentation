JSON (JavaScript Object Notation)

Ya lesson madhye JSON format, syntax rules, JavaScript Object ani JSON madhil difference, stringify() ani parse() shikuya.

Beginner Level 30–35 Minutes

1. What is JSON?

JSON cha full form JavaScript Object Notation aahe. JSON ha data store ani exchange karnyasathi vaparla janara lightweight text format aahe.

Don applications madhye data send ani receive karnyasathi JSON cha mothya pramanat use hoto.

Definition: JSON is a lightweight text format used to store and exchange data.

Example:

{
    "name": "Rohan",
    "age": 20,
    "course": "Computer Science"
}

Explanation:

  • name hi property aahe ani Rohan hi value aahe.
  • age chi value 20 aahe.
  • course chi value Computer Science aahe.
  • JSON data text format madhye represent karto.

2. Why Do We Use JSON?

JSON cha use applications madhye data exchange karnyasathi hoto.

Uses:

  • Frontend ani Backend madhye data exchange.
  • REST API madhun data receive karne.
  • Server kade data send karne.
  • Configuration files madhye data store karne.
  • Local Storage madhye structured data save karne.
Backend Developer sathi: Django REST Framework madhun API response detana JSON format cha use kela jato.

3. JSON Syntax Rules

JSON lihitana kahi important rules follow karave lagtat.

Rules:

  1. Data key-value pairs madhye lihila jato.
  2. Keys double quotes madhye lihilya pahijet.
  3. String values double quotes madhye lihilya pahijet.
  4. Key ani value madhye colon (:) vapartat.
  5. Multiple properties madhye comma (,) vapartat.
  6. Object sathi curly brackets { } vapartat.
  7. Array sathi square brackets [ ] vapartat.
  8. Shevatchya property nantar trailing comma allowed nahi.

Correct JSON:

{
    "name": "Rohan",
    "age": 20,
    "is_student": true
}

Incorrect JSON:

{
    name: "Rohan",
    'age': 20,
    "is_student": true,
}
Important: JSON madhye single quotes ani unquoted keys allowed nahit. Shevatchya property nantar comma suddha deu naye.

4. JSON Data Types

JSON madhye khalil data types support kele jatat.

Data Type Example
String "Rohan"
Number 20
Boolean true / false
Null null
Object { "city": "Pune" }
Array ["Python", "Django"]
Remember: JSON madhye undefined, function ani Symbol data types support hot nahit.

5. JavaScript Object vs JSON

JavaScript Object ani JSON disayla similar astat, pan donhi ekach goshta nahit.

JavaScript Object:

const student = {
    name: "Rohan",
    age: 20,
    greet: function() {
        return "Hello";
    }
};

JSON:

{
    "name": "Rohan",
    "age": 20
}

Differences:

JavaScript Object JSON
JavaScript data structure Text data format
Keys la quotes optional astat (identifier asel tar) Keys double quotes madhye pahijet
Functions allowed Functions allowed nahit
undefined value possible undefined support nahi
Directly JavaScript madhye use hoto Parse karun JavaScript value milavta yete

6. JSON.stringify()

JSON.stringify() cha use JavaScript value la JSON string madhye convert karnyasathi hoto.

Example:

const student = {
    name: "Rohan",
    age: 20,
    course: "BSc CS"
};

const jsonData = JSON.stringify(student);

console.log(jsonData);
console.log(typeof jsonData);

Output:

{"name":"Rohan","age":20,"course":"BSc CS"}
string

Explanation:

  • student ha JavaScript Object aahe.
  • JSON.stringify() object la JSON string madhye convert karto.
  • jsonData madhye string store hote.
  • typeof vaprun data type check karta yeto.
Remember: stringify() = JavaScript Value → JSON String

7. JSON.parse()

JSON.parse() cha use valid JSON string la JavaScript value madhye convert karnyasathi hoto.

Example:

const jsonData = '{"name":"Rohan","age":20}';

const student = JSON.parse(jsonData);

console.log(student.name);
console.log(student.age);
console.log(typeof student);

Output:

Rohan
20
object

Explanation:

  • jsonData hi valid JSON string aahe.
  • JSON.parse() string la JavaScript Object madhye convert karto.
  • student.name ani student.age access karta yetat.
  • typeof student cha result object milto.
Remember: parse() = JSON String → JavaScript Value

8. stringify() vs parse()

JSON.stringify() JSON.parse()
Value to JSON string JSON string to value
Serialization Parsing
Data send/store karnyasathi useful Data read/use karnyasathi useful

9. Practical Example – Student Data

Student object JSON string madhye convert karu ani punha JavaScript Object madhye convert karu.

JavaScript:

const student = {
    name: "Rohan",
    course: "BSc Computer Science",
    skills: ["Python", "Django"]
};

// Convert Object to JSON String
const jsonData = JSON.stringify(student);

// Convert JSON String to Object
const newStudent = JSON.parse(jsonData);

console.log(newStudent.name);
console.log(newStudent.course);
console.log(newStudent.skills[0]);

Output:

Rohan
BSc Computer Science
Python

11. Common Beginner Mistakes

Mistake 1: JSON madhye single quotes vaprane

JSON strings ani keys sathi double quotes vapra.

Mistake 2: stringify() ani parse() confuse karne

stringify() value la string karto, parse() string la value karto.

Mistake 3: JSON madhye function lihine

JSON madhye function ani undefined support hot nahit.

Mistake 4: Invalid JSON parse karne

Invalid JSON string parse kelyas SyntaxError yeu shakto.

Mistake 5: JSON ani JavaScript Object same samajne

JavaScript Object ha data structure aahe, JSON ha text format aahe.
