JavaScript Events

Ya lesson madhye user webpage sobat interact karto tevha JavaScript events kase work kartat te shikuya. Button click, input, change ani form submit yanche examples pahuya.

Beginner Level 40–45 Minutes

1. What are JavaScript Events?

Event mhanje webpage var ghadnari ek action kiwa activity. User kiwa browser kahi action karto tevha event trigger hou shakto.

Examples:

  • Button click karne.
  • Input madhye text type karne.
  • Dropdown madhil option change karne.
  • Form submit karne.
  • Webpage load hone.
  • Keyboard madhil key press karne.
Definition: JavaScript Events are actions or occurrences that happen in the browser and can be handled using JavaScript.

2. addEventListener()

addEventListener() method cha use HTML element var specific event listen karnyasathi ani event ghadlyavar function execute karnyasathi hoto.

Syntax:

element.addEventListener("event", function() {
    // Code to execute
});

Example:

const button = document.getElementById("myButton");

button.addEventListener("click", function() {
    console.log("Button Clicked!");
});

Explanation:

  • button variable madhye HTML button select hoto.
  • addEventListener() event listen karte.
  • "click" ha event type aahe.
  • Click zalyavar function execute hote.
Remember: addEventListener() vaparlyamule HTML ani JavaScript code vegale thevta yetat.

3. Click Event

click event tevha trigger hoto jevha user HTML element var click karto.

HTML:

<button id="clickButton">Click Me</button>

<p id="message">Waiting...</p>

JavaScript:

const button = document.getElementById("clickButton");
const message = document.getElementById("message");

button.addEventListener("click", function() {
    message.textContent = "Button Clicked!";
});

Output:

Button click kelyavar:
Button Clicked!

Button click kelyavar paragraph madhil text change hoto.

4. Input Event

input event tevha trigger hoto jevha user input field madhil value type karto kiwa change karto.

HTML:

<input type="text" id="nameInput">

<p id="result"></p>

JavaScript:

const nameInput = document.getElementById("nameInput");
const result = document.getElementById("result");

nameInput.addEventListener("input", function() {
    result.textContent = nameInput.value;
});

Explanation:

  • input field select kele.
  • input event listen kela.
  • nameInput.value madhun current value milte.
  • Result paragraph madhye value display hote.

5. Change Event

change event tevha trigger hoto jevha input, select kiwa checkbox chi value change hote ani ti change confirm hote.

HTML:

<select id="course">
    <option value="Python">Python</option>
    <option value="JavaScript">JavaScript</option>
</select>

<p id="selectedCourse"></p>

JavaScript:

const course = document.getElementById("course");
const selectedCourse = document.getElementById("selectedCourse");

course.addEventListener("change", function() {
    selectedCourse.textContent = course.value;
});

Explanation:

  • Dropdown madhil value select keli jate.
  • Value change zalyavar change event trigger hoto.
  • Selected value paragraph madhye display hote.

6. Submit Event

submit event tevha trigger hoto jevha user form submit karto. Form submit button click karun kiwa keyboard madhil Enter key vaprun suddha hou shakto.

HTML:

<form id="myForm">
    <input type="text" id="username">
    <button type="submit">Submit</button>
</form>

JavaScript:

const form = document.getElementById("myForm");

form.addEventListener("submit", function(event) {
    event.preventDefault();

    console.log("Form Submitted!");
});

Explanation:

  • Form element select kele.
  • submit event listen kela.
  • event.preventDefault() default form submission thambavte.
  • Tyachyanantar custom JavaScript code execute hoto.
Important: preventDefault() vaparlyane browser chi default action thambte. Form data server la pathvaycha asel tar tyasathi vegli submission logic lihavi lagte.

7. Event Object

Event trigger zalyavar browser event handler function la event object provide karto. Ya object madhye event baddal information aste.

Example:

const button = document.getElementById("myButton");

button.addEventListener("click", function(event) {
    console.log(event.type);
    console.log(event.target);
});

Explanation:

  • event.type: Event cha type sangte.
  • event.target: Event jya element var trigger zala to element dete.
  • event.preventDefault(): Default browser action thambavte.

Output:

click
<button id="myButton">Click Me</button>
Remember: Event handler madhye event parameter cha nav badlu shakta. Udaharanarth e kiwa event.

9. Common Beginner Mistakes

Mistake 1: addEventListener() madhye brackets lavne

Function reference dyaycha asto. Function call karun tyacha result pass karu naye.

Mistake 2: Event name wrong lihine

addEventListener() madhye "onclick" aivaji "click" event name vapra.

Mistake 3: Form submit mule page reload hone

Default submission thambvaychi asel tar event.preventDefault() vapra.

Mistake 4: input ani change madhil difference na samajne

input event value type kartana trigger hoto. change event value change confirm zalyavar trigger hoto.

Mistake 5: Event object la function parameter na dene

Event details access karayche astil tar function madhye event parameter ghya.
