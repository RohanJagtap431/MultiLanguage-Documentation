Array Higher Order Methods

Ya lesson madhye callback functions, array higher order methods, some(), every() ani method chaining practical examples sah shikuya.

Beginner Level 35–40 Minutes

1. What are Higher Order Functions?

Higher Order Function mhanje asa function jo dusra function argument mhanun accept karto kiwa function return karto.

JavaScript madhil anek array methods Higher Order Functions aahet. Udaharanarth map(), filter() ani forEach().

Definition: A Higher Order Function is a function that accepts another function as an argument or returns a function.

Example:

function greet(name) {
    return "Hello " + name;
}

function processUser(callback) {
    console.log(callback("Rohan"));
}

processUser(greet);

Output:

Hello Rohan

Explanation:

  • greet ha ek normal function aahe.
  • processUser function callback accept karto.
  • greet function argument mhanun pass kela.
  • processUser madhye callback execute hoto.

2. Callback Function

Callback Function mhanje asa function jo dusrya function la argument mhanun pass kela jato.

Example:

function calculate(a, b, callback) {
    return callback(a, b);
}

function add(x, y) {
    return x + y;
}

console.log(calculate(10, 20, add));

Output:

30

Explanation:

  • calculate() function three parameters accept karto.
  • callback madhye add function pass kela.
  • callback(a, b) mule add function execute hoto.
  • Final result 30 milto.
Remember: Array Higher Order Methods madhye apan callback functions khup vela vaparto.

3. forEach() Method

forEach() cha use array madhil pratyek element var operation perform karnyasathi hoto.

Example:

const numbers = [10, 20, 30];

numbers.forEach(function(number) {
    console.log(number);
});

Output:

10
20
30

Important Points:

  • Pratyek element sathi callback execute hoto.
  • forEach() navin array return karat nahi.
  • Pratyek element var operation karnyasathi use hoto.
Important: forEach() cha return value undefined asto. Navin array pahije asel tar map() vapra.

4. map() Method

map() cha use existing array madhil pratyek element transform karun navin array tayar karnyasathi hoto.

Example:

const numbers = [1, 2, 3, 4];

const result = numbers.map(function(number) {
    return number * 2;
});

console.log(result);

Output:

[2, 4, 6, 8]

Important Points:

  • map() pratyek element var callback execute karto.
  • Callback madhil return value navin array madhye yete.
  • Original array change hot nahi, jar callback ne tyatil nested mutable data modify kele nahi tar.

5. filter() Method

filter() cha use condition satisfy karnare elements select karun navin array tayar karnyasathi hoto.

Example:

const numbers = [10, 15, 20, 25, 30];

const result = numbers.filter(function(number) {
    return number > 20;
});

console.log(result);

Output:

[25, 30]

Important Points:

  • filter() condition check karto.
  • Condition true aslele elements navin array madhye yetat.
  • Condition false aslele elements exclude hotat.

6. some() Method

some() cha use array madhil kamit kami ek element condition satisfy karto ka te check karnyasathi hoto.

Example:

const marks = [35, 45, 75, 80];

const result = marks.some(function(mark) {
    return mark >= 75;
});

console.log(result);

Output:

true

Explanation:

  • some() pratyek element condition sathi check karto.
  • Ek tari element condition satisfy karat asel tar true milte.
  • Ekahi element satisfy karat nasel tar false milte.
  • Result boolean value asto.
Remember: some() mhanje at least one element condition satisfy karto ka?

7. every() Method

every() cha use array madhil sarv elements condition satisfy kartat ka te check karnyasathi hoto.

Example:

const marks = [60, 70, 80, 90];

const result = marks.every(function(mark) {
    return mark >= 35;
});

console.log(result);

Output:

true

Explanation:

  • every() sarv elements check karto.
  • Sarv elements condition satisfy kartat tar true milte.
  • Ek jari element condition fail karat asel tar false milte.
  • Result boolean value asto.
Important: Empty array var some() false return karto, tar every() true return karto.

8. Method Chaining

Ekach statement madhye ekapeksha jast array methods ekamagun ek use karnyala Method Chaining mhantat.

Example:

const numbers = [10, 15, 20, 25, 30];

const result = numbers
    .filter(number => number >= 20)
    .map(number => number * 2);

console.log(result);

Output:

[40, 50, 60]

Step-by-step Explanation:

  1. Original array madhye 5 numbers aahet.
  2. filter() 20 kiwa tyapeksha jast numbers select karto.
  3. Result [20, 25, 30] milto.
  4. map() pratyek number la 2 ne multiply karto.
  5. Final result [40, 50, 60] milto.
Remember: Method Chaining mule multiple operations clean ani readable paddhatine lihita yetat.

9. Comparison of Higher Order Methods

Method Purpose Return Value
forEach() Each element var operation undefined
map() Elements transform karne New Array
filter() Condition nusar select karne New Array
some() At least one condition check Boolean
every() All elements condition check Boolean
find() First matching element Element / undefined
reduce() Single accumulated result Any Value

10. Practical Example – Student Marks

Higher Order Methods vaprun student marks filter, transform ani check karu.

JavaScript:

const marks = [35, 45, 60, 75, 90];

// Students who passed
const passed = marks.filter(mark => mark >= 35);

// Add 5 bonus marks
const bonusMarks = marks.map(mark => mark + 5);

// Check if any student scored 90
const hasTopper = marks.some(mark => mark >= 90);

// Check if all students passed
const allPassed = marks.every(mark => mark >= 35);

console.log(passed);
console.log(bonusMarks);
console.log(hasTopper);
console.log(allPassed);

Output:

[35, 45, 60, 75, 90]
[40, 50, 65, 80, 95]
true
true

11. Common Beginner Mistakes

Mistake 1: map() madhye return visarne

Callback madhye value return keli nahi tar navin array madhye undefined values yeu shaktat.

Mistake 2: forEach() cha result store karne

forEach() undefined return karto. Navin array sathi map() vapra.

Mistake 3: some() ani every() confuse karne

some() ek tari element check karto, every() sarv elements check karto.

Mistake 4: filter() madhye condition na dene

filter() callback madhun true kiwa false result milne avashyak aahe.

Mistake 5: Method Chaining cha order na samajne

Pratyek method cha result pudhchya method la milto. Mhanun order samjun code liha.
