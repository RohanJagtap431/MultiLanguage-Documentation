JavaScript Input and Output

User kadun data kasa ghyaycha ani program madhil result user la kasa dakhvaycha he JavaScript madhye examples sahit shikuya.

Beginner Level 30–35 Minutes

1. What is Input and Output?

Input mhanje user kadun program sathi data ghene. Output mhanje program cha result user la dakhavne.

Real-Life Example:

Samaj tu ek calculator vapartoy. Tu calculator madhye don numbers enter kartos, hi input aahe. Calculator tyancha addition result dakhavto, ha output aahe.

Input User data deto
→
Process JavaScript calculation karte
→
Output Result display hoto

Example:

let a = 10;
let b = 20;

let result = a + b;

console.log(result);

Output:

30

2. console.log()

console.log() cha use browser chya Developer Console madhye output display karnyasathi hoto. Debugging ani code testing sathi ha method khup upyogi aahe.

Syntax:

console.log(value);

Example:

let name = "Rohan";
let age = 20;

console.log(name);
console.log(age);
console.log("Hello JavaScript");

Output:

Rohan
20
Hello JavaScript

Console madhye Output kasa baghaycha?

  1. Browser madhye webpage open kar.
  2. Keyboard var F12 press kar.
  3. Console tab open kar.
  4. JavaScript cha output tithe disel.
Tip: JavaScript code madhil values check karnyasathi console.log() regular use kar.

3. alert()

alert() cha use browser madhye message popup display karnyasathi hoto.

Syntax:

alert("Message");

Example:

alert("Welcome to JavaScript!");

Output:

!

Welcome to JavaScript!

OK

Browser madhye asa popup disel.

Practical Example:

let name = "Rohan";

alert("Welcome " + name);
Important: alert() popup user ne OK click kareparyant browser madhil JavaScript execution thambavto. Mhanun tyacha use maryadit thev.

4. prompt()

prompt() cha use user kadun text input ghenyasathi hoto. Browser madhye ek popup open hoto ani user tyamadhye value enter karu shakto.

Syntax:

prompt("Enter your name");

Example:

let name = prompt("Enter your name");

console.log(name);

Working:

  1. prompt() user la input popup dakhavto.
  2. User tyache nav enter karto.
  3. Enter kiwa OK click karto.
  4. Entered value name variable madhye store hote.

Practical Example:

let name = prompt("What is your name?");

alert("Hello " + name);
Important: prompt() madhun milnari value String aste. User number enter kela tari value String svarupat milte. Cancel click kelyas null milte.

5. Number() for Numeric Input

prompt() madhun milnari value String aste. Mathematical calculation karnyasathi ti Number madhye convert karavi lagte.

Wrong Example:

let a = prompt("Enter first number");
let b = prompt("Enter second number");

console.log(a + b);

User ne 10 ani 20 enter kele tar + operator strings jodto.

Output:

1020

Correct Example:

let a = Number(prompt("Enter first number"));
let b = Number(prompt("Enter second number"));

let result = a + b;

console.log(result);

Output:

30
Tip: Number() vaprun String madhil numeric value Number madhye convert karta yete.

6. confirm()

confirm() cha use user kadun Yes kiwa No type confirmation ghenyasathi hoto.

Browser madhye OK ani Cancel ase don buttons aslela popup display hoto.

Syntax:

confirm("Are you sure?");

Example:

let answer = confirm("Do you want to continue?");

console.log(answer);

Output:

OK click   → true
Cancel     → false

Practical Example:

let answer = confirm("Are you sure?");

if (answer) {
    alert("You selected OK");
} else {
    alert("You selected Cancel");
}
Important: confirm() OK click kelyas true ani Cancel click kelyas false return karto.

7. document.getElementById()

document.getElementById() cha use HTML madhil specific id aslela element select karnyasathi hoto. Tyamule JavaScript madhun webpage var output display karta yeto.

HTML Code:

<h2 id="message">Old Message</h2>

JavaScript Code:

document.getElementById("message").innerText =
    "Hello Rohan!";

Output:

Hello Rohan!

Explanation:

  • document: Current webpage represent karto.
  • getElementById(): ID vaprun HTML element select karto.
  • innerText: Element madhil visible text change karto.

8. innerText and textContent

HTML element madhil text read kiwa change karnyasathi innerText ani textContent properties vaparta yetat.

innerText Example:

document.getElementById("message").innerText =
    "Welcome!";

innerText visible text sobat kam karto ani layout nusar hidden text ignore karu shakto.

textContent Example:

document.getElementById("message").textContent =
    "Hello JavaScript!";

textContent element madhil text content access karto. Hidden elements madhil text suddha include hou shakto.

Tip: Simple text display kiwa update karnyasathi innerText kiwa textContent vapra.

9. innerHTML

innerHTML cha use HTML element madhye HTML content add kiwa change karnyasathi hoto.

HTML Code:

<div id="result"></div>

JavaScript Code:

document.getElementById("result").innerHTML =
    "<h2>Hello Rohan!</h2>";

Output:

Hello Rohan!

Security Warning: User kadun direct milalela untrusted data innerHTML madhye taklyas XSS security risk nirman hou shakto. User input display karnyasathi textContent prefer kar.

10. document.write()

document.write() cha use webpage madhye direct content write karnyasathi hoto.

Example:

document.write("Hello JavaScript!");

Output:

Hello JavaScript!

Important: Page load zalyanantar document.write() vaparlyas existing webpage overwrite hou shakto. Modern web development madhye DOM methods prefer kara.

11. Practical Example - User Greeting

Ata prompt() vaprun user kadun name gheu ani webpage var greeting display karu.

HTML Code:

<h2 id="greeting">Welcome!</h2>

<button onclick="showGreeting()">
    Enter Name
</button>

JavaScript Code:

function showGreeting() {

    let name = prompt("Enter your name");

    if (name !== null) {

        document.getElementById("greeting").textContent =
            "Hello " + name + "!";

    }

}

Explanation:

  • showGreeting(): Greeting function tayar karto.
  • prompt(): User kadun name gheto.
  • name !== null: User ne Cancel kele nahi he check karto.
  • textContent: Webpage var greeting display karto.

Output:

Welcome!

12. Input and Output Methods Comparison

confirm() OK kiwa Cancel confirmation gheto.
innerText Visible text read kiwa update karto.
textContent Element madhil text read kiwa update karto.

13. Common Beginner Mistakes

Mistake 1: prompt() madhil value direct addition sathi vaprane

prompt() String return karto. Number() vaprun numeric value convert kara.

Mistake 2: getElementById() madhye chukiche ID dene

HTML madhil ID ani JavaScript madhil ID same asne avashyak aahe.

Mistake 3: console.log() cha output webpage var shodhne

console.log() cha output browser Developer Console madhye disato.

Mistake 4: prompt() madhil Cancel ignore karne

Cancel click kelyas null milte. Garaj aslyas null check kara.

Mistake 5: Untrusted input innerHTML madhye takne

User input display karnyasathi textContent vapra.

14. Quick Revision

  • Input mhanje user kadun data ghene.
  • Output mhanje result display karne.
  • console.log() console madhye output dakhavto.
  • alert() message popup dakhavto.
  • prompt() user kadun String input gheto.
  • confirm() true kiwa false return karto.
  • Number() String value la Number madhye convert karto.
  • getElementById() HTML element select karto.
  • innerText ani textContent text update kartat.
  • innerHTML HTML content update karto.
  • Untrusted input sathi textContent prefer kara.
