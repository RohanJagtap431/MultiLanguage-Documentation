JavaScript Objects

Object cha use related information key-value pairs madhye store karnyasathi hoto. Ya lesson madhye object creation, properties, access ani modification shikuya.

Beginner Level 35–45 Minutes

1. What is an Object?

JavaScript madhye Object ha data structure aahe. Tyat information key-value pairs chya format madhye store hote.

Pratyek key la property name mhantat ani tyachyashi sambandhit data la value mhantat.

Example:

let student = {
    name: "Rohan",
    age: 20,
    course: "BSc Computer Science"
};

console.log(student);

Output:

{
  name: "Rohan",
  age: 20,
  course: "BSc Computer Science"
}
Simple Definition: Object mhanje related data key-value pairs madhye store karanari structure.

2. Object Properties

Object madhil key-value pair la property mhantat. Ekach object madhye anek properties asu shaktat.

Example:

let student = {
    name: "Rohan",
    age: 20,
    city: "Kolhapur",
    isActive: true
};

Properties:

Key Value
name "Rohan"
age 20
city "Kolhapur"
isActive true
Remember: Object madhye String, Number, Boolean, Array ani dusre Objects suddha store karta yetat.

3. Creating an Object

Object create karnyasathi curly brackets {} vapartat.

Example:

let car = {
    brand: "Tata",
    model: "Nexon",
    year: 2025
};

console.log(car);

Output:

{
  brand: "Tata",
  model: "Nexon",
  year: 2025
}

Ithe car ha object aahe ani brand, model, year ya tyachya properties aahet.

4. Accessing Object Properties

Object madhil value access karnyasathi dot notation kiwa bracket notation vapartat.

1. Dot Notation

let student = {
    name: "Rohan",
    age: 20
};

console.log(student.name);
console.log(student.age);

Output:

Rohan
20

2. Bracket Notation

let student = {
    name: "Rohan",
    age: 20
};

console.log(student["name"]);
console.log(student["age"]);

Output:

Rohan
20
Difference: Dot notation madhye property name direct lihitat. Bracket notation madhye property name String madhye lihitat.

5. Adding New Properties

Existing object madhye new property add karta yete.

Example:

let student = {
    name: "Rohan",
    age: 20
};

student.city = "Kolhapur";
student.course = "BSc CS";

console.log(student);

Output:

{
  name: "Rohan",
  age: 20,
  city: "Kolhapur",
  course: "BSc CS"
}

6. Updating Object Properties

Existing property chi value navin value assign karun update karta yete.

Example:

let student = {
    name: "Rohan",
    age: 20
};

student.age = 21;

console.log(student.age);

Output:

21

7. Deleting Object Properties

Object madhil property remove karnyasathi delete operator vapartat.

Example:

let student = {
    name: "Rohan",
    age: 20,
    city: "Kolhapur"
};

delete student.city;

console.log(student);

Output:

{
  name: "Rohan",
  age: 20
}

8. Nested Objects

Eka object madhye dusra object store kela asel tar tyala Nested Object mhantat.

Example:

let student = {
    name: "Rohan",

    address: {
        city: "Kolhapur",
        state: "Maharashtra"
    }
};

console.log(student.address.city);
console.log(student.address.state);

Output:

Kolhapur
Maharashtra
Remember: Nested object access karnyasathi multiple dot notation vaparta yete.

9. Objects with Arrays

Object madhye Array store karta yete. Ekach object madhye vegveglya type cha data asu shakto.

Example:

let student = {
    name: "Rohan",
    skills: ["Python", "Django", "JavaScript"]
};

console.log(student.skills);
console.log(student.skills[0]);
console.log(student.skills[1]);

Output:

["Python", "Django", "JavaScript"]
Python
Django

10. Object Methods

Object madhil property chi value function asel tar tya function la Method mhantat.

Example:

let student = {
    name: "Rohan",

    greet: function() {
        return "Hello " + this.name;
    }
};

console.log(student.greet());

Output:

Hello Rohan

Ithe greet hi method aahe ani this.name current object madhil name property access karte.

11. Object.keys(), values() and entries()

Object.keys()

Object madhil sarva property names chi Array return karte. 

let student = {
    name: "Rohan",
    age: 20,
    city: "Kolhapur"
};

console.log(Object.keys(student));

Output:

["name", "age", "city"]

Object.values()

Object madhil sarva property values chi Array return karte. 

let student = {
    name: "Rohan",
    age: 20
};

console.log(Object.values(student));

Output:

["Rohan", 20]

Object.entries()

Object madhil key-value pairs chi Array return karte. 

let student = {
    name: "Rohan",
    age: 20
};

console.log(Object.entries(student));

Output:

[["name", "Rohan"], ["age", 20]]

12. Checking Object Properties

Object madhye specific property aahe ka te check karnyasathi in operator vaparta yeto.

Example:

let student = {
    name: "Rohan",
    age: 20
};

console.log("name" in student);
console.log("city" in student);

Output:

true
false

13. Object vs Array

Object Array
Key-value pairs madhye data store karto. Ordered list madhye data store karto.
Properties access karnyasathi keys vapartat. Elements access karnyasathi index vapartat.
Example: student.name Example: numbers[0]
Curly brackets {} vapartat. Square brackets [] vapartat.

14. Common Beginner Mistakes

Mistake 1: Property name chukicha lihine

Object madhye je property name aahe tech access kartana vapra.

Mistake 2: Dot notation madhye quotes vaprane

student.name ase lihayche. student."name" ase nahi.

Mistake 3: Bracket notation madhye quotes visarne

student["name"] ase lihayche.

Mistake 4: Object ani JSON same samajne

JavaScript Object ani JSON ya related pan veglya formats aahet.
