Fetch API

Ya lesson madhye server sobat communication karne, GET ani POST requests pathavne ani API madhun data milavne shikuya.

Beginner Level 40–45 Minutes

1. What is Fetch API?

Fetch API he JavaScript madhil built-in feature aahe. Tyacha use server kadun data milavnyasathi ani server la data pathavnyasathi hoto.

Definition: Fetch API is used to make HTTP requests and communicate with servers.

Real Life Example:

Samja aplya website var student details display karayche aahet.

  • JavaScript server la request pathavto.
  • Server student details process karto.
  • Server response pathavto.
  • JavaScript response madhil data website var display karto.

Fetch API Uses:

  • Server kadun data milavane.
  • Server la new data pathavane.
  • API sobat communication karane.
  • Dynamic website tayar karane.

2. What is an API?

API mhanje Application Programming Interface. API mule don software applications ekmekansobat communicate karu shaktat.

Example:

Aplya Django backend madhye student data aahe. JavaScript frontend API request pathavun ha data milavu shakto.

Backend Developer Connection: Django REST Framework vaprun apan APIs tayar karto. JavaScript Fetch API vaprun tya APIs sobat communicate karu shakto.

3. fetch() Syntax

fetch() function cha use HTTP request pathavnyasathi hoto.

Syntax:

fetch("API_URL")
    .then(response => response.json())
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.log(error);
    });

Important Points:

  • fetch() URL accept karto.
  • fetch() Promise return karto.
  • response.json() response body JSON madhye parse karto.
  • then() madhye received data handle karto.
  • catch() network kiwa itar rejected errors handle karto.

4. GET Request

GET request cha use server kadun data milavnyasathi hoto. fetch() madhye default method GET aste.

Example:

async function getUsers() {
    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users"
        );

        if (!response.ok) {
            throw new Error("Failed to fetch users");
        }

        const data = await response.json();

        console.log(data);

    } catch (error) {
        console.log(error.message);
    }
}

getUsers();

Output:

[
  {
    id: 1,
    name: "Leanne Graham",
    email: "Sincere@april.biz"
  },
  ...
]

Ya example madhye server kadun users chi list milte. Console madhye complete response array display hoto.

5. POST Request

POST request cha use server la new data pathavnyasathi hoto. Udaharanarth, new student register karane.

Example:

async function createUser() {
    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users",
            {
                method: "POST",

                headers: {
                    "Content-Type": "application/json"
                },

                body: JSON.stringify({
                    name: "Rohan",
                    email: "rohan@example.com"
                })
            }
        );

        if (!response.ok) {
            throw new Error("Failed to create user");
        }

        const data = await response.json();

        console.log(data);

    } catch (error) {
        console.log(error.message);
    }
}

createUser();

Explanation:

  • method: "POST" request method set karte.
  • headers madhye content type specify karto.
  • JSON.stringify() JavaScript object la JSON string madhye convert karto.
  • body madhye server la pathvaycha data asto.
  • response.json() server cha response parse karto.
Important: JSONPlaceholder hi testing API aahe. POST request cha response milto, pan data permanently save hot nahi.

7. response.json()

response.json() method response body madhil JSON data JavaScript value madhye convert karto.

Example:

async function getData() {
    const response = await fetch(
        "https://jsonplaceholder.typicode.com/users/1"
    );

    const data = await response.json();

    console.log(data.name);
}

getData();

Output:

Leanne Graham
Remember: response.json() suddha Promise return karto. Mhanun async function madhye tyachyasobat await vapartat.

8. HTTP Status Codes

Server request process zalyavar HTTP status code pathavto. Tyavarun request cha result samajto.

Status Code Meaning
200 OK – Request successful.
201 Created – New resource created.
400 Bad Request – Invalid request.
401 Unauthorized – Authentication required.
403 Forbidden – Access not allowed.
404 Not Found – Resource not found.
500 Internal Server Error.

Check Status Example:

const response = await fetch("/api/users/");

console.log(response.status);
console.log(response.ok);

response.status status code return karto. response.ok status 200 te 299 asel tar true return karto.

9. Display API Data in HTML

API madhun milalela data JavaScript vaprun HTML madhye display karu shakto.

HTML:

<h2>User Details</h2>
<div id="user-details"></div>

JavaScript:

async function showUser() {
    const container = document.getElementById("user-details");

    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users/1"
        );

        if (!response.ok) {
            throw new Error("Unable to load user");
        }

        const user = await response.json();

        container.textContent =
            "Name: " + user.name + " | Email: " + user.email;

    } catch (error) {
        container.textContent = error.message;
    }
}

showUser();

Output:

User Details

Name: Leanne Graham | Email: Sincere@april.biz

Security Tip: API madhun yenara user-controlled data display kartana textContent vapra. Untrusted data direct innerHTML madhye takne avoid kara.

10. Error Handling in Fetch API

Fetch API madhye network error ani HTTP error vegvegale handle karave lagtat.

Example:

async function loadData() {
    try {
        const response = await fetch("/api/students/");

        if (!response.ok) {
            throw new Error(
                "HTTP Error: " + response.status
            );
        }

        const data = await response.json();

        console.log(data);

    } catch (error) {
        console.log("Error:", error.message);
    }
}

loadData();

Errors:

  • Network connection fail zalyas fetch reject hou shakto.
  • 404 kiwa 500 status sathi response.ok check karava lagto.
  • Invalid JSON asel tar response.json() reject hou shakto.
  • try...catch vaprun errors handle karta yetat.

11. Fetch API with Django REST Framework

Django REST Framework madhye apan API endpoint tayar karto. JavaScript Fetch API vaprun tya endpoint kadun data milavto.

JavaScript Example:

async function getStudents() {
    try {
        const response = await fetch("/api/students/");

        if (!response.ok) {
            throw new Error("Unable to load students");
        }

        const students = await response.json();

        console.log(students);

    } catch (error) {
        console.log(error.message);
    }
}

getStudents();

Working Flow:

  1. JavaScript Django API la request pathavto.
  2. Django request receive karto.
  3. Backend database madhun student data gheto.
  4. Django JSON response return karto.
  5. JavaScript response madhil data use karto.
Career Connection: Python/Django Backend Developer mhanun REST API create karne ani frontend kadun yenarya requests samjun ghene mahatvache aahe.

12. Common Beginner Mistakes

Mistake 1: response.json() visarne

JSON response parse kelyashivay tyatil fields direct access karta yet nahit.

Mistake 2: await na vaprane

Promise settle honyapurvi data access karnyacha prayatna karu naka.

Mistake 3: response.ok check na karne

HTTP error status sathi response.ok check kara.

Mistake 4: POST madhye JSON.stringify() visarne

JSON body pathavatana JavaScript object la JSON string madhye convert kara.

Mistake 5: Error handling na karne

Network ani HTTP errors handle karnyasathi try...catch ani response.ok vapra.
