JavaScript Conditional Statements

JavaScript madhye condition check karun program la vegvegale decisions kase ghyayla lavayche he shikuya. if, else, else if ani switch statements samjun gheuya.

Beginner Level 35–40 Minutes

1. What are Conditional Statements?

Conditional Statements cha use condition check karun tyapramane specific code execute karnyasathi hoto.

Real life madhye suddha apan conditions nusar decisions gheto. Udaharanarth, exam madhye 35 kiwa tyapeksha jast marks milale tar student pass hoto.

Real-Life Example:

Student Marks
↓
Marks >= 35 ?
YES Pass
NO Fail
Simple Definition: Condition true kiwa false aahe he check karun yogya code execute karnyasathi conditional statements vapartat.

2. if Statement

if statement cha use condition true asel tevha specific code execute karnyasathi hoto.

Syntax:

if (condition) {
    // Condition true aslyas ha code execute hoil
}

Example:

let age = 20;

if (age >= 18) {
    console.log("You are eligible");
}

Output:

You are eligible

Explanation:

  • if: Condition check karto.
  • age >= 18: Age 18 kiwa tyapeksha jast aahe ka te check karto.
  • { }: Condition true aslyas execute honara code ya block madhye asto.
  • console.log(): Message console madhye display karto.
Important: if madhil condition true asel tarch tyatil code execute hoto. Condition false asel tar block skip hoto.

3. if...else Statement

if...else cha use don possible situations madhun ek nivadnyasathi hoto.

Condition true asel tar if block execute hoto. Condition false asel tar else block execute hoto.

Syntax:

if (condition) {
    // Condition true aslyas
} else {
    // Condition false aslyas
}

Example:

let marks = 30;

if (marks >= 35) {
    console.log("Pass");
} else {
    console.log("Fail");
}

Output:

Fail

Another Example:

let number = 10;

if (number % 2 === 0) {
    console.log("Even Number");
} else {
    console.log("Odd Number");
}

Output:

Even Number
Tip: Even kiwa Odd number, Pass kiwa Fail ani Login success kiwa failure asha situations madhye if...else upyogi aahe.

4. if...else if...else Statement

Jevha anek conditions check karaychya astat tevha if...else if...else vapartat.

JavaScript conditions ek-ek karun check karte. Ji pahili condition true hote ticha block execute hoto. Nantarche blocks skip hotat.

Syntax:

if (condition1) {
    // First condition true

} else if (condition2) {
    // Second condition true

} else if (condition3) {
    // Third condition true

} else {
    // Kontihi condition true naslyas
}

Example:

let marks = 75;

if (marks >= 90) {
    console.log("Grade A");

} else if (marks >= 75) {
    console.log("Grade B");

} else if (marks >= 50) {
    console.log("Grade C");

} else if (marks >= 35) {
    console.log("Grade D");

} else {
    console.log("Fail");
}

Output:

Grade B

Explanation:

  • Marks 90 aahet ka? Nahi.
  • Marks 75 aahet ka kiwa tyapeksha jast? Ho.
  • Tyamule Grade B display hoto.
  • Urlelya conditions check hot nahit.
Important: Conditions yogya order madhye lihine mahatvache aahe. Sarvat mothi marks condition aadhi check kara.

5. Nested if Statement

Ek if statement chya aat dusra if statement lihilyas tyala Nested if mhantat.

Ek condition true zalyanantar tyachya aat ajun ek condition check karaychi asel tar nested if vapartat.

Example:

let age = 20;
let hasID = true;

if (age >= 18) {

    if (hasID === true) {
        console.log("Entry Allowed");
    }

} else {
    console.log("Entry Not Allowed");
}

Output:

Entry Allowed

Explanation:

  • First age 18 kiwa tyapeksha jast aahe ka te check hote.
  • Age condition true aslyamule inner if execute hoto.
  • hasID true aslyamule Entry Allowed display hote.
Tip: Nested if cha use multiple dependent conditions check karnyasathi hou shakto. Pan unnecessary nesting tal.

6. switch Statement

switch statement cha use ekach expression chya vegveglya possible values check karnyasathi hoto.

Anek fixed values check karaychya astil tar switch statement code adhik readable banvu shakto.

Syntax:

switch (expression) {

    case value1:
        // Code
        break;

    case value2:
        // Code
        break;

    default:
        // Kontahi case match naslyas

}

Example:

let day = 3;

switch (day) {

    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    case 3:
        console.log("Wednesday");
        break;

    case 4:
        console.log("Thursday");
        break;

    default:
        console.log("Invalid Day");

}

Output:

Wednesday

switch madhil important keywords:

  • switch: Expression check karto.
  • case: Possible value define karto.
  • break: Matching case execute zalyanantar switch madhun baher padto.
  • default: Kontahi case match naslyas execute hoto.
Important: break nasel tar pudhil cases suddha execute hou shaktat. Yala fall-through mhantat.

7. Ternary Operator

Ternary operator ha simple if...else condition short form madhye lihinyasathi vapartat.

Syntax:

condition ? valueIfTrue : valueIfFalse;

Example:

let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);

Output:

Adult

Explanation:

  • age >= 18 condition check hote.
  • Condition true asel tar "Adult" milte.
  • Condition false asel tar "Minor" milte.
  • Final value result madhye store hote.
Tip: Simple condition sathi ternary vapra. Complex decision making sathi if...else adhik readable aste.

8. Truthy and Falsy Values

JavaScript madhye condition check kartana kahi values true sarkhya ani kahi false sarkhya treat kelya jatat. Yanna Truthy ani Falsy values mhantat.

Truthy Values:

Boolean madhye convert kelyavar true denarya values mhanje Truthy values. 

console.log(Boolean("Hello"));
console.log(Boolean(10));
console.log(Boolean("0"));
console.log(Boolean([]));
console.log(Boolean({}));

Output:

true
true
true
true
true

Falsy Values:

Boolean madhye convert kelyavar false denarya values mhanje Falsy values. 

console.log(Boolean(false));
console.log(Boolean(0));
console.log(Boolean(""));
console.log(Boolean(null));
console.log(Boolean(undefined));
console.log(Boolean(NaN));

Output:

false
false
false
false
false
false
Important: Empty array [] ani empty object {} he JavaScript madhye Truthy astat. Empty String "" hi Falsy aste.

9. Difference Between if...else and switch

if...else switch
Conditions check karnyasathi. Expression chya fixed values check karnyasathi.
Comparison operators vapru shakto. case values sobat strict equality comparison karto.
Range check karu shakto. Fixed cases sathi upyogi.
Complex conditions sathi yogya. Menu kiwa fixed options sathi yogya.
Learning Tip: Marks range, age ani eligibility sathi if...else vapra. Weekday, menu options ani fixed choices sathi switch vapra.

11. Common Beginner Mistakes

Mistake 1: if condition madhye = vaprane

= value assign karto. Comparison sathi === kiwa yogya comparison operator vapra.

Mistake 2: else if conditions cha order chukavne

Range conditions madhye mothya value chi condition aadhi check kara.

Mistake 3: switch madhye break visarne

break naslyas pudhil cases execute hou shaktat.

Mistake 4: switch madhye default visarne

Unexpected value alyas default case madhye message display karta yeto.

Mistake 5: Empty values nehmi Falsy astat ase samajne

[] ani {} ya empty values suddha Truthy astat.

Mistake 6: Curly brackets chukiche vaprane

if ani else blocks madhil { } yogya thikani close kara.
