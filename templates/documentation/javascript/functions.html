JavaScript Functions

Function cha use code reusable banavnyasathi hoto. Ek function tayar karun tyala garjenusar anek vela call karta yete.

Beginner Level 35–40 Minutes

1. What is a Function?

Function ha code cha ek block asto jo specific task perform karnyasathi tayar kela jato.

Function lihilyanantar to lagech execute hot nahi. Function execute karnyasathi tyala call karave lagte.

Without Function:

console.log("Hello Rohan");
console.log("Hello Rohan");
console.log("Hello Rohan");

With Function:

function greet() {
    console.log("Hello Rohan");
}

greet();
greet();
greet();

Output:

Hello Rohan
Hello Rohan
Hello Rohan
Simple Definition: Specific task perform karanara reusable code block mhanje Function.

2. Function Declaration

function keyword vaprun function tayar karnyachya paddhatila Function Declaration mhantat.

Syntax:

function functionName() {
    // Code to execute
}

Example:

function welcome() {
    console.log("Welcome to JavaScript");
}

welcome();

Output:

Welcome to JavaScript

Explanation:

  • function: Function declare karnyasathi keyword.
  • welcome: Function che name.
  • (): Parameters lihinyasathi vapartat.
  • { }: Function cha code block.
  • welcome(): Function call karto.
Important: Function declaration ani function call ya don veglya goshti aahet. Function call kelyavarach function execute hoto.

3. Function Parameters and Arguments

Function la external values dyaychya astil tar parameters ani arguments vapartat.

Parameters:

Function declare kartana parentheses madhye lihilelya variable names na Parameters mhantat.

Arguments:

Function call kartana pass kelelya actual values na Arguments mhantat.

Example:

function greet(name) {
    console.log("Hello " + name);
}

greet("Rohan");
greet("Amit");

Output:

Hello Rohan
Hello Amit

Explanation:

  • name ha parameter aahe.
  • "Rohan" hi pahili argument aahe.
  • "Amit" hi dusri argument aahe.
  • Pratyek call madhye vegli value pass karta yete.

Multiple Parameters Example:

function add(a, b) {
    console.log(a + b);
}

add(10, 20);
add(5, 15);

Output:

30
20
Tip: Function parameters mule ekach function vegveglya input values sobat use karta yeto.

4. return Statement

return statement cha use function madhun result parat pathavnyasathi hoto.

console.log() fakt output display karto, tar return function madhun value parat deto.

Example:

function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);

Output:

30

Explanation:

  • add() function don values accept karto.
  • a + b calculate hote.
  • return mule result function chya baher pathavla jato.
  • To result variable madhye store hoto.
  • console.log() result display karto.

Another Example:

function calculateSquare(number) {
    return number * number;
}

let answer = calculateSquare(5);

console.log(answer);

Output:

25
Important: return execute zalyanantar function madhil pudhil statements execute hot nahit.

5. Default Parameters

Function call kartana argument dili nahi tar default value use karnyasathi Default Parameters vapartat.

Example:

function greet(name = "Guest") {
    console.log("Hello " + name);
}

greet("Rohan");
greet();

Output:

Hello Rohan
Hello Guest

Explanation:

  • name chi default value "Guest" aahe.
  • Pahilya call madhye "Rohan" pass kele.
  • Dusrya call madhye argument dili nahi.
  • Mhanun dusrya call madhye "Guest" use hoto.

6. Function Expression

Function la variable madhye store karnyachya paddhatila Function Expression mhantat.

Example:

const greet = function() {
    console.log("Hello JavaScript");
};

greet();

Output:

Hello JavaScript

Explanation:

  • const vaprun greet variable tayar kela.
  • Function expression variable madhye store kele.
  • greet() vaprun function call kela.
Important: Function expression la variable declare honyapurvi call karta yet nahi. Function declaration madhye hoisting mule vegle behavior aste.

7. Anonymous Function

Jya function la swatach nav naste tyala Anonymous Function mhantat.

Example:

const message = function() {
    console.log("Learning JavaScript");
};

message();

Output:

Learning JavaScript

Ya example madhye function la direct name nahi. To message variable madhye store kela aahe.

Note: Anonymous functions callbacks ani event handling madhye suddha vapartat. Tyabaddal pudhil topics madhye shiku.

8. Function Scope

Scope mhanje variable program madhye kuthe access karta yeto he tharavnara niyam.

Global Scope:

Function chya baher declare kelela variable global scope madhye asto. To function chya aat access karta yeto. 

let name = "Rohan";

function showName() {
    console.log(name);
}

showName();

Output:

Rohan

Local Scope:

Function chya aat declare kelela local variable fakt tya function madhye access karta yeto. 

function showAge() {
    let age = 20;
    console.log(age);
}

showAge();

Output:

20
Important: showAge() chya baher age variable access karta yet nahi. Local variables cha scope tyanchya function purta asto.

9. Function vs Function Expression

Function Declaration Function Expression
function keyword vaprun declare karto. Function variable madhye store karto.
Function la nav aste. Function anonymous asu shakto.
Declaration hoisting support karte. Variable declaration chya niyamanusar behavior aste.
Function name ne call karto. Variable name ne call karto.

10. Practical Example - Student Result Function

Ata marks accept karun Pass kiwa Fail result return karanara function tayar karu.

JavaScript Code:

function checkResult(marks) {

    if (marks >= 35) {
        return "Pass";
    } else {
        return "Fail";
    }

}

let result1 = checkResult(75);
let result2 = checkResult(25);

console.log(result1);
console.log(result2);

Output:

Pass
Fail

Explanation:

  • checkResult() function marks accept karto.
  • if...else marks check karte.
  • 35 kiwa tyapeksha jast marks aslyas Pass return hoto.
  • 35 peksha kami marks aslyas Fail return hoto.
  • Donhi results vegveglya variables madhye store hotat.
Backend Relevance: Django madhye data process karne, calculations karne, validation karne ani reusable business logic lihinyasathi functions upyogi padtat.

11. Common Beginner Mistakes

Mistake 1: Function call karayla visarne

Function declare kelyane to automatic execute hot nahi. FunctionName() vaprun call kara.

Mistake 2: Parameter ani argument confuse karne

Function declaration madhil variable parameter asto. Function call madhil actual value argument aste.

Mistake 3: return ani console.log confuse karne

console.log output display karto, tar return value function madhun parat pathavto.

Mistake 4: return nantar code lihine

return execute zalyanantar tyach function madhil pudhil statements execute hot nahit.

Mistake 5: Local variable baher access karne

Function chya aat declare kelela local variable function chya baher access karta yet nahi.
