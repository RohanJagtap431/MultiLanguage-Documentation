JavaScript Syntax

JavaScript code lihinyache basic rules, statements, comments, case sensitivity ani code blocks kase lihayche he ya lesson madhye shikuya.

Beginner Level 30–35 Minutes

1. What is JavaScript Syntax?

Syntax mhanje programming language madhye code lihinyache rules.

Jase English language madhye sentence lihinyache kahi rules astat, tasech JavaScript madhye code lihinyache rules astat.

JavaScript code lihitana proper keywords, brackets, quotes ani operators vaprane avashyak aste.

Simple Definition: JavaScript Syntax mhanje JavaScript code lihinyasathi follow karave laganare rules.
Example: 
console.log("Hello World");
Ya code madhye console.log() he message display karnyasathi vaprale aahe.

2. JavaScript Statements

JavaScript statement mhanje browser kiwa JavaScript engine la dileli ek instruction.

Ek program anek statements pasun tayar hoto. Pratyek statement ek specific task perform karte.

Example:

let name = "Rohan";
let age = 20;

console.log(name);
console.log(age);

Explanation:

  • let name = "Rohan"; Name variable madhye Rohan value store keli.
  • let age = 20; Age variable madhye 20 value store keli.
  • console.log(name); Name chi value console madhye display keli.
  • console.log(age); Age chi value console madhye display keli.

Output:

Rohan
20
Tip: JavaScript madhye ek statement ekach line madhye lihine compulsory nahi. Pan suruvatila pratyek statement veglya line madhye lihinyachi savay thev.

3. Semicolon ( ; )

JavaScript madhye semicolon (;) statement cha end dakhavnyasathi vaparla jato.

Example with Semicolon:

let name = "Rohan";
let city = "Kolhapur";

console.log(name);
console.log(city);

Example without Semicolon:

let name = "Rohan"
let city = "Kolhapur"

console.log(name)
console.log(city)

JavaScript madhye anek statements semicolon shivay suddha chalu shaktat. JavaScript Automatic Semicolon Insertion (ASI) vaprun kahi thikani semicolon automatically insert karte.

Important: Suruvatila pratyek statement nantar semicolon (;) vaprane changli savay aahe. Pan pratyek situation madhye semicolon optional aahe ase samju naye.

4. JavaScript Comments

Comments mhanje code madhye lihilelya notes. Comments cha use code samjavnyasathi hoto.

JavaScript comments execute karat nahi. Mhanje comments madhil text program cha output badalat nahi.

JavaScript madhye 2 types che comments astat:

A. Single-line Comment

Single-line comment lihinyasathi double slash (//) vapartat. 

// This is a single-line comment

console.log("Hello Rohan");

B. Multi-line Comment

Multiple lines madhye comment lihinyasathi /* ani */ vapartat. 

/*
This is a
multi-line comment
*/

console.log("Learning JavaScript");

Output:

Hello Rohan
Learning JavaScript
Tip: Code madhye important logic samjavnyasathi comments vapra. Pratyek line la unnecessary comment lihinyachi garaj nahi.

5. Case Sensitivity

JavaScript hi case-sensitive language aahe. Mhanje capital letters ani small letters yanna vegvegale samajle jate.

Example:

let name = "Rohan";

console.log(name);

Varil code madhye name variable tayar kela aahe. Tyamule console.log(name) barobar aahe.

Wrong Example:

let name = "Rohan";

console.log(Name);
Why Error? name ani Name hi don vegvegli nave aahet. Name navacha variable create kelela naslyamule ReferenceError yeu shakto.

More Examples:

Code Same or Different?
name / Name Different
age / Age Different
city / City Different

6. JavaScript Identifiers

Identifier mhanje JavaScript madhye variable, function kiwa itar element la dilele name.

Udaharanarth, name, age, total ani studentName hi identifiers chi examples aahet.

Identifier lihinyache Rules:

  • Identifier madhye letters vaparta yetat.
  • Numbers vaparta yetat, pan first character number nasava.
  • Underscore (_) ani dollar sign ($) vaparta yetat.
  • Spaces vaparta yet nahit.
  • JavaScript reserved keywords identifier mhanun vaparta yet nahit.
  • Identifiers case-sensitive astat.

Valid Identifiers:

let name = "Rohan";
let studentAge = 20;
let total_marks = 450;
let $price = 100;
let _count = 5;

Invalid Identifiers:

// Invalid examples

let 1name = "Rohan";
let student name = "Rohan";
let let = 10;
Important: Varil invalid examples code madhye run karu naye. Tyamule syntax errors yeu shaktat.

7. Strings and Quotes

JavaScript madhye text value la String mhantat. String lihinyasathi single quotes (' '), double quotes (" ") kiwa backticks (` `) vaparta yetat.

A. Single Quotes

let name = 'Rohan';

console.log(name);

B. Double Quotes

let city = "Kolhapur";

console.log(city);

C. Backticks

let name = "Rohan";
let age = 20;

console.log(`My name is ${name}`);
console.log(`My age is ${age}`);

Output:

My name is Rohan
My age is 20

Backticks madhye ${ } vaprun variable chi value string madhye insert karta yete. Ya feature la Template Literal mhantat.

Tip: Backticks cha use pudhe dynamic messages, API data ani HTML content tayar kartana suddha hoil.

8. JavaScript Code Blocks

Curly brackets { } madhye lihilelya statements chya group la code block mhantat.

Code blocks cha use functions, conditions ani loops madhye hoto.

Example:

if (true) {
    console.log("Condition is true");
}

Explanation:

  • if: Condition check karte.
  • (true): Condition true aahe.
  • { }: Code block chi suruvat ani shevat dakhavtat.
  • console.log(): Message display karte.

Output:

Condition is true

9. JavaScript Indentation and Spacing

Indentation mhanje code lihitana spaces vaprun statements vyavasthit lihine.

Indentation mule code vachayla ani samjayla sopa hoto. JavaScript madhye indentation compulsory nasle tari clean code sathi ti important aahe.

Without Proper Indentation:

function greet(){
let name="Rohan";
if(name){
console.log("Hello "+name);
}
}

With Proper Indentation:

function greet() {
    let name = "Rohan";

    if (name) {
        console.log("Hello " + name);
    }
}
Tip: VS Code madhye Shift + Alt + F shortcut vaprun code format karta yeto.

10. Complete Practical Example

Ata apan HTML, CSS ani JavaScript ekatra vaprun ek simple greeting card tayar karu.

Step 1: HTML Code

<div class="card">
    <h2 id="heading">Hello!</h2>

    <p id="message">Welcome to my page.</p>

    <button onclick="showMessage()">
        Click Me
    </button>
</div>

Step 2: CSS Code

.card {
    max-width: 350px;
    padding: 25px;
    margin: 20px auto;
    text-align: center;
    background: #f8fafc;

.card button {
    padding: 10px 18px;
    background: #ca8a04;

Step 3: JavaScript Code

function showMessage() {
    document.getElementById("heading").innerText =
        "Welcome Rohan!";

    document.getElementById("message").innerText =
        "You are learning JavaScript.";
}

Explanation:

  • function showMessage(): showMessage navacha function tayar karto.
  • getElementById(): HTML madhil id vaprun element select karto.
  • innerText: Element madhil text change karto.
  • onclick: Button click zalyavar function call karto.
Backend Connection: Pudhe JavaScript madhil Fetch API vaprun Django backend kadun data gheta yeil. Tyasathi HTML madhil elements select karne ani JavaScript syntax samajne upayogi tharel.

11. Common Beginner Mistakes

Mistake 1: Variable name madhye capital-small letters chukavne

name ani Name vegvegale identifiers aahet.

Mistake 2: String la quotes na dene

Text value lihitana single quotes, double quotes kiwa backticks vapra.

Mistake 3: Brackets close karayla visarne

Opening bracket sobat yogya closing bracket vaprane avashyak aahe.

Mistake 4: Code indentation ignore karne

Code neat format madhye lihilyas errors shodhne sope hote.
