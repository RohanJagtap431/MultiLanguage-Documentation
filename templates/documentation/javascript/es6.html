JavaScript ES6 Features

ES6 madhye introduce zalele important JavaScript features ani tyanchya practical uses ya lesson madhye shikuya.

Beginner Level 40–45 Minutes

1. What is ES6?

ES6 che full form ECMAScript 2015 aahe. Hi JavaScript chi ek important version update aahe.

ES6 madhye code lihinyasathi anek nave features introduce kele gele. Ya features mule code readable ani maintainable hoto.

Important ES6 Features:

  • let and const
  • Template Literals
  • Arrow Functions
  • Default Parameters
  • Destructuring
  • Spread Operator
  • Object Property Shorthand
  • for...of Loop
Definition: ES6 is a major JavaScript update introduced in 2015 that added modern language features.

2. let and const

ES6 madhye variables declare karnyasathi let ani const introduce kele gele.

let Example:

let age = 20;

age = 21;

console.log(age);

Output:

21

let variable chi value nantar change karta yete.

const Example:

const country = "India";

console.log(country);

Output:

India

const variable la initial value dene compulsory aste ani tyala punha assign karta yet nahi.

Remember: Modern JavaScript madhye default ne const vapra. Value change honar asel tar let vapra.

3. Template Literals

Template Literals cha use strings madhye variables ani expressions easily add karnyasathi hoto.

Template Literals sathi backtick (`) vapartat.

Old Method:

const name = "Rohan";
const age = 20;

const message = "My name is " + name +
                " and my age is " + age;

console.log(message);

ES6 Method:

const name = "Rohan";
const age = 20;

const message = `My name is ${name} and my age is ${age}`;

console.log(message);

Output:

My name is Rohan and my age is 20

Explanation:

  • Backtick vaprun string create keli.
  • ${name} madhye variable chi value add hote.
  • ${age} madhye age chi value add hote.
  • ${} madhye expressions suddha lihita yetat.

Expression Example:

const a = 10;
const b = 20;

console.log(`Total: ${a + b}`);
Total: 30

4. Arrow Functions

Arrow Function ha function lihinyacha short ani modern method aahe.

Old Method:

function add(a, b) {
    return a + b;
}

console.log(add(10, 20));

ES6 Method:

const add = (a, b) => {
    return a + b;
};

console.log(add(10, 20));

Short Syntax:

const add = (a, b) => a + b;

console.log(add(10, 20));

Output:

30
Remember: Arrow Functions cha detail apan Page 11 madhye shiklo aahot. ES6 madhil ha ek important feature aahe.

5. Default Parameters

Function call kartana argument pass kela nahi tar default parameter chi value use hote.

Example:

function greet(name = "Guest") {
    return `Hello ${name}`;
}

console.log(greet("Rohan"));
console.log(greet());

Output:

Hello Rohan
Hello Guest

Explanation:

  • name parameter chi default value Guest aahe.
  • greet("Rohan") call kelyavar Rohan use hoto.
  • greet() call kelyavar Guest use hoto.

6. Destructuring

Destructuring cha use array kiwa object madhil values easily variables madhye store karnyasathi hoto.

Array Destructuring:

const colors = ["Red", "Green", "Blue"];

const [first, second, third] = colors;

console.log(first);
console.log(second);
console.log(third);

Output:

Red
Green
Blue

Object Destructuring:

const student = {
    name: "Rohan",
    age: 20,
    course: "BSc CS"
};

const { name, age, course } = student;

console.log(name);
console.log(age);
console.log(course);

Output:

Rohan
20
BSc CS
Remember: Array Destructuring madhye position important aste. Object Destructuring madhye property name important aste.

7. Object Property Shorthand

Object madhye key ani variable name same asel tar shorthand syntax vaprun code short karta yeto.

Old Method:

const name = "Rohan";
const age = 20;

const student = {
    name: name,
    age: age
};

console.log(student);

ES6 Method:

const name = "Rohan";
const age = 20;

const student = {
    name,
    age
};

console.log(student);

Output:

{ name: "Rohan", age: 20 }

Donhi code cha result same aahe. ES6 shorthand mule unnecessary repetition kami hote.

8. Optional Chaining

Optional Chaining cha use object madhil property access kartana value null kiwa undefined aslyas error talnyasathi hoto.

Example:

const student = {
    name: "Rohan",
    address: {
        city: "Kolhapur"
    }
};

console.log(student.address?.city);
console.log(student.contact?.phone);

Output:

Kolhapur
undefined

Explanation:

  • student.address?.city madhun city milte.
  • student.contact property available nahi.
  • ?. mule error yenyayevaji undefined milte.
Important: Optional Chaining fakt null kiwa undefined access mule honara error talte. Pratyek prakarcha error talat nahi.

9. for...of Loop

for...of loop cha use array kiwa iterable madhil values ek-ek karun access karnyasathi hoto.

Example:

const languages = ["Python", "JavaScript", "Java"];

for (const language of languages) {
    console.log(language);
}

Output:

Python
JavaScript
Java

Ya loop madhye pratyek iteration la array madhil next value language variable madhye yete.

10. ES6 Features Comparison

11. Common Beginner Mistakes

Mistake 1: Template Literal madhye single quotes vaprane

Variable interpolation sathi backtick (`) ani ${} syntax vapra.

Mistake 2: const variable reassign karne

const variable la punha value assign karta yet nahi.

Mistake 3: Destructuring madhye order visarne

Array Destructuring madhye values cha position mahatvacha asto.

Mistake 4: Object property name chukvane

Object Destructuring madhye property name barobar asne avashyak aahe.

Mistake 5: Optional Chaining cha jast use karne

Optional Chaining mule missing property silently undefined deu shakte. Required data missing asel tar validation kara.
