JavaScript Form Validation

Ya lesson madhye form madhil user information validate karne, errors display karne ani valid data submit karne shikuya.

Beginner Level 45–50 Minutes

1. What is Form Validation?

Form Validation mhanje user ne form madhye bharleli information yogya aahe ka te check karne.

Examples:

  • Name field empty nasava.
  • Email address yogya format madhye asava.
  • Password required length cha asava.
  • Confirm Password ani Password same asavet.
Definition: Form Validation is the process of checking user input before accepting or submitting form data.

Validation mule chukichi kiwa incomplete information submit honyapasun rokhta yete.

2. Required Fields

Required field mhanje asa input jyamadhye user ne value bharne avashyak aste.

HTML Example:

<form>
    <input type="text" required>

    <button type="submit">Submit</button>
</form>

Explanation:

  • required attribute field bharne compulsory karte.
  • Field empty asel tar browser form submit hou det nahi.
  • HTML madhye basic validation sathi required vaparta yete.
Remember: HTML required attribute browser-level validation dete. JavaScript vaprun apan custom validation suddha karu shakto.

3. Checking Empty Fields

JavaScript madhye input field empty aahe ka te check karnyasathi value ani trim() vaparta yete.

HTML:

<input type="text" id="username">

<button id="checkButton">Check</button>

JavaScript:

const username = document.getElementById("username");

document.getElementById("checkButton").addEventListener("click", function() {

    if (username.value.trim() === "") {
        alert("Name is required");
    } else {
        alert("Valid Name");
    }

});

Explanation:

  • value input madhil text milavte.
  • trim() suruvatila ani shevti aslele spaces remove karte.
  • Empty value asel tar error message display hoto.
  • Value asel tar valid message display hoto.
Important: User ne fakt spaces type kele tari trim() mule value empty samajli jate.

4. Email Validation

Email validation madhye user ne email yogya format madhye enter kela aahe ka te check kele jate.

HTML:

<input type="text" id="email">

<button id="emailButton">Check Email</button>

JavaScript:

const email = document.getElementById("email");

const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

if (emailPattern.test(email.value)) {
    console.log("Valid Email");
} else {
    console.log("Invalid Email");
}

Explanation:

  • emailPattern madhye Regular Expression aahe.
  • test() method value pattern shi match hote ka te check karte.
  • Match zalyas true return hote.
  • Match naslyas false return hote.
Note: Hi basic email format check aahe. Email address kharach exist karto ka he ya validation madhun samjat nahi.

5. Password Validation

Password validation madhye password required rules follow karto ka te check kele jate.

Example Rules:

  • Minimum 8 characters.
  • At least one uppercase letter.
  • At least one lowercase letter.
  • At least one number.

HTML:

<input type="password" id="password">

JavaScript:

const password = document.getElementById("password").value;

if (password.length < 8) {
    console.log("Password must be 8 characters");
} else {
    console.log("Password Length Valid");
}

Explanation:

  • length property password madhil characters mojte.
  • 8 peksha kami characters aslyas error milto.
  • 8 kiwa tyapeksha jast aslyas length condition pass hote.
Important: Password length check mhanje complete password security nahi. Actual applications madhye server-side validation ani secure password hashing avashyak aste.

6. Confirm Password

Confirm Password cha use user ne password don vela same enter kela aahe ka te check karnyasathi hoto.

HTML:

<input type="password" id="password">

<input type="password" id="confirmPassword">

JavaScript:

const password = document.getElementById("password").value;

const confirmPassword =
    document.getElementById("confirmPassword").value;

if (password === confirmPassword) {
    console.log("Password Matched");
} else {
    console.log("Password Does Not Match");
}

Explanation:

  • Donhi password values access kelya.
  • === operator vaprun values compare kelya.
  • Donhi same aslyas password matched message milto.
  • Vegale aslyas error message milto.

7. Displaying Error Messages

Validation fail zalyas user la kay chukle aahe te message madhun sangta yete.

HTML:

<input type="text" id="name">

<p id="error"></p>

JavaScript:

const name = document.getElementById("name");
const error = document.getElementById("error");

if (name.value.trim() === "") {
    error.textContent = "Name is required";
} else {
    error.textContent = "";
}

Explanation:

  • error paragraph select kela.
  • textContent vaprun error message display kela.
  • Value valid aslyas error message clear kela.
Remember: User input display kartana textContent vaprane innerHTML peksha surakshit aahe.

8. preventDefault() with Validation

Form submit hotana browser default action perform karto. Validation fail zalyas form submission thambvayla preventDefault() vaparto.

Example:

const form = document.getElementById("myForm");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    console.log("Validation Started");

});

Explanation:

  • submit event form submit hotana trigger hoto.
  • event.preventDefault() browser chi default action thambavte.
  • Tyachyanantar apan validation check karu shakto.
  • Valid data asel tar application madhil submission logic chalavta yete.

9. Complete Form Validation Example

Ata Name, Email, Password ani Confirm Password check karanara complete practical example pahuya.

Live Demo:

JavaScript Code:

const form = document.getElementById("validation-demo-form");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    // Get Values
    const name = document.getElementById("validation-name").value.trim();
    const email = document.getElementById("validation-email").value.trim();
    const password = document.getElementById("validation-password").value;
    const confirmPassword = document.getElementById("validation-confirm-password").value;

    // Get Error Elements
    const nameError = document.getElementById("validation-name-error");
    const emailError = document.getElementById("validation-email-error");
    const passwordError = document.getElementById("validation-password-error");
    const confirmError = document.getElementById("validation-confirm-error");
    const success = document.getElementById("validation-success");

    // Clear Old Messages
    nameError.textContent = "";
    emailError.textContent = "";
    passwordError.textContent = "";
    confirmError.textContent = "";
    success.textContent = "";

    let isValid = true;

    // Name Validation
    if (name === "") {
        nameError.textContent = "Name is required";
        isValid = false;
    }

    // Email Validation
    const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

    if (!emailPattern.test(email)) {
        emailError.textContent = "Enter a valid email";
        isValid = false;
    }

    // Password Validation
    if (password.length < 8) {
        passwordError.textContent = "Minimum 8 characters required";
        isValid = false;
    }

    // Confirm Password
    if (confirmPassword === "" || password !== confirmPassword) {
        confirmError.textContent = "Passwords do not match";
        isValid = false;
    }

    // Final Result
    if (isValid) {
        success.textContent = "Validation successful!";
        form.reset();
    }

});
Important: Ya demo madhye validation successful zalyavar form reset hoto. Ha demo data Django server la save kiwa submit karat nahi. Actual Django application madhye server-side validation suddha karavi lagte.

10. Common Beginner Mistakes

Mistake 1: trim() na vaprane

Fakt spaces enter kele tari input empty samajla jau shakto. Mhanun text validation kartana trim() vapra.

Mistake 2: Password comparison na karne

Confirm Password ani Password donhi same aahet ka te check kara.

Mistake 3: preventDefault() visarne

Custom validation karaychi asel tar form submit event madhye preventDefault() vapra.

Mistake 4: Error messages clear na karne

Navin validation suru kartana previous error messages clear kara.

Mistake 5: Fakt JavaScript validation var depend rahane

Client-side validation bypass hou shakte. Backend madhye suddha validation avashyak aahe.
