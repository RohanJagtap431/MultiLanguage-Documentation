JavaScript Local Storage

Ya lesson madhye browser madhye data permanently save karne, read karne, update karne ani delete karne shikuya.

Beginner Level 30–35 Minutes

1. What is Local Storage?

Local Storage hi browser madhil ek storage facility aahe. Yachya madatine apan website cha data browser madhye save karu shakto.

Browser close kela kiwa page refresh kela tari save kelela data rahato. To manually remove kareparyant kiwa browser data clear kareparyant rahu shakto.

Definition: Local Storage is a browser storage feature used to store key-value data on the user's device.

Examples:

  • Website theme preference save karne.
  • User settings store karne.
  • Simple notes save karne.
  • Shopping cart data store karne.

2. Local Storage Properties

Local Storage madhye data key-value pair format madhye store hoto.

Example:

localStorage.setItem("name", "Rohan");

Ya example madhye name hi key aahe ani Rohan hi value aahe.

Important: Local Storage madhye keys ani values strings mhanun store hotat. Object kiwa array save karaycha asel tar JSON.stringify() vapra.

3. setItem() Method

setItem() cha use Local Storage madhye data save karnyasathi hoto.

Syntax:

localStorage.setItem("key", "value");

Example:

localStorage.setItem("username", "Rohan");

console.log("Data Saved");

Output:

Data Saved

Browser madhye Developer Tools open karun Application section madhye Local Storage check karta yete.

4. getItem() Method

getItem() cha use Local Storage madhun save kelela data read karnyasathi hoto.

Syntax:

localStorage.getItem("key");

Example:

localStorage.setItem("username", "Rohan");

const name = localStorage.getItem("username");

console.log(name);

Output:

Rohan
Remember: getItem() madhye key dilyavar tyachi value milte. Key nasel tar null milte.

5. removeItem() Method

removeItem() cha use Local Storage madhun specific key ani tyachi value delete karnyasathi hoto.

Example:

localStorage.setItem("username", "Rohan");

localStorage.removeItem("username");

console.log(localStorage.getItem("username"));

Output:

null

6. clear() Method

clear() cha use Local Storage madhil sarv keys ani values delete karnyasathi hoto.

Example:

localStorage.setItem("name", "Rohan");
localStorage.setItem("course", "BSc CS");

localStorage.clear();

console.log(localStorage.getItem("name"));

Output:

null
Warning: clear() current website chya origin madhil Local Storage madhil sarv data delete karto. Mhanun kalajipurvak vapra.

7. Updating Local Storage Data

Same key sobat setItem() punha call kelyas existing value replace hote.

Example:

localStorage.setItem("city", "Pune");

localStorage.setItem("city", "Kolhapur");

console.log(localStorage.getItem("city"));

Output:

Kolhapur

Ya example madhye city chi old value Pune hoti. Navin value Kolhapur save zalyamule old value replace zali.

8. JSON with Local Storage

Local Storage madhye direct JavaScript Object save hot nahi. Object la string madhye convert karun save karava lagto.

Object Save Karne:

const student = {
    name: "Rohan",
    age: 20,
    course: "BSc CS"
};

localStorage.setItem(
    "student",
    JSON.stringify(student)
);

Object Read Karne:

const data = localStorage.getItem("student");

const studentData = JSON.parse(data);

console.log(studentData.name);
console.log(studentData.course);

Output:

Rohan
BSc CS
Remember: Object save kartana stringify() ani read kartana parse() vapra.

9. Local Storage vs Session Storage

Browser madhye Local Storage ani Session Storage he don storage options aahet.

Local Storage Session Storage
Data browser sessions madhye tikto. Data current tab session purta asto.
Browser restart nantarhi data rahu shakto. Tab close kelyavar data clear hoto.
localStorage vapartat. sessionStorage vapartat.

10. Practical Example – Notes Saving App

Ata ek simple Notes Saving App tayar karu. Ya app madhye note save, read ani delete karta yeil.

HTML:

<textarea id="noteInput"
    placeholder="Write your note"></textarea>

<button id="saveNote">Save Note</button>
<button id="deleteNote">Delete Note</button>

<p id="status"></p>

JavaScript:

const noteInput = document.getElementById("noteInput");
const saveButton = document.getElementById("saveNote");
const deleteButton = document.getElementById("deleteNote");
const status = document.getElementById("status");

// Load saved note
noteInput.value = localStorage.getItem("myNote") || "";

// Save note
saveButton.addEventListener("click", function() {
    localStorage.setItem("myNote", noteInput.value);
    status.textContent = "Note saved successfully!";
});

// Delete note
deleteButton.addEventListener("click", function() {
    localStorage.removeItem("myNote");
    noteInput.value = "";
    status.textContent = "Note deleted!";
});

Working:

  • User textarea madhye note lihito.
  • Save Note click kelyavar note Local Storage madhye save hote.
  • Page refresh kelyavar saved note parat load hote.
  • Delete Note click kelyavar note delete hote.
Security Note: Passwords, authentication tokens kiwa sensitive personal data Local Storage madhye store karne talave. JavaScript madhun Local Storage access karta yete.

11. Common Beginner Mistakes

Mistake 1: Object direct save karne

Object save karnyapurvi JSON.stringify() vapra.

Mistake 2: JSON.parse() visarne

Stored JSON string object madhye convert karnyasathi parse() vapra.

Mistake 3: Wrong key vaprane

setItem() ani getItem() madhye key same asne avashyak aahe.

Mistake 4: clear() cha unnecessary use

Specific data delete karaycha asel tar removeItem() vapra.

Mistake 5: Local Storage la database samajne

Local Storage browser-based storage aahe. Te Django database sarkhe server-side database nahi.

12. Quick Revision

  • Local Storage browser madhye data save karte.
  • setItem() data save karte.
  • getItem() data read karte.
  • removeItem() specific data delete karte.
  • clear() sarv Local Storage data delete karte.
  • Same key var setItem() kelyas value update hote.
  • JSON.stringify() object la string madhye convert karte.
  • JSON.parse() string la JavaScript value madhye convert karte.
