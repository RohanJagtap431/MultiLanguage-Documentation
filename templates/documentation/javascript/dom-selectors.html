DOM Selectors

Ya lesson madhye JavaScript vaprun HTML elements select kase karayche te shikuya. DOM Selectors mule apan specific HTML elements access karu shakto.

Beginner Level 35–40 Minutes

1. What are DOM Selectors?

DOM Selectors mhanje JavaScript madhil ase methods jyanchya madatine HTML document madhil specific elements select karta yetat.

Element select kelyanantar apan tyacha text, style, attributes ani itar properties access kiwa update karu shakto.

Definition: DOM Selectors are methods used to find and access HTML elements from a document.

Common DOM Selectors:

  • getElementById()
  • getElementsByClassName()
  • getElementsByTagName()
  • querySelector()
  • querySelectorAll()

2. getElementById()

getElementById() method cha use HTML madhil specific ID asanara element select karnyasathi hoto.

HTML:

<h1 id="heading">Hello World</h1>

JavaScript:

const heading = document.getElementById("heading");

console.log(heading);

Explanation:

  • document HTML document access karte.
  • getElementById() ID vaprun element select karte.
  • heading variable madhye selected element store hoto.
Important: ID select kartana # symbol vapraycha nahi. Fakt ID che name lihayche.

3. getElementsByClassName()

Ya method cha use same class name asanare HTML elements select karnyasathi hoto.

HTML:

<p class="message">First Message</p>
<p class="message">Second Message</p>

JavaScript:

const messages =
    document.getElementsByClassName("message");

console.log(messages);
console.log(messages[0]);
console.log(messages[1]);

Explanation:

  • Same class asanare elements select hotat.
  • Result HTMLCollection asto.
  • Index vaprun specific element access karta yeto.
  • Index 0 pasun suru hoto.
Remember: Class select kartana dot (.) vapraycha nahi. Fakt class name lihayche.

4. getElementsByTagName()

Ya method cha use specific HTML tag name asanare sarva elements select karnyasathi hoto.

HTML:

<p>First Paragraph</p>
<p>Second Paragraph</p>
<h1>Welcome</h1>

JavaScript:

const paragraphs =
    document.getElementsByTagName("p");

console.log(paragraphs);
console.log(paragraphs[0]);

Explanation:

  • Tag name vaprun elements select hotat.
  • Result HTMLCollection asto.
  • Fakt p elements select kele aahet.

5. querySelector()

querySelector() method CSS selector vaprun element select karte. Matching elements madhil fakt pahila element return hoto.

HTML:

<h1 id="title">Welcome</h1>

<p class="message">Hello Student</p>

<p class="message">Learn JavaScript</p>

JavaScript:

const title = document.querySelector("#title");

const message = document.querySelector(".message");

console.log(title);
console.log(message);

Important CSS Selectors:

Selector Meaning
#title ID select karte.
.message Class select karte.
p Paragraph tag select karte.
div p div madhil paragraph select karte.
Important: querySelector() matching elements madhil fakt pahila element return karte. Element match nasel tar null milte.

6. querySelectorAll()

querySelectorAll() method CSS selector vaprun matching asanare sarva elements select karte.

HTML:

<p class="message">First</p>
<p class="message">Second</p>
<p class="message">Third</p>

JavaScript:

const messages =
    document.querySelectorAll(".message");

console.log(messages);
console.log(messages[0]);
console.log(messages[1]);

Explanation:

  • Matching sarva elements select hotat.
  • Result NodeList asto.
  • Index vaprun element access karta yeto.
  • forEach() vaprun NodeList madhil elements var loop chalavta yeto.

Using forEach():

const messages =
    document.querySelectorAll(".message");

messages.forEach(function(message) {
    console.log(message.textContent);
});

Output:

First
Second
Third

7. DOM Selectors Comparison

Method Returns Selection
getElementById() Single Element ID
getElementsByClassName() HTMLCollection Class
getElementsByTagName() HTMLCollection Tag
querySelector() Single Element First CSS match
querySelectorAll() NodeList All CSS matches
Note: HTMLCollection ani NodeList ya donhi collections madhye anek elements asu shaktat. HTMLCollection live aste, tar querySelectorAll() chi NodeList static aste.

8. Practical Example – DOM Selectors

Khali dilelya example madhye apan ID, Class ani querySelectorAll() vaprun elements select karu.

HTML:

<h1 id="pageTitle">My Website</h1>

<p class="info">Learn Python</p>
<p class="info">Learn JavaScript</p>

<button id="changeButton">Change Title</button>

JavaScript:

const title = document.getElementById("pageTitle");

const infos = document.querySelectorAll(".info");

const button = document.querySelector("#changeButton");

button.addEventListener("click", function() {
    title.textContent = "Welcome to DOM Selectors!";

    infos.forEach(function(item) {
        item.textContent = "JavaScript Selected";
    });
});

Live Output:

My Website

Learn Python

Learn JavaScript

Button click kelyavar heading ani donhi paragraphs madhil text change hoto.

9. Common Beginner Mistakes

Mistake 1: ID select kartana # vaprane

getElementById() madhye fakt ID name lihayche. querySelector() madhye # vapraycha.

Mistake 2: Class select kartana dot vaprane

getElementsByClassName() madhye dot vapraycha nahi. querySelector() madhye . vapraycha.

Mistake 3: querySelector() sarva elements return karte ase samajne

querySelector() fakt pahila matching element return karte. Sarva elements sathi querySelectorAll() vapra.

Mistake 4: Index 1 pasun suru samajne

JavaScript collection madhil index 0 pasun suru hoto.

Mistake 5: Missing element check na karne

Element match nasel tar kahi selectors null return kartat. Element access karnyapurvi to available aahe ka te check kara.

10. Quick Revision
